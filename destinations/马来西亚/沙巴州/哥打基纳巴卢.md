# 哥打基纳巴卢（亚庇）

哥打基纳巴卢通称亚庇，是婆罗洲西北岸的沙巴州首府。加雅街的店屋里，牛杂汤粉和鱼汤面常从早餐就开始供应；逢周日，果蔬、糕点和手工艺摊占满街面。往海边走几条街，载客的小艇已在码头往返近岸岛屿。傍晚的丹绒亚路，沙滩上的木麻黄与海面上的岛影一起勾出西岸的轮廓。

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 首访重点 | 早上看加雅街或市区海岸，另留一天搭船去东姑阿都拉曼海洋公园，傍晚再回市区吃海鲜 |
| 建议停留 | 2–3 天适合市区、海岛与一次近郊文化参观；京那巴鲁山区需另外安排交通和住宿 |
| 天气 | 船班受风浪、雷雨及园方公告影响。海洋公园日放在停留中段，方便与陆上活动调换 |
| 费用 | 船票、码头费用、海洋公园入园费、浮潜装备及活动各有收费条件，订票时逐项确认 |
| 步行强度 | 老城与海滨可分段平缓步行，码头上下船、沙滩与文化村高脚屋的通行条件各异 |

## 城市格局与游览区域

市中心沿着西海岸展开。加雅街（Jalan Gaya）在老城区，往西很快到海边的滨海步道，往北则到哲斯顿码头（Jesselton Point）。从码头出发的近岸岛屿中，马努干岛（Manukan）和沙比岛（Sapi）都属于东姑阿都拉曼海洋公园；两者即使在同一天安排，岛间也要乘船。

丹绒亚路（Tanjung Aru）位于市中心以南，海滩与机场同在城市南侧，两处各有独立入口。沙巴州博物馆园区在城区南部内陆；马里马里文化村在东北方向的 Inanam、Kionsom 一带，需要公路接送。京那巴鲁公园则在更远的内陆山区，需按跨区公路行程计算车程。

## 美食与餐饮

加雅街一带适合从一碗粉面开始。Ngiu chap 是牛杂汤粉，常把牛肉丸、不同部位的牛肉和内脏配在一起，点单时可说明喜欢的配料。鱼汤面（mi sup ikan）则以鱼片或鱼块为主，也有干拌面配汤的吃法。周日市集从早晨开始，买一两份小糕点分食，能给午餐留下余地。

市中心海滨的海鲜餐馆通常按品种、重量和烹调方式计价。点活鲜先确认计价单位与总重量，再选清蒸、炒或其他做法。晚餐和日落若安排在同一晚，可先决定留在市区滨海步道还是去丹绒亚路看海，再订附近的餐位。

## 经典行程

| 场景 | 建议走法 |
|---|---|
| 市区一日 | 上午从加雅街吃早餐，逢周日加上市集；沿海滨看码头。午后去州博物馆当日开放的分馆，傍晚乘车到丹绒亚路 |
| 两日初访 | 首日走市区、加雅街与丹绒亚路。次日上午到哲斯顿码头乘船，留在一座岛上吃午饭，按约定船班回城 |
| 三日海岛与文化 | 在两日线外加一个文化村预约场次，半天看住宅和传统工艺。余下半天回市区休息，也能作为海况变化时的调整空间 |
| 风浪或雷雨 | 停航时改为老城咖啡店和当天开放的博物馆分馆。文化村含露天路段，先与运营方核实天气安排 |
| 亲子或少步行 | 先以市区海滨和加雅街一小段为主，午间留时间休息。想登岛时向船家确认上下船协助、救生衣尺寸和岸上遮阴条件 |
| 市集主题 | 把周日上午完整留给加雅街，再到街内咖啡店吃面；前一晚若有周末夜市，可对照同一条街的夜宵摊与清晨货摊 |

## 住宿区域

| 区域 | 适合谁 | 订房时留意 |
|---|---|---|
| 加雅街／市中心 | 喜欢步行找早餐、市集和海滨的人 | 周末市集期间部分路段限车，提前与酒店确认车辆在哪个路口接送 |
| 哲斯顿码头周边 | 清早登岛、夜间希望留在市区用餐的人 | 按实际公共入口确认步行距离，住海景房时尤其要核对所在岸段 |
| 丹绒亚路 | 希望多看海滩、行程偏悠闲的人 | 海滩、度假村与机场分别使用不同入口，去码头和市集另计车程 |

## 市内交通

亚庇国际机场代码为 BKI，抵达后可按到达层指示乘出租车或在指定位置叫车。市中心各处距离看似短，跨主干道、等红灯和中午日晒都会增加体力消耗；加雅街至海滨可步行，丹绒亚路、博物馆园区、文化村适合另叫车或提前约接送。

哲斯顿码头是从市区登岛的主要公共出发点。柜台售票时确认具体岛名、登船口、岛间接驳、返城上船位置和时间。搭船后按工作人员要求穿救生衣。若行程还包括京那巴鲁山，山区接送与登山许可须另办，登顶需注册向导并预留至少两天的山程。

## 不同旅行者须知

带幼儿或行动较慢的旅行者，可把海滩观景与下水活动分开决定；码头梯级、船舷和潮位会影响上下船，出发前把协助需求告知运营方。文化村参观通常随团步行，行动辅助设备能否进入各座展示屋以村方答复为准。住市集附近的人可在周日前一晚向住宿方确认离店时的接车地点。

## 行前核对

- 查海洋公园公告及船方当日安排，保留至少一套陆上活动；买票时记录回程码头和接人时间。
- 确认州博物馆园区真实开放的具体馆舍，预约文化村时核对场次与包含的接送。
- 看日落先查雷雨和返程车辆，赶飞机的当天优先选陆上活动。
- 京那巴鲁山登顶是独立山地行程，按公园规定核对许可、注册向导与山屋安排。
