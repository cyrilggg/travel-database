# 新山

新山是柔佛州首府，隔着柔佛海峡与新加坡相望。长堤一端是通勤人潮汇集的车站和关卡，走进西南侧的老城区，沿街店屋却仍按各自的节奏烤面包、煮咖啡。柔佛古庙的一口铜钟和木牌记录着华人社群的往来，山坡上俯望海峡的苏丹阿布峇卡清真寺，则把另一段州王室的历史留在城市轮廓里。

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 初访重点 | 从陈旭年街走到柔佛古庙，用半天认识长堤旁的老城；再到州清真寺看柔佛建筑与海峡的关系 |
| 停留 | 一天可走市中心历史街区。两天可加西侧文化景点；带孩子去乐高乐园宜另留完整一天 |
| 天气 | 热带日间湿热，老街适合上午慢走，阵雨时可在文物馆、咖啡店或车站相连的商场休息 |
| 预算 | 街区和宗教建筑外围适合自由散步；博物馆、园区、机场交通与跨境铁路分别计费 |

## 城市格局与游览区域

JB Sentral（新山中央车站）在长堤马来西亚一端，附近通过连廊连接苏丹依斯干达大厦关卡（CIQ）和市中心商场。想进老城，先按市区方向下到地面，再去 Jalan Trus 的柔佛古庙和 Jalan Tan Hiok Nee（陈旭年街）。陈旭年街、Jalan Dhoby 和 Jalan Ibrahim 集中了传统店屋、餐饮和文物馆，适合步行串联。

州清真寺在老城区以西的高地，往返建议留一段车程；热天步行还要考虑道路过街点。马来西亚乐高乐园在更西面的依斯干达公主城（Iskandar Puteri），是独立的跨城目的地。若主要行程是老城和新加坡通关，住在乐园附近会增加每天的往返时间。

## 美食与餐饮

早上走老街，可从传统咖啡、烤面包或 kacang pool 开始。后者是浓稠的蚕豆料理，常配鸡蛋和烤面包，适合坐下来慢慢吃。午餐可尝 mee rebus，黄面配浓酱和配料；多人用餐还可选酸辣的 asam pedas 鱼菜，配白饭分享。

陈旭年街与 Jalan Dhoby 适合把早餐、买面包和看店屋连起来。准备搭跨境火车的人，可把最后一餐放在车站附近，先按检票截止时间安排离席。周末热门老店和乐园餐厅的用餐队伍都要另算时间。

## 经典行程

| 场景 | 建议走法 |
|---|---|
| 老城一日 | 上午逛陈旭年街与 Jalan Dhoby，早午餐后去华族历史文物馆和柔佛古庙。下午乘车上州清真寺所在山坡，傍晚回市中心 |
| 两日文化与慢游 | 首日专注老街、咖啡店与文物馆。次日上午根据礼拜安排去州清真寺，午后回车站商区吃饭休息，留出返程交通余量 |
| 三日亲子 | 两日城市线中加入单独的乐园日。早晨直接去依斯干达公主城，下午仍留在同一园区，晚饭后再回住宿处 |
| 雨天 | 把文物馆、老店午餐和 JB Sentral 相连商区排在同一天。骑楼有顶，换街和过路时仍有露天路段 |
| 少步行 | 以 Jalan Ibrahim 或陈旭年街一端作为落客点，选一间馆和一条街。去清真寺分别安排上下车位置，减少连续上坡 |
| 新加坡往返短停 | 先订好回程交通。抵新山后只走老城与古庙，最后一站放在车站附近；返程按检票、查验及走连廊所需时间倒推 |

## 市内交通

士乃国际机场（JHB）可乘 Causeway Link 的 AA1 机场巴士往返 JB Sentral，按当天班次核对具体上车层与末班。市中心步行适合相邻老街之间；去州清真寺或乐园可选出租车、网约车或预订接送。长堤两侧的平均行车时间难以反映实际排队长度，安排同日航班时要给通关独立留时。

跨境铁路 Shuttle Tebrau 连接 JB Sentral 与新加坡 Woodlands Train Checkpoint。订票使用实际乘车护照信息，原件用于检票。按铁路运营方现行说明，新山出发在开车前 30 分钟开闸、前 10 分钟关闸；兀兰出发在前 40 分钟开闸、前 20 分钟关闸。前往新加坡市区还需由兀兰火车关卡换乘陆路交通。新柔捷运 RTS Link 截至研究日处于开通筹备阶段，官方目标为 2027 年 2 月开始客运，实际开通时间以两地公告为准。

## 不同旅行者须知

跨境旅行准备入境材料时，按本人证件、国籍与行进方向查阅两国当局要求；列车检票条件和边检条件分别确认。带孩子去乐园，先按身高和天气挑主园，订好返程接送。需要无台阶通行的人，可提前询问老建筑的楼层开放情况，在关卡和商场连接处跟随电梯标识换层。

## 行前核对

- 确认 Shuttle Tebrau 的方向、车次、护照资料和对应车站关闸时间；RTS Link 按最新运营公告判断是否可用。
- 参观宗教场所与文物馆先查当天时间，节庆或礼拜期间调整停留区域。
- 订乐园时核对园区、日期和所在城市，机场日同时查 AA1 末班与航班值机时间。
