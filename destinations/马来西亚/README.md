# 马来西亚旅行目的地

半岛城市可串联吉隆坡、马六甲、怡保与乔治市；沙巴州的亚庇位于婆罗洲，另行安排航班和住宿。乔治市正文聚焦历史城区，地图入口沿用槟岛身份。
