# 马来西亚旅行目的地

半岛西岸可串联巴生、吉隆坡、怡保、乔治市和亚罗士打，东岸另有彭亨的关丹与登嘉楼的瓜拉登嘉楼。美里和亚庇都在婆罗洲，分别属于砂拉越和沙巴，组合行程时要单独安排城际交通。乔治市正文聚焦历史城区，地图入口沿用槟岛身份。

## 组合与行前准备

前往槟城，搭火车到北海可从[威省](./槟城州/威省.md)查车站与渡轮的衔接，再看海峡对岸的[乔治市](./槟城州/乔治市.md)。古晋由两个市政机构管理，沿河老街和两岸村落见[古晋北区](./砂拉越州/古晋北区.md)，市政公园与传统市场见[古晋南区](./砂拉越州/古晋南区.md)。跨城时按具体机场、铁路站或码头计算抵离时间；当天开放、预约、班次及天气通过各篇官方入口确认。
