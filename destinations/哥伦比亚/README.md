# 哥伦比亚旅行目的地

沿加勒比海岸向东，可从[卡塔赫纳](./玻利瓦尔省/卡塔赫纳.md)的城墙老城，经[巴兰基亚](./大西洋省/巴兰基亚.md)前往[圣玛尔塔](./马格达莱纳省/圣玛尔塔.md)，再单独安排泰罗纳国家公园的入园日。在内陆，波哥大适合逛高原老城和博物馆，麦德林可搭缆车看山坡社区，到卡利则值得留出夜晚听萨尔萨音乐。想住进咖啡产区可从金迪奥省的亚美尼亚城出发，亚马孙河行程则从莱蒂西亚另行安排。
