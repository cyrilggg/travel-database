# 乌兹别克斯坦旅行目的地

塔什干适合作为抵离和换乘的起点。撒马尔罕的大型建筑群分布在不同街区，布哈拉和希瓦则适合围绕老城步行。四城跨越不同地区，订票时请按各篇交通章节核对车站、机场和住宿的位置。

## 四城之间的铁路

按从东到西的顺序，可将塔什干、撒马尔罕、布哈拉、希瓦串成一线。查询时选具体日期和站点，分别看每段的抵达时刻，再决定当天还能安排多少步行。境外旅客按实际乘车护照填写购票资料，保留电子票和到站名称，方便在酒店约接送。[乌兹别克斯坦旅游部门交通指南](https://uzbekistan.travel/en/i/travel-tips/) · [铁路运营方电子票说明](https://eticket.uzrailpass.uz/en/pages/how-to-buy)
