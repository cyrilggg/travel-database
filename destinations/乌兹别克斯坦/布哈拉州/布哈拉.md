# 布哈拉旅行指南

布哈拉是一座绿洲商城，老城的道路从池塘边伸进有穹顶的十字路口。商贩仍在砖拱下摆开织物和金绣，茶桌则沿着拉比豪兹池的岸边排列。走出商廊，卡扬宣礼塔细密的砖纹和经学院的蓝色瓷面相继出现。更西边，萨曼王朝陵墓只用砖块的方向和凹凸便织出整面墙的纹样，同一种材料在这里既搭起了店铺，也塑造了城市最庄重的建筑。

> 建议停留：老城 2 天，加入城外夏宫可留 3 天\
> 旅行关键词：丝路商廊、砖砌宣礼塔、经学院、绿洲饮食\
> 主要体力：老城平路为主，城堡入口有坡，夏季户外日晒强\
> 最近研究：2026-11-24

## 城市速览

| 到访条件 | 怎样安排 |
|---|---|
| 初访 | 从池畔、商廊走到宣礼塔，在相连的街口辨认商业、宗教和教学空间 |
| 关注工艺 | 细看宣礼塔砖纹、陵墓墙体和商廊拱券，再进织物工坊看同类几何图案如何用于刺绣 |
| 喜欢建筑史 | 西侧陵墓与城堡留半天，城外夏宫另留半天，便于对照不同朝代的居住与纪念空间 |
| 天气和费用 | 炎热时在早晚走广场，午间转到有顶商廊或餐厅。城堡、博物馆与宫殿依各自入口核对票务 |

## 城市格局与游览区域

拉比豪兹池（Lyabi-Hauz）靠近核心步行区东南侧，是约定碰面、用餐和找住宿的实用地标。沿弯曲街道向西北，经数座圆顶市场走到卡扬建筑群（Poi-Kalyan），宣礼塔、清真寺和米里阿拉伯经学院围绕同一处广场。商廊有多个出口，记住上一座穹顶的名称比只跟着主街走更容易找到回路。

从卡扬向西是阿尔克城堡（Ark），继续往西到萨曼王朝陵墓所在的公园。这一段在地图上与老城相连，走完后再原路返回会增加不少曝晒时间。西托拉伊·莫希霍萨夏宫（Sitorai Mohi Xosa）是城外的埃米尔行宫，适合用车往返。

## 主要景点

| 地点 | 看点 | 建议用时与条件 |
|---|---|---|
| 拉比豪兹池与周边经学院 | 在池岸观察教学建筑与苏菲修习场所怎样围出公共空间；从对岸能看清入口拱门与水池的比例 | 45–75 分钟，池边适合休息，演出和建筑内部各按当日安排 |
| 圆顶市场与有顶商廊 | 辨认道路交会处的穹顶与两侧摊位，找找金匠、帽商等旧行当留在建筑名称里的痕迹 | 1–1.5 小时，观看织造或近拍工匠前先征得同意 |
| 卡扬建筑群 | 从塔脚看砖环的砌法，再往经学院方向退几步，把塔、蓝色穹顶与清真寺门廊放在一起观察 | 1–1.5 小时。礼拜和教学空间按现场允许范围进入 |
| 阿尔克城堡与博洛豪兹清真寺 | 城堡高台与坡道呈现旧统治中心的防御尺度；广场另一侧的清真寺以细长木柱撑起前廊 | 1.5–2 小时，城堡展室以当天开放为准，清真寺内依礼拜时段参观 |
| 萨曼王朝陵墓 | 从四面比较砖砌的凹凸纹理与拱角，光线变化会让同一面墙上的纹样显出不同深浅 | 45–60 分钟，可连公园休息一起安排 |
| 埃米尔夏宫 | 从彩色窗饰、镜面装饰的接待厅看宫殿如何结合本地工艺和欧洲式布局，与老城经学院的庭院形成对照 | 含往返约半天，入场前核对当日开放厅室 |

## 美食与餐饮

布哈拉抓饭（oshi sofi）常把米与肉分别煮好，再配胡萝卜和油装盘。点餐时可从一人份尝起，看分层装盘后米粒和配菜的口感；询问当日所用肉类与油脂，有饮食限制的人还可请店家说明米饭所用的汤底。午间到本地抓饭馆吃主餐，晚些时候再到池畔喝茶，能把用餐与观景分开。

拉比豪兹周围方便坐下来吃饭，附近商廊也有小吃和茶点。多人想分食烤肉串时，先问每串的肉类、大小和面饼是否另点。夏天从西侧城堡回到街市，可在有遮阴的餐桌补水再走下一段。

## 经典行程

| 场景 | 路线与取舍 |
|---|---|
| 只有一天 | 上午先走阿尔克城堡与木柱前廊，中午回到卡扬建筑群附近用餐。午后经有顶商廊一路向拉比豪兹池走，晚间留在池畔。若抵达较晚，从卡扬开始即可 |
| 老城两日 | 第一天从池边一路向北看圆顶市场、经学院和卡扬，预留逛手工艺店的时间。第二天上午从西侧萨曼陵墓步行到博洛豪兹与城堡，午餐后回到第一天最感兴趣的街口 |
| 两晚加城外半日 | 首日走东侧池畔与商廊，次日看老城西段，第三日上午预约车辆往返夏宫。若当天搭火车离开，让司机确认接行李的位置，并给从市区前往卡甘的车程留余量 |

## 住宿区域

| 区域 | 适合谁 | 选房细节 |
|---|---|---|
| 拉比豪兹周边 | 第一次来、希望晚上步行用餐的人 | 老城小巷内常需步行到门口，先向旅馆索取司机可停靠的路口 |
| 卡扬至城堡一带 | 建筑摄影、清晨走广场的人 | 核对到最近主路的实际距离、房间楼层与行李搬运条件 |
| 老城外围的现代街道 | 带大件行李、需要车辆到门或早班车的人 | 按到老城入口及卡甘车站的分别车程选址；酒店名称与门牌可一并保存 |

## 市内交通

从塔什干、撒马尔罕方向乘火车抵达时，主要客运站“布哈拉站”实际位于东南方向的卡甘市（Kogon / Kagan）。车票目的地、旅馆所在老城与司机会合点是三个不同位置。抵达后乘车进布哈拉，离开时按实际站名和车次核对，把取行李、进站及上车时间都算入行程。

核心街区适合步行，打车可在老城外围的主路上下。前往城外夏宫，把往返、等候和结束地点与司机一并说清；两人分开游览时可在池畔或城堡主入口会合。

## 不同旅行者须知

使用轮椅或手推车可从拉比豪兹池周围和卡扬广场外部开始，古巷铺面、商廊门槛、城堡坡道各有高差，订导览时具体询问可通行的入口。宗教空间按礼拜安排和着装要求进入。与孩子同行可让他们先在宣礼塔上找砖纹，再到陵墓四面找相似图案，中途在公园或有顶茶座休息。

## 行前核对

- 将火车票站名与卡甘接车地址一起发给司机，保存住宿的车辆落客位置。
- 查出行日城堡、陵墓和夏宫的开放范围与票务，周五提前询问清真寺的访客时段。
- 拍摄织物制作或宗教活动前征求同意。夏季给露天广场留早晚时段，正午在有遮阴的地方用餐。
