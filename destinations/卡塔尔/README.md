# 卡塔尔旅行目的地

住在多哈，可以把老市场和港湾博物馆放在同一天，再按方向安排半日或一日外出。向北去卢赛尔看现代海滨，向西去赖扬的教育城，向南则到沃克拉逛临海市场。

| 地区 | 城市指南 | 旅行主题 |
|---|---|---|
| [多哈市](./多哈市/README.md) | [多哈](./多哈市/多哈.md) | 旧市场、海滨大道与博物馆 |
| [戴扬市](./戴扬市/README.md) | [卢赛尔](./戴扬市/卢赛尔.md) | 海滨新城、电车与体育场 |
| [赖扬市](./赖扬市/README.md) | [赖扬](./赖扬市/赖扬.md) | 教育城、图书馆与公共艺术 |
| [沃克拉市](./沃克拉市/README.md) | [沃克拉](./沃克拉市/沃克拉.md) | 渔港、海岸老市场与沙滩 |

## 从多哈搭地铁出发

三条地铁线在 Msheireb 站交会。前往教育城，可按场馆选择绿线 Education City 或 Qatar National Library 站；去卢赛尔海滨，可先到 Legtaifiya 站，按当天运营区段选择电车或接驳巴士。红线向南到 Al Wakra 站后，去海岸市场还有一段市内接驳。[卡塔尔旅游局地铁指南](https://visitqatar.com/intl-en/plan-your-trip/getting-around/doha-metro)
