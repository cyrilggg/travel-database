# 山东省旅行目的地

山东从黄海、渤海沿岸延伸到鲁中山地、沂蒙山区、黄河下游与鲁西平原，省内城市的旅行主题和交通边界差异很大。济宁与聊城分别以大运河、湖区和运河商贸遗产为主；东营把油田城市史与黄河口湿地分开组织，滨州沿黄河下游展开主城文博、孙子文化、季节农业和滨海湿地，德州则把运河老城、苏禄王墓、东部公共文化片区与夏津古桑林分开安排。枣庄由多个城区组团构成，威海沿胶东半岛东端展开海防史、城市海岸、海岛与分散县级市；日照以东港城市海岸为核心，向南进入岚山港产与茶乡复合地带，向西分别连接莒县文化线和五莲山地。曲阜、邹城、临清、滕州、荣成、乳山、邹平、乐陵、禹城等法定县级市仍按独立城市统计，不能因为由地级市代管或常与主城组合就自动计作完成。

当前目录收录达到 `researched` 状态的十六座地级城市，并另行收录县级诸城市，共十七座城市。诸城由潍坊代管，但拥有独立法定代码、城市页和完整旅行范围；其他山东城市将在城市范围、交通结构、景点去重、动态核对项和官方来源均完成研究后加入。空模板、自动目录和未研究页面不计作覆盖完成。

## 区域格局与行程组合

- 青岛中心滨海带：由青岛湾老城向东经过汇泉湾、八大关、太平角，延伸到浮山湾的五四广场与奥帆中心。片区内部适合步行，片区之间应使用公共交通，不能把整条海岸当成普通一日步道。
- 青岛远郊与跨湾：崂山包含多个不同入口和游览区，一天通常只选一条线；金沙滩位于胶州湾西岸黄岛方向，应按跨湾独立行程处理。
- 济南泉水与明府城：趵突泉、五龙潭、黑虎泉、护城河和大明湖共同构成天下第一泉风景区的不同游览段，城市覆盖只计为一个完整景区；相邻的曲水亭街、百花洲和芙蓉街可与景区串联，并按一个明府城历史街区处理，内部街巷不再拆分计数。
- 济南山城关系与远郊：千佛山位于中心城区南侧，山东博物馆和山东美术馆位于经十路东段；章丘的百脉泉、朱家峪与长清的灵岩寺均需跨区移动，应按独立半日或一日行程处理。泰山、曲阜属于其他地级市，不列入济南景点。
- 济南的莱芜—钢城组团：2018 年国务院批复撤销原莱芜市并将其市域划入济南，现由莱芜区与钢城区承接；旧称“莱芜市”不是另一座现行法定城市。两区位于泉水主城东南远端，莱芜城区、雪野、齐长城沿线、北部山地和钢城分属不同接驳方向，至少独立安排 1 天。生产钢厂、矿区、货运铁路、水库工程区和非开放齐长城段不得当作普通景点。
- 泰安山城主轴：通天街、岱庙、岱宗坊和红门构成泰城至山麓的连续文化轴；岱庙与泰安市博物馆是同一实地单元。红门、天外村、桃花峪、东御道和天烛峰是进入泰山主景区的不同线路，中天门、十八盘、南天门、天街、玉皇顶、景交和索道均不拆分计数。
- 泰安远郊与县域：大汶口遗址公园通常需要半日至一日，东平湖范围广且至少单独一日；新泰市、肥城市、宁阳县和东平县均有独立县域旅行体系，不能因收录泰安市页或到访其中一个节点自动计作完成。
- 淄博多中心结构：张店是铁路、住宿与市级场馆中枢；临淄、周村、淄川、博山和桓台分处不同方向，跨区移动应按半日至一日安排。齐文化博物院内部两馆、周村古商城内部街巷院落、蒲松龄故居相关节点和同一陶琉园区均不重复计数。
- 淄博南北主题：博山与淄川南部连接陶琉、文学、工业文化和山地，桓台向北连接马踏湖与王渔洋故里。山地与湿地受天气、生态管理和接驳影响，济南、青岛则属于独立地级市，不列入淄博景点。
- 临沂主城区：兰山老城集中王羲之故居、银雀山汉墓竹简博物馆等文化节点，北城新区设临沂市博物馆；沂河把兰山、北城与河东片区连接成较长的城市带，过河或跨片区宜乘车，不能把整段滨河空间当成连续短步道。
- 临沂县域方向：沂南、沂水、蒙阴、平邑和费县分处不同方向，革命纪念地、洞穴与蒙山各游览区应按独立一日安排。同一景区内部展馆、旧村或山岳节点不重复计数；云蒙、龟蒙等入口相互独立，也不因共用“沂蒙山”品牌而合并成同一入口。
- 烟台中心城区：芝罘老城与港城滨海是首访中枢，莱山—高新区、开发区—福山和牟平—养马岛分处东西两翼；片区之间应乘车，不能把整条海岸视为连续短步道。
- 烟台蓬莱、长岛与县域：蓬莱陆地主城可独立一日，长岛需从蓬长客港按海况乘船；龙口、招远、莱州等县级市各自至少按一日处理。复合蓬莱 5A、养马岛整岛及长岛各完整景区的内部节点不重复计数。
- 潍坊中心城区与寒亭：潍城—奎文串联世界风筝博物馆、十笏园、潍坊市博物馆和潍县旧址博物馆，寒亭的杨家埠适合独立半日至一日。十笏园街区和杨家埠园区的内部院落、展馆及作坊均不拆分计数。
- 潍坊县域方向：青州、临朐、诸城、寿光、高密等各有自己的车站、住宿和完整旅行主题，通常按独立一日处理。诸城现有独立城市页；诸城市恐龙博物馆与诸城中国暴龙馆是相距明显、使用不同入口的两个场馆，而各馆内部化石点和展厅不重复计数。青州、寿光、高密等法定县级市仍需各自完成研究。
- 菏泽主城与牡丹园带：曹州核心、主城东部公共文化片区和北部牡丹园带不是一条连续步行线；花期通常只选曹州牡丹园、曹州百花园或冠宇牡丹园其中一座，每座园的内部展区与演艺不再拆分计数。非花期可用市博物馆、书画院和曹州文化线替代赏花路线。
- 菏泽县域方向：定陶、郓城、巨野、单县和东明分处不同方向，每条线都要另算去返交通。水浒主题演艺不能代替真实历史材料；浮龙湖、黄河湿地与普通河岸也不是同一开放范围。县域目的地只按一日模块组合，不因同属菏泽市而横向压进同一天。
- 济宁主城与县域：任城老城、太白湖、兖州与东部公共文化区不是一个连续步行圈；嘉祥武氏墓群石刻、汶上南旺、微山湖、梁山等方向应分别占用一日。曲阜和邹城是法定县级市，需独立建页；港区、矿区、沉陷地与生产铁路不作为自由进入的旅行空间。
- 聊城湖城与运河：水上古城、东昌湖、东关运河与运河博物馆可按分段步行和短途交通组合，完整绕湖不等于普通街区漫步。阳谷、东阿、冠县、莘县、高唐各自需要县域接驳；临清是法定县级市，应独立建页。阿胶生产区、农业园和水利设施只有正式开放的访客部分可以进入。
- 东营城市组团与黄河口：东城、西城相距明显，垦利与黄河口湿地又是独立远郊方向；广饶历史线位于市域南部，应另占一日。黄河口生态旅游区整体只计一次，自然保护区及世界遗产组件不是自由进入的景点；油井、管线、盐田、养殖塘和港口生产区也必须遵守准入边界。
- 滨州主城与滨北：滨城区西部新城、蒲湖—黄河楼和滨北不是一个连续步行圈，主城东西向移动与滨北半日线都需要城市交通。杜受田故居和渤海革命老区纪念园可同向安排，但仍是两个分别核对开放状态、以车辆连接的场馆。
- 滨州县域与滨海：惠民、沾化、阳信、无棣和博兴分属不同公路方向，通常一日只选一个县域；孙武古城内部开放单元按一个完整景区去重。邹平是法定县级市，应独立建页。贝壳堤岛与湿地自然保护区、黄河防洪工程、盐碱地试验田、港口、油田、盐田和养殖塘不因邻近旅游线路而成为自由进入的景点。
- 德州老城与东部片区：德城老城、运河古街、苏禄王墓与东部博物馆—董子园风景区—德州东站片区不在同一连续步行圈，应分段乘车。“两河潮生”VR 体验馆位于德城区运河古街，是付费数字文化体验项目，不按传统博物馆或整条运河景区重复计数。
- 德州县域与管理边界：夏津黄河故道古桑林适合独立一日，陵城及宁津、庆云、临邑、齐河、平原、武城等方向也需另算往返；乐陵、禹城是法定县级市，应独立建页。天衢新区是省级新区与功能管理区域，不是新增市辖区；运河、黄河、漳卫河沿线的闸坝、泵站、作业堤防、历史航道和复航规划线路不能按公共滨水空间进入。
- 枣庄多中心结构：薛城新城、市中老城和峄城虽共同组成中心城区体系，仍需跨组团交通；台儿庄与山亭是更远的独立目的地，滕州则是法定县级市，需另建城市记录。台儿庄古城及其内部运河节点、铁道游击队纪念园、同一煤矿遗产园和抱犊崮—熊耳山各按完整运营单元去重。生产矿井、废弃井口、工业铁路、运河航道、地质裂隙和未开放山洞均不得因“工业遗产”或“探险”主题自由进入；枣庄站位于薛城，不能按站名推定在市中老城。
- 威海海岸与县级市：环翠老城、刘公岛、高区西海岸、经区和文登分属不同片区，不能把三面海岸当作一条连续步道。刘公岛及内部博物馆、遗址和炮台按一个完整景区去重；火炬高区、经区和临港区是功能管理称谓，不是新增法定市辖区。荣成、乳山是法定县级市，成山头、那香海和银滩均按跨城整日方向处理，不计入威海主城完成范围。海岛船班、浴场、风浪、台风和冬季结冰必须动态核对，港口、养殖、生产岸线和未开放礁滩不作为普通景点。
- 日照东港主城与城市海岸：文博中心、万平口—东夷小镇—灯塔沿线、北部阳光海岸绿道与森林公园、南部刘家湾分属不同游览段，不能把整条海岸压成一条轻松步道。万平口的门区、沙滩和内部节点按一个景区去重，东夷小镇与绿道短段作为路线节点；刘家湾只有在景区开放、潮汐和现场活动区均允许时进入。离岸流可能出现在表面较平静的浪线缺口，是否游泳必须服从规范泳区、现场旗号、广播和救生管理；台风、雷雨、大浪或闭园通知下取消海岸活动。
- 日照岚山与西部县域：岚山位于东港主城以南，港口、工业、茶乡和旅游海岸并存，多岛海与确认接待的茶文化点可组成独立一日；石臼港区、岚山港区、养殖区、工业道路、施工岸线、保护地、未开放沙滩和礁石不作为观景或抄近路空间。莒县位于主城以西，莒州博物馆与莒国古城可同日组合，浮来山更适合作为另一个主项目；五莲县位于西北方向，五莲山和九仙山归入同一上位景区，当日通常二选一。岚山、莒县和五莲县三个方向不能横向串进同一天。
- 鲁中与鲁西历史文化线：泰安、曲阜、淄博等目的地涉及山岳、古建筑、博物馆和遗址，需按各自预约、体力与行政范围独立研究。
- 县级城市与景区型目的地：只有在交通边界、城市属性和官方来源达到质量要求后才加入；同一景区内部子景点不拆成多个“已完成城市”。
