# 江苏省旅行目的地

江苏跨越长江两岸，城市密集，高铁与城市轨道使主要目的地之间的组合较为方便。南京以山水城林、明代遗存、近现代史场馆和长江空间见长；苏州则以古城水系、古典园林和江南饮食为核心。两座城市可以连游，但各自都需要独立安排，不宜压缩成同一天的往返打卡。

## 区域格局与城市组合

南京的核心游览区沿钟山—中山东路—老城南展开，玄武湖与明城墙位于老城北部，河西和长江滨江在主城西部；牛首山、栖霞山等外围目的地需要单独半天至一天。苏州行政范围同样很大，主城、太湖沿岸、吴江古镇以及代管县级市不能视作一个可连续步行的目的地。苏州城市页以姑苏古城和相邻城区为核心，将同里等外围目的地标为独立一日路线；昆山、常熟、太仓和张家港以后应分别建立城市记录。

南京与苏州之间有铁路联系，具体车次与到发车站应在购票时核对。跨城行程至少给每座城市保留一个完整游览日，并把换酒店、进出站和市内接驳计入时间。
