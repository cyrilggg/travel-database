# 江苏省旅行目的地

江苏跨越淮河、长江与太湖流域，城市密集，但历史城区、湖岸、港区、县域山水和代管县级市常处在不同旅行尺度。本目录现收录十九座达到 `researched` 标准的城市：既有南京、苏州、扬州和镇江等古城与文博目的地，也有徐州的汉代考古和矿区转型、宜兴的紫砂陶与阳羡山水、太仓的江海文化，以及沿江、沿海、运河和太湖城市。城市之间可用铁路或轨道组合，每座仍应保留完整游览日，不能因交通便捷而把行政范围或景区边界混在一起。

## 区域格局与城市组合

南京的核心游览区沿钟山—中山东路—老城南展开，玄武湖与明城墙位于老城北部，河西和长江滨江在主城西部；牛首山、栖霞山等外围目的地需要单独半天至一天。

无锡的梁溪老城、惠山、蠡湖—鼋头渚和马山是不同尺度的片区。江阴现已建立独立城市记录；宜兴同样拥有独立城区和旅行体系，不能作为无锡市区的顺路景点。苏州太湖岸与常州太湖湾也属于其他城市。苏州行政范围同样很大，主城、太湖沿岸、吴江古镇以及代管县级市不能视作一个可连续步行的目的地。苏州城市页以姑苏古城和相邻城区为核心，将同里等外围目的地标为独立一日路线；昆山、常熟、张家港和太仓现均有独立城市记录。

太仓是苏州市管辖的法定县级市，法定代码 `320585`，不属于苏州主城区或上海市域。娄城主城区、沙溪古镇、浏河江海文化片区和港城相互分离，通常依靠公交或车辆衔接；沙溪与浏河各适合独立半日至一天。郑和公园与园内纪念馆、沙溪古镇与内部街巷展馆分别按完整游览单元理解。港区以生产和口岸功能为主，只前往明确开放的公共景点，不进入工作码头、限定区域或跨越围挡；上海—苏州—无锡—常州城际铁路太仓段仍应按运营方现状核对，不能把在建线路写成已经开通。

江阴北临长江，旧城、外滩和滨江要塞虽都位于主城，却不构成一条全天连续步行线；徐霞客故里、长泾、华西和新桥分属不同乡镇方向。锡澄 S1 连接无锡主城区与江阴，不改变两座城市独立统计的边界。江阴周庄镇也不是昆山周庄古镇，港口、船厂、工业园区和桥下空间均不因地图可见而对游客开放。

徐州位于江苏西北部，主城可分为彭城老城、云龙湖—泉山、汉文化景区、龟山和徐州东站等片区；贾汪的湖区、山地与矿区转型项目应另留半日至一天。新沂、邳州是法定县级市，拥有独立城区与旅行体系，不计入徐州城市页完成率；矿井、铁路专用线、采石区和生产港区也只有在正式开放时才能进入。

宜兴是无锡代管的法定县级市，宜城主城、丁蜀陶业空间、湖㳇竹海与洞穴、张渚—善卷、云湖和太湖西岸分属不同方向。紫砂作坊、龙窑和生产区域不因“陶都”主题而默认开放；善卷洞、竹海及太湖水域受维护、天气、防火和生态管控影响，应按独立半日或一日安排。

昆山的玉山主城区、巴城—正仪、花桥和南部古镇不是一个连续步行区。主城区适合作为铁路到达与住宿基地，正仪以戏曲百戏博物馆和沪苏轨道联系见长，巴城延伸至阳澄湖东岸，花桥是连接上海的现代门户；周庄、锦溪、千灯则是三座彼此独立的古镇景区。昆山市虽然由苏州市代管，仍按法定县级市独立统计；甪直、同里和朱家角分别属于苏州吴中、苏州吴江和上海青浦，不能计入昆山景点完成度。

常熟的虞山、古城和尚湖距离较近，但分别对应山地、街巷与湖泊景区三种游览尺度；沙家浜、古里和梅李需要独立接驳。常熟虽由苏州市代管，仍按法定县级市独立统计。尚湖风景区与尚湖镇不是同一范围，“沙家浜·虞山尚湖旅游区”的等级总称也不作为额外景点重复计数。

张家港的暨阳主城适合作为住宿和交通中心，香山—金港、凤凰—塘桥及乐余—常阴沙分属不同方向，张家港湾与双山岛还受长江水情、船班和开放边界影响。张家港虽由苏州市代管，仍按法定县级市独立统计；江阴与常熟是相邻城市，不计入张家港景点完成度。港口、码头、船厂和产业园区只有明确开放的公共空间才能进入，生产岸线不能按地图自行探访。

泰州的海陵老城、姜堰—溱湖、医药高新区（高港区）和三个代管县级市分属不同旅行尺度。凤城河内部楼园按一个完整景区统计，溱湖与溱潼是两个独立运营单元；兴化、泰兴、靖江均是法定县级市，本页列出的千垛、黄桥或长江岸线不代表三个城市已自动完成。江苏泰州与浙江台州中文写法不同，购票和检索必须同时核对省份与完整站名。

扬州的广陵老城、蜀冈—瘦西湖、运河三湾、西部邗江与江都分别需要步行或车辆接驳。个园和何园是独立园林，瘦西湖内部亭桥不拆成多个完成项；运河三湾与扬州中国大运河博物馆相邻但各自管理。高邮、仪征是法定县级市，宝应是独立县域，邵伯和江都水利设施也不属于古城步行圈，安排时应单独核对交通与返程。

常州的天宁—钟楼老城、新北、武进、金坛和溧阳也属于不同旅行尺度。青果巷、天宁寺—红梅公园和古运河可组成主城文化线；中华恐龙园与春秋淹城应各自按大型主题目的地安排；金坛茅山和溧阳天目湖则需要独立一天或住宿。常州太湖湾不能与无锡太湖景点混算，金坛一侧的茅山度假区也不能与镇江句容的茅山景点混算。

镇江的京口—润州主城沿长江与古运河展开，金山、西津渡和镇江博物馆可连成一条西部文化线，北固山与焦山位于主城东北侧，丹徒则是范围更广的市辖区。句容、丹阳和扬中是法定县级市，均需独立城市记录；句容茅山、丹阳南朝石刻与扬中江岛不计入镇江主城步行范围。镇江“三山”按金山、焦山、北固山三个独立景区计数，各自内部亭阁不重复；港口、船厂、生产岸线、山林防火区和长江水域只进入正式开放部分。

南通的濠河老城、五山滨江、唐闸、通州和海门也不是一个连续步行区。南通博物苑、寺街—西南营和一段濠河可组成主城文化日；五山滨江与唐闸应分日安排；海门张謇故里需要独立半天至一天。启东、如皋、海安三个县级市和如东县拥有各自的旅行中心，不作为南通主城顺路景点；长江南岸的张家港、常熟属于苏州市，上海崇明也不属于南通。

淮安的清江浦主城、淮安区古城、淮阴北部、洪泽湖东岸和盱眙同样不是一个连续步行区。清江浦适合作为住宿与换乘中心，淮安区的河下、纪念场馆、漕运博物馆和府署应占一整天；洪泽湖与盱眙还应各自安排一天。淮安北接连云港、东邻盐城、南接扬州和安徽滁州、西邻宿迁，南京并非相邻城市；洪泽湖跨越较大范围，不能把宿迁一侧湖区项目计入淮安景点完成度。

盐城主城区以亭湖、盐都和盐南片区为城市服务核心，大丰区城、沿海麋鹿保护主题、亭湖黄尖丹顶鹤方向、盐都大纵湖以及五县各自相距明显。黄海候鸟栖息地是多组成部分的系列世界遗产，不等于整条海岸或所有湿地景区；公众景区、自然保护区、港区和生产岸线的边界必须分别遵守。东台是盐城代管的法定县级市，仍须独立建页，条子泥与黄海森林公园不能作为盐城主城的顺路加项。

宿迁的宿城—宿豫主城、骆马湖—三台山、皂河和洋河分属不同旅行方向。皂河龙王庙行宫与龙运城适合按同一片区安排，但古建、现代展演和夜场各有开放边界；沭阳、泗阳、泗洪则是独立县域目的地。洪泽湖湿地属于泗洪方向，不能因湖区跨域而计入淮安城市完成度。

连云港的海州主城、连云港站周边旧新浦、海州古城、东部连云港区和三县也不在同一连续步行范围。海州与连云之间由东西向公共交通和道路连接；花果山、连岛各需完整时段，连岛经道路抵达，而赣榆秦山岛需要按船班、潮汐和海况独立安排。东海水晶、灌云大伊山与灌南二郎神文化等属于县域路线，不能当作海州或连岛的顺路加项；生产港区也不作为自由进入的观景区。

省内城市之间有铁路、轨道或公路联系，具体车次与到发车站应在购票时核对。徐州站与徐州东站、宜兴站与各南部景区、江阴站与无锡主城，以及其他同名或近似站点服务的片区并不相同；规划或在建车站也不能按未来名称提前使用。跨城行程至少给每座城市保留一个完整游览日，并把换酒店、进出站和市内接驳计入时间。
