# 江苏省旅行目的地

江苏跨越长江两岸，城市密集，高铁与城市轨道使主要目的地之间的组合较为方便。南京以山水城林、明代遗存、近现代史场馆和长江空间见长；无锡把太湖、古运河、近代工商记忆与锡帮菜连在一起；苏州以古城水系、古典园林和江南饮食为核心；常州则把大运河老城、博物馆、主题乐园和溧阳山水连接成两套不同节奏的路线；南通由濠河文博、五山滨江和唐闸工业遗存展开，再向通州、海门与沿海地区延伸；淮安从清江浦里运河延伸到淮安区古城，再以洪泽湖和盱眙形成独立的湖区、县域旅行。六座城市可以顺铁路组合，但各自都需要独立安排，不宜压缩成同一天的往返打卡。

## 区域格局与城市组合

南京的核心游览区沿钟山—中山东路—老城南展开，玄武湖与明城墙位于老城北部，河西和长江滨江在主城西部；牛首山、栖霞山等外围目的地需要单独半天至一天。

无锡的梁溪老城、惠山、蠡湖—鼋头渚和马山是不同尺度的片区。行政范围内的江阴、宜兴拥有独立城区和旅行体系，不作为无锡市区的顺路景点；苏州太湖岸与常州太湖湾也属于其他城市。苏州行政范围同样很大，主城、太湖沿岸、吴江古镇以及代管县级市不能视作一个可连续步行的目的地。苏州城市页以姑苏古城和相邻城区为核心，将同里等外围目的地标为独立一日路线；昆山、常熟、太仓和张家港以后应分别建立城市记录。

常州的天宁—钟楼老城、新北、武进、金坛和溧阳也属于不同旅行尺度。青果巷、天宁寺—红梅公园和古运河可组成主城文化线；中华恐龙园与春秋淹城应各自按大型主题目的地安排；金坛茅山和溧阳天目湖则需要独立一天或住宿。常州太湖湾不能与无锡太湖景点混算，金坛一侧的茅山度假区也不能与镇江句容的茅山景点混算。

南通的濠河老城、五山滨江、唐闸、通州和海门也不是一个连续步行区。南通博物苑、寺街—西南营和一段濠河可组成主城文化日；五山滨江与唐闸应分日安排；海门张謇故里需要独立半天至一天。启东、如皋、海安三个县级市和如东县拥有各自的旅行中心，不作为南通主城顺路景点；长江南岸的张家港、常熟属于苏州市，上海崇明也不属于南通。

淮安的清江浦主城、淮安区古城、淮阴北部、洪泽湖东岸和盱眙同样不是一个连续步行区。清江浦适合作为住宿与换乘中心，淮安区的河下、纪念场馆、漕运博物馆和府署应占一整天；洪泽湖与盱眙还应各自安排一天。淮安北接连云港、东邻盐城、南接扬州和安徽滁州、西邻宿迁，南京并非相邻城市；洪泽湖跨越较大范围，不能把宿迁一侧湖区项目计入淮安景点完成度。

南京、无锡、苏州、常州、南通与淮安之间有铁路联系，具体车次与到发车站应在购票时核对。南通站、南通西站和多种“南通东站”含义容易混淆，且南通站枢纽建设可能改变接驳，不能仅凭城市名判断位置。跨城行程至少给每座城市保留一个完整游览日，并把换酒店、进出站和市内接驳计入时间；相邻城市也不应在半天内把两地核心景点硬拼成一条路线。
