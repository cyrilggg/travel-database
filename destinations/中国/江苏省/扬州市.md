# 扬州旅行指南

扬州的核心旅行体验分布在三条彼此相连、节奏不同的线上：广陵老城适合沿街巷寻找园林、盐商住宅与地方手艺，蜀冈—瘦西湖适合用半天到一天看城市园林与水岸关系，运河三湾和扬州中国大运河博物馆则把古代水运放进更大的历史与地理框架。早茶和淮扬菜不是行程之外的附加项目，而是理解城市生活方式的重要一环。主城两至三天可以形成完整认识；江都、高邮、仪征和宝应方向需要另算公路、铁路与返程时间。

> 建议停留：2–4 天\
> 旅行关键词：瘦西湖、古城街巷、盐商园林、大运河、博物馆、淮扬菜、早茶\
> 主要体力：中等步行；园林假山、老街石板路和瘦西湖长线会增加负担\
> 最近研究：2026-07-30

## 城市格局与游览区域

旅行者所说的“扬州古城”主要位于广陵区：东关街—东圈门、国庆路、仁丰里、皮市街和南河下一带集中了园林、盐商住宅、传统商业与小型场馆。古城西北接蜀冈—瘦西湖片区，向南沿古运河抵达运河三湾与扬州中国大运河博物馆；西部邗江区分布着扬州站、扬州博物馆和较新的居住商业区，隋炀帝陵遗址公园则在主城西北外围。三者并非一条可以从早走到晚的连续步行线。

江都区位于主城以东，江都城区、邵伯古镇和位于丁沟镇的扬州泰州国际机场彼此仍有明显距离。高邮市、仪征市是扬州市代管的两个法定县级市，宝应县是独立县域；它们分别拥有自己的城区、车站和旅行资源。高邮的盂城驿与湖区、仪征的丘陵与长江沿线、宝应的湖荡与运河段不能视为扬州古城的“顺路景点”，也不能因完成本页而自动算作这些县级城市或县域已经研究完成。

## 主要景点

优先级用于安排时间，不代表绝对排名：**A** 为首访核心，**B** 为按兴趣补充，**C** 为远郊、季节性或通常需要独立半天以上的目的地。车站、开放街巷、公共岸线和观景平台等标记为“路线节点”，不计入城市景点完成率。同一景区及其内部子景点只作为一个项目记录。

## 美食与餐饮

扬州饮食的两条主线是早茶点心和淮扬菜。早茶适合放在上午并预留等位时间，淮扬菜则更重视刀工、火候、清鲜和汤汁。古城、文昌阁周边、瘦西湖外围与成熟社区都有同类型餐饮，不必把某一家老字号当作唯一答案；热门门店满位时，优先寻找菜单、份量与价格标示清楚的同类茶社或地方菜馆。

| 菜品或餐饮类型 | 常见区域 | 一个人用餐与常见份量 | 风味、过敏原与饮食限制 | 排队风险与替代方法 |
|---|---|---|---|---|
| 扬州早茶：烫干丝、包子、蒸饺、翡翠烧卖、千层油糕 | 古城、瘦西湖外围和社区茶社 | 可按笼、只或小份组合，适合一人；套餐常有重复主食，可先少量加点 | 面点含小麦；干丝含大豆，调味可能含芝麻油、虾米；三丁、五丁和汤包常含猪肉、鸡肉、虾或海参 | 周末和节假日热门茶社排队长；改选社区茶社，先问候位、最低消费和是否现点现蒸 |
| 扬州炒饭 | 全城淮扬菜馆、家常餐馆 | 单份适合一人，但正式餐厅份量可能够两人分享 | 常见配料有鸡蛋、虾仁、火腿或肉丁；不能从菜名推定为素食，需确认酱油、猪油和配料 | 名店候位时可选普通淮扬菜馆；先问是否现炒及能否去除过敏配料 |
| 大煮干丝与烫干丝 | 早茶店、淮扬菜馆 | 烫干丝多为小份冷盘或早点，大煮干丝常适合共享 | 主要原料为豆制品；大煮汤底可能含鸡汤、火腿、虾仁和猪油，素食者需逐项确认 | 热门早茶时段等待较久；也可在正餐店点大煮干丝，避免只追逐早餐名店 |
| 蟹粉狮子头、清炖狮子头等淮扬菜 | 古城和新城正规淮扬菜馆 | 狮子头可按只询价，但蟹粉、整锅或宴席做法常适合两人以上 | 以猪肉为主，蟹粉含甲壳类过敏原；高汤、淀粉、大豆和酒类调味需确认 | 秋季和节假日蟹粉菜需求高、价格波动；无法确认来源或份量时改点普通清炖做法 |
| 扬州盐水鹅与卤味 | 菜市场、熟食店、社区餐馆 | 常可按重量切片，适合一人少量购买；整鹅适合多人 | 咸鲜，钠含量较高；卤水可能含香辛料、酱油和酒，购买后注意冷藏与食用时限 | 热门摊位会售罄；选择明码标价、卫生条件清楚的正规经营点，不必固定一家 |
| 河鲜、湖鲜与时令水产 | 古运河、江都及全城地方菜馆 | 多为共享份量；点单前确认按份、按重量还是时价，以及加工费 | 鱼、虾、蟹和贝类过敏风险高；细刺、未熟透水产和共锅油需留意 | 节假日、蟹季与湖鲜旺季价格和候位上升；要求称重和总价确认，不购买来源不明水产 |
| 藕粉圆子、糯米藕及季节甜品 | 老城小吃店、茶社和甜品店 | 单碗或小份适合一人，糯米类饱腹感强 | 常含糯米、糖、桂花、芝麻或坚果；糖摄入受限者先问甜度和糖浆 | 景区店容易集中排队；选择配料说明清楚的同类店，季节缺货时不必勉强寻找 |

对素食、清真、低盐或过敏饮食有要求时，应把高汤、猪油、虾籽、蟹粉、火腿、蚝油和共锅油都纳入询问；“清淡”“素包”或“干丝”不能自动等于无动物成分。早茶现点现蒸需要时间，安排一桌点心时不要再用紧接的预约场馆压缩用餐。

## 经典行程

### 一日经典路线

**路线**：瘦西湖北门或大明寺 → 瘦西湖单向游线 → 个园 → 东关街短段

- **串联逻辑**：上午沿蜀冈和瘦西湖由北向南移动，下午乘短途车辆到个园，再把东关街作为离园后的步行收尾；这样避免在瘦西湖内往返，也不把整座古城塞进一天。
- **预约锚点**：先核对瘦西湖和个园当日票务、入园时段；若加入大明寺，还要独立确认宗教活动和入口。
- **休息安排**：瘦西湖游客服务区、景区出口及东关街外围成熟商业区；夏季将户外长段放在较凉时段。
- **时间不足时**：先删大明寺或东关街夜段，保留瘦西湖单向游线和个园；低体力条件下把瘦西湖缩为南段。

### 两日城市路线

**第 1 天**：大明寺或唐城遗址博物馆二选一 → 瘦西湖 → 古城北部晚餐

**第 2 天**：个园 → 东关街—东圈门短段 → 仁丰里或皮市街 → 何园

- **串联逻辑**：第一天集中在蜀冈水岸，第二天顺古城东北到东南移动；个园和何园分别承担早、晚两个园林锚点，中间街巷用于换气而不是逐店打卡。
- **预约锚点**：瘦西湖、个园、何园；小型场馆若有闭馆日，直接从街巷段中删除。
- **休息安排**：古城内每参观一座园林安排一次室内餐饮或茶歇；园林假山和街巷石板路不连续叠加。
- **时间不足时**：第二天在个园与何园中保留一座，再走与其相邻的一段街巷；不要为了“看两园”压缩园内停留。

### 三日深度路线

**第 1 天**：大明寺 → 瘦西湖单向游线 → 北护城河或古城北部

**第 2 天**：个园 → 东关街—仁丰里 → 何园 → 古运河短段

**第 3 天**：扬州中国大运河博物馆 → 运河三湾短环线 → 古城或新城晚餐

- **串联逻辑**：三天分别建立园林水岸、盐商古城和大运河整体史三个层次；第三天只安排一座大型博物馆，给常设展、临展和休息留足弹性。
- **预约锚点**：第三天优先锁定扬州中国大运河博物馆，再倒推其余日期；瘦西湖与两座园林按各自官方渠道核对。
- **休息安排**：博物馆内使用明确开放的休息区，三湾只选靠近场馆的一段；古城日午间回到成熟餐饮区避暑或避雨。
- **时间不足时**：第三天删三湾远段，第二天删第二座园林或古运河夜段；不要压缩博物馆为一小时“打卡”。

### 雨天路线

**路线**：扬州中国大运河博物馆 → 室内午餐 → 扬州博物馆或一座确认开放的小型场馆

- **适用条件**：普通降雨时以大型室内场馆为主，场馆之间乘车；暴雨、雷电大风、积水或台风预警下取消跨城移动和水岸活动。
- **预约锚点**：两座博物馆的开放、闭馆日、实名预约和临展规则相互独立，优先保留已成功预约的一馆。
- **休息安排**：在馆内或邻近成熟商业区用餐，不把三湾公园、东关街和古运河岸线当作雨天遮蔽路线。
- **时间不足时**：只保留扬州中国大运河博物馆；若无预约，则改为扬州博物馆或一座已确认可入场的场馆。

### 亲子或低体力路线

**亲子路线**：扬州中国大运河博物馆适龄展厅 → 馆内午休 → 运河三湾靠近博物馆的短段 → 提前结束或返回成熟商业区

**低体力路线**：扬州中国大运河博物馆无障碍入口 → 一至两个重点展厅 → 馆内休息 → 车辆前往古城外围用餐；次日另选何园或瘦西湖南段，不在同日叠加

- **减负方式**：亲子路线提前确认童车、寄存、互动项目年龄和监护规则，并避开临水追跑；低体力路线使用馆方轮椅和电梯服务，园林路线另行确认门槛、坡道与可跳过段落。
- **预约锚点**：扬州中国大运河博物馆；如改去园林，按所选园林重新核对入口和票务，不能沿用博物馆预约。
- **休息安排**：馆内服务区、三湾游客服务点及车辆可达的商业区；不要把户外长椅视为高温或暴雨时可靠的休息点。
- **时间不足时**：两条路线都只保留一座主场馆；亲子路线删三湾，低体力路线不临时增加古城石板路。

### 远郊一日路线

**路线**：扬州主城 → 江都城区短暂停靠 → 邵伯古镇核心街区 → 邵伯古堤、码头与运河故道观察段 → 返回主城

- **适用条件**：适合希望理解大运河水工与集镇关系、能够承担往返公路接驳和中等步行者；高温、暴雨、强风和水位异常时取消临水长段。
- **串联逻辑**：邵伯镇内的古镇、古堤、码头和运河故道属于同一遗产片区，可在一地集中理解，不再顺路增加高邮或宝应。
- **预约锚点**：邵伯计划进入的展馆或收费点；若江都水利枢纽相关展示确认可预约，可替换江都城区停靠，而不是临时闯入生产管理区。
- **休息安排**：江都城区和邵伯镇正规餐饮、游客服务设施；出发前确认返程站点和末班，不把网约车即时接单当作唯一保障。
- **时间不足时**：整段删除江都城区停靠，只保留邵伯核心；若返程不稳，则放弃远郊，改走主城古运河和三湾。

高邮、仪征和宝应不作为这条远郊路线的加项。前往高邮盂城驿或湖区、仪征丘陵与长江沿线、宝应湖荡和运河段时，应各自建立完整的一日或过夜方案，并按对应城市或县域计算。

## 住宿区域

| 区域 | 优点 | 缺点 | 适合人群 | 交通特点 |
|---|---|---|---|---|
| 文昌阁—国庆路 | 位于老城与现代商业交界，餐饮和公共交通选择多，前往东关街、个园和瘦西湖较均衡 | 节假日拥堵和噪声较明显，酒店停车与车辆进出不一定方便 | 首访、独行、以古城和餐饮为核心者 | 多条地面公交和出租车可用，步行到不同景点仍需选择方向，不宜每天横穿全城 |
| 东关街—古运河外围 | 早晚可步行体验古城街巷，靠近个园、何园和古运河 | 核心步行街内行李拖行、叫车和安静度受限，老建筑无障碍差异大 | 喜欢老城氛围、早出晚归和轻装旅行者 | 车辆通常在街区外围上下客；订房前确认最近可停车或叫车点 |
| 瘦西湖南部—蜀冈南缘 | 靠近瘦西湖、北护城河和部分早茶餐饮，园林行程起步方便 | 旺季价格、客流和交通管制压力较高，前往三湾和东站较远 | 以瘦西湖、园林和较慢节奏为主者 | 步行覆盖只限湖区一端；去古城南部、博物馆和车站仍需乘车 |
| 西部新城—扬州站 | 现代酒店、商业和道路条件较完整，靠近扬州站与扬州博物馆 | 距离老城和三湾较远，历史氛围弱 | 铁路经扬州站抵离、重视房间条件、低体力或自驾者 | 以公交、出租车或网约车进老城；注意扬州站与扬州东站不是同一站 |
| 扬州东站—生态科技新城 | 适合从扬州东站抵离，前往三湾和江都方向相对直接 | 夜间古城体验少，去瘦西湖与老城核心需要跨片区 | 抵离时间紧、重点参观大运河博物馆或继续向东者 | 东站接驳便利，但不能仅凭“东部”推定到机场很近 |
| 江都城区 | 便于江都、邵伯和机场方向，日常餐饮成本通常较可控 | 不适合作为每天往返扬州古城的默认基地 | 有机场早晚航班、江都业务或专门安排邵伯日者 | 前往主城、邵伯和机场是三个方向，需分别确认交通，不应合并估时 |

不推荐未经核验的具体酒店。古城民宿和历史建筑住宿应在预订前确认消防疏散、隔音、楼梯、电梯、行李接送、车辆到达点和潮湿情况；“临近东关街”不等于出租车能停到门口，“湖景”也不等于步行可直达景区入口。

## 市内交通

### 抵达扬州

- **铁路**：主城旅行常用扬州东站和扬州站。扬州东站在城市东部，适合接古城东侧、三湾和江都方向；扬州站在西部邗江，接西部新城和扬州博物馆更方便。购票、接站和打车时必须以中国铁路 12306 的票面站名为准，不能把两站视作同一枢纽的不同出口。
- **航空**：扬州泰州国际机场位于江都区丁沟镇，是扬州、泰州共享的机场，离扬州古城仍有一段公路接驳。机场巴士、公交、出租车、航点、值机区和二期施工组织均属于动态信息，应按机场和承运航司公告核对。
- **跨江与周边城市**：镇江与扬州隔长江相望，可经公路桥梁、铁路组合或镇扬汽渡等方式移动。汽渡首先服务渡运，受大风、浓雾、水位和管制影响，不应把它当作固定班次的观光船。南京、镇江、泰州和高邮的铁路或公路时间也不能替代扬州城内接驳时间。

### 主城片区移动

- **公交**：扬州主城以地面公交为公共交通骨架，可连接铁路站、瘦西湖、古城外围和三湾。线路、首末班、节假日绕行和景区临时接驳会变化，出发当天查询运营方或交通部门公告。
- **出租车与网约车**：适合在瘦西湖、古城南北、三湾和西部场馆之间减步行。古城步行街、节假日管制区和景区出口可能需要走到指定上下客点；定位时写清具体入口而非只写景区名。
- **步行**：个园—东关街、仁丰里—皮市街、何园—南河下等可以分段连续步行；瘦西湖内部是长线，古城到三湾、扬州博物馆或隋炀帝陵遗址公园不适合靠步行串联。
- **骑行**：古城外围和部分公共绿道可用于短距离补充，但核心步行街、人群密集区、石板路和景区内部通常需要下车或禁行。雨天、水岸、夜间和高温下不宜把共享单车作为唯一返程方式。
- **游船**：瘦西湖游船、古运河游船和其他水上项目属于景区体验，不是通用市内交通；码头、航线、班次、票价、无障碍登乘和停航条件需分别核对。
- **自驾**：主城核心不必依赖自驾，古城停车、节假日管制和景区拥堵会增加成本。前往江都、邵伯或县域方向时自驾更灵活，但应核对停车、渡运、施工和饮酒后驾驶风险。

截至研究日，扬州主城没有投入运营的城市轨道交通。未来规划或施工信息不能当成现有交通方式；长期页面只保留公交、道路和步行的结构，具体线路与班次放在行前核对。

## 不同旅行者须知

| 旅行维度 | 实用建议 |
|---|---|
| 独行旅行 | 早茶、面饭、炒饭和按重量切卤便于控制份量；晚间从古运河或老街返回时使用明亮主路和正规交通。县域末端、深夜机场接驳和远郊返程不应依赖临时拼车。 |
| 亲子旅行 | 大运河博物馆优先于连续两座园林；提前确认童车、寄存、互动项目和儿童预约。瘦西湖、三湾、古运河和园林水池均有临水边界，假山洞壑、窄桥与拥挤街巷需要成人近距离看护。 |
| 长者或低体力旅行 | 每半天只设一个主景点，以车辆连接；瘦西湖走单向短段，园林在个园和何园中择一。即使有游船或接驳，也仍需承担排队、码头台阶和入口到停车点的步行。 |
| 无障碍需求 | 扬州中国大运河博物馆有官方无障碍设施与轮椅服务资料，可作为可靠锚点；但从停车或公交下客点到馆门、从古城街巷进入园林、以及园内假山和老宅门槛是否连续可通行，均需向运营方逐项确认。 |
| 摄影旅行 | 园林适合观察框景、漏窗和水石关系，古运河与瘦西湖受季节、客流和光线影响大。展馆常限制闪光灯、三脚架、自拍杆和商业拍摄；无人机涉及古城、景区、机场净空和文保规定，未经许可不飞。 |
| 预算有限 | 以一座收费园林、一座大型免费博物馆和古城公共街巷组成两日核心，减少夜游、重复园林和跨县用车。免费不代表免预约，交通距离也应计入预算。 |
| 晚出发或紧凑行程 | 下午到达只选东关街—个园外围、何园—皮市街或三湾—博物馆外部三组之一；没有足够入园时间时不临时购买长线景区票，也不在离城日安排远郊。 |
| 夏季高温与梅雨 | 盛夏把长距离户外放在较凉时段，随时补水并增加室内休息；雷电、暴雨、台风外围影响和积水预警下取消游船、水岸长线与远郊。园林石阶、木桥和青石板遇雨更滑。 |
| 冬季与寒潮 | 湿冷和水边风会放大体感寒冷，园林和湖区需防风、防滑；低温结冰或大雾时减少早晚水岸停留，返程交通留出余量。 |
