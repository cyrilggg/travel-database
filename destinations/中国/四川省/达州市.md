# 达州旅行指南

达州位于四川东北部、大巴山南麓。州河穿过由通川区与达川区共同构成的主城区，博物馆、城市山地、滨水公园和巴渠饮食适合组成一至两天的城市路线；巴山大峡谷、八台山、賨人谷等代表性山地景区则分散在宣汉、万源和渠县，不能当作主城区近郊连续打卡。达州更适合作为川东北城市文化入口和县域山地旅行集散地，而不是一座景点都挤在步行范围内的城市。

> 建议停留：2–4 天；只看主城区可用 1–2 天，增加北部山地宜另住 1–2 晚\
> 旅行关键词：巴文化、州河、博物馆、凤凰山、灯影牛肉、大巴山\
> 主要体力：主城区中等步行；峡谷、洞穴、山地景区为中高至高强度\
> 最近研究：2026-07-30

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 主要旅行价值 | 以达州博物馆理解巴文化、川东北地方史与红色历史，在州河两岸和凤凰山观察山水城市格局；再按兴趣选择真佛山或宣汉、万源、渠县的独立山地路线 |
| 建议停留 | 1 天可走博物馆与一段城市山水；2 天可加入凤凰山、神剑园或达州钢琴博物馆；3–4 天只宜增加一个县域方向。巴山大峡谷、八台山更适合一至两晚 |
| 较舒适季节 | 春季和秋季通常更适合主城区步行。夏季主城湿热，但北部高山也会有雷雨；冬季主城阴冷，八台山等高处可能出现冰雪，均需按临近预报调整 |
| 预算特点 | 主城区场馆、公交和小吃可组成中低至中等预算路线；县域包车或多段接驳、景区门票、观光车、索道及额外住宿是主要增量成本 |
| 步行强度 | 博物馆和公园短段为低至中等；凤凰山为中等爬升；真佛山、賨人谷、巴山大峡谷和八台山涉及坡道、台阶、洞穴或长距离景区交通，为中高至高 |
| 主要天气风险 | 夏季高温、局地强降雨、山洪、城市内涝和滑坡崩塌；秋季连阴雨；北部高海拔冬季有低温、积雪、结冰和低能见度风险 |
| 独行旅行 | 主城区一人食和公交、叫车较方便；远端山区返程班次少、单人用车成本高，不宜脱离开放线路独自进入峡谷或未管理山地 |
| 亲子旅行 | 达州博物馆、达州钢琴博物馆和短段公园便于组合；洞穴、玻璃体验、高山冰雪、漂流及长车程需按年龄、身高和现场规则取舍 |
| 长者与低体力旅行 | 可采用“一座场馆＋一次车辆接驳＋一段平坦公园”的结构；不把凤凰山完整登高、峡谷全线或当天跨县往返设为必做 |
| 无障碍信息 | 公开资料不足以证明车站、城市街道和各景区核心游线全过程连续无障碍；电梯、轮椅、坡道、无障碍卫生间、观光车及陪同规则需逐点向运营方确认 |

## 城市格局与游览区域

主城区沿州河和山谷展开，不能只按地图直线距离估算步行。通川老城位于传统商业和生活核心，西外—莲花湖片区集中了达州博物馆、公共文化设施与较新的城市空间；凤凰山从主城北侧抬升，是独立的城市登高单元。州河南侧的达川南外有达州钢琴博物馆及生活餐饮，往福善镇、真佛山方向则已经进入需要车辆接驳的远端。达州站、金垭机场、县城和景区游客中心分别是不同层级的交通门户。

| 区域 | 主要内容 | 游览特点 | 与其他区域的关系 |
|---|---|---|---|
| 通川老城—州河两岸 | 传统商业、地方餐饮、州河城市空间 | 适合吃饭和选择一段滨水散步；桥梁、坡道与车流会打断连续步行 | 可用公交或车辆接西外、达川南外；州河与沿岸各公园作为一条城市水系理解，不重复计数 |
| 西外—莲花湖 | 达州博物馆、莲花湖湿地公园、公共文化设施 | 博物馆适合作为预约锚点，湖区只选一段慢行，不追求完整环湖 | 与达州站方向相对接近，可与主城餐饮同日；去凤凰山仍需另行接驳 |
| 凤凰山—主城北侧 | 凤凰山公园、城市登高与元九登高文化 | 山地范围大、出入口多，内部楼亭和观景节点按一个公园单元记录 | 可与老城或神剑园分时组合，但完整登高不宜再叠加远郊 |
| 罗江—神剑园 | 神剑园、张爱萍故居及红军文化展陈 | 园内故居、陈列馆、战史馆和广场属于同一运营景区，不拆分完成项 | 位于主城北缘，通常车辆往返；可接凤凰山，但两处不是连续步行线 |
| 达川南外 | 达州钢琴博物馆、南外生活与餐饮 | 适合半日室内文化路线；展演或活动可能改变参观范围 | 与通川隔河相连，可与老城同日；不顺路连接北部县域山地 |
| 福善—真佛山 | 真佛山景区、山林与宗教建筑 | 现行景区名录列在达州东部经开区，较早官方介绍常写达川区；应按远端山地一日安排 | 从主城区往返需车辆，德化寺、玉佛寺、金刚寺、洞穴和湖泊均属于同一景区内部节点 |
| 宣汉县 | 县城、罗家坝遗址博物馆、巴山大峡谷及东北部土家族乡 | 县城与巴山大峡谷相距仍远；大峡谷幅员大、海拔差显著，适合住宿而非主城当天赶场 | 宣汉是独立县域。到过大峡谷不代表宣汉县城和其他景点均已完成研究 |
| 万源市 | 万源城区、红色历史、八台山及大巴山高地 | 县级市，铁路门户、城区和八台山是三个不同节点；高山冰雪与云雾影响明显 | 宜在万源住宿后进入八台山。万源属于达州代管县级市，但需独立城市页才算完成覆盖 |
| 渠县 | 渠县城区、賨人谷、汉阙与城坝遗址文化 | 賨人谷在渠县东部，洞穴、峡谷、瀑布和陈列馆按一个景区去重 | 适合独立一日或一晚；到过賨人谷不等于渠县城区、汉阙或城坝遗址均已研究 |
| 大竹县与开江县 | 大竹竹文化和醪糟、开江豆笋与县域休闲资源 | 两县都不是主城短距离外延，景区、县城和餐饮产地需分别规划 | 本页只说明市域关系，不表示大竹、开江目的地页已经完成 |

达州市法定范围为通川区、达川区两区，宣汉、开江、大竹、渠县四县，以及代管的县级万源市。达州高新区和达州东部经开区是功能园区，不应与法定县级行政区并列增加完成项。主城区研究只覆盖通川—达川城市核心；每个县、县级市及其景区仍需独立核验，不能因行政上属于达州而自动算作完成。

## 主要景点

优先级用于安排时间：**A** 为首访核心，**B** 为按兴趣补充，**C** 为远郊、季节性或通常需要独立半天以上的目的地。“路线节点”用于滨水空间、车站、游客中心和换乘点，不计入景点完成率。同一景区及其内部展馆、建筑、洞穴、索道、观景台和游乐项目只记录一次。

## 美食与餐饮

达州饮食属于川东北味型，常见麻辣、卤制、腌腊和河鲜。主城区适合从灯影牛肉、七星椒卤味和家常川菜入手；石梯蒸鱼、宣汉麻辣鸡、万源老腊肉、开江豆笋和大竹醪糟分别带有明确县镇来源，不应因为主城可以买到就视为已经到访对应县域。热门品牌只是同类型入口，正规同类店、市场和家常菜馆通常可以替代。

| 菜品或餐饮类型 | 常见区域 | 一个人用餐与常见份量 | 风味、过敏原与饮食限制 | 排队风险与替代方法 |
|---|---|---|---|---|
| 灯影牛肉 | 通川、达川特产店与川菜馆 | 即食小包装适合一人，餐馆份量可共享；高盐高油，不宜代替正餐 | 牛肉、辣椒、香辛料和芝麻油常见，复合调味料可能含大豆、麸质与糖 | 节庆伴手礼店可能排队；比较配料、净含量、生产日期和正规标签，不必锁定单一品牌 |
| 七星椒卤味 | 通川老城、美食街和熟食店 | 多按重量售卖，一人先问能否小份拼切 | 常见禽肉、内脏、豆制品、辣椒、花椒、酱油和芝麻；严格素食、麸质或大豆过敏者需询问共锅 | 饭点和节前排队较多；选择明码标价、能说明制作与保存时间的同类卤味店 |
| 川东北面食、米豆腐与凉粉 | 主城区早餐店、小吃店和市场周边 | 通常一人一碗或一份，便于独行用餐 | 肉臊、骨汤、红油、花生、芝麻、大豆和含麸质酱油常见；“少辣”不等于无过敏原 | 早餐高峰周转快；选择调料和价格说明清楚的店，米制主料也不代表整碗无麸质 |
| 达川石梯蒸鱼 | 达川区石梯镇及主城部分川菜馆 | 整鱼多按重量计价，偏多人分享；独行者先问最小鱼重或改点鱼片 | 鱼类、鱼刺、辣椒、豆豉、酱油和食用油需留意，可能含大豆与麸质 | 先确认鱼种、重量、单价和加工费；石梯镇路线应结合返程交通，不为一餐长距离赶路 |
| 宣汉麻辣鸡 | 宣汉县城及主城区部分卤菜、川菜店 | 可按重量或小份切盘，适合一至两人 | 禽肉、辣椒、花椒、芝麻、花生和复合酱料常见 | 同类熟食可替代；关注冷藏、切配和制作时间，不把一道菜当作完成宣汉旅行 |
| 万源老腊肉、旧院黑鸡 | 万源市及主城区地方菜馆 | 腊肉适合小份共享，整鸡偏多人；一人先问半份或小炒 | 猪肉或禽肉，盐分和烟熏味较重；炖汤与炒菜可能含大豆、麸质和动物油 | 在万源住宿时更便于寻找；主城区可选正规川东北菜馆，不追逐未经核验的“野味”宣传 |
| 开江豆笋 | 开江县及主城区特产店、家常菜馆 | 干货适合买小包装，餐馆多作为炖、烧或凉拌配菜 | 主要原料为大豆，豆类过敏者应避免；汤底和调料可能含肉、麸质、花生或芝麻 | 查看正规包装和保存方式；严格素食者需确认汤底与共锅，主城购买不等于到访开江 |
| 大竹东柳醪糟 | 大竹县及主城区甜品、小吃店 | 通常一人一碗，也可买小包装；常与鸡蛋、汤圆同煮 | 发酵米食可能含少量酒精；加蛋、汤圆后涉及蛋类和麸质，儿童、孕期或需避酒精者先询问 | 热门时段可换同类甜品店；包装产品核对酒精、添加物、保质期和冷藏要求 |

点鱼、卤味和腊制品前，先确认计价单位、最小份和加工费。对花生、芝麻、大豆、鱼、蛋、奶或麸质严重过敏者，应询问共油、共锅、砧板和复合酱料；“不放辣”不能替代过敏原确认。高温季节购买散装熟食，要关注制作时间、冷藏和携带时长。

## 经典行程

### 一日经典路线

**路线**：达州博物馆 → 西外午餐 → 莲花湖湿地公园短段 → 车辆前往州河两岸或凤凰山低段

- **串联逻辑**：先用博物馆建立巴文化与地方史框架，再在西外观察现代城市空间；下午只选湖区或山地中的一段，不把主城所有公园串成徒步挑战。
- **预约锚点**：以达州博物馆当日开放和预约规则为锚点；若选择凤凰山，另查入口、道路和恶劣天气管制。
- **休息安排**：博物馆座席、西外坐席餐馆和车辆接驳；高温时把户外段放到较晚时段。
- **时间不足时**：先删莲花湖或州河段；只剩半天时保留博物馆，不为登高跨区赶路。

### 两日城市路线

**第 1 天（历史与西外）**：达州博物馆 → 西外午餐 → 莲花湖湿地公园短段 → 州河城市空间\
**第 2 天（红色历史与城市山地）**：神剑园 → 罗江或通川午餐 → 凤凰山选择一条已确认开放的登高路线

- **串联逻辑**：第一天集中在西外和州河，第二天处理主城北侧的神剑园与凤凰山，减少南北反复穿行。神剑园内部各馆不拆分打卡。
- **预约锚点**：第一天是博物馆；第二天先确认神剑园开放和团体活动，再看凤凰山天气与步道情况。
- **休息安排**：两天均在城区完成坐席午餐；神剑园参观后先休息，再决定凤凰山登高长度。
- **时间不足时**：第二天先删凤凰山高处，只保留神剑园；不临时加入真佛山或任何县域景区。

### 三日文化路线

**第 1 天**：达州博物馆 → 莲花湖短段\
**第 2 天**：神剑园 → 凤凰山低至中段\
**第 3 天**：达州钢琴博物馆 → 达川南外午餐 → 州河南岸选择一段公共空间

- **串联逻辑**：三天分别处理地方史、近现代历史与城市山地、音乐文化与达川生活，强度逐日可调，也不依赖县域长途交通。
- **预约锚点**：博物馆与钢琴博物馆的实际开放楼层、活动和预约；小型场馆若临时闭馆，以城市公园短段替代。
- **休息安排**：每天只设一座主要室内场馆，午餐回到服务密集区；凤凰山日预留更多补水与下山时间。
- **时间不足时**：第三天先删州河段，再按兴趣在钢琴博物馆与神剑园之间二选一。

### 雨天路线

**路线**：达州博物馆 → 西外坐席午餐 → 达州钢琴博物馆（已确认开放时）

- **适用条件**：普通降雨且道路、公交和场馆正常。强降雨、山洪或内涝预警下，即使目的地在室内也不跨越积水路段，不前往凤凰山、州河岸和县域峡谷。
- **预约锚点**：两馆当日公告；钢琴博物馆若因演出或活动限制参观，就只保留达州博物馆。
- **休息安排**：场馆和固定餐馆；准备防滑鞋，湿伞与行李按馆方规则寄存。
- **时间不足时**：只保留达州博物馆，不为增加数量跨河往返。

### 亲子或低体力路线

**亲子路线**：达州博物馆重点展厅 → 坐席午餐 → 达州钢琴博物馆或莲花湖短段\
**低体力路线**：车辆直达达州博物馆 → 坐席午餐 → 车辆到州河或莲花湖附近，选择靠近落客点的一小段公共空间

- **减负方式**：亲子路线在室内场馆与短时户外之间切换；低体力路线不安排凤凰山登高、洞穴台阶或长距离环湖。两类路线都先确认电梯、座椅、卫生间和落客点。
- **预约锚点**：场馆预约、儿童活动年龄与无障碍服务；公开公园也需核对施工、积水和最近出口。
- **休息安排**：场馆、餐馆与车辆构成固定休息点，不假定山地或湖岸全线都有座椅。
- **时间不足时**：删去户外段，只保留一座场馆与午餐。

### 真佛山一日路线

**路线**：达州主城区 → 福善方向景区入口 → 真佛山旅游景区内部选择一条完整游线 → 原线返回

- **串联逻辑**：把寺观、山林、洞穴和湖泊视为一个运营单元，全天不再加入主城区场馆或其他远郊。
- **预约锚点**：景区开放、门票、观光车、宗教活动和末班返程；地图上的旧区划名称需与当前购票入口核对。
- **休息安排**：游客中心、已开放服务点和坐席午餐；上山前备水，雨后缩短陡坡与洞穴段。
- **时间不足时**：整段删除，改为主城区场馆日，不在午后临时出发。

### 宣汉、万源与渠县独立路线

**巴山大峡谷 1–2 晚**：达州 → 宣汉县城或景区门户住宿 → 次日按开放情况选择大象洞、桃溪谷、罗盘顶中的可行组合 → 原路返回或再住一晚。景区幅员和海拔差都很大，不保证一天能完整覆盖所有核心片区。

**八台山 1–2 晚**：达州 → 铁路或公路到万源 → 万源住宿 → 次日进入八台山景区 → 天黑前下山并回到稳定交通点。把日出、云海、索道、玻璃设施和冰雪活动视作同一景区内的季节选项，不为追日出夜间冒险上山。

**賨人谷一日或一晚**：达州 → 铁路或公路到渠县方向 → 车辆接驳賨人谷 → 完成一条洞穴与峡谷组合游线 → 按返程班次回渠县或住宿。汉阙、城坝遗址和渠县城区是另外的物理单元，不与賨人谷自动合并。

- **交通边界**：三条路线一天只选一个方向。铁路或县际客运只解决主段，县城、车站、游客中心与景区入口之间仍可能有长距离山路接驳。
- **预约锚点**：景区开放、内部交通与回程班次必须同时锁定；巴山大峡谷和八台山还要核对海拔段天气、道路和夜间运营。
- **休息安排**：优先以县城或景区合规住宿换取稳定时间，不把最后一班车设为唯一退路。
- **时间不足时**：删除整个县域方向；不从达州主城区午后出发硬做往返。

## 住宿区域

| 区域 | 优点 | 缺点 | 适合人群 | 交通特点 |
|---|---|---|---|---|
| 通川老城—中心广场方向 | 餐饮、商业和城市生活密集，便于体验州河与夜间用餐 | 道路拥堵、临街噪声、停车和老楼电梯条件差异较大 | 首次到访、独行、重视餐饮与晚间便利者 | 去西外、达川南外和凤凰山均需公交或车辆，不以跨河直线距离估算时间 |
| 西外—莲花湖—市政中心 | 靠近达州博物馆、莲花湖和公共文化设施，街区较新 | 与老城传统餐饮及达川南外有距离，部分路段尺度大 | 以博物馆为核心、亲子、低体力和偏好安静城市环境者 | 适合第一天落脚；去达州站较方便，具体仍看酒店位置与进站口 |
| 达州站周边 | 早晚铁路衔接和行李寄存方便 | 站区噪声、交通秩序和住宿品质差异大，不是主要游览街区 | 早班车、晚到或转去万源、渠县等方向者 | 核对“达州站”完整站名、进站口和实际步行路线，不用营销距离代替导航 |
| 达川南外 | 餐饮和城市服务充足，靠近达州钢琴博物馆及南侧道路 | 去神剑园、凤凰山北侧和达州站需要跨河或跨城 | 重点看钢琴博物馆、在南城办事或自驾者 | 公交、出租车和网约车连接通川；高峰期跨河应留余量 |
| 金垭机场衔接区 | 适合极早出发、极晚抵达或自驾中转 | 远离主城区核心景点和传统餐饮，不宜作为完整城市游览基地 | 航空过渡、团队或有机场接送安排者 | 订房前确认实际机场距离、接送时段和夜间车辆；河市机场已不承担民航客运 |
| 宣汉县城或巴山大峡谷门户 | 可把长距离山路拆成两天，便于锁定景区早间时段 | 县城到景区仍可能很远；山地住宿供暖、隔音和餐饮稳定性需确认 | 巴山大峡谷 1–2 晚、摄影和山地旅行者 | 先按景区入口和内部交通选住宿，不只看“宣汉”行政名称 |
| 万源城区 | 铁路、公路和城市服务相对集中，便于八台山前后休整 | 到八台山仍需山路接驳，冬季返程受天气影响 | 八台山、万源红色历史或大巴山路线 | 以万源站、正规车辆和次日景区开放为三项核对点 |
| 渠县城区或賨人谷附近 | 可根据返程班次在城市服务与景区早入之间取舍 | 两地不能视为同一个步行区域，洞穴游览后再赶末班负担大 | 賨人谷一日或一晚、计划增加渠县文化主题者 | 核对渠县铁路站点、县城到景区车辆和夜间返程，不把游客中心当县城 |

不推荐未经核验的具体酒店。订房时核对电梯、无障碍客房、空调或供暖、停车、临街噪声、早餐时段、行李寄存和退改规则；山区住宿还要确认热水、应急供电、夜间到达、消防疏散和恶劣天气取消安排。

## 市内交通

| 场景 | 建议与取舍 | 行前需要重查的内容 |
|---|---|---|
| 达州站抵达 | 达州站是主城区主要铁路门户，位于西侧；到西外相对直接，去老城、达川南外仍需地面接驳 | 车次、完整站名、进出站口、公交、出租车上客点、施工和无障碍协助 |
| 达州金垭机场抵达 | 金垭机场自 2022 年起承接民航客运，河市机场同步关闭；机场到主城区是一段独立公路接驳 | 实际执飞航线、机场巴士或公交、出租车与网约车上客点、夜间到达和特殊旅客服务 |
| 通川—达川跨河 | 主城区依靠公交、出租车和合规网约车，路线按“同片区成组、少跨河”更稳定 | 公交线路与首末班、桥梁施工、活动管制、雨天拥堵和夜间叫车 |
| 单片区步行 | 博物馆内部、老城短段、莲花湖短段和州河短段可以分别步行；凤凰山应按入口和下山点单独规划 | 人行道施工、过街、坡度、夜间照明、积水、共享交通停放和无障碍连续性 |
| 神剑园与真佛山 | 神剑园位于罗江方向，真佛山位于福善方向，均不适合从主城核心徒步抵达 | 景区直通车或公交是否运行、正规包车、停车、末班、入口变化和返程叫车 |
| 宣汉与巴山大峡谷 | 先以铁路或公路到宣汉方向，再解决县城或门户到景区的山路接驳；景区内部还可能使用巴士等交通 | 县际班次、游客中心、内部交通、道路管制、落石滑坡、夜间驾驶和住宿接送 |
| 万源与八台山 | 铁路或公路先到万源，次日用正规车辆进入八台山；不要把万源站到山门、山门到核心区视为一段 | 列车、道路、索道与观光车运营、雪链或冬季装备、结冰、停车和最晚下山时间 |
| 渠县与賨人谷 | 铁路或县际客运解决达州—渠县主段，县城或车站到景区仍需地面交通 | 使用哪个铁路站、正规车辆、景区接驳、末班、洞穴关闭和雨后道路情况 |
| 自驾 | 多人前往真佛山或县域景区时更灵活，但大巴山长坡、弯道、雾、强降雨和冬季结冰显著增加驾驶负担 | 高速与国省道施工、景区停车、充电加油、保险、天气预警、交通管制和救援电话 |

达州没有可替代公交和道路交通的城市轨道网络。铁路查询使用[中国铁路 12306](https://www.12306.cn/)并核对完整站名；航班以承运人和金垭机场当日信息为准。县域“有铁路站”不等于景区可无缝到达，景区直通车、旅游巴士、观光车、索道和漂流等都只在确认当期运营后使用。

## 不同旅行者须知

| 旅行维度 | 可行条件 | 主要取舍 | 需额外核对 |
|---|---|---|---|
| 独行旅行 | 主城区场馆、一人食、公交和叫车方便，可在西外或老城建立稳定基地 | 单人包车去县域成本高，山地末班后替代交通少；不进入未开放洞穴、峡谷或无人管理步道 | 末班、正规车辆、住宿入住、手机信号、景区应急点和紧急联系人 |
| 亲子旅行 | 达州博物馆、钢琴博物馆和公园短段适合知识型组合 | 洞穴湿滑、玻璃设施、漂流、高山冰雪和长车程会增加照护负担 | 儿童预约、推车、电梯、卫生间、身高年龄限制、救生装备和食品过敏原 |
| 长者或低体力旅行 | 每半天一座场馆，车辆点到点连接，户外只选最近入口的一段 | 凤凰山完整登高、真佛山陡坡、賨人谷洞穴和巴山大峡谷多片区应主动删减 | 落客点、电梯、轮椅借用、座椅、卫生间、观光车与陪同要求 |
| 无障碍需求 | 优先联系铁路、机场和大型公共场馆安排协助，并选择有电梯和无障碍客房的住宿 | 公开资料不能证明历史建筑、山地、洞穴、湿地步道和景区车辆全过程连续可达 | 需向每个运营方确认入口坡度、轮椅尺寸、升降设备、无障碍卫生间、换乘和应急疏散 |
| 摄影旅行 | 州河、凤凰山、莲花湖和北部山地提供城市、云海、峡谷与人文题材 | 山地云雾和日出具有不确定性；三脚架、无人机和商业拍摄受场馆、景区及自然保护规则约束 | 日出时段是否开放、夜间下山、无人机空域、闪光灯、三脚架和文物摄影规定 |
| 预算有限 | 博物馆、城市公园、小吃和公交可构成低成本主城区路线 | 县域接驳、观光车、索道、景区住宿和单人用车是主要成本，不宜为“都在达州”集中购买多地行程 | 免费预约、优惠资格、联票是否必要、退改、明码标价和交通总成本 |
| 晚出发或紧凑行程 | 半天只选达州博物馆、钢琴博物馆或州河短段中的一个 | 午后不前往真佛山、巴山大峡谷、八台山或賨人谷；傍晚不以末班县际交通作为唯一退路 | 最晚入场、闭馆日、公交末班、夜间叫车和次日首班 |
| 夏季高温与强降雨 | 早晚安排城市户外，中午进入场馆；普通小雨改为博物馆日 | 高温放大凤凰山和洞穴外接驳体力；强降雨后山洪、滑坡、落石、积水会滞后于降雨结束 | 四川及达州气象、应急、自然资源、交通和景区公告，预警、闭园与道路中断 |
| 冬季高山旅行 | 主城区仍可按城市路线活动，八台山等高处只在道路与景区确认开放时进入 | 主城阴冷不等于高山无雪；冰雪、低温、浓雾和索道停运会改变整日计划 | 山区温度、积雪结冰、轮胎与防滑装备、索道、最晚下山和住宿供暖 |

本页 `geonames_id` 使用 GeoNames 城市居民点记录 `1813325`。项目固定日期的 GeoNames `cities15000` 清单将其记为 Dazhou，坐标约为北纬 31.21060、东经 107.46308，类型为 `P/PPLA2`，层级显示该城市点位于 Dazhou Shi 下的 Tongchuan Qu。它用于定位达州主城，不是一张达州市法定行政边界，也不能代表宣汉、万源、渠县等县域已经研究完成。
