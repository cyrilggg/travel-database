# 四川省旅行目的地

四川从成都平原延伸到川西高原、秦巴山地、川南河谷和攀西山地，同一省内的海拔、气候、道路条件与旅行尺度差异很大。省会成都适合作为铁路和航空枢纽，也能衔接平原古城、古蜀文明与川菜文化；九寨沟、黄龙、四姑娘山、稻城亚丁、乐山—峨眉山等目的地则分属其他市州，不能因为常从成都出发，就并入成都城市页或城市完成率。

当前仅完成成都的完整指南。成都页覆盖中心城区、成都大熊猫繁育研究基地，以及行政上属于成都市、但需要按远郊整日安排的都江堰与青城山。其他城市和自治州将在独立研究后逐页加入；空目录、模板和仅有名称的页面均不算完成。

## 区域格局与城市组合

| 区域 | 代表目的地 | 旅行条件 | 与成都的关系 |
|---|---|---|---|
| 成都平原 | 成都、都江堰、崇州、邛崃、大邑及德阳、眉山等周边城市 | 海拔相对较低，铁路和公路密集，但古镇、山地与县域景点仍有明显“最后一段”交通 | 都江堰和青城山在成都市行政范围内，列入成都远郊；广汉三星堆属于德阳市，不计入成都景点 |
| 川南与川东南 | 乐山、宜宾、泸州、自贡、内江 | 河谷城市、石窟、盐业与酒文化并存，夏季常有高温和强对流 | 乐山大佛与峨眉山属于乐山市，应建立独立城市页；不能作为成都当天的附属景点处理 |
| 川北与秦巴方向 | 德阳、绵阳、广元、巴中、南充 | 古蜀遗址、三国交通线、古城与山地景观相间 | 可从成都乘铁路衔接，但不同城市的闭馆、预约和接驳需分别核验 |
| 阿坝与甘孜高原 | 九寨沟、黄龙、四姑娘山、康定、稻城等 | 海拔上升快，天气、地质灾害、道路和身体适应是首要条件 | 不能按成都近郊估算；需要独立住宿、交通冗余和高海拔风险说明 |
| 攀西与凉山 | 西昌、攀枝花及凉山州各地 | 山地、峡谷、湖泊和民族文化并存，季节、火险与长距离交通影响明显 | 通常使用航空、铁路或长途公路另行成段，不适合塞入成都短停留 |

四川行程最容易出现的边界误判，是把“从成都有车可达”理解成“属于成都且能当日轻松往返”。三星堆博物馆位于德阳市广汉市；乐山大佛与峨眉山位于乐山市；九寨沟、黄龙和四姑娘山位于阿坝州。它们都应在各自行政区页面中计算覆盖和维护来源。

省内组合还要考虑三个尺度：成都平原的城市通勤尺度、川南和川北的城际铁路尺度、川西高原的跨山长途尺度。高原、峡谷和汛期道路不应仅凭地图直线距离判断。实时车次、道路管制、景区接驳和气象预警统一在出发前重新核对。
