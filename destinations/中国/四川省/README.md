# 四川省旅行目的地

四川从成都平原延伸到川西高原、秦巴山地、川南河谷和攀西山地，同一省内的海拔、气候、道路条件与旅行尺度差异很大。省会成都适合作为铁路和航空枢纽，也能衔接平原古城、古蜀文明与川菜文化；雅安从雨城主城和蒙顶山茶区过渡到大熊猫栖息地与川西山地，乐山以三江地形和大佛遗产为核心，遂宁则沿涪江展开；西昌以安宁河谷州府、邛海湿地和泸山为城市核心，同时承担凉山州跨县交通集散。九寨沟、黄龙、四姑娘山、稻城亚丁等目的地同样需要按各自市州和景区尺度安排，不能因为常从成都出发，就并入成都城市页。

当前可浏览二十四座城市的完整指南。新增的[马尔康](./马尔康市.md)以州府高原适应、卓克基—西索、松岗与山地远线为主线；其余指南也区分主城、县域远线、保护地与生产空间。

四川行程最容易出现的边界误判，是把“有车可达”理解成“属于同一城市且能当日轻松往返”。三星堆博物馆位于德阳市代管的广汉市，可与成都或德阳衔接，但不计入德阳景点；乐山大佛位于乐山主城对岸的景区，峨眉山则位于乐山市代管的独立县级市峨眉山市；九寨沟、黄龙和四姑娘山位于阿坝州。绵阳代管的[江油](./江油市.md)是法定县级市，北川老县城遗址、九皇山与平武保护地也不是主城的连续郊区。巴中北面的汉中属于陕西省，西面的广元和东面的达州也是独立地级市。它们分别拥有独立的行政边界、交通条件和行前信息，应查阅对应城市或自治州资料。

乐山主城以市中区为核心，乐山站、新城区、嘉州老城与三江对岸的乐山大佛景区需要公交或车辆串联。大佛白天游山与白天游江、夜游等水上项目是不同运营单元；九曲栈道、佛脚平台和出入口可能因维修、落石、客流或暴雨单独调整，游船的航线、码头和停航则随丰枯水、水位、流速、天气及海事管理变化。沙湾区的郭沫若故居和犍为县的嘉阳小火车各需独立半日或一日，非开放厂矿、专用铁路、航道、坝区与河滩不属于游览空间。峨眉山市由乐山市代管，但具有独立法定代码 `511181`；它与乐山大佛同属 UNESCO 复合遗产，不等于同一景区、主城或住宿单元。

德阳主城以旌阳区为住宿、铁路与公共文化核心，罗江区白马关和中江县城—挂面村—继光湖分属两个需要单独交通的方向。德阳市同时代管广汉市（`510681`）、什邡市（`510682`）和绵竹市（`510683`）；三者拥有独立城区和旅行边界。中国二重、东方电机、东方汽轮机等生产厂区，宝成铁路与货运专用线，继光水库坝体和非开放岸线均不是自由游览空间；只有运营方明确开放的展览、参观线路和公共岸线可以进入。汉旺东汽工业遗址在绵竹，穿心店地震遗址在什邡，两者均应按独立城市路线核对开放与安全规则。

绵竹以剑南、紫岩主城承担住宿、地方餐饮和公共文化服务，孝德年画村与绵竹南站在主城以南方向，汉旺和清平沿龙门山前向西北延伸，九龙—麓棠则是另一组山前休闲目的地。绵竹年画博物馆和中国绵竹年画村不是同一场馆；剑南老街公开的天益老号文物及酒文化展陈，也不能替代对酿造、储酒和物流生产区的准入核对。汉旺地震遗址的危损构筑物与维护区、九顶山风景名胜区的保护分区、清平沟谷、林区矿道、水库坝体和非开放河岸都不属于自由游览空间。强降雨、山洪、落石、地质灾害、森林火险和冬季结冰会直接决定沿山路线能否执行。

广元以利州主城承担铁路、航空、住宿和市级文博，皇泽寺与千佛崖虽然都属于广元石窟体系，仍是两个独立入口。昭化古城位于嘉陵江水系南向节点；朝天的明月峡和曾家山分别属于河谷古道与高地度假方向；剑阁县的剑门关和翠云廊同属联合 5A 旅游区，却有独立入口、票制与体力条件，宜分两日。苍溪、旺苍、青川各有独立县城和远线，不能当作利州近郊或同日环线。广元全市没有下辖县级市，法定代码为 `510800`；机场净空区、铁路桥隧、港口航道、坝体水电站、矿山、采石场、林区生产道路和自然保护地非开放区都不属于自由游览空间。汛期山洪、滑坡和落石，曾家山等高处冬季结冰，剑门关索道与步道状态，以及翠云廊古柏保护和森林火险，均需在进入相应方向前重新核对。

自贡的自流井—大安盐业历史线、大山铺恐龙化石原址、中国彩灯博物馆与灯会园区是不同参观单元；盐井、机械、矿区和生产设施没有正式开放时不得进入。内江主城的沱江两岸和场馆可分段组合，资中历史城区、威远穹窿地貌与隆昌县级市则应分别核对交通和住宿；隆昌有独立法定代码，不能作为内江市区的连续景点安排。

泸州的江阳—龙马潭主城沿长江、沱江展开，纳溪、泸县、合江、叙永和古蔺则分处不同公路方向。泸州老窖旅游区及内部窖池群按一个运营单元去重，合江福宝、泸县宋代石刻和古蔺赤水河流域也应各占独立县域日。酿酒厂、储酒区、港口、矿山和赤水河生态保护范围只有正式开放部分可进入；县级市在泸州现行法定下辖中不存在。

资阳以雁江主城为市级场馆、住宿与铁路门户，安岳和乐至是具有各自县城与乡镇腹地的普通县，不是主城近郊街区。安岳石刻是分布于多个乡镇的文物体系，圆觉洞、卧佛院、毗卢洞等是不同地点，同一地点内部洞龛不重复计数；乐至陈毅故里内部故居、展馆和纪念空间按一个景区处理。简阳与天府国际机场属于成都，内江和重庆大足也在市界之外。考古工地、非开放洞龛、果园农田、水库坝体、天然气井站与工业生产区均只在明确接待和安全边界内进入。

广安的市级旅行核心在广安区，邓小平故里位于协兴方向；广安站位于前锋区，不能与广安南站混为一处。华蓥市具有独立法定代码 `511681`，其城区和华蓥山旅游区属于跨城市延伸；邻水天意谷、武胜宝箴塞与沿口古镇、岳池县城也各有单独接驳和返程条件。邓小平故里旅游区及内部场馆按一个整体理解，山地、峡谷、江岸与生产区域只在正式开放边界内游览。

遂宁主城以船山区、涪江两岸和观音湖为核心，船山老城—广德寺主要在西岸，河东文化中心—四川宋瓷博物馆—灵泉寺主要在东岸，过江依赖桥隧和车辆。安居区、蓬溪县和大英县分别对应乡村农耕、宝梵寺、井盐与盐卤等远线，不能合成主城步行圈；射洪市虽由遂宁代管，但为独立法定县级市，陈子昂读书台等目的地应另作城市路线。广德寺、灵泉寺是持续使用的宗教场所；涪江与观音湖还承担湿地、行洪和航道功能，乡村田地、井盐生产区、码头、坝体和封闭岸段只有明确开放时才可进入。水上项目、水位、寺院活动和县域返程均需行前核对。

宜宾主城由翠屏老城、叙州南岸和跨江新城组团构成；“三江新区”是功能区称谓，不是新增法定市辖区。李庄虽属翠屏区，仍需单独接驳；蜀南竹海跨江安—长宁方向，兴文石海位于兴文县，两者都应按整日远线安排。五粮液旅游景区与生产、仓储和物流区域必须分开，金沙江、岷江和长江的公共江岸也不能代替对码头、航道和水位风险的核对。

攀枝花主城沿金沙江和雅砻江河谷分为多个组团：东区炳草岗、大渡口一带承担主要城市服务，西区保留密集的工矿城市景观，仁和区连接三线建设博物馆、苴却砚文化展示与攀枝花南站，三者之间都需要地面接驳。米易县和盐边县各有独立县城；迤沙拉、二滩、格萨拉和颛顼龙洞又分属不同公路方向，不能按主城近郊或一条连续环线估算。攀枝花中国三线建设博物馆和兰尖工业旅游基地分别按完整场馆、完整运营线路理解；钢铁厂、采矿区、专用铁路、尾矿库、料场、水电生产设施及非开放江岸不因具有工业景观就可进入，只有运营方明确接待的区域才属于游览范围。

西昌是凉山彝族自治州驻地和州内交通集散中心，法定层级仍为县级市。建昌古城位于主城，邛海湿地沿多个湖滨入口展开，泸山从邛海西南岸升起，大石板古村则在邛海南侧；古城、环湖、登山与乡村各有独立的步行和接驳尺度。邛海兼具湿地、饮用水水源与公共游憩功能，湖滨修复区、鸟类栖息地和非开放岸线不能自由穿行；泸山及周边林区受森林草原防火和现场封控约束。西昌卫星发射中心是机构和品牌名称，面向公众的冕宁航天旅游景区位于冕宁县；螺髻山常规游客入口与服务主要按普格县方向组织，两处都不是西昌市区的顺路景点。

眉山的东坡老城、岷江现代城市空间、彭山江口沉银博物馆和各县域景区不是连续城区。江口明末战场遗址的保护河道、考古工作区与博物馆分开管理；洪雅县城、柳江古镇、瓦屋山镇和景区入口也不是同一落脚点。前往瓦屋山宜在洪雅西部增加住宿，并把道路、索道、低温、浓雾和地质灾害作为能否执行路线的前提。仁寿、洪雅、丹棱和青神是普通县域，前往这些方向仍需分别核对交通、住宿和开放条件。

雅安以雨城主城承担铁路、住宿、城市文博与跨县换乘，名山区的蒙顶山集中茶园、茶史和景区游线，主城北侧的碧峰峡—上里则是另一条公路方向。荥经的龙苍沟、天全的喇叭河、芦山的古城与地震记忆、宝兴的熊猫溯源和神木垒、汉源湖与九襄、石棉的安顺场与王岗坪，均应按独立县域日安排；宝兴和高山远线更适合增加住宿。碧峰峡游客区、中国大熊猫保护研究中心雅安基地公开区与其科研繁育、救护设施必须分开，大熊猫国家公园和“四川大熊猫栖息地”世界自然遗产也各有法定或遗产边界，不能由一个名称推定另一处可以进入。雅雨并不只是旅行气氛：暴雨、山洪、滑坡、泥石流、落石、地震后道路维护和冬季结冰都可能使景区闭园或公路中断，县域出发前应同时核对气象、道路和运营公告。

省内组合还要考虑三个尺度：成都平原的城市通勤尺度、川南和川北的城际铁路尺度、川西高原的跨山长途尺度。高原、峡谷和汛期道路不应仅凭地图直线距离判断。实时车次、道路管制、景区接驳和气象预警统一在出发前重新核对。
