# 四川省旅行目的地

四川从成都平原延伸到川西高原、秦巴山地、川南河谷和攀西山地，同一省内的海拔、气候、道路条件与旅行尺度差异很大。省会成都适合作为铁路和航空枢纽，也能衔接平原古城、古蜀文明与川菜文化；九寨沟、黄龙、四姑娘山、稻城亚丁、乐山—峨眉山等目的地则分属其他市州，不能因为常从成都出发，就并入成都城市页或城市完成率。

当前已完成成都、绵阳、眉山、巴中、南充、达州、自贡、内江和泸州九座城市的完整指南。眉山、自贡与内江分别处理岷江考古、井盐工业和沱江城市结构；泸州页则把长江—沱江主城、老窖池群、宋代石刻、古镇与赤水河流域县域方向分开说明。其他城市和自治州将在独立研究后逐页加入；空目录、模板和仅有名称的页面均不算完成。

## 区域格局与城市组合

| 区域 | 代表目的地 | 旅行条件 | 边界与组合 |
|---|---|---|---|
| 成都平原与岷江中游 | 成都、都江堰、崇州、邛崃、大邑，以及德阳、眉山等周边城市 | 海拔相对较低，铁路和公路密集，但古镇、山地与县域景点仍有明显“最后一段”交通 | 都江堰和青城山在成都市行政范围内；广汉三星堆属于德阳市；眉山已有独立城市页，三者不可因通达成都而混入成都景点 |
| 川南与川东南 | 乐山、宜宾、泸州、自贡、内江 | 河谷城市、石窟、盐业与酒文化并存，夏季常有高温和强对流 | 泸州、自贡、内江已有独立页；乐山大佛与峨眉山属于乐山市，应建立独立城市页，不能作为成都当天的附属景点处理 |
| 川北与秦巴方向 | 德阳、绵阳、广元、巴中、南充、达州 | 古蜀遗址、三国交通线、古城与秦巴山地相间；巴中和达州的县域景区仍有较长公路接驳 | 可从成都乘铁路衔接，但不同城市的闭馆、预约和接驳需分别核验；汉中属于陕西省，巴中、广元、南充与达州也彼此独立 |
| 阿坝与甘孜高原 | 九寨沟、黄龙、四姑娘山、康定、稻城等 | 海拔上升快，天气、地质灾害、道路和身体适应是首要条件 | 不能按成都近郊估算；需要独立住宿、交通冗余和高海拔风险说明 |
| 攀西与凉山 | 西昌、攀枝花及凉山州各地 | 山地、峡谷、湖泊和民族文化并存，季节、火险与长距离交通影响明显 | 通常使用航空、铁路或长途公路另行成段，不适合塞入成都短停留 |

四川行程最容易出现的边界误判，是把“有车可达”理解成“属于同一城市且能当日轻松往返”。三星堆博物馆位于德阳市广汉市；乐山大佛与峨眉山位于乐山市；九寨沟、黄龙和四姑娘山位于阿坝州。绵阳代管的江油是法定县级市，北川老县城遗址、九皇山与平武保护地也不是主城的连续郊区。巴中北面的汉中属于陕西省，西面的广元和东面的达州也是独立地级市。它们都应在各自行政区页面中计算覆盖和维护来源。

自贡的自流井—大安盐业历史线、大山铺恐龙化石原址、中国彩灯博物馆与灯会园区是不同参观单元；盐井、机械、矿区和生产设施没有正式开放时不得进入。内江主城的沱江两岸和场馆可分段组合，资中历史城区、威远穹窿地貌与隆昌县级市则应分别核对交通和住宿；隆昌有独立法定代码，不因由内江代管而计入内江城市页完成率。

泸州的江阳—龙马潭主城沿长江、沱江展开，纳溪、泸县、合江、叙永和古蔺则分处不同公路方向。泸州老窖旅游区及内部窖池群按一个运营单元去重，合江福宝、泸县宋代石刻和古蔺赤水河流域也应各占独立县域日。酿酒厂、储酒区、港口、矿山和赤水河生态保护范围只有正式开放部分可进入；县级市在泸州现行法定下辖中不存在。

眉山的东坡老城、岷江现代城市空间、彭山江口沉银博物馆和各县域景区不是连续城区。江口明末战场遗址的保护河道、考古工作区与博物馆分开管理；洪雅县城、柳江古镇、瓦屋山镇和景区入口也不是同一落脚点。前往瓦屋山宜在洪雅西部增加住宿，并把道路、索道、低温、浓雾和地质灾害作为能否执行路线的前提。仁寿、洪雅、丹棱和青神是普通县域，本页出现这些方向不表示已完成其独立清单记录。

省内组合还要考虑三个尺度：成都平原的城市通勤尺度、川南和川北的城际铁路尺度、川西高原的跨山长途尺度。高原、峡谷和汛期道路不应仅凭地图直线距离判断。实时车次、道路管制、景区接驳和气象预警统一在出发前重新核对。
