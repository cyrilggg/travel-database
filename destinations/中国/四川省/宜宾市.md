# 宜宾旅行指南

宜宾位于金沙江与岷江汇成长江之处。三江口老城、酒业遗产、川南饮食和沿江夜景构成紧凑的城市体验，李庄的抗战文化史、蜀南竹海的山林湖瀑、兴文石海的喀斯特洞穴则把旅行范围延伸到数十公里外。主城适合用两天慢慢认识；加入竹海、石海或其他县域遗产时，应按方向增加整天，而不是把全市误当成一个连续景区。

> 建议停留：2–5 天；主城 2 天，李庄、蜀南竹海或兴文石海各增加半日至 1 天<br>
> 旅行关键词：三江汇流、历史老城、酒文化、李庄、竹海、喀斯特、燃面与早茶<br>
> 主要体力：主城中等步行；山地、洞穴和县域换乘较高<br>
> 最近研究：2026-07-31

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 主要旅行价值 | 在金沙江、岷江汇成长江的城市空间中认识宜宾的老城、酒业和茶食文化，再按兴趣前往李庄、蜀南竹海、兴文石海或川南县域文化遗产 |
| 建议停留 | 2 天可覆盖主城历史、博物馆和酒文化；3 天可加入李庄；4–5 天适合再选蜀南竹海或兴文石海，两个远线都去则宜更换住宿基地 |
| 较舒适季节 | 春季和秋季通常较适合城市及山地步行，但秋雨会影响能见度；盛夏湿热且强降雨、雷暴较多，冬季阴湿，洞穴和竹林体感会低于城区 |
| 预算特点 | 主城小吃、公交和公共空间支出较易控制；县域接驳、景区门票与内部交通、山地住宿和单人包车是主要增量 |
| 步行强度 | 老城可分段步行，但滨江高差、翠屏山台阶和街区过街会累积体力；竹海范围大，石海含石阶、洞穴和湿滑路段，不宜按平地公园估算 |
| 主要天气风险 | 高温、短时强降雨、雷暴大风、江河水位变化，以及中南部山地的山洪、滑坡、崩塌和落石风险；洞穴遇停电、积水或管制时也可能关闭 |
| 独行旅行 | 主城区一人用餐、公共交通和叫车方便；远县末班、景区到车站的最后一段以及夜间山路需提前锁定，不独自进入未开放竹林、洞穴或河滩 |
| 亲子旅行 | 博物院、李庄部分展馆和正规景区可组合；临江平台、酒厂生产区、竹海湖泊、洞穴台阶和高空体验需要持续看护，品酒不适用于未成年人 |
| 长者与低体力旅行 | 主城可采用每半天一个目标、车辆点到点连接；竹海应缩短到单片区，石海需先确认观光车、电梯或替代出口，不能默认全程低体力 |
| 无障碍信息 | 现代场馆和交通枢纽可优先咨询协助，但公开资料不足以证明老城、李庄旧址、酒业遗产、竹海和石海全过程连续可达；入口、坡度、卫生间、景交车与应急疏散均需向官方确认 |

## 城市格局与游览区域

宜宾市依法管辖翠屏区、南溪区、叙州区，以及江安县、长宁县、高县、珙县、筠连县、兴文县、屏山县，共 **3 区 7 县**，现行行政区划中没有县级市。旅行者常见的“三江新区”是功能区和城市发展片区名称，不是第四个法定市辖区；判断景点、住宿和行政服务归属时，仍要看其实际所在的翠屏、南溪等县区。

| 区域 | 主要内容 | 游览特点 | 与其他区域的关系 |
|---|---|---|---|
| 翠屏老城与三江口 | 大观楼、冠英古街、合江门、滨江公共空间 | 历史信息密度最高，适合半日至一日分段步行；江岸高差、节假日人流和临水边界不可忽略 | 首访核心；可与翠屏山同日，但不必再把每个广场重复计为景点 |
| 岷江北岸与翠屏山方向 | 翠屏山—真武山文化景观、五粮液旅游景区 | 山地台阶与工业旅游并存，需要车辆连接；酒厂只按正式游客线路进入 | 与老城隔岷江或位于其西北侧，可组成主城第二天 |
| 叙州区南岸与铁路枢纽片区 | 南岸商圈、宜宾西站、宜宾站及城市服务 | 住宿、交通和现代商业较集中，部分道路尺度大，不是老城步行范围的自然延续 | 适合抵离与住宿；去翠屏老城、三江新区仍需公交、智轨或车辆 |
| 三江新区相关片区 | 宜宾市博物院、大学城、临港及长江东侧新城空间 | 现代场馆和道路较新，点位分散，宜按场馆时段安排 | 属功能区概念；博物院地址在翠屏区沙坪街道，不应另算一座行政城市 |
| 李庄镇 | 李庄古镇、抗战文化博物馆聚落、长江沿岸 | 古街、旧址和新展馆组成一个完整目的地，通常需要半日至一日 | 法定归属翠屏区，但与三江口老城不连续步行，应单独接驳 |
| 南溪区 | 南溪城区、沿江空间与地方饮食 | 已离开宜宾主城核心；智轨或公路可连接，但仍需核对运营时间 | 可作独立半日至一日，不与李庄、竹海按“沿江顺路”强拼 |
| 江安—长宁方向 | 夕佳山民居、蜀南竹海 | 蜀南竹海跨江安、长宁相关区域，景区内部尺度大，常需景交车或自驾 | 适合独立一天或住一晚；不能把竹海内部湖泊、瀑布和步道重复算作多座景区 |
| 兴文方向 | 兴文石海、兴文世界地质公园相关地质与文化资源 | 从主城进入县域后仍有景区接驳，洞穴、天坑和石林体力门槛明显 | 独立一天更稳妥；不与蜀南竹海同日赶场 |
| 高县、珙县、筠连县、屏山县 | 茶乡、古民居、悬棺保护点、岩溶山地、金沙江库区等 | 资源分散且开放条件差异大，部分区域兼有矿业、水利或生态保护功能 | 只选有正式开放、交通和返程方案的点位；矿区、坝区、林场和保护地不等于旅游景区 |

金沙江、岷江和长江既是城市景观，也是通航、行洪和生产空间。码头、锚地、酒业物流区、仓储区、水电设施及普通河滩不默认向游客开放；夜游或渡运只使用持证运营方公布的码头与航线。酒厂中的旅游景区与生产车间、储酒区、危化和物流作业区也必须分开理解，未经授权不得跨越围栏、消防通道或生产标识。

## 主要景点

优先级用于安排时间，不代表绝对排名：**A** 为首访核心，**B** 为按兴趣补充，**C** 为远郊、季节性或通常需要独立半天以上的目的地。车站、码头入口和观景平台等只作路线节点，不列为独立景点。同一景区及其内部子景点只作为一个项目记录。

## 美食与餐饮

宜宾饮食是川南风味的重要组成，早餐面食、芽菜、蒜泥白肉、竹笋竹荪和茶馆生活都比追逐某一家名店更能说明地方饮食。主城适合一人用餐的面馆和小吃多；李庄白肉、全竹宴、土火锅等通常按多人份设计。具体经营者会变化，本页只提供菜品与寻找区域。

| 菜品或餐饮类型 | 常见区域 | 一个人用餐与常见份量 | 风味、过敏原与饮食限制 | 排队风险与替代方法 |
|---|---|---|---|---|
| 宜宾燃面 | 翠屏、叙州主城区及各县城区 | 通常一人一碗，可按食量加汤或配小菜 | 小麦含麸质；传统调味常有辣椒油、花生、芝麻、宜宾芽菜、酱油和动物油，素食及过敏需求应逐项询问 | 早餐、午餐热门店可能排队；选择明档操作、能说明配料的社区面馆即可，不必只认一家 |
| 宜宾芽菜与芽菜入菜 | 市场、川菜馆、面馆 | 多作为调味或配菜，单独购买宜选小包装 | 腌制蔬菜钠含量较高，菜肴可能加入猪肉末、酱油或辣椒 | 认准正规包装和配料表；餐馆可要求少放，但不能假设完全无盐或纯素 |
| 李庄白肉 | 李庄及主城区川菜馆 | 多为共享份量，单人先问小份或半份 | 猪肉配蒜泥、红油和酱油，可能含芝麻、花生或味精；不适合素食，清淡需求需单独说明 | 节假日李庄热门餐馆等位明显；选择明码标价、现切现拌的同类店即可 |
| 李庄白糕与川南米糕 | 李庄、主城区糕点铺 | 单块或小份，适合单人和随行分享 | 以大米、糖等为主，具体做法可能含猪油或其他油脂；控糖、素食和交叉接触需询问 | 上午可能售罄；以当日制作、保存条件清楚的同类糕点替代 |
| 竹笋、竹荪与全竹宴 | 蜀南竹海、长宁、江安及主城区竹主题餐馆 | 竹笋小菜可单点；汤锅和全竹宴多为多人份 | 竹荪属于食用菌，汤底常含鸡、猪骨或火腿；对菌菇、大豆和复合调料过敏者要问清 | 景区核心时段排队且套餐份量大；在县城正规餐馆点两三道竹主题菜即可，不采食野生菌 |
| 双河凉糕 | 长宁县双河镇及宜宾各城区 | 通常一人一碗，适合作为小吃 | 常见米浆与红糖风味，配料可能含芝麻、花生或其他坚果；甜度可提前询问 | 夏季热门时段排队；选卫生、冷藏和用水条件清楚的同类店，不必专程追单店 |
| 南溪豆腐干 | 南溪区及全市特产店 | 小袋适合单人，也常作伴手礼 | 大豆过敏者避免；卤味产品钠较高，部分含辣椒、肉汤或含麸质酱油 | 购买有完整标签、保质期和储存说明的产品；散装无法说明日期时改选正规包装 |
| 高县土火锅及川南汤锅 | 高县、主城区川菜馆 | 多为 2 人以上共享，单人用餐不经济 | 常见猪肉、内脏、豆制品、菌菇和复合汤底；清真、素食、低盐及过敏需求不易通过“挑掉”解决 | 先问锅型、最低份量和计价；人数少可改点小份蒸菜、烧菜或汤菜 |
| 宜宾早茶与本地茶馆 | 翠屏老城、叙州、屏山等茶区与正规茶馆 | 一壶可单人慢饮，也适合多人分享 | 茶含咖啡因；对咖啡因敏感或需要限制摄入量者可选择淡茶和小份量，不把保健宣传当医疗结论 | 热门江景茶座可能等位；普通社区茶馆、茶叶门店体验同类茶即可 |
| 白酒与无酒精替代 | 酒文化景区和合规餐饮场所 | 品鉴通常量少，但完全可以不饮酒；茶、水和其他无酒精饮品均可替代 | 未成年人、孕期与哺乳期、驾驶或操作设备者、服药或有相关疾病者应避免饮酒；酒精与多类健康风险相关 | 预约工业旅游不等于必须品酒；拒绝劝酒，提前说明不饮酒，并把品酒与当天驾驶彻底分开 |

世界卫生组织指出，不存在对健康完全无风险的饮酒方式，风险会随饮用量和频率增加。宜宾的酒文化可以通过窖池、工艺、历史和建筑理解，饮酒不是“完成旅行”的条件。餐厅若以“野生长江鱼”为卖点，应谨慎核对合法来源，不购买或食用来源不明的长江水生野生动物。

## 经典行程

### 一日经典路线

**路线**：宜宾市博物院 → 三江新区或南岸午餐 → 大观楼 → 冠英古街 → 合江门公共江岸

- **串联逻辑**：上午先用博物院建立三江、巴蜀和地方历史背景，下午进入老城，把大观楼、传统街区和汇流地理连成一条步行线；两大片区之间使用智轨、公交或车辆转场。
- **预约锚点**：宜宾市博物院的开放日、临展与团队规则；老城演艺不作为固定行程前提。
- **休息安排**：午餐放在有固定座位和卫生间的商业区，老城在冠英古街或合江门周边分段休息，不连续走完整条滨江线。
- **时间不足时**：先删延伸江岸和夜景等待，保留博物院与大观楼—合江门核心段；若博物院闭馆且五粮液旅游景区仍有可预约时段，可把酒文化项目改作上午唯一锚点，并把老城缩短到大观楼—合江门核心段。

### 两日城市路线

**第 1 天**：宜宾市博物院 → 老城午餐 → 大观楼—冠英古街—合江门。<br>
**第 2 天**：五粮液旅游景区正式游客线路 → 岷江北岸午餐 → 翠屏山—真武山短线。

- **串联逻辑**：第一天认识城市历史和三江格局，第二天集中在翠屏区西北侧理解酒业与城市山林，减少反复跨江。
- **预约锚点**：五粮液旅游景区的预约时段与允许参观线路；翠屏山内场馆和宗教建筑开放另行核对。
- **休息安排**：酒文化游览后先在正式餐饮空间休息，再决定是否上山；低体力者可取消登高，只在可落客的公共空间短停。
- **时间不足时**：先删翠屏山完整登高，保留已预约的酒文化项目；不为赶夜景在饮酒后驾车。

### 三日深度路线

**第 1 天**：宜宾市博物院 → 三江口老城历史步行线。<br>
**第 2 天**：五粮液旅游景区 → 翠屏山短线。<br>
**第 3 天**：主城区 → 李庄古镇及正式开放博物馆聚落 → 返回主城或住李庄。

- **串联逻辑**：前两天完成主城的江、城、酒主题，第三天沿长江向李庄延伸，集中理解抗战时期内迁机构与川南场镇，不把李庄当老城步行线的附属点。
- **预约锚点**：李庄各馆开放、讲解和活动安排；一张古镇票或预约不必然覆盖所有馆舍。
- **休息安排**：李庄午餐和下午茶分开，古街、月亮田及旧址展馆择重点进入，避免正午连续走石板路。
- **时间不足时**：李庄只保留文化抗战博物馆和一段传统街巷，删夜游与外围展馆；若返程较早，整段第三天删除。

### 雨天路线

**路线**：宜宾市博物院 → 有固定座位的午餐 → 五粮液旅游景区的获准室内线路；普通小雨且老城无临水管制时，可加大观楼外围短停

- **适用条件**：仅适用于普通降雨。暴雨、雷暴大风、江河洪水、山洪或地质灾害预警下，应取消江岸、山地、竹海、石海和跨县非必要移动。
- **预约锚点**：博物院与酒文化景区；生产安全要求可能使部分酒业线路临时关闭。
- **休息安排**：场馆间用正规车辆转场，在博物院、景区游客中心或商场休息，不把“室内路线”理解为完全不受天气影响。
- **时间不足时**：只保留已确认开放的一个场馆，不临时转去李庄或洞穴景区。

### 亲子或低体力路线

**亲子路线**：宜宾市博物院 → 午餐 → 合江门公共区域短线 → 大观楼外围；根据儿童兴趣再选择李庄文化抗战博物馆作为另一半天。<br>
**低体力路线**：宜宾市博物院 → 车辆接驳至老城 → 大观楼近距离观看 → 合江门可落客区域短停；取消翠屏山登高和连续滨江步行。

- **减负方式**：亲子路线不安排品酒和酒厂生产环节，临江处由成年人持续看护；低体力路线每半天一个核心，提前确认落客点、电梯、座椅和卫生间。
- **预约锚点**：场馆对儿童、推车、轮椅、陪同人员和团体的最新规定。
- **休息安排**：以博物院和商业区的固定座椅为主，江岸只作短停；不在桥下、码头或无护栏河滩休息。
- **时间不足时**：两条路线都先删合江门延伸段；低体力路线只保留博物院。

### 远郊一日路线

**竹海方案**：主城区或长宁县住宿地 → 蜀南竹海游客入口 → 景交车连接的一条短环线 → 原住宿地。<br>
**石海方案**：主城区或兴文县城住宿地 → 兴文石海景区 → 地质博物馆与体力允许的洞穴线路 → 原住宿地。<br>
**川南民居方案**：主城区或江安县城 → 夕佳山民居 → 江安县城用餐 → 返回；不与竹海完整线硬拼。

- **适用条件**：三条只选一条。竹海与石海都需要早出、完整返程和天气余量；晕车、行动受限、洞穴不耐受或携幼儿者宜在景区附近住一晚。
- **预约锚点**：门票、正式入口、景交车、索道或洞穴开放、县际班次和住宿接送；自驾还要核对停车与景区车辆管理。
- **休息安排**：只在游客中心、县城、正规餐馆和景区休息点停留；不在山路弯道、林区消防通道、采石矿区或无管理河滩停车。
- **时间不足时**：整段远郊删除，不把竹海与石海压成“一日两海”；竹海只走一个片区，石海则放弃最耗体力的洞穴或地面延伸段。

## 住宿区域

| 区域 | 优点 | 缺点 | 适合人群 | 交通特点 |
|---|---|---|---|---|
| 翠屏老城与核心商圈 | 方便老城、合江门、燃面和夜间城市生活，首访氛围最集中 | 节假日拥堵、临街噪声和停车压力明显；老楼电梯与隔音差异大 | 首访、短停留、以老城与美食为主 | 老城内可步行加短途叫车，去博物院、李庄和铁路站仍需转场 |
| 叙州南岸与宜宾西站周边 | 铁路抵离、现代商业、餐饮和房型选择通常较稳定 | 与翠屏老城隔江，步行旅游氛围较弱；不同铁路站不可混用 | 晚到早走、行李较多、家庭和商务旅行 | 智轨、公交和车辆连接主城；订房时核对完整站名、出口与实际路线 |
| 宜宾站及高铁南片区 | 适合使用对应高铁车次和南部公路方向，较新住宿供给可能较多 | 建设与道路调整可能持续，去老城需预留接驳 | 铁路中转、计划去高县或南部县域者 | 以当期 12306 车次和地面交通为准，不凭“高铁站附近”判断是哪一站 |
| 三江新区相关片区 | 靠近博物院、大学城和新城公共空间，环境与现代设施较新 | 老城餐饮和传统街巷较远，点位分散 | 重点看博物院、亲子、需要较新建筑设施者 | 智轨、公交或车辆连接老城与铁路站；夜间末班需重查 |
| 李庄镇 | 便于古镇早晚错峰，能把博物馆聚落拆成两段 | 节假日客流、活动噪声和古镇住宿设施差异大，返主城选择较少 | 李庄深度游、摄影、慢节奏文化旅行 | 核对主城接驳、停车和最晚返程；临江住宿不等于可安全下到水边 |
| 长宁县城或蜀南竹海正式住宿区 | 减少主城当天往返，便于竹海早入与天气调整 | 县城到景区仍可能有距离，林区供电、热水、消防和退改需逐店确认 | 竹海 1–2 天、摄影、山林度假 | 按实际景区入口与景交车选择，不只看“竹海附近”的营销距离 |
| 兴文县城或石海门户 | 便于石海早入、洞穴与地质主题分段游览 | 晚间交通和住宿供给少于主城，县城到景区仍需接驳 | 石海、僰王山、地质研学 | 优先确认兴文铁路站、县城、景区入口三者之间的正规交通 |
| 南溪区或江安县城 | 方便南溪、夕佳山及江安方向分段 | 不适合作为每天游览三江口老城的唯一基地 | 县域文化、探亲办事、自驾分段旅行 | 智轨、公路或县际交通的末班和落客点需要逐次核对 |

不推荐未经核验的具体酒店。订房时核对电梯、无障碍客房、空调或冬季取暖、临街和活动噪声、行李寄存、停车与充电、早餐时段及退改规则；竹海、石海周边住宿还要确认消防疏散、山路接送、恶劣天气取消和夜间医疗条件。
