# 绵竹旅行指南

绵竹是德阳市代管的县级市，主城落在成都平原西北缘，向西很快进入龙门山前和峡谷。绵竹木版年画、剑南老街的酒业遗存、汉旺地震遗址，以及孝德、九龙—麓棠、清平等不同方向的乡村与山地，共同构成这座城市的旅行内容。各片区并不连续：年画村在孝德方向，汉旺和清平沿山展开，九顶山风景名胜区又有严格的保护与准入边界，不能把它们当成主城周边的一串步行景点。

> 建议停留：2–3 天；只看主城与年画可压缩为 1 天，增加清平或九龙—麓棠宜再留 1 天<br>
> 旅行关键词：绵竹年画、酒文化、地震记忆、川西乡村、龙门山<br>
> 主要体力：主城低至中等；山前景区和清平中等，正式山地线路可达较高<br>
> 最近研究：2026-07-31

## 城市格局与游览区域

绵竹的落脚中心是剑南、紫岩两个街道组成的主城，公共服务、餐饮和住宿最集中。绵竹南站位于孝德镇年俗村方向，与主城仍有地面接驳；中国绵竹年画村也在孝德镇，可与车站方向组合，但不是站前步行景点。向西进入九龙、麓棠等山前地带，向西北到汉旺，再沿绵远河进入清平，海拔、路况和天气敏感度逐级上升。

|---|---|---|---|
| 剑南—紫岩主城 | 绵竹年画博物馆、剑南老街—天益老号历史文化街区、居民餐饮和公共文化空间 | 两个核心文化点可用步行加短途车辆组合；酒坊文物、展陈空间与仍在运行的生产区要分开 | 适合作为多日住宿基地；前往年画村、汉旺和清平均需车辆接驳 |

**行政与地名边界：**绵竹法定行政代码为 `510683`，是德阳市代管的独立县级市，不属于德阳旌阳主城。广汉市、什邡市同样是独立县级市，三星堆、穿心店地震遗址和什邡山区不计入绵竹景点。固定快照采用 GeoNames `12492662`（Mianzhu）作为当前城市聚居点记录；Wikidata `Q1209118` 的 GeoNames 属性仍指向旧记录 `1800624`（Jiannan/Mianzhu），两处坐标相距约 2.43 公里，均落在主城尺度内。城市页以法定绵竹市及其主城为对象，不能把 GeoNames 聚居点的人口值当作官方全市人口。

**开放边界：**天益老号等依法开放的文物与展览空间可以参观，剑南春及其他酒企的酿造、储酒、包装、物流和消防管制区域只有运营方明确接待时才能进入。汉旺地震遗址的危损构筑物、维护区和封闭厂区不因可见就可以靠近；九顶山风景名胜区、林区、河道、矿山和水利设施也应服从保护分区、火险、汛期和现场封控。

汉旺遗址公园作为一个完整保护与运营单元记录，其内部钟楼、厂区遗迹、纪念墙和展陈不重复计算。九龙山—麓棠山旅游区的温泉、花田、乡村项目也按对应运营单元理解；若只是路过绵竹南站、年俗村入口或山前观景点，应视为路线节点。

地震遗址的价值来自保留和解释，而不是“废墟探险”。不翻越护栏、不触摸或攀爬危损构件，不进入封闭厂房、宿舍、施工和修缮区，也不对悼念者进行近距离拍摄。清平和九顶山方向不得凭社交媒体轨迹进入未开放沟谷、野路、采矿道路或巡护通道。

## 美食与餐饮

绵竹饮食以川西北平坝日常餐食为底色，米粉是最容易单人体验的早餐；板鸭、腊肉、柴火鸡、火锅和山地合餐更适合多人分享。酒文化是城市主题之一，但品鉴不是进入生产区的通行证，饮酒后不得驾车、骑行或参加漂流和山地活动。

## 经典行程

### 一日经典路线

**路线：**绵竹年画博物馆 → 主城午餐 → 剑南老街—天益老号公开区域 → 中国绵竹年画村 → 返回主城或绵竹南站

- **串联逻辑：**先在博物馆建立木版年画的历史与技艺框架，再看酒业街区，下午到孝德观察年画进入村落、画坊和当代体验；主城两点相近，年画村则需车辆接驳。
- **预约锚点：**年画博物馆闭馆与入馆规则、老街内部展陈开放、年画村所选画坊或体验项目；铁路离开者还需锁定列车与接驳。
- **休息安排：**主城安排完整午餐；到年画村后先在游客服务区坐下，再决定村内步行和体验长度。
- **时间不足时：**先删除老街外围与购物，再在年画村和老街中二选一；中午后才到时只做“博物馆＋主城短线”，不为赶车压缩站前时间。

### 两日城市与地震记忆路线

**第 1 天：**年画博物馆 → 主城午餐 → 剑南老街 → 年画村可选短线<br>
**第 2 天：**主城 → 汉旺地震遗址公园正式入口 → 纪念与科普主线 → 汉旺镇休息 → 返回主城

- **串联逻辑：**第一天集中年画和酒文化，第二天单独处理地震遗址、工业记忆与灾后重建；分日能避免把纪念空间压缩成赶路打卡。
- **预约锚点：**第 1 天场馆与体验开放，第 2 天遗址公园、展陈和团队接待安排，以及主城—汉旺往返交通。
- **休息安排：**两天午间都使用主城或汉旺镇的固定餐饮；遗址参观中按游客中心和规定休息点停留，不坐卧在遗址构件旁。
- **时间不足时：**第 1 天删除年画村，第 2 天只保留公开纪念科普核心；不翻越封闭区寻找所谓“更完整”的厂区视角。

### 三日文化与山前路线

**第 1 天：**年画博物馆 → 剑南老街 → 主城住宿<br>
**第 2 天：**年画村 → 孝德午餐与休息 → 返回主城<br>
**第 3 天：**九龙山—麓棠山旅游区中一个当季开放板块 → 正规服务区午餐 → 太平水库公开短段或另一低强度项目二选一 → 返回

- **串联逻辑：**三天分别对应主城文化、年画乡村和山前休闲；第 3 天只选一个运营板块为主，避免在分散景区之间反复开车。
- **预约锚点：**年画体验、温泉或季节项目，以及太平水库公开游线、停车和汛期状态；花期与宣传图不能代替当日开放公告。
- **休息安排：**第 2 天在孝德固定餐饮休息，第 3 天在游客中心、正规餐厅或住宿地长休，不在坝体、河床和临水临崖处野餐。
- **时间不足时：**第 2 天压缩村内外围步行，第 3 天删除太平水库或第二项目；若降雨或预警升级，整段取消山前路线。

### 雨天路线

**路线：**绵竹年画博物馆 → 主城坐席午餐 → 剑南老街当日开放的室内展陈 → 提前返回住宿

- **适用条件：**普通降雨且主城道路、场馆运行正常时使用；暴雨、雷电、山洪、地质灾害或道路管制预警下，不前往汉旺遗址边缘、九龙—麓棠、清平和九顶山方向。
- **串联逻辑：**活动留在主城固定建筑内，并用短途车辆减少湿滑路面暴露；老街只选择明确开放的室内空间。
- **预约锚点：**年画博物馆与老街展陈的闭馆、临展、维修和最晚入场。
- **休息安排：**午餐、候车和等雨都放在固定室内，不在桥下、河岸、地下通道低洼处或临时棚内停留。
- **时间不足时：**只保留年画博物馆；若积水加深或官方建议减少出行，则直接返回安全住宿。

### 亲子或低体力路线

**亲子路线：**年画博物馆重点展厅 → 午休 → 年画村已预约的短时体验 → 返回<br>
**低体力路线：**车辆抵达年画博物馆最近合规落客点 → 重点展厅 → 长午休 → 剑南老街平缓短段 → 返回

- **减负逻辑：**亲子行程用“看作品—做一次体验”形成完整主题；低体力行程留在主城并减少跨片区、石板路和长时间站立，两类条件不共用同一条路线。
- **预约锚点：**儿童体验的年龄、材料、时长和陪同规则，以及博物馆、老街的无障碍入口、卫生间、轮椅和最近落客点，资料不足处需向官方确认。
- **休息安排：**午间至少安排一次完整坐席休息，下午活动要有随时退出的车辆接点；携童车或轮椅时先确认路面连续性。
- **时间不足时：**亲子路线删除村内外围，低体力路线删除老街；出现疲劳、闷热、地面湿滑或不适时直接返回。

### 汉旺与清平两日路线

**第 1 天：**主城 → 汉旺地震遗址公园 → 汉旺镇午餐与休息 → 当日确认开放的镇区短线 → 汉旺、清平或主城住宿<br>
**第 2 天：**住宿地 → 清平镇正式游客区域 → 羌汉文化或当季经营项目 → 固定服务区休息 → 原路返回

- **串联逻辑：**汉旺是地震记忆和城镇重建主题，清平是更深的山谷聚落与度假方向；分两天可以把公路、天气和返程风险分别处理。
- **预约锚点：**遗址公园开放、清平具体项目和住宿，以及绵茂公路、支路、停车、末班接驳与气象预警。
- **休息安排：**第 1 天在汉旺固定餐饮补给，第 2 天只在镇区、游客中心或正规经营场所停留；不把河床、沟口、弃置厂区或林道当休息点。
- **时间不足时：**第 1 天删除镇区外围，第 2 天只留清平一个公开板块；强降雨、落石、道路抢修、结冰或封控时整日取消，不改走导航推荐的小路。

九顶山正式山地线路不宜从上列行程中临时加塞。只有在运营方或主管部门明确开放、天气和火险适合、装备与体力匹配且返程有保障时，才另作整日或多日方案；没有这些条件时，以清平镇公开游客区域为边界。

## 住宿区域

| 区域 | 优点 | 缺点 | 适合人群 | 交通特点 |
|---|---|---|---|---|
| 剑南—紫岩主城 | 餐饮、药店、车辆和公共服务最集中，前往年画博物馆与老街方便 | 前往年画村、汉旺和清平均需接驳；中心道路可能有车流和活动噪声 | 首访、公共交通、独行、预算有限和晚到旅行者 | 适合作为多日基底；订房时确认与实际街道、汽车站和上车点的距离 |
| 孝德—绵竹南站方向 | 方便铁路早出晚到，可衔接年画村 | 离主城餐饮和晚间服务有距离，“高铁站附近”不等于步行可达站房或景区 | 铁路到发、年画研学和次日早班旅客 | 依赖公交、接驳或车辆；站前道路、年画村入口和住宿地点需分别定位 |
| 汉旺镇 | 便于完整参观地震遗址并为清平方向预留时间 | 夜间餐饮、医疗和返程选择少于主城；遗址周边不一定都是住宿区 | 地震史、防灾教育和沿山慢行旅行者 | 主要依赖公路；遗址入口、镇区和继续进山的道路并非一个停车点 |
| 九龙—麓棠山前 | 靠近温泉、花田和乡村休闲项目，适合放慢节奏 | 项目季节性强，部分民宿离公共交通远；节庆、花期与周末价格波动 | 山前度假、亲子、自驾和摄影旅行者 | 多依赖自驾或预约车辆；确认最后进场道路、停车、充电与夜间照明 |
| 清平镇及正规山地住宿 | 减少夜间往返山路，便于体验清晨和山谷气候 | 强降雨、落石或道路管制可能造成行程中断；网络、医疗、维修和补给有限 | 避暑、山地停留和愿意预留机动日的旅行者 | 订房前确认车辆能否抵达、停车、供暖、信号、退改及封路时的应急安排 |

山地和乡村住宿应核对营业资质、消防疏散、停车或落客距离、房间台阶、电梯、热水、空调或供暖、夜间餐饮、手机信号和天气取消政策。带轮椅、童车或大件行李时，还需确认房门与卫生间尺寸；营销名称中的“景区内”“温泉旁”“高铁站店”不能代替实际地址。

## 市内交通

| 场景 | 建议与取舍 | 行前需要重查的内容 |
|---|---|---|
| 铁路抵达 | 绵竹南站是主要铁路门户，位于孝德镇年俗村方向而非剑南主城；出站后使用公交、接驳、出租车或网约车前往主城和年画村 | 12306 车次、检票与晚点，站前公交和接驳的线路、发车时刻、末班、行李规则及夜间车辆；旧线路资料不能当作永久班次 |
| 从成都、德阳或绵阳进入 | 铁路和公路均可使用；没有合适铁路时可先到区域枢纽再转合法客运或预约车辆 | 实际到达站、汽车客运站、跨城公交、施工和节假日拥堵；不要把德阳站、绵阳站或三星堆站当作绵竹市内车站 |
| 主城与年画村 | 主城内部可用步行加公交或短途车辆，年画村与绵竹南站方向可组合但仍需预留接驳 | 公交运行日、首末班、体验地点、景区入口和站前安检时间；返程票不应压在体验结束后立即衔接 |
| 前往汉旺 | 公路车辆是主要方式，适合半日至一日往返；遗址公园应从正式入口进入 | 班线或公交终点、返程末班、遗址入口、道路施工与活动管制；不在旧厂区封闭道路上下车 |
| 前往九龙—麓棠 | 点位分散，自驾或合规预约车辆通常比多次换乘更灵活 | 所选景区真实入口、停车、花期、温泉或漂流运营、山前暴雨与水库管理；一个项目开放不代表整个旅游区开放 |
| 前往清平与九顶山方向 | 先确认清平镇和所选正规项目，再安排车辆；更深山地线路需要独立运营、向导或管理许可条件 | 绵茂公路及支路管制、隧道、落石、山洪、结冰、森林火险、末班与信号；封控时不绕行矿区、林区和村道 |
| 步行与骑行 | 主城平坝适合分段步行；乡村骑行应选择公开道路并控制返程体力 | 高温、雷雨、货车、夜间照明、共享车辆服务范围和道路封闭；酒后不骑行 |
| 自驾与包车 | 自驾提高跨片区灵活度，但无法消除山地风险和景区内部步行；包车需核验营运资质与保险 | 高速与国省道路况、临时限行、停车预约、充电、救援、驾驶人饮酒安排及住宿退改 |

绵竹没有民用机场。选择成都双机场或绵阳机场后仍需完成城际铁路、公路或车辆接驳，航班与机场接驳不固定写入日程。地图上的直线距离也不能替代山路行车时间；清平和九顶山方向遇预警或封路时，应以取消山地行程为默认方案。

## 不同旅行者须知

| 旅行维度 | 可行条件 | 主要取舍 | 需额外核对 |
|---|---|---|---|
| 独行旅行 | 主城场馆、年画村和汉旺正式开放区可独立组合，米粉与小吃方便单人用餐 | 乡村与山区返程班次少，合餐份量偏大；不独自进入遗址封闭区、沟谷、林道和矿区 | 末班交通、单人接驳、住宿前台、手机信号和山地项目最低成行人数 |
| 亲子旅行 | 年画展陈、手工体验和地震科普主题明确，可分两天安排 | 遗址内容可能使低龄儿童不适，漂流、河谷、危损构件和山路增加看护负担 | 体验年龄、材料安全、儿童票、童车、卫生间、安全座椅和项目身高体重限制 |
| 长者或低体力旅行 | 车辆串联年画博物馆、老街短段和年画村服务区，可保留长午休 | 石板路、村内距离、遗址步行和山前坡道会累积负担，清平当日往返较疲劳 | 最近落客点、台阶、电梯、座椅、观光车、医疗点和返程车辆 |
| 无障碍需求 | 可优先咨询年画博物馆、游客中心、铁路重点旅客服务和现代住宿 | 老街、村落、遗址和山地游线容易出现门槛、碎石、坡道或车辆换乘中断；有接驳车不等于全线无障碍 | 无障碍入口、电梯、卫生间、轮椅尺寸、陪同规则、接驳装载与应急疏散均需向官方确认 |
| 摄影旅行 | 年画色彩、酒业街区、地震记忆、山前花田和峡谷题材差异明显 | 文物、作品版权、悼念者、居民、宗教活动、工业设施、无人机空域和保护地都有边界 | 闪光灯、三脚架、商业拍摄、人物授权、无人机、花田进入和遗址拍摄规定 |
| 预算有限 | 主城公共场馆、居民餐饮和公共交通可构成低成本骨架 | 跨片区包车、温泉、漂流、体验课和山地住宿比门票更易推高支出 | 免费场馆预约、体验材料费、接驳、停车、退票和住宿取消政策 |
| 晚出发或紧凑行程 | 只选年画博物馆或剑南老街一个主城主题，仍可形成完整半日 | 年画村、汉旺、九龙—麓棠和清平均不宜临时晚出发 | 最晚入场、闭馆、公交末班、铁路安检和夜间返程 |
| 雨季、高温或寒冷天气 | 普通小雨可转主城室内；夏季主城户外放在早晚，冬季优先平坝线路 | 暴雨会触发山洪、滑坡、落石和闭园；高温增加步行与遗址暴晒负担，低温可能使山路结冰 | 气象与地灾预警、河流水位、景区闭园、道路管制、森林火险和住宿供暖 |

汉旺地震遗址首先是纪念与教育空间。参观时降低音量，不摆拍灾难场景，不直播悼念者，不触碰、移动遗址物件。对地震经历敏感者和低龄儿童可先了解展陈内容，再决定停留长度。

沿山区域出现强降雨、雷声、沟水突然变浑或上涨、落石、树木倾倒、道路新裂缝及现场撤离提示时，应立即离开河道、沟口、崖壁和低洼处，服从封控并前往正规安置点。雨停、导航显示可通行或住宿仍可预订，都不代表地质灾害风险已经解除。
