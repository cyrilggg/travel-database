# 安顺旅行指南

安顺位于贵州中西部，旅行体验由三种截然不同的空间组成：西秀主城的老街、文庙与地方小吃，平坝和西秀乡间延续至今的屯堡聚落，以及黄果树、龙宫等以水为核心的喀斯特景区。三者在行政上同属安顺市域，却不能靠连续步行串联；把主城、屯堡方向和瀑布洞穴分别安排，行程会更从容，也更能应对预约、汛期和山地交通变化。

> - 建议停留：3–5 天；只看主城可留 1 天，黄果树至少单列 1 天
> - 旅行关键词：黄果树瀑布、喀斯特水洞、屯堡文化、古城街巷、地方博物馆、安顺小吃
> - 主要体力：中等至较高；大型景区有台阶、湿滑步道和多次换乘
> - 最近研究：2026-07-31

## 城市速览

| 维度 | 旅行判断 |
|---|---|
| 主要旅行价值 | 在一座尺度适中的高原城市中，把瀑布与洞穴地貌、屯堡聚落、明清以来的城市遗存和密集小吃组合起来。黄果树是首访自然核心，主城与屯堡则补足地方历史和日常生活。 |
| 建议停留 | 1 天可游主城；2 天可加黄果树；3 天再选龙宫或一条屯堡线；4–5 天适合把黄果树放慢，并在龙宫、平坝屯堡、西秀屯堡或更远县域中择一至两处。 |
| 季节取舍 | 春秋适合主城与村镇步行；夏季瀑布水量和避暑吸引力较强，但也是强降雨、雷电、客流和湿滑风险较高的时段；冬季游客相对少，需防湿冷、大雾和道路凝冻。水量、天气和舒适度不能同时保证。 |
| 预算 | 主城街巷、公共公园和小吃可低预算完成；黄果树、龙宫等大型景区的门票、观光车、游船或其他内部项目，以及远线往返车辆，是主要增量。 |
| 步行强度 | 主城可拆成短段；文物建筑常有门槛和台阶。黄果树三个核心片区距离远且地形起伏，龙宫含船行、洞内步道和换乘，屯堡村寨多石板路。 |
| 主要天气风险 | 强降雨、雷电、大风、冰雹、山洪、景区水位上涨、临水步道漫溢、滑坡与落石；冬季另有大雾、低温和局部凝冻。收到高等级预警时应取消洞穴、水边、峡谷和山地远线。 |
| 独行 | 主城点餐和公共交通较方便；远线要在出发前同时确认去程、返程和最后入园时间，不能把单程叫到车视为已有返程保障。 |
| 亲子 | 博物馆、主城短线和只选一个核心片区的景区路线较易控制；瀑布水边、洞穴乘船、狭窄步道、观光车站和村寨道路需要持续看护。 |
| 长者与低体力 | 可用车辆连接主城点位，并在黄果树只选大瀑布或陡坡塘等一个重点区域。景区提供的辅助器具不等于全程无台阶，无障碍连续性须逐段向运营方确认。 |
| 无障碍信息 | 黄果树公开资料列有轮椅等辅助器具和观光车乘车帮助，但不代表全部步道可连续通行；龙宫船舶、历史院落和屯堡石板路缺少足够的全程无障碍证据，均需向官方确认。 |

安顺市法定行政代码为 `520400`。市域包含西秀区、平坝区、普定县、镇宁布依族苗族自治县、关岭布依族苗族自治县和紫云苗族布依族自治县。安顺经济技术开发区与黄果树旅游区是管理范围，不应误当成新增的法定县级行政区。

## 城市格局与游览区域

安顺中心城区主要位于西秀区。安顺古城、文庙、王若飞故居、顾府街和儒林路一带构成适合分段步行的老城核心；虹山湖在其北侧，安顺站在南侧，安顺西站和较新的城市片区位于更西方向。老城内部距离可控，但路面、坡度和过街条件并不处处连续平坦。

| 区域 | 主要内容 | 移动方式 | 行程边界 |
|---|---|---|---|
| 安顺古城—文庙—顾府街 | 文庙、武庙、王若飞故居、老街巷、小吃和夜间公共文化空间。 | 片区内分段步行，远端点位以公交或车辆衔接。 | “安顺古城”是开放式街区，不是把所有古建筑包在一张票内的封闭景区；不同场馆各自核对开放。 |
| 虹山湖片区 | 城市公园、湖岸公共空间与居民休闲。 | 从老城乘公交或车辆，湖岸只选一段步行。 | 水边、夜景和活动安排受天气与现场管理影响。 |
| 安顺市博物馆—安顺学院方向 | 位于安顺学院北门一带的地方综合博物馆。 | 从老城或虹山湖乘公交或车辆，参观后再转往下一片区。 | 博物馆与虹山湖不是同一处；开放日、预约和展览独立核对。 |
| 安顺西站—西部片区 | 高铁到达枢纽、较新的住宿和商业片区。 | 公交、出租车或网约车接老城及景区车辆。 | 站名中的“安顺”不表示步行可到老城；“安顺西站”也不在黄果树景区门口。 |
| 平坝—天龙屯堡方向 | 平坝城区、天龙村及屯堡文化点位，位于主城以东。 | 高铁、县域公交、旅游车辆或自驾组合；村内步行。 | 平坝是安顺另一座城区；天龙屯堡不是安顺老城的街区，也不与云峰、旧州天然连成一条步行线。 |
| 西秀东南乡间 | 云峰屯堡、鲍家屯、旧州古镇等分散村镇。 | 车辆往返为主，到达后走石板街巷。 | 各聚落有独立社区、保护和运营边界；一天通常只选一个主点，或在可靠车辆支持下加一个近邻点。 |
| 龙宫方向 | 水溶洞、地下河、洞口瀑布和喀斯特地貌，位于西秀区龙宫镇。 | 从主城或其他枢纽乘旅游车辆、自驾或核验后的公共交通。 | 法定行政上仍属西秀区范围；运营管理纳入黄果树旅游区体系。它与黄果树大瀑布是两个独立大型景区。 |
| 黄果树方向 | 大瀑布、陡坡塘、天星桥及游客集散片区，位于主城西南远线。 | 景区直达车辆、自驾或铁路加地面接驳；景区内依靠观光车和步行。 | 核心游客服务中心在镇宁方向，景区范围还涉及关岭；黄果树旅游区管委会是受托管理机构，不是法定县。三大核心片区合计一个黄果树景区。 |
| 关岭、紫云及其他县域 | 坝陵河与花江峡谷、格凸河、县城文化和山地村寨。 | 长距离公路或铁路加地面接驳，通常需要独立一天以上。 | 虽属安顺市域，也不应作为主城“顺路景点”；高桥、峡谷、洞穴和户外项目另有安全及预约门槛。 |

黄果树旅游区工委、管委会公开资料显示，其受西秀区、镇宁自治县和关岭自治县委托管理龙宫镇、黄果树镇和白水镇。这解释了为什么宣传、票务和运营常以“大黄果树”统称多个片区，但旅行中仍要按实际入口、县域道路和独立景区来安排行程。

黄果树内部的大瀑布、水帘洞、陡坡塘、天星桥、索道、扶梯与观光车都是同一大型景区中的游览区或服务项目，不分别增加景点数量。龙宫的一进龙宫、二进龙宫、天池、龙门飞瀑和游船也合计一处。景区临时关闭某个内部区域时，不应寻找非开放入口替代。

## 美食与餐饮

安顺小吃密度高，适合用“少量多样”的方式认识地方饮食。常见风味有酸、辣、脆、糯，糟辣椒、辣椒蘸水、折耳根和发酵酸汤经常出现。菜名无法完整说明汤底、肉类和过敏原；严格素食、清真、无麸质或严重过敏需求需要逐店确认锅具、油和蘸水。

| 菜品或餐饮类型 | 常见区域 | 一个人用餐与份量 | 风味、过敏原与饮食限制 | 排队风险与替代方法 |
|---|---|---|---|---|
| 安顺裹卷 | 顾府街、儒林路、老城及居民商业区 | 常按个或小份购买，适合独行和拼成小吃餐 | 米皮包豆芽、蔬菜或肉末等，配糟辣椒或蘸水；肉类、花生、芝麻、酱油和折耳根按店变化 | 热门摊高峰排队；换同类店并先看馅料、制作台与明码标价，不必只认一家 |
| 小锅凉粉、剪粉与凉拌粉 | 老城、市场和社区店 | 一碗或一盘即可，份量容易控制 | 辣椒、醋、酱油、花生、芝麻和脆哨常见；“凉粉”不等于无麸质，调料需核对 | 午后和夜间较集中；不耐辣可让辣椒、蘸水分开，严重过敏需确认共用器具 |
| 夺夺粉 | 主城火锅与小吃餐饮区 | 通常更适合 2 人以上；独行先问小锅 | 常以酸辣汤底涮粉和配菜，可能含肉汤、豆制品、花生、芝麻及多种复合底料 | 晚餐高峰可能等位；人数少可换酸汤粉或单人小锅，先问最低份量 |
| 破酥包 | 早餐店、老城小吃区 | 单个购买，适合早餐或加餐 | 小麦面皮，馅料可能含猪肉、芝麻、坚果或糖；酥皮可能使用动物油 | 早间较常见，售完即止；可换松糕粑或其他蒸点，但仍需重新核对成分 |
| 油炸粑稀饭 | 老城早餐与小吃店 | 常见一碗一份，可独食 | 糯米或米制品配油炸物和调味；炸油共用、花生芝麻和高糖高油需留意 | 早餐时段更易找到；排队时换社区早餐店，吞咽困难者慎选黏糯食物 |
| 屯堡烤小肠 | 顾府街、屯堡村镇及夜间餐饮区 | 小份可试吃，也常适合分享 | 猪小肠配辣椒、折耳根等；不适合素食或清真需求，内脏应确保充分熟制 | 热门夜间摊位排队；以卫生、熟度和价格为优先，不追逐单一招牌 |
| 松糕粑、冲冲糕与冰浆 | 老城、市集和屯堡方向 | 小份甜点，适合分享或加餐 | 糯米、糖、奶制品、花生、芝麻和其他坚果可能出现；冰浆另需注意冷饮卫生 | 商业街选择多；可要求少糖或少配料，但严重过敏仍需确认交叉接触 |
| 布依族或苗族风味合餐 | 镇宁、关岭、紫云及村寨餐饮 | 多为多人共享，独行先问套餐与最小份 | 腊肉、酸汤、辣椒、鱼、豆制品和米酒可能出现；不同社区饮食不可互相概括 | 节庆和团队时段可能繁忙；优先看当日菜单与明码标价，不把表演餐视为唯一体验 |

### 餐饮区域

| 区域 | 餐饮特点 | 主要取舍 |
|---|---|---|
| 顾府街—儒林路—古城 | 裹卷、粉面、破酥包、烤小肠和夜间小吃集中，适合主城步行日。 | 商业更替和节假日排队明显；先看价格与卫生条件，同类替代丰富。 |
| 中华路及周边居民区 | 日常粉面、早餐和家常菜更分散，游客密度相对低。 | 营业和菜单信息可能不完整，饮食限制需要现场沟通。 |
| 虹山湖与新城商业区 | 商场、连锁和正餐选择较完整，适合博物馆日或多人用餐。 | 地方小吃密度和老城氛围较弱。 |
| 平坝与屯堡方向 | 屯堡菜、村镇小吃和农家餐饮，可与单一村寨行程结合。 | 份量常偏合餐，返程前预留用餐时间；不把居民家院默认成营业场所。 |
| 黄果树游客集散区 | 游览前后餐饮和住宿集中，便于早入园。 | 旺季价格、等位和营业变化大；进入长步道前准备饮水，但遵守景区携带规定。 |

## 经典行程

以下路线按半日或整日组织，不采用分钟级课表。黄果树、龙宫和屯堡各自都可能消耗一整天，不把三个方向压缩为“安顺一日游”。

### 一日主城路线

- **顺序**：安顺市博物馆 → 乘车到安顺古城午餐 → 安顺文庙 → 王若飞故居或老街巷二选一 → 顾府街、儒林路结束；仍有体力时再到虹山湖选一段。
- **串联逻辑**：上午先用博物馆建立地方历史背景，再乘车进入古城看建筑与城市生活；古城内部才以步行为主，虹山湖只是天气与体力允许时的弹性收尾。
- **预约锚点**：以安顺市博物馆或文庙当天确认的开放时段为锚点，另一处如遇闭馆则改成街区短线。
- **休息区域**：虹山湖周边商业、古城午餐店和顾府街一带；进入文物院落前先处理补水与卫生间需求。
- **时间不足**：先删虹山湖，再把王若飞故居与文庙改为二选一；保留古城街巷和一处有明确开放信息的文化点。

### 两日城市与瀑布路线

- **第 1 天**：按一日主城路线，晚上在古城范围用餐，不再转场远郊。
- **第 2 天**：提前预约黄果树 → 大瀑布片区 → 正式休息与午餐 → 陡坡塘短线或天星桥选段二选一 → 返回主城或住黄果树集散区。
- **串联逻辑**：主城和黄果树各占完整一天。黄果树第二片区只做一项，避免把大瀑布、陡坡塘和天星桥全程硬塞在同一天。
- **预约锚点**：黄果树入园时段是硬锚点；计划进入水帘洞时，还需单独确认实名分时名额。
- **休息区域**：游客中心、片区服务点和明确开放的餐饮区；不要在狭窄游道、临水护栏或观光车排队通道停留休息。
- **时间不足**：保留大瀑布，删除第二片区；遇强降雨或官方管控则整段取消，不绕行非开放道路。

### 三日城市、瀑布与屯堡路线

- **第 1 天**：安顺市博物馆、古城、文庙和小吃短线。
- **第 2 天**：黄果树景区，采用两日路线中的不过载版本。
- **第 3 天**：天龙屯堡独立半日至一日；若住宿和车辆更靠近西秀东南方向，也可改选云峰屯堡或旧州古镇，但不把三个聚落全部串联。
- **串联逻辑**：三天分别回答安顺的城市历史、喀斯特水景和屯堡聚落三条主线，减少跨方向折返。
- **预约锚点**：黄果树最先锁定；屯堡日再确认景区开放、表演、讲解与返程交通，不能用旧活动海报安排当天行程。
- **休息区域**：主城用商业设施，黄果树用游客中心，屯堡日用正规游客服务区或镇区餐饮；村内不依赖临时摊点补给。
- **时间不足**：第三天只保留一座屯堡村镇；缩成两天时，在“主城历史”与“屯堡文化”之间按兴趣二选一，黄果树不与两者拼成同日。

### 雨天路线

- **顺序**：安顺市博物馆 → 室内午餐 → 王若飞故居 → 古城有遮蔽的短段；任何一处未开放就以商业区室内休息替代。
- **适用条件**：仅适合普通降雨且市区交通正常。暴雨、雷电、大风或地质灾害预警期间应减少外出，不把龙宫水洞当作天然避雨场所。
- **预约锚点**：以博物馆和故居当日开放为准；提前查看黄果树、龙宫是否发布停航、闭园或部分封闭公告。
- **休息区域**：博物馆服务区、古城周边正规餐饮和商场；石板路积水时缩短街巷段。
- **时间不足**：保留一座已确认开放的室内场馆和一顿地方餐；取消虹山湖、村寨、瀑布、洞穴及所有临水远线。

### 亲子或低体力路线

- **亲子顺序**：安顺市博物馆 → 午餐 → 古城主街短段 → 王若飞故居或文庙二选一。用车辆连接，不安排夜间远郊返程。
- **低体力顺序**：古城就近下车 → 文庙或故居二选一 → 正式午餐与长休息 → 顾府街短段；次日若去黄果树，只选一个核心片区并提前确认辅助服务。
- **减负方式**：不以观光车、扶梯或游船等同于无步行；提前询问入口到核心看点之间仍需走的坡道、台阶和湿滑路段。
- **预约锚点**：主城以一个场馆为锚点；黄果树以入园和辅助服务确认为锚点，龙宫则需同时确认船舶运营、上下船要求和洞内步道。
- **休息区域**：优先游客中心、场馆服务区和正规餐饮，不在村寨私宅门口或景区狭窄步道长时间停留。
- **时间不足**：删掉第二个场馆或街区延伸段；出现疲劳、眩晕或湿滑风险时立即结束，不为完成内部子景点继续赶路。

### 黄果树一日路线

- **顺序**：主城或黄果树集散区出发 → 按预约时段入园 → 大瀑布片区 → 午餐和完整休息 → 陡坡塘短线或天星桥选段 → 按已确认的车辆返程。
- **适用条件**：已完成门票、时段、交通和返程确认，且天气与景区公告正常。希望完整走天星桥上下半程者，应删去陡坡塘并评估是否需要把黄果树扩为两天。
- **预约锚点**：门票和入园时段；水帘洞名额是额外锚点，未预约成功不影响从其他合规路线观看大瀑布。
- **休息区域**：游客中心和各片区官方服务点。用餐不安排在短暂换乘缝隙里，旺季为排队预留弹性。
- **时间不足**：只保留大瀑布主线；第二片区整段删除。不要先进入天星桥长线后再以赶末班车为由抄近路。

### 龙宫或屯堡一日路线

- **龙宫方案**：主城出发 → 龙宫游客中心 → 按当日开放范围完成船行与步道 → 午餐和休息 → 原路或已确认车辆返程。水位、停航和上下船条件是硬门槛。
- **屯堡方案**：主城出发 → 天龙屯堡、云峰屯堡或旧州古镇三选一 → 村镇午餐 → 继续同一景区或镇区短线 → 返程。
- **串联逻辑**：两类目的地都需要可靠地面交通，但自然风险和文化参观方式不同，因此只能二选一，不互相拼接。
- **预约锚点**：龙宫为门票、船舶与入园时段；屯堡为开放、讲解或演出和返程车辆。
- **休息区域**：景区游客中心、镇区正规餐饮和明确开放的公共空间。
- **时间不足**：龙宫取消非核心项目；屯堡只走主街与一处代表性建筑。午后才从主城出发时，改留在主城，不临时启动远线。

## 住宿区域

| 区域 | 优点 | 缺点 | 适合人群 | 交通特点 |
|---|---|---|---|---|
| 安顺古城及中华路周边 | 步行可接老街、小吃和部分文化点，夜间生活便利。 | 老建筑、商业街和临街房可能有台阶、隔音或停车限制。 | 首次到访、重视城市漫步和餐饮者。 | 到安顺站较近；去安顺西站、黄果树和龙宫仍需车辆。 |
| 虹山湖—主城北部 | 环境相对开阔，可接博物馆、公园和城市商业。 | 与古城核心并非全部连续步行，夜间活动分散。 | 希望在主城放慢、重视公园与场馆者。 | 公交或车辆接古城和车站；远线仍需单独集散。 |
| 安顺西站—西部新城 | 高铁到发和早晚转场便利，现代住宿与商业较集中。 | 距老城有明显转场，城市历史氛围较弱。 | 晚到早走、携大件行李或以高铁为主者。 | 先确认酒店接驳和景区车辆实际上车点，不以“西站附近”推定能直达景区。 |
| 安顺站—南部片区 | 普速铁路和主城交通衔接方便，住宿选择多。 | 站前交通、人流和临街噪声可能更明显。 | 使用安顺站或重视公共交通换乘者。 | 与安顺西站不是同一车站；订票和叫车时核对全名。 |
| 黄果树游客集散区 | 有利于早入园、把大型景区拆成两天，并减少当天主城往返。 | 旺季价格与客流波动较大，城市餐饮和场馆选择少。 | 把黄果树作为旅行核心、希望降低单日体力者。 | 返主城、去铁路站或下一目的地都需提前锁定车辆；并非所有住宿都在同一票务中心旁。 |
| 平坝或屯堡村镇周边 | 便于观察村镇早晚生活，减少屯堡日往返。 | 住宿标准、无障碍、餐饮和夜间交通差异大。 | 已确定单一屯堡方向、愿意放慢的旅行者。 | 公共交通班次和叫车可得性需逐日确认，不能依赖临时返程。 |

不推荐未经当日核验的具体酒店。需要无障碍客房时，应直接确认入口坡道、电梯、浴室扶手、门宽、床高、轮椅转身空间和车辆落客点；“无障碍房”名称本身不足以证明连续可用。

## 市内交通

安顺没有城市轨道交通。旅行移动依靠铁路、机场、公交、出租车、网约车、旅游车辆和自驾。主城内部可把古城当作步行核心，但远线之间必须回到交通枢纽或使用预先确认的车辆。

| 场景 | 建议与取舍 | 行前需要重查 |
|---|---|---|
| 高铁到达 | 安顺西站是主要高铁枢纽，适合从贵阳、昆明等方向到达；出站后再用公交或车辆前往老城、住宿或景区集散点。 | 车次、实际到站、末班公交、出租车排队、住宿接驳与景区直通车上车点。 |
| 普速铁路到达 | 安顺站更靠近传统主城，适合停靠该站的列车。 | 不要把安顺站与安顺西站混用；核对车次、出站交通和深夜到达方案。 |
| 航空到达 | 安顺黄果树机场是运输机场，但航线和班期波动较大；只有航班日期合适时才作为主要入口。 | 航班是否实际执飞、退改、机场到住宿或景区的车辆、晚到后的替代住宿。机场名称不代表位于黄果树瀑布入口。 |
| 主城公交 | 适合连接车站、古城、虹山湖和城市商业区，成本较低。 | 线路、站名、运营时段、临时绕行和支付方式；晚间不要依赖未确认的末班。 |
| 出租车与网约车 | 适合主城跨片区、携行李和低体力移动。去远线时应确认司机是否合规接单及是否包含等候和返程。 | 价格、取消规则、上车点、景区交通管制、返程订单和手机信号。 |
| 黄果树接驳 | 可从安顺西站、主城、机场或其他枢纽寻找官方旅游车辆，也可自驾。铁路只把旅客带到安顺西站或关岭站等区域节点，仍需地面转移。 | 运营主体、购票渠道、去回程时刻、具体票务中心、行李政策和天气退改。 |
| 龙宫与屯堡方向 | 公共交通、旅游专线和包车均可能可用，但频次与上车点变化较大。一天只走一个方向可降低错过返程的风险。 | 当日班次、末班、是否直达游客中心、儿童或轮椅装载、返程预约。 |
| 自驾 | 多个县域目的地分散，自驾灵活；但山地公路、景区限流和停车管理会把时间从驾驶转移到等待。 | 暴雨、大雾、凝冻、落石、道路管制、停车预约、充电或加油，以及驾驶员山路经验。 |

“黄果树”在机场、景区、旅游区和宣传线路中会反复出现。订票时必须看完整名称：安顺黄果树机场、黄果树景区、黄果树旅游区和黄果树镇不是同一个地点；安顺西站、关岭站也都不是景区检票口。

铁路重点旅客服务可通过中国铁路 12306 提前申请，但站内协助不会自动延伸到站外车辆、酒店、村寨和景区步道。黄果树 2026 年暑期公开须知说明游客中心有轮椅、拐杖和婴儿车等辅助器具，观光车乘车点有轮椅辅助踏板；同时，景区仍有陡坡、台阶、狭窄潮湿游道。需要连续无障碍路线时，应逐段确认，不把单项设施等同于全程无障碍。

## 不同旅行者须知

| 旅行维度 | 实用建议 |
|---|---|
| 独行旅行 | 主城小吃和场馆可灵活安排。去黄果树、龙宫或村寨前，把去程、返程、住宿、紧急联系人和无信号时的集合点同时确认；不跟随陌生招揽进入非开放洞穴、河道或村寨私宅。 |
| 亲子旅行 | 一天只安排一个大型景区，给观光车排队、用餐和卫生间留出时间。瀑布临水区、洞穴上下船、湿滑台阶和停车场持续牵护；项目年龄、身高和监护规则逐项询问。 |
| 长者或低体力旅行 | 主城用车辆连接单一场馆和短街区。黄果树选择一个核心片区，龙宫先询问上下船和必经台阶；辅助器具只能减轻部分路段，不承诺完成全线。 |
| 无障碍需求 | 黄果树有部分辅助器具和乘车帮助的公开证据，但水帘洞狭窄湿滑，其他片区连续通行仍需确认。龙宫船舶、历史建筑、石板村寨和不同住宿之间缺少足够公开证据证明全程无障碍，应向各运营方确认并准备短线替代。 |
| 摄影旅行 | 瀑布水雾、洞穴弱光和村寨石墙适合不同题材，但三脚架、闪光灯、无人机和商业拍摄受场馆、景区与空域规则限制。黄果树现行公告禁止未经批准的无人机飞行；未来行程仍需重查。 |
| 预算有限 | 以主城为住宿基地、公共交通衔接，并在黄果树、龙宫和屯堡中按天数取舍，可减少换房和包车。不要用低价非正规车辆或非开放入口节省成本。 |
| 晚出发或紧凑行程 | 下午只走古城与一处确认开放的场馆，或虹山湖短段。没有完整白天和可靠返程时，不临时前往黄果树、龙宫、格凸河或分散村寨。 |
| 雨季与强对流 | 普通小雨可采用主城室内线；暴雨、雷电、大风或地质灾害预警时，取消瀑布、洞穴、峡谷、河岸和村道。龙宫曾因水位超过安全行船线而停航或闭园，黄果树也会分区管控。 |
| 冬季湿冷与凝冻 | 室内外温差、低云雾和湿冷会增加体力消耗；高架、桥面、坡道和景区石阶可能结冰。没有冬季山路经验时，不把自驾作为唯一方案。 |
| 多民族与屯堡文化参观 | 安顺市域有屯堡、布依族、苗族等不同社区和文化传统，不能用一种服饰、表演或饮食概括全部居民。拍摄人物和仪式先征得同意，不要求居民表演、换装或开放私人空间。 |
| 洞穴与水边安全 | 只走官方开放路线，不进入野洞、地下河、施工便道或封闭游道。洞穴停航、景区封闭和警戒线都是取消信号，不通过徒步绕行规避。 |
| 饮食限制 | 猪肉、内脏、肉汤、辣椒、折耳根、花生、芝麻、豆制品和发酵底料常见。清真、素食、低盐、无麸质和严重过敏需求按每家店的汤底、油、锅具、蘸水分别确认。 |

景区、村寨和县城之间的天气可能不同。主城无雨时，黄果树上游来水仍可能影响临水游道，龙宫也可能因水位停航；判断远线是否可走，应同时查看目的地预警和运营方公告，而不是只看住宿地窗外。
