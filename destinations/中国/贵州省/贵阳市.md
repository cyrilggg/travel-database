# 贵阳旅行指南

贵阳是一座被山体、河谷和立交切分的高原城市。传统中心围绕喷水池、文昌阁和南明河展开，甲秀楼标记河上历史轴线，黔灵山直接嵌入中心城区；向西北是观山湖的新城与省级场馆，向南则依次进入花溪湿地、青岩古镇和更远的喀斯特景区。理解这些片区的距离和体力差异，比在地图上把景点连成一圈更重要。

> - 建议停留：2–4 天
> - 旅行关键词：山城、南明河、历史楼阁、城市森林、贵州省博物馆、青岩古镇、酸辣饮食
> - 主要体力：中等步行；黔灵山、青岩石路和天河潭为中高强度
> - 最近研究：2026-07-30

## 城市速览

| 维度 | 旅行判断 |
|---|---|
| 主要旅行价值 | 在紧凑但起伏明显的中心城区观察山、河与城市生活，再通过省级博物馆、花溪和青岩理解贵州的历史、自然与多民族文化。 |
| 建议停留 | 1 天可走黔灵山与传统中心；2 天可加入青岩；3 天可增加贵州省博物馆和观山湖；4 天适合花溪湿地或天河潭。 |
| 季节取舍 | 春秋适合城市步行；夏季相对许多低海拔城市凉爽，但也是热门期，降雨、雷电和短时强降水不能忽略；冬季常有湿冷、低云雾和凝冻风险。 |
| 预算 | 街巷、公园和小吃可组成较低预算行程；主要增量来自省外到达、热门季住宿、正餐火锅、青岩或天河潭交通，以及景区内部项目。 |
| 步行强度 | 中心点位直线距离不大，坡道、台阶、河岸绕行和立交过街会增加体力；黔灵山、青岩城墙和喀斯特景区应单独评估。 |
| 主要天气风险 | 暴雨、雷电、大雾、山地滑坡与道路中断风险；冬季低温雨雪和凝冻。普通小雨可继续场馆路线，气象预警时应取消山地、洞穴、水边和远郊。 |
| 独行 | 公共交通和单人小吃选择丰富；夜间不熟悉的山路、河岸支路和远郊返程应降低复杂度。 |
| 亲子 | 贵州省博物馆、花溪湿地选段和青岩短线较易组合；黔灵山猕猴、水边、湿滑石路和洞穴项目需要持续看护。 |
| 长者与低体力 | 可把传统中心分成文昌阁和南明河两段，段间乘车；黔灵山不要求登顶，青岩只选主街和近入口节点。无障碍连续性需向官方确认。 |

贵阳既可作为一座城市单独游览，也常被当作贵州跨市旅行的交通中心。后者容易造成范围混淆：黄果树、荔波、西江千户苗寨和遵义都不属于贵阳，往返所占的一天也不应被写成“贵阳市区一日游”。

## 城市格局与游览区域

传统中心主要位于云岩区和南明区。喷水池、民生路一带是餐饮和商业核心，文昌阁保留旧城东门附近的历史记忆；甲秀楼位于南明河上，向西可接筑城广场和贵州省民族博物馆。几块区域能串联，但并非全程平坦步行街。

| 区域 | 城市关系与主要内容 | 适合的移动方式 | 行程边界 |
|---|---|---|---|
| 喷水池—民生路—文昌阁 | 传统中心北部与东部，街巷餐饮、商业和历史楼阁交织。 | 片区内步行；跨大路口依导航使用人行设施。 | 老城遗存是散点，不是完整封闭古城；夜市和店铺营业变化快。 |
| 甲秀楼—南明河—筑城广场 | 传统中心南部的河岸文化轴，甲秀楼、浮玉桥、翠微园与城市公共空间相接。 | 河岸选段步行，必要时乘车接文昌阁或黔灵山。 | 甲秀楼建筑群只计一处；河岸夜景和亮灯时间不应视为永久安排。 |
| 黔灵山片区 | 位于传统中心西北侧，是城市森林、山路、寺院、湖泊、动物园和野生猕猴共同构成的综合公园。 | 公共交通到入口后按线路步行，体力不足者选低处短线。 | 公园内部看点不拆分计数；与老城不要默认连续登山步行。 |
| 观山湖—省级场馆 | 位于传统中心西北方向的新城区，贵州省博物馆、观山湖公园和现代商业分布于此。 | 轨道交通、公交或车辆跨城转场，片区内再步行。 | 贵州省博物馆与观山湖公园不是同一景点；公园很大，只选一段。 |
| 贵阳北站片区 | 高铁交通节点，位于观山湖与传统中心之间的北部方向。 | 铁路与轨道交通换乘。 | 适合到达和中转，不等于住在老城或省博物馆门口。 |
| 贵阳站—河滨公园一带 | 位于传统中心南侧，是铁路、住宿与城市公共交通节点。 | 轨道交通、公交、步行或车辆。 | 站名与贵阳北、贵阳东不同；抵达后仍需确认具体住宿方向。 |
| 花溪国家城市湿地公园 | 中心城区南侧，以花溪河串联十里河滩、花溪公园和平桥等游览段。 | 轨道交通或公交到片区，再选择步行或骑行短段。 | 三个内部游览段合计一个湿地公园，不重复计算；全线并非轻松散步。 |
| 青岩古镇 | 花溪区更南侧的历史城镇，石街、城墙、宗教建筑和居民商业空间并存。 | 公共交通或车辆独立往返，镇内步行。 | 不属于贵阳老城，也不是花溪湿地内部；通常占独立半日至 1 天。 |
| 天河潭 | 花溪区与贵安方向交界附近的喀斯特景区。 | 轨道交通、公交或车辆，景区内按项目移动。 | 洞穴、瀑布、峡谷、游船和商业区合计一个景区；不要与青岩强行同日全走。 |
| 龙洞堡机场—东部 | 机场位于城市东部，贵阳东站在东北方向，均与传统中心有转场距离。 | 轨道交通、公交或车辆；铁路接驳以实际车次为准。 | 机场、贵阳东站和贵阳站不是同一交通节点。 |

贵阳行政范围还包括清镇、修文、开阳、息烽等县市区，分布着红枫湖、阳明文化园、峡谷和温泉等目的地。这些地点即使在贵阳市域内，也有远郊交通和独立运营边界，不能因为行政归属就塞进中心城区路线。

跨市州边界应单独记住：黄果树属于安顺市；荔波大小七孔属于黔南州荔波县；西江千户苗寨属于黔东南州雷山县；遵义拥有独立的地级市与景区体系。它们可以与贵阳组合成贵州旅行，但不计入贵阳景点完成率。

## 主要景点

优先级说明：A 为首访核心；B 为按兴趣补充；C 为远郊、季节性或通常需要独立半日以上；“路线节点”只用于衔接，不计入景点完成率。同一景区及内部子点只计一次。

喷水池、民生路、正新街、青云市集和筑城广场是餐饮或换乘节点，不作为独立景点计数。商业空间变化很快，不能用一家店或一条夜市代表整座城市。

### 城市山地与观山湖

| 景点 | 区域 | 类型 | 主要看点 | 建议用时 | 室内外 | 体力 | 预约风险 | 天气影响 | 优先级 |
|---|---|---|---|---:|---|---|---|---|---|
| 黔灵山公园 | 云岩区、传统中心西北 | 城市森林、山地公园、寺院与动物观察 | 山体直接进入城市的关系、林地步道、黔灵湖及公园文化 | 3–5 小时 | 室外为主 | 中高；低处短线可降低 | 高；预约和客流管理可能变化 | 高；雷雨、暴雨、结冰和大雾均影响山路 | A |
| 贵州省博物馆 | 观山湖区 | 综合博物馆 | 贵州古生物、历史进程、各民族服饰与工艺，以及地区交流 | 3–5 小时 | 室内 | 低至中 | 高；实名预约、展览和证件规则会变 | 低；极端天气仍可能调整 | B |
| 观山湖公园 | 观山湖区 | 城市公园、湖泊与绿地 | 新城尺度、湖岸和居民日常休闲空间 | 1.5–3 小时 | 室外 | 低至中；完整绕行偏高 | 低 | 中高；暴晒、雷雨和冬季湿冷影响明显 | B |

黔灵山公园内的弘福寺、黔灵湖、山路、动物园和其他节点属于同一个公园，不分别增加景点数量。园内野生猕猴不是互动道具：不要投喂、逗弄、触摸或展示食物，收好塑料袋和饮料，保持距离并服从现场管理。

贵州省博物馆和贵州省民族博物馆是两家不同机构。前者在观山湖提供自然、历史和文化的省域总览；后者位于传统中心，适合围绕民族生活与专题展继续深入。展品中的一种服饰或工艺只代表特定地区、时期或群体，不能据此概括所有苗族、布依族、侗族或整个贵州。

花溪国家城市湿地公园内部的十里河滩、花溪公园和平桥只计一个公园；青岩古镇内部的城门、背街、城墙、赵公祠、慈云寺等只计一个古镇；天河潭内部的洞穴、瀑布、游船和天生桥只计一个景区。三个大景区彼此独立，只有时间、交通和体力都充足时才考虑同方向组合。

## 美食与餐饮

贵阳饮食常以酸、辣、香和蘸水形成层次，糊辣椒、糟辣椒、折耳根、木姜子等味道辨识度很高。辣度不是唯一变量：汤底是否含肉、蘸水是否含花生或芝麻、面条是否含蛋和小麦、是否共锅共油，都需要按具体店铺确认。

| 菜品或类型 | 风味与点餐方式 | 单人和份量 | 饮食限制与风险 | 寻找区域与替代方法 |
|---|---|---|---|---|
| 丝娃娃 | 薄面皮包入多种切丝蔬菜、豆制品和腌菜，再浇蘸水，口感清脆酸辣。 | 可按份或按盘点，独行较友好。 | 面皮含小麦；蘸水可能含花生、芝麻、酱油或动物性汤料，素食和过敏需求需确认。 | 传统中心、花溪和居民商业区均可找；长队时换同类店，重点看配菜新鲜与蘸水说明。 |
| 肠旺面 | 鸡蛋面配猪大肠、血旺、脆哨、红油和汤底，是贵阳代表性早餐或正餐。 | 一碗即一餐，适合独行。 | 含猪肉、动物血、蛋和小麦，不适合素食或清真需求；辣油和汤底较重。 | 喷水池、民生路、老社区和市场周边常见；不吃内脏可换牛肉粉或素粉，但汤底仍需确认。 |
| 花溪牛肉粉 | 米粉配牛肉和牛骨汤，可加酸菜、辣椒、香菜等。 | 一碗一餐，份量容易控制。 | 牛肉和动物汤；调味酱可能含小麦或豆制品，共锅也影响严格无麸质需求。 | 花溪最有地域联系，市区也普遍；按汤味和肉质选成熟粉店，不必专程追一家。 |
| 酸汤鱼或酸汤牛肉 | 发酵酸汤配鱼或牛肉，常以火锅形式共享，蘸水决定额外辣度。 | 更适合 2 人以上；独行先问小锅或单人锅。 | 鱼刺、牛肉、发酵配料与动物汤；蘸水可能含坚果、芝麻、酱油和折耳根。 | 正餐区和商场较易找到；人数少可选酸汤粉，严重过敏者需确认底料和共锅。 |
| 豆米火锅 | 豆类煮成浓稠汤底，常搭配软哨、肉类、蔬菜和蘸水。 | 通常适合分享，也有小锅。 | 名称看似植物性，但常见版本含猪肉、动物油或高汤；豆类、花生和辣椒需注意。 | 居民区和成熟黔菜馆较常见；素食应明确要求独立无动物汤底，而不是只去掉肉块。 |
| 豆腐圆子与恋爱豆腐果 | 前者多为炸豆腐丸配蘸水，后者常将烤豆腐剖开加入辣椒、折耳根等馅料。 | 小份适合独行和加餐。 | 豆制品；蘸料可能含花生、芝麻、酱油或动物油，炸锅可能共用。 | 小吃街、市场和社区店均可找；排队过长可改选洋芋粑或米豆腐，并重新核对蘸料。 |
| 贵阳辣子鸡 | 鸡块与糍粑辣椒等炒制或煨制，辣香浓厚。 | 多为合餐菜；独行应先问份量。 | 禽肉，可能含花生、芝麻、酱油和较多油；不能只说“微辣”就假设辣度低。 | 黔菜馆和家常餐馆较常见；不耐辣可换清汤菜或把蘸水分开。 |
| 青岩卤猪脚 | 青岩代表性卤味，常切块配辣椒蘸水。 | 常见共享份量，也可按重量或小份购买。 | 猪肉；老卤可能含多种香料、酱油和酒类，需询问过敏原。 | 青岩镇内选择多；比较明码标价和份量，避开把单店故事当作唯一标准。 |
| 糕粑稀饭与玫瑰冰粉 | 糕粑稀饭常以藕粉糊、糯米糕和玫瑰糖组成；冰粉可加花生、芝麻、果干等。 | 小碗适合加餐或分享。 | 常见花生、芝麻、坚果和高糖配料；糯食吞咽与血糖需求需留意。 | 青岩及市区甜品店可找；可要求减少配料，但严重过敏仍需确认工具和容器交叉接触。 |

### 餐饮区域

| 区域 | 餐饮特点 | 主要取舍 |
|---|---|---|
| 民生路—正新街—喷水池 | 小吃、粉面、老店类型和商业餐饮密集，适合传统中心路线。 | 高峰排队和道路拥挤明显；店铺更替快，优先同类替代。 |
| 甲秀楼—青云市集—南明河 | 晚餐、夜间小吃和较新的餐饮空间多，可接甲秀楼夜间散步。 | 市集活动、亮灯和营业时间变化快，嘈杂与排队不适合所有人。 |
| 花溪中心 | 牛肉粉、黔味正餐和居民日常餐饮较集中，适合湿地或青岩转场。 | 与传统中心有距离，不要为一餐来回跨城。 |
| 青岩古镇 | 卤猪脚、糕粑稀饭、米豆腐和玫瑰甜品集中。 | 游客区价格、份量和排队差异大；先看菜单，保存返程时间。 |
| 观山湖 | 商场、连锁与多人餐厅较齐全，博物馆日容易安排饮食限制和正式休息。 | 地方街巷感较弱，与老城夜市不在同一片区。 |
| 成熟居民区和菜市场周边 | 粉面、豆米火锅、烙锅与家常菜更日常。 | 英文菜单、过敏原和无障碍信息可能不完整，需要直接沟通。 |

“不放辣椒”应同时问清汤底、红油、糍粑辣椒和蘸水；“不要折耳根”也应分别说明主食、配菜与蘸水。严格素食、清真、无麸质或严重过敏需求，不能只凭菜名判断。

## 经典行程

路线按半日或一日块组合，不写成分钟级课表。每条路线都保留一个预约锚点，并明确可以提前结束的位置。

### 一日经典路线

- 顺序：黔灵山公园选定线路 → 乘车到喷水池或民生路午餐 → 文昌阁 → 传统中心街巷 → 甲秀楼建筑群 → 南明河短段或筑城广场结束。
- 串联逻辑：上午利用较适合登山的时段完成城市森林，下午从老城东部向南明河单向步行；黔灵山与传统中心之间乘车，不把它们误当一条连续山路。
- 预约锚点：以黔灵山公园当日预约和入园时段为锚点，同时确认甲秀楼、文昌阁建筑内部是否开放。
- 休息区域：民生路或喷水池完成正式午餐；文昌阁到甲秀楼之间可在商场、咖啡馆或筑城广场周边补充室内休息。
- 时间不足：先删黔灵山登高和动物园支线，只保留低处公园段；下午再删文昌阁内部参观，保留甲秀楼与南明河。不要在闭馆前跨城追场馆。

黔灵山若遇雷雨、暴雨、结冰或超大客流，应直接改为贵州省民族博物馆或其他室内场馆，不以“只爬一小段”规避管控。

### 两日城市路线

- 第一天：采用一日经典路线，建立黔灵山、传统中心与南明河三层城市关系。
- 第二天：中心城区出发 → 青岩古镇主入口 → 城门与主街 → 背街和代表性建筑选段 → 镇内午餐 → 下午继续短线或提前返城。
- 串联逻辑：青岩交通和石路步行足以占用大半天，单独成日能避开与黔灵山、天河潭互相挤压。
- 预约锚点：以青岩古镇票务、内部景点和返程交通为锚点；节庆演出不是固定可见内容。
- 休息区域：古镇主街和游客服务区容易找到餐饮与座位，进入背街或城墙前先完成补水和卫生间安排。
- 时间不足：先删城墙完整段和最远支巷，再删非重点收费小景点；保留主街、背街一段和一处历史建筑。返程时间优先于夜间活动。

### 三日深度路线

- 第一天：黔灵山公园 → 传统中心 → 甲秀楼与南明河。
- 第二天：青岩古镇独立半日至一日。
- 第三天：贵州省博物馆 → 观山湖区午餐 → 观山湖公园选一段 → 观山湖商业区或住宿地结束。
- 串联逻辑：第三天集中在观山湖，避免博物馆参观后再穿城去花溪；场馆提供贵州自然、历史和文化的总览，公园补充现代城市尺度。
- 预约锚点：第三天以贵州省博物馆实名预约为锚点，公园只作弹性部分；三天分别核对公园、古镇和博物馆规则。
- 休息区域：贵州省博物馆公共服务区和观山湖商业设施；公园只走靠近明确出口的一段，不依赖临时摊点。
- 时间不足：第三天先删观山湖公园，保留博物馆；整个行程需缩为两天时，按“青岩历史城镇”与“省域博物馆”兴趣二选一。

### 雨天路线

- 顺序：贵州省博物馆 → 观山湖室内午餐 → 乘轨道交通或车辆前往贵州省民族博物馆 → 结束后就近返住处。
- 串联逻辑：两馆分别提供省域总览和民族文化专题，虽然不相邻，但转场明确且大部分时间在室内，能避开山路、石街和河岸。
- 预约锚点：以贵州省博物馆时段为硬锚点，出发前确认贵州省民族博物馆当日展览与入馆规则。
- 休息区域：观山湖商业设施和两馆公共服务区；跨城前先完成午餐，避免在雨中寻找街边店。
- 时间不足：先取消第二馆，完整参观贵州省博物馆；若暴雨、积水或交通管制升级，则取消跨城移动并按官方指引避险。

普通降雨和气象预警不是一回事。暴雨、雷电、大雾、凝冻或地质灾害风险期间，博物馆也可能临时调整，室内路线不能被当作必然开放的避险方案。

### 亲子或低体力路线

- 顺序：贵州省博物馆重点展厅 → 午休 → 乘车到甲秀楼附近 → 仅走平缓河岸短段 → 筑城广场或住宿地结束。
- 串联逻辑：上午在室内控制温度和体力，下午只保留一段城市地标；跨片区乘车，避免黔灵山登高与青岩石阶。
- 预约锚点：贵州省博物馆预约；同时向甲秀楼管理方确认轮椅、婴儿车、桥面和建筑入口通行情况。
- 休息区域：博物馆服务区、观山湖商业设施和筑城广场周边；河岸不适合作为唯一休息点。
- 时间不足：先删河岸延伸，只在安全可达位置看甲秀楼；儿童疲劳或天气变差时，博物馆后直接结束。

博物馆有电梯或服务并不自动形成从车站、下客点到展厅的连续无障碍路线。入口坡度、安检、卫生间、轮椅借用和车辆停靠均需向官方确认。

### 花溪与青岩路线

- 顺序：中心城区 → 花溪国家城市湿地公园选一个入口和 1 段河岸 → 花溪午餐 → 青岩古镇主街与背街选段 → 返回市区。
- 串联逻辑：两地同在南向，但不是连续步行区；湿地只短走一段，把主要体力留给青岩石街。
- 预约锚点：以青岩票务和返程为锚点，湿地活动、骑行租赁与局部管控另行确认。
- 休息区域：花溪中心完成午餐和正式休息，青岩游客服务区补给；不在湿地长线中途才临时找车。
- 时间不足：先删湿地，把青岩作为单点；若更重自然，可保留湿地和花溪公园，取消青岩而不是两边各停一小时。

### 天河潭远郊路线

- 顺序：中心城区出发 → 天河潭游客服务区 → 按当日开放选择瀑布、峡谷或洞穴主线 → 正式休息 → 留出充足时间返城。
- 串联逻辑：洞穴、船行、步道和接驳本身已经构成完整一日，不再叠加青岩或黔灵山。
- 预约锚点：以景区票种、洞穴与水上项目开放、入园时段和返程交通为锚点；不同票种覆盖范围不能凭旧攻略推断。
- 休息区域：游客服务区和官方开放的餐饮休息点，自备水与防滑装备，洞内外注意温差。
- 时间不足：先删附加体验和商业区，再按官方建议保留一条核心自然线；暴雨、水位异常或项目停运时整条取消，不转入未开发洞穴或野外瀑布。

黄果树、荔波、西江千户苗寨或遵义若从贵阳继续前往，应另外增加至少一个完整旅行日，并按所在地官方规则规划。当天从贵阳往返不改变其跨市州属性。

## 住宿区域

| 区域 | 优点 | 缺点 | 适合人群 | 交通特点 |
|---|---|---|---|---|
| 喷水池—大十字—民生路 | 餐饮、商业和传统中心步行便利，初访容易建立方向感。 | 人流、车流和夜间噪声较大，车辆到门与老楼电梯条件差异明显。 | 首访、短住、重视小吃和晚间活动者。 | 轨道交通与公交选择多，步行可接文昌阁，前往甲秀楼仍需看坡度和过街。 |
| 甲秀楼—筑城广场—河滨公园 | 接近南明河、贵州省民族博物馆和贵阳站方向，夜间散步方便。 | 河岸房间可能受道路、活动和照明影响；暴雨时低洼路段需留意。 | 喜欢城市地标、河岸、铁路到达和较低登山需求者。 | 可步行选段，跨到黔灵山或观山湖用公共交通。 |
| 北京路—黔灵山周边 | 接近黔灵山入口、医院和成熟生活区，早餐选择多。 | 山地和主路造成绕行，节假日公园客流大。 | 计划早游黔灵山、偏好居民区者。 | 公共交通进入传统中心方便，携行李需确认住宿上下坡。 |
| 观山湖—会展城—省博物馆周边 | 现代酒店、商场和省级场馆集中，房间与道路设施通常较新。 | 离传统中心和青岩较远，晚间街巷感较弱。 | 博物馆、亲子、商务、需要大型商业和较新设施者。 | 轨道交通连接北站和传统中心，具体步行距离仍需核对。 |
| 贵阳北站 | 高铁早出晚归和跨城中转方便，住宿供应量大。 | 站区尺度大，与省博物馆、甲秀楼都不是门口关系。 | 早班高铁、只住一晚、继续前往省内其他城市者。 | 轨道交通换乘便利；铁路与地铁安检动线需预留时间。 |
| 贵阳站—遵义路 | 接近传统中心南部和铁路，餐饮、公交较密集。 | 站前交通复杂，部分住宿隔音和房龄差异大。 | 普速或本站车次、预算有限、需要快速到老城者。 | 与贵阳北、贵阳东站不同，订票后再决定是否住此处。 |
| 花溪中心 | 湿地、公园、大学区和南向交通方便，环境较舒展。 | 前往传统中心和观山湖通勤较长。 | 计划花溪、青岩、天河潭，或停留较长者。 | 轨道交通加公交或车辆接景区，末班和最后一段需确认。 |
| 青岩古镇周边 | 清晨和夜间可避开部分日间客流，适合慢游古镇。 | 石路、车辆到门、隔音、电梯和餐饮营业差异大；返城不便。 | 以青岩为主、愿意减少市区夜生活者。 | 依赖景区接驳、公交或车辆，预订前确认下客点和行李搬运。 |

选择住宿时应先核对实际到发站，再比较坡度、电梯、车辆能否到门和夜间公共交通。地图上的几百米可能包含长坡、地下通道、天桥或绕行；轮椅、婴儿车和大件行李不能只看直线距离。

## 市内交通

### 到达与离开

| 枢纽 | 相对位置与用途 | 旅行判断 |
|---|---|---|
| 贵阳龙洞堡国际机场 | 城市东部的航空综合交通节点，可换乘轨道交通、机场巴士、公交、出租车或网约车。 | 航站楼、航班、夜间接驳和铁路衔接会变化，按实际航班重新核对。 |
| 贵阳北站 | 城市北部偏西的重要高铁站，与轨道交通和公交枢纽相接。 | 适合跨省和省内高铁中转；不是观山湖全部景点或传统中心的步行起点。 |
| 贵阳站 | 传统中心南侧的铁路站，靠近河滨公园和遵义路方向。 | 对中心住宿较方便，但并非所有高铁都在此到发。 |
| 贵阳东站 | 城市东北方向的铁路站。 | 与机场、贵阳北站和传统中心均为不同节点，需预留接驳时间。 |
| 金阳客车站等公路客运节点 | 服务省内外公路客运和部分景区方向。 | 线路、发车站和班次变化频繁，不能按旧游记中的“汽车站”泛称前往。 |

贵阳北、贵阳东和贵阳站不是同一车站的不同入口。铁路票面、住宿和叫车必须使用完整站名；具体车次以中国铁路 12306 为准。

### 城区移动

- 轨道交通：适合连接机场、铁路枢纽、观山湖、传统中心和花溪方向。线路、首末班、出入口、票务和施工属于动态信息，出发前查看官方线网图。
- 公交与快速公交：能补足山地城市的最后一段，部分夜间或旅游线路按季节、周末和客流调整。不要把临时专线当作全年固定班次。
- 步行：文昌阁、民生路、甲秀楼和筑城广场可分段串联，但坡道、大路口、地下通道与高架会使导航距离失真。雨天石阶和河岸更滑。
- 出租车与网约车：适合低体力分段、场馆转场和携行李；传统中心拥堵、景区门口管制和上下客点变化需要留缓冲。
- 自行车与电动自行车：花溪湿地等局部绿道可骑行，中心城区的坡度、隧道、立交和车流不适合把骑行作为唯一方式。租赁、停放和禁行区需现场确认。
- 自驾：中心城区不必依赖自驾，停车和拥堵可能抵消便利；前往青岩、天河潭或更远市域景区时更灵活，但要核对山路、停车和恶劣天气管制。

贵阳地铁公开提供面向行动不便乘客的预约协助渠道，但具体预约提前量、接送范围、电梯故障和站外衔接均会变化。需要连续无障碍出行时，应向运营方确认起点站、换乘站、终点站与景区入口的完整链条。

### 跨市州继续旅行

- 黄果树：位于安顺市范围。可从贵阳乘铁路或公路交通继续，但景区预约、交通和体力按安顺行程计算。
- 荔波大小七孔：位于黔南州荔波县。高铁、航班或公路接驳之后仍有景区内部交通，通常不适合作为贵阳市区附带点。
- 西江千户苗寨：位于黔东南州雷山县。往返凯里或雷山的交通、住宿和村寨参观礼仪需独立安排。
- 遵义：是独立地级市，高铁可组合，但城市遗址和赤水等远端目的地应分别留日。

## 不同旅行者须知

| 旅行维度 | 实用建议 |
|---|---|
| 独行旅行 | 粉面、小吃和公共交通便于单人安排。夜间从青岩、天河潭或跨市景区返程前先锁定班次；不进入陌生山路、未开发洞穴或偏僻河谷。 |
| 亲子旅行 | 贵州省博物馆适合作为室内锚点，花溪湿地只选短段。黔灵山不得用食物吸引猕猴，儿童与猴群、水边、石阶和洞穴之间保持安全距离。 |
| 长者或低体力旅行 | 传统中心拆成文昌阁段和甲秀楼段，段间乘车；黔灵山只选低处，青岩不走完整城墙。一天只安排一个山地或远郊项目。 |
| 无障碍需求 | 轨道交通可申请协助，但站外坡道、老城过街、甲秀楼桥面、黔灵山山路、青岩石街、湿地入口和洞穴项目能否连续无障碍，均需向官方确认。 |
| 摄影旅行 | 清晨可选择南明河或青岩主街，傍晚适合城市河岸。拍摄居民、摊主、手工艺人、宗教活动或节庆仪式前先征得同意，不为取景阻挡街巷和祭祀空间。 |
| 预算有限 | 传统中心或贵阳站周边住宿、公共交通、粉面和城市公园能控制成本。跨市一日团、远郊包车、热门季房价和多人火锅是常见增量。 |
| 晚出发或紧凑行程 | 下午只选“文昌阁—民生路—甲秀楼”或“贵州省博物馆—观山湖”之一，不横跨花溪。未确认返程时不临时去青岩或天河潭。 |
| 雨季与强对流 | 普通小雨可场馆优先；暴雨、雷电、山洪或地质灾害预警时取消黔灵山、花溪水边、青岩城墙、天河潭和跨市山地景区。 |
| 冬季与凝冻 | 湿冷体感可能明显，桥面、石阶、山路和高速公路可能结冰。穿防滑鞋并给机场、铁路和远郊交通留更大缓冲。 |
| 多民族文化参观 | 使用场馆和社区提供的具体名称，不把不同民族或支系混称为一种“少数民族风情”。服饰、歌舞、节庆和手工艺是现实生活与传承的一部分，人物拍摄、私人院落和宗教空间以同意和现场规则为先。 |
