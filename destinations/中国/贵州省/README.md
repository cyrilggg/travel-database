# 贵州省旅行目的地

贵州以喀斯特山地、河谷、瀑布、洞穴、历史城镇和多民族共同生活形成的文化景观见长。省内交通通常以贵阳为换乘中心，但“从贵阳出发”不等于“属于贵阳”：黄果树位于安顺，荔波位于黔南州，西江千户苗寨位于黔东南州雷山县，遵义也是独立地级市。跨市州行程应分别计算交通、住宿、预约和天气风险，不能作为贵阳城市景点合并处理。

## 区域格局与行程组合

- 贵阳传统中心：喷水池、民生路、文昌阁、甲秀楼、南明河和筑城广场分布在云岩、南明两区的山间盆地与河谷中。部分街段可步行串联，但坡度、立交和大路口会放大实际距离。
- 黔灵山与观山湖：黔灵山在传统中心西北侧，需按独立半日山地公园处理；观山湖是更靠西北的新城区，聚集贵州省博物馆、城市公园和贵阳北站等节点，不能从老城连续步行抵达。
- 花溪与贵安方向：花溪国家城市湿地公园、青岩古镇和天河潭位于中心城区南侧或西南侧。三者不是一个大景区；十里河滩、花溪公园和平桥属于花溪国家城市湿地公园内部游览段，不应重复计数。
- 安顺方向：黄果树、龙宫和安顺屯堡文化均属于安顺市范围。即使从贵阳参加一日往返，也应作为跨市旅行，不计入贵阳完成率。
- 黔南方向：荔波大小七孔位于黔南布依族苗族自治州荔波县，交通和游览本身通常需要独立安排，不能写成贵阳远郊。
- 黔东南方向：西江千户苗寨位于黔东南苗族侗族自治州雷山县。村寨是居民生活空间和文化传承地，不是把族群简化为服饰、歌舞或拍照背景的主题园区。
- 黔北方向：遵义市及其历史遗址、赤水等目的地有独立的城市和景区体系，需另建页面研究。
- 多民族文化：贵州不同民族、地区、支系和社区拥有各自的语言、服饰、技艺、信仰与当代生活。省级博物馆、非遗工坊、节庆和村寨访问应说明具体地域与语境，征得同意后再拍摄人物、仪式或私人空间，避免用单一符号代表整个贵州。
