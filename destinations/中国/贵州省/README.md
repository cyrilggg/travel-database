# 贵州省旅行目的地

贵州以喀斯特山地、河谷、瀑布、洞穴、历史城镇和多民族共同生活形成的文化景观见长。省内交通通常以贵阳为换乘中心，但“从贵阳出发”不等于“属于贵阳”：黄果树位于安顺，荔波位于黔南州，西江千户苗寨位于黔东南州雷山县，遵义也是独立地级市。跨市州行程应分别计算交通、住宿、预约和天气风险，不能作为贵阳城市景点合并处理。

当前目录提供 5 篇完整城市指南：贵阳、遵义、六盘水、毕节与安顺。各页分别说明中心城区、外围县域和大型景区之间的关系；例如毕节以七星关主城作为交通和住宿基地，百里杜鹃、织金洞、威宁草海与赫章高原分属不同县域方向，安顺则把西秀主城、屯堡村镇、黄果树和龙宫拆成独立游览单元。

## 区域格局与行程组合

- 贵阳传统中心：喷水池、民生路、文昌阁、甲秀楼、南明河和筑城广场分布在云岩、南明两区的山间盆地与河谷中。部分街段可步行串联，但坡度、立交和大路口会放大实际距离。
- 黔灵山与观山湖：黔灵山在传统中心西北侧，需按独立半日山地公园处理；观山湖是更靠西北的新城区，聚集贵州省博物馆、城市公园和贵阳北站等节点，不能从老城连续步行抵达。
- 花溪与贵安方向：花溪国家城市湿地公园、青岩古镇和天河潭位于中心城区南侧或西南侧。三者不是一个大景区；十里河滩、花溪公园和平桥属于花溪国家城市湿地公园内部游览段，不应重复计数。
- 安顺主城与屯堡：[安顺](./安顺市.md)的传统中心位于西秀区，古城、文庙、王若飞故居和地方小吃可组成主城短线。平坝是主城以东的另一座城区；天龙屯堡在平坝方向，云峰屯堡、鲍家屯和旧州古镇分散在西秀乡间，各有独立社区、保护和运营边界，不能视为一条连续步行街。
- 黄果树与龙宫：黄果树旅游区管委会受西秀区、镇宁自治县和关岭自治县委托管理龙宫镇、黄果树镇和白水镇，是管理机构而非法定县级行政区。黄果树景区的大瀑布、陡坡塘和天星桥合计一个大型景区；龙宫位于法定西秀区范围并纳入该管理体系，但仍是另一座需要独立半日至一天的景区。
- 安顺喀斯特与社区参观：瀑布、地下河、洞穴和峡谷受上游来水、强降雨、雷电、湿滑、落石与地质灾害共同影响，景区停航或分区关闭后不得寻找野洞、河道或非开放入口替代。屯堡、布依族和苗族社区不是表演布景；拍摄人物、住宅和仪式前应征得同意，不用一种服饰或活动概括整个地区。
- 黔南方向：荔波大小七孔位于黔南布依族苗族自治州荔波县，交通和游览本身通常需要独立安排，不能写成贵阳远郊。
- 黔东南方向：西江千户苗寨位于黔东南苗族侗族自治州雷山县。村寨是居民生活空间和文化传承地，不是把族群简化为服饰、歌舞或拍照背景的主题园区。
- 黔北方向：[遵义](./遵义市.md)不是单一紧凑城区。红花岗老城与汇川场馆可组成 2–3 天城市线；海龙屯和娄山关景区都在汇川区的不同山地方向，后者位于板桥镇、邻近桐梓但不属于桐梓县；乌江寨在播州，茅台镇在仁怀，土城在习水，赤水丹霞在赤水市，均应按独立半日至多日安排。新蒲新区是功能区，不是法定县级行政区；新舟机场、茅台机场、遵义站和乌江寨站也不是同一到达节点。
- 贵州西部六盘水：[六盘水](./六盘水市.md)以钟山主城为主要落脚点，梅花山、水城区野玉海、六枝河谷与盘州高原分处不同方向。盘州市是代码独立的县级市，应按独立目的地安排；乌蒙大草原和妥乐古银杏也是两个不同景区。高海拔、雨雾、冬季凝冻、工业生产道路和矿区边界都需单独核对。
- 贵州西北毕节：[毕节](./毕节市.md)没有一条连续串联主要景区的城市旅游轴线。七星关主城、大方与百里杜鹃、织金、威宁和赫章分属不同方向，每天通常只选一个县域或大型景区。百里杜鹃管理区是功能管理区，不是新增法定县级行政区；黔西市是代码独立的县级市，应单独安排交通、住宿和游览范围。洞穴、湿地、天然花海与高原草场还要分别遵守容量、自然保护、生产和天气边界。
- 多民族文化：贵州不同民族、地区、支系和社区拥有各自的语言、服饰、技艺、信仰与当代生活。省级博物馆、非遗工坊、节庆和村寨访问应说明具体地域与语境，征得同意后再拍摄人物、仪式或私人空间，避免用单一符号代表整个贵州。
