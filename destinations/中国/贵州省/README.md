# 贵州省旅行目的地

贵州以喀斯特山地、河谷、瀑布、洞穴、历史城镇和多民族共同生活形成的文化景观见长。省内交通通常以贵阳为换乘中心，但“从贵阳出发”不等于“属于贵阳”：黄果树位于安顺，荔波位于黔南州，西江千户苗寨位于黔东南州雷山县，遵义也是独立地级市。跨市州行程应分别计算交通、住宿、预约和天气风险，不能作为贵阳城市景点合并处理。

当前目录提供 13 篇完整城市指南：贵阳、遵义、仁怀、赤水、六盘水、毕节、黔西、安顺、铜仁、兴义、兴仁、凯里与都匀。仁怀以盐津主城和茅台镇为双核；赤水按丹霞、瀑布、竹林与河谷古镇分日；黔西以城区水西文脉和化屋—东风湖为两条主线。

## 区域格局与行程组合

- 黔东北铜仁：[铜仁](./铜仁市.md)以碧江主城和万山为城市基点，梵净山位于江口、印江、松桃交界方向，石阡温泉与古城是另一条远线。先选主城—万山或一个县域远线，再锁定交通、住宿和景区预约。
- 黔南州府与都匀边界：都匀是黔南布依族苗族自治州辖县级市和州人民政府驻地，法定代码为 `522701`，但黔南州代码 `522700` 与州内其他县市不因此并入都匀。荔波大小七孔在荔波县，平塘“中国天眼”在平塘县，独山、三都、福泉等也须按各自属地安排行程。2026 年匀东镇部分区划调整并设立杉木湖街道，现为 6 个街道、4 个镇和 1 个民族乡；旧政府概况页的“5 街道、4 镇、1 乡”数量已经滞后，县级市代码和州府边界则未改变。
- 都匀老城、东部新城与远线：剑江老城可分段连接石板街、百子桥、文峰园和三江堰；东方记忆及三线建设博物馆须核对开放楼栋；杉木湖、绿博园、秦汉影视城、中国茶文化博览园和都匀东站分散在东部，不是一条连续步行线。官方名录把茶博园、毛尖小镇和秦汉影视城归在“都匀茶文化影视小镇景区”总名下，但各子项目仍分别核对入口、票务和开放。斗篷山是风景名胜区和保护空间，螺蛳壳—坪阳首先是茶叶生产与居民生活空间，两条远线每天只选一条，片场、茶园、加工车间、未开放林地和水源地不能凭地图进入。
- 黔东南州府与凯里边界：凯里是黔东南苗族侗族自治州辖县级市和州人民政府驻地，法定代码为 `522601`，但州府职能不等于全州行政范围。雷山、镇远、黎平、麻江、黄平等都是独立县级政区；西江、镇远古城、肇兴等只能作为换城后的属地行程，不能列入凯里景点或住宿片区。
- 凯里城区、下司与山地方向：老城—大十字适合住宿、酸汤餐饮和城市生活，苗侗风情园—凯里南站位于南部交通走廊，下司古镇沿清水江展开；舟溪镇曼洞村的凯里青曼苗寨景区包含地名文化展示馆，该馆不是城区独立景点，需与云谷田园、三棵树—巴拉河或香炉山等远线分别取舍。每天宜只选一个远线，村寨、农田、河谷、工业园和未开放林地不能凭地图随意进入。
- 黔西南州府与兴义边界：兴义是黔西南布依族苗族自治州代管的县级市和州人民政府驻地，法定代码为 `522301`。[兴仁市](./兴仁市.md)、安龙县、贞丰县、晴隆县等均是独立县级政区；前往兴仁时按独立页选择城区、草原或乡村路线。
- 兴义三个自然方向：万峰林在城市南侧方向，马岭河峡谷在桔山方向，万峰湖兴义一侧公共游览入口以红椿码头及当日运营公告为准。三者各有入口、票务、内部交通和天气边界，不能压成一条连续步行线或一张通票；UNESCO 兴义世界地质公园覆盖多类地质遗产与社区，也不是单门票景区。
- 贵阳传统中心：喷水池、民生路、文昌阁、甲秀楼、南明河和筑城广场分布在云岩、南明两区的山间盆地与河谷中。部分街段可步行串联，但坡度、立交和大路口会放大实际距离。
- 黔灵山与观山湖：黔灵山在传统中心西北侧，需按独立半日山地公园处理；观山湖是更靠西北的新城区，聚集贵州省博物馆、城市公园和贵阳北站等节点，不能从老城连续步行抵达。
- 花溪与贵安方向：花溪国家城市湿地公园、青岩古镇和天河潭位于中心城区南侧或西南侧。三者不是一个大景区；十里河滩、花溪公园和平桥属于花溪国家城市湿地公园内部游览段，无需分别另排一站。
- 安顺主城与屯堡：安顺的传统中心位于西秀区，古城、文庙、王若飞故居和地方小吃可组成主城短线。平坝是主城以东的另一座城区；天龙屯堡在平坝方向，云峰屯堡、鲍家屯和旧州古镇分散在西秀乡间，各有独立社区、保护和运营边界，不能视为一条连续步行街。
- 黄果树与龙宫：黄果树旅游区管委会受西秀区、镇宁自治县和关岭自治县委托管理龙宫镇、黄果树镇和白水镇，是管理机构而非法定县级行政区。黄果树景区的大瀑布、陡坡塘和天星桥合计一个大型景区；龙宫位于法定西秀区范围并纳入该管理体系，但仍是另一座需要独立半日至一天的景区。
- 安顺喀斯特与社区参观：瀑布、地下河、洞穴和峡谷受上游来水、强降雨、雷电、湿滑、落石与地质灾害共同影响，景区停航或分区关闭后不得寻找野洞、河道或非开放入口替代。屯堡、布依族和苗族社区不是表演布景；拍摄人物、住宅和仪式前应征得同意，不用一种服饰或活动概括整个地区。
- 黔南方向：荔波大小七孔位于黔南布依族苗族自治州荔波县，交通和游览本身通常需要独立安排，不能写成贵阳远郊。
- 黔东南方向：西江千户苗寨位于黔东南苗族侗族自治州雷山县。村寨是居民生活空间和文化传承地，不是把族群简化为服饰、歌舞或拍照背景的主题园区。
- 黔北方向：遵义不是单一紧凑城区。红花岗老城与汇川场馆可组成 2–3 天城市线；海龙屯和娄山关景区分处汇川区不同山地方向，播州也需另行接驳。仁怀市、赤水市是代码独立的县级市，应另查属地交通、住宿和游览信息；新蒲新区是功能区，不是法定县级行政区。
- 赤水丹霞与古镇：赤水城区适合作为多日住宿基点，大瀑布、佛光岩、燕子岩、四洞沟和竹海分散在不同山谷与入口；每天选择一处大型景区，再用丙安或大同古镇补充河谷文化。世界遗产地、自然保护地和森林公园以开放步道为活动范围，强降雨、山洪、地灾或火险期间按官方分区管控调整。
- 贵州西部六盘水：六盘水以钟山主城为主要落脚点，梅花山、水城区与六枝河谷分处不同方向。盘州市是代码独立的县级市，应另查属地交通、住宿和游览信息。高海拔、雨雾、冬季凝冻、工业生产道路和矿区边界都需单独核对。
- 贵州西北毕节：毕节没有一条连续串联主要景区的城市旅游轴线。七星关主城、大方与百里杜鹃、织金、威宁和赫章分属不同方向，每天通常只选一个县域或大型景区。百里杜鹃管理区是功能管理区，不是新增法定县级行政区；黔西市是代码独立的县级市，应单独安排交通、住宿和游览范围。洞穴、湿地、天然花海与高原草场还要分别遵守容量、自然保护、生产和天气边界。
- 黔西城区与乌江源：黔西城区可用水西文化、公共场馆和水西柯海湿地组成一日；化屋村与东风湖位于市域南部，山路、码头和正规游船共同构成独立一日。观音洞、素朴象祠等乡镇历史点按开放与接待另选一天，百里杜鹃管理区继续按独立管理边界处理。
- 多民族文化：贵州不同民族、地区、支系和社区拥有各自的语言、服饰、技艺、信仰与当代生活。省级博物馆、非遗工坊、节庆和村寨访问应说明具体地域与语境，征得同意后再拍摄人物、仪式或私人空间，避免用单一符号代表整个贵州。
