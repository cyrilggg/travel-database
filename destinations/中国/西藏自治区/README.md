# 西藏自治区旅行目的地

西藏自治区的旅行尺度不能只按地图距离判断：海拔变化、天气、道路状况和证件要求都可能改变同一段行程的实际难度。拉萨集中了自治区级交通枢纽和重要文化遗产，但日喀则、山南、林芝、那曲、昌都与阿里各有独立的城市和区域结构，不应都作为“从拉萨顺路往返”的景点处理。

## 区域格局与城市组合

拉萨位于自治区中部，是航空、铁路和公路换乘的重要节点。市区核心景点相对集中，但拉萨市行政范围还延伸到当雄、尼木、林周、曲水、墨竹工卡等地；纳木错方向与甘丹寺等远点都需要独立核算海拔、路况和往返时间。

日喀则、山南、林芝、那曲、昌都与阿里不是拉萨城区的延伸。羊卓雍错位于山南方向，不计入拉萨城市景点；纳木错跨拉萨当雄与那曲班戈方向，进入哪个景区、使用哪条道路和是否允许自驾应按当期公告确认。跨地区组合时，应先按适应海拔的节奏确定过夜地，再安排交通和景点，而不是把多个高海拔远点连续塞进同一天。

山南指南以乃东区泽当为主城基地，把昌珠与雍布拉康作为近郊，把琼结、桑耶和羊卓雍错分别作为跨县远点。错那市是山南市代管的县级市，不是泽当近郊；其景点、住宿、边境证件和道路条件应另行核对，不能用一条山南主城路线代替。

林芝指南以巴宜区主城为住宿、补给和换乘基地，把鲁朗作为山地专日，把工布江达的巴松措、波密的森林冰川以及墨脱、察隅分别作为逐级增加时间、道路和证件门槛的远线。米林市已是林芝市代管的独立县级市；林芝米林机场和铁路可以作为抵离节点，但米林市的景点、住宿与完整路线不预写进巴宜指南。

## 行前核对

- 自治区文旅公告、景区票务与临时关闭：[西藏自治区文化和旅游厅](https://wlt.xizang.gov.cn/)
- 政府公告、道路和公共服务信息：[西藏自治区人民政府](https://www.xizang.gov.cn/)
- 暴雪、强对流、大风和高原天气预警：[西藏自治区气象局](http://xz.cma.gov.cn/)
- 铁路车次、到发站和实名购票规则：[中国铁路 12306](https://www.12306.cn/)
- 民航运行与监管公告：[中国民用航空西南地区管理局](https://xn.caac.gov.cn/)；具体航班、航站楼和机场接驳另查航空公司与机场官方渠道
- 来华签证、入境和不同证件持有人的出入境规则：[国家移民管理局](https://www.nia.gov.cn/)
- 按国籍、居住身份、证件类型与具体线路另行确认在特定地区旅行所需的许可、接待单位或旅行社要求；来华签证或免签资格不能自动回答全部地区旅行资格问题。
