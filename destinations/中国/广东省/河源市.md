# 河源旅行指南

河源位于东江中上游，是一座需要按“湖城、古邑与远县”理解的粤东北山水城市。源城区以两江沿岸、恐龙化石和客家老城为主，东源县的万绿湖需要围绕旅游码头与游船单独留日，龙川、和平、紫金和连平则各有古城、古村、红色遗址与山地目的地，不能压缩成市区近郊。首访以源城和万绿湖为骨架，便能看见河源最鲜明的水、城与客家文化关系。

> 建议停留：2–4 天<br>
> 旅行关键词：万绿湖、恐龙化石、客家古邑、东江、古村、湖鲜<br>
> 主要体力：市区中等步行；游船登离、古村与山地为中等至较高体力<br>
> 最近研究：2026-08-11

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 主要旅行价值 | 以万绿湖的湖泊生态、河源恐龙文博园的化石与地方史、两江沿岸的客家老城为核心，并可向东源古村、龙川佗城、和平林寨与紫金红色遗址延伸 |
| 建议停留 | 1 天可看源城核心；2 天增加万绿湖；3 天可加入东源古村或度假休息；4 天以上才适合选择一处远县过夜或山地线路 |

| 预算特点 | 市区公园、街区和公共文化空间可低成本游览；万绿湖门船组合、跨县包车或自驾、温泉与度假项目会显著提高预算 |
| 步行强度 | 源城街区为中等；文博园有馆舍与坡地，古村常见门槛和不平路面；万绿湖受登船、岛上游线和候船影响，山地景区为中高至高体力 |
| 主要天气风险 | 高温高湿、短时强降雨、雷电、城市积水、江河水位上涨、山洪、滑坡与落石、台风外围风雨，以及万绿湖水面强风和低能见度 |
| 独行旅行 | 源城用餐和叫车较方便；湖区、度假区与远县的一人交通成本较高，游船返程、县际客运和夜间用车应提前确认 |
| 亲子旅行 | 恐龙文博园、图书馆和万绿湖自然教育主题清楚；临水空间、游船、古村台阶、长距离公路与暑热需要缩短时长并持续看护儿童 |
| 长者与低体力旅行 | 可采用“一座场馆或一个短街区为半日”的节奏，以车辆连接源城、新城和湖区；不把登塔、长山径、多个岛点或跨县往返列为必做 |
| 无障碍信息 | 铁路可预约重点旅客服务；公共文化场馆、旧街、古村、游船登离、岛上步道和山地尚无可靠的全程连续资料，需逐一向车站、场馆和运营方确认 |

## 城市格局与游览区域

河源法定行政区划为源城区一个市辖区，以及东源、和平、龙川、紫金、连平五县；市政府所在地和主要连续建成区在源城。江东新区与河源国家高新区承担实际管理与产业、新城功能，但不是另设的法定县级市；河源也没有代管的法定县级市。订房、查车站或辨认景点时，应以完整区县、乡镇和地址为准，不能用“河源市区”概括整个地级市。

| 区域 | 主要内容 | 游览特点 | 与其他区域的关系 |
|---|---|---|---|
| 源城老城—两江交汇 | 河源恐龙文博园、太平古街、北直街、东江与新丰江沿岸 | 历史与城市生活最集中，可分段步行；馆舍、古塔外围、旧街和滨水空间的开放边界不同 | 最适合作为首日；不同江岸之间宜用公交或短途车减少回走 |
| 源城新市区—客家文化公园 | 客家文化公园、河源市图书馆、商业与公共服务 | 道路尺度比老城大，室内休息和日常餐饮较方便 | 与老城不是一条连续短步行线，适合乘车组合成“场馆加公园”半日 |
| 江东新区—河源东站 | 高铁门户、新城与东江东岸功能区 | 以到发、换乘和新城住宿为主，传统景点较少 | 到源城老城、万绿湖码头或远县都需继续接驳；站名不能替代住宿地址 |
| 源城南部—高埔岗 | 国家级和省级旅游度假区、温泉与亲子娱乐项目 | 多为独立经营的综合度假目的地，门票、住宿与温泉权益分开组合 | 不宜与源城老街连续步行；适合过夜或单列半天至一天 |
| 东源新港—万绿湖 | 万绿湖游客中心、旅游码头、游船与湖区游线 | 游船班次决定游览节奏，码头、岛点和环湖道路不是一条自由步行线路 | 通常从源城公路往返，至少留出大半天，旺季和恶劣天气需预留弹性 |
| 东源仙塘—义合—漳溪 | 南园古村、啸仙故里、苏家围、黄龙岩畲族风情 | 点位沿不同道路分散，古村、红色文化和溶洞各需独立参观时间 | 可选同方向的两处组合，不能在万绿湖游船日再横跨全部点位 |
| 龙川 | 佗城、霍山、老隆县城与龙川西站 | 历史古城和丹霞山地是两种不同节奏，末端都依赖道路接驳 | 从河源主城出发通常是完整一日或过夜段；佗城与霍山也不宜默认同日全走完 |
| 和平、紫金与连平 | 林寨古村、温泉度假、紫金苏区革命旧址群、九连山与古驿道方向 | 县域跨度大，公共交通频率、山区道路和住宿条件差异明显 | 每个县应按独立目的地安排行程；自然保护地、林场和生产区不因地图可达而开放 |

万绿湖是新丰江水库及其旅游品牌，湖面、国家级风景名胜区、旅游码头、游船线路、环湖公路与水源保护范围并不等同。游客可进入的范围以景区和属地当期公告为准；饮用水源保护、航道、岛屿和作业码头的管理边界高于观景便利，不能自行寻找野码头、下水点或非开放岸线。

## 主要景点

优先级用于安排时间，不代表绝对排名：**A** 为首访核心，**B** 为按兴趣补充，**C** 为远郊、季节性或通常需要独立半天以上的目的地。“路线节点”用于串联交通、餐饮或休息，不与正式景区等量比较；同一景区内的展馆、岛点、索道或游船停靠点只按一个整体安排行程。

## 美食与餐饮

河源饮食以东江流域客家菜为主，常见酿菜、盐焗、炖汤、猪肉与米粉，万绿湖和东江沿线又形成湖鲜、河鲜餐饮。源城老城、新市区和东源县城较容易找到日常粉面与客家家常菜；新港镇更集中于湖鲜，紫金八刀汤等县域菜则在当地更有代表性。寻找同类型社区店或县域正规餐馆，比把一家热门店当作唯一答案更可靠。

| 菜品或餐饮类型 | 常见区域 | 一个人用餐与常见份量 | 风味、过敏原与饮食限制 | 排队风险与替代方法 |
|---|---|---|---|---|
| 河源猪脚粉 | 源城及各县城早餐、粉面店 | 通常一人一碗，适合早餐或紧凑行程；可询问肉量与是否加卤蛋 | 汤卤常含猪肉、酱油和较高钠；大豆、小麦、花生或共锅接触需确认 | 早餐高峰翻台快，选择菜单和卫生信息清楚的社区粉店即可 |
| 客家酿豆腐与酿三宝 | 源城、东源及全市客家菜馆 | 可按例点，但多人共享更容易尝试多种酿菜 | 豆腐、苦瓜或辣椒内常酿猪肉、鱼蓉，并非素食；涉及大豆、鱼类、小麦和共油 | 家常菜馆替代度高；素食者需明确确认馅料、肉汤与烹调用油 |
| 东江盐焗鸡 | 源城及全市客家菜馆 | 常按半只或整只供应，一人宜询问小份、手撕做法或拼盘 | 咸香，油脂与钠含量较高；沙姜蘸料可能含大豆、花生或芝麻 | 正餐高峰热门，一般客家餐馆均有相近做法，不必跨县追单店 |
| 万绿湖鱼与新丰江鱼菜 | 东源新港、源城和正规湖鲜餐馆 | 多按重量或整鱼计价，独行者可选鱼片、鱼汤或小规格鱼并先问总价 | 鱼类过敏风险明确，汤底和酱汁可能含大豆、小麦；刺多的做法不适合低龄儿童 | 旺季湖区等位和价格波动较大，点单前确认品种、重量单位、加工费和预计总价 |
| 五指毛桃汤与客家炖汤 | 客家菜馆、县城正餐 | 多为共享汤盅，也有一人份；先问容量和是否需要预订 | 常配鸡、排骨或猪骨，不是素汤；药食同源材料、花生和其他配料需按过敏与用药情况确认 | 售罄时换当日例汤即可，不必追逐固定配方 |
| 艾粄与客家粄类 | 老城、市场周边、节庆与早餐店 | 多为单件或小份，适合分次尝试 | 可能使用糯米、艾草、花生、芝麻、豆沙或猪肉馅；共蒸、共油与保存时间需留意 | 节令性较强，找当天制作、明示馅料的正规门店替代 |
| 紫金八刀汤 | 紫金及源城部分客家早餐店 | 常按一碗供应，适合单人配米粉或米饭 | 以猪肉及部分内脏为主，口味清鲜但胆固醇、嘌呤与食品熟度需按自身情况取舍 | 在源城不必为单店排长队；若把紫金列入行程，再在县城寻找更自然 |

点湖鲜时应在下厨前确认品种、计价单位是每 500 克还是每份、称重是否含水、最低份量、加工费与预计总价，并保留点菜单或电子订单。野生动物、保护鱼类、来源不明的“野味”和未经许可的捕捞产品不应购买。严重食物过敏者需具体询问汤底、酱料、共锅、共油和砧板交叉接触，不能只凭菜名判断。

## 经典行程

### 一日经典路线

**路线**：河源恐龙文博园 → 源城老城午餐 → 太平古街—北直街短段 → 两江沿岸或客家文化公园二选一

- **串联逻辑**：上午用文博园建立恐龙化石、河源历史和客家文化的背景，下午转入仍有日常生活的老城；最后只选一个滨水或新城公园，避免在不同江岸反复折返。
- **预约锚点**：河源市博物馆、河源恐龙博物馆的当日票制与开放通告；龟峰塔不预设可以登塔。
- **休息安排**：老城正规餐馆、博物馆公共区或新市区商业空间；高温正午减少无阴影的滨江步行。
- **时间不足时**：先删最后的公园段，再把老城缩成太平古街附近短线；不压缩博物馆参观去追多个夜景点。

### 两日城市与万绿湖路线

**第 1 天（源城）**：河源恐龙文博园 → 老城午餐 → 太平古街—两江沿岸<br>
**第 2 天（东源新港）**：源城或新港住宿地 → 万绿湖旅游码头 → 一条当日运行的正规游船线 → 原路返回或新港住宿

- **串联逻辑**：城市文化和湖区游船各占一天，船班延误不会挤压文博园。万绿湖内部只按一条已售游线安排，镜花缘、龙凤岛、水月湾等以票面实际包含内容为准。
- **预约锚点**：第二天的船票、发船时段和返航安排；第一天以两座博物馆的当日通告为辅。
- **休息安排**：第一天在馆舍与老城餐馆休息；第二天使用游客中心、候船区、船舱与已开放岛点设施，自备饮水和防晒用品。
- **时间不足时**：万绿湖只保留一条短线或整日取消，不把游船压成半天再追加东源古村；风浪或雷电条件下服从停航与退改。

### 三日湖城与东源人文路线

**第 1 天（源城）**：恐龙文博园 → 太平古街 → 客家文化公园短段<br>
**第 2 天（万绿湖）**：旅游码头 → 正规游船线 → 新港镇用餐或休息<br>
**第 3 天（东源义合）**：啸仙故里文化旅游区 → 义合午餐 → 苏家围客家乡村旅游区

- **串联逻辑**：第三天把同属义合方向的红色文化与客家古村连接起来，与仙塘南园、漳溪黄龙岩分开；三天分别处理城市、湖泊和乡村，不在一天横跨三个方向。
- **预约锚点**：万绿湖船班；第三天同时确认两处景区开放、团队接待或临时活动，若其中一处关闭只保留另一处。
- **休息安排**：义合镇正规餐馆、景区游客服务点和车辆；古村座椅、遮雨与无障碍卫生间不预设处处具备。
- **时间不足时**：第三天删苏家围，只保留啸仙故里；若第二天船班较晚，直接返回住宿地，不把第三天景点前移。

### 雨天路线

**路线**：河源市博物馆与河源恐龙博物馆 → 室内午餐 → 河源市图书馆或市文化馆当期开放活动

- **串联逻辑**：两座博物馆同处河源恐龙文博园，可在同一园区内依开放情况顺序参观；午餐后再乘车前往新市区的图书馆或文化馆，避免雨中长距离步行。
- **适用条件**：普通降雨可用公共文化场馆替代长时间户外；暴雨、雷电、洪水、积水或地质灾害预警下减少移动并服从停课、闭馆、停航和道路管制。
- **预约锚点**：两座博物馆的票制、闭馆与临时检修信息，图书馆或文化馆的开放公告。
- **休息安排**：馆内公共区、正规餐馆和商业空间；不在江边低洼地、地下通道或山脚边坡等待雨停。
- **时间不足时**：只保留文博园内一至两座已确认开放的馆舍；不因雨势暂缓临时前往万绿湖、溶洞或山区。

### 亲子或低体力路线

**亲子路线**：河源恐龙文博园 → 室内午餐 → 河源市图书馆或客家文化公园短段<br>
**低体力路线**：河源市博物馆 → 乘车到太平古街附近短停 → 沿江室内餐饮或新市区休息

- **串联与减负**：亲子路线以恐龙科普和阅读空间为主，不追加长湖岸；低体力路线用车辆连接老城与新城，只走平缓、入口明确的短段。两条路线都不预设龟峰塔登塔、游船登离或古村门槛无障碍。
- **预约锚点**：场馆的儿童票、陪同、讲解和当日活动；轮椅、助行器使用者另行确认落客点、坡道、电梯和卫生间。
- **休息安排**：馆舍、图书馆、正规餐馆优先，公园座椅不替代高温或雷雨天气的室内休息。
- **时间不足时**：只保留恐龙文博园或市博物馆一个核心，删去跨片区移动。

### 龙川佗城一日路线

**路线**：河源主城或龙川西站 → 佗城景区 → 佗城或龙川县城午餐与休息 → 原路返回

- **适用条件**：适合对秦汉古邑、赵佗历史与客家建筑有明确兴趣，并能承担完整公路接驳的一天；若从源城当日往返，应提前锁定返程车次或车辆。
- **预约锚点**：佗城景区开放、讲解与票务，以及龙川西站至景区的往返接驳；远县日以返程时间为硬边界。
- **休息安排**：景区游客服务点、佗城镇或龙川县城正规餐馆；古建筑内部和居民院落只进入明确开放区域。
- **时间不足时**：删去县城零散停留，只保留佗城；不临时追加霍山，霍山应另留一个山地日。

## 住宿区域

| 区域 | 优点 | 缺点 | 适合人群 | 交通特点 |
|---|---|---|---|---|
| 源城老城—太平古街周边 | 接近老城、文博园、传统餐饮和两江沿岸，夜间仍有生活感 | 老物业、停车、噪声与无障碍条件差异大 | 首访、历史街区、短住与步行为主 | 到文博园和沿江点位较方便；去河源东站、万绿湖和度假区仍需乘车 |
| 源城新市区—客家文化公园周边 | 商业、餐饮、公共文化设施和房型选择较集中 | 历史氛围弱于老城，道路尺度大，步行跨路口较多 | 家庭、商务、雨天场馆与希望住宿条件稳定者 | 适合叫车连接老城、河源东站与湖区公路入口 |
| 河源东站—江东新区 | 方便高铁早晚到发，新建住宿和道路条件通常较整齐 | 不是传统旅行核心，晚间餐饮和景点密度取决于具体街区 | 过境、晚到早走、次日转远县 | 到源城老城和万绿湖都需继续接驳；订房看实际距离而非只看“高铁新城”标签 |
| 东源新港—万绿湖码头周边 | 便于早班游船、湖区晨昏和减少市区往返 | 旺季价格与供给波动，夜间餐饮、医疗和跨点交通少于源城 | 万绿湖为主要目的、摄影或愿意住一晚 | 核对住宿到游客中心的实际道路、停车和是否提供正规接送 |
| 源城高埔岗度假区 | 温泉、亲子设施和住宿可在同一经营空间内组合 | 与老城和万绿湖均不连续，套餐、池区和活动权益复杂 | 度假、亲子、低频移动或温泉休息 | 主要依赖道路接驳；预订时确认是否含门票、温泉、早餐和退改 |
| 龙川、和平、紫金或连平县城 | 可把远县景点拆成较轻松的两日段，县城餐饮和补给更稳妥 | 不适合作为源城与万绿湖的共同基地，县际往返时间长 | 古城、古村、红色历史或山地深度游 | 选择与目标景区同县的县城或镇区，重新核对铁路站、县际客运和末端用车 |

湖区、温泉和综合度假住宿的名称常带“万绿湖”“客天下”“巴伐利亚”等大地名，但名称不能说明它靠近游客中心，也不保证包含船票、温泉池区或景区权益。预订前应核对地图位置、经营主体、实际房型、施工噪声、儿童与长者规则、无障碍房型、停车、接送和天气退改。

## 市内交通

| 场景 | 建议与取舍 | 行前需要重查的内容 |
|---|---|---|
| 高铁抵达河源主城 | 河源东站是主城高铁门户，位于江东新区，需要公交、出租车或网约车继续前往源城；不要把“河源东”理解成老城步行站 | 12306 车票上的完整站名、列车时刻、进出站口、公交接驳、网约车上客点与停车场运行 |
| 普速铁路抵达 | 河源站位于源城，与河源东站不是同一站；若住宿在老城或新市区，普速车次有时能减少市区末端距离 | 当前是否有合适客运车次、到站时间、公交末班与无障碍协助 |
| 前往东源和远县 | 河源北、龙川西、和平北等高铁站服务不同县域，铁路只能解决部分跨县段；佗城、霍山、林寨、紫金苏区和万绿湖仍需道路接驳 | 实际停靠车次、车站到景区的距离、县际客运、返程末班、叫车范围与山区道路 |
| 航空衔接 | 河源支线运输机场仍在推进前期工作，不能作为当前民航到达点；航空旅客通常经广州、深圳或惠州机场再转铁路或公路 | 航班、跨城车票、机场到铁路站的换乘时间、行李规则与延误退改 |
| 源城片区移动 | 河源没有城市轨道交通；公交承担日常出行，出租车和网约车适合跨江、连接老城与新市区 | 公交线路、首末班、道路施工、活动管制、叫车上客点与老街步行边界 |
| 前往万绿湖 | 从源城或河源东站先走公路到东源新港旅游码头，再按票面乘正规游船；陆路到湖边不等于可以自由登岛或下水 | 游客中心地址、船班、套票所含岛点、停车、返航、强风雷雨停航和退改 |
| 前往古村与山地 | 东源古村、黄龙岩、霍山、林寨、紫金苏区及连平山地公共交通频率较低，多人同行时自驾或正规预约车更可控 | 道路落石与积水、景区停车、充电、夜间返程、司机资质和保险 |
| 自驾与水上交通 | 自驾能减少县域换乘，但雨季山区驾驶、节假日景区停车和夜间疲劳成本高；水上只使用持证旅游船、客班船或正式渡运 | 高速与国省道施工、景区车辆预约、停车费、船舶经营资质、救生设备、天气与停航 |

河源境内的河源东、河源北、龙川西、和平北等高铁站与河源、龙川、和平等普速站服务范围不同，旧规划名和现用站名也可能混在早期资料中。铁路票只通过[中国铁路 12306](https://www.12306.cn/)核对。机场项目仍在推进前期工作，任何把“河源机场”写成已运营定期客运机场的行程都需要重新验证。

万绿湖旅游船、交通船和渡船具有不同运营地点与用途。观光应从景区明确公布的游客中心或旅游码头购票登船，不接受陌生人以渔船、私人艇或非固定码头提供的载客服务。雷雨大风时湖面风力和浪高可能明显大于陆地，是否开航由海事、景区和船方的安全判断决定。

| 长者或低体力旅行 | 每半天只排一座场馆或一段短街区，以车辆连接老城、新城和码头 | 游船登离、完整岛线、古村门槛、霍山登山和跨县往返应主动删减 | 落客点、坡道、电梯、座椅、观光车、轮椅借用、船舶登乘协助与返程车辆 |

| 摄影旅行 | 两江晨昏、老城街巷、万绿湖水面与客家古村题材差异大 | 湖面反光、雾雨、高湿、器材负重和远县返程是主要成本；居民院落与纪念场所应克制拍摄 | 船上器材固定、三脚架、闪光灯、无人机、商业拍摄、水源保护区和场馆规定 |
| 预算有限 | 市区公共公园、老城街区、市博物馆与社区餐饮可构成低成本城市日 | 万绿湖船票、跨县用车、综合度假区和温泉抬高预算 | 公共场馆领票、景区优惠资格、接驳费、停车、套餐二次消费和住宿押金 |
| 晚出发或紧凑行程 | 只选“恐龙文博园”或“太平古街—两江短段”一组 | 半天不加入万绿湖、东源古村、度假区或远县 | 最晚入馆、闭馆日、返程末班、夜间叫车与沿江照明 |
| 高温、暴雨与台风时段 | 高温日把街区放在早晚，正午进入馆舍；普通降雨改为公共文化场馆 | 暴雨、雷电、山洪、滑坡、城市积水和水面强风可导致闭园、停航、封路及铁路调整 | 河源气象预警、属地应急响应、水库与江河水情、景区停运、道路管制和退改 |

水域安全是河源行程的刚性边界。只在明确开放、具有管理和救生条件的项目内参与水上活动，穿着合适的救生衣并服从船员指令；不从非开放岸线下水，不在水源保护范围垂钓、露营、生火或丢弃废物。出现雷电、强风、暴雨、能见度骤降或停航通知时，取消游船和亲水活动，不以“已经到码头”为由要求开船。

温泉并非对所有人都属于低体力活动。有心脑血管疾病、高血压等基础疾病者、孕妇和近期身体不适者应谨慎，必要时先咨询医生；酒后、空腹或过度疲劳时不入池。进入池区后逐步适应水温、控制时长并补水，出现头晕、胸闷、心悸或恶心应立即离池求助。
