# 广东省旅行目的地

广东从珠江三角洲延伸到粤东、粤西和粤北，海岸、山地与高密度城市群并存。省内城市间交通联系发达，但距离和旅行主题差异很大：珠江口城市不能视作同一片可连续步行的目的地，跨到潮汕、粤西海岸、粤北山地或云浮等中西部广域城市，通常也需要重新安排交通与停留天数。粤东的汕头、揭阳和潮州共享“潮汕”文化与交通名称，却仍是行政、住宿和景点覆盖分别计算的城市。

## 区域格局与城市组合

广州是珠江三角洲北部的交通枢纽，老城与珠江中轴构成主要旅行骨架；佛山位于广州以西，由禅城、南海、顺德、高明和三水构成，祖庙—石湾、西樵山、顺德中心城区和西北部远郊不能视作同一片连续城区。广佛线、佛山地铁 2 号线和广州地铁 7 号线等联系跨越市界，其中广州南站位于广州市番禺区，是进入佛山的交通入口而不是佛山景点。深圳位于珠江口东岸，福田、罗湖、南山、宝安与大鹏半岛之间跨度大，城市核心、跨境口岸和东部海岸不能视作同一片步行区域。东莞位于广州与深圳之间，但不设县级市辖区，由镇街组团构成多中心城市；莞城、南城、松山湖、虎门与长安既不在同一片连续城区，也不宜为了只住一处而反复横穿。中山位于珠江口西岸，同样不设县级区；石岐老城、南朗—翠亨、五桂山与小榄是相对独立的旅行组团，不能因同属一市而压缩成连续市区路线。珠海位于中山以南和珠江口西岸，香洲主城与情侣路、拱北口岸枢纽、横琴合作区、金湾、斗门和万山群岛不是一片连续城区；澳门隔着独立边界，东澳、外伶仃和桂山等岛屿也必须按不同目的港和船班组织。江门位于珠三角西南部，蓬江与江海构成主城生活圈，新会连接江门站、会城与更南部的人文湿地，开平碉楼、台山川岛、鹤山水乡和恩平侨乡则是各自成日的县域目的地；江门站位于新会区，不能按站名推断已到蓬江老城。惠州位于深圳、东莞以东，惠城西湖与东江老城、惠阳—大亚湾、仲恺、惠东海岸、博罗罗浮山和龙门山地是相距明显的旅行组团；巽寮湾、双月湾和大亚湾也不是同一片海滩。清远位于广州以北，清城—清新构成北江主城，佛冈温泉、英德峰林、连州洞穴、阳山高山以及连南、连山的文化与农耕山地则须按独立全日或住宿段安排。珠三角八城之间铁路、城际和道路联系密集，但广州南、广州东、佛山西、深圳北、福田、深圳、东莞、东莞东、东莞南、虎门、中山北、中山、南朗、小榄、珠海、珠海北、横琴、珠海机场、江门、江门东、开平南、台山、恩平，以及惠州北、惠州南、惠阳、惠东、惠东南和罗浮山等到发站的位置差异会显著改变接驳时间。云浮位于广东中西部，云城—云安构成城市与石材产业核心，新兴、罗定和郁南是方向不同、应各自成日的县域旅行组团；云浮东、新兴南、郁南和南江口也是服务不同片区的铁路门户。肇庆位于云浮东侧，广西梧州位于云浮西侧，广州则是外部换乘方向，三地景点都不计入云浮覆盖。汕头位于粤东，旅行骨架围绕小公园开埠区、内海湾及更远的南澳岛展开；它与珠三角城市之间应按独立城市段安排，潮州、揭阳也不计入汕头景点覆盖。肇庆、梧州、潮州、梅州、韶关、湛江等目的地也不作为广州、佛山、深圳、东莞、中山、珠海、江门、惠州、清远、云浮或汕头页面的“顺路景点”处理。组合行程时，应先确定城市与片区，再按实际到发站、总耗时和住宿位置选择铁路、城际、长途客运或航空；前往香港或澳门还需另行核对证件、口岸和当地交通，两地景点不计入广东城市指南覆盖。

江门页覆盖蓬江、江海、新会及全市跨县旅行框架，但台山、开平、鹤山、恩平是依法设立的县级市。页面列出开平碉楼、川山群岛、古劳水乡和冯如故里，是为了说明地级市域内的路线关系，不代表四个县级市已自动完成独立城市指南。开平碉楼与村落按 UNESCO 世界遗产整体去重，立园等景区运营节点不再重复累计；上川岛和下川岛则按不同目的港、船票与住宿分别组织。

肇庆以端州古城—七星岩—鼎湖山为主轴，高要需跨西江，广宁、怀集、德庆、封开和四会分别需要独立一日或住宿。星湖旅游景区是七星岩与鼎湖山的组合品牌，但两处是相距明显的物理单元；内部峰洞、寺观、车船和观景点不重复计数。四会是法定县级市，本页说明其衔接关系，不代表四会独立城市指南已经完成。

清远页以清城区、清新区相连主城为起点，并将佛冈、阳山、连南、连山及英德、连州分别作为县域旅行段。英德市和连州市是清远市代管的法定县级市，本页列出英西峰林、连州地下河和湟川三峡，是为了说明全市空间与交通关系，不代表两个县级市已自动完成独立城市指南。黄腾峡、古龙峡是两个独立运营景区，南岗瑶寨和欧家梯田也分属不同自治县，不能合并计数或同日扫点。

潮州以湘桥古城、韩江两岸和人民广场片区构成中心旅行骨架，潮安南北、凤凰山茶区及饶平山地与海岸是不同县域方向。广济桥是有开放和通航条件的文物景区，不能当作全天候跨江通道；凤凰山、道韵楼和汛洲岛各需独立交通与天气核对。潮州、汕头、揭阳是三座并列地级市，潮汕站位于潮州潮安，揭阳潮汕国际机场位于揭阳，交通枢纽名称不能改变景点归属。

揭阳的核心城市区由榕城古城与揭东多个片区共同构成，普宁市则是由揭阳市代管的法定县级市，揭西山地和惠来海岸又分别位于西部、南部远郊。揭阳页列出普宁德安里等代表目的地，是为了说明地级市范围和跨县路线，不代表普宁市已自动完成独立城市指南。揭阳潮汕国际机场位于揭阳市，潮汕站位于潮州市潮安区；机场或车站服务范围不能用来判断景点行政归属。
