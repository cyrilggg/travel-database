# 广东省旅行目的地

广东从珠江三角洲延伸到粤东、粤西和粤北，海岸、山地与高密度城市群并存。省内城市间交通联系发达，但距离和旅行主题差异很大：珠江口城市不能视作同一片可连续步行的目的地，跨到潮汕、粤西海岸或粤北山地通常也需要重新安排交通与停留天数。

## 区域格局与城市组合

广州是珠江三角洲北部的交通枢纽，老城与珠江中轴构成主要旅行骨架；佛山位于广州以西，由禅城、南海、顺德、高明和三水构成，祖庙—石湾、西樵山、顺德中心城区和西北部远郊不能视作同一片连续城区。广佛线、佛山地铁 2 号线和广州地铁 7 号线等联系跨越市界，其中广州南站位于广州市番禺区，是进入佛山的交通入口而不是佛山景点。深圳位于珠江口东岸，福田、罗湖、南山、宝安与大鹏半岛之间跨度大，城市核心、跨境口岸和东部海岸不能视作同一片步行区域。东莞位于广州与深圳之间，但不设县级市辖区，由镇街组团构成多中心城市；莞城、南城、松山湖、虎门与长安既不在同一片连续城区，也不宜为了只住一处而反复横穿。中山位于珠江口西岸，同样不设县级区；石岐老城、南朗—翠亨、五桂山与小榄是相对独立的旅行组团，不能因同属一市而压缩成连续市区路线。珠三角五城之间铁路、城际和道路联系密集，但广州南、广州东、佛山西、深圳北、福田、深圳、东莞、东莞东、东莞南、虎门、中山北、中山、南朗和小榄等到发站的位置差异会显著改变接驳时间。汕头位于粤东，旅行骨架围绕小公园开埠区、内海湾及更远的南澳岛展开；它与珠三角城市之间应按独立城市段安排，潮州、揭阳也不计入汕头景点覆盖。珠海和惠州虽与已有指南城市联系紧密，仍应分别建立城市指南；肇庆、开平、潮州、梅州、韶关、湛江等目的地也不作为广州、佛山、深圳、东莞、中山或汕头页面的“顺路景点”处理。组合行程时，应先确定城市与片区，再按实际到发站、总耗时和住宿位置选择铁路、城际、长途客运或航空；前往香港还需另行核对证件、口岸和当地交通，香港景点不计入深圳城市覆盖。

## 行前核对

- 省内及跨省铁路的车次、到发站和实名购票规则：[中国铁路 12306](https://www.12306.cn/)
- 全省景区、文化活动和临时文旅公告：[广东省文化和旅游厅](https://whly.gd.gov.cn/)
- 暴雨、高温、台风和海上天气预警：[广东省气象局](http://gd.cma.gov.cn/)
- 广佛跨市轨道、佛山市内线网与站点设施：[佛山地铁](https://www.fmetro.net/)、[广州地铁](https://www.gzmtr.com/)
- 航空到发与航站楼信息：[广州白云国际机场](https://www.gbiac.net/)、[深圳宝安国际机场](https://www.szairport.com/)
- 跨境证件、口岸和停留规则：[国家移民管理局](https://www.nia.gov.cn/)
