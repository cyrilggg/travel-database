# 广东省旅行目的地

广东从珠江三角洲延伸到粤东、粤西和粤北，海岸、山地与高密度城市群并存。省内城市间交通联系发达，但距离和旅行主题差异很大：珠江口城市不能视作同一片可连续步行的目的地，跨到潮汕、粤西海岸或粤北山地通常也需要重新安排交通与停留天数。

## 区域格局与城市组合

广州是珠江三角洲北部的交通枢纽，老城与珠江中轴构成主要旅行骨架；深圳位于珠江口东岸，福田、罗湖、南山、宝安与大鹏半岛之间跨度大，城市核心、跨境口岸和东部海岸不能视作同一片步行区域。东莞位于两城之间，但不设县级市辖区，由镇街组团构成多中心城市；莞城、南城、松山湖、虎门与长安既不在同一片连续城区，也不适合为省一次住宿而反复横穿。三城之间铁路和城际联系密集，但广州南、广州东、深圳北、福田、深圳、东莞、东莞东、东莞南和虎门等到发站的位置差异会显著改变接驳时间。佛山、珠海、中山和惠州虽与三城联系紧密，仍应分别建立城市指南；开平、潮州、汕头、梅州、韶关、湛江等目的地也不作为广州、深圳或东莞页面的“顺路景点”处理。组合行程时，应先确定城市与片区，再按实际到发站、总耗时和住宿位置选择铁路、城际、长途客运或航空；前往香港还需另行核对证件、口岸和当地交通，香港景点不计入深圳城市覆盖。

## 行前核对

- 省内及跨省铁路的车次、到发站和实名购票规则：[中国铁路 12306](https://www.12306.cn/)
- 全省景区、文化活动和临时文旅公告：[广东省文化和旅游厅](https://whly.gd.gov.cn/)
- 暴雨、高温、台风和海上天气预警：[广东省气象局](http://gd.cma.gov.cn/)
- 航空到发与航站楼信息：[广州白云国际机场](https://www.gbiac.net/)、[深圳宝安国际机场](https://www.szairport.com/)
- 跨境证件、口岸和停留规则：[国家移民管理局](https://www.nia.gov.cn/)
