# 广东省旅行目的地

广东从珠江三角洲延伸到粤东、粤西和粤北，海岸、山地与高密度城市群并存。省内城市间交通联系发达，但距离和旅行主题差异很大：珠江口城市、潮汕三市、粤西海岸、粤北韶关和粤东北梅州都需要重新安排交通与停留天数。普宁、高州、兴宁、陆丰与阳春虽分别由地级市代管，仍有独立城区、法定代码和完整旅行体系；共享交通联系不改变各城市的行政和旅行边界。

## 区域格局与城市组合

广州是珠江三角洲北部的交通枢纽，老城与珠江中轴构成主要旅行骨架；[番禺](./番禺区.md)位于主城南侧，长隆、市桥—沙湾、大学城与莲花山—海鸥岛按独立区级旅行指南规划。佛山位于广州以西，由禅城、南海、顺德、高明和三水构成，祖庙—石湾、西樵山、顺德中心城区和西北部远郊不能视作同一片连续城区。广佛线、佛山地铁 2 号线和广州地铁 7 号线等联系跨越市界，其中广州南站位于番禺，是区域交通入口而不是佛山景点。

深圳位于珠江口东岸，福田、罗湖、南山、宝安与大鹏半岛之间跨度大，城市核心、跨境口岸和东部海岸不能视作同一片步行区域。东莞位于广州与深圳之间，但不设县级市辖区，由镇街组团构成多中心城市；莞城、南城、松山湖、虎门与长安既不在同一片连续城区，也不宜为了只住一处而反复横穿。中山位于珠江口西岸，同样不设县级区；石岐老城、南朗—翠亨、五桂山与小榄是相对独立的旅行组团，不能因同属一市而压缩成连续市区路线。

珠海位于中山以南和珠江口西岸，香洲主城与情侣路、拱北口岸枢纽、横琴合作区、金湾、斗门和万山群岛不是一片连续城区；澳门隔着独立边界，东澳、外伶仃和桂山等岛屿也必须按不同目的港和船班组织。江门位于珠三角西南部，蓬江与江海构成主城生活圈，新会连接江门站、会城与更南部的人文湿地；台山、开平、鹤山和恩平是独立法定县级市，前往这些城市应另算跨城交通、返程和是否换宿，不能视作蓬江—江海主城景点。江门站位于新会区，不能按站名推断已到蓬江老城。惠州位于深圳、东莞以东，惠城西湖与东江老城、惠阳—大亚湾、仲恺、惠东海岸、博罗罗浮山和龙门山地是相距明显的旅行组团；巽寮湾、双月湾和大亚湾也不是同一片海滩。清远位于广州以北，清城—清新构成北江主城，佛冈、阳山、连南和连山须按不同县域方向安排；英德和连州是独立法定县级市，前往时应另算跨城交通、返程和是否换宿。

河源位于东江中上游，源城老城与新市区构成主城，江东新区和高新区是功能管理区而非另设的法定县级市。东源新港的万绿湖以旅游码头和游船组织游览，仙塘、义合与漳溪的古村、红色文化和畲族溶洞又分属不同道路方向；龙川、和平、紫金和连平则各有独立县城、住宿与末端交通，均不能视作源城近郊。河源东、河源北、龙川西和和平北服务不同片区，购票和订房应核对完整站名。

珠三角八城之间铁路、城际和道路联系密集，但广州南、广州东、佛山西、深圳北、福田、深圳、东莞、东莞东、东莞南、虎门、中山北、中山、南朗、小榄、珠海、珠海北、横琴、珠海机场、江门、江门东、开平南、台山、恩平，以及惠州北、惠州南、惠阳、惠东、惠东南和罗浮山等到发站的位置差异会显著改变接驳时间。云浮位于广东中西部，云城—云安构成城市与石材产业核心，新兴和郁南是方向不同、应各自成日的普通县域，罗定则是独立法定县级市，须另算跨城交通、返程和是否换宿；云浮东、新兴南、郁南和南江口也是服务不同片区的铁路门户。肇庆、梧州和广州是云浮不同方向的外部换乘目的地，三地景点均不属于云浮市旅行范围。汕头位于粤东，旅行骨架围绕小公园开埠区、内海湾及更远的南澳岛展开；它与珠三角城市之间应按独立城市段安排，潮州、揭阳的景点也不属于汕头市。肇庆、梧州、潮州、梅州、韶关、湛江等目的地不作为周边城市的“顺路景点”处理。组合行程时，应先确定城市与片区，再按实际到发站、总耗时和住宿位置选择铁路、城际、长途客运或航空；前往香港或澳门还需另行核对证件、口岸和当地交通，两地应按各自目的地规则安排。

江门市域包括蓬江、江海、新会及台山、开平、鹤山、恩平等县级市。四座县级市各有独立城区和交通体系，从江门主城前往可按跨城段核对到发站、返程和是否换宿；[鹤山](./鹤山市.md)承接沙坪、古劳、大雁山和茶乡，[恩平](./恩平市.md)承接城区、航空史、温泉与乡村山地。

肇庆以端州古城—七星岩—鼎湖山为主轴，高要需跨西江，广宁、怀集、德庆、封开和四会分别需要独立一日或住宿。星湖旅游景区是七星岩与鼎湖山的组合品牌，但两处是相距明显的物理单元；内部峰洞、寺观、车船和观景点不重复计数。四会是法定县级市，拥有独立城区与交通节奏；纳入肇庆广域行程时应单独留日。

清远以清城区、清新区相连主城为起点，佛冈、阳山、连南和连山分别构成县域旅行段。英德市和[连州市](./连州市.md)是清远市代管的独立法定县级市，从主城前往先核对到发站、返程和是否换宿；连州城区、洞穴与峡谷由独立页组织。黄腾峡、古龙峡是两个独立运营景区，南岗瑶寨和欧家梯田也分属不同自治县。

潮州以湘桥古城、韩江两岸和人民广场片区构成中心旅行骨架，潮安南北、凤凰山茶区及饶平山地与海岸是不同县域方向。广济桥是有开放和通航条件的文物景区，不能当作全天候跨江通道；凤凰山、道韵楼和汛洲岛各需独立交通与天气核对。潮州、汕头、揭阳是三座并列地级市，潮汕站位于潮州潮安，揭阳潮汕国际机场位于揭阳，交通枢纽名称不能改变景点归属。

揭阳的核心城市区由榕城古城与揭东多个片区共同构成，揭西山地和惠来海岸又分别位于西部、南部远郊。普宁市是由揭阳市代管的独立法定县级市，从榕城前往应另算跨城交通、返程和是否换宿；普宁旅行内容不纳入揭阳主城路线。揭阳潮汕国际机场位于揭阳市，潮汕站位于潮州市潮安区；机场或车站服务范围不能用来判断景点行政归属。

普宁现有独立城市页，以流沙主城为商贸、交通和公共服务基点，洪阳古城、南溪水乡、大南山街道与云落温泉方向分别需要车辆接驳。普宁是法定县级市 `445281`，不等于揭阳榕城的一个街区；揭阳机场在普宁市域之外，汕头潮阳、潮南和揭阳惠来也不能并入普宁景点。洪阳古建群、德安里、英歌传承展示和各正式景区按运营与物理边界去重；祠堂、生活村落、专业市场、工厂仓库、物流装卸区、河道和山地只有明确开放的公众范围可以进入。

汕尾位于广东东南沿海，市城区的品清湖、凤山祖庙、二马路与金町湾构成城市文化和滨水主线，红海湾遮浪方向则需一次完整公路转场。海丰县的红宫红场与莲花山、陆河县的梅园与山地各自适合独立成日；[陆丰](./陆丰市.md)是代码 `441581` 的独立法定县级市，从汕尾市区前往应另算跨城交通、返程和是否换宿。项目固定 Donghai 城市点实际对应东海街道，不替代完整陆丰市域；陆丰的景点、餐饮、住宿与路线均由独立页承接，不纳入汕尾市区路线。红海湾经济开发区是功能区而非法定县级行政区；沙滩、礁岸、渔港、蚝场、养殖滩涂、海洋保护范围与生产港区必须按当期开放边界区分。

湛江位于雷州半岛，赤坎、霞山、麻章、坡头四个主城组团分处海湾两岸及西部交通轴，湖光岩、东海岛、硇洲岛和特呈岛各有独立接驳与天气条件。经开区不是第五个法定市辖区；廉江、雷州、[吴川](./吴川市.md)是湛江代管的法定县级市，遂溪和徐闻是独立县域，适合按各自交通和住宿组织。湛江湾的客运航线、公共岸线、航道与生产港区保留明确边界，游览选择开放公共空间和持证交通。

茂名位于粤西中部，本页以茂南主城与电白海岸为旅行骨架。露天矿生态公园等公共展示空间可以说明工业城市转型；石化厂区、矿坑作业面、管线和港口生产区遵守生产边界。高州、[化州](./化州市.md)、信宜是具有独立代码的县级市，均按各自城区、住宿、交通和行程天数安排。

高州现有独立城市页，是法定县级市 `440981`，不等于茂南主城的一处郊区。高州城区、根子—分界荔乡、长坡遗址和深镇山地分别需要独立接驳；大唐荔乡文化旅游区的中国荔枝博览馆、贡园、古荔园等内部模块按一个景区记录。生产果园、高州水库饮用水源、文保遗址和非正式山林道路只有明确开放的公众范围可以进入。[茂名](./茂名市.md)与[高州](./高州市.md)之间只以跨城交通和行政关系衔接，不重复安排景点、餐饮或住宿。

阳江由江城区城市文化、海陵岛文博与海滩、阳东东平和阳西沙扒等相反方向的海岸组成。海陵岛以公路连接大陆，广东海上丝绸之路博物馆、十里银滩、大角湾与闸坡镇分段安排；渔港参观使用开放公共区域和持证项目。[阳春](./阳春市.md)是独立法定县级市，以主城、凌霄岩、春湾和山地远线另行组织。

韶关的紧凑主城主要是浈江老城与武江中心，曲江的南华寺和马坝考古需另用道路交通，仁化丹霞山、乳源大峡谷与始兴自然教育则各是独立山地日。丹霞山按一个完整大型景区去重；南岭相关保护地、林场、矿山、钢厂、水库和农业生产区按正式开放边界进入。[乐昌](./乐昌市.md)与[南雄](./南雄市.md)均有独立指南，南雄的珠玑—梅关和银杏山地按换城行程规划。

梅州的连续城市核心跨梅江区与梅县区，客家博物馆、嘉应古城和近郊围龙屋可分片组合；松口、雁洋、大埔、丰顺、五华、平远与蕉岭各需县域接驳。[兴宁](./兴宁市.md)是法定县级市 `441481`，由梅州代管但拥有独立城区、住宿、兴宁南站与市内交通节奏；兴宁博物馆、兴田古城文保、神光山、熙和湾、乡镇围屋、餐饮和住宿均由兴宁独立页承接，不纳入梅州主城路线。兴宁的文保名录不等于建筑开放，合水水库饮用水源、矿山、茶园农田、林地和居民院落也只有明确开放的公众范围可以进入。
