# 广东省旅行目的地

广东从珠江三角洲延伸到粤东、粤西和粤北，海岸、山地与高密度城市群并存。省内城市间交通联系发达，但距离和旅行主题差异很大：珠江口城市不能视作同一片可连续步行的目的地，跨到潮汕、粤西海岸、粤北山地或云浮等中西部广域城市，通常也需要重新安排交通与停留天数。粤东的汕头、揭阳和潮州共享“潮汕”文化与交通名称，却仍是行政、住宿和景点覆盖分别计算的城市。

## 区域格局与城市组合

广州是珠江三角洲北部的交通枢纽，老城与珠江中轴构成主要旅行骨架；佛山位于广州以西，由禅城、南海、顺德、高明和三水构成，祖庙—石湾、西樵山、顺德中心城区和西北部远郊不能视作同一片连续城区。广佛线、佛山地铁 2 号线和广州地铁 7 号线等联系跨越市界，其中广州南站位于广州市番禺区，是进入佛山的交通入口而不是佛山景点。深圳位于珠江口东岸，福田、罗湖、南山、宝安与大鹏半岛之间跨度大，城市核心、跨境口岸和东部海岸不能视作同一片步行区域。东莞位于广州与深圳之间，但不设县级市辖区，由镇街组团构成多中心城市；莞城、南城、松山湖、虎门与长安既不在同一片连续城区，也不宜为了只住一处而反复横穿。中山位于珠江口西岸，同样不设县级区；石岐老城、南朗—翠亨、五桂山与小榄是相对独立的旅行组团，不能因同属一市而压缩成连续市区路线。珠海位于中山以南和珠江口西岸，香洲主城与情侣路、拱北口岸枢纽、横琴合作区、金湾、斗门和万山群岛不是一片连续城区；澳门隔着独立边界，东澳、外伶仃和桂山等岛屿也必须按不同目的港和船班组织。惠州位于深圳、东莞以东，惠城西湖与东江老城、惠阳—大亚湾、仲恺、惠东海岸、博罗罗浮山和龙门山地是相距明显的旅行组团；巽寮湾、双月湾和大亚湾也不是同一片海滩。珠三角七城之间铁路、城际和道路联系密集，但广州南、广州东、佛山西、深圳北、福田、深圳、东莞、东莞东、东莞南、虎门、中山北、中山、南朗、小榄、珠海、珠海北、横琴、珠海机场，以及惠州北、惠州南、惠阳、惠东、惠东南和罗浮山等到发站的位置差异会显著改变接驳时间。云浮位于广东中西部，云城—云安构成城市与石材产业核心，新兴、罗定和郁南是方向不同、应各自成日的县域旅行组团；云浮东、新兴南、郁南和南江口也是服务不同片区的铁路门户。肇庆位于云浮东侧，广西梧州位于云浮西侧，广州则是外部换乘方向，三地景点都不计入云浮覆盖。汕头位于粤东，旅行骨架围绕小公园开埠区、内海湾及更远的南澳岛展开；它与珠三角城市之间应按独立城市段安排，潮州、揭阳也不计入汕头景点覆盖。肇庆、梧州、开平、潮州、梅州、韶关、湛江等目的地也不作为广州、佛山、深圳、东莞、中山、珠海、惠州、云浮或汕头页面的“顺路景点”处理。组合行程时，应先确定城市与片区，再按实际到发站、总耗时和住宿位置选择铁路、城际、长途客运或航空；前往香港或澳门还需另行核对证件、口岸和当地交通，两地景点不计入广东城市指南覆盖。

揭阳的核心城市区由榕城古城与揭东多个片区共同构成，普宁市则是由揭阳市代管的法定县级市，揭西山地和惠来海岸又分别位于西部、南部远郊。揭阳页列出普宁德安里等代表目的地，是为了说明地级市范围和跨县路线，不代表普宁市已自动完成独立城市指南。揭阳潮汕国际机场位于揭阳市，潮汕站位于潮州市潮安区；机场或车站服务范围不能用来判断景点行政归属。
