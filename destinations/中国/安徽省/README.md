# 安徽省旅行目的地

安徽从淮北平原延伸到皖南山地，省内城市之间的自然条件与旅行节奏差异很大。目前可查阅二十座城市指南；[明光](./明光市.md)以女山湖、女山地质景观和皖东山地湖区形成独立路线。县级市、县城和山水景区常与地级市主城相距较远，规划路线时分别核对交通、住宿和开放条件。

## 区域格局与城市组合

合肥位于安徽中部，是省级文化机构、铁路与航空交通的重要节点。老城、政务新区、高新区、骆岗公园与合肥侧滨湖分别成片；三河古镇按远郊一日处理。[巢湖市](./巢湖市.md)是合肥代管的独立县级市，中庙—姥山岛、城区湖岸与山地路线进入其独立页面。

阜阳位于安徽西北部，中心城区的旅行主线集中在颍州城南文化片区、老城与颍州西湖；颍泉生态乐园和颍东程文炳宅院分别位于其他方向。颍上八里河与尤家花园—五里湖、阜南王家坝—蒙洼、临泉综合景区和太和县博物馆都应按县域独立路线处理。界首是阜阳代管的法定县级市，行政范围、接驳方式和停留时间均应与阜阳主城分开，具体游览须查阅属地信息。

芜湖以镜湖—弋江—鸠江主城为主要交通和住宿骨架，湾沚、繁昌、南陵及江北无为分属不同远端方向。鸠兹风景区、芜湖古城、赭山和各方特园区应按各自实际运营范围安排；无为是芜湖代管的法定县级市，其住宿、接驳和游览时间应单独安排。

马鞍山以花山—雨山连续主城为铁路、住宿、文博与城市服务核心，采石矶位于雨山区长江岸线；当涂在主城以南，博望靠近南京江宁、溧水边界，含山与和县则需从主城跨江前往。宁马市域铁路连接南京、主城和当涂，但不经过博望、含山或和县，后三地通常各需独立一天。采石矶内的太白楼、三元洞、林散之艺术馆、延园、古镇与滨江空间共同组成一处大型旅游区。凹山地质文化公园等明确开放空间可以游览；马钢工业旅游只有在官方预约系统显示可约日期、接待对象、集合点和规则时才可进入，不把 App 入口存在等同于任意日期开放。在产钢厂、矿山、专用铁路、港区、码头、防洪和水利设施不属于自由游览范围。长江岸线只使用正式开放的景区、公园和步道，汛期高水位或管理封闭时不进入滩地、闸站和生产岸线。

铜陵以铜官区主城为住宿、铁路接驳与公共文化核心，铜陵博物馆、天井湖和铜官山·1978之间适合用公交或短途车辆连接。义安区的凤凰山—金牛洞、永泉和犁桥属于彼此独立的乡旅方向；郊区大通古镇需要公路接驳；枞阳县位于长江北岸，浮山通常要留完整一天。在产矿山、冶炼厂、尾矿库、专用铁路、港口、码头和江堤作业段不属于游览空间，矿冶主题只进入博物馆、公开遗址和正式开放的工业遗产园区。汛期高水位、强降雨或景区管制时，不进入滩地、洞穴、山路和未开放岸线。

淮南的田家庵—山南承担主要住宿、交通和现代公共文化功能，寿县古城、八公山、大通工矿遗产与焦岗湖分处不同方向。寿县古城内部城墙、城门、街巷和场馆按完整古城游览单元组织；八公山跨越淮南、六安一带，只有行政归属和运营边界明确的入口计入对应路线。县级目的地和管理区不是可由主城一并涵盖的连续游览范围。

淮北以相山区主城和相山为日常住宿、文博与城市步行核心，烈山矿区遗存、南湖等沉陷地修复空间、濉溪县临涣古镇与柳孜运河遗址分处不同方向。工业生产区、废弃矿坑和生态修复公园不是同一类开放空间，未正式开放的生产设施不得进入；临涣、柳孜及县域酒类生产展示需单独落实往返、开放与安全条件。

六安中心城区主要跨金安、裕安展开，叶集位于西部边界；金寨、霍山、舒城和霍邱则分别形成大别山、水库湖泊与沿淮平原方向。天堂寨、白马尖、万佛湖、万佛山和临淮岗互不构成一条连续近郊线，县城与同县景区也可能相距很远。寿县现属淮南，不属于六安；各景区内部岛屿、峡谷、瀑布和场馆均属于相应完整运营单元。

宿州以埇桥主城区为交通与住宿中心，砀山、萧县、灵璧和泗县分列不同县域方向。砀山梨园、皇藏峪、灵璧奇石和泗县通济渠各自需要独立接驳；宿州站、宿州东站、砀山南站与萧县北站不能按相似站名互换。安徽宿州与江苏苏州是两座不同城市，订票和导航必须同时核对省份与完整站名。

亳州以谯城北关历史片区和老城为人文核心，市博物馆—魏武大道片区、中药材专业市场南部商贸区与古井镇分属不同方向。花戏楼、曹氏公园墓群和老街应按各自实际景区边界安排，中药材市场是专业商贸空间，不替代医疗建议。涡阳、蒙城和利辛是独立县域目的地，不能因同属亳州市而当作主城短途景点。

黄山市位于皖南，行政上辖屯溪、黄山、徽州 3 个区和歙、休宁、黟、祁门 4 个县。市政府驻地和常规城市服务集中在屯溪，黄山风景区位于市域北部山地，常用南大门依托汤口镇；黄山区、黄山风景区与黄山市是三个不同范围。歙县徽州古城、黟县西递与宏村、休宁县齐云山都需要公路或跨县交通，不能与屯溪视为可连续步行的同一片区。

池州的市级交通、住宿与文博服务集中在贵池主城，杏花村位于主城西侧，齐山—平天湖在东南侧，长江公共岸线则与货运港区、闸站和生产码头并存，只进入明确开放的公园、步道和客运设施。九华山处在青阳县方向，由山下游客服务中心、九华街和天台或花台等山岳区域构成，宗教活动场所应尊重礼仪，内部寺院按完整景区组织，不拆成重复目的地，通常需独立一至两天。石台的牯牛降、仙寓山和秋浦河源，与东至的升金湖、东流方向分别需要独立县域交通；湿地与自然保护区、矿山采石场、港区和未开放林道均不属于自由穿行范围。

蚌埠主城由龙子湖、蚌山、禹会和淮上四区构成，淮河、铁路和龙子湖把城市片区分开；怀远、五河、固镇三个普通县都需要独立公路或铁路接驳。双墩与禹会村属于不同史前遗址，考古证据与大禹、垓下等地方历史记忆也须分层说明。龙子湖、张公山、白乳泉、垓下和沱湖分别是完整景区或保护空间；考古工地、铁路运行区、水利岸线和湿地保护地只有正式开放部分可以进入。

安庆主城主要跨迎江、大观和宜秀三区，安庆博物馆、菱湖、倒扒狮老街、迎江寺—振风塔和独秀园分处不同片区，可用 1–2 天组合。桐城 `340881` 与潜山 `340882` 都是法定县级市，不能因机场或交通产品的名称而当作安庆主城近郊，具体游览须分别查阅属地信息。枞阳县自 2016 年起属铜陵市。长江港区、化工生产区、湖泊湿地和大别山方向只进入正式开放范围；景区内部展馆、古塔或山岳节点属于各自完整游线。

滁州主城横跨琅琊、南谯两区，琅琊山—醉翁亭与老城可以组成主线；凤阳的明中都、明皇陵和小岗村位于另一县域方向，宜单独安排一天。天长 `341181`、明光 `341182` 是法定县级市，不属于滁州主城近郊。南京虽是常用跨省门户，但属于另一城市；“南京太仆寺”是历史机构名称，其遗址位于滁州。森林、水库、湿地和矿区只进入正式开放范围，不走生产道路、坝体泄洪区或采矿作业区。

宣城主城以宣州区为交通和住宿中心，敬亭山、宛陵湖与城市文博设施可组合游览。泾县的宣纸与古村、绩溪的徽州古城镇与徽杭古道、旌德的宣砚与古村分属不同方向，通常各需独立一天；宁国 `341881` 与[广德](./广德市.md) `341882` 是法定县级市，广德的太极洞、卢湖竹海和南部山地进入独立指南。皖南山地在强降雨后按道路、涉水和景区公告调整；生产体验使用明确开放的展示区。

合肥、芜湖、马鞍山、铜陵、淮南、淮北、六安、阜阳、宿州、亳州、黄山、池州、蚌埠、安庆、滁州与宣城是十六座彼此独立的城市。铁路或市域铁路连接方便，不代表任一城市属于另一城的远郊，也不代表所辖县区可以从中心城区顺路游览；各地行程仍应分别计算停留、住宿和景区交通。
