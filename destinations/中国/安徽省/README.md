# 安徽省旅行目的地

安徽从淮北平原延伸到皖南山地，省内城市之间的自然条件与旅行节奏差异很大。本阶段以合肥建立“省会老城、博物馆、科教新区、大型公园与湖岸远郊”并存时的写法，以黄山建立“中心城区、山岳景区、县城与古村落”并存时的写法。后续城市、县城与聚落仍须按覆盖清单分别研究，不能由省会或知名景区所在城市代替。

## 区域格局与城市组合

合肥位于安徽中部，是省级文化机构、铁路与航空交通的重要节点。老城核心集中在包公园、淮河路、李鸿章故居和逍遥津一带；安徽博物院蜀山馆与政务文化新区位于城市西南方向，高新区、骆岗公园和滨湖新区又各自形成独立片区。巢湖岸线横跨多个相距较远的游览区域，三河古镇位于肥西县南部，都需要按远郊一日路线处理，不能与中心城区视为连续步行范围。

黄山市位于皖南，行政上辖屯溪、黄山、徽州 3 个区和歙、休宁、黟、祁门 4 个县。市政府驻地和常规城市服务集中在屯溪，黄山风景区位于市域北部山地，常用南大门依托汤口镇；黄山区、黄山风景区与黄山市是三个不同范围。歙县徽州古城、黟县西递与宏村、休宁县齐云山都需要公路或跨县交通，不能与屯溪视为可连续步行的同一片区。

合肥与黄山是两座独立城市。铁路连接方便不等于黄山属于合肥远郊，两地行程应分别计算停留、住宿和景区交通。本页出现的肥西、巢湖市、三河古镇、中庙、姥山岛、歙县、黟县、汤口、宏村、西递、齐云山等地点，只说明它们与所在城市旅行线路的关系，不表示这些地点在全球覆盖清单中的独立记录已经完成。芜湖、安庆、池州、宣城等安徽城市也应分别研究，不能套用合肥或黄山的页面结构。

## 来源与维护

合肥的城市与远郊关系依据[合肥市“十四五”现代服务业发展规划](https://www.hfyaohai.gov.cn/public/155377/109464978.html)、[文化和旅游部关于合肥文旅结构的资料](https://www.mct.gov.cn/whzx/qgwhxxlb/ah/202302/t20230206_938917.htm)及各场馆官方资料整理。黄山市行政区划依据[黄山市人民政府人口区划资料](https://www.huangshan.gov.cn/zjhs/hssq/rkqh/index.html)，黄山与西递、宏村的世界遗产属性分别依据 [UNESCO 黄山名录](https://whc.unesco.org/en/list/547/)和 [UNESCO 皖南古村落名录](https://whc.unesco.org/en/list/1002/)，均核验于 2026-07-30。实时交通、票价、开放状态、预约政策、索道或船运运行和天气不保存在本页。
