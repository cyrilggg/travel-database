# 安徽省旅行目的地

安徽从淮北平原延伸到皖南山地，省内城市之间的自然条件与旅行节奏差异很大。现有指南从合肥、芜湖等中心与沿江城市延伸到淮河两岸、皖北平原、大别山，以及滁州的江淮丘陵、宣城和黄山的皖南山水、安庆的长江港城。县级市、县城和山水景区常与地级市主城相距较远，规划路线时应分别核对交通、住宿和开放条件。

## 区域格局与城市组合

合肥位于安徽中部，是省级文化机构、铁路与航空交通的重要节点。老城核心集中在包公园、淮河路、李鸿章故居和逍遥津一带；安徽博物院蜀山馆与政务文化新区位于城市西南方向，高新区、骆岗公园和滨湖新区又各自形成独立片区。巢湖岸线横跨多个相距较远的游览区域，三河古镇位于肥西县南部，都需要按远郊一日路线处理，不能与中心城区视为连续步行范围。

阜阳位于安徽西北部，中心城区的旅行主线集中在颍州城南文化片区、老城与颍州西湖；颍泉生态乐园和颍东程文炳宅院分别位于其他方向。颍上八里河与尤家花园—五里湖、阜南王家坝—蒙洼、临泉综合景区、太和县博物馆及界首市博物馆都应按县域独立路线处理。界首是阜阳代管的法定县级市，行政范围、接驳方式和停留时间均应与阜阳主城分开考虑。

芜湖以镜湖—弋江—鸠江主城为主要交通和住宿骨架，湾沚、繁昌、南陵及江北无为分属不同远端方向。鸠兹风景区、芜湖古城、赭山和各方特园区按实际运营单元去重；无为是芜湖代管的法定县级市，其住宿、接驳和游览时间应单独安排。

淮南的田家庵—山南承担主要住宿、交通和现代公共文化功能，寿县古城、八公山、大通工矿遗产与焦岗湖分处不同方向。寿县古城内部城墙、城门、街巷和场馆按完整古城游览单元组织；八公山跨越淮南、六安一带，只有行政归属和运营边界明确的入口计入对应路线。县级目的地和管理区不是可由主城一并涵盖的连续游览范围。

淮北以相山区主城和相山为日常住宿、文博与城市步行核心，烈山矿区遗存、南湖等沉陷地修复空间、濉溪县临涣古镇与柳孜运河遗址分处不同方向。工业生产区、废弃矿坑和生态修复公园不是同一类开放空间，未正式开放的生产设施不得进入；临涣、柳孜及县域酒类生产展示需单独落实往返、开放与安全条件。

六安中心城区主要跨金安、裕安展开，叶集位于西部边界；金寨、霍山、舒城和霍邱则分别形成大别山、水库湖泊与沿淮平原方向。天堂寨、白马尖、万佛湖、万佛山和临淮岗互不构成一条连续近郊线，县城与同县景区也可能相距很远。寿县现属淮南，不计入六安；各景区内部岛屿、峡谷、瀑布和场馆按完整运营单元去重。

宿州以埇桥主城区为交通与住宿中心，砀山、萧县、灵璧和泗县分列不同县域方向。砀山梨园、皇藏峪、灵璧奇石和泗县通济渠各自需要独立接驳；宿州站、宿州东站、砀山南站与萧县北站不能按相似站名互换。安徽宿州与江苏苏州是两座不同城市，订票和导航必须同时核对省份与完整站名。

亳州以谯城北关历史片区和老城为人文核心，市博物馆—魏武大道片区、中药材专业市场南部商贸区与古井镇分属不同方向。花戏楼、曹氏公园墓群和老街按实际景区边界去重，中药材市场是专业商贸空间，不替代医疗建议。涡阳、蒙城和利辛是独立县域目的地，不能因同属亳州市而当作主城短途景点。

黄山市位于皖南，行政上辖屯溪、黄山、徽州 3 个区和歙、休宁、黟、祁门 4 个县。市政府驻地和常规城市服务集中在屯溪，黄山风景区位于市域北部山地，常用南大门依托汤口镇；黄山区、黄山风景区与黄山市是三个不同范围。歙县徽州古城、黟县西递与宏村、休宁县齐云山都需要公路或跨县交通，不能与屯溪视为可连续步行的同一片区。

蚌埠主城由龙子湖、蚌山、禹会和淮上四区构成，淮河、铁路和龙子湖把城市片区分开；怀远、五河、固镇三个普通县都需要独立公路或铁路接驳。双墩与禹会村属于不同史前遗址，考古证据与大禹、垓下等地方历史记忆也须分层说明。龙子湖、张公山、白乳泉、垓下和沱湖分别按完整景区或保护空间去重；考古工地、铁路运行区、水利岸线和湿地保护地只有正式开放部分可以进入。

安庆主城主要跨迎江、大观和宜秀三区，安庆博物馆、菱湖、倒扒狮老街、迎江寺—振风塔和独秀园分处不同片区，可用 1–2 天组合。桐城 `340881` 与潜山 `340882` 都是法定县级市，天柱山位于潜山市，不能因“安庆天柱山机场”的名称而当作机场旁或主城近郊。枞阳县自 2016 年起属铜陵市。长江港区、化工生产区、湖泊湿地和大别山方向只进入正式开放范围；景区内部展馆、古塔或山岳节点不重复拆分。

滁州主城横跨琅琊、南谯两区，琅琊山—醉翁亭与老城可以组成主线；凤阳的明中都、明皇陵和小岗村位于另一县域方向，宜单独安排一天。天长 `341181`、明光 `341182` 是法定县级市，不属于滁州主城近郊。南京虽是常用跨省门户，但属于另一城市；“南京太仆寺”是历史机构名称，其遗址位于滁州。森林、水库、湿地和矿区只进入正式开放范围，不走生产道路、坝体泄洪区或采矿作业区。

宣城主城以宣州区为交通和住宿中心，敬亭山、宛陵湖与城市文博设施可组合游览。泾县的宣纸与古村、绩溪的徽州古城镇与徽杭古道、旌德的宣砚与古村分属不同方向，通常各需独立一天；宁国 `341881`、广德 `341882` 是法定县级市，也应分别核算交通和住宿。皖南山地在强降雨后可能出现道路封闭、落石和涉水风险；宣纸、宣砚等生产空间仅在明确开放参观时进入，原料仓库、晒场和机械作业区不作为公共游览区。

合肥、芜湖、淮南、淮北、六安、阜阳、宿州、亳州、黄山、蚌埠、安庆、滁州与宣城是十三座彼此独立的城市。铁路连接方便不等于任一城市属于另一城的远郊，也不等于所辖县市可以从中心城区顺路游览；各地行程应分别计算停留、住宿和景区交通。本页提到的县市、景区和乡镇只用于说明地理关系与线路边界，池州、马鞍山、铜陵等其他安徽目的地不能套用现有城市页面。

## 来源与维护
