# 安徽省旅行目的地

安徽从淮北平原延伸到皖南山地，省内城市之间的自然条件与旅行节奏差异很大。本阶段以黄山建立“中心城区、山岳景区、县城与古村落”并存时的写法；后续城市、县城与聚落仍须按覆盖清单分别研究，不能由黄山市一页代替。

## 城市指南

|---|---|---:|---|---|
| [黄山](./黄山市.md) | 黄山风景区、徽州文化、古城古村、徽菜与名茶 | 3–5 天 | `researched` | 2026-07-30 |

## 区域格局与城市组合

黄山市位于皖南，行政上辖屯溪、黄山、徽州 3 个区和歙、休宁、黟、祁门 4 个县。市政府驻地和常规城市服务集中在屯溪，黄山风景区位于市域北部山地，常用南大门依托汤口镇；黄山区、黄山风景区与黄山市是三个不同范围。歙县徽州古城、黟县西递与宏村、休宁县齐云山都需要公路或跨县交通，不能与屯溪视为可连续步行的同一片区。

本页出现的歙县、黟县、汤口、宏村、西递、齐云山等目的地，只说明它们与黄山市旅行线路的关系，不表示这些地点在全球覆盖清单中的独立记录已经完成。合肥、芜湖、安庆、池州、宣城等安徽城市也应分别研究，不能套用黄山的山岳与古村结构。
