# 宣城旅行指南

宣城位于安徽东南部，是皖南山区与沿江平原交接处的一座山水文化城市。宣州主城可用博物馆、谢朓楼一带和敬亭山读懂诗歌传统、文房四宝与现代城市；更广的地级市范围则向泾县的宣纸和古村、绩溪的徽文化与古道、旌德的宣砚、郎溪的丘陵湖区展开。市域东西与南北跨度都很大，县域山水并不是主城近郊，旅行时宜先选一个方向，再为公路转场、山区天气和住宿留出余量。

> 建议停留：2–4 天；只看宣州主城 1–2 天<br>
> 旅行关键词：敬亭山、诗歌文化、文房四宝、扬子鳄、皖南古村、徽菜<br>
> 主要体力：主城中等步行；古道、峡谷和山地为中高至高强度<br>
> 最近研究：2026-08-12

## 城市格局与游览区域

宣城市法定行政代码为 `341800`。现辖宣州区 `341802`，郎溪县 `341821`、泾县 `341823`、绩溪县 `341824`、旌德县 `341825`，以及县级宁国市 `341881`、[广德市](./广德市.md) `341882`。市政府驻宣州区，常规所说的“宣城市区”主要指宣州主城。宁国和广德均按独立县级市组织交通、住宿与旅行网络。

| 郎溪方向 | 县城、南漪湖周边、丘陵茶区与观天下等景区 | 湖区、茶园和景区之间依赖公路，开放边界与水位需确认 | 位于市域东北，适合单独一天；宁国、广德不因相邻而并入郎溪路线 |
| 泾县方向 | 宣纸文化园、桃花潭、查济、云岭、月亮湾等 | 文房工艺、古村、红色历史与涉水山地分散在不同乡镇 | 从主城出发宜只选一个主题组合，深入古村或水上活动时更适合住泾县 |
| 绩溪方向 | 绩溪古城、博物馆、龙川、徽杭古道与徽墨文化 | 古城和博物馆可组合，龙川与古道各有独立入口；山区路线受天气影响明显 | 距宣州主城较远，可乘铁路或公路抵达后换乘，不适合主城当天来回打卡多个景区 |
| 旌德方向 | 旌德县城、文庙、宣砚文化园、江村与古道 | 县城文化点与村落、山路并非连续步行区 | 可作为文房四宝或皖南村落一日方向，若再接绩溪需核算车次与住宿 |

宣州主城最顺畅的阅读顺序是“博物馆了解城市与文房四宝—老城寻找诗歌与历史现场—敬亭山观察诗歌如何落到山水空间”。若希望继续看工艺，泾县、绩溪和旌德各自承担不同内容，不能把四种技艺想象成集中在同一条街上的连续表演。宣纸制作等工艺既是非遗，也是现实生产：只有明确面向公众开放的博物馆、文化园、体验区或预约参观线路可以进入，普通厂房、原料仓库、晾晒场、机械作业区和匠人工作间都不是自由参观空间。

市域南部多山，北部与河湖平原相接。汛期强降雨会同时影响山路、古道、峡谷、河岸、漂流和低洼城区；过去已有多处景区因强降雨集中暂停开放。节假日热门旅游公路也可能实施临时交通组织，自驾不能只按地图预计用时。

## 美食与餐饮

宣州主城适合寻找水阳三宝、麻辣粉丝、皖南家常菜和敬亭绿雪；水东、泾县、绩溪等县域则各有糕点、米食、徽菜与茶。地方食品常见腌制、卤制、炖焖和较重调味，严格控盐、纯素、清真、无麸质或严重过敏者需要逐项确认原料、汤底、酱油和共用厨具。热门街区同类型餐馆较多，不必把某一家店当作唯一答案。

| 菜品或餐饮类型 | 常见区域 | 一个人用餐与常见份量 | 风味、过敏原与饮食限制 | 排队风险与替代方法 |
|---|---|---|---|---|
| 水阳三宝 | 宣州主城、水阳镇及本地菜馆 | 鸭脚包、鸭翅和水阳干子常以拼盘或锅煲出现，更适合二人以上；独食先问小份 | 含禽肉和大豆，卤汁常见酱油、小麦与较高盐分；鸭脚有骨，食用时留意碎骨 | 热门餐馆正餐时段可能等位；改选能说明原料和份量的普通本地菜馆，不必专程追单店 |
| 麻辣粉丝 | 主城小吃店与普通街区 | 通常一人一碗，适合作简餐 | 辣度可高；汤底可能含肉、动物油、大豆和小麦，配料中的豆腐锅巴、面筋也需确认 | 午餐与夜间可能排队；选择同类小店并要求少辣，不能吃辣时改清汤粉面 |
| 徽菜家常炖烧 | 主城及各县本地菜馆 | 臭鳜鱼、笋干烧肉、腌鲜等多为共享菜；独食先问小份或按位做法 | 常见鱼、猪肉、黄酒、酱油和腌制食材，盐分可能较高；素菜也可能用肉汤或动物油 | 用普通小炒、时蔬和米饭替代大份硬菜，先问计价、鱼重与是否可减盐 |
| 绩溪一品锅 | 绩溪县及徽菜餐馆 | 多层炖锅通常适合多人分享，不适合独食者为尝味点大锅 | 常见猪肉、鸡肉、蛋饺、豆制品、笋和高汤；含蛋、大豆，丸子或调味可能含小麦 | 节假日与团队餐时段风险较高；改点小砂锅或一荤一素，不必为一品锅跨县 |
| 绩溪挞粿 | 绩溪县早餐、小吃店 | 一人一个或一份，适合早餐和途中补充 | 面皮通常含小麦，馅料可能含肉、腌菜、豆制品或辣椒；煎制油与交叉接触需问 | 早餐高峰可能售罄；用普通馅饼、面点或米食替代，不因单一摊位打乱路线 |
| 水东蜜枣 | 水东镇、主城特产店与正规零售点 | 适合少量试食和携带，包装份量差异大 | 糖分高；不同加工品可能加入糖浆、蜂蜜或其他配料，控糖者少量食用 | 选择标签完整、密封良好的产品，比较生产日期与储存要求，避免来源不明散装品 |
| 敬亭绿雪及本地茶 | 敬亭山周边、主城茶馆与正规茶叶店 | 一人可按杯或壶饮用，购买前先少量试饮 | 绿茶含咖啡因；调饮茶和茶点可能另含乳、糖、芝麻或坚果 | 不把现场推销当作购买义务；比较产地标识、等级、包装和可追溯信息 |
| 宣木瓜饮品与酒类 | 宣州区正规零售点 | 代用茶、固体饮料和复合饮料适合小份尝试；宣木瓜黄酒按含酒精饮品对待 | 配方、含糖量和酒精度因产品而异；“药食同源”不能替代配料、禁忌与营养标签 | 选择产品类别、配料和生产信息清楚的包装；避免酒精者只购买标签明确的无酒精产品，不以未经核验的保健功效作为购买依据 |
| 云岭锅巴 | 泾县云岭镇及正规零售点 | 以大米焙烤的锅巴适合分享或途中补充，独食可购买小包装 | 原味与孜然、花椒等调味产品配方不同；不能仅凭“大米”推定成品无麸质或不含其他过敏原 | 查看具体包装的配料、生产许可和保存期限；严重过敏者避免散装、混装与标签不清产品 |

## 经典行程

### 一日经典路线

**路线**：宣城市博物馆 → 谢朓楼遗址—北门老街—三眼井 → 敬亭山下段至经确认开放的主要观景区

- **串联逻辑**：上午先用博物馆建立宣城历史与文房四宝背景，午后在老城找到诗歌与城市遗址，最后向北转到敬亭山。三段之间用公交或出租车衔接，山上只走与余下日照和体力相符的开放路线。
- **预约锚点**：宣城市博物馆入馆规则和敬亭山当日开放；若谢朓楼楼体暂停开放，仍可保留周边遗址与街巷短线。
- **休息区域**：博物馆公共区、老城餐饮区与敬亭山正式服务点。盛夏把山地步行移到较早或较晚时段。
- **时间不足时**：先删老城支巷和敬亭山高处，只保留博物馆、谢朓楼周边与敬亭山低处三个层次。

### 两日城市路线

**第 1 天**：宣城市博物馆 → 宛陵湖短线 → 谢朓楼遗址—北门老街—三眼井。<br>
**第 2 天**：敬亭山半日至一日路线；体力和天气不适合登高时，改为中国鳄鱼湖正式开放游线。

- **串联逻辑**：第一天集中处理城市历史、文房四宝和主城空间，第二天只选城北低山或城南保护科普中的一个方向，避免南北来回赶路。
- **预约锚点**：博物馆、敬亭山或扬子鳄景区；三者开放和活动安排可能变化。
- **休息区域**：第一天在博物馆与老城，第二天使用所选景区的游客中心和正式休息点。
- **时间不足时**：压缩第一天湖区；第二天不把敬亭山和扬子鳄景区硬拼在一起。

### 三日城市与文房路线

**第 1 天**：宣城市博物馆 → 老城历史步行线。<br>
**第 2 天**：敬亭山完整半日至一日 → 返回主城休息。<br>
**第 3 天**：前往泾县 → 中国宣纸文化园 → 泾县县城用餐 → 桃花潭或查济二选一 → 返回或住泾县。

- **串联逻辑**：先在主城了解文房四宝整体，再到泾县的正式展示空间看宣纸工艺；第三天下午只选一个人文景区，不把桃花潭、查济、云岭和月亮湾全部堆在一起。
- **预约锚点**：宣纸文化园的开放、讲解与体验项目，以及所选古村或景区票务；生产展示可能因工序和安全安排调整。
- **休息区域**：主城博物馆、敬亭山服务点、泾县县城或文化园游客区。
- **时间不足时**：第三天只保留宣纸文化园和县城，不在下午临时加入偏远古村或漂流。

### 雨天路线

**路线**：宣城市博物馆 → 就近午餐与休息 → 经确认开放的室内临展、文化活动或住宿区休整

- 普通降雨时让博物馆承担主要内容，老城只走短段，敬亭山、古道和河岸不作为必选项目。
- 暴雨、雷电、大风、山洪或地质灾害预警时，取消敬亭山、徽杭古道、峡谷、桃花潭临水段和全部漂流活动；若公共场馆也临时关闭，直接休整或改期。
- **预约锚点**：博物馆与临展开放，两者可能在同一闭馆日不可用。
- **时间不足时**：只完成已确认开放的博物馆，不用商业作坊或生产车间替代关闭场馆。

### 亲子或低体力路线

**亲子路线**：宣城市博物馆 → 午餐 → 中国鳄鱼湖正式科普游线。<br>
**低体力路线**：宣城市博物馆 → 车辆转场 → 宛陵湖经现场确认平整的短段 → 就近休息。

- **串联逻辑**：亲子路线用室内展览与动物保护科普组合，但保护区内仍需持续看护；低体力路线只选一个室内锚点和一段可随时折返的户外空间。
- **减负方式**：亲子路线不追加漂流、洞穴和山地；低体力路线不默认进入敬亭山台阶段、古村石板长线或老建筑楼梯。
- **预约锚点**：博物馆、扬子鳄景区的儿童规则和科普活动；低体力路线另问上下车点、无障碍入口、座椅和卫生间。
- **时间不足时**：两条路线都只保留博物馆；不为增加数量跨县。

### 绩溪文化一日路线

**路线**：抵达绩溪县城 → 绩溪县博物馆—古城短线 → 当地午餐 → 龙川景区 **或** 徽杭古道短线二选一 → 住绩溪或按已确认交通离开

- **串联逻辑**：县城先提供徽州历史与饮食背景，下午按兴趣选传统村落或山地古道。龙川与徽杭古道不是同一景区，不安排全量串联。
- **预约锚点**：博物馆、所选景区、古道开放范围和返程交通；完整穿越徽杭古道需要另行规划两端接送，不能沿用本路线。
- **休息区域**：绩溪县城、景区游客中心与正式服务点；古道上不依赖临时摊点。
- **时间不足时**：只保留县城与龙川；若天气恶化，删除全部古道和峡谷段。

### 泾县古村一日路线

**路线**：从宣州主城或泾县县城出发 → 桃花潭景区 **或** 查济景区完整游览 → 正式餐饮区休息 → 返回或住泾县

- **串联逻辑**：两处各自足以承担半日至一天，选一处才能把时间留给街巷、水域、建筑与休息；不把月亮湾漂流作为返程前的临时加项。
- **预约锚点**：所选景区门票、渡船或内部交通、返程车辆；临水活动服从水位与天气管理。
- **休息区域**：景区游客中心、村镇正式餐饮与住宿，不在河滩、桥头或公路弯道久留。
- **时间不足时**：保留一个景区核心区，不再绕行云岭、宣纸文化园或水墨汀溪。

## 住宿区域

| 区域 | 优点 | 缺点 | 适合人群 | 交通特点 |
|---|---|---|---|---|
| 宣城站—中心城区 | 抵离方便，餐饮与城市服务集中，前往老城和各县换乘较灵活 | 节假日站区和主干道可能拥堵，部分酒店距景点仍需乘车 | 首访、晚到早走、依赖公共交通者 | 以宣城站为铁路枢纽，公交、出租车与公路客运衔接便利，具体站点和末班需重查 |
| 博物馆—宛陵湖片区 | 靠近博物馆、湖区与较新的城市服务，路线易控制体力 | 与敬亭山、老城和扬子鳄景区都不是连续步行关系 | 亲子、低体力、偏好安静或现代设施者 | 适合车辆分段接送；先确认住宿入口、停车和无障碍设施 |
| 敬亭山南麓与城北 | 清晨或傍晚进入敬亭山较方便，环境相对安静 | 距城南景区、部分餐饮和交通枢纽较远 | 徒步、诗歌文化与摄影旅行 | 进出仍依赖公交或车辆，山门、住宿和具体登山入口不能只凭“敬亭山附近”判断 |
| 泾县县城 | 便于拆分宣纸文化、桃花潭、查济、云岭等方向，减少主城往返 | 各景区仍分散，县城住宿不等于步行可达景点 | 安排泾县两日、文房四宝或古村旅行者 | 可用铁路或公路抵达，再换县域公交、正规客运或预约车辆 |
| 绩溪县城与绩溪北站方向 | 便于组合博物馆、古城、龙川和徽杭古道，徽菜选择集中 | 车站、县城、龙川和古道入口是不同节点 | 徽文化、古道、县域深度旅行者 | 铁路抵达后仍需接驳；完整古道穿越要另安排终点交通 |
| 旌德县城 | 适合文庙、宣砚与村落方向分日安排 | 夜间服务和公共交通选择通常少于主城 | 宣砚、古建与慢节奏县域旅行 | 车站到县城及景区需核对接驳，晚到前先落实入住和用餐 |

不推荐未经核验的具体酒店。预订山区、古村或乡镇住宿时，应确认合法登记、夜间到达方式、取消规则、供暖或空调、电梯、无障碍卫生间、儿童入住和停车条件；只写“景区附近”不足以判断能否步行到入口。

## 市内交通

| 场景 | 建议与取舍 | 行前需要重查的内容 |
|---|---|---|
| 从机场抵达 | 芜湖宣州机场由芜湖、宣城共建，机场主体位于芜湖市境内且靠近两市边界，并不在宣州主城内。使用机场专线、出租车或接送时按实际落地时间选择 | 航线、到达航站楼、机场专线时刻与上下车点、夜间接送和道路施工 |
| 从铁路抵达 | 宣城站是主城主要铁路门户；泾县站、旌德站、绩溪北站、郎溪南站分别服务不同县域方向。车票上的完整站名比“宣城附近”更可靠 | 车次、检票口、换乘时间、县域接驳和末班；宁国南、广德南分别属于独立县级市方向 |
| 主城公交 | 主城公共交通可连接车站、博物馆、老城、敬亭山和扬子鳄景区。2026 年开通的旅游公交 T1 环线曾串联多处核心节点，可作为理解城市方向的参考 | T1 及普通公交是否仍按原线路运行、首末班、票价、临时改道和节假日加班 |
| 主城步行 | 博物馆—宛陵湖和老城内部可分段步行；博物馆、老城、敬亭山与扬子鳄景区之间应乘车 | 人行道施工、景区出入口、夜间照明、湖岸封闭和高温天气 |
| 跨县移动 | 铁路适合宣城站与部分县城之间的长距离骨干移动，公路客运与正规预约车辆负责车站到景区；先选一个县域方向再订票 | 实际班次、发车站、景区接驳、返程余票、行李和儿童票规则 |
| 自驾 | 泾县、绩溪、旌德和郎溪的分散点位更适合有经验的驾驶者，但山路、古村停车与节假日管制会增加负担 | 皖南山区天气、交通管制、停车预约、充电、道路结冰、落石和绕行信息 |
| 水域与漂流 | 普通河湖、保护区水域和货运码头不是公共渡运或自由下水区域；只选择持证、明确营业并提供救生装备的项目 | 运营许可、年龄身高与健康限制、救生衣、保险、水位、雷电和退改规则 |

市域有内河航道和货运码头，但多数承担生产运输功能，不应据地图上的“码头”标记推断存在游客轮渡。进入宣纸、徽墨、宣砚等产业展示空间时同样遵守分区：售票或预约的参观通道与真实生产线可能相邻，现场围栏、人员指引和消防要求优先于旧攻略。

## 不同旅行者须知

| 旅行维度 | 可行条件 | 主要取舍 | 需额外核对 |
|---|---|---|---|
| 独行旅行 | 主城场馆、正式景区和一人小吃易于安排 | 偏远古道、峡谷、漂流和乡村夜路不独自进入；跨县先锁定返程 | 手机信号、景区闭园、末班交通、住宿登记和紧急联络 |
| 亲子旅行 | 博物馆、扬子鳄科普和短距离古村体验可按年龄调整 | 水边、保护区、洞穴、古井、山路和旧建筑需要持续看护；不进入生产设备区 | 儿童票、研学最低人数、体验课年龄、婴儿车寄存、护栏与卫生间 |
| 长者或低体力旅行 | 每天选一个室内锚点和一段平缓户外，用车辆连接 | 敬亭山高处、徽杭古道、峡谷、漂流和古村全程长走不作默认安排 | 下客点、坡度、台阶、电梯、座椅、轮椅借用与可提前退出路线 |
| 无障碍需求 | 可先从宣城市博物馆等现代公共场馆逐处询问 | 单点有坡道或无障碍通道不等于从车站到全部展厅、古街和景区连续可达 | 入口净宽、电梯、无障碍卫生间、轮椅席位、陪同、交通转移与应急疏散；需向官方确认 |
| 摄影旅行 | 敬亭山、老城、古村、文房工艺和水域题材差异大 | 雾、花期、云海与日落无法保证；不翻越护栏、不干扰匠人和保护动物 | 三脚架、闪光灯、无人机、文物展厅、宗教空间、生产线与商业拍摄规则 |
| 预算有限 | 以博物馆、城市街区和公共湖区为主，只选一处付费县域景区 | 多次跨县、包车、漂流与频繁换住宿会迅速增加成本 | 免费预约、优惠资格、联票范围、交通总价与退改 |
| 晚出发或紧凑行程 | 抵达后只安排博物馆、湖区或老城中的一个片区 | 不在下午临时出发去徽杭古道、桃花潭、查济或偏远漂流点 | 最晚入场、闭园、末班、夜间照明和住宿接待时间 |
| 高温与强对流 | 城市步行移到早晚，中午使用博物馆和正式餐饮休息 | 雷电时停止登山、涉水和在孤立高处停留；高温下缩短石板路与无荫路段 | 高温、雷电、大风预警，补水点与中暑应急 |
| 梅雨、台风与汛期 | 保留室内替代日，住宿和交通选择可退改方案 | 强降雨时取消古道、峡谷、漂流、河滩、低洼湖岸和山区自驾 | 暴雨、洪水、地质灾害、景区关闭、道路中断和列车航班变化 |
| 文房四宝与工艺旅行 | 先在博物馆理解材料与流程，再预约正式开放的文化园、展馆或体验区 | 不把销售展示等同于完整工艺，不擅入作坊，不触碰原料、刀具、机械或晾晒制品 | 展示工序、讲解语言、体验内容、拍摄许可、消防与职业安全要求 |
| 山地徒步 | 使用正式开放步道，留足日照、补水和返程时间 | 古道穿越与景区短线不是同一难度；不凭轨迹软件走封闭支线 | 开放区段、天气、接送、救援信号、防滑与个人体能 |
| 漂流与水上活动 | 只参加正规运营项目并全程穿着合格救生衣 | 不饮酒后下水，不携幼儿进入不符合年龄条件的项目，不在自然河段野泳 | 水位、雷电、年龄身高、健康禁忌、救生与保险、退改规则 |
