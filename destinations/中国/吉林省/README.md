# 吉林省旅行目的地

吉林省从松辽平原延伸至长白山地，省内旅行尺度远大于地图上的直线距离。长春的城市历史、电影与汽车工业、雕塑和森林公园是一组城市主题；吉林市的松花江、雾凇与山水格局，延边的朝鲜族文化与边境地区，长白山的火山地貌和高山天气则需要各自独立规划。冬季低温、暴雪、道路结冰和景区季节运营会改变交通与体力成本，不能把全省热门地点都写成“从长春顺路”。

当前目录只收录达到 `researched` 状态的长春城市页。其他吉林城市及区域须在行政边界、交通尺度、季节开放、自然风险和官方来源完成研究后再加入；空模板、自动目录和未研究页面不计入覆盖完成。

## 区域格局与行程组合

- 长春中心城区：宽城老站与伪满皇宫、人民大街、朝阳区新民大街—红旗街—南湖、南部世界雕塑园可依靠轨道交通和短途道路交通分片游览。历史建筑中有学校、医院和办公单位，未经公告不得进入院落。
- 长春东南部净月方向：净月潭、吉林省博物院和长影世纪城都在城市东南，但每一处本身尺度较大。三者可以共享住宿或交通方向，不能因此压成半天“打卡线”。
- 长春东部与市域远点：莲花山、天定山及长春冰雪新天地等项目具有明显季节性，往返交通、雪场规则和低温风险足以占用完整一天；农安、德惠、榆树、公主岭等县市也不按中心城区景点处理。
- 吉林市方向：吉林市是独立的地级市，松花江城市景观、雾凇、北山和松花湖不属于长春。即使铁路可达，也应按另一座城市安排住宿、天气和交通。
- 长白山方向：长白山保护开发区及其各坡景区远离长春，涉及高山天气、景区预约、集散中心与接驳，应按多日区域行程规划，不能列入长春远郊一日游。
- 延边、通化、白山与西部湿地方向：民族文化、边境规则、山地森林和草原湿地条件差异明显，均需独立城市或区域页面承载。
