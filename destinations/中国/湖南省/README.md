# 湖南省旅行目的地

湖南位于中国中南部，省内旅行空间大致由湘江流域、洞庭湖平原、湘西山地和南岭北麓构成。省会长沙是主要综合交通门户；株洲、常德、衡阳与永州分别以铁路工业、沅澧水城、南岳山城和潇湘—南岭县域展开；岳阳位于洞庭湖与长江交汇处；湘潭则以湘江主城、齐白石艺术、工业城市与湘潭县、湘乡、韶山等不同尺度组成。郴州、张家界、湘西等方向仍是相互独立的目的地。

本目录只把达到研究标准的城市页列为已完成内容。城市行政区内的县市、景区和古镇，若具有独立旅行尺度，将在后续核验后单独建页或明确归属；自动生成的空白文件、模板和仅有名称的目录不计入覆盖率。

| 株洲 | 湖南省东部、湘江中游的地级市 | 与长沙、湘潭城际联系紧密，但主城、醴陵、茶陵和炎陵分属不同旅行尺度 | 本目录已有完整城市页；醴陵为法定县级市，仍需独立处理 |

| 岳阳 | 湖南省北部、洞庭湖与长江交汇区域的地级市 | 需要城际铁路或公路移动，不是“长沙远郊”；主城、君山和县域湿地分属不同尺度 | 本目录已有完整城市页；汨罗、临湘为法定县级市，仍需独立处理 |
| 张家界 | 湖南省西北部的地级市 | 与长沙相距较远，通常需要单独住宿和多日安排 | 后续独立建页 |
| 湘潭 | 长株潭城市群中的另一座地级市 | 与长沙、株洲城际联系紧密，但行政、景点统计和行程仍应分开 | 本目录已有完整城市页；湘乡、韶山为法定县级市，仍需独立处理 |
| 湘西、怀化、郴州等方向 | 分布于湖南西部和南部 | 自然条件、交通时间和旅行主题差异较大 | 按城市和行政区逐步研究，不以空页占位 |

长沙可作为省内换乘点，但“能从长沙当天往返”并不等于“属于长沙”。株洲、常德、衡阳、永州与岳阳的主城和县域方向都须分日。岳阳楼景区整体、君山岛、东洞庭湖保护地和长江港航空间具有不同运营与保护边界；功能区不是新增法定县区，汨罗、临湘也不能由岳阳地级市页自动完成。永州的柳宗元文化旅游区、浯溪摩崖、九嶷山和女书文化空间分别按整体去重。生产矿山、港区、冶炼空间、保护地非开放区和农业生产区域均不能作为景点擅自进入。

湘潭的连续主城区仅包括雨湖与岳塘两区的湘江两岸片区；湘潭县是普通县，湘乡和韶山是两个法定县级市。韶山虽可从主城或长沙往返，却有独立铁路、换乘、预约与住宿体系，不列入主城景点表。窑湾历史街区、湘钢文化园、彭德怀纪念地、湘乡书院与韶山纪念地分别按完整空间或运营单元去重；正式工业旅游与生产厂区、开放河岸与水利设施必须分开。

## 浏览与贡献

城市页按固定顺序提供城市速览、空间格局、主要景点、美食、经典行程、住宿区域、交通、不同旅行条件、行前核对和来源记录。长期较稳定的地理关系、游览取舍和餐饮类型写入正文；开放时间、门票、预约、交通班次、临时关闭和极端天气等会变化的信息集中列入“行前核对”。

新增或修订城市页时，应满足以下条件：

- 使用可核验的 GeoNames 和 Wikidata 标识，并明确行政归属；
- 景区及其内部子景点只计算一次，车站、商圈入口和观景节点不冒充独立景点；
- 路线说明串联原因、预约锚点、休息位置和删减顺序，不写成分钟级课表；
- 以政府、官方旅游机构、场馆、景区和公共交通运营方为主要来源；
- 无障碍信息不足时明确写明“需向官方确认”，不从局部设施推断全程连续可达；
- 不推荐未经核验的具体酒店，也不把一家热门餐厅写成唯一选择；
- 新页面只有在主要章节完整、事实与链接通过核验后，才能标记为 `researched`。

## 湖南旅行的通用行前核对

- 通过目的地政府、湖南省文化和旅游厅以及景区或场馆官网，复核开放时间、闭馆日、票务和预约规则。
- 通过铁路官方渠道核对城际列车，通过机场和当地公共交通运营方核对首末班、施工及临时管制。
- 春夏强降雨期间关注湖南省气象部门、水文信息和地质灾害预警；湘江、洞庭湖及山地区域可能因水位、雷暴或持续降雨调整开放。
- 盛夏关注高温、强对流和户外暴晒；冬季关注湿冷、寒潮及山路结冰。
- 涉及国家公园、自然保护区、古建筑、校园和纪念场所时，遵守现场边界、消防、教学和文物保护要求。
