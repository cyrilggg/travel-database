# 湖南省旅行目的地

湖南位于中国中南部，省内旅行空间大致由湘江流域、洞庭湖平原、湘西山地、雪峰山地和南岭北麓构成。省会长沙是主要综合交通门户；株洲、常德、衡阳与永州分别以铁路工业、沅澧水城、南岳山城和潇湘—南岭县域展开；岳阳位于洞庭湖与长江交汇处；湘潭则以湘江主城、齐白石艺术、工业城市与周边县市组成。郴州连接湘南主城、丹霞和南岭远线，邵阳连接宝庆主城、雪峰山地和湘桂边县域，怀化则以鹤城铁路枢纽为起点，向芷江、洪江区、会同、通道和沅陵等彼此独立的广域线路展开。娄底位于湘中，以娄星主城为交通基点，向双峰、新化的名人故居、梯田、溶洞和梅山文化延伸；冷水江与涟源则按独立县级市安排。张家界位于湘西北，以永定城区和天门山为一套城市—山岳单元，以武陵源世界自然遗产为另一套多日峰林单元；湘西州各目的地仍须单独规划。

城市名称链接可直接进入完整指南。县级市、县域景区和古镇按实际旅行尺度区分：能与主城连续游览的内容收入同一城市页，需要长距离接驳、独立住宿或单独预约的目的地，则在表格和正文中明确边界。目前收录 **21 座城市**。

长沙可作为省内换乘点，但“能从长沙当天往返”并不等于“属于长沙”。株洲、常德、衡阳、永州与岳阳的主城和县域方向都须分日。岳阳楼景区整体、君山岛、东洞庭湖保护地和长江港航空间具有不同运营与保护边界；功能区不是新增法定县区，汨罗、临湘也应按独立县级市规划。永州的柳宗元文化旅游区、浯溪摩崖、九嶷山和女书文化空间各自是完整的游览单元。生产矿山、港区、冶炼空间、保护地非开放区和农业生产区域均不能作为景点擅自进入。

湘潭的连续主城区仅包括雨湖与岳塘两区的湘江两岸片区；湘潭县是普通县，[湘乡](湘乡市.md)和[韶山](韶山市.md)是两个独立法定县级市。从主城或长沙前往两市应另算跨城交通、返程和是否换宿，再进入对应指南选择路线。

郴州主城由北湖与苏仙两区共同构成，博物馆、苏仙岭和裕后街可分片组合；高椅岭、飞天山、万华岩与仰天湖均需专门接驳，莽山位于宜章县。资兴是代码 `431081` 的独立法定县级市，从郴州主城前往应另算跨城交通、返程和是否换宿，资兴旅行内容不纳入郴州主城路线。生产矿山、水库作业区和未开放山地不得进入；暴雨、泄洪、地质灾害、浓雾和结冰可能同时改变多个远线，应以当日公告决定是否取消。

邵阳连续主城由双清区、大祥区和北塔区构成。新邵县、邵阳县、隆回县、洞口县、新宁县、绥宁县和城步苗族自治县按县域远线理解，通常不能与主城景点同日密集串联。武冈市 `430581` 与邵东市 `430582` 是邵阳市代管的独立法定县级市，从主城前往应另算跨城交通、返程和是否换宿，两市旅行内容不纳入邵阳主城路线。崀山、南山、黄桑分属新宁、城步、绥宁方向，每条远线通常各需完整一日，跨线串联往往需要住宿。游览时应把同一景区的内部点位看作一个整体；南山景区与候选国家公园、黄桑景区与自然保护区的管理边界不同，未开放保护区、洞穴、峡谷和汛期封控路段不得擅自进入。

怀化连续主城的主要旅行与换乘功能集中在鹤城区；怀化站、怀化南站、图博馆与河岸公共空间仍需城市交通串联。洪江古商城位于市辖洪江区；洪江市则是代码 `431281` 的独立法定县级市，从鹤城前往应另算跨城交通、返程和是否换宿，洪江市旅行内容不纳入怀化主城路线，两者行政边界不能混用。芷江受降旧址和飞虎队纪念馆、会同高椅古村、通道转兵纪念地与侗寨、沅陵龙兴讲寺与二酉山都应按独立县域远线安排。雪峰山是跨县山地概念，公开景区、风景名胜区分级保护地、自然保护地、林业生产区和水利设施须分别识别；铁路货场、国际陆港、科研试验田和机场作业区也不能作为普通景点擅自进入。

娄底连续主城主要位于娄星区；娄底站、娄底南站、市级公共文化场馆和孙水公园仍需城市交通串联。双峰县 `431321`、新化县 `431322` 是普通县，紫鹊界梯田、梅山龙宫和曾国藩故居应按不同县域与运营边界安排。冷水江市 `431381`、涟源市 `431382` 是娄底市代管的独立法定县级市，从主城前往应另算跨城交通、返程和是否换宿，两市旅行内容不纳入娄底主城路线。梯田耕作区、灌溉水渠、生产矿山、尾矿库、废弃矿洞、水库大坝、泄洪区、水源保护区、非开放洞穴与林业生产区均不能作为普通景点擅自进入。

张家界常规抵达与城市服务集中在永定区；天门山从城区方向进入，武陵源则是需要公路转场、再用环保车、索道、电梯和步道组合的大范围山地景区。武陵源世界自然遗产是依法保护的范围，不等同于一张覆盖所有设施的通票；张家界国家森林公园、袁家界、杨家界、天子山、金鞭溪和十里画廊共同构成核心游览单元，不重复拆分。黄龙洞、宝峰湖、慈利县大峡谷与玻璃桥各有独立入口和票务，天门山也不属于武陵源遗产地。芙蓉镇和凤凰古城位于湘西土家族苗族自治州，不属于张家界市。

[吉首](吉首市.md)是湘西土家族苗族自治州州府和独立县级市。乾州古城、老城文博与矮寨—德夯山地分属三种旅行尺度，可先用一天看城市文化，再为矮寨—德夯单列一天；凤凰、花垣等州内县域按各自属地另排交通、住宿和开放核对。

## 浏览与贡献

城市页按固定顺序提供城市速览、空间格局、主要景点、美食、经典行程、住宿区域、交通、不同旅行条件、行前核对和来源记录。长期较稳定的地理关系、游览取舍和餐饮类型写入正文；开放时间、门票、预约、交通班次、临时关闭和极端天气等会变化的信息集中列入“行前核对”。

新增或修订城市页时，应满足以下条件：

- 使用可核验的 GeoNames 和 Wikidata 标识，并明确行政归属；
- 景区及其内部子景点只计算一次，车站、商圈入口和观景节点不冒充独立景点；
- 路线说明串联原因、预约锚点、休息位置和删减顺序，不写成分钟级课表；
- 以政府、官方旅游机构、场馆、景区和公共交通运营方为主要来源；
- 无障碍信息不足时明确写明“需向官方确认”，不从局部设施推断全程连续可达；
- 不推荐未经核验的具体酒店，也不把一家热门餐厅写成唯一选择；
- 提交前确认主要章节完整、事实与链接已经核对，并清楚标明资料更新日期。

- 通过目的地政府、湖南省文化和旅游厅以及景区或场馆官网，复核开放时间、闭馆日、票务和预约规则。
- 通过铁路官方渠道核对城际列车，通过机场和当地公共交通运营方核对首末班、施工及临时管制。
- 邵阳主城与县域远线可分别查看[邵阳市人民政府](https://www.shaoyang.gov.cn/)、[邵阳市文化旅游广电体育局](https://wtgxj.shaoyang.gov.cn/)、[邵阳市交通运输局](https://jtj.shaoyang.gov.cn/)和[邵阳市应急管理局](https://ajj.shaoyang.gov.cn/)；崀山、南山、黄桑、白水洞等行程还需复核所在地政府或景区公告，武冈机场班次以[湖南机场集团](https://www.hunanairport.cn/content/syAirPort.html)为准。
- 怀化主城与广域远线可分别查看[怀化市人民政府](https://www.huaihua.gov.cn/)、[怀化市文化旅游广电体育局](https://www.huaihua.gov.cn/wlgdtj/)、[怀化市交通运输局](https://www.huaihua.gov.cn/jtj/)和[怀化市突发事件预警](https://www.huaihua.gov.cn/huaihua/tfsj/zfxxgkList.shtml)；芷江、洪江区、洪江市、会同、通道和沅陵还需复核属地政府与景区公告，机场班次以[湖南机场集团](https://www.hunanairport.cn/content/hhAirPort.html)为准。
- 娄底主城、双峰和新化远线可分别查看[娄底市人民政府](https://www.hnloudi.gov.cn/)、[湖南省文化和旅游厅娄底信息](https://whhlyt.hunan.gov.cn/whhlyt/news/sxxw/)、[娄底市交通运输局](http://jtj.hnloudi.gov.cn/)和[娄底市应急管理局](https://yjglj.hnloudi.gov.cn/)；紫鹊界、梅山龙宫和曾国藩故居还需复核属地政府、景区或场馆公告，前往冷水江或涟源时另查对应城市的当期信息。
- 张家界行程可分别查看[湖南省政府张家界市概况](https://www.hunan.gov.cn/jxxx/szmp/zjjs/szmp.html)、[武陵源世界自然遗产资料](https://whc.unesco.org/en/list/640/)、[武陵源区通知与旅游资讯](https://www.wlynews.cn/)、[张家界荷花国际机场](https://www.hunanairport.cn/content/zjjAirPort.html)和[湖南省交通运输厅](https://jtt.hunan.gov.cn/)；天门山、武陵源、大峡谷、黄龙洞、宝峰湖与茅岩河的票务和开放状态应按各自运营方当日公告核对。
- 吉首城市与矮寨—德夯行程可查看[吉首市人民政府](https://www.jishou.gov.cn/)、[湘西州文化旅游广电局](https://whlygdj.xxz.gov.cn/)和[湖南省交通运输厅](https://jtt.hunan.gov.cn/)；景区接驳、峡谷天气、活动管制和返程班次按到访日复核。
- 春夏强降雨期间关注湖南省气象部门、水文信息和地质灾害预警；湘江、洞庭湖及山地区域可能因水位、雷暴或持续降雨调整开放。
- 盛夏关注高温、强对流和户外暴晒；冬季关注湿冷、寒潮及山路结冰。
- 涉及国家公园、自然保护区、古建筑、校园和纪念场所时，遵守现场边界、消防、教学和文物保护要求。
