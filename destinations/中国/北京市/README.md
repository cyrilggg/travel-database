# 北京市旅行目的地

北京市既是城市，也是范围广阔的省级行政区。普通城市旅行主要集中在东城、西城、海淀和朝阳的旧城、皇家园林、博物馆与现代公共空间；延庆、怀柔、昌平等方向的长城和陵寝则需要按远郊一日游处理。目录不会把行政区内所有地点误写成可以从市中心顺路抵达，也不会用空白页面代替经过研究的城市指南。

## 区域格局与行程组合

北京核心旅行可按四个层次组织：

- 中轴线与旧城：天坛、前门、天安门广场、故宫、景山、什刹海和钟鼓楼；沿线单位分别预约，不能把整条轴线视作一处景区。
- 西北与北部城区：颐和园、圆明园、奥林匹克公园和中国科学技术馆；每处尺度都很大，跨区组合应保留交通余量。
- 东北现代城区：798 艺术区以及朝阳的现代商业和餐饮区域；适合单独半天，不与西部园林反复横穿。
- 远郊：八达岭与慕田峪属于不同长城方向，一次只选一个；明十三陵内部也由多个分散点位组成。长城和十三陵原则上各留完整一天。
- 城市副中心：[通州](./通州区.md)的大运河文化旅游景区、城市绿心文化设施和环球度假区分属不同组团，适合分日安排；北京中心城区与通州之间按跨区门到门时间比较交通和住宿。

北京市其他远郊区还包含自然、乡村与遗产目的地。只有在资料、交通边界和来源达到城市页质量要求后才会新增记录；自动目录、种子文件和空模板不计入完成数量。
