# 陕西省旅行目的地

陕西横跨关中平原、陕北黄土高原和陕南秦巴山地，省内城市之间的历史主题、自然条件与交通距离差异很大。现有指南覆盖西安、宝鸡与渭南：西安重点整理城墙内外、南部唐文化片区、博物馆群与临潼秦陵之间的空间关系；宝鸡从渭河主城的青铜器与工业遗产出发，向凤翔、岐山—扶风、眉县、陇县和秦岭县域形成多条分支；渭南则以临渭主城为基地，连接华州、渭北历史遗存、黄河湿地以及需另建页的华阴、韩城。

## 区域格局与城市组合

西安市区的城墙核心、雁塔—曲江片区与城北遗址可按半日或一日组合；临潼的秦始皇帝陵博物院位于主城以东，应按独立半日至一日处理。陕西省内其他地级市、县级城市和山地目的地以后分别建立记录，不因能够从西安往返就计入西安市景点完成率。

宝鸡主城区沿渭河谷地展开，宝鸡站、石鼓园—青铜器博物院、金台老城和长乐塬需要跨河或跨塬移动。凤翔区、岐山和扶风的周秦遗址、眉县太白山入口、陇县关山草原以及凤县、太白县的秦岭山地都不是主城顺路加项。周原遗址横跨岐山与扶风，太白山景区入口位于眉县，均应按实际入口和开放边界规划。

渭南以临渭区主城承担博物馆、住宿和综合交通，华州区的渭华起义纪念地与少华山可形成一至两天分支；大荔、合阳、蒲城、白水、澄城、富平和潼关方向各有粮仓、唐陵、古庙、窑址或黄河湿地，需要按县域择一。华阴市与韩城市拥有独立县级行政代码和完整旅行体系，华山按华阴目的地整体去重，不计入渭南主城完成率。
