# 陕西省旅行目的地

陕西横跨关中平原、陕北黄土高原和陕南秦巴山地，省内城市之间的历史主题、自然条件与交通距离差异很大。现有 9 篇指南覆盖西安、宝鸡、渭南、咸阳、铜川、延安、汉中、安康与商洛：关中城市沿平原与北缘台塬展开秦汉唐遗址、文博、帝陵、耀州瓷、药王文化和县域山地；延安以宝塔主城革命旧址、黄土沟壑、黄河景观和分散县域构成陕北长距离旅行体系；汉中、安康和商洛位于秦巴山地及其河谷，分别以汉江谷地、库区湖泊、商於古道和秦岭生态组织行程。

## 区域格局与城市组合

西安市区的城墙核心、雁塔—曲江片区与城北遗址可按半日或一日组合；临潼的秦始皇帝陵博物院位于主城以东，应按独立半日至一日处理。陕西省内其他地级市、县级城市和山地目的地需要分别安排行程，不能仅因能够从西安往返就视为西安市内景点。

宝鸡主城区沿渭河谷地展开，宝鸡站、石鼓园—青铜器博物院、金台老城和长乐塬需要跨河或跨塬移动。凤翔区、岐山和扶风的周秦遗址、眉县太白山入口、陇县关山草原以及凤县、太白县的秦岭山地都不是主城顺路加项。周原遗址横跨岐山与扶风，太白山景区入口位于眉县，均应按实际入口和开放边界规划。

渭南以临渭区主城承担博物馆、住宿和综合交通，华州区的渭华起义纪念地与少华山可形成一至两天分支；大荔、合阳、蒲城、白水、澄城、富平和潼关方向各有粮仓、唐陵、古庙、窑址或黄河湿地，需要按县域择一。华阴市与韩城市拥有独立县级行政代码和完整旅行体系，其旅行内容不纳入渭南主城路线，联程时应另查属地信息。

咸阳的秦都—渭城现代主城、由西咸新区相关功能区管理的秦咸阳城遗址片区、汉阳陵与西部和北部县域帝陵并非一片连续城区。西安与咸阳、西咸新区的交通管理联系不能替代法定行政边界；杨陵区在省民政代码表中仍列于 `610400` 下，但由省级杨凌示范区独立管理，也不并入咸阳主城路线。兴平市和彬州市是代码独立的县级市，两市旅行内容应另查属地交通、住宿与开放信息。各遗址或陵园均按完整游览体系安排，内部建筑和展陈无需另排多站。

铜川由南部新区—耀州、北部王益—印台、耀州西部照金和宜君北部山地构成。新区是位于耀州区代码体系内的功能管理片区，不是新增法定县级行政区；铜川站、铜川北站和宜君站分别服务不同方向，也不表示三站到景区已有高频接驳。黄堡耀州窑遗址与博物馆、陈炉古镇与陈炉博物馆分属两个实际游览节点，但共同构成耀州窑遗产主题，馆、窑址和作坊宜按各自游线连贯安排；照金纪念馆、薛家寨和陈家坡组成一条革命旧址主题线。王石凹仅在明确开放的工业遗址范围内参观，生产矿区、井下巷道、铁路专用线和厂区不得作为游览通道。陈炉、照金、玉华宫、金锁关和宜君在暴雨、雨后地质灾害、冬季结冰或森林高火险时可能限制开放，预警与道路管制优先于既定路线。

延安以宝塔区延河谷地承担革命纪念馆、王家坪、杨家岭、枣园、宝塔山、住宿和综合交通；安塞区适合按半日至一天安排非遗与地方文化。延长、延川、志丹、吴起、甘泉、富县、洛川、宜川、黄龙、黄陵十县分属黄河岸线、西部高原和南部交通走廊，各县远线均需单独处理。子长市是代码 `610681` 的独立县级市，其旅行内容不纳入延安主城与普通县域路线。壶口瀑布位于陕西宜川与山西吉县交界，出发前须确认实际入口、水位、冰情和跨省道路；黄土沟壑在强降雨及雨后存在山洪、滑坡、泥石流和崩塌风险，预警与道路管制优先于既定路线。革命旧址、陵园、石窟、古柏和峡谷均服从文物、生态与景区开放边界，内部单元宜按完整游线连贯参观。

汉中的汉台—南郑主城与汉江两岸可分区组合，褒斜道石门、勉县三国遗存、城固张骞墓与洋县朱鹮保护方向都需要公路或铁路接驳；佛坪、留坝、镇巴等秦巴山地更应独占一日或住宿。汉中市下辖两区九县，没有县级市；县域景点仍是独立旅行单元。张骞墓是丝绸之路系列世界遗产的一个组成部分，褒斜道、武侯墓祠和朱鹮保护区也分别作为完整遗址、景区或保护地理解，非开放保护区、铁路、水库和山林生产道路不能自由进入。

安康以汉滨主城为住宿和综合交通基点，安康博物馆所在的汉江北岸与老城、西城坊一带的南岸需要过江衔接；瀛湖位于主城西南，应围绕当天游船与天气独占半日至一天。石泉、紫阳、岚皋等县域山地与茶区彼此分散，不宜横向压进同一日；旬阳市是代码 `610981` 的独立县级市，应单独安排住宿、交通与行程。高新区、恒口示范区和瀛湖生态旅游区等功能管理称谓不是新增法定县级行政区。瀛湖及内部岛屿属于一个完整湖区运营单元，保护地、茶园、工厂、库区航道和山林生产道路只有明确开放的公众范围可以进入；汛期山洪、滑坡和泥石流预警优先于既定路线。

商洛以商州区主城承担秦岭博物馆、住宿和综合交通，丹凤、商南、柞水、镇安、洛南、山阳六县则分属不同山地与河谷方向。丹凤棣花和商南金丝峡大致位于东向商於古道走廊；柞水牛背梁、柞水溶洞与镇安木王山、塔云山位于另一条南向秦岭山地走廊；洛南位于洛河谷地方向，山阳天竺山与漫川关又形成东南分支。西十高铁已服务商洛西、山阳和漫川关，但车站到古镇、峡谷和森林公园仍需接驳；柞水、镇安相关新站只有正式售票后才可使用。各峡谷、溶洞和森林公园都需要按自己的入口与完整游线安排，不能因同属商洛而压进一日。全市处于秦岭保护范围，保护地、林场、防火区、矿区、水库、电站、铁路工地和农业生产区只有明确开放的公众范围可以进入；森林火险、山洪滑坡、冬季结冰和封路通知优先于既定路线。
