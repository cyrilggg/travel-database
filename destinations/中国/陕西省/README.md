# 陕西省旅行目的地

陕西横跨关中平原、陕北黄土高原和陕南秦巴山地，省内城市之间的历史主题、自然条件与交通距离差异很大。现有指南覆盖西安、宝鸡、渭南、咸阳与汉中：前四座城市沿关中平原展开秦汉唐遗址、文博、帝陵与县域山地；汉中则位于秦巴之间，以汉江主城、两汉三国遗存、秦蜀古道、朱鹮保护与分散县域构成另一套旅行结构。

## 区域格局与城市组合

西安市区的城墙核心、雁塔—曲江片区与城北遗址可按半日或一日组合；临潼的秦始皇帝陵博物院位于主城以东，应按独立半日至一日处理。陕西省内其他地级市、县级城市和山地目的地以后分别建立记录，不因能够从西安往返就计入西安市景点完成率。

宝鸡主城区沿渭河谷地展开，宝鸡站、石鼓园—青铜器博物院、金台老城和长乐塬需要跨河或跨塬移动。凤翔区、岐山和扶风的周秦遗址、眉县太白山入口、陇县关山草原以及凤县、太白县的秦岭山地都不是主城顺路加项。周原遗址横跨岐山与扶风，太白山景区入口位于眉县，均应按实际入口和开放边界规划。

渭南以临渭区主城承担博物馆、住宿和综合交通，华州区的渭华起义纪念地与少华山可形成一至两天分支；大荔、合阳、蒲城、白水、澄城、富平和潼关方向各有粮仓、唐陵、古庙、窑址或黄河湿地，需要按县域择一。华阴市与韩城市拥有独立县级行政代码和完整旅行体系，华山按华阴目的地整体去重，不计入渭南主城完成率。

咸阳的秦都—渭城现代主城、由西咸新区相关功能区管理的秦咸阳城遗址片区、汉阳陵与西部和北部县域帝陵并非一片连续城区。西安与咸阳、西咸新区的交通管理联系不能替代法定行政边界；杨陵区在省民政代码表中仍列于 `610400` 下，但由省级杨凌示范区独立管理，也不并入咸阳主城路线。兴平市和彬州市是代码独立的县级市，茂陵与彬州大佛寺作为咸阳全域延伸出现，并不代表两座城市页已完成。秦咸阳城、汉阳陵、茂陵、乾陵和昭陵均按各自完整遗址或陵园体系去重。

汉中的汉台—南郑主城与汉江两岸可分区组合，褒斜道石门、勉县三国遗存、城固张骞墓与洋县朱鹮保护方向都需要公路或铁路接驳；佛坪、留坝、镇巴等秦巴山地更应独占一日或住宿。汉中市下辖两区九县，没有县级市；县域景点仍是独立旅行单元。张骞墓是丝绸之路系列世界遗产的一个组成部分，褒斜道、武侯墓祠和朱鹮保护区也分别按完整遗址、景区或保护地去重，非开放保护区、铁路、水库和山林生产道路不能自由进入。
