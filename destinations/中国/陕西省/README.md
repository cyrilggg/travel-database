# 陕西省旅行目的地

陕西横跨关中平原、陕北黄土高原和陕南秦巴山地，省内城市之间的历史主题、自然条件与交通距离差异很大。当前以西安作为首个完整城市指南，重点整理城墙内外、南部唐文化片区、博物馆群与临潼秦陵之间的空间关系。

## 城市指南

| 城市 | 旅行重点 | 建议停留 | 状态 | 最近研究 |
|---|---|---:|---|---|
| [西安](./西安市.md) | 秦汉唐考古、明城墙、博物馆、关中面食与临潼秦陵 | 3–5 天 | `researched` | 2026-07-30 |

## 区域格局与城市组合

西安市区的城墙核心、雁塔—曲江片区与城北遗址可按半日或一日组合；临潼的秦始皇帝陵博物院位于主城以东，应按独立半日至一日处理。陕西省内其他地级市、县级城市和山地目的地以后分别建立记录，不因能够从西安往返就计入西安市景点完成率。
