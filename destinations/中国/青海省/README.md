# 青海省旅行目的地

青海位于青藏高原东北部，省内城市、湖区、盐湖、高原牧区和山地之间距离很长，海拔、气候与道路条件也会显著变化。当前首先提供西宁完整指南：它既是一座可独立停留的高原省会，也是前往青海其他市州的重要交通门户，但不能代替整省旅行资料。

## 区域关系

西宁市现辖城东、城中、城西、城北、湟中五区，以及大通回族土族自治县和湟源县。中心城区沿湟水河谷东西展开；塔尔寺位于西宁市湟中区鲁沙尔镇，属于市域远郊，通常需要独立半天至一天。海湖新区是城西区内的城市功能片区，并非独立行政区。

省内常见线路跨越多个市州。青海湖流域涉及海北、海南和海西等地；茶卡盐湖位于海西蒙古族藏族自治州乌兰县；门源回族自治县属于海北藏族自治州；同仁市属于黄南藏族自治州。这些目的地可以从西宁出发，但不计入西宁城市景点完成率，也不应因旅行社使用“西宁周边”一词而被归入西宁市。
