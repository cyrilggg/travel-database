# 青海省旅行目的地

青海位于青藏高原东北部，省内城市、湖区、盐湖、高原牧区和山地之间距离很长，海拔、气候与道路条件也会显著变化。当前提供西宁、海东、同仁与玉树市四座城市指南：西宁是高原省会和省域交通门户，海东以乐都、平安双核心连接河湟文化，[同仁](./同仁市.md)以热贡艺术和隆务河谷为主线，玉树市则以结古主城、嘉那嘛呢和文成公主庙为主线。

## 区域关系

西宁市现辖城东、城中、城西、城北、湟中五区，以及大通回族土族自治县和湟源县。中心城区沿湟水河谷东西展开；塔尔寺位于西宁市湟中区鲁沙尔镇，属于市域远郊，通常需要独立半天至一天。海湖新区是城西区内的城市功能片区，并非独立行政区。

海东市法定代码为 `630200`，现辖乐都、平安二区，以及民和回族土族自治县、互助土族自治县、化隆回族自治县和循化撒拉族自治县。市级规划所称中心城区沿湟水河形成乐都、平安双核心，并涉及互助县河湟新区一带；这不表示六县区构成连续城区。乐都集中市级行政与河湟文博，平安连接海东西站、河湟新区、平安驿和以“西宁”命名的曹家堡机场；民和喇家遗址、互助故土园和北山、化隆夏琼寺、循化撒拉族文化与孟达天池均应按独立县域模块安排。

海东页固定采用 GeoNames `1799471`：2026-07-30 项目快照名称为 `Nianbo`，实时资料在同一编号下使用 `Haidong`，Wikidata `Q984788` 的 `P1566` 与其精确对应。该点位帮助定位乐都居民点，不代替地级市边界；Q984788 中终止于 2013 年的旧统计代码表达也不能覆盖现行 `630200`。

省内常见线路跨越多个市州。青海湖流域涉及海北、海南和海西等地；茶卡盐湖位于海西蒙古族藏族自治州乌兰县；门源回族自治县属于海北藏族自治州；[同仁](./同仁市.md)属于黄南藏族自治州。以上方向可从西宁衔接，但各自按住宿、交通和高原条件安排；同仁的隆务寺、热贡艺术与村落路线由独立页面承接。

## 浏览与贡献

- 城市页只收录达到 `researched` 质量要求的内容；空模板、自动生成目录和未核验页面不列入城市指南。
- 同一景区及其内部殿堂、展厅、观景台或交通项目合并计数；不同地址、不同管理机构和不同参观入口的场馆可以分别记录。
- 开放时间、门票、预约、航班车次、道路管制、宗教场所开放边界和季节活动统一放在城市页“行前核对”，不作为永久事实。
- 新增内容优先引用政府、官方文旅机构、场馆、交通运营方、气象部门及开放地名资料，并注明支持内容和核验日期。
