# 辽宁省旅行目的地

辽宁连接东北平原、辽东山地与渤海、黄海海岸，省内城市的旅行主题差异很大：沈阳、大连、鞍山、抚顺和盘锦分别呈现清前史、海滨、钢铁、煤矿与辽河口湿地；本溪从钢铁山城向洞穴、森林、满族自治县和高句丽山城遗址延伸，葫芦岛则把辽西走廊、兴城古城、渤海海滨、九门口长城和辽西山地连在一座尺度很大的地级市内。城市之间虽有铁路和公路联系，但不能把整个辽宁当作一个可从沈阳当天连续游览的“大景区”。

## 区域格局与城市组合

沈阳位于辽宁中部，是全省铁路与航空交通的重要枢纽。大连位于辽东半岛南端，抚顺在沈阳以东，本溪在沈阳东南方向，三者均为独立的地级市，不属于沈阳市景点范围。前往这些城市需要查询跨城交通，并为换乘和当地移动单独留时。

鞍山位于辽宁中南部，主城的鞍钢博物馆、站前与玉佛山片区需要跨区移动，千山又是完整的一日山地目的地。海城市、台安县和岫岩满族自治县属于鞍山市域，却各有独立县城、乡镇和交通网络；鞍钢生产厂区、矿区和专用铁路也不因邻近博物馆而向普通游客开放。

清代关外三陵中，清福陵和清昭陵位于沈阳，清永陵位于抚顺市新宾满族自治县。规划世界遗产主题线路时，可以跨城组合三陵，但不得把清永陵列为沈阳远郊景点。大连海滨、本溪水洞及抚顺市内的遗址、博物馆同样应在各自城市页中研究。

抚顺主城区沿浑河东西展开，望花的雷锋与煤矿工业主题、新抚—顺城的城市场馆、高尔山和东洲历史空间需要车辆连接。抚顺县、新宾满族自治县和清原满族自治县属于市域却不是主城街区；清永陵与赫图阿拉城在新宾方向，三块石和清原峡谷又各自需要独立一天。生产矿区、水源保护岸线和铁路设施不因地图可见而开放，煤矿博物馆内部设备与正式观景位置按一个工业旅游项目去重。

盘锦主城由兴隆台和双台子两组中心构成，大洼向南连接红海滩、田庄台和滨海湿地，盘山县则展开在北部农业与河流湿地区域。红海滩国家风景廊道内部栈道、碱蓬、稻田和交通节点按同一大型景区去重；辽河口保护地、油田生产区、港区与养殖作业道路不因地图可达而成为公共游览空间。

本溪主城沿太子河分布于平山、溪湖、明山和南芬四区，本溪满族自治县的小市—水洞—森林方向与桓仁满族自治县的五女山—桓龙湖方向都不是主城近郊步行范围。高新区是管理区域而非新增法定县区。本溪水洞内部洞穴、游船和配套项目按一个景区去重，大石湖—老边沟按相连旅游区整体处理，五女山景区与山城遗址也不重复累计；钢铁厂矿、水库水源区和自然保护地仅开放正式公众范围。

葫芦岛的连山区与龙港区组成连续主城区：连山偏铁路、传统商业与城市日常，龙港偏行政商务和龙湾海岸，两区之间仍常需公交或短途车辆。南票区是与主城区分离的市辖区，不是连山—龙港的步行延伸；兴城市是独立的县级市，不是主城海滨街区；绥中县和建昌县是普通县，前者包含九门口长城与东戴河等彼此分散的方向，后者深入辽西山地，龙潭大峡谷通常需要独立一天。

葫芦岛的景点和安全边界也应在省级目录中保持清楚：兴城古城的城墙、钟鼓楼、石坊和文庙按一个古城项目计算；兴城海滨的兴海湾、港口湾、邴家湾、龙回头和兴海栈道按一个海滨风景区计算；龙湾与 313 海滨浴场所在的相邻海滨带不重复计数。觉华岛是另一个完整海岛项目，只从运营方和主管部门确认的兴城陆岛交通码头乘持证客船，并按风浪、海雾、雷暴与海冰核对停复航。九门口只走正式开放长城段，不根据网络轨迹进入“野长城”。港口、船厂、炼化、冶炼、能源设施、铁路专用线、航道和防波堤属于生产或管制空间，不因临海、地图可达或适合摄影而成为公共景点。

跨城组合可按以下原则安排：

- 沈阳与抚顺距离相对较近，仍需按跨城行程核对车次、道路和返程时间；若参观清永陵，通常不能把它当作沈阳市区半日路线。
- 沈阳与本溪可以铁路或公路衔接，自然景区的接驳、天气和季节性开放需要另查。
- 沈阳与鞍山、大连与鞍山均可组合成跨城线路，但千山、县域和两座铁路站的接驳应在鞍山单独核算。
- 沈阳与大连适合组成多城市线路，但应分别住宿或明确计算较长的往返时间，不宜用沈阳城市页代替大连规划。
- 大连市域内部跨度同样很大：旅顺口和金石滩仍属大连，但各自适合独立一天；庄河、瓦房店和长海县方向不能当作主城区随手附带的景点。丹东、营口则是独立地级市，需按跨城行程处理。
- 盘锦宜把红海滩完整一日与兴隆台—双台子城市日分开；田庄台、鼎翔湿地等方向按开放、潮汐、物候和返程择一，不与主城连续步行。
- 葫芦岛可把连山—龙港主城与县级兴城组成两日线；觉华岛、绥中九门口长城和建昌龙潭大峡谷各自再留完整一天。沿辽西走廊衔接锦州或秦皇岛时仍需按实际车站与跨城班次核算，不能把海滨、长城或港区道路视为连续景区。
- 辽宁冬季寒冷，夏季可能出现强降雨；沿海与内陆天气差异明显，应分别查看目的地预报。

## 浏览与贡献

城市页按城市速览、区域关系、景点、美食、路线、住宿、交通、不同旅行者须知、行前核对和来源顺序组织。贡献新城市或更新现有内容时，应优先引用政府、文旅部门、场馆和交通运营方的一手信息，并把长期稳定的空间关系与会变化的票价、预约、班次、临时关闭分开记录。

每个景区只计算一次，内部建筑和展厅不拆成多个“已完成景点”。行政边界也应明确：代管县级市、邻近地级市和跨市景区应依据实际管理关系决定是否独立建页。只有完成研究和来源核验的城市页才可标为 `researched`。
