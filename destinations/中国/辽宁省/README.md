# 辽宁省旅行目的地

辽宁连接东北平原、辽东山地与渤海、黄海海岸，省内城市的旅行主题差异很大：沈阳以清初宫殿与陵寝、近现代历史和工业遗产为主，大连以海滨城市空间见长，鞍山把钢铁工业、玉文化和千山山地结合在一起，本溪和抚顺则分别拥有山地自然景观与工业、历史遗存。城市之间虽有铁路和公路联系，但不能把整个辽宁当作一个可从沈阳当天连续游览的“大景区”。

## 区域格局与城市组合

沈阳位于辽宁中部，是全省铁路与航空交通的重要枢纽。大连位于辽东半岛南端，抚顺在沈阳以东，本溪在沈阳东南方向，三者均为独立的地级市，不属于沈阳市景点范围。前往这些城市需要查询跨城交通，并为换乘和当地移动单独留时。

鞍山位于辽宁中南部，主城的鞍钢博物馆、站前与玉佛山片区需要跨区移动，千山又是完整的一日山地目的地。海城市、台安县和岫岩满族自治县属于鞍山市域，却各有独立县城、乡镇和交通网络；鞍钢生产厂区、矿区和专用铁路也不因邻近博物馆而向普通游客开放。

清代关外三陵中，清福陵和清昭陵位于沈阳，清永陵位于抚顺市新宾满族自治县。规划世界遗产主题线路时，可以跨城组合三陵，但不得把清永陵列为沈阳远郊景点。大连海滨、本溪水洞及抚顺市内的遗址、博物馆同样应在各自城市页中研究。

抚顺主城区沿浑河东西展开，望花的雷锋与煤矿工业主题、新抚—顺城的城市场馆、高尔山和东洲历史空间需要车辆连接。抚顺县、新宾满族自治县和清原满族自治县属于市域却不是主城街区；清永陵与赫图阿拉城在新宾方向，三块石和清原峡谷又各自需要独立一天。生产矿区、水源保护岸线和铁路设施不因地图可见而开放，煤矿博物馆内部设备与正式观景位置按一个工业旅游项目去重。

跨城组合可按以下原则安排：

- 沈阳与抚顺距离相对较近，仍需按跨城行程核对车次、道路和返程时间；若参观清永陵，通常不能把它当作沈阳市区半日路线。
- 沈阳与本溪可以铁路或公路衔接，自然景区的接驳、天气和季节性开放需要另查。
- 沈阳与鞍山、大连与鞍山均可组合成跨城线路，但千山、县域和两座铁路站的接驳应在鞍山单独核算。
- 沈阳与大连适合组成多城市线路，但应分别住宿或明确计算较长的往返时间，不宜用沈阳城市页代替大连规划。
- 大连市域内部跨度同样很大：旅顺口和金石滩仍属大连，但各自适合独立一天；庄河、瓦房店和长海县方向不能当作主城区随手附带的景点。丹东、营口则是独立地级市，需按跨城行程处理。
- 辽宁冬季寒冷，夏季可能出现强降雨；沿海与内陆天气差异明显，应分别查看目的地预报。

## 浏览与贡献

城市页按城市速览、区域关系、景点、美食、路线、住宿、交通、不同旅行者须知、行前核对和来源顺序组织。贡献新城市或更新现有内容时，应优先引用政府、文旅部门、场馆和交通运营方的一手信息，并把长期稳定的空间关系与会变化的票价、预约、班次、临时关闭分开记录。

每个景区只计算一次，内部建筑和展厅不拆成多个“已完成景点”。行政边界也应明确：代管县级市、邻近地级市和跨市景区应依据实际管理关系决定是否独立建页。只有完成研究和来源核验的城市页才可标为 `researched`。
