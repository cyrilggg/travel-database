# 辽宁省旅行目的地

辽宁连接东北平原、辽东山地与渤海、黄海海岸，省内城市的旅行主题差异很大：沈阳、大连、鞍山、抚顺和盘锦分别呈现清前史、海滨、钢铁、煤矿与辽河口湿地；本溪从钢铁山城向洞穴、森林、满族自治县和高句丽山城遗址延伸；丹东沿鸭绿江展开边境城市史、长城与辽东山地；营口把辽河口商埠与湿地、近代海防、鲅鱼圈港城和熊岳温泉放在南北分离的城市结构中；辽阳把白塔古迹、汉魏墓葬壁画、清初城址、工业组团和弓长岭温泉放在同一市域；阜新则从煤矿工业遗产延伸到查海遗址、蒙古贞文化和彰武治沙景观；瓦房店以复州古城、渤海海岸、许屯温泉和县级工业城市为主线。辽西的锦州与葫芦岛又呈现古塔文博、辽沈战役史、渤海海滨、长城和山地等不同主题；两市代管的县级市仍须作为独立城市安排。城市之间虽有铁路和公路联系，但不能把整个辽宁当作一个可从沈阳当天连续游览的“大景区”。

## 区域格局与城市组合

沈阳位于辽宁中部，是全省铁路与航空交通的重要枢纽。大连位于辽东半岛南端，抚顺在沈阳以东，本溪与辽阳分别在沈阳东南和南侧，阜新位于辽西北；这些城市均为独立的地级市，不属于沈阳市景点范围。前往这些城市需要查询跨城交通，并为换乘和当地移动单独留时。

瓦房店位于辽东半岛中西部，是大连代管的独立县级市，不属于大连主城区、旅顺口或金石滩的近郊游览范围。瓦房店站—主城区、复州古城、仙浴湾与驼山等西部海岸、许屯—龙门汤温泉、得利寺山城分属不同交通方向，通常每天选择一个主题。长兴岛经济技术开发区与瓦房店有道路联系，但由开发区独立管理；长琴海岸等公开旅游空间与石化、造船、港口、码头和专用铁路的生产边界必须按当期公告区分。

鞍山位于辽宁中南部，主城的鞍钢博物馆、站前与玉佛山片区需要跨区移动，千山又是完整的一日山地目的地。海城市是鞍山代管的独立法定县级市，从主城前往应另算跨城交通、返程和是否换宿；台安县和岫岩满族自治县是普通县域，也各有独立县城、乡镇和交通网络。鞍钢生产厂区、矿区和专用铁路不因邻近博物馆而向普通游客开放。

辽阳位于沈阳—鞍山交通轴线上，但市域内部仍有明显分区。白塔—文圣主城适合连续安排白塔历史街区、辽阳博物馆和太子河公共河岸；宏伟区的石化生产空间、弓长岭区的矿业—温泉组团及辽阳县都需要另行乘车。灯塔市是辽阳代管的独立法定县级市，从主城前往应另算跨城交通、返程和是否换宿，灯塔旅行内容不纳入辽阳主城路线。辽阳白塔与复建后的广佑寺不能混写成同年代建筑，分散的壁画墓、东京城与东京陵也不能按普通公园自由连穿；厂矿、尾矿库、铁路专用线和汤河水库水源保护区只按正式开放边界活动。

清代关外三陵中，清福陵和清昭陵位于沈阳，清永陵位于抚顺市新宾满族自治县。规划世界遗产主题线路时，可以跨城组合三陵，但不得把清永陵列为沈阳远郊景点。大连海滨、本溪水洞及抚顺市内的遗址、博物馆同样应按各自城市分别安排行程。

抚顺主城区沿浑河东西展开，望花的雷锋与煤矿工业主题、新抚—顺城的城市场馆、高尔山和东洲历史空间需要车辆连接。抚顺县、新宾满族自治县和清原满族自治县属于市域却不是主城街区；清永陵与赫图阿拉城在新宾方向，三块石和清原峡谷又各自需要独立一天。生产矿区、水源保护岸线和铁路设施不因地图可见而开放，煤矿博物馆内部设备与正式观景位置按一个工业旅游项目去重。

阜新主城由海州、细河和太平等组团构成，市博物馆、海州露天矿国家矿山公园、万人坑死难矿工纪念馆和玛瑙街区之间仍需公交或短途车辆。阜新蒙古族自治县的查海、瑞应寺和海棠山分属不同公路方向；彰武县的大清沟或章古台治沙方向只有在具体接待单位、开放入口和返程都得到确认后才能安排，不能当作主城当天顺手附带的点位。矿山公园不等于整座矿坑开放，海棠山景区不等于自然保护区全域开放，治沙试验林、生产矿区、铁路和沙地恢复区均须服从各自管理边界。

盘锦主城由兴隆台和双台子两组中心构成，大洼向南连接红海滩、田庄台和滨海湿地，盘山县则展开在北部农业与河流湿地区域。红海滩国家风景廊道内部栈道、碱蓬、稻田和交通节点按同一大型景区去重；辽河口保护地、油田生产区、港区与养殖作业道路不因地图可达而成为公共游览空间。

本溪主城沿太子河分布于平山、溪湖、明山和南芬四区，本溪满族自治县的小市—水洞—森林方向与桓仁满族自治县的五女山—桓龙湖方向都不是主城近郊步行范围。高新区是管理区域而非新增法定县区。本溪水洞内部洞穴、游船和配套项目按一个景区去重，大石湖—老边沟按相连旅游区整体处理，五女山景区与山城遗址也不重复累计；钢铁厂矿、水库水源区和自然保护地仅开放正式公众范围。

丹东主城主要沿鸭绿江分布于振兴—元宝连续城区，振安连接北部近郊；丹东站、鸭绿江断桥和沿江公共空间可以步行组合，英华山上的抗美援朝纪念馆更适合短途接驳。虎山长城已经进入宽甸满族自治县，宽甸县城、河口、天桥沟和青山沟又分属不同乡镇与公路方向，不能把“虎山—宽甸”理解成主城外的一条连续步道。东港市与凤城市都是丹东代管的独立县级市，从主城前往应另算跨城交通、返程和是否换宿；两市旅行内容不纳入丹东主城路线。

鸭绿江是国际界河，沿江公共空间、断桥景区、口岸限定区、跨江桥梁、铁路设施和水域各有不同开放规则；只能使用公告开放的道路、场馆、码头和持证船舶，不越过护栏或进入海关、边检、军事及其他管制空间。丹东港和东港沿海码头首先是生产运输空间，不能把港池、堆场、养殖作业路或防波堤当作观景通道。鸭绿江口世界遗产组成地、自然保护区和公众观鸟点的边界并不相同，应从当期开放观察点进入，不下潮滩追鸟，也不穿越潮沟、养殖区和保护封闭区。

营口中心城区分成南北两核：站前—西市—老边构成北部城区，辽河老街、老港与渡口、辽河文化产业带、西炮台和大辽河口观鸟方向由此展开；鲅鱼圈—熊岳构成南部城区，月亮湖、山海广场、望儿山和温泉片区之间需要车辆串联。北部老街与部分公共河岸可以连续步行，但营口东站、兰旗机场、西炮台和湿地观察点仍需接驳；南北城区也不能当作一条普通市中心步行轴。

盖州市和大石桥市是营口代管的两座独立县级市。“盖鲅同域”和“大老一体”是区域联系，不会把两座县级市变成鲅鱼圈或老边的街区；从营口主城前往应另算跨城交通、返程和是否换宿，两市旅行内容不纳入营口主城路线。营口港鲅鱼圈港区、钢厂、堆场、油气设施、渔港作业区和铁路专用线首先是生产或管制空间；大辽河口湿地、候鸟栖息地和公共观鸟点也不是同一开放范围，只能使用正式景区、公共道路和公告观察点。

锦州主城以古塔—凌河连续城区为核心，太和向南连接锦州南站和滨海方向；古塔文博片区可以连续步行，辽沈战役纪念馆与滨海笔架山则分别需要城市接驳和独立郊区交通。义县、黑山县是锦州所辖县，奉国寺—万佛堂和黑山阻击战纪念地分属不同县域方向；凌海市、北镇市是锦州代管的独立县级市，从主城前往应另算跨城交通、返程和是否换宿，两市旅行内容不纳入锦州主城路线。笔架山大陆端的现实游览入口常以锦州经济技术开发区或滨海新区表述，法定市辖层级仍需结合太和区核对；早期无居民海岛名录将大、小笔架山岛列于凌海市，这一登记口径也不能用来把大陆端入口、凌海市区和整片海岸合并成一个景区。

笔架山的潮汐天桥只在景区当日判断允许时通行，固定潮汐表、旧攻略和目测退潮都不能替代现场动态潮汐牌与工作人员指挥；风浪、海雾、雷暴或结冰时应改走当期开放的正规交通或取消上岛。锦州港、临港工业设施、盐田、养殖区、铁路专用线和防波堤属于生产或管制空间，不因临海、地图可达或适合摄影而开放，滨海行程只使用正式景区入口和公共道路。

葫芦岛的连山区与龙港区组成连续主城区：连山偏铁路、传统商业与城市日常，龙港偏行政商务和龙湾海岸，两区之间仍常需公交或短途车辆。南票区是与主城区分离的市辖区，不是连山—龙港的步行延伸；兴城市是独立法定县级市，从主城前往应另算跨城交通、返程和是否换宿；绥中县和建昌县是普通县，前者包含九门口长城与东戴河等彼此分散的方向，后者深入辽西山地，龙潭大峡谷通常需要独立一天。

葫芦岛市域内的海滨、海岛、长城和山地不构成连续景区，独立运营项目须分别核对票务、停复航和道路。兴城市的旅行内容不纳入葫芦岛主城路线；九门口只走正式开放长城段，不根据网络轨迹进入“野长城”。港口、船厂、炼化、冶炼、能源设施、铁路专用线、航道和防波堤属于生产或管制空间，不因临海、地图可达或适合摄影而成为公共景点。

跨城组合可按以下原则安排：

- 沈阳与抚顺距离相对较近，仍需按跨城行程核对车次、道路和返程时间；若参观清永陵，通常不能把它当作沈阳市区半日路线。
- 沈阳与本溪可以铁路或公路衔接，自然景区的接驳、天气和季节性开放需要另查。
- 沈阳与鞍山、大连与鞍山均可组合成跨城线路，但千山、县域和两座铁路站的接驳应在鞍山单独核算。
- 辽阳位于沈阳—鞍山交通轴线上，可与两城组成多城市线路；白塔—文圣主城可以作为一站，弓长岭、辽阳县和灯塔市则需另留半日至一天，不能因铁路距离较近而压缩成同一城区路线。
- 阜新可与沈阳按实际铁路或公路班次组合，但主城、阜蒙县和彰武县要分别计算接驳与返程；海棠山、查海和彰武治沙方向不宜在同一天跨县串联。
- 沈阳与大连适合组成多城市线路，但应分别住宿或明确计算较长的往返时间，不宜用沈阳城市页代替大连规划。
- 大连主城区、旅顺口、金石滩与瓦房店之间跨度很大：旅顺口和金石滩各适合独立一天，瓦房店则应作为独立县级市，按跨城交通、返程和是否换宿安排，并使用瓦房店城市指南规划当地行程；庄河、长海县与营口也都应按各自目的地规划。
- 营口可与盘锦、鞍山或大连沿铁路和公路组合，但北部主城与鲅鱼圈—熊岳仍需分别计算接驳；盖州和大石桥是独立县级市，应另算跨城交通、返程和是否换宿。大辽河口观鸟、海滨浴场、温泉和港区道路都需要当期核对，不能用跨城到达时间代替片区内移动。
- 丹东可从沈阳、大连或本溪按实际铁路与公路班次衔接，主城与虎山—宽甸方向分别计算接驳与返程；东港和凤城是独立县级市，应另算跨城交通、返程和是否换宿。边境口岸等动态开放事项不能用跨城到达时间代替当日核对。
- 盘锦宜把红海滩完整一日与兴隆台—双台子城市日分开；田庄台、鼎翔湿地等方向按开放、潮汐、物候和返程择一，不与主城连续步行。
- 锦州可与盘锦、葫芦岛沿辽西走廊组合，但古塔—凌河主城、笔架山滨海、义县和黑山仍是不同方向；凌海和北镇是独立县级市，应另算跨城交通、返程和是否换宿。潮汐、县域末班与港区道路不能按铁路城市间距压缩。
- 葫芦岛可把连山—龙港主城与绥中九门口长城或建昌龙潭大峡谷分日安排；兴城是独立县级市，只作为跨城联程另算交通、返程和是否换宿。沿辽西走廊衔接锦州或秦皇岛时仍需按实际车站与跨城班次核算，不能把海滨、长城或港区道路视为连续景区。
- 辽宁冬季寒冷，夏季可能出现强降雨；沿海与内陆天气差异明显，应分别查看目的地预报。

## 浏览与贡献

城市页按城市速览、区域关系、景点、美食、路线、住宿、交通、不同旅行者须知、行前核对和来源顺序组织。贡献新城市或更新现有内容时，应优先引用政府、文旅部门、场馆和交通运营方的一手信息，并把长期稳定的空间关系与会变化的票价、预约、班次、临时关闭分开记录。

每个景区按整体理解，内部建筑和展厅不拆成多个目的地。行政边界也应明确：代管县级市、邻近地级市和跨市景区各有自己的城区、住宿与交通条件，应按实际管理关系和旅行尺度分别安排。标记为 `researched` 的城市指南已经过资料与来源核验，但仍需在出发前重查动态信息。
