# 新疆维吾尔自治区旅行目的地

新疆地域辽阔，天山、阿尔泰山、昆仑山及两大盆地把城市分成多个旅行尺度。乌鲁木齐是自治区首府和重要航空、铁路枢纽，但伊犁河谷、阿勒泰、喀什、和田、吐鲁番、哈密、巴音郭楞等方向都有独立的城市、气候和交通结构，不能因为常从乌鲁木齐中转，就并入乌鲁木齐城市指南或城市景点范围。

当前已完成 **5 座城市**的完整指南。乌鲁木齐指南覆盖中心城区、城市东北和北部专题场馆，以及行政上属于乌鲁木齐县、但需要整日公路安排的天山大峡谷与南山方向。石河子指南以军垦文博、旧工业记忆、绿洲城市和玛纳斯河水系为主线，并把一五二团、一四三团、第八师治理范围与石河子市法定市域分别说明。库尔勒指南以巴州文博、孔雀河城市水系、铁门关和香梨文化为主线，并把县级市法定市域、自治州集散功能与博湖、尉犁、轮台等跨县目的地分开。阿克苏指南以地区文博院、多浪河、绿洲湿地和阿克苏老街为主线，并把县级市法定市域、地区驻地功能、阿依库勒镇远点以及温宿、拜城、库车、沙雅、阿瓦提等跨县市目的地分开。喀什指南以古城、高台民居、地区博物馆、香妃园和南疆餐饮为主线，并把县级市、地区驻地与帕米尔高原、塔什库尔干及其他跨县目的地分开。其他城市和自治州将在独立研究后逐页加入；空目录、模板、自动生成名称和未研究页面均不算完成。

## 区域格局与城市组合

| 区域方向 | 代表城市或地区 | 旅行条件 | 主要边界与组合规则 |
|---|---|---|---|
| 乌鲁木齐与天山北坡 | 乌鲁木齐、昌吉、阜康、石河子、玛纳斯、沙湾等 | 城市和交通枢纽较集中，但市区、团场、绿洲农业、水利设施与山地景区仍是不同尺度 | 乌鲁木齐县南山属于乌鲁木齐远郊；天山天池位于阜康市；石河子是独立的自治区直辖县级市，不能并入乌鲁木齐或把第八师所有团场都算作石河子市区 |
| 东疆 | 吐鲁番、哈密 | 荒漠、绿洲、遗址与极端高温并存，景点常散布在城区之外 | 铁路能快速连接不代表景点可无缝当天往返；吐鲁番和哈密都应建立独立城市页 |
| 伊犁河谷与博尔塔拉 | 伊宁、霍尔果斯、昭苏、特克斯、博乐等 | 山地、草原、口岸与河谷城市并存，花期、道路、景区接驳和跨县距离影响很大 | 通常从乌鲁木齐使用航空、铁路或长途公路另行成段，不属于首府近郊 |
| 阿勒泰、塔城与克拉玛依方向 | 阿勒泰、布尔津、塔城、克拉玛依等 | 城市、荒漠、湖泊与山地景区距离长，冬季冰雪和夏季公路的旅行逻辑不同 | 应按实际过夜地和景区入口规划，不能用“北疆环线”替代城市归属 |
| 南疆西部 | 喀什、阿图什、和田等 | 历史城市、绿洲、山地和长距离交通并存，部分线路涉及更高海拔或边境地区 | 从乌鲁木齐转机或转车只是交通关系；证件、道路和具体地区规则须按目的地官方信息核验 |
| 天山南麓与塔里木盆地北缘 | 库尔勒、轮台、库车、阿克苏等 | 城市间距离大，遗址、峡谷、胡杨与沙漠点位常需公路接驳；高温、严寒、风沙和道路状态会改变当日可行性 | 库尔勒与阿克苏都是自治州或地区驻地的县级市。博斯腾湖、罗布人村寨和轮台胡杨林分别核对博湖、尉犁、轮台入口；天山托木尔景区和柯柯牙纪念馆在温宿县，克孜尔石窟在拜城县，库车、沙雅和阿瓦提的景区也不能因从阿克苏集散而并入阿克苏市 |

新疆行程最常见的边界误判，是把交通集散地当成景点归属地。天山天池虽然常见乌鲁木齐出发的一日产品，行政上位于昌吉回族自治州阜康市；吐鲁番虽然可由铁路衔接，却是独立地级市。相反，天山大峡谷和水西沟、白杨沟等南山方向位于乌鲁木齐县，可以进入乌鲁木齐页，但应按远郊整日项目而非市区顺路点处理。

石河子的边界还多一层兵团治理关系。石河子市是行政区划代码 **659001** 的自治区直辖县级市；新疆生产建设兵团第八师与石河子市实行特殊的师市管理体制，但第八师分散的团场、生产区和管理范围不能自动等同于石河子市法定市域。石河子镇是另有基层建制的镇，不是整座石河子市的简称；普通团场、农田、院校、科研、工业、水利和军事管理设施也不因师市联系而成为开放景点。

资料标识同样需要分清：石河子城市驻地点使用 **GeoNames 1529195**，城市实体使用 **Wikidata Q848680**，法定行政代码为 **659001**。Q848680 的 GeoNames 属性仍保留旧号 1529194，因此旧号只作为跨资料识别记录，不另算一个城市。石河子花园机场是中心城区以外的到达节点，一四三团桃源旅游区属于区域联游尺度，军垦第一连位于一五二团山前方向；三者都应按实际入口、车程和开放信息安排，而不是作为中心城区步行点。

库尔勒的行政身份与集散功能也需分别记录。巴州官方行政区划显示，自治州下辖八县一市，州府设在库尔勒；库尔勒是行政区划代码 **652801** 的县级市。其城市点使用 **GeoNames 1529376**，城市实体使用 **Wikidata Q837425**；GeoNames 的 PPLA2 标记说明城市承担第二级行政区驻地功能，不表示它是地级市。库尔勒市域可纳入孔雀河—天鹅河开放游览段、铁门关、龙山和明确接待游客的香梨乡村点，但油田、军事、水利、农业生产设施以及巴州其他县的景区都不因集散关系成为城市景点。

从库尔勒跨县组合时，应以实际景区入口而不是“库尔勒出发”产品名判断归属。博斯腾湖大河口和莲海世界等核心游览区应查询博湖县入口，罗布人村寨与相关沙漠体验应查询尉犁县入口，塔里木胡杨林公园应查询轮台县入口；每个方向都需独立核算单程车程、季节、开放、返程和当晚住宿。铁门关景区位于库尔勒北郊，与独立的铁门关市也不是同一目的地。

阿克苏的行政身份与地区集散功能同样需要分开。阿克苏市是行政区划代码 **652901** 的县级市，也是阿克苏地区行政公署驻地；城市驻地点使用 **GeoNames 1529660**，城市实体使用 **Wikidata Q421648**。GeoNames 的 PPLA2 标记表示城市承担第二级行政区驻地功能，不表示它是地级市。阿克苏市内可纳入地区文博院、多浪河、国家湿地公园、老街和依法开放的市域度假区，但果园、农场、林场、水利、油气、工业和军事设施不因位于市域或靠近公共道路而成为景点。

从阿克苏跨县市组合时，也应按实际入口判断归属。柯柯牙纪念馆和天山托木尔景区在温宿县，克孜尔石窟在拜城县，库车王府、龟兹小巷和天山神秘大峡谷应查库车市公告，胡杨与沙漠体验应按沙雅县等实际入口核对，刀郎部落应查阿瓦提县。柯柯牙绿化工程跨越不同管理和使用范围，只有主管部门公布的游客入口可进入；果园、苗圃、林带、水渠、泵站和内部道路不作为临时替代景点。

喀什的城市名称与地区名称相同，行政层级必须分别记录。喀什市是行政区划代码 **653101** 的县级市，也是喀什地区行政公署驻地；城市驻地点使用 **GeoNames 1280849**，城市实体使用 **Wikidata Q170521**，两者的 GeoNames 标识精确对应。GeoNames 的 PPLA2 标记表示喀什市承担第二级行政区驻地功能，不表示它是地级市。古城、高台民居、香妃园、地区博物馆和市域内明确开放的遗址可以进入喀什市页，但同一景区的街巷、宗教建筑、墓园、展陈和演艺不拆成多个景点。

从喀什跨县组合时，应按实际行政区、入口和过夜地判断归属。疏附县、疏勒县、岳普湖县、莎车县等各有独立景区；帕米尔高原常见路线还会跨越克孜勒苏柯尔克孜自治州阿克陶县与喀什地区塔什库尔干塔吉克自治县。白沙湖、喀拉库勒湖、慕士塔格峰、石头城、盘龙古道和红其拉甫口岸不是喀什市远郊，必须独立核算高海拔、长距离道路、边境管理、有效证件、住宿、天气和返程条件。

跨区域组合至少要分别核算四项：实际到发站或机场、抵达后的最后一段交通、目的地海拔与天气、当晚住宿地。新疆地图上的相邻城市可能仍相距数小时，山区和荒漠道路也会因季节、施工和预警改变可行性。固定页面只记录长期结构，具体班次、票价、道路和开放状态留到出发前确认。
