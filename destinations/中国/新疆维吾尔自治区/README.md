# 新疆维吾尔自治区旅行目的地

新疆地域辽阔，天山、阿尔泰山、昆仑山及两大盆地把城市分成多个旅行尺度。乌鲁木齐是自治区首府和重要航空、铁路枢纽，但伊犁河谷、阿勒泰、喀什、和田、吐鲁番、哈密、巴音郭楞等方向都有独立的城市、气候和交通结构，不能因为常从乌鲁木齐中转，就并入乌鲁木齐城市页或景点完成率。

当前仅完成乌鲁木齐的完整指南。乌鲁木齐页覆盖中心城区、城市东北和北部专题场馆，以及行政上属于乌鲁木齐县、但需要整日公路安排的天山大峡谷与南山方向。其他城市和自治州将在独立研究后逐页加入；空目录、模板、自动生成名称和未研究页面均不算完成。

## 区域格局与城市组合

| 区域方向 | 代表城市或地区 | 旅行条件 | 与乌鲁木齐的关系 |
|---|---|---|---|
| 乌鲁木齐与天山北坡 | 乌鲁木齐、昌吉、阜康、石河子等 | 城市和交通枢纽较集中，但市区、近郊山地与相邻地州仍是不同尺度 | 乌鲁木齐县南山属于乌鲁木齐远郊；天山天池位于昌吉回族自治州阜康市，应单独计算 |
| 东疆 | 吐鲁番、哈密 | 荒漠、绿洲、遗址与极端高温并存，景点常散布在城区之外 | 铁路能快速连接不代表景点可无缝当天往返；吐鲁番和哈密都应建立独立城市页 |
| 伊犁河谷与博尔塔拉 | 伊宁、霍尔果斯、昭苏、特克斯、博乐等 | 山地、草原、口岸与河谷城市并存，花期、道路、景区接驳和跨县距离影响很大 | 通常从乌鲁木齐使用航空、铁路或长途公路另行成段，不属于首府近郊 |
| 阿勒泰、塔城与克拉玛依方向 | 阿勒泰、布尔津、塔城、克拉玛依等 | 城市、荒漠、湖泊与山地景区距离长，冬季冰雪和夏季公路的旅行逻辑不同 | 应按实际过夜地和景区入口规划，不能用“北疆环线”替代城市归属 |
| 南疆西部 | 喀什、阿图什、和田等 | 历史城市、绿洲、山地和长距离交通并存，部分线路涉及更高海拔或边境地区 | 从乌鲁木齐转机或转车只是交通关系；证件、道路和具体地区规则须按目的地官方信息核验 |
| 天山南麓与塔里木盆地北缘 | 库尔勒、轮台、库车、阿克苏等 | 城市间距离大，遗址、峡谷、胡杨与沙漠点位常需公路接驳 | 适合按城市和过夜地分段维护，不能把所有景点统称为“乌鲁木齐出发南疆游” |

新疆行程最常见的边界误判，是把交通集散地当成景点归属地。天山天池虽然常见乌鲁木齐出发的一日产品，行政上位于昌吉回族自治州阜康市；吐鲁番虽然可由铁路衔接，却是独立地级市。相反，天山大峡谷和水西沟、白杨沟等南山方向位于乌鲁木齐县，可以进入乌鲁木齐页，但应按远郊整日项目而非市区顺路点处理。

跨区域组合至少要分别核算四项：实际到发站或机场、抵达后的最后一段交通、目的地海拔与天气、当晚住宿地。新疆地图上的相邻城市可能仍相距数小时，山区和荒漠道路也会因季节、施工和预警改变可行性。固定页面只记录长期结构，具体班次、票价、道路和开放状态留到出发前确认。

- 铁路到发站、车次、票务与实名规则：[中国铁路 12306](https://www.12306.cn/)
- 航班、机场运行和民航安全规则：[中国民用航空局新疆管理局](https://xj.caac.gov.cn/)

- 涉及边境、特殊区域、自驾证件或特定户外活动时，只采用目的地政府、主管部门和景区的当期正式公告，不根据旅行平台传言推断。
