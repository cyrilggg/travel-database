# 新疆维吾尔自治区旅行目的地

新疆地域辽阔，天山、阿尔泰山、昆仑山及两大盆地把城市分成多个旅行尺度。乌鲁木齐是自治区首府和重要航空、铁路枢纽，但伊犁河谷、阿勒泰、喀什、和田、吐鲁番、哈密、巴音郭楞等方向都有独立的城市、气候和交通结构，不能因为常从乌鲁木齐中转，就并入乌鲁木齐城市指南或城市景点范围。

本索引现收录 **35 座城市或县域目的地**的完整指南。各页分别说明法定市域、地州、县域或兵团管理范围、跨县市目的地与生产保护边界；[阿拉山口](./阿拉山口市.md)以国门口岸史、英雄山和艾比湖北岸胡杨为主线，[霍尔果斯](./霍尔果斯市.md)以国门展陈、边境合作中心和口岸城市生活为主线，[霍城](./霍城县.md)与[新源](./新源县.md)分别按伊犁河谷西部历史花田线和东部那拉提草原线组织。[阜康](./阜康市.md)适合把城区补给与天山天池完整日组合，[库车](./库车市.md)则按老城、丝路遗产和独库公路南段分日安排；[奎屯](./奎屯市.md)适合以公园水系和夜间街区为城市主线，再衔接独库、乌苏或独山子。[铁门关](./铁门关市.md)与[可克达拉](./可克达拉市.md)分别从第二师、第四师城市核心进入，分散团场按真实距离拆成独立方向。

新增的哈密指南以伊州区丝路文博、大海道雅丹、东天山及巴里坤、伊吾两个县域模块为主线，并单列第十三师新星市边界；博乐指南以博州文博、博尔塔拉河和赛里木湖为主线，把精河、温泉、阿拉山口及第五师双河市从县级市法定范围中分开。阿勒泰指南以地区文博、克兰河、桦林公园、将军山和阿禾公路市域段为主线，区分县级阿勒泰市、阿勒泰地区以及布尔津、富蕴等跨县目的地。

克拉玛依市是行政区划代码 **650200** 的地级市，下辖克拉玛依区、白碱滩区、乌尔禾区和独山子区，没有下辖县或独立县级市。克拉玛依区是主城住宿与石油文化中心，白碱滩和乌尔禾位于北向公路模块，独山子则是与主城相隔很远的南部分离片区。四区行政上属于同一市，不等于适合在一天内连续游览。

用于跨资料识别的 **GeoNames 1529401** 与城市实体 **Wikidata Q658240** 的 GeoNames 属性相对应，法定边界仍以 650200 和政府区划资料为准。世界魔鬼城位于乌尔禾区，百里油区正式景区位于白碱滩区，独山子大峡谷和独库公路博物馆按独山子模块安排。抽油机、管线或炼化装置可见，不代表油田生产路、井场、集输站、储罐区或厂区开放；只进入公共道路、依法运营景区和运营单位明确接待的线路。

阿勒泰市是行政区划代码 **654301** 的县级市，也是阿勒泰地区行政公署驻地。固定城市点 **GeoNames 1529651** 的主记录名为 `Jinshanlu`、类别为 `PPLA2`，而法定城市实体 **Wikidata Q434924** 的 P1566 精确对应 1529651；这个标签只用于定位地区驻地所在主城点，不表示整座县级市等于金山路街道，更不能把阿勒泰地区全域并入阿勒泰市。金山路街道另有实体 **Wikidata Q14147886**，且没有 P1566，正好说明居民点标签、街道建制、县级市和地区是四个不同粒度。

阿勒泰市页纳入地区博物馆、克兰河、桦林公园、将军山以及依法开放的市域远点；阿禾公路按阿勒泰市境内且当期开放的路段规划。[布尔津](./布尔津县.md)页面承接喀纳斯、禾木和五彩滩，[富蕴](./富蕴县.md)页面承接可可托海及三号矿脉，[北屯](./北屯市.md)页面承接第十师军垦与团场方向。山区雪崩沟、未开放冰雪区、边境管理区、牧业和林业生产道路、湿地与水源保护空间均按主管部门开放边界通行。

新疆行程最常见的边界误判，是把交通集散地当成景点归属地。阜康市是独立县级市，从乌鲁木齐跨城游览须另查属地信息；吐鲁番虽然可由铁路衔接，却是独立地级市。相反，天山大峡谷和水西沟、白杨沟等南山方向位于乌鲁木齐县，可以进入乌鲁木齐页，但应按远郊整日项目而非市区顺路点处理。

昌吉市是行政区划代码 **652301** 的县级市，也是昌吉州州府。固定清单中的 **GeoNames 1529569** 是类型为 PPLA2 的昌吉主城居民点；法定城市实体使用 **Wikidata Q994523**，但该实体目前没有 P1566，1529569 被挂在无中文标签和行政层级声明的点实体 **Q28794358** 上。因此地名点只用于定位主城，县级市范围、州府功能和昌吉州全域不能相互替代。

昌吉与乌鲁木齐相邻并共享重要交通联系，乌鲁木齐机场、乌鲁木齐站和乌鲁木齐景点按乌鲁木齐行程安排。天山天池位于独立的阜康市；北庭故城和江布拉克分别按吉木萨尔县、奇台县核对。昌吉市政府区划页的面积统计注明“含兵团”，第六师[五家渠市](./五家渠市.md)及团场仍按兵团属地组织旅行。S101 昌吉段、天山保护地、农牧业与工业园区分别使用公开道路、开放入口和接待区域。

吐鲁番市是行政区划代码 **650400** 的地级市，下辖高昌区、鄯善县和托克逊县。开放地名资料中，**GeoNames 1529114** 定位高昌主城居民点，Wikidata 将该编号关联到 **Q192564 高昌区**；法定地级吐鲁番市使用 **Wikidata Q868527**，其 GeoNames 属性为 1529113。这个粒度差异说明居民点、高昌区和吐鲁番全市不能互相替代，也不能把鄯善和托克逊写成高昌城区。

吐鲁番跨区县组合须按真实入口拆分。交河故城、坎儿井、葡萄沟、火焰山和高昌故城集中在高昌区不同方向；吐峪沟和库木塔格沙漠属于鄯善县模块，托克逊县又是另一方向。坎儿井仍是受保护的水利系统，遗址、竖井、暗渠、农田、晾房和生产道路均以正式游客入口为界；阿斯塔那古墓群与吐鲁番博物馆的关闭、复开信息须分别查询文物和场馆公告。

伊宁市是行政区划代码 **654002** 的县级市，也是伊犁州首府。开放地名资料中，**GeoNames 1529435** 记录名为 `Ghulja`、类别为 `PPLA2`，定位伊宁主城居民点与州府；法定伊宁市使用 **Wikidata Q866021**，其 GeoNames 属性为 8563527。`PPLA2` 只表示第二级行政区驻地功能，不把伊宁市变成地级市；外文名、居民点坐标、县级市法定范围和伊犁州全域也不能相互替代。

伊宁跨县市组合还需考虑 2025 年区划调整：胡地亚于孜镇、阿热吾斯塘镇已由伊宁县划归伊宁市，但伊宁县仍是独立普通县。霍尔果斯市和奎屯市均为伊犁州直属的独立县级市，霍城县、新源县、特克斯县、昭苏县等也各有属地边界；赛里木湖位于博州博乐市境内。州博物馆展示全州历史、交通产品从伊宁出发，都不改变上述景点归属。六星街和喀赞其是居民生活社区，伊犁河兼具生态与防洪功能，北部牧道、草场、矿业、农业和水利生产空间不作为自由游线。

石河子的边界还多一层兵团治理关系。石河子市是行政区划代码 **659001** 的自治区直辖县级市；新疆生产建设兵团第八师与石河子市实行特殊的师市管理体制，但第八师分散的团场、生产区和管理范围不能自动等同于石河子市法定市域。石河子镇是另有基层建制的镇，不是整座石河子市的简称；普通团场、农田、院校、科研、工业、水利和军事管理设施也不因师市联系而成为开放景点。

资料标识同样需要分清：石河子城市驻地点使用 **GeoNames 1529195**，城市实体使用 **Wikidata Q848680**，法定行政代码为 **659001**。Q848680 的 GeoNames 属性仍保留旧号 1529194，因此旧号只作为跨资料识别记录，避免把同一座城市误认成两个地点。石河子花园机场是中心城区以外的到达节点，一四三团桃源旅游区属于区域联游尺度，军垦第一连位于一五二团山前方向；三者都应按实际入口、车程和开放信息安排，而不是作为中心城区步行点。

库尔勒的行政身份与集散功能也需分别记录。巴州官方行政区划显示，自治州下辖八县一市，州府设在库尔勒；库尔勒是行政区划代码 **652801** 的县级市。其城市点使用 **GeoNames 1529376**，城市实体使用 **Wikidata Q837425**；GeoNames 的 PPLA2 标记说明城市承担第二级行政区驻地功能，不表示它是地级市。库尔勒市域可纳入孔雀河—天鹅河开放游览段、铁门关、龙山和明确接待游客的香梨乡村点，但油田、军事、水利、农业生产设施以及巴州其他县的景区都不因集散关系成为城市景点。

从库尔勒跨县组合时，应以实际景区入口而不是“库尔勒出发”产品名判断归属。博斯腾湖大河口和莲海世界等核心游览区应查询博湖县入口，罗布人村寨与相关沙漠体验应查询尉犁县入口，塔里木胡杨林公园应查询轮台县入口；每个方向都需独立核算单程车程、季节、开放、返程和当晚住宿。铁门关景区位于库尔勒北郊，与独立的铁门关市也不是同一目的地。

阿克苏的行政身份与地区集散功能同样需要分开。阿克苏市是行政区划代码 **652901** 的县级市，也是阿克苏地区行政公署驻地；城市驻地点使用 **GeoNames 1529660**，城市实体使用 **Wikidata Q421648**。GeoNames 的 PPLA2 标记表示城市承担第二级行政区驻地功能，不表示它是地级市。阿克苏市内可纳入地区文博院、多浪河、国家湿地公园、老街和依法开放的市域度假区，但果园、农场、林场、水利、油气、工业和军事设施不因位于市域或靠近公共道路而成为景点。

从阿克苏跨县市组合时，也应按实际入口判断归属。柯柯牙纪念馆和天山托木尔景区在温宿县，克孜尔石窟在拜城县；库车市是独立县级市，具体游览须另查属地信息；胡杨与沙漠体验应按沙雅县等实际入口核对，刀郎部落应查阿瓦提县。柯柯牙绿化工程跨越不同管理和使用范围，只有主管部门公布的游客入口可进入；果园、苗圃、林带、水渠、泵站和内部道路不作为临时替代景点。

喀什的城市名称与地区名称相同，行政层级必须分别记录。喀什市是行政区划代码 **653101** 的县级市，也是喀什地区行政公署驻地；城市驻地点使用 **GeoNames 1280849**，城市实体使用 **Wikidata Q170521**，两者的 GeoNames 标识精确对应。GeoNames 的 PPLA2 标记表示喀什市承担第二级行政区驻地功能，不表示它是地级市。古城、高台民居、香妃园、地区博物馆和市域内明确开放的遗址可以进入喀什市页，但同一景区的街巷、宗教建筑、墓园、展陈和演艺不拆成多个景点。

从喀什跨县组合时，应按实际行政区、入口和过夜地判断归属。疏附县、疏勒县、岳普湖县、莎车县等各有独立景区；帕米尔高原常见路线还会跨越克孜勒苏柯尔克孜自治州阿克陶县与喀什地区塔什库尔干塔吉克自治县。白沙湖、喀拉库勒湖、慕士塔格峰、石头城、盘龙古道和红其拉甫口岸不是喀什市远郊，必须独立核算高海拔、长距离道路、边境管理、有效证件、住宿、天气和返程条件。

阿图什的行政身份与克州首府功能必须分开。阿图什市是行政区划代码 **653001** 的县级市，也是克孜勒苏柯尔克孜自治州首府；城市驻地点使用 **GeoNames 1281743**，城市实体使用 **Wikidata Q668353**，其 GeoNames 属性精确对应 1281743。GeoNames 的 PPLA2 标记表示城市承担第二级行政区驻地功能，不表示它是地级市。克州博物馆、南湖、阿孜汗、木纳格葡萄、天门、吐古买提峡谷和哈拉峻方向可按阿图什市内不同尺度核对，但州级展陈和交通集散不把全州景点都变成阿图什景点。

从阿图什跨县组合时，应按实际行政区、入口、海拔、边境管理与过夜地判断归属。阿克陶县、乌恰县、阿合奇县是独立县级行政区；帕米尔高原常见湖泊、雪山与高原道路应查阿克陶县等实际入口，吐尔尕特和伊尔克什坦口岸位于乌恰县，莫尔寺遗址核心位于喀什地区。吐古买提乡属于阿图什市，但官方将其界定为边境型乡；进入具体边境管理区仍须按属地公安当期答复准备证件，通行证不等于口岸通行或跨境许可。阿图什天门、吐古买提峡谷、哈拉峻盐湖和怪柳林彼此相距较远，不能压成同一日远郊环线。

和田市与和田地区、和田县同名相近，但行政层级和旅行范围不同。和田市是行政区划代码 **653201** 的县级市，也是和田地区行政公署驻地；城市实体使用 **Wikidata Q235389**。用于定位主城的 **GeoNames 1281019** 记录名为 `Gujangbagh`，不能据此把它解释成古江巴格街道；古江巴格街道另有 **GeoNames 8992549** 与 **Wikidata Q10913420**。地区博物馆、团城、昆仑公园、吉亚乡和明确开放的市域沙漠胡杨可以进入和田市路线，河道、工坊、生产区和乡村内部则须以正式开放信息为准。

从和田市跨县组合时，应按实际入口和当晚住宿地判断归属。约特干故城、稻香村、乌鲁瓦提等应查和田县，桑皮纸产业园及相关乡村体验应查墨玉县，玉龙湾等应查洛浦县，达里雅布依和龙湖等应查于田县。玉龙喀什河横跨不同管理范围，河道采砂、取土和采玉受水利法规与属地执法管理；只有主管部门或有资质运营方明确公布的开放区域才能安排体验，不能把自由下河、挖掘或驾车进入河床当作普通游览。

跨区域组合至少要分别核算四项：实际到发站或机场、抵达后的最后一段交通、目的地海拔与天气、当晚住宿地。新疆地图上的相邻城市可能仍相距数小时，山区和荒漠道路也会因季节、施工和预警改变可行性。城市页保留长期稳定的空间结构，具体班次、票价、道路和开放状态留到出发前确认。

哈密市是行政区划代码 **650500** 的地级市，下辖伊州区、巴里坤哈萨克自治县和伊吾县；主城公共交通与文博集中在伊州区，大海道、东天山及两县景点按远线分别核算。**GeoNames 1529484** 是主城居民点，但城市实体 **Wikidata Q989892** 当前关联的是旧行政记录 1529482，1529484 又被映射到伊州区 **Q650585**，因此地图点只用于定位，法定边界以 650500 和政府区划资料为准。新疆生产建设兵团第十三师新星市及其团场不是哈密市法定下辖区县，生产道路、矿区和团场内部空间也不因靠近主城而自动开放。

博乐市是行政区划代码 **652701** 的县级市，也是博尔塔拉蒙古自治州首府；**GeoNames 8521718**、**Wikidata Q894256** 与法定城市粒度一致。赛里木湖行政归属博乐市，但应按独立整日远线安排；精河县、温泉县和阿拉山口市都是独立县级行政区，不能并入博乐城市页。新疆生产建设兵团第五师双河市及所属团场另有治理边界，只有正式开放的公共道路、景区和接待点可进入。
