# 北部山海与客家乡镇旅行指南

台湾北部的乡镇呈现两种不同的地理面貌：雪山山脉东侧，宜兰平原的温泉、林业遗存与渔港连着太平洋；西侧的新竹、苗栗丘陵，客家聚落、茶食与木雕产业散布在河谷和山坡。礁溪与苏澳分别以热泉、冷泉形成休闲生活，罗东留下木材集散的历史；北埔的古宅、南庄的街巷和三义的雕刻，则让乡镇文化有了各自具体的形状。

## 区域格局与选择

这里是跨县旅行分组，不是一个可以连续步行的景区。宜兰县的礁溪、罗东、苏澳在台湾东北侧；新竹县的内湾、北埔和苗栗县的南庄、三义在西侧。**首次选宜兰两晚，或选一个客家乡镇作一日游；不要把东西两侧塞进同一天。** 行政市区另见城市攻略，本页也不覆盖太平山、雪山登山与原住民族部落深度行程。

| 分组 | 城镇与性格 | 时间取舍 |
|---|---|---|
| 宜兰北段 | 礁溪的温泉旅宿与平原边缘小镇 | 半日至一晚；适合以住宿休息为主要体验 |
| 宜兰中南段 | 罗东林业文化园区、市场餐饮；苏澳冷泉与南方澳渔港 | 罗东与苏澳分别留半日至一天，港区另需地面接驳 |
| 新竹丘陵 | 内湾铁路河谷、北埔古宅与客家餐食 | 内湾与北埔是不同方向，一天选一处更从容 |
| 苗栗北部 | 南庄街巷、老邮局及周边山地聚落 | 老街半日；加入步道须独立核对交通与开放 |
| 苗栗南部 | 三义木雕博物馆、木雕商街 | 半日至一天；南庄与三义之间需要换区移动 |

## 主要体验

**罗东：读一段木材从山里来到平原的历史。** 林业文化园区保留林场与铁路相关遗存，适合从储木、运输和职工生活理解罗东发展。先选一座开放展馆再走户外园区，避免只绕水面拍照。园区与各馆开放时间不同；林业主管机关页面列部分展示馆周三至周日开放，不能把公共空间可进入当作所有展馆开门。[罗东林业文化园区](https://recreation.forest.gov.tw/Forestry/CP?typ_id=0100021)

**礁溪与苏澳：两种泉水，各安排一种节奏。** 礁溪适合选有明确使用规则的温泉旅馆；苏澳冷泉约 22℃，不是热温泉。冷泉公园、付费池和汤屋的营业条件应分别向经营方确认，不能仅凭景点名称认定可随时入浴。[宜兰县苏澳冷泉介绍](https://travel.yilan.gov.tw/zh-tw/attraction/1/)

**北埔与南庄：从街巷进入客家生活。** 北埔适合观察寺庙、古宅与老街的紧密关系，南庄适合沿街尝小食、看老邮局等公共文化空间。古宅有的仍属私人使用，开放参观须按现场说明；客家文化也不能概括当地所有居民与社区。[参山老街专题](https://www.trimt-nsa.gov.tw/zh-tw/slow-city/)

**三义：木雕比购物更值得先看懂。** 先在博物馆看木材、题材和雕刻形式，再看商街作品，就能比较工艺而非只比较体积。官方常见问答列周二至周日 09:00–17:00、16:30 停止入馆；节日调整另查，不沿用春节临时日历。[苗栗文化观光局参观问答](https://www.mlc.gov.tw/faq/index.aspx?Parser=27%2C8%2C50%2C%2C%2C%2C%2C16%2C%2C%2C0)

| 体验 | 建议用时 | 体力与预约 | 天气与替代 |
|---|---|---|---|
| 罗东林业文化园区 | 2–3 小时 | 低至中；团体解说另约 | 下雨缩短户外，先确认展馆开放 |
| 礁溪温泉 | 半日 | 汤屋或住宿先预约 | 风雨天仍核对经营与到达交通 |
| 苏澳冷泉＋南方澳用餐 | 半日至一天 | 两地需接驳；池区另查 | 强风浪时删除港边步行 |
| 内湾或北埔 | 半日至一天 | 街区中等步行 | 雨天舍弃河岸、吊桥和山路延伸 |
| 南庄老街 | 半日 | 低至中；节假日拥挤 | 留一顿坐下吃的正餐 |
| 三义木雕馆与商街 | 半日至一天 | 馆舍优先核对开放 | 可作普通雨天文化线 |

## 餐饮与当地味道

宜兰可从米食、葱制点心和渔港海产进入；客家乡镇常见粄条、菜包、擂茶等，适合一碗主食搭配小食。擂茶体验若包含制作或讲解，应先预约，不把茶店视作随时开课。内湾野姜花粽等地方食品可从[参山内湾游程](https://www.trimt-nsa.gov.tw/zh-tw/tour/2147/)了解背景。

南方澳点海鲜先问计价单位、重量和料理费；单人选有明码标价的饭面套餐。粄类可能含虾米或肉馅，擂茶常含花生、芝麻或其他坚果；素食与过敏需求逐店确认。三义买木雕、各镇买食品时都保留正式收据，伴手礼成分与跨境携带条件另查。

## 可执行路线

### 宜兰两晚：温泉、林场与港镇

第 1 天抵达礁溪，午餐后在住宿处休息，按预约使用温泉；不要把到达日再拉长到苏澳。第 2 天移至罗东，上午林业文化园区，午餐后休息，傍晚再选市场或夜市；林业展館闭馆时缩为户外开放段与镇区生活。第 3 天按回程时间选苏澳冷泉或南方澳午餐，预留返回车站的接驳。

预约锚点为第一天住宿／汤屋和第三天池区；台铁指定车次另锁。遇雨或疲劳先删南方澳港边散步，时间不足直接从罗东返程。苏澳与苏澳新站不是同一站，购票前以车次实际停站及后续交通决定。

### 西侧乡镇：可独立采用的三条一日线

- **北埔线：** 上午古迹街区，午餐客家饭食，下午预约茶体验；先核对欲入内的古宅，未开放改看公共街巷。午餐后休息，删减时舍掉外围点，返程用已查好的公交或预约车辆。
- **内湾线：** 以新竹方向铁路衔接为骨架，上午抵达街区，午餐后散步，再按回程班次离开。列车时刻是锚点，不临时追加北埔；山雨加大时不去河边或吊桥，直接返回车站。[台铁时刻查询](https://www.railway.gov.tw/tra-tip-web/tip)
- **南庄或三义线：** 南庄选择老街与一顿坐下吃的午餐；三义先木雕馆再商街。两者各成一天，不能把两段稀疏接驳当作城市公交随到随走。三义馆休时可改商街，但若主要兴趣是展览，应换日。

## 住宿与交通

宜兰无车者优先礁溪或罗东车站、转运站附近；分散民宿需先确认最后一段接送。往来台北可比较铁路与客运，周末公路拥堵须留弹性。新竹丘陵宜以新竹或竹东为门口；南庄与三义分别核对客运和站到住宿距离，名称写“苗栗”不代表靠近苗栗站。内湾支线换乘按台铁日期查询，不能凭旧线路图保证直达。

## 旅行须知

海岸使用正式开放步行区，渔港作业码头不作为自由游览平台；不因退潮进入陌生潮间带。山区暴雨时删除瀑布、溪谷和未确认开放步道。亲子及轮椅旅行先询问馆舍入口、汤屋扶手和住宿电梯；老街骑楼可能有高差。证件和入境条件见[台湾旅行总览](../../README.md)，按本人身份核对。
