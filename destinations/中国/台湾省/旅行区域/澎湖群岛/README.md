# 澎湖群岛旅行指南

澎湖位于台湾海峡，群岛上的玄武岩海岸、石墙聚落与港口生活形成鲜明的海洋景观。马公是较集中的城市中心，白沙与西屿的村落展现另一种岛居尺度；七美、望安则各有独立的港湾与社区。风、潮汐和捕鱼方式留下了石沪、传统建筑及地方饮食，也塑造了岛与岛之间的日常联系。海景之外，认识聚落和地形同样是理解澎湖的重要线索。

## 区域格局

本页介绍群岛组合，马公老城另见城市稿。首访 4 天可选城市、本岛北环和一次外岛方向；偏好慢住者将七美或望安延长为过夜。不要把“澎湖”理解成全部地点都能由公路抵达的一座岛。

| 旅行单元 | 主要内容 | 接续关系 |
|---|---|---|
| 马公与湖西 | 城市、机场、港口及近郊 | 适合作抵离与用餐基地，机场和市区仍需接驳 |
| 北环：白沙—西屿 | 桥梁、村落、玄武岩与灯塔 | 陆路跨岛，留一整天并选择少量停靠 |
| 望安 | 岛屿聚落与海岸 | 按交通船或明确旅游产品安排，停靠不等于有足够游览时间 |
| 七美 | 石沪、地形与南部岛屿生活 | 与望安及马公之间需船班或适用航班，不能按陆路环线估时 |

## 主要体验

**北环的桥、村与岩。** 从白沙通梁经过跨海大桥到西屿，在二崁聚落与大菓叶玄武岩之间选择停靠，可以比较建筑材料与自然地形。官方北环列有更多节点，但不需要全部照单完成；二崁住宅仍有私人边界，院门开启不等于可进入。[澎湖官方北环](https://www.penghu-nsa.gov.tw/ChiHoOneLer/tour/ThematicTours/MustIsland/NorthLoop.htm)。

**七美与望安各有独立时间。** 七美可围绕石沪及海岸眺望安排，望安适合聚落与岛居生活。石沪首先是传统捕鱼设施，双心外形之外，还能观察石墙怎样利用潮差；不擅自下到滩地或踩踏石墙。[双心石沪官方介绍](https://www.penghu-nsa.gov.tw/TravelInformationSceneryDetailC001200.aspx?Cond=a98c092b-65f5-4b7e-bbb3-de16bf9be2cf&Keyword=%E9%A2%A8%E6%AB%83&Language=1028&SearchAdvanced=False&SortType=1)。首次只选一座过夜，更容易把午餐、休息与码头接送留完整；若购买一日两岛产品，应先读清每岛实际停留、交通方式和遇风浪取消规则，不能把船上经过也算游览。

七美游客中心紧邻南沪港，可作为到岛后的咨询与休息节点。管理处资料区分交通船与旺季民营快艇，不能将两者航程、码头及票制互换。[七美游客中心](https://www.penghu-nsa.gov.tw/TravelInformationSceneryDetailC001200.aspx?Cond=4b124a07-0bc4-4e96-bd52-7f144f5454be&Language=1028&SearchAdvanced=False)。

## 餐饮

海鲜、面线与当地农渔产品适合穿插在岛屿移动之间。马公容易安排有座位的正餐，北环与外岛则应提前选定午餐聚落。点海鲜先确认品种、计价单位、重量和烹调费用；两人以下不必以大份合菜作为默认。

过夜外岛先问住宿能否供应早餐与晚餐、最晚点餐及素食安排。食材依运输和渔获变化，不将菜单照片视为当天供应保证。搭船前后留正常用餐余量，不让赶码头挤掉补水和休息。

## 路线

### 四天首访线：一条陆路、一个海上方向

| 日程 | 安排与休息 | 锚点、删减与退出 |
|---|---|---|
| 第一天 | 抵澎湖，入住马公，下午只走老城短段，坐下吃晚饭 | 实际航班或船班是锚点；延误删散步 |
| 第二天 | 北环选通梁、二崁与一处玄武岩景观，中午在村落餐馆休息 | 先落实车辆和回程；风大先删临崖停靠与灯塔延伸 |
| 第三天 | 船班及海况允许时七美或望安择一；出发前落实岛上接送、午餐与返航 | 船票为锚点，不靠临时叫车补最后一段；停航改马公已确认室内展馆或休息 |
| 第四天 | 早餐后按抵离安排返回台湾本岛，本岛活动仅在时间充足时加入 | 不在离开当天再去外岛，预留行李提取及机场码头手续 |

若想两岛过夜，增加至少两天，并按实际交通船停靠顺序订房。单程停靠船不是随上随下的旅游巴士；若无法确认第二段交通，就保留单岛，不能临时寻找私人快艇接续。

## 住宿与交通

马公适合首次进出及多日同住；西屿住宿适合减少北环往返，但夜间餐饮和次日接驳要先核对。七美、望安过夜应同时确认住宿、岛上交通与离岛票，给可能延误留预算及可取消房晚。

台湾本岛至澎湖的飞机和客船需按出发机场、港口查实际运行，不能把澎湖机场、马公商港与南海游客乘船点视为同一位置。跨岛交通可查[七美乡公所交通说明](https://www.penghu.gov.tw/TChimei/ch/home.jsp?id=50)及其指向的[澎湖交通平台](https://www.penghu-go.tw/penghugo/)；德安航空[即时航班页](https://flight.dailyair.com.tw/)列有高雄—七美、高雄—望安、澎湖—七美等查询方向，具体日期、余票与是否起飞仍需运营方确认。

北环可选择合法租车、包车或适用公车；风势强时骑行负担显著，不把整条官方自行车路线作为初学者默认方案。驾驶资格、保险、儿童安全座椅与无障碍接送在订车时确认。

## 旅行须知

东北季风、台风及浪况会同时影响船班与岸边活动。“航班有售”不代表未来天气保证，“飞机停飞”也不代表船一定可替代。返台湾本岛后再留缓冲，不把外岛离开日紧接不可更改的国际航班。

石沪与潮间带是渔业及生态空间，不能仅因退潮就擅自进入；玄武岩崖边不越栏、海龟相关区域按保育规定行动。到访前看[澎湖风景区公告](https://www.penghu-nsa.gov.tw/)与[中央气象署](https://www.cwa.gov.tw/)，特殊活动、花火日期及夜间船班另查主办方。
