# 绿岛与兰屿旅行指南

绿岛与兰屿是台湾东南外海两座各有生活脉络的岛屿。绿岛的火山海岸、聚落与人权历史遗址并存，海洋景观之外还保存着需要认真阅读的近代记忆。兰屿则与达悟族的海洋文化、传统建筑和社区生活紧密相连，拼板舟与地下屋都有实际用途及文化意义。两岛都受到海洋环境深刻影响，却不能合并成一种海岛印象，社区传统也不能互相套用。

## 区域格局

首次建议选一岛，绿岛安排约 3 天，兰屿约 4 天，另留本岛交通缓冲。两岛都去需要按实际船班重新排住宿，不能把地图上邻近理解为每天有便捷直达。

| 岛屿与门户 | 主要旅行特征 | 需要分开的环节 |
|---|---|---|
| 绿岛 | 海岸景观、水上活动与人权历史 | 南寮港、机场、住宿和岛上景点各有接驳 |
| 兰屿 | 达悟社区、传统建筑与海岸 | 开元港、机场及不同社区分散，导览须确定地点与接送 |
| 台东富冈 | 两岛的主要海上出发门户之一 | 台东车站、机场、市区和富冈港不是同一位置 |
| 恒春后壁湖 | 兰屿部分季节船班出发方向 | 不与台东船票混用，运营日期逐次确认 |

## 主要体验

**绿岛的海岸与历史各留一个半天。** 海岸散步和正规水上活动之外，白色恐怖绿岛纪念园区值得完整停留，用展览理解政治案件受难者与岛屿历史。纪念空间不适合戏谑摆拍，展区、导览与活动按[国家人权博物馆参观信息](https://www.nhrm.gov.tw/w/nhrm/GI_Visit)核对；可留 2–3 小时，属于编辑估计。

**兰屿从社区导览开始。** 地下屋、拼板舟和工作中的海岸有各自的使用规则。通过当地认可的导览认识住宅和海洋文化，比自行穿梭私人空间更能理解生活脉络。导览预约未确认时，只使用明确公共道路与开放观景处，不把住宅当成免费展馆。

**水上活动单独判断条件。** 两岛都可查询正规经营者提供的适用活动，但船班运行不证明每个潜点可下水。根据经验、年龄、身体状况与经营者评估选择，不把下水作为全体同行者必做项目。陪同者可在安全、开放且有返程安排的陆地停留。台东县官方[潜水说明](https://tour.taitung.gov.tw/zh-tw/discover/diving)明确提醒兰屿飞鱼季部分传统海域禁止水上及水下活动；具体社区、日期和范围出行前确认，不以经营者宣传替代社区要求。

## 餐饮

兰屿餐饮中的鱼类、芋与当地食材和社区生活相连，飞鱼相关饮食更有季节及文化背景。不要要求每一家餐厅全年供应同样菜色，也不要为拍摄食材闯入晾晒场地。绿岛在餐饮集中的聚落更容易安排普通饭面和海鲜，远离聚落前先确认返程能否赶上晚餐。

离岛供应受运输影响，素食、过敏原和儿童餐应在订住宿或体验时沟通。点海鲜先问价格与分量，潜水或长途搭船日留足午餐、补水和休息时间。只购买明确可售的产品，不带走自然物或受保护生物。

## 路线

### 绿岛三天：海洋与记忆

第一天按船班或航班到岛，接送入住后仅在附近短走；第二天上午选一项已确认的正规活动或开放海岸短线，午餐后至少休息一小时，再参观纪念园区；第三天依返程票离岛。若活动预约在下午，将园区移至上午；若到达晚或身体疲累，删海岸加项，不压缩纪念园区阅读和正餐。风浪取消水上活动时改陆上开放场馆，强风暴雨则留住宿等候官方安排。

### 兰屿四天：社区与海岸

| 日程 | 内容与休息 | 锚点、删减与退出 |
|---|---|---|
| 第一天 | 抵岛、接送入住、确认社区导览，住处附近晚餐 | 抵达交通是锚点；不排紧接船到的收费活动 |
| 第二天 | 预约社区导览，午餐长休，下午只选邻近公共海岸 | 导览集合时间优先；摄影许可未获同意就不拍，不改闯别处住宅 |
| 第三天 | 在已落实接送和海况允许下选另一片区或一项活动 | 不要求环岛所有点；风大删登高与海边停留，提早回住宿 |
| 第四天 | 返回台东或其他已确认门户 | 预留行李与候船手续；取消时联系原运营方，不自行寻私船 |

两岛合行应增加天数和台湾本岛的交通缓冲，直达或经停串岛船需向船公司确认**具体日期、是否载客、行李和第二段票**。没有确认就分别经台东安排，不要将两岛压缩成跳岛日游。

## 住宿与交通

绿岛按南寮与目标片区距离选住宿，兰屿按希望认识的社区及接送条件选；“岛上住宿”不保证能在码头随叫到车。提前约好车站到富冈、港口到住宿、活动到住宿三段交通。驾驶证件、保险及道路经验不满足时，选择接送或合法包车，不把临时学骑机车当作默认解决方式。

[东海岸管理处客船资料](https://www.eastcoast-nsa.gov.tw/zh-tw/service/ferry/)列有富冈—绿岛、富冈—兰屿与后壁湖—兰屿方向，并提醒淡旺季及气象变化。该页同时保留旧年份季节航班，不能整页照抄成当前班表；以实际船公司当日确认取代旧时间。后壁湖方向尤其应核实季节停驶。

[德安即时航班](https://flight.dailyair.com.tw/)提供台东—绿岛、台东—兰屿状态查询；座位、行李与取消处理按[运营方订位说明](https://www.dailyair.com.tw/Dailyair/Page/OrderService/)办理。不把飞机满位或停飞后的候补船位当成必然可得。返回台湾本岛后安排缓冲住宿，再接国际航班或必须准时的事务。

## 旅行须知

**达悟文化中的许可必须具体。** 私人住宅、传统服饰长者及社区活动在拍摄前先征得本人同意；地下屋须在获准并由合适人员带领的情况下进入或拍摄。未获许可不触碰、攀坐拼板舟，不进入作业与晾晒空间；祭仪与海域使用听从所属社区当时说明，不将某处许可推广到全岛。[台东县官方旅游折页](https://tour.taitung.gov.tw/file/1057/)明确提示住宅与人像摄影规则。

海岸陡坡、长浪、夜间照明不足与交通延误会影响两岛活动。亲子、长者及无障碍需求先确认登船协助、房间台阶、车辆及医疗可及性；不能只凭住宿照片判断。垃圾减量并按住宿及当地收运方式处理，不将海岸当作露营或生火的自由空间。
