# 甘肃省旅行目的地

甘肃从陇东黄土高原延伸到河西走廊与西部荒漠，省内城市之间距离长，气候、海拔和旅行主题差异明显。现有指南覆盖兰州与敦煌：兰州以黄河河谷、省域文博和城市生活为核心，敦煌则连接石窟艺术、绿洲城区、西部关隘与雅丹地貌。

## 区域格局与城市组合

兰州主城区沿黄河东西延伸，是进入甘肃后理解全省地理与丝路历史的常用起点。甘肃省博物馆、甘肃简牍博物馆和黄河中心段可组成两天城市框架；水墨丹霞与河口古镇分别位于远郊方向，通常各占半天至一整天，不能按市中心景点处理。水墨丹霞是兰州近郊景区，与张掖市域内的七彩丹霞不是同一地点。

敦煌位于甘肃西端，是河西走廊西部的重要旅行基地。敦煌城区、莫高窟和鸣沙山月牙泉可以用两天形成基本框架；阳关方向与玉门关—雅丹方向分处不同荒漠道路，均需另算交通、天气和返程时间，不应因为都被称作“西线”就压入同一天。

瓜州县的榆林窟、锁阳城等目的地不计入敦煌城市景点。炳灵寺石窟位于临夏州永靖县，即使由敦煌研究院管理，也不计入兰州；甘南需按高海拔、道路和季节另做区域行程。嘉峪关、酒泉、张掖、武威、临夏、兰州、甘南与敦煌各有独立的城市或区域结构；河西走廊铁路能够串联城市，不等于相邻两站之间适合当天往返游览。跨城组合应按实际到发站、车次、住宿地和季节路况逐段安排。
