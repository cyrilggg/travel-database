# 甘肃省旅行目的地

甘肃从陇东黄土高原延伸到河西走廊与西部荒漠，省内城市之间距离长，气候、海拔和旅行主题差异明显。现有 15 篇指南；新增的[合作](./合作市.md)以州府高原适应、米拉日巴佛阁、当周草原与美仁草原为主线。

## 区域格局与城市组合

兰州主城区沿黄河东西延伸，是进入甘肃后理解全省地理与丝路历史的常用起点。甘肃省博物馆、甘肃简牍博物馆和黄河中心段可组成两天城市框架；水墨丹霞与河口古镇分别位于远郊方向，通常各占半天至一整天，不能按市中心景点处理。水墨丹霞是兰州近郊景区，与张掖市域内的七彩丹霞不是同一地点。

庆阳位于甘肃东部，城市指南覆盖西峰区及庆城、环县、华池、合水、正宁、宁县、镇原七县。西峰是博物馆、机场与庆阳站所在的城市核心；周祖陵、南梁、山城堡和子午岭开放片区分属不同县域方向，通常各需独立半天至一天，不能当作连续城区景点。银西高铁沿线的庆阳、庆城、曲子、环县、甜水堡和宁县站服务不同片区，均不等于景区入口；华池、合水、正宁、镇原及多数远郊仍需公路接驳。

敦煌位于甘肃西端，是河西走廊西部的重要旅行基地。敦煌城区、莫高窟和鸣沙山月牙泉可以用两天形成基本框架；阳关方向与玉门关—雅丹方向分处不同荒漠道路，均需另算交通、天气和返程时间，不应因为都被称作“西线”就压入同一天。

天水由秦州与麦积两个城市核心构成：秦州集中伏羲庙、市博物馆、胡氏古民居和老城，麦积承担铁路、机场与麦积山方向集散。麦积山石窟内部洞窟、栈道和相关参观节点属于同一完整景区，不必另排多站；秦安大地湾、甘谷大像山、武山水帘洞和张家川马家塬分属不同县域，适合择一整日，不应串成连续市区路线。

武威的常规主城位于凉州区，雷台、文庙与西夏博物馆可按城市线组合；天梯山石窟、民勤荒漠与治沙点位、古浪县域以及天祝高原分处不同方向。天梯山石窟内部洞窟、展陈和水库岸线属于一处完整游览区域，雷台汉墓与相关展馆也宜连贯安排。自然保护地、治沙作业区、矿区和高原牧业空间只有明确开放的公众部分可以进入。

[金昌](./金昌市.md)现辖金川区和永昌县，日常主城在金川区；金昌站却位于永昌县河西堡镇，永昌县城还需继续向南接驳。金川主城的市博物馆、紫金苑、矿山公园公众区和城市公园可用一至两天分段理解，永昌县博物馆、钟鼓楼与北海子适合单列县城一日，御山峡长城方向则再单列远线。紫金花城是广义城市文旅体系，不能与具体的紫金苑或一张统一门票画等号；矿山公园也不意味着在产矿井、冶炼、尾矿和工业厂区开放。火星 1 号基地最新明确公共状态仍为暂停营业，后续组织活动不能证明散客复业；骊靬相关历史叙事和项目建设同样不等于常态开放，均须取得当期运营证据后才能加入路线。

张掖以甘州区为主城与交通基地，大佛寺、老城餐饮、市博和黑河湿地可以在城市范围内分段组合；七彩丹霞位于临泽与肃南交界，平山湖大峡谷位于甘州北部荒漠，马蹄寺在肃南祁连山北麓，三者分别朝西、北、南展开，通常各占大半天至一日。高台、民乐和山丹又是更远的县域方向。祁连山国家公园、军马场生产区、湿地、水库和矿山只能进入公告明确开放的公众区域，地图道路不等于游客准入。

[嘉峪关](./嘉峪关市.md)是不设区县的地级市，中心城区承担住宿、城市博物馆和多方向换乘；嘉峪关关城、长城第一墩和悬壁长城共同构成嘉峪关文物景区，但分处西、南、北三个方向，应作为一个完整长城防御体系去重并分段接驳。新城魏晋墓、草湖湿地、南市区东湖与讨赖河又是独立半日或一日方向。未开放长城点段、黑山岩画周边、湿地、水库、河沟、酒钢厂区、铁路、能源和核技术保障设施不作为自由游览空间；工业研学只有在运营方明确组织时才能进入。

平凉的城市核心位于崆峒区泾河河谷，市博、柳湖、崆峒古镇集散区和崆峒山需要分成主城与山地两天理解。泾川、庄浪、崇信、静宁与灵台分处不同县域，各自需要往返和最后一段交通。华亭市是平凉代管的独立县级市，其旅行内容不纳入平凉主城或普通县域路线，联程时应另查属地交通与开放信息。崆峒水库供水设施、未开放库岸和各地矿区均不作为观光空间。

酒泉的日常主城在肃州区，酒泉市博物馆、鼓楼、西汉酒泉胜迹和 1969 文化艺术创意园可用一至两天分段组合。金塔位于北向县域，胡杨林适合单独一天；瓜州距离肃州更远，榆林窟与锁阳城又分处县城外不同方向，宜住瓜州后按天选择。肃北和阿克塞涉及山地、长距离戈壁公路与偏远通信，不作为肃州当天往返。玉门市、敦煌市是酒泉代管的独立县级市，[嘉峪关市](./嘉峪关市.md)是独立地级市，三者的景点均不并入酒泉指南。东风航天城又名酒泉卫星发射中心，实际位于内蒙古自治区阿拉善盟额济纳旗，只能在取得运营方和管理单位当期许可后作为跨省受控联程另行规划，也可能完全不开放；机场、军事设施、能源生产区、矿山、水库和自然保护地同样服从各自准入边界。

定西以安定区主城为铁路、公路和公共服务基地，定西市博物馆、西岩山与玉湖公园适合用一天分段了解；通渭、陇西、临洮、渭源、漳县和岷县则分属不同县域方向。陇西李家龙宫与威远楼可组成县城古建线，临洮以马家窑文化为核心，渭源连接灞陵桥与渭河源，漳县贵清山—遮阳山和岷县狼渡湿地草原都需要完整山地日。六县景点不能压成安定主城的连续步行线，马铃薯田、中药材基地、仓储加工区、湿地、林场和文物保护范围也只有明确开放部分可进入。

白银以白银区主城为城市文博和工业历史入口，白银市博物馆、火焰山国家矿山公园公众区域与城市公园可组成一天；水川虽属白银区，仍是需要车辆往返的黄河远线。平川区、靖远县、景泰县和会宁县各有独立城区与住宿条件，黄河石林、永泰古城、会宁会师旧址、水岸三合和陶瓷小镇不应压进白银主城路线。矿山公园的主题公园不等于在产矿区开放，黄河景区也不等于坝体、灌渠、库岸和行洪空间开放；寿鹿山、哈思山、屈吴山、铁木山等保护地只进入公告明确开放的公众区域。白银现辖三县两区，不代管县级市；兰州和宁夏中卫均为跨市联程。

临夏市是临夏回族自治州所辖县级市和州府，法定代码为 `622901`；临夏州代码为 `622900`，临夏县代码为 `622921`，三者不是同一对象。临夏市内可按八坊十三巷—老城、东城文博、南部大夏河与折桥湾四个方向分段；八坊首先是居民与宗教生活持续发生的社区，折桥湾、牡丹种植区和河岸又包含农业、居住与行洪空间，只进入明确开放的公共区域和正规经营点。永靖县炳灵寺石窟、和政与广河等州辖县目的地均属跨县行程。GeoNames `1803331` 虽命名为 “Linxia Chengguanzhen” 并标记 `PPLA3`，地方志记载临夏市于 1983 年恢复时已撤销城关镇；本库据法定县级市实体和 Wikidata `Q653608` 的 `P1566=1803331` 建立临夏市页，不沿用旧地名扩大或缩小市域。兰合铁路临夏站截至 2026-08-12 仍在建设，临夏机场仍属前期或规划事项，当前抵离以公路为主。

瓜州县的榆林窟、锁阳城等目的地不计入敦煌城市景点。炳灵寺石窟位于临夏州永靖县，即使由敦煌研究院管理，也不计入兰州或县级临夏市；西安、延安、银川和平凉均在庆阳市域之外，其景点不计入庆阳。[合作](./合作市.md)是甘南州府和独立县级市，先按高海拔、道路和季节安排合作城市日，再规划州内其他县域。[嘉峪关](./嘉峪关市.md)、酒泉、张掖、武威、临夏、合作、兰州、庆阳与敦煌各有独立旅行结构，跨城组合按实际到发站、住宿地和季节路况逐段安排。
