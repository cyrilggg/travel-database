# 甘肃省旅行目的地

甘肃从陇东黄土高原延伸到河西走廊与西部荒漠，省内城市之间距离长，气候、海拔和旅行主题差异明显。当前以敦煌作为首个完整城市指南，重点整理石窟艺术、绿洲城区、鸣沙山月牙泉以及西部关隘和雅丹地貌之间的空间关系。

## 区域格局与城市组合

敦煌位于甘肃西端，是河西走廊西部的重要旅行基地。敦煌城区、莫高窟和鸣沙山月牙泉可以用两天形成基本框架；阳关方向与玉门关—雅丹方向分处不同荒漠道路，均需另算交通、天气和返程时间，不应因为都被称作“西线”就压入同一天。

瓜州县的榆林窟、锁阳城等目的地不计入敦煌城市景点。嘉峪关、酒泉、张掖、武威、兰州及甘南也各有独立的城市或区域结构；河西走廊铁路能够串联城市，不等于相邻两站之间适合当天往返游览。跨城组合应按实际到发站、车次、住宿地和季节路况逐段安排。
