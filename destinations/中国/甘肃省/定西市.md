# 定西旅行指南

定西位于甘肃中部，安定区主城是铁路与公路到达基地，真正拉开旅行尺度的则是分散在六个县的彩陶遗址、古建筑、渭河源头、黄土梯田、西秦岭山地和长征历史。这里不适合用一条步行线“扫完”：陇西、临洮、渭源、漳县、岷县和通渭各有自己的县城、住宿与最后一段交通。把主城文博与一至两个县域方向组合起来，通常比每天长距离折返更从容。

> 建议停留：2–5 天；安定主城 1 天，县域方向各留 1 天<br>
> 旅行关键词：马家窑彩陶、李氏文化、渭河源、贵清山与遮阳山、长征历史、马铃薯与中药材<br>
> 主要体力：主城低至中等；山地、草原与跨县路线中高强度<br>
> 最近研究：2026-08-12

## 城市格局与游览区域

定西法定市域横跨黄土高原丘陵沟壑区与西秦岭、高寒阴湿山区。安定主城位于北部交通轴上，定西站、定西北站和城市公共服务集中于此；六县则分别沿不同铁路和公路方向展开。县城之间“地图上相邻”不等于景点入口彼此顺路，山区还会受到弯道、施工、降雨、结冰和季节运营影响。

|---|---|---|---|

| 通渭方向 | 榜罗革命遗址、书画文化、温泉与黄土梯田 | 红色历史、书画和康养主题分处县城及乡镇，活动和温泉项目时效性强 | 位于安定以东，适合独立一日或住宿通渭；不能与岷县红色景点合并成市内短线 |

**行政与数据范围：** 法定地级市定西市行政代码为 **621100**，辖安定区和通渭县、陇西县、临洮县、渭源县、漳县、岷县六县。GeoNames **1812749** 是安定主城附近的 `PPLA2` 城市点，用于定位行政中心；GeoNames **1812743** 是更大尺度的 `A/ADM2` 行政记录。Wikidata **Q186006** 表示法定地级定西市，其 `P1566=1812743` 指向行政记录；另一个内容很少的居民点实体 **Q31853829** 则以 `P1566=1812749` 精确连接主城居民点。法定实体、居民点和两种 GeoNames 记录承担不同空间尺度，均不能替代民政部门确认的行政边界。

**农业与中药材空间：** 马铃薯田、中药材基地、种薯繁育田、试验地、仓库、加工厂和交易市场首先是生产经营空间。只有明确开放的展馆、体验基地或正式市场公共区域才可进入；不跨越围栏、不踩踏作物，不为拍摄进入机耕道、装卸区、检验区或冷库。购买当归、党参、黄芪等产品应看标签、产地、生产许可和用法，不能把旅游推介等同于医疗建议。

**自然与文保边界：** 渭河源、贵清山—遮阳山和狼渡湿地草原均应按公告开放范围活动。保护地、林场、湿地、水源涵养地、未开放峡谷和防火通道不是普通景区步道；马家窑遗址、汪氏元墓群、古桥和古建筑也不能因导航可达就触摸、攀爬或进入封闭区。

## 主要景点

优先级用于安排时间，不代表绝对排名：**A** 为首访核心，**B** 为按兴趣补充，**C** 为远郊、季节性或通常需要独立半天以上的目的地。车站、游客中心、市场入口和商业街标记为“路线节点”，不计入景点数量。同一景区内的步道、观景台、古建筑、交通和体验单元按一个完整景区安排。

## 美食与餐饮

定西饮食以小麦面食、马铃薯、粉制品、牛羊肉和县域熟食为常见基础。安定主城适合寻找马铃薯与宽粉类菜品；陇西腊肉、岷县点心和通渭苦荞茶在对应县城更容易遇到。中药材是重要产业，但药膳、茶饮和保健产品不能替代诊疗，也不应以“当地特产”为由忽略剂量、禁忌和药物相互作用。

| 菜品或餐饮类型 | 常见区域 | 一个人用餐与常见份量 | 风味、过敏原与饮食限制 | 排队风险与替代方法 |
|---|---|---|---|---|
| 定西宽粉与马铃薯粉制品 | 安定主城、各县正规餐馆 | 汤粉、砂锅或小锅适合一人；火锅、炒粉大盘更适合共享 | 主要原料常含马铃薯淀粉，汤底、酱油、辣椒、芝麻、花生、肉类和复合调料因店而异；“粉”不等于无麸质 | 节庆和热门餐饮区排队较高；选择明码标价、能说明配料和生产信息的同类店 |
| 马铃薯家常菜与面食 | 安定、通渭、临洮及县城家常餐馆 | 洋芋类小份菜、面食或搅团类主食通常可一人点；宴席做法份量较大 | 可能配小麦面粉、油泼辣子、醋、蒜、肉臊子和乳制品；麸质与辣度需逐项确认 | 不必追某一菜名或门店；在居民餐饮区选择当日菜单和小份组合 |
| 陇西腊肉 | 陇西县及部分全市正餐馆、正规熟食店 | 炒菜或夹馍可做单人份，拼盘与整块熟食适合共享 | 猪肉、盐和香辛料为主，可能含酱油、糖或亚硝酸盐；高盐饮食者需控制份量，清真饮食不适用 | 节庆与饭点排队中高；购买预包装产品时查看生产日期、冷藏和配料表 |
| 岷县点心 | 岷县县城及正规特产店 | 可按个或小盒购买，适合一人加餐，不宜把大礼盒当作一餐 | 常见小麦、糖、油脂，具体馅料可能含蛋、乳、芝麻或坚果；配方与保质期依产品变化 | 选择标签完整、储存条件清楚的产品；严重过敏者避开无法说明馅料的散装点心 |
| 通渭苦荞茶与书画街区茶饮 | 通渭县城、书画村及正规商店 | 一壶可分享，独行先问小杯或独立包装 | 混合茶可能加枸杞、糖、坚果或其他草本；先核对配料和自身饮食限制，妊娠或用药期间如有疑问应咨询专业人员 | 景区套餐价格可能较高；选择标识、配料、净含量和生产信息清楚的同类产品 |
| 当归、党参、黄芪主题药膳或茶饮 | 陇西、渭源、岷县及中医药主题餐饮 | 多为多人汤锅、炖品或小杯茶饮；独行先问最小份与全部成分 | 中药材可能与药物、疾病、妊娠或过敏状况冲突；“药食同源”也不代表无限量或人人适用 | 不把养生宣传当作疗效证明；无法说明原料、剂量和加工主体时，改选普通汤面或家常菜 |

需要清真饮食时，应核对门店当期资质、肉类来源、酒类使用和共用厨具，不凭“牛羊肉店”或街区位置推断。县域远线应准备可独立辨识配料、便于保存的补给，不依赖山口、林区、湿地或乡村公路临时找到餐饮。

## 经典行程

### 一日主城路线

**路线**：定西市博物馆 → 安定主城午餐 → 玉湖公园短段 → 西岩山低段或城市餐饮区

- **串联逻辑**：先用市博理解彩陶、陇中历史和六县文化，再用公园观察安定主城；西岩山只在天气、日照和道路条件允许时加入，不在同日赶往县域。
- **预约锚点**：市博的馆址、实名预约、闭馆日、临展和停止入馆时间。
- **休息安排**：在市博服务区或主城正规餐饮长休；玉湖和西岩山只走靠近出入口、卫生间和车辆接驳的短段。
- **时间不足时**：先删西岩山，再缩短玉湖；保留市博和一顿本地餐饮。

### 两日城市与县域路线

**第 1 天**：定西市博物馆 → 玉湖公园或西岩山短段 → 安定主城住宿<br>
**第 2 天**：陇西县城李家龙宫 → 午餐 → 威远楼与县城历史街段；或临洮马家窑文化博物馆 → 县城午餐 → 岳麓山短段

- **串联逻辑**：第一天建立全市背景，第二天只选择陇西或临洮一个县；两种方案分别围绕古建筑姓氏文化和史前考古展开，不跨县追点。
- **预约锚点**：第二天主场馆或景区的开放、讲解和交通是首要锚点；安定与所选县之间的车票或车辆同步锁定。
- **休息安排**：在陇西或临洮县城用餐、补给和长休，不把乡镇公路服务区当作固定休息点。
- **时间不足时**：删除第二天下午的岳麓山或县城支线；若到达县城已晚，只保留一处主场馆并留足返程。

### 三日文化与山水路线

**第 1 天**：安定主城文博与公园<br>
**第 2 天**：陇西李家龙宫 → 威远楼 → 陇西县城住宿<br>
**第 3 天**：转入渭源县 → 灞陵桥 → 渭河源当期开放主游线 → 渭源县城或下一交通节点

- **串联逻辑**：按安定、陇西、渭源逐步向南移动，减少回到安定的重复车程；第三天仍把渭河源作为单一山地主目标。
- **预约锚点**：渭河源票务、景区交通、最后入园和天气是全程第一锚点；陇西两处古建开放同步核对。
- **休息安排**：第二天在陇西县城休整，第三天先在渭源县城补给；景区内只使用正式服务点。
- **时间不足时**：第三天删去灞陵桥或缩短景区支线，不压缩返程缓冲；天气不适合山地时整段改为渭源县城文博。

### 普通降雨路线

**路线**：定西市博物馆重点展厅 → 主城室内午餐 → 经确认开放的城市展览或公共文化空间

- **适用条件**：只适用于普通降雨。出现暴雨、雷电、山洪、地质灾害预警或道路管制时，取消渭河源、贵清山—遮阳山、狼渡湿地草原、西岩山和全部山谷、林草方向。
- **预约锚点**：市博当日开放；其他室内空间必须取得散客开放确认，不能以曾举办团体活动推断可直接进入。
- **休息安排**：全程以场馆、正规餐饮和车站候车空间为休息点，不在河道、边坡、桥下或施工围挡附近避雨。
- **时间不足时**：只保留市博；如场馆临时关闭，改为休息和调整车票，不用车内观景替代已经封闭的山地行程。

### 亲子或低体力路线

**亲子路线**：定西市博物馆适龄展厅 → 室内午餐 → 玉湖公园近入口短段<br>
**低体力路线**：车辆到市博最近开放入口 → 精选展厅 → 长休 → 主城平缓公共空间

- **减负方式**：两条路线都不加入西岩山登高或跨县往返。若另日去陇西或临洮，选择县城场馆与车辆接驳；渭河源、贵清山—遮阳山和狼渡草原可直接取消。
- **预约锚点**：市博儿童证件、讲解、寄存、轮椅、婴儿车和电梯规则，以及公园水边设施与活动年龄限制。
- **休息安排**：使用场馆座椅、卫生间和主城正规餐饮；亲子活动持续看护，低体力行程避免连续上下车。
- **时间不足时**：先删公园，只保留市博；不以“车能到”作为古建、遗址或山地全程低体力的依据。

### 陇西古建筑一日路线

**路线**：陇西县城到达 → 李家龙宫 → 县城午餐 → 威远楼与周边短段 → 陇西站或县城住宿

- **串联逻辑**：两处核心都在陇西县城范围，主题从姓氏文化过渡到城市古建；中药材市场只在明确开放、无装卸作业冲突时作为商业观察补充。
- **预约锚点**：李家龙宫和威远楼的开放、祭祖或节庆活动、讲解和内部参观范围。
- **休息安排**：在县城餐饮区和公共服务空间长休，不进入仓库、加工厂或交易市场装卸区休息拍照。
- **时间不足时**：删除市场和街巷支线，保留李家龙宫；赶车前不追加城外景点。

### 临洮史前文化一日路线

**路线**：临洮县城或正式接驳点 → 马家窑文化博物馆及当期开放展示空间 → 县城午餐 → 岳麓山低段或洮河公共空间 → 返回

- **串联逻辑**：上午集中理解彩陶与遗址，下午只补一处县城近郊公共空间；遗址保护区、博物馆和文旅体验区不混称为一个可自由穿行的大景区。
- **预约锚点**：博物馆准确馆名、馆址、闭馆日、讲解和遗址开放边界。
- **休息安排**：在临洮县城用餐和补水，岳麓山只走接近入口的正式步道；洮河水边服从防汛管理。
- **时间不足时**：删除岳麓山或河边，只保留博物馆；不缩短回程去寻找未开放遗址点。

### 渭源或漳县山地一日路线

从两个方向中选择一个：

**渭源路线**：渭源县城 → 灞陵桥 → 渭河源景区当期开放主线 → 县城<br>
**漳县路线**：漳县县城或正式游客集散点 → 贵清山或遮阳山当日开放的一套主线 → 原路返回

- **适用条件**：已核实开放、门票、景交、天气、道路和返程；两条路线不能在同一天拼接，漳县也不应尝试把贵清山与遮阳山全部走完。
- **预约锚点**：所选山地景区的入口、实名票、景交、最后入园、森林防火和临时关闭公告。
- **休息安排**：在县城完成早餐与补给，山内只用正式服务区；不在临崖弯道、河滩、林道或地质灾害警示区停车。
- **时间不足时**：渭源先删灞陵桥，漳县删全部支线；到达过晚或预警升级时取消整段山地，不以夜间返程补时间。

### 通渭或岷县专题一日路线

从两个方向中选择一个：

**通渭路线**：通渭县城 → 榜罗镇革命遗址与纪念场馆 → 县城午餐 → 悦心国际书画村当期展览<br>
**岷县路线**：岷县县城 → 岷州会议相关纪念场馆 → 县城午餐 → 当期开放的县城文博；狼渡湿地草原另留完整一天

- **串联逻辑**：通渭把红色历史与书画文化分成上午、下午；岷县以纪念场馆为主，不把高寒草原作为“顺路加点”。
- **预约锚点**：榜罗或岷州场馆的闭馆、讲解与团队接待；书画村展览、温泉和商业项目分别核对。
- **休息安排**：在县城正规餐饮和场馆休息区停留，乡镇与草原公路不预设补给。
- **时间不足时**：通渭删书画村经营项目，岷县删县城支线；没有完整白天时不去狼渡湿地草原。

## 住宿区域

| 区域 | 优点 | 缺点 | 适合人群 | 交通特点 |
|---|---|---|---|---|
| 安定主城中心区 | 餐饮、公共服务、市博和城市公园相对集中 | 到定西站、定西北站及长途客运节点仍可能需要乘车；不能降低县域往返距离 | 首次到访、只停一晚、以主城为基地选择一个县域的旅行者 | 城市公交、出租车和合规网约车选择较多；铁路站名和住宿地址要逐一核对 |
| 定西站周边 | 普速铁路到发方便，适合早晚班和短暂停留 | 站前环境、噪声与餐饮品质差异大，到新城区和定西北站并非步行换乘 | 普速铁路中转、次日乘车前往陇西或邻近城市的旅行者 | 不把“定西站”简称与“定西北站”混用，换站预留城市交通时间 |
| 定西北站—新城片区 | 高铁到发和较新的城市设施较方便 | 与老城餐饮、公园及定西站有距离，晚间接驳需提前确认 | 高铁到达、晚到早走、重视新城设施的旅行者 | 先确认住宿到出站口、公交或车辆上客点的真实距离 |
| 陇西或临洮县城 | 可把古建筑或考古日从长距离往返变为县城慢游 | 只对明确的县域方向有价值，换宿增加行李成本 | 李氏文化、中药材或马家窑文化专题旅行者 | 陇西可利用铁路；临洮以实际公路客运和车辆接驳为主，均需核对末班 |
| 渭源、漳县或岷县县城 | 靠近南部山地和次日出发点，补给优于景区深处 | 海拔、气候和服务条件差异大；景区仍有最后一段道路 | 渭河源、贵清山—遮阳山或岷县高寒方向旅行者 | 先确认县城站点、景区入口、返程车辆和夜间到达，不把同名乡镇当作住宿地 |
| 通渭县城 | 榜罗、书画与温泉方向可减少安定往返 | 景点分散，温泉和商业综合体营业具有季节性 | 红色历史、书画或康养专题旅行者 | 通渭站与县城、榜罗镇和具体经营场所之间仍需接驳 |

不推荐未经核验的具体酒店。预订时确认准确地址、夜间前台、供暖或空调、热水、电梯、无障碍客房、停车、外宾接待、证件登记和取消规则。南部县域冬季供暖、山区停电停水和极端天气改签的应对条件，也应在付款前询问。

## 市内交通

定西没有一条能把安定与六县核心景点连续串起的城市公交线。铁路解决的是城市或县城之间的骨干移动，县城到遗址、山地、草原和乡镇场馆仍需公交、班线、合规预约车辆或自驾。安定主城的定西站与定西北站分别服务不同铁路产品，购票时要看完整站名。

| 场景 | 建议与取舍 | 行前需要重查的内容 |
|---|---|---|
| 高铁到达安定 | 定西北站服务主城高铁到达，适合从兰州、西安等铁路方向进入；出站后再接城市交通 | 车次、站口、城市公交、出租车上客点、夜间接驳和施工 |
| 普速铁路到达安定 | 定西站位于安定区另一片区，适合部分陇海铁路车次；不能按定西北站的地图与接驳安排 | 可售车次、行李业务、站口施工、到住宿地和换站时间 |
| 前往六县 | 官方资料列出通渭、陇西、渭源、岷县等铁路节点，但不同线路和列车停靠差异大；临洮、漳县及景区末段常更依赖公路 | 实际站名、列车停靠、汽车站、班次、实名购票、行李和末班 |
| 安定主城公交 | 适合车站、住宿、场馆和公园间的低成本移动，但线路调整和站名不宜固化 | 线路、首末班、支付方式、道路施工和节庆绕行 |
| 县城到景区 | 先到目的县城，再使用正式公交、旅游专线、客运或合规车辆；网络宣传中的“直通车”可能只在旺季或团队运行 | 运营日期、上车点、预约人数、车辆资质、返程和取消条件 |
| 航空接驳 | 航空不是安定主城内的常规到达轴；先选择实际有航班的机场，再把机场到定西的铁路或公路作为独立行程 | 航班、落地机场、联程余量、夜间交通和恶劣天气备选 |
| 自驾 | 跨县弹性较高，适合山地和乡镇目的地；驾驶负担、山区弯道、雾、雨雪、落石和通信条件也会显著增加 | 租车合同、保险、道路施工、地质灾害、结冰、停车、加油充电和救援 |

地图显示的县际距离不能代替实际车程。遇到强降雨、低能见度、降雪或道路结冰时，不使用村道、林道、矿区道路和机耕道绕行；铁路、公路和景区都已停运时，应留在有公共服务的城区或县城等待官方恢复通知。

## 不同旅行者须知

| 旅行维度 | 安排建议与限制 |
|---|---|
| 独行旅行 | 安定、陇西、临洮等城区文博和餐饮容易独自安排；县域山地与草原需把往返、通信和住宿落实到具体运营者，不搭乘无资质车辆，不独自进入封闭林草地 |
| 亲子旅行 | 优先市博、县域博物馆和公园短段；遗址边坡、古桥水边、山地台阶、温泉、冰雪娱乐及草原公路需持续看护，并核对年龄、身高和装备规则 |
| 长者或低体力旅行 | 每天只设一个主要场馆或景区，点位间乘车并安排县城午休；南部山地和狼渡方向可直接取消，景交终点之后的台阶与坡道需向官方确认 |
| 无障碍需求 | 定西市博物馆等现代场馆可能具备部分设施，古建筑门槛、遗址土路、山地栈道、草原和县际客运不保证连续；电梯、坡道、轮椅、卫生间和可接驳入口需逐处确认 |
| 摄影旅行 | 彩陶、古建、黄土梯田、山地和草原题材差异大；闪光灯、三脚架、无人机及商业拍摄服从场馆、文保、湿地、防火和空域规定，不进入农田或墓区取景 |
