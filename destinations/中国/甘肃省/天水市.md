# 天水旅行指南

天水位于甘肃东南部，秦岭山地、黄土丘陵与渭河谷地在这里交会。城市旅行并不是围绕单一市中心展开：秦州区集中了伏羲庙、天水市博物馆、胡氏古民居和老城街巷，麦积区承担铁路、机场等交通功能，麦积山石窟则在麦积城区以外的山地。市域内的秦安大地湾、甘谷大像山、武山水帘洞和张家川马家塬博物馆又各在不同县域，适合按独立一日行程选择。

> 建议停留：2–4 天；县域目的地每处另加 1 天<br>
> 旅行关键词：麦积山石窟、伏羲文化、史前考古、明清古建、陇东南面食<br>
> 主要体力：市区中等步行；石窟栈道与县域山地为中高强度<br>
> 最近研究：2026-07-31

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 主要旅行价值 | 在秦州阅读伏羲祭祀传统、明清古建和地方博物馆，在麦积山观察丝绸之路佛教石窟艺术，再按兴趣延伸至大地湾史前遗址或县域石窟群 |

| 主要天气风险 | 5 月以后强对流、暴雨、山洪和地质灾害风险上升，山地还可能出现落石、湿滑和道路管制；盛夏有高温和强日照，冬春有雨雪、结冰、冻融和大风 |

| 长者与低体力旅行 | 可把秦州行程压缩为一馆一庙和一段老城；麦积山可查询当期不登临票型，但地面视角、接驳和全程无台阶条件都需确认，不应默认能够完整观看石窟 |
| 无障碍信息 | 伏羲庙游客中心公布了轮椅、休息和母婴服务，现代馆舍也可能提供协助；历史院落门槛、街巷铺装、山地接驳和石窟栈道无法据此视为连续无障碍，需逐段向官方确认 |

## 城市格局与游览区域

天水实行两区五县的行政格局：秦州区、麦积区构成主要城市核心，秦安县、甘谷县、武山县、清水县和张家川回族自治县分布在更广阔的山地与河谷。秦州与麦积之间需要乘公交、出租车或网约车移动；麦积山又在麦积城区东南方向，不能把“住在麦积区”理解为可以步行到石窟。天水经济技术开发区等属于功能管理区域，不是新增的法定县级行政区。

| 区域 | 主要内容 | 游览特点 | 与其他区域的关系 |
|---|---|---|---|
| 秦州西关与老城 | 伏羲庙—天水市博物馆、胡氏古民居、天水古城及餐饮街巷 | 主要点位相对集中，可步行与短途乘车结合；古建院落有门槛，商业街区在节假日拥挤 | 最适合组成首日；玉泉观位于老城北侧，可在体力允许时接续 |
| 秦州南北山体 | 玉泉观、南郭寺及城市山地景观 | 坡道、台阶和高差明显，夏季暴晒、雨雪和湿滑会放大体力负担 | 可分别接在秦州核心之后，不宜同日完成两处完整登高 |
| 麦积城区与交通走廊 | 天水站、天水南站、天水机场、商业与住宿 | 铁路和机场功能集中，城区沿渭河与交通轴展开；不同枢纽不能只写“天水车站” | 是秦州与麦积山之间的换乘基地，跨区移动要留出道路拥堵缓冲 |
| 麦积山地 | 麦积山石窟、仙人崖及大景区其他分区 | 石窟、栈道、山路和景区接驳共同决定游览能力；不同分区入口和开放状态可能不同 | 麦积山石窟应单独安排半天以上；仙人崖是另一处实体景区，不是石窟内部洞窟 |
| 秦安县 | 大地湾遗址及县城公共服务 | 遗址位于县域乡村，考古展示与复原展示需要区分；往返与最后一段交通占时 | 适合史前考古主题一日，不与麦积山或甘谷、武山同日拼接 |
| 甘谷县与武山县 | 大像山石窟、水帘洞石窟群 | 都在天水西部方向，但分属两县，且景区山地范围、道路和开放规则独立 | 每县选一处作为一日主目的地；“在同一铁路方向”不等于可连续游览 |
| 清水县与张家川回族自治县 | 赵充国陵园景区、马家塬车舆博物馆及县域文化 | 位于市域东部、东北部，公共交通与末班返程需要事先确认 | 各自按独立县域行程理解；不要把县城展馆算作麦积山顺路附属点 |

几个常见边界需要特别说明：

- **麦积山石窟只计一个景点。** 东崖、西崖、各编号洞窟、栈道路线和数字体验属于一次石窟参观的内部内容，不分别增加景点完成数。
- **麦积山石窟、麦积山景区与麦积山大景区不是完全相同的运营范围。** 强降雨时曾出现石窟关闭而其他游览区域继续开放的情况；仙人崖、石门等也是分别管理和核验开放状态的实体分区。
- **伏羲庙与大地湾讲述两类不同证据。** 伏羲是古史传说与祭祀传统中的文化祖先，伏羲庙是可核验的明清祭祀建筑；大地湾提供新石器时代考古材料，不能作为某位传说人物生平的考古证明。
- **胡氏古民居的南宅子、北宅子整体计一次。** 两组院落同属胡氏古民居与天水民俗博物馆的参观体系，不按院落数量重复计数。
- **天水古城是保护利用与当代经营并存的街区。** 适合作为伏羲庙、胡氏古民居之间的步行和餐饮节点，不应把整片街区描述成未经改变保存至今的单一古城遗址。

## 主要景点

优先级用于安排时间，不代表绝对排名：**A** 为首访核心，**B** 为按兴趣补充，**C** 为远郊或通常需要独立半天以上的目的地。车站、街区和观景平台可作为“路线节点”，不计入城市景点完成率。同一景区及其内部洞窟、院落、殿宇、展厅和接驳只作为一个项目记录。

伏羲庙与天水市博物馆由同一机构管理，门票、预约和当期开放展厅仍可能分项调整。阅读伏羲文化时，宜把“传说人物”“后世祭祀传统”“现存明清建筑”“博物馆藏品”分开理解；祭典、演出和数字体验属于动态活动，不是常设核心内容。

麦积山石窟是“丝绸之路：长安—天山廊道的路网”世界遗产系列项目的组成部分。完整登临要经过高空、狭窄且有连续台阶的栈道，官方历史公告曾区分较陡路线与相对平缓路线，也曾提供登临和不登临票型；路线、票型、开放洞窟及承载量会调整，不能把旧公告中的数字当作永久规则。雨雪、落石检查或文物保护可能只关闭石窟栈道，而大景区其他区域继续开放。

大地湾遗址的考古分期、复原展示和伏羲传说不能合并成一条未经证实的历史线。水帘洞石窟群中的拉梢寺等四个单元也不拆成四个“已完成景点”。县域场馆的开放日、乡村道路和返程班次比市区更容易变化，行程应以一个县、一个主目的地为单位。

## 美食与餐饮

天水饮食以小麦、荞麦、淀粉制品和酸辣调味为常见线索，油泼辣子、花椒、蒜、醋、芝麻酱等会在同一餐中叠加。秦州老城和麦积城区都能寻找日常小吃；热门时期无需只追一家店，可用“同类菜品、公开后厨或明码标价、客流可控、交通顺路”筛选替代。县域风味在产地更常见，但不值得为一顿饭跨县往返。

| 菜品或餐饮类型 | 常见区域 | 一个人用餐与常见份量 | 风味、过敏原与饮食限制 | 排队风险与替代方法 |
|---|---|---|---|---|
| 天水麻辣烫 | 秦州老城、麦积城区及商业街周边 | 多按食材自选或一人一碗，独行方便；先确认称重、串数或套餐计价 | 辣椒与花椒风味突出；汤底、丸类可能含肉、海鲜、蛋、奶或麸质，芝麻、花生和共锅交叉接触需询问。清淡需求应在下锅前说明 | 热门店和正餐时段排队高；优先选同区域经营稳定、标价清楚的同类店，不把甘谷辣椒或某家酱料视为唯一标准 |
| 天水呱呱、然然与面皮 | 老城早餐摊、小吃店、市场周边 | 通常为小碗或小份，适合一人早餐和加餐；多种淀粉小吃可少量组合 | 呱呱常见荞麦或其他淀粉，调料可能含芝麻酱、芥末、酱油、蒜和辣椒；荞麦、芝麻、大豆及麸质交叉接触需确认 | 早餐和节假日热门店排队较高；寻找现场拌制且可分开加辣、加蒜的同类摊店 |
| 浆水面或浆水拌汤 | 家常面馆、秦州与麦积城区 | 一人一碗，份量通常为正餐；酸味明显，初尝可先点小份 | 发酵浆水配小麦面食，常加韭菜、蒜和油泼辣子；含麸质，汤底是否纯素、是否共用肉汤需现场确认 | 排队通常低于网红小吃；选择客流稳定的家常面馆，同类替代比跨城追店更实际 |
| 猪油盒 | 老城小吃铺、早餐与点心店 | 单个点心，适合加餐，但油脂较高且宜趁热 | 常见面粉、生猪板油、大葱和胡麻油；含麸质、猪肉，不适合素食或需要清真饮食者 | 现做时可能等待；在同片区选择当日制作、周转快的点心铺即可 |
| 天水暖锅、八大碗与老三片 | 正餐馆、县区传统宴席餐饮 | 多为共享菜或组合菜，一个人不易完整体验；先问半份、小份或能否单点 | 常见猪肉、牛羊肉、丸子、夹板肉、蛋、豆制品和小麦制品，具体组合差异大；过敏、素食与清真需求必须逐项确认 | 节假日和晚餐排队中高；与两三人共享更合适，独行可改点杂烩、酸辣里脊等单菜或同风味小份 |
| 花牛苹果与时令果蔬 | 麦积及全市市场、正规特产店 | 适合一人购买，按实际食量少量选购 | 新鲜水果风险较低，但果干、果汁和加工品可能加糖或含其他配料；季节与产地标识需核对 | 不必追特定摊位；优先选择明码标价、可查看品相和产地信息的市场或商店 |

需要清真饮食时，应查看门店当期资质、询问肉类来源和共用锅具，不凭“西北菜”“牛羊肉”或街区位置推断。需要低辣时，麻辣烫、呱呱和浆水面都应在制作前沟通，因为成品辣油往往难以完全去除。

## 经典行程

### 一日经典路线

**路线**：伏羲庙—天水市博物馆 → 胡氏古民居（南北宅子） → 天水古城午餐与休息 → 玉泉观低段或完整游览

- **串联逻辑**：前半日在秦州西关连续阅读祭祀建筑、地方史与明代民居，午后再按体力决定是否登玉泉观；古城承担步行过渡和餐饮，不重复计入核心景点。
- **预约锚点**：伏羲庙—天水市博物馆及胡氏古民居的当期实名预约、票务和停止入馆时间。
- **休息安排**：天水古城或西关正规餐饮区安排长休，进入玉泉观前补水并判断天气。
- **时间不足时**：先删玉泉观登高，再缩短古城商业段；保留伏羲庙—市博和胡氏古民居两个核心组合。

### 两日城市路线

**第 1 天**：伏羲庙—天水市博物馆 → 胡氏古民居 → 天水古城<br>
**第 2 天**：秦州或麦积住宿地 → 麦积山游客中心 → 景区接驳 → 麦积山石窟 → 返回麦积城区或秦州

- **串联逻辑**：第一天只处理秦州老城，第二天完整留给麦积山，避免在双城与山地之间来回折返；石窟内部洞窟和两崖栈道仍是一项参观。
- **预约锚点**：先锁定麦积山石窟分时预约与票型，再安排两天顺序；秦州场馆同步核对闭馆日。
- **休息安排**：麦积山只在正式游客服务点和许可区域休息、补水，不在栈道停留阻塞；返城后再安排正餐。
- **时间不足时**：第二天取消附加影院、演出和其他大景区分区，不压缩石窟安全所需时间；若未取得石窟票，不用仙人崖冒充等价替代。

### 三日深度路线

**第 1 天**：秦州历史核心<br>
**第 2 天**：麦积山石窟<br>
**第 3 天**：玉泉观 → 午间长休 → 南郭寺，或另择仙人崖作为整日山地行程

- **串联逻辑**：第三天提供“秦州古建”与“麦积山地”两种完整主题，只选其一；仙人崖虽同属大景区体系，仍要单独计算交通和开放状态。
- **预约锚点**：麦积山石窟仍是全程第一锚点；仙人崖、玉泉观和南郭寺的门票、活动与施工按所选主题核对。
- **休息安排**：秦州方案在两座山地景区之间安排长午休，仙人崖方案使用景区正式服务区。
- **时间不足时**：秦州方案先删南郭寺，山地方案则整段取消仙人崖，不在返程前强行加入。

### 雨天路线

**路线**：天水市博物馆精选展厅 → 伏羲庙有遮蔽的短段 → 室内午餐 → 胡氏古民居已开放展室

- **适用条件**：只适用于普通降雨。伏羲庙和胡氏古民居都有院落与室外衔接；出现暴雨、雷电、山洪、地质灾害或城市积涝预警时，应减少出行并取消麦积山、玉泉观、南郭寺和全部县域山地。
- **预约锚点**：市博与胡氏古民居的开放展室和最后入馆时间，确认是否因维修或天气临时关闭院落。
- **休息安排**：以西关室内餐饮和游客中心为休息点，避免在古城湿滑铺装上长距离步行。
- **时间不足时**：只保留市博已开放展厅；强降雨时不以“石窟可能仍售景区票”作为进山理由。

### 亲子或低体力路线

**亲子路线**：天水市博物馆适龄展厅 → 伏羲庙短段 → 天水古城午餐 → 胡氏古民居精选院落

**低体力路线**：伏羲庙游客中心 → 天水市博物馆重点展厅 → 车辆前往胡氏古民居入口 → 西关短距离休息

- **减负方式**：亲子路线以室内讲解、院落观察和短距离步行为主，避开同日山地登高；低体力路线取消玉泉观、南郭寺和古城长步行。麦积山不登临票型只能作为另日备选，是否在售、接驳距离和可见内容均需官方确认。
- **预约锚点**：秦州场馆的儿童证件、讲解、寄存、婴儿车和轮椅规定；若另日去麦积山，单独确认年龄、票型和栈道安全要求。
- **休息安排**：使用伏羲庙游客中心公布的座椅、母婴和医疗服务，并核对胡氏古民居实际休息点；这些服务不等于两处之间全程无障碍。
- **时间不足时**：亲子路线先删胡氏古民居，低体力路线只保留伏羲庙—市博组合。

### 县域一日路线

从以下方向选择一个，不把多个县域目的地并成同一天：

- **秦安考古线**：秦州或麦积出发 → 大地湾遗址 → 遗址或县城正规服务区长休 → 原路返回。重点是实际考古遗存与展示，不用伏羲传说替代考古解释。
- **甘谷石窟线**：天水市区出发 → 甘谷县城交通衔接 → 大像山石窟 → 县城休息 → 返回。山脊各洞窟和古建整体计一次。
- **武山石窟线**：天水市区出发 → 武山县城或核定接驳点 → 水帘洞石窟群 → 返回。四个石窟单元整体计一次，雨雪和道路状况是首要门槛。
- **东部县域线**：清水赵充国陵园景区或张家川马家塬车舆博物馆二选一 → 县城午餐 → 返回。两县不是同一站点，也不属于麦积山内部线路。

- **适用条件**：已落实往返车辆、末班交通、天气和景区开放；县域铁路或客运只能解决部分路段，最后一段常需公交、出租车或预约车辆。
- **预约锚点**：所选遗址、石窟或博物馆的开放公告，以及可靠返程；大地湾和马家塬车舆博物馆尤其要核对闭馆日。
- **休息安排**：只在县城或景区正式服务区域用餐补给，乡村道路沿线不预设随时有餐饮和卫生间。
- **时间不足时**：取消整段县域行程，改回秦州或麦积城区；不要为了“打卡”省略山地安全和返程缓冲。

## 住宿区域

| 区域 | 优点 | 缺点 | 适合人群 | 交通特点 |
|---|---|---|---|---|
| 秦州西关—伏羲庙周边 | 接近伏羲庙、胡氏古民居、古城和小吃，首日步行效率高 | 节假日拥挤、夜间噪声和停车压力较大；去铁路站和麦积山需要跨区 | 首次到访、以历史文化和餐饮为主的旅行者 | 公交、出租车连接麦积城区；道路拥堵时要为天水南站和麦积山方向留缓冲 |
| 秦州中心城区 | 餐饮、商业和城市服务选择多，比最热门古城街区更容易平衡安静与便利 | 具体住宿到景点仍可能需要公交或车辆，不等同于所有老城点位步行可达 | 停留三天以上、希望兼顾市区服务和古建路线的旅行者 | 适合作为秦州与县域公路行程基地；前往麦积山仍是独立跨区移动 |
| 麦积城区—天水站周边 | 普速铁路到发方便，距麦积山方向相对更顺，日常餐饮完整 | 距秦州历史核心较远，站前道路和早晚噪声可能明显 | 普速列车到发、把麦积山安排在抵达次日的旅行者 | 天水站不是天水南站；景区公交、出租车和返程时间需重查 |
| 天水南站周边 | 高铁到发和首末日衔接方便，可减少携带行李跨城 | 周边街区与秦州老城、麦积山入口仍有距离，晚间餐饮密度因具体位置而异 | 高铁晚到早走、第二天去麦积山或继续跨城的旅行者 | 先确认住宿到实际进站口、公交站和网约车上客点，不把站名当作景区近邻 |
| 麦积山游客中心与景区外围 | 有利于较早进入景区，减少从秦州出发的晨间通勤 | 住宿、餐饮、夜间交通和医疗选择少，山地天气与道路更易影响计划 | 已取得早时段预约、明确以麦积山为主且能接受山地条件的旅行者 | 自驾或预约车辆更稳妥；景区门口住宿不代表可绕过游客中心、接驳和分时入园 |
| 所选县城 | 便于次日早访大地湾、大像山、水帘洞或县域博物馆，也降低当晚赶回市区的压力 | 只对一个明确县域目标有价值，不能兼顾秦州与麦积山 | 连续考古、石窟专题或公共交通班次有限时的旅行者 | 分别核对秦安、甘谷、武山、清水或张家川的客运、铁路和最后一段交通 |

## 市内交通

截至本页研究日，天水没有把主要旅行区域串成一条连续步行轴。秦州和麦积构成双核心，城市有轨电车、公交、出租车和网约车共同承担跨区移动；麦积山与各县域目的地则需要景区接驳、城乡客运或已落实的车辆。有轨电车的一、二期线路沿两区交通走廊展开，并覆盖天水南站走廊及天水站方向支线，但交路、终点站名和换乘组织已有调整记录，实时信息不能写成长期不变的事实。

| 场景 | 建议与取舍 | 行前需要重查的内容 |
|---|---|---|
| 天水站到达 | 天水站位于麦积城区，适合普速铁路到发和麦积城区住宿；去秦州或麦积山仍需继续乘车 | 车次实际到发站、公交线路、出租车上客点和夜间末班 |
| 天水南站到达 | 天水南站承担高铁到发，可向秦州、麦积城区或麦积山方向分流，但三者都不是出站即达 | 车票站名、站口施工、行李寄存、景区公交与末班车 |
| 天水机场到达 | 机场位于麦积区，航线数量有限且调整频繁；若衔接石窟或县域行程，应给航班延误和地面交通留余量 | 航线、航站手续、机场巴士、出租车服务和实际运营日期 |
| 有轨电车 | 适合沿秦州—麦积东西走廊移动，也可衔接天水南站走廊和天水站方向；去往支线时可能涉及换乘 | 当前交路、终点站名、运营时段、票价、换乘站和站口无障碍设施 |
| 秦州—麦积跨区 | 公交适合预算有限且时间宽松者，出租车或网约车更便于携带行李和早晚移动 | 高峰拥堵、道路施工、首末班和大型活动管制 |
| 麦积山石窟 | 自驾车辆按当期规则停在指定游客中心或停车区域，再使用景区接驳；公共交通适合已确认班次的白天往返 | 分时预约、游客中心位置、观光车、景区公交、停车、道路管制和末班返程 |
| 县域目的地 | 铁路或长途客运可能只到县城，遗址和山地石窟的最后一段通常仍要本地交通；一个县只安排一个主目标 | 客运站位置、列车停靠、乡村公交、包车合规性、返程与天气封路 |
| 秦州老城步行 | 伏羲庙、古城与胡氏古民居可分段步行，玉泉观需额外登高；古街门槛、石板和拥挤会影响婴儿车与轮椅 | 临时封路、活动人流、院落入口、无障碍绕行和夜间照明 |
| 自驾 | 对麦积山和县域最有机动性，但城市停车、山路弯坡、落石、雨雪和节假日分流需要额外判断 | 景区预约是否绑定车辆、停车场容量、道路结冰、地质灾害预警和临时交通管制 |

历史攻略中的某条公交直达、固定机场航线或“距市区多少公里”很容易因参照中心和运营调整而失真。规划时应分别输入“天水站”“天水南站”“天水机场”“麦积山游客中心”和具体县域场馆，不用笼统的“天水市区”代替目的地。

## 不同旅行者须知

| 旅行维度 | 安排建议与限制 |
|---|---|
| 独行旅行 | 秦州小吃、博物馆和两区公交便于独自安排；暖锅、八大碗等先问小份。麦积山和县域要提前确认返程，不在山地闭园后临时寻找陌生车辆 |
| 亲子旅行 | 市博精选展厅、伏羲庙短段和胡氏古民居适合做历史主题；高空栈道、山路、水边和拥挤时段需按年龄、体力与陪同规则取舍，推车不能进入的路段要有替代方案 |
| 长者或低体力旅行 | 一天一座主要场馆加一处短距离院落，秦州—麦积尽量乘车；麦积山不登临票型、接驳和休息点全部在出发前确认，玉泉观、南郭寺和县域山地可直接取消 |
| 无障碍需求 | 伏羲庙游客中心提供部分辅助服务，但古建门槛、胡氏民居院落、古城铺装和石窟栈道的连续通行资料不足；逐段确认停车点、入口、电梯或坡道、卫生间和返程，设施连续性需向官方确认 |
| 摄影旅行 | 秦州院落适合建筑细节，麦积山适合崖壁与山地空间；洞窟内部、祭祀空间、展柜、三脚架、闪光灯、无人机和商业拍摄均服从当日规定，不以网络照片推断可拍范围 |
| 预算有限 | 住在公交便利的秦州或麦积城区，以一日一区减少车费；优先市博、街区和已确认低价或免费空间，在麦积山接驳与县域交通中预留不可压缩的安全支出 |
| 晚出发或紧凑行程 | 下午开始只选伏羲庙—市博或胡氏古民居其中一组，不跨秦州、麦积和麦积山三处；到站后若赶不上石窟预约时段，应改到次日而不是缩短安全流程 |
| 雨季与高温 | 高温时减少正午登山，补水、防晒并安排室内长休；强降雨、雷暴或地质灾害预警时取消石窟、山谷和乡村道路，注意城市低洼路段积水 |
| 冬季与冻融 | 山地道路、台阶和栈道可能积雪结冰，早晚温差与短日照压缩行程；冬末春初冰雪消融也会提高部分坡体风险，不能因天气晴朗就跳过道路和景区公告 |
| 文化与宗教场所 | 伏羲庙的祭祀活动、佛教石窟和寺观都按现场规定着装、拍摄和保持安静；不触碰造像、壁画、碑刻与供器，不把正在进行的仪式当作表演围拍 |

## 行前核对

以下事项具有明显时效性，应在出发前重新确认：

- **麦积山预约与票型**：通过“麦积山石窟”“麦积山旅游”等官方入口核对放票时间、实名要求、预约时段、登临或不登临票型、开放洞窟、参观路线、承载量和退改规则。旧公告中的人数与路线不作为永久事实。
- **麦积山接驳与分区开放**：核对车辆停放、游客中心、观光车、景区公交和返程；分别确认石窟、仙人崖、石门等区域状态。石窟关闭不自动等于整个大景区关闭，反之亦然。
- **秦州场馆**：确认伏羲庙—天水市博物馆、胡氏古民居、玉泉观和南郭寺的闭馆日、门票、停止入场、维修与活动。伏羲祭典、节庆、演出和数字体验只按当期公告加入。
- **县域目的地**：逐一核对大地湾遗址、大像山、水帘洞石窟群、赵充国陵园景区和马家塬车舆博物馆的开放范围、讲解、闭馆日、道路与最后一段交通，不依据旧游记直接进山。
- **铁路、机场和公交**：在 12306、航空公司、机场及本地交通官方渠道确认天水站、天水南站、航班、跨区公交、景区线路、县域客运和末班时间。
- **暴雨、山洪与地质灾害**：出发前三日和当天查看气象、应急、自然资源、交通与景区公告；强降雨后即使天气转晴，也要等待道路、崖壁和栈道安全检查结论。
- **高温、雨雪与道路结冰**：夏季核对高温、雷电和冰雹预警，冬季核对降雪、寒潮、结冰和冻融；山地天气与秦州城区可能不同。
- **无障碍与重点服务**：向每个场馆确认轮椅借用、坡道、卫生间、陪同、接驳车上下车和栈道替代视角；官方“无障碍阅读”网页或游客中心有轮椅，不等于全线路无障碍。
- **餐饮与活动**：具体门店营业、排队、明码标价和过敏原信息会变化；热门麻辣烫店可用同区域同类型店替代。需要清真、素食或严重过敏管理时，现场确认资质、汤底与共用厨具。
- **入境与安全规则**：跨境旅行者按国籍、证件和出发地查询中国外交、移民管理及驻外使领馆最新要求；国内旅行者也应携带满足实名预约和铁路乘车要求的有效证件。
