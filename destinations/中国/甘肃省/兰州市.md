# 兰州旅行指南

兰州沿黄河河谷东西伸展，南北山体把城市压缩成狭长带状。中山桥、黄河风情线、白塔山和牛肉面构成直观的城市印象，甘肃省博物馆、甘肃简牍博物馆和兰州市博物馆则分别从全省、简牍专题和本地城市史补全丝路脉络。中心城区以外，水墨丹霞和河口古镇都需要专门交通；临夏、甘南、张掖和敦煌更是独立的跨市目的地，不能因兰州是交通门户而压缩成城市近郊。

> 建议停留：市区 2–3 天；水墨丹霞或河口古镇各增加半天至 1 天\
> 旅行关键词：黄河河谷、丝路文博、中山桥、白塔山、简牍、牛肉面、丹霞\
> 主要体力：市区中等步行；白塔山、五泉山与远郊为中高强度\
> 最近研究：2026-07-30

## 城市格局与游览区域

兰州主城区被皋兰山、白塔山等南北山体夹在黄河两侧，东西方向远长于南北方向。城关区承担老城、兰州站和主要商业文化功能；七里河区集中了甘肃省博物馆、兰州西站、甘肃简牍博物馆和黄河楼；安宁区沿北岸向西展开；西固区继续向西连接工业城市记忆与河口古镇。兰州新区和中川机场位于主城区以北的另一片城市空间，不能按“机场在市内”估算通勤。

| 区域 | 主要内容 | 游览特点 | 与其他区域的关系 |
|---|---|---|---|
| 中山桥—黄河中心段 | 中山桥、黄河母亲雕塑、水车博览园及沿河公共空间 | 景点沿河分散，不宜全程步行；桥、雕塑和水车等按一条黄河中心段理解 | 可在中山桥北端接白塔山，向西可到七里河，但应搭配公交、地铁或短途车辆 |
| 白塔山北岸 | 白塔山公园、白塔寺、碑林与俯瞰城市的高点 | 从河边向上高差明显，台阶和坡道连续；缆车或车辆服务不能视为永久可用 | 与中山桥形成最经典的南北组合，不宜同日再完整攀登五泉山 |
| 城关老城与五泉山 | 张掖路、兰州市博物馆、五泉山公园及城市餐饮 | 市中心商业与文化点位密集，五泉山位于南侧山麓并有明显爬升 | 可与黄河中心段分成两半天；兰州站在城关东部，不等于步行可达所有老城点位 |
| 七里河省博—兰州西站 | 甘肃省博物馆、铁路枢纽和周边商业 | 省博是大型室内锚点，兰州西站适合高铁到发；道路和站区尺度较大 | 地铁 1 号线连接城关，省博参观后可向东去黄河母亲一带 |
| 马滩—黄河楼—简牍博物馆 | 甘肃简牍博物馆、黄河楼、兰州老街一带餐饮与公共空间 | 两座文化场馆较近，兰州老街主要承担餐饮和休息，不作为古城遗存计数 | 位于主城区西部，可独立组成一天；不必在同日往返城关多次 |
| 安宁与西固 | 北岸大学城区、湿地公园、西固城市空间及河口古镇方向 | 城市继续向西延伸，工业区、居住区和远郊古镇并存，直线距离容易低估移动 | 河口古镇在西固区更西端，应按专程半日或一日安排 |
| 水墨丹霞方向 | 永登县树屏镇及永登、皋兰交界处的丹霞景区 | 大型户外景区，依赖景区交通、观景平台、天气和返程 | 与张掖七彩丹霞不是同一景区；从主城区往返通常占半天以上 |
| 兰州新区与中川机场 | T3 航站楼、中川机场东站、兰州新区站及新区城市功能 | 与主城区相隔较远，机场过夜和城市观光住宿的逻辑不同 | 城际铁路和机场巴士连接主城区；兰州新区站不是机场航站楼下方的车站 |

几个机构与目的地边界需要明确：

- **甘肃省博物馆、甘肃简牍博物馆和兰州市博物馆是三个独立公共场馆。** 省博讲全省历史与自然，简牍博物馆聚焦出土简牍和边塞文书，市博以兰州地方史及白衣寺塔为重要内容；同一天全量参观三个馆会产生明显信息疲劳。
- **敦煌研究院是文物保护与研究机构，不是一座集中在兰州的“敦煌景区”。** 兰州院部负责行政、研究与敦煌艺术馆公共文化服务；只有敦煌艺术馆正式公告开放的展览和活动可以作为兰州参观内容，办公与研究区域不默认对公众开放。
- **机构管理关系不改变遗址所在地。** 莫高窟在敦煌，炳灵寺石窟在临夏州永靖县，麦积山石窟在天水；即使相关保护研究单位与敦煌研究院有关，也不计入兰州景点。
- **省博展陈不替代原属地旅行。** 在兰州看到敦煌、张掖、临夏或甘南相关文物和资料，只是建立省域背景，不能替代对应城市、遗址和自然区域。
- **兰州水墨丹霞与张掖七彩丹霞完全不同。** 前者在兰州市域近郊，后者位于张掖市临泽县、肃南县，交通和住宿应分别安排。

## 主要景点

优先级用于安排时间，不代表绝对排名：**A** 为首访核心，**B** 为按兴趣补充，**C** 为远点、季节性或通常需要独立半天以上的项目。桥梁、雕塑、商业街入口和观景平台可作为路线节点，不重复计入完成率。同一公园或景区的内部寺院、展馆、观景台、演出和接驳只作为一个项目记录。

## 美食与餐饮

兰州牛肉面是最容易进入城市日常的食物：一人一碗，常在早晨和午间最有生活感，面型、辣度、加肉和加蛋可以分别选择。它不是素面，汤底通常含牛肉和骨汤；面条由小麦制成。牛肉面之外，酿皮、甜醅子、灰豆子、热冬果、三炮台茶与羊肉菜构成更完整的地方饮食。正宁路、南关、大众巷、张掖路和普通居民区都有餐饮密集点，热门夜市适合集中尝试，却不代表单店不可替代。

| 菜品或餐饮类型 | 常见区域 | 一个人用餐与常见份量 | 风味、过敏原与饮食限制 | 排队风险与替代方法 |
|---|---|---|---|---|
| 兰州牛肉面 | 全城早餐店、社区与交通枢纽周边 | 一人一碗，牛肉、鸡蛋和小菜通常另点；面型可从细面、二细、韭叶、宽面等常见选项中选择 | 小麦麸质、牛肉与骨汤是核心，辣油可分量调整但共享器具无法保证无交叉接触；汤清不等于低盐或素食 | 热门店早午餐排队高，居民区同类型门店很多；优先看现场制面、明码标价和食材周转，不为单店跨城 |
| 酿皮子 | 小吃街、凉皮店与市场周边 | 一份适合一人，可与其他小吃分食 | 常以小麦面筋和淀粉制品为主，含麸质，调料可能有芝麻、花生、辣椒、醋和蒜 | 夜市排队时换社区小吃店；先确认是高担酿皮、普通酿皮还是其他做法，口感与配料不同 |
| 甜醅子 | 小吃店、甜品摊与夏季餐饮 | 杯装或碗装，适合一人小份 | 以发酵谷物为主，可能含青稞、小麦或燕麦成分，含少量发酵产生的酒精和较多糖；严格无麸质或禁酒需避开 | 季节和温度影响供应，可用灰豆子或热冬果等当地甜品替代 |
| 灰豆子与热冬果 | 老城甜食店、夜市及冬季摊点 | 通常是一人一碗，适合步行间休息 | 灰豆子为豆类甜食，热冬果以梨类甜汤为主；都可能高糖，坚果、枣和其他配料逐店询问 | 热门夜市晚间排队高，在老城普通甜食店寻找同类即可 |
| 牛奶鸡蛋醪糟 | 夜市和甜食店 | 一人一碗，饱腹度高 | 含乳制品、鸡蛋和发酵米酒，常撒芝麻、花生、葡萄干或坚果；乳糖不耐、蛋奶或坚果过敏者谨慎 | 排队高时选择配料标示更清楚的甜食店，不以短视频热门摊为唯一答案 |
| 手抓羊肉 | 清真餐馆、羊肉馆与多人餐桌 | 常按重量或盘装，较适合 2 人以上共享；一人先问最小份 | 含羊肉，蘸料可能含辣椒、椒盐和醋；是否符合特定清真认证、锅具是否共用需向餐厅确认 | 热门时段等待较长，可换小份羊肉、羊肉汤或其他按碗供应的餐食 |
| 烤羊肉与羊杂 | 夜间餐饮、烧烤店和社区市场 | 烤串容易控制份量，羊杂汤多为一人一碗 | 辣椒、孜然、动物脂肪和内脏较常见；烤架、调料和餐具存在交叉接触 | 不必限定夜市，可选通风、明码标价且食材保存清楚的正规门店 |
| 三炮台茶 | 茶园、餐馆和黄河沿岸休息区 | 一杯可慢饮，适合长休，也常与多人聊天共享续水 | 常见茶叶、冰糖、红枣、桂圆、葡萄干和枸杞，部分配方含坚果；糖分和配料可先询问 | 沿河景观位可能等位，离开最热门桥头后仍有同类茶园 |
| 兰州百合菜 | 本地菜馆、宴席餐馆和部分甜品店 | 清炒百合常为共享菜，百合甜品可一人一份；先问份量和做法 | 口味可清甜或与肉类同炒，甜品可能含乳制品、蛋和坚果；植物过敏者询问配料 | 不必追特定餐厅，可在菜单标明本地百合的正规餐馆选择当季做法 |

兰州百合常用于清炒、甜品或宴席菜，单人点餐时先问份量和是否与肉类同炒。需要清真、素食、低盐、无麸质、无乳糖或无坚果饮食时，应逐店确认原料、汤底、发酵成分和共用锅具；“不放肉片”不代表汤底无肉。

## 经典行程

以下路线按东西城区和场馆尺度组合，不是分钟级课表。兰州的地理形态决定了“少折返”比“多打卡”更重要；预约时段、天气和远郊返程优先于书面顺序。

### 一日经典路线

**路线**：甘肃省博物馆 → 七里河牛肉面午餐 → 黄河母亲雕塑附近短段 → 中山桥 → 白塔山低段或观景台

- **串联逻辑**：上午以省博建立甘肃历史框架，午后沿黄河由西向东分段移动，最后在中山桥北侧决定是否登白塔山；省博到中山桥之间不建议全程步行。
- **预约锚点**：甘肃省博物馆；登山、索道或夜游没有可靠公告时不作为锚点。
- **休息安排**：省博参观后在七里河完整午餐，中山桥附近安排茶园或室内长休，避开正午登山。
- **时间不足时**：先删白塔山登高，再删黄河母亲以西的延伸步行；保留省博、中山桥和一小段河岸。

### 两日城市路线

**第一日**：甘肃省博物馆 → 黄河中心段 → 中山桥 → 白塔山按体力取舍\
**第二日**：甘肃简牍博物馆 → 马滩或兰州老街午餐与休息 → 黄河楼 → 西部河岸短段

- **串联逻辑**：第一日从七里河向城关移动，第二日集中在更西的马滩文化区，避免连续两天跨全城往返；两个大型博物馆各占半天。
- **预约锚点**：分别锁定省博和简牍博物馆；黄河楼票务和展演仅在确定后加入。
- **休息安排**：第二日把兰州老街当作餐饮和室内休息区域，不把仿古商业空间当作历史街区完成项。
- **时间不足时**：先删黄河楼的夜间内容，再缩短河岸；不压缩简牍馆到匆忙走完全部展厅。

### 三日深度路线

**第一日**：省博与黄河中心段\
**第二日**：简牍博物馆与黄河楼\
**第三日**：五泉山公园 → 城关区午餐与长休 → 兰州市博物馆 → 敦煌艺术馆按开放公告选加

- **串联逻辑**：第三日集中在城关，以城市山体和本地历史补充前两日的省域、简牍主题；馆与馆之间使用公交或短途车辆，不假定全程步行。
- **预约锚点**：兰州市博物馆和敦煌艺术馆的当期开放信息；敦煌艺术馆若仅有预约活动，就不作为固定日程。
- **休息安排**：五泉山下山后安排长午休，下午只选一座馆；不在同日再登白塔山。
- **时间不足时**：先删敦煌艺术馆，再缩短五泉山高处路线；保留市博作为理解兰州本地历史的室内锚点。

### 雨天、沙尘或严寒路线

**路线**：甘肃省博物馆或甘肃简牍博物馆二选一 → 室内午餐 → 同一区域短距离补充

- **串联逻辑**：恶劣天气下把一天收缩到一座大型馆，减少在桥面、河岸、山体和宽阔站前道路暴露；强降雨时也不前往丹霞和古镇。
- **预约锚点**：选择已成功预约且交通最顺的一馆，不同时押注两个热门场馆。
- **休息安排**：每参观一至两个主题展厅就休息，冬季注意室内外温差和干燥。
- **时间不足时**：只看两到三个核心展览；取消全部室外续程，不以购物中心替代文化内容。

### 亲子或低体力路线

**路线**：甘肃省博物馆精选展厅 → 七里河午餐 → 车辆前往黄河母亲雕塑 → 中山桥南岸平缓短段

- **串联逻辑**：一个大型室内馆加两个短停节点，避免白塔山和五泉山的连续台阶；是否真正无台阶取决于入口、电梯、道路施工和河岸坡道。
- **预约锚点**：省博，并同步询问轮椅、婴儿车、寄存、无障碍卫生间和临时展厅情况。
- **休息安排**：午餐后再决定是否去河边，中山桥只走到适合折返的位置。
- **时间不足时**：删去中山桥，省博只选适龄展厅；设施连续性需向官方确认。

### 水墨丹霞一日路线

**路线**：主城区出发 → 水墨丹霞游客中心 → 景区观光车与核心观景平台 → 按公告选择地质科普或演出 → 返城

- **串联逻辑**：游客中心、观光车、平台、漂流和演出都属于一个景区，往返与园内移动足以占半天至一天；地质景观优先于附加游乐。
- **预约锚点**：景区门票、观光车和可靠往返交通，同时核对强风、雷雨、高温及停运公告。
- **休息安排**：在正式服务区补水、防晒和用餐；观景台之间利用园内交通，不用步行追全部点位。
- **时间不足时**：先删演出和游乐项目，再删次要平台；天气恶化时取消整段户外行程。

### 河口古镇一日路线

**路线**：主城区出发 → 河口古镇主街与公共历史空间 → 午餐与长休 → 按开放选择古院落或非遗活动 → 黄河交汇区域短段 → 返城

- **串联逻辑**：古镇位于西固更西端，交通往返不可忽略；主街、民居、海关旧址和活动作为一个古镇景区，不以院落数量增加完成率。
- **预约锚点**：往返车辆或公共交通的末班信息；收费院落和活动仅在确认开放后加入。
- **休息安排**：在古镇正规餐饮和游客服务区域安排午餐，夏季避开午后长时间无遮挡步行。
- **时间不足时**：删去临时市集和黄河沿岸延伸段，保留主街与一处已开放历史空间；返程优先。

## 住宿区域

| 区域 | 优点 | 缺点 | 适合人群 | 交通特点 |
|---|---|---|---|---|
| 西关—张掖路—中山桥南 | 接近黄河中心段、老城餐饮和地铁 1 号线，夜间步行选择多 | 热门时段人流、噪声和道路拥堵明显；到省博、简牍馆和机场仍需交通 | 首次到访、以黄河与老城为主的旅行者 | 地铁 1 号线连接七里河和东部，去白塔山可过中山桥；具体出口与施工需核对 |
| 东方红广场—城关中心 | 去五泉山、兰州市博物馆、兰州大学方向和商业区较均衡 | 与中山桥、兰州站都不是同一个步行核心，主干道尺度大 | 三日城市游、需要兼顾城关多个方向的旅行者 | 1、2 号线可换乘，公交密集；机场仍需铁路或巴士 |
| 甘肃省博物馆—兰州西站 | 省博和高铁站近，抵离城市方便，餐饮与商业较完整 | 距中山桥和城关老城有东西通勤，站区人流与道路复杂 | 高铁到发、首日或末日参观省博的旅行者 | 地铁 1 号线连接主城区；确认“兰州西站北广场”与实际进站口关系 |
| 马滩—简牍博物馆—黄河楼 | 简牍馆和黄河楼组合方便，现代住宿和商业空间较多 | 离城关传统核心较远，晚间返回依赖地铁、公交或车辆 | 简牍专题、亲子和希望降低第二日移动量的旅行者 | 靠近地铁 1 号线马滩方向，仍要核对住宿到场馆入口的最后一段 |
| 兰州站周边 | 普速和部分动车到发便利，清晨出发较省时间 | 站前道路、噪声、行李和车流负担较高，到黄河核心仍需城市交通 | 晚到早走、下一程从兰州站出发的旅行者 | 地铁 2 号线接入，不能与兰州西站或兰州新区站混淆 |
| 兰州新区—中川机场 | 早班机、深夜到达或新区事务更方便 | 距主城区主要景点远，不适合作为连续城市观光基地 | 只在航班或新区行程决定住宿时考虑 | T3 下方为中川机场东站；兰州新区站是另一铁路站，机场巴士和列车班次需重查 |

河口古镇和水墨丹霞一般不作为首次兰州市区游的住宿基地。只有明确安排连续远郊活动、景区夜间项目或次日向河西走廊出发，并已落实合法住宿和交通时，才考虑在相应方向停留。

## 市内交通

兰州交通首先要分清“主城区东西轴”和“机场—新区北向轴”。轨道交通 1 号线承担主城区东西向骨架，连接兰州西站、七里河、西关、城关东部等区域；2 号线服务兰州站、东方红广场、五里铺和雁滩方向，并与 1 号线换乘。两条地铁都不直达中川机场，机场依靠城际铁路、机场巴士和道路交通连接主城区。

| 枢纽或方式 | 位置与作用 | 旅行者容易混淆之处 |
|---|---|---|
| 兰州中川国际机场 T3 | 位于兰州新区方向，2025 年启用 T3 后航班集中在新航站楼；中川机场东站位于 T3 综合交通中心下方 | 机场离主城区远，不能按普通市内机场预留时间；T1、T2 状态、航空公司柜台、机场巴士和铁路交路仍应临行核对 |
| 兰州站 | 城关区东部的传统铁路枢纽，地铁 2 号线可接入 | 与老城黄河核心仍有距离；车票上的“兰州”不等于“兰州西” |
| 兰州西站 | 七里河区重要高铁枢纽，靠近省博方向，地铁 1 号线可接入 | 站体与道路尺度大，出站口、地铁入口和网约车上客点会影响换乘时间 |
| 兰州新区站 | 位于兰州新区，是机场铁路与新区交通节点 | 不是 T3 航站楼下的机场站；乘飞机通常应核对车票是否到“中川机场东站” |
| 中川机场东站 | 与 T3 衔接的铁路车站，可由兰州站、兰州西站等方向乘部分列车到达 | 并非每趟列车都停靠同样车站，班次、始发终到和运行时间以 12306 当日结果为准 |
| 地铁 1、2 号线 | 1 号线适合东西向城市移动，2 号线连接兰州站和城关东部，两线在东方红广场、五里铺换乘 | 首末班、施工、站口电梯与票价会变化；站名靠近景点不代表入口全程遮雨或无台阶 |
| 公交、出租车与网约车 | 补足黄河两岸、五泉山、马滩和场馆入口之间的最后一段 | 东西主干道高峰拥堵，桥梁和大型活动管制会放大时间；远郊返程不能只依赖临时叫车 |
| 景区直通车与自驾 | 水墨丹霞、河口古镇等远点可能有季节直通车，自驾提高机动性 | 线路、发车点、停车、山路和末班最易变化；只把已经确认的班次写入当日计划 |
| 步行与沿河活动 | 中山桥周边、各博物馆内部和黄河短段适合步行 | 黄河风情线很长，桥下通道、堤岸坡道、风沙和高温都会增加体力；不在非开放水域下水 |

需要重点旅客或无障碍协助时，可通过 12306、航空公司、机场和兰州轨道交通官方渠道提前申请。地铁站内服务、铁路站内服务和机场服务各自只覆盖运营范围；住宿门口、道路过街、河岸坡道、山体公园和景区观光车能否连续衔接，需向官方确认。

## 不同旅行者须知

| 旅行维度 | 安排建议与限制 |
|---|---|
| 独行旅行 | 牛肉面、小吃和博物馆适合一人安排，地铁能覆盖多数城市核心；手抓羊肉与大盘热菜先问最小份。水墨丹霞、河口古镇和深夜机场返程要预先落实 |
| 亲子旅行 | 省博、简牍馆和黄河短段可按年龄组合；丹霞附加游乐、羊皮筏子、游船和演出逐项核对身高、年龄、天气与陪同规则，不用“亲子景区”标签代替安全条件 |
| 长者或低体力旅行 | 一天只安排一座大馆加一段平缓河岸，跨东西城区乘地铁或车辆；白塔山只看低段或从南岸观景，五泉山和远郊山地可取消 |
| 无障碍需求 | 地铁和交通枢纽提供部分电梯、宽通道与预约帮助，现代博物馆也有相关服务；历史塔院、桥面衔接、山体台阶、河岸坡道和景区观光车资料不完整，设施连续性需向官方确认 |
| 摄影旅行 | 中山桥南北两岸、白塔山高点和水墨丹霞分别适合城市、河谷和地貌主题；强风、沙尘和阴雨影响视野，无人机、三脚架、馆内摄影和商业拍摄均服从当日规定 |
| 预算有限 | 以已确认免费的公共博物馆、黄河短段和城市公园为骨架，用地铁减少道路交通成本；在黄河楼、丹霞演出、游船和远郊包车中按主题取舍 |
| 晚出发或紧凑行程 | 下午才开始时只选中山桥—白塔山低段或一座已预约博物馆，不从兰州西站、兰州站和机场之间反复横移；夜景不能替代白天展陈 |
| 干燥、风沙与温差 | 补水、润唇、防晒和防风比单看最高温更重要；沙尘或大风时减少山顶、桥面和丹霞暴露。兰州主城区不是典型高原适应目的地，但海拔、干燥和昼夜温差仍可能使心肺疾病或敏感人群不适 |
| 宗教与文化场所 | 白塔山、五泉山及周边寺观按现场规定着装、拍摄和进入殿堂；不触碰供器、塑像和展品，不把正在进行的宗教活动当作表演围拍 |

继续前往甘南时，海拔、道路和医疗条件会明显改变；前往临夏炳灵寺、张掖丹霞或敦煌荒漠时，水路、山地、强风和长距离交通风险也各不相同。兰州的适用判断不能直接复制到下一目的地。

## 行前核对

以下事项具有明显时效性，应在出发前重新确认：

- **博物馆开放与预约**：核对甘肃省博物馆、甘肃简牍博物馆、兰州市博物馆的闭馆日、实名预约、停止入馆、临展换展和明星文物轮换；免费不代表免预约。
- **敦煌艺术馆公共开放**：只依据敦煌研究院当期公告确认开放日、展览、公益讲解和社教活动，不把兰州院部办公区视为常设景点。
- **山体与黄河项目**：查看白塔山、五泉山的施工、台阶、缆车或车辆服务，以及游船、羊皮筏子、夜游、灯光和索道是否运营；大风、雷电或高水位时可能停运。
- **远郊景区**：确认水墨丹霞门票、观光车、演出、游乐项目、直通车和末班；确认河口古镇收费院落、非遗活动、道路和返程。临时优惠不写成永久票价。
- **机场与铁路**：在航空公司、机场和 12306 核对航站楼、列车到发站、兰州站、兰州西站、兰州新区站与中川机场东站的实际停靠；不要沿用旧攻略中的中川机场站名称或时刻。
- **地铁与道路**：查看 1、2 号线首末班、站口施工、电梯检修、桥梁管制、马拉松或大型活动封路；东西城区高峰时间另留缓冲。
- **天气与自然风险**：查询甘肃气象部门的大风、沙尘、雷电、暴雨、山洪、高温、寒潮和道路结冰预警；丹霞、古镇、桥面和山体路线按临近日期调整。
- **无障碍与重点旅客服务**：逐段确认住宿—地铁或铁路—场馆入口—馆内电梯—卫生间—返程，提前预约轮椅、渡板、人工引导或机场特殊服务。
- **餐饮营业与饮食限制**：牛肉面店营业时段、夜市摊位和具体餐厅存续会变化；过敏原、清真认证、汤底、发酵食物与共用锅具需现场再次询问。
- **跨市续程**：临夏、甘南、张掖和敦煌分别核对住宿、天气、景区交通及返程，不以兰州出发的理论车程推导当天可游览时间。
