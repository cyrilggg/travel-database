# 山西省旅行目的地

山西的古建筑、石窟、壁画、古城和晋商遗产分布在多个城市与县域，省会太原只是其中一个入口。太原适合用晋祠、府城古建和省市级博物馆建立山西历史的基本时间线；大同、平遥、五台山、晋南古建群等目的地需要跨城移动，不应作为太原市内景点排列。

## 区域格局与城市组合

太原位于山西中部，是省内铁路、公路和航空交通的重要集散地。大同是山西北部独立的地级市；五台山主要位于忻州市五台县；平遥古城位于晋中市平遥县；乔家大院位于晋中市祁县。这些目的地可以和太原组成多日线路，但都不属于太原市景点范围。

跨城安排行程时应注意：

- 太原与平遥之间有铁路和公路联系，但平遥车站到古城、行李寄存和住宿转换都需要另计时间。
- 大同与太原适合用铁路连接，两城各自的古建、石窟与博物馆均足以安排多日，不宜当天往返压缩。
- 五台山是山地型目的地，景区内部尺度、道路、天气和交通组织与太原城市旅行不同，应独立研究。
- 晋中、临汾、运城等地的晋商大院、古城、寺观和遗址应归入各自城市或县域页面，不能以“从太原出发的一日游”改变行政归属。

城市页按城市速览、区域关系、景点、美食、路线、住宿、交通、不同旅行者须知、行前核对和来源顺序组织。更新时应优先使用政府、文旅部门、场馆和交通运营方资料，并将稳定的地理与历史信息和会变化的票价、班次、预约、施工、节庆分开保存。
