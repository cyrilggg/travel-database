# 山西省旅行目的地

山西的古建筑、石窟、壁画、古城、工业遗产和晋商文化分布在多个城市与县域，省会太原只是其中一个入口。目前可浏览太原、大同、忻州、吕梁、晋中、长治、晋城、临汾、阳泉和运城 10 座地级市指南：大同通往晋北石窟古建，忻州由忻府主城展开到五台山、雁门关、芦芽山和黄河长城，吕梁面向晋西黄河—黄土高原，晋中从榆次延伸到平遥、祁县、太谷、灵石和东部太行县域，长治由上党盆地主城通往太行峡谷与浊漳河谷，晋城从城区与泽州展开到沁河古堡和陵川南太行，临汾串联汾河谷地、黄河壶口、陶寺与晋国遗址，阳泉连接煤城工业史与太行关隘，运城则由盐湖、解州关帝庙展开到黄河渡口和晋南古建。城际与县际移动是旅行结构本身，五台山、王莽岭等山岳目的地还需要独立留出完整白天或多日。

## 区域格局与城市组合

太原位于山西中部，是省内铁路、公路和航空交通的重要集散地。大同是山西北部独立的地级市；五台山主要位于忻州市五台县；平遥古城位于晋中市平遥县；乔家大院位于晋中市祁县。这些目的地可以和太原组成多日线路，但都不属于太原市景点范围。

阳泉位于太原与石家庄之间的太行山西麓，主城由城区、矿区和郊区的多个山地组团组成。城区集中住宿、商业和主要公共文化场馆；矿区位于主城西部，以工矿社区和煤炭工业史为鲜明特征；郊区从北部、东部等方向环绕主城，分布着荫营、小河古村和桃林沟等近郊片区。三者有道路和公交联系，却受坡地、铁路与工业用地分隔，不能按一个连续步行中心理解。在产矿井、煤场、企业厂区和专用铁路不是公共参观点，工业史参观只进入运营方正式开放的文化园、展馆和遗产空间。

阳泉的两条主要远线分属不同县域：娘子关景区和固关长城位于平定县东部、接近晋冀省界，但按各自游览时长应二选一或分日；藏山位于盂县北部，通常需要完整一天。当前主要铁路客运门户为阳泉东站和阳泉北站：阳泉北站位于盂县方向，并不在阳泉主城，阳泉东站更便于进入主城东部。阳泉站片区接近老城生活区，可作市内公交地标，但在 12306 没有当期可售客运列车时不能按铁路门户安排行程。

大同位于山西北部，法定范围包括平城、云冈、云州、新荣四区及阳高、天镇、浑源、广灵、左云、灵丘六县。平城古城和主城东部场馆属于城区的不同片区，云冈石窟位于西部，北岳恒山与悬空寺位于浑源县，火山群与土林位于云州区，长城和堡寨还分布在多个北部县区。应县木塔位于朔州市应县，不因旅游产品常与大同组合而改变归属。

忻州以忻府区主城为交通和住宿基点，五台山位于东部五台县及风景名胜区管理范围，雁门关位于北部代县，芦芽山主要由西部宁武县方向进入，偏关老牛湾则位于黄河与长城相遇的西北远端。这些片区分属不同县域与道路方向，五台山宜独立安排 2–3 天，雁门关、芦芽山和偏关老牛湾通常各占完整一天或需要换宿，不能按一个连续景区扫点。

五台山世界遗产包括台怀与佛光寺等组成部分，是寺院、朝圣道路和山岳共同形成的大尺度文化景观；南禅寺是五台县另一处独立唐代古建，不属于联合国教科文组织列出的台怀与佛光寺两个遗产组成部分。寺院首先也是宗教活动场所，参观应服从开放、法会、修缮、香火和摄影规定，不把同一寺院内部殿宇重复计算。芦芽山自然保护与景区经营范围不同，偏关黄河岸线还包含村落、水利和生态空间，只进入正式开放线路。原平市的法定行政代码为 `140981`，是忻州市代管的独立县级市，不作为忻府主城的普通远郊景点处理。

吕梁位于山西中西部，地级市范围包括离石区、汾阳市、孝义市及十个县。离石是主城和交通中心；碛口位于临县，汾酒文化旅游景区位于汾阳，中阳楼和三皇庙位于孝义，卦山—天宁寺与玄中寺位于交城。各县市之间没有连续步行关系，按一个“吕梁市区”集中扫点会严重低估道路时间。平遥、祁县、介休等地属于晋中，山西一侧壶口瀑布主要属于临汾市吉县，也不能因交通组合而改变归属。

晋中以榆次为地级市主城，北部新城与山西大学城、榆次老城、常家庄园并非一个连续步行区；平遥古城、祁县乔家大院、太谷古城、灵石王家大院及东部县域更需分日或换宿。平遥是县，介休是法定县级市，两者都在晋中市域内但城市属性不同；介休应按独立目的地安排，平遥古城则按完整世界遗产与活态县城处理，不把城门、街巷和票号拆成多个独立目的地。

长治以潞州主城为历史、住宿和交通基点，壶关太行山大峡谷、平顺浊漳河谷古建、长子彩塑以及武乡、黎城抗战遗址分属不同县区方向。太行山大峡谷内部峡谷、栈道、交通和观景节点按同一大型景区去重；县域古建和山地入口之间没有连续步行关系，也不能把仍在生产的矿山、厂区或主题仿建项目当作开放遗产。

晋城位于山西东南部，中心城区由城区全域和泽州县金村、南村、大箕、高都、巴公等镇的部分空间共同构成；这解释了府城玉皇庙、珏山—青莲寺等“近市区”目的地为何在行政上属于泽州县。阳城和沁水沿沁河分布皇城相府、郭峪、砥洎城、湘峪、柳氏民居等古堡聚落，陵川东部的王莽岭—锡崖沟则是需要完整一天的南太行山地。高平市是晋城市代管的独立县级市，炎帝文化、长平历史和高平城区应按高平目的地另行安排，不能并入晋城主城景点。珏山大景区内部运营单元、王莽岭与锡崖沟内部游线均按各自完整景区去重；生产矿井、煤层气井、煤场和企业专用铁路不是公共参观点。

临汾以尧都主城为交通与住宿基点，洪洞—霍州、襄汾—曲沃—侯马、吉县壶口、隰县—蒲县和乡宁云丘山分属不同方向，通常一个方向占用一天。侯马与霍州是法定县级市，均应按独立目的地安排；襄汾、曲沃、洪洞、吉县、隰县、蒲县和乡宁是普通县域。黄河河岸、考古工作区、古建修缮区和山地步道只进入正式开放范围。

运城以盐湖区中心城区为交通和住宿基点，盐湖开放游览带、解州关帝庙、永济黄河古渡、芮城永乐宫、万荣民居与新绛古城分属不同方向，通常一天只选一条远线。永济和河津是法定县级市，均应按独立目的地安排；芮城、万荣、新绛等仍作为运城市域内县域目的地理解。盐湖生态核心区、黄河河道、水利设施、考古工作区和古建修缮区均不因文旅宣传而成为自由进入区域。

跨城安排行程时应注意：

- 太原与平遥之间有铁路和公路联系，但平遥车站到古城、行李寄存和住宿转换都需要另计时间。
- 大同与太原适合用铁路连接，两城各自的古建、石窟与博物馆均足以安排多日，不宜当天往返压缩；大同站与大同南站也应按车票分别核对。
- 大同内部宜按“古城与市博物馆”“云冈石窟”“浑源恒山”“云州地质”或“一个长城、灵丘等县域方向”分日，不能把地级市范围当成一个连续景区。
- 五台山是山地型世界遗产和宗教活动区域，景区内部尺度、道路、天气与交通组织和太原、忻府主城均不同；从太原联程也不改变其属于忻州五台县方向的归属，宜以台怀为基地独立留出 2–3 天。
- 忻州宜按“忻府主城”“五台山”“代县雁门关”“宁武芦芽山”或“偏关黄河长城”分段；五台山机场位于定襄县，机场名称和铁路“五台山站”都不能替代对实际景区入口与接驳的核对。原平是独立县级市，需要单独安排住宿、交通与行程。
- 吕梁适合按“离石—碛口”“汾阳—孝义”或“交城古建与山地”分段；碛口内部的古镇、西湾、李家山等按同一旅游区域处理，但外围村落仍需车辆接驳。
- 太原与吕梁之间可用铁路或公路连接；若主要游览汾阳、孝义或交城，应按具体车次和住宿位置选择门户，不必机械地先到离石再折返。
- 晋中、临汾和运城等地的晋商大院、古城、寺观和遗址应归入各自城市或县域页面，不能以“从太原出发的一日游”改变行政归属；三地均已有独立指南。
- 长治宜按“潞州主城”“壶关峡谷”“平顺古建”“武乡—黎城抗战史”择一分日；前往晋城、临汾或河南方向属于跨城移动，应按实际站点与道路另算。
- 晋城宜按“城区—泽州彩塑古建”“阳城沁河古堡”“沁水古堡”“陵川王莽岭”择一分日；皇城相府与郭峪可同日组合，王莽岭不宜再拼另一条县域远线。高平可从晋城铁路或公路联程，但仍是一段独立城市行程。
- 阳泉宜按“城区—矿区—郊区主城”“平定娘子关或固关”“盂县藏山”分日；从太原或石家庄乘铁路进入时，先核对阳泉东、阳泉北的车次及与住宿地的实际距离。阳泉站只有在 12306 显示当期客运列车时才作为铁路选项；远县末班车和山路天气比地图直线距离更影响行程。
- 运城宜按“中心城区与博物馆”“盐湖—解州”“永济”“芮城”“万荣或新绛”择线分日；盐湖岸线、解州和各县域不能按连续步行带理解。永济路线只是市域联程示例，永济仍应按独立目的地安排。

## 浏览与贡献

城市页按城市速览、区域关系、景点、美食、路线、住宿、交通、不同旅行者须知、行前核对和来源顺序组织。更新时应优先使用政府、文旅部门、场馆和交通运营方资料，并将稳定的地理与历史信息和会变化的票价、班次、预约、施工、节庆分开保存。

同一景区及内部建筑只计算一次。具有统一品牌但入口、场馆和参观流程相互独立的地点，应在正文说明计数边界；邻近城市、县域和跨市景区也必须明确归属。只有完成来源核验和可直接使用路线的页面才能标为 `researched`。
