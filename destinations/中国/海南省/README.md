# 海南省旅行目的地

海南是中国最南端的省级行政区之一，海岛内部既有省会城市、热带海岸、火山地貌与雨林山地，也有分属不同市县的海湾、渔村和民族文化目的地。城市之间看似能在地图上串联，实际常受环岛铁路站点、公路距离、天气与节假日客流影响，资料库将按行政边界分别建立城市页。

当前已完成海口与三亚的完整指南。海口页说明骑楼老街、海甸岛、海口湾、西海岸、火山口和东部湿地之间的空间关系；三亚页集中说明四大海湾、海岛码头、西部文化景区与远距离交通。儋州、琼海、万宁、东方等城市以后单独研究。文昌、澄迈的目的地不因邻近海口而计入海口市景点完成率，陵水的分界洲岛、保亭的呀诺达与槟榔谷等目的地也不计入三亚市景点完成率。

## 区域格局与城市组合

海口位于海南岛北部，传统城市空间围绕骑楼老街、海甸河与海口湾展开，向西延伸至西海岸，向西南进入石山火山地貌，向东则到江东新区与东寨港红树林。文昌航天与东郊椰林、澄迈老城与福山、儋州那大与洋浦、琼海博鳌及三亚各有独立行政与旅行体系；即使能由海口乘铁路或车辆往返，也应另页研究。

三亚位于海南岛南端，城市内部已经包含三亚湾、大东海、亚龙湾、海棠湾和崖州湾等多个相距较远的片区。向东进入陵水、向北进入保亭、向西进入乐东后，即属于其他市县；这些地方可以与三亚组合成更长的海南南部行程，但应各自建立来源、交通与风险记录。

海南全岛路线还要区分环岛铁路能否直达、车站到景点的“最后一段”、自驾过海安排以及台风或强对流天气对航班、铁路、轮渡和海上项目的联动影响。省级索引不固化班次、票价或所谓“最佳月份”。
