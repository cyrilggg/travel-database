# 海南省旅行目的地

海南是中国最南端的省级行政区之一，海岛内部既有省会城市、热带海岸、火山地貌与雨林山地，也有分属不同市县的海湾、渔村和民族文化目的地。城市之间看似能在地图上串联，实际常受环岛铁路站点、公路距离、天气与节假日客流影响，资料库将按行政边界分别建立城市页。

当前已完成海口、三亚、文昌、万宁与琼海五座城市的完整指南。海口页说明骑楼老街、海甸岛、海口湾、西海岸、火山口和东部湿地之间的空间关系；三亚页集中说明四大海湾、海岛码头、西部文化景区与远距离交通；文昌页分开文城—清澜主城、龙楼—铜鼓岭、东郊椰林、会文—十八行、潭牛和铺前—木兰湾，并把公开航天科普、观礼活动与发射场生产安保区明确区分；万宁页分开万城—东山岭、兴隆、东澳—神州半岛、礼纪—石梅湾、礼纪—日月湾与东澳—大洲岛外海，并把冲浪、潜水、离岛和保护地边界分别说明；琼海页分开嘉积主城、博鳌河口与会址、潭门渔港、中原侨乡、官塘—白石岭和乡村片区，并把论坛年会与公众参观、渔港生产与休闲船艇明确区分。儋州、东方等城市以后单独研究。文昌、澄迈不属于海口行政范围；陵水的分界洲岛、保亭的呀诺达与槟榔谷也不属于三亚市，均应按各自市县安排交通、住宿和行前核对。

## 区域格局与城市组合

海口位于海南岛北部，传统城市空间围绕骑楼老街、海甸河与海口湾展开，向西延伸至西海岸，向西南进入石山火山地貌，向东则到江东新区与东寨港红树林。文昌航天与东郊椰林、澄迈老城与福山、儋州那大与洋浦、琼海博鳌及三亚各有独立行政与旅行体系；即使能由海口乘铁路或车辆往返，也应使用各自城市页。

文昌位于海南岛东北部，行政范围从铺前和木兰湾延伸到文城—清澜、会文、东郊、龙楼与铜鼓岭。文城镇主城承担铁路、住宿和主要城市服务，龙楼—铜鼓岭是航天与滨海山地模块，东郊椰林、会文传统村落、潭牛饮食农业和铺前骑楼则分属不同镇域，不能按连续城区规划。铺前经海文大桥接近海口方向，海口美兰机场也常作为抵达门户，但二者都不会改变文昌的独立行政与旅行边界。航天发射场生产安保区、自然保护区、港区、农业椰林、灯塔与红树林各有进入规则，只有明确开放的场馆、景区、道路和公共空间属于旅行范围。

琼海位于海南岛东部，是海南省直辖县级市。嘉积镇是行政、铁路和日常服务中心；万泉河向东在博鳌入海，博鳌镇的论坛成立会址、东屿岛永久会址和公共河海空间各有入口；潭门镇集中了中国（海南）南海博物馆、中心渔港与海鲜餐饮；中原镇保留侨乡街景，也是博鳌站和琼海博鳌国际机场所在方向。嘉积、博鳌、潭门、中原、官塘—白石岭及乡村片区不能按连续城区步行规划。论坛年会的代表注册和安保体系不等于会址日常公众参观，潭门渔港的泊位、装卸、修船与冷链区也不等于观光码头；普通渔船不得替代合规休闲渔船载客。向北进入文昌、向南进入万宁后即属其他市县。

万宁位于海南岛东南部，是海南省直辖县级市。万城主城和东山岭组成北部城市模块，兴隆位于南部内陆，东澳镇包含神州半岛方向，礼纪镇的石梅湾与日月湾又各有独立海岸、住宿和水上活动体系。万宁站、神州站只是不同方向的铁路入口，不能把这些片区理解成连续滨海城区。大洲岛属于海洋生态国家级自然保护区，不按普通离岛游处理；兴隆热带植物园、咖啡生产园区、林场、青皮林、大花角等自然保护地和内陆山林也各有开放边界。南行进入陵水后，分界洲岛等景点不再属于万宁。

三亚位于海南岛南端，城市内部已经包含三亚湾、大东海、亚龙湾、海棠湾和崖州湾等多个相距较远的片区。向东进入陵水、向北进入保亭、向西进入乐东后，即属于其他市县；这些地方可以与三亚组合成更长的海南南部行程，但应各自建立来源、交通与风险记录。

海南全岛路线还要区分环岛铁路能否直达、车站到景点的“最后一段”、自驾过海安排以及台风或强对流天气对航班、铁路、轮渡和海上项目的联动影响。文昌还需额外关注发射活动交通管制、东部海况、铜鼓岭山地关闭、椰林落果和分散镇域返程；琼海需复核博鳌论坛会期安保、南海博物馆开放、万泉河水位、潭门渔港生产与船艇资质、琼海站—博鳌站—机场接驳和白石岭山地关闭；万宁则需复核日月湾冲浪赛事、海湾节庆交通、潜水与船艇资质、大洲岛禁入、山林保护地开放和万宁站—神州站的接驳分工。省级索引不固化班次、票价、发射日期、会议与赛事安排或所谓“最佳月份”。
