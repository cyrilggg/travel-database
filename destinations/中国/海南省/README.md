# 海南省旅行目的地

海南是中国最南端的省级行政区之一，海岛内部既有省会城市、热带海岸、火山地貌与雨林山地，也有分属不同市县的海湾、渔村和民族文化目的地。城市之间看似能在地图上串联，实际常受环岛铁路站点、公路距离、天气与节假日客流影响；各市县应按自身行政边界、交通与住宿条件分别安排行程。

本目录收录海口、三亚、文昌、万宁、琼海、东方与儋州七座城市的旅行指南。海口页说明骑楼老街、海甸岛、海口湾、西海岸、火山口和东部湿地之间的空间关系；三亚页集中说明四大海湾、海岛码头、西部文化景区与远距离交通；文昌页分开文城—清澜主城、龙楼—铜鼓岭、东郊椰林、会文—十八行、潭牛和铺前—木兰湾，并把公开航天科普、观礼活动与发射场生产安保区明确区分；万宁页分开万城—东山岭、兴隆、东澳—神州半岛、礼纪—石梅湾、礼纪—日月湾与东澳—大洲岛外海，并把冲浪、潜水、离岛和保护地边界分别说明；琼海页分开嘉积主城、博鳌河口与会址、潭门渔港、中原侨乡、官塘—白石岭和乡村片区，并把论坛年会与公众参观、渔港生产与休闲船艇明确区分；东方页分开八所主城、鱼鳞洲、大田珍贵树种园区、板桥花梨谷—金月湾、大广坝—俄贤岭和白查村，并把水库、港区、渔业生产、国家公园与自然保护区边界分别说明；儋州页分开那大、热作科研片区、中和东坡文化、八一—雅星地质方向、白马井—环新英湾、洋浦古盐田与峨蔓火山海岸，并把港口、炼化、水利、盐田生产和地质保护边界明确区分。其他市县各有独立行政与旅行体系，不应借用相邻城市页替代。文昌、澄迈不属于海口行政范围；陵水的分界洲岛、保亭的呀诺达与槟榔谷也不属于三亚市，均应按各自市县安排交通、住宿和行前核对。

## 区域格局与城市组合

海口位于海南岛北部，传统城市空间围绕骑楼老街、海甸河与海口湾展开，向西延伸至西海岸，向西南进入石山火山地貌，向东则到江东新区与东寨港红树林。文昌航天与东郊椰林、澄迈老城与福山、儋州那大与洋浦、琼海博鳌及三亚各有独立行政与旅行体系；即使能由海口乘铁路或车辆往返，也应使用各自城市页。

文昌位于海南岛东北部，行政范围从铺前和木兰湾延伸到文城—清澜、会文、东郊、龙楼与铜鼓岭。文城镇主城承担铁路、住宿和主要城市服务，龙楼—铜鼓岭是航天与滨海山地模块，东郊椰林、会文传统村落、潭牛饮食农业和铺前骑楼则分属不同镇域，不能按连续城区规划。铺前经海文大桥接近海口方向，海口美兰机场也常作为抵达门户，但二者都不会改变文昌的独立行政与旅行边界。航天发射场生产安保区、自然保护区、港区、农业椰林、灯塔与红树林各有进入规则，只有明确开放的场馆、景区、道路和公共空间属于旅行范围。

琼海位于海南岛东部，是海南省直辖县级市。嘉积镇是行政、铁路和日常服务中心；万泉河向东在博鳌入海，博鳌镇的论坛成立会址、东屿岛永久会址和公共河海空间各有入口；潭门镇集中了中国（海南）南海博物馆、中心渔港与海鲜餐饮；中原镇保留侨乡街景，也是博鳌站和琼海博鳌国际机场所在方向。嘉积、博鳌、潭门、中原、官塘—白石岭及乡村片区不能按连续城区步行规划。论坛年会的代表注册和安保体系不等于会址日常公众参观，潭门渔港的泊位、装卸、修船与冷链区也不等于观光码头；普通渔船不得替代合规休闲渔船载客。向北进入文昌、向南进入万宁后即属其他市县。

万宁位于海南岛东南部，是海南省直辖县级市。万城主城和东山岭组成北部城市模块，兴隆位于南部内陆，东澳镇包含神州半岛方向，礼纪镇的石梅湾与日月湾又各有独立海岸、住宿和水上活动体系。万宁站、神州站只是不同方向的铁路入口，不能把这些片区理解成连续滨海城区。大洲岛属于海洋生态国家级自然保护区，不按普通离岛游处理；兴隆热带植物园、咖啡生产园区、林场、青皮林、大花角等自然保护地和内陆山林也各有开放边界。南行进入陵水后，分界洲岛等景点不再属于万宁。

东方位于海南岛西部，是海南省直辖县级市，市政府驻八所镇。八所集中了东方站、城市服务、海南铁路博物馆、近现代历史纪念地和鱼鳞洲海岸；大田方向有珍贵树种园区，南部板桥镇则把花梨谷、金月湾站和金月湾海岸组成另一组森林康养与滨海节点，向东则进入大广坝、俄贤岭和白查村。东方站与金月湾站服务不同方向，海岸和山区也不能按连续城区规划。八所港及相关码头以商港、工业、渔业和海事作业为主，不是默认开放的游客码头；大广坝首先是水利水电工程，东方市内的海南热带雨林国家公园、坡鹿与候鸟保护地也以生态保护为先。环园旅游公路、公开景区和社区可以游览，不代表港区、水库设施、保护区核心区域和林道可自由进入。

儋州位于海南岛西北部，是海南省地级市。那大承担行政、住宿、餐饮与城市服务，中和集中东坡书院和相关文物，宝岛新村—八一—雅星方向连接热带农业与石花水洞，白马井—排浦面向环新英湾和海花岛，洋浦—三都保留古盐田并承接深水港和临港工业，峨蔓则是分散的火山海岸远线。白马井站靠近海岸而不在那大，那大、洋浦、中和和峨蔓也不能按连续城区规划。儋州洋浦一体化不会把码头、炼化、仓储、专用铁路和施工道路变成公共景点；盐田、水库、科研园区和火山海岸也分别服从生产、水利、科研和地质生态管理。

三亚位于海南岛南端，城市内部已经包含三亚湾、大东海、亚龙湾、海棠湾和崖州湾等多个相距较远的片区。向东进入陵水、向北进入保亭、向西进入乐东后，即属于其他市县；这些地方可以与三亚组合成更长的海南南部行程，但应分别安排交通、住宿并核对风险。

海南全岛路线还要区分环岛铁路能否直达、车站到景点的“最后一段”、自驾过海安排以及台风或强对流天气对航班、铁路、轮渡和海上项目的联动影响。文昌还需额外关注发射活动交通管制、东部海况、铜鼓岭山地关闭、椰林落果和分散镇域返程；琼海需复核博鳌论坛会期安保、南海博物馆开放、万泉河水位、潭门渔港生产与船艇资质、琼海站—博鳌站—机场接驳和白石岭山地关闭；万宁则需复核日月湾冲浪赛事、海湾节庆交通、潜水与船艇资质、大洲岛禁入、山林保护地开放和万宁站—神州站的接驳分工；东方需复核铁路博物馆开放、鱼鳞洲和金月湾海况、大广坝水库调度、俄贤岭与白查村道路、国家公园和自然保护区边界、东方站—金月湾站接驳及八所港生产管理；儋州需复核东坡书院与相关遗址开放、植物园和石花水洞运营、白马井站接驳、海花岛具体项目、古盐田生产、峨蔓海岸入口、洋浦港区安保和台风海浪影响。省级索引不固化班次、票价、发射日期、会议与赛事安排或所谓“最佳月份”。
