# 河南省旅行目的地

河南横跨黄河中下游、中原腹地与西南部山地盆地，古都、考古遗址、山水和现代交通枢纽分布在多个地级市。现有指南覆盖十三座城市；焦作位于太行山南麓与黄河平原之间，主城工业史、修武云台山和温县太极拳分处不同方向；信阳由浉河—羊山—平桥主城向南湾湖、鸡公山和更远的豫南县域展开；驻马店则以驿城主城为门户，分别通往嵖岈山、竹沟及需要先核实具体开放单元的汝南、泌阳湖库方向。

## 区域格局与城市组合

郑州是省会和综合交通枢纽，也是理解河南考古脉络的入口；登封、巩义、新郑等县级市属于郑州市域，但从主城区前往仍需按远郊行程计算。开封、洛阳、焦作、安阳等是独立地级市，各自拥有完整的历史主题和城市交通，不能因铁路通达就并入郑州景点清单。

开封中心城区可分为城墙合围老城和西部新城。龙亭湖、中轴街巷、铁塔、包公湖与繁塔分属不同片区，开封市博物馆也不在老城步行圈内；朱仙镇、兰考和黄河沿线更需要独立往返。开封页把真实文物与考古遗址同当代宋文化主题园分开说明，并不以主题相同为由重复计算园区内部节点。

洛阳的古都资源跨越主城、洛龙、龙门和偃师多个方向。龙门石窟适合独立半天至一天；隋唐洛阳城的应天门、明堂天堂与九洲池属于同一遗址展示体系，不拆成多个完成项；二里头夏都遗址博物馆、偃师商城与汉魏洛阳城位于偃师方向，也不与主城博物馆群按连续步行理解。栾川、嵩县等县域山地目的地需要另算往返、天气与住宿。

安阳主城的殷墟、中国文字博物馆、古城和东部新城分属不同片区。殷墟博物馆、宫殿宗庙遗址和王陵遗址共同构成一次大型考古主题，不按馆舍、墓葬和遗址节点重复计数；曹操高陵与汤阴文化景点需要独立半日以上。林州是安阳代管的法定县级市，红旗渠和太行大峡谷应从林州组织并分别留出完整时间，不能当作安阳主城的远郊节点。

漯河主城区由沙河、澧河及两岸公共空间构成，许慎文化园位于东部，食品文化和工业展示也分散在不同片区。临颍向北、舞阳向西，分别承载小商桥—南街村和贾湖遗址—北舞渡等县域路线，两县不能与主城区压成连续步行日。食品企业的公共展示区、商业体验和正常生产厂区边界不同，只有明确开放的参观空间才可进入。

商丘位于河南东部，主城区的商丘站—梁园中心、睢阳古城、商丘博物馆—火神台文化片区并不是一个连续步行区域。法定市域还包括民权、睢县、宁陵、柘城、虞城、夏邑与县级永城市；芒砀山位于永城市芒山镇方向，通常需要独立一天。商丘页介绍这条广域线路，不代表永城市区或其他县域目的地已经各自完成研究。

南阳位于河南西南部。卧龙岗—汉画馆、古宛城—府衙、医圣文化园和鼎盛大道公共文化区属于中心城区的不同片区；内乡县衙、西峡恐龙遗迹园与老界岭、淅川丹江水源区都要另算县际往返。邓州虽由南阳市代管，仍是独立县级市；花洲书院等邓州目的地需要按邓州自身的交通、住宿和开放条件安排。

许昌主城由魏都老城、东部公共文化区、灞陵桥方向、张潘镇许都故城遗址和三座铁路客站构成，不能按一个连续步行圈理解。禹州、长葛是法定县级市，需独立建页；鄢陵花木和襄城古建适合作为各自的一日方向。考古遗址、后世祠庙与桥梁、现代主题街区和商业演艺在证据性质及开放方式上不同，不以“曹魏”主题相同为由混算。

新乡主城由四个市辖区构成，新乡市博物馆、红旗区老城、卫河公共空间和凤泉区潞王陵需要分段移动。卫辉、辉县、长垣是三座代码独立的县级市；八里沟、万仙山、宝泉都在辉县方向，分别是完整大型山地项目，不能拆分内部节点或压入主城半日。山区强降雨、山洪、落石和道路结冰时应取消整段，黄河滩区、堤防、农田与未开放沟谷也不作为自由进入的景点。

平顶山的连续主城主要包括新华、卫东、湛河及相邻功能片区，石龙区则是空间分离的工矿区。宝丰、叶县、鲁山和郏县是普通县，汝州与舞钢是法定县级市，均不能当作主城附近步行点。尧山—中原大佛按一个联合大型景区处理，叶县县衙—文庙—明清街、舞钢二郎山—石漫滩和各湖库也按完整空间去重；矿井、采空沉陷区、尾矿设施、水库工程和工业厂区只有明确开放部分可进入。

焦作主城以解放—山阳为住宿和公共文化基点，中站工业遗产带需要短途交通；北部修武县云台山、南部温县陈家沟、东南武陟嘉应观和博爱青天河都是不同的一日方向。沁阳、孟州是代码独立的县级市，神农山等沁阳目的地不并入焦作主城景点；济源也不属于焦作市。云台山内部峡谷、峰区与景交按一个完整景区去重，矿井、铁路货场、黄河堤防、水库工程和山地非开放线不作为普通游览空间。

信阳连续主城可分为浉河老城、羊山—信阳东站新城轴线和平桥城区，三者之间仍需公交或短途用车；信阳站靠近浉河老城，信阳东站与信阳博物馆位于羊山方向，票面站名不能互换。南湾湖在主城西南，完整游船与岛屿路线应留出大半天；鸡公山位于约 38 公里外的豫鄂交界山地，适合独立一天。法定信阳市辖浉河、平桥 2 区和罗山、光山、新县、商城、固始、潢川、淮滨、息县 8 县；羊山新区、南湾湖风景区和鸡公山管理区是功能管理片区，不是新增法定市辖区。罗山、新县、商城、固始等县域拥有各自的县城、住宿和接驳体系，不能按主城半日远郊处理。南湾湖的岛屿、码头与内部活动按一个景区组织，鸡公山的峰顶、建筑、景交和索道也不重复拆分；茶园是农业生产空间，只进入明确开放的步道和经营体验区。

驻马店以驿城区承担市级场馆、铁路门户和主要住宿功能，遂平嵖岈山、确山竹沟、汝南宿鸭湖与泌阳铜山湖分属不同县域方向，每条都需要单独计算往返和开放条件。嵖岈山内部峰林、峡谷、索道和观景节点按一个大型景区去重；竹沟按开放的纪念馆与旧址群组织。现有官方资料不足以证明宿鸭湖有一条稳定开放的公共游线，铜山、铜山湖水库、露营地与建设项目也不能合成同一运营单元；两者只在确认可定位的当期开放入口后安排。薄山、板桥等其他湖库同样先服从防汛、供水、生态保护和工程管理要求。

从郑州向东可接开封和商丘，向西可接洛阳，向南经许昌方向可接漯河和平顶山，向北越过黄河后可接新乡并继续前往安阳；南阳则位于河南西南方向。这些城市都是需要分别安排住宿和本地交通的独立旅行段。跨省边际目的地不并入河南城市景点，跨市组合应先锁定票面站名、车票与住宿，再查看相应城市官方文旅和场馆预约，不在本索引页固化车次、票价或班次。
