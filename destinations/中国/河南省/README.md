# 河南省旅行目的地

河南横跨黄河中下游、中原腹地与西南部山地盆地，古都、考古遗址、山水和现代交通枢纽分布在多个地级市与省直管县级市。现有指南覆盖三十二座城市或县域目的地；唐河以县城文化、湿地、山林和季节乡村形成短途行程。

焦作位于太行山南麓与黄河平原之间，主城工业史、修武云台山和温县太极拳分处不同方向；信阳由浉河—羊山—平桥主城向南湾湖、鸡公山和更远的豫南县域展开；驻马店则以驿城主城为门户，分别通往嵖岈山、竹沟及需要先核实具体开放单元的汝南、泌阳湖库方向。

周口位于豫东沙颍河水运轴线，川汇主城的市级文博与商埠老街、淮阳的太昊伏羲陵和史前城址，以及鹿邑、商水等普通县域分处不同方向。太昊陵与龙湖按官方旅游区整体组织，平粮台另作考古单元；项城是独立法定县级市，应另作跨城行程查询属地信息，不能因由周口代管就并入川汇主城。

邓州是南阳市代管的独立县级市，花洲—古城核心、湍北公共文化区、两个铁路门户和湍河沿线构成自己的城市旅行结构。花洲书院按完整园区去重；宋金商业街的考古发现、当代运营街区和复建城门也需分别理解。邓州页独立承担其景点、路线、住宿和交通，南阳页只保留行政与跨城边界。

济源是河南省直辖县级市，产城融合示范区管委会与市政府“一个机构、两块牌子”，不因此产生另一法定城市。济水城区、东北五龙口、西北王屋山、远西小沟背以及南部小浪底济源侧与黄河三峡分属不同方向；每个山地或黄河目的地宜独立留日。济源不属于焦作，小浪底济源北岸入口也不能与洛阳孟津方向的入口、票务和道路默认互通。

## 区域格局与城市组合

郑州是省会和综合交通枢纽，也是理解河南考古脉络的入口；[巩义](./巩义市.md)是郑州代管的独立县级市，已按河洛文化与黄河山地建立完整指南，登封、新郑等城市继续按各自属地规划。开封、洛阳、焦作、安阳等是独立地级市，各自拥有完整的历史主题和城市交通，不能因铁路通达就并入郑州景点清单。

开封中心城区可分为城墙合围老城和西部新城。龙亭湖、中轴街巷、铁塔、包公湖与繁塔分属不同片区，开封市博物馆也不在老城步行圈内；朱仙镇、兰考和黄河沿线更需要独立往返。开封页把真实文物与考古遗址同当代宋文化主题园分开说明，并不以主题相同为由重复计算园区内部节点。

洛阳的古都资源跨越主城、洛龙、龙门和偃师多个方向。龙门石窟适合独立半天至一天；隋唐洛阳城的应天门、明堂天堂与九洲池属于同一遗址展示体系，不重复计数；二里头夏都遗址博物馆、偃师商城与汉魏洛阳城位于偃师方向，也不与主城博物馆群按连续步行理解。栾川、嵩县等县域山地目的地需要另算往返、天气与住宿。

三门峡主城包括湖滨区的文博与黄河公园、三门峡南站—商务中心区和天鹅湖湿地带，片区之间需要公交或用车；陕州、渑池和卢氏方向各需独立往返。[义马](./义马市.md)进入独立指南，灵宝也按跨城尺度安排。水库工程、湿地保育区与矿业生产区保留明确边界，游览选择正式开放的景区、栈道和观景点。

安阳主城的殷墟、中国文字博物馆、古城和东部新城分属不同片区。殷墟博物馆、宫殿宗庙遗址和王陵遗址共同构成一次大型考古主题，不按馆舍、墓葬和遗址节点重复计数；曹操高陵与汤阴文化景点需要独立半日以上。林州是安阳代管的法定县级市，应另作跨城行程查询属地景点、交通与住宿，不能当作安阳主城的远郊节点。

鹤壁的淇滨区承担高铁门户、主要住宿、城市文博和淇河公共空间，山城区、鹤山区则是空间分离的老工矿与生活组团；三组之间不能只靠步行串联。浚县的古城、大伾山和运河遗产，与淇县县城、朝歌文化线和云梦山分别构成两条完整县域方向，各自需要车辆、返程和开放核对。生产或闭坑矿井、采空沉陷治理区、矸石山、工业厂区和货运铁路不因“工业记忆”而开放；淇河行洪河道、水库堤坝、蓄滞洪区、湿地保育区及未开放山路也服从水利、生态和现场封闭要求。

濮阳的连续主城以华龙区的市级场馆、戚城遗址和城市公园为核心，相邻功能区可通过城市交通连接；濮阳县的西水坡遗址、老城与卫国故城方向需要单独往返。清丰、南乐、范县、台前各有独立县城和目的地，中原油田的生活区、展陈空间和仍在生产的井场装置也不能合并为一条可自由穿行的城市街区。黄河滩区、北金堤蓄滞洪区、堤防和河务工程承担行洪与管理功能，油井、管线、站场、化工装置及检修道路属于生产空间；只使用正式开放入口，不因地面平坦或道路可见就进入。

周口中心城区以川汇老城、东部新城和相邻功能片区构成，周口市博物馆、周口东站、关帝庙与沙颍河老街之间需要城市交通连接。淮阳区拥有独立古城与湖区，太昊陵和龙湖相关开放片区共同组成太昊伏羲陵文化旅游区，按一个景区理解；平粮台古城遗址博物馆以当期开放范围为准。鹿邑、商水和扶沟等普通县域各需独立往返；项城是代码独立的县级市，应按跨城行程查询其属地信息，本索引不预先安排具体景点或停留时间。沙颍河航道、港区、闸坝、龙湖保育水域、考古工地、农田与生产厂区不因邻近游览点而对公众开放。

漯河主城区由沙河、澧河及两岸公共空间构成，许慎文化园位于东部，食品文化和工业展示也分散在不同片区。临颍向北、舞阳向西，分别承载小商桥—南街村和贾湖遗址—北舞渡等县域路线，两县不能与主城区压成连续步行日。食品企业的公共展示区、商业体验和正常生产厂区边界不同，只有明确开放的参观空间才可进入。

商丘位于河南东部，主城区的商丘站—梁园中心、睢阳古城、商丘博物馆—火神台文化片区并不是一个连续步行区域。法定市域还包括民权、睢县、宁陵、柘城、虞城、夏邑与县级永城市；永城应另作跨城行程查询属地景点、交通与住宿，本索引不预先安排具体路线或停留时间。

南阳位于河南西南部。卧龙岗—汉画馆、古宛城—府衙、医圣文化园和鼎盛大道公共文化区属于中心城区的不同片区；内乡县衙、西峡恐龙遗迹园与老界岭、淅川丹江水源区都要另算县际往返。邓州虽由南阳市代管，仍是独立县级市，南阳主城页只保留跨城边界。

邓州中心城区以花洲、古城、湍河三个街道及相邻建设片区为基础。花洲书院、福胜寺塔、宋金商业街和复建平成门集中在古城大方向，湍北的邓州市博物馆需要车辆转场；邓州站与邓州东站是两个不同铁路门户。湍河国家湿地公园是跨街道乡镇的自然资源管理单元，不等于一条可任意穿行的游客步道；八里岗遗址和仍带建设属性的项目须等主管部门公布明确开放单元。

许昌主城由魏都老城、东部公共文化区、灞陵桥方向、张潘镇许都故城遗址和三座铁路客站构成，适合分片区移动。鄢陵花木和襄城古建可各占一天；前往[禹州](./禹州市.md)后按独立指南选择钧瓷、神垕或山地方向，长葛继续按属地资料规划。

新乡主城由四个市辖区构成，新乡市博物馆、红旗区老城、卫河公共空间和凤泉区潞王陵需要分段移动。卫辉、辉县、长垣是三座代码独立的县级市，应分别按跨城行程查询属地景点、交通与住宿，不压入新乡主城半日。山区强降雨、山洪、落石和道路结冰时应取消整段，黄河滩区、堤防、农田与未开放沟谷也不作为自由进入的景点。

平顶山的连续主城主要包括新华、卫东、湛河及相邻功能片区，石龙区则是空间分离的工矿区。宝丰、叶县、鲁山和郏县是普通县，汝州与舞钢是法定县级市，应分别按跨城行程查询属地景点、交通与住宿。普通县域的山地、古建和湖库各有独立入口与往返条件；矿井、采空沉陷区、尾矿设施、水库工程和工业厂区只有明确开放部分可进入。

焦作主城以解放—山阳为住宿和公共文化基点，中站工业遗产带需要短途交通；北部修武县、南部温县、东南武陟县和博爱县是不同的普通县域方向。沁阳、孟州是代码独立的县级市，应分别按跨城行程查询属地景点、交通与住宿；济源也不属于焦作市。普通县域的大型景区内部峡谷、峰区与接驳宜按一个完整游览组织理解，矿井、铁路货场、黄河堤防、水库工程和山地非开放线不作为普通游览空间。

济源由省直管，城区以济水之源和公共文化为基点，王屋山、小沟背、五龙口、大峪小浪底与下冶黄河三峡分别占用独立方向。王屋山地质公园、太行山猕猴与黄河湿地保护范围不等于全域开放；大坝、发电检修区、矿厂、专用铁路和非运营库岸属于保护或生产空间。小浪底跨洛阳、济源相关地域，济源页只承担济源侧正式游客入口，不能依据地图直线跨坝或互换两侧票务。

信阳连续主城可分为浉河老城、羊山—信阳东站新城轴线和平桥城区，三者之间仍需公交或短途用车；信阳站靠近浉河老城，信阳东站与信阳博物馆位于羊山方向，票面站名不能互换。南湾湖在主城西南，完整游船与岛屿路线应留出大半天；鸡公山位于约 38 公里外的豫鄂交界山地，适合独立一天。法定信阳市辖浉河、平桥 2 区和罗山、光山、新县、商城、固始、潢川、淮滨、息县 8 县；羊山新区、南湾湖风景区和鸡公山管理区是功能管理片区，不是新增法定市辖区。罗山、新县、商城、固始等县域拥有各自的县城、住宿和接驳体系，不能按主城半日远郊处理。南湾湖的岛屿、码头与内部活动按一个景区组织，鸡公山的峰顶、建筑、景交和索道也不重复拆分；茶园是农业生产空间，只进入明确开放的步道和经营体验区。

驻马店以驿城区承担市级场馆、铁路门户和主要住宿功能，遂平嵖岈山、确山竹沟、汝南宿鸭湖与泌阳铜山湖分属不同县域方向，每条都需要单独计算往返和开放条件。嵖岈山内部峰林、峡谷、索道和观景节点按一个大型景区去重；竹沟按开放的纪念馆与旧址群组织。现有官方资料不足以证明宿鸭湖有一条稳定开放的公共游线，铜山、铜山湖水库、露营地与建设项目也不能合成同一运营单元；两者只在确认可定位的当期开放入口后安排。薄山、板桥等其他湖库同样先服从防汛、供水、生态保护和工程管理要求。

从郑州向东可接开封和商丘，向东北可接濮阳，向东南经许昌或漯河方向可接周口，向西经洛阳可继续到三门峡，向南经许昌方向可接漯河和平顶山，向北越过黄河后可接新乡、鹤壁并继续前往安阳；南阳则位于河南西南方向。这些城市都是需要分别安排住宿和本地交通的独立旅行段。跨省边际目的地不并入河南城市景点，跨市组合应先锁定票面站名、车票与住宿，再查看相应城市官方文旅和场馆预约，不在本索引页固化车次、票价或班次。
