# 河南省旅行目的地

河南横跨黄河中下游与中原腹地，古都、考古遗址、山地和现代交通枢纽分布在多个地级市。当前先以郑州建立完整城市指南，重点说明省级与市级博物馆、商代都城、黄河方向和登封嵩山之间的空间关系。

## 区域格局与城市组合

郑州是省会和综合交通枢纽，也是理解河南考古脉络的入口；登封、巩义、新郑等县级市属于郑州市域，但从主城区前往仍需按远郊行程计算。开封、洛阳、焦作、安阳等是独立地级市，各自拥有完整的历史主题和城市交通，不能因铁路通达就并入郑州景点清单。

从郑州向东可接开封，向西可接洛阳，向北越过黄河可接焦作，向北更远可到安阳。跨市组合应先锁定车票与住宿，再查看相应城市官方文旅和场馆预约，不在本索引页固化车次、票价或班次。
