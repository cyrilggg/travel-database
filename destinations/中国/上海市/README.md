# 上海市旅行目的地

上海既是一座超大城市，也是一处省级行政区。多数首访行程集中在黄浦江中心段两岸：人民广场—南京东路—外滩构成清晰的东西轴线，衡山路—复兴路一带保留近代街区与住宅建筑，陆家嘴展示现代天际线，徐汇滨江和虹口则分别提供工业滨水更新与多层历史记忆。闵行七宝适合从中心城或虹桥方向安排半日；青浦朱家角、浦东临港、迪士尼度假区和崇明等方向则需要单独安排更长交通，不能当作市中心顺路景点。

## 区域格局与行程组合

上海核心旅行可按六个片区组织：

- 人民广场—南京东路—外滩：从城市公共文化设施向黄浦江顺向步行，是首访最容易理解的一条轴线；若安排上海博物馆，不宜再叠加浦东大型场馆。
- 老城厢—豫园—外滩南段：园林、传统商业和上海县城历史叠合，节庆与周末客流明显；可与外滩南段组合，不必再折返人民广场。
- 衡山路—复兴路历史文化风貌区及相邻街区：武康路—安福路、淮海中路—思南路是不同的小尺度线路。旅行宣传中的“原法租界”只是一种宽泛历史称呼，不是现行行政区，也不等于所有林荫街道。
- 陆家嘴与浦东文化场馆：从浦西隔江可见，但过江仍要乘地铁、轮渡或公路交通。观景台一次选一座即可，上海博物馆东馆应视为另一处大型场馆。
- 徐汇滨江与虹口：西岸位于外滩西南方向的徐汇江岸，并非外滩的相邻西侧；北外滩、提篮桥和山阴路—鲁迅公园也分属虹口内不同小片区。
- 闵行七宝：七宝古镇、七宝老街与蒲汇塘组成紧凑半日片区，可由轨道交通接入；石桥、窄街、小型场馆和节庆客流需逐项核对。GeoNames `1798097` 是七宝镇城市点，不是一座独立法定城市，相关旅行内容由上海指南完整承接。
- 远点：朱家角、迪士尼度假区、临港和崇明通常各占一天。上海行政范围很大，这些方向不应按市中心半日线理解。
