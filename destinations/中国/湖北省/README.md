# 湖北省旅行目的地

湖北位于长江中游，旅行空间从江汉平原、长江与汉江沿岸延伸到鄂西山地。省内目的地之间差异明显：武汉是一座由两江三镇、东湖和大型文化场馆共同构成的超大城市；仙桃是省直管县级市，以沔阳文脉、排湖水乡和湿地农业形成独立行程，天门同为省直管县级市，以石家河考古、陆羽茶文化、侨乡和湿地湖荡形成另一条江汉平原线路；鄂州以古武昌、吴都文物、西山、武昌鱼和梁子湖连接紧凑主城与湖区；黄石沿长江南岸展开，以主城工业遗产和湖山景观见长，大冶则以铜绿山矿冶考古、城市湖山和乡村景区构成独立行程；黄冈以黄州东坡文化为主城线索，向北、向东延伸到大别山、革命史、李时珍与黄梅戏等县域主题，武穴则以广济港埠、武山湖湿地和横岗山山水构成独立县级市行程；咸宁从温泉城区、桂花与鄂南古村延伸到幕阜山地；宜昌关联长江三峡与水利工程；襄阳偏重古城与三国文化，老河口则以汉江商埠、丹渠水利和梨桃农业构成独立县级市行程；荆州偏重古城与楚文化；荆门从东宝—掇刀主城延伸到漳河水库、屈家岭考古和江汉平原农业；孝感从江汉平原孝文化与云梦简牍延伸到北部山地和平原县域，应城则以蒲阳老城、膏盐矿业、温泉与湿地构成独立县级市行程；随州以曾随考古、炎帝传统和大洪山连接主城与县域；十堰、恩施等方向则具有更强的山地交通、天气和体力边界。各地不能按“武汉周边顺路景点”合并处理。

现有 **26 座**可直接查阅的城市指南；新增的[麻城](./麻城市.md)以龟峰山、革命史、杜鹃花季和大别山门户为主线。每个条目先说明城市与周边区域的空间关系，再提供景点、餐饮、路线、住宿、交通、天气和行前核对入口。

## 区域格局与行程组合

- 武汉中心城区：长江与汉江把城市分为武昌、汉口、汉阳。跨江移动应视作行程节点，黄鹤楼—汉口历史轴、省博—东湖和汉阳近江片区适合分日组织。
- 武汉北部远郊：黄陂木兰片区包含多个相互独立的景区，一日通常只选一处；山地天气、道路和返程接驳需要单独核对。
- 江汉平原仙桃：[仙桃](./仙桃市.md)是湖北省直辖县级市，不归武汉或荆州。干河—龙华山—沙嘴—杜湖主城承担住宿、铁路接驳和公共文化，南部排湖的沔阳小镇与密塘渔村、西部梦里水乡、西南沔城、东南沙湖湿地及西流河纪念点分属不同方向。仙桃站与仙桃西站不是同一门户；排湖旅游区、湿地保育区、鱼塘养殖区和堤防水利设施也不能混作连续公共游线。只进入正式景区、游客村、开放步道和持证船舶，暴雨、雷电、大风、积水或防汛管制时取消湖区与乡村道路行程。
- 江汉平原天门：[天门](./天门市.md)是湖北省直辖县级市，没有地级父市。竟陵主城承担住宿和公共文化，石家河考古片区、张家湖湿地、东湖—茶圣故里、北湖侨乡片区及乡村景区分属不同尺度，不能靠主城步行串联。天门站、天门南站与天门北站是三个不同铁路门户，订票时须同时核对全名和最后一段接驳。考古保护区、发掘工地、湿地保育区、鱼塘农田、堤防水利设施和生产厂区不因邻近景点而成为开放游线；只进入正式场馆、景区、游客村和公布步道。
- 鄂东鄂州：[鄂州](./鄂州市.md)的鄂城主城以博物馆、西山、洋澜湖和分段开放的长江滨水空间为核心；华容与葛店位于西向，偏田园、休闲和武汉都市圈联程，梁子湖位于南向，以梁子岛正式景区、游客码头和持证船舶为旅行边界，两者不应合并为同一日环线。花湖机场位于临空方向，兼有客运与大规模货运功能，客运航班和接驳须按当日核对；机场货站、跑道周界、沿江货运港区、码头、堤防、湿地保护区和渔业水域均不因临水或具有产业特色而成为公众景区。观音阁是否可进入以文物部门当期公告为准，无正式开放信息时只从认可的岸上公共位置远观。
- 鄂东南黄石与大冶：[黄石](./黄石市.md)主城由黄石港、西塞山、下陆和铁山等组团构成，长江岸线、磁湖、工业遗产和山地景区并非一段连续步行区。[大冶](./大冶市.md)是黄石市代管的法定县级市，拥有独立城区、铁路门户、住宿和公交体系；铜绿山、城区公共文化与各乡镇景区按大冶指南安排，不作为黄石主城的一段步行延伸。阳新是县。“黄石经济技术开发区·铁山区”属于功能管理表述，不是新增的法定县级行政区。两座城市正式开放的工业或考古遗产都必须与在产矿厂、尾矿库、港区、专用铁路和治理区分开；黄石主城、大冶城区与阳新湖山方向宜分别留足时间。
- 鄂东北黄冈、麻城与武穴：[黄冈](./黄冈市.md)以黄州为市级场馆、住宿和交通基点，东坡赤壁、黄冈市博物馆和遗爱湖之间需要地面接驳。团风、红安、罗田、英山、浠水、蕲春、黄梅分属不同县域方向；[麻城](./麻城市.md)与[武穴](./武穴市.md)是已有独立指南的法定县级市，分别安排跨城交通与住宿。大别山世界地质公园、经营景区、自然保护地、茶园与药材生产区边界不同；长江港区、湖库大坝、林业作业区和厂区不属于公共游线。
- 鄂东南咸宁与赤壁：[咸宁](./咸宁市.md)主城由温泉城区与咸安／永安城区共同构成，博物馆、淦河、潜山和不同经营者的温泉场馆可分段组合；刘家桥、汀泗桥仍需公路接驳。通山的九宫山与隐水洞分别占用完整县域日。[赤壁](./赤壁市.md)是代码独立的县级市，古战场、羊楼洞和陆水湖按独立页面分日安排。九宫山自然保护范围与陆水湖水利、施工、水源保护空间都应遵循各自管理边界。
- 鄂西长江方向：[宜昌](./宜昌市.md)的沿江主城、三峡大坝、三峡人家与县域景区需分日安排。[宜都](./宜都市.md)是代码独立的县级市，陆城、清江、九凤谷与枝城按独立页面规划。大坝、船闸、升船机、专用码头及部分水域是持续运行的生产设施，旅行者使用官方开放区和持证交通。
- 宜昌县级城市边界：[宜都](./宜都市.md)、当阳、枝江是代码独立的县级市，不是宜昌主城郊区；宜都已经有完整指南，当阳与枝江仍按属地信息规划。秭归、长阳、兴山、远安与五峰等县域方向也要分别核对公路、船期、天气与住宿。
- 荆州—洪湖边界：[洪湖](./洪湖市.md)由荆州代管，但湖区、瞿家湾、住宿和交通形成独立旅行单元。洪湖生态旅游区的开放水域、湿地保护空间与生产水面按不同边界使用；荆州父页只保留行政关系和跨城链接。
- 随州—广水边界：[广水](./广水市.md)由随州代管，应山主城、广水街道、中华山—三潭和徐家河形成独立行程。广水站点、住宿和山地交通按属地页核对，不作为随州曾都主城的同日散点。
- 鄂西北十堰：茅箭、张湾构成河谷型主城，武当山旅游经济特区、郧阳及四县都是需要独立接驳的旅行单元；丹江口市是独立法定县级市，具体游览、交通和住宿须另查属地信息。武当山内部宫观属于同一整体景区；神农架林区、襄阳市和陕西省安康市属于十堰市域之外。
- 汉江中游襄阳、老河口与枣阳：[襄阳](./襄阳市.md)以古城、樊城、古隆中和汉江两岸为主；[老河口](./老河口市.md)集中介绍汉江商埠、丹渠与王府洲；[枣阳](./枣阳市.md)集中介绍汉文化、白水寺和农业乡村。三页分别承担住宿、路线与属地交通，跨城时重新规划到发。
- 鄂中荆门：[荆门](./荆门市.md)以东宝—掇刀为主城，东宝老城、掇刀公共文化片区之间需要地面接驳；漳河位于主城西南，沙洋县和屈家岭管理区位于江汉平原方向，均不与主城构成连续步行区。钟祥市、京山市是代码独立的县级市，具体游览、往返、住宿和天气须分别查阅属地信息。漳河机场是通用机场，公众展陈或持证体验不代表跑道、停机坪和机库开放；水库大坝、闸室、取水设施、港区、磷矿及其他生产矿区也不属于公共游线。漳河及市域林区遇暴雨、山洪、地质灾害或森林防火管制时，应按官方公告取消临水、进沟、穿林和非开放道路活动。
- 鄂北随州：[随州](./随州市.md)以曾都主城为场馆、住宿和交通基点，随县的厉山与大洪山分属不同方向，大洪山通常占用完整一日；广水市是代码独立的县级市，具体游览与住宿应单独核对。擂鼓墩古墓群、曾侯乙墓与遗址博物馆作为一个遗址整体安排，毗邻的随州市博物馆因承担地方综合展陈可单列；考古工地、保护区和施工范围只按公告开放。大洪山内部山峰、寺院、洞穴和步道属于同一景区游线；河湖水库、未开放林道和矿业作业区也不是公共景区。暴雨后以及山洪、地灾或森林火险预警期间，应避开沟谷、临水岸线和林区小路，并服从封山、停运与疏散安排。
- 鄂西南恩施：恩施市是恩施州首府，同时是法定县级市；州城公共文化与恩施土司城、土家女儿城等近郊文化景区可组成城市日，恩施大峡谷、梭布垭石林则各需独立山地日。恩施大峡谷—腾龙洞世界地质公园横跨恩施市与利川市，不是一座单入口、单票制景区；利川市是另一法定县级市，建始、巴东、宣恩、咸丰、来凤、鹤峰六县也须分别核对属地信息。峡谷、洞穴、清江水域、地质公园保护范围、茶园与农田只进入正式开放或经许可的空间；暴雨、山洪或地灾预警时取消进沟、临水和山路行程。
- 江汉平原荆州：[荆州](./荆州市.md)的荆州古城—博物馆、纪南考古片区、沙市商埠和长江公共岸线分属不同组团。古城墙作为一个整体，熊家冢遗址博物馆与车马阵属于同一景区；石首、洪湖、松滋、监利是法定县级市，具体游览与住宿应分别核对。港口、堤防、行洪区、湿地保护地和考古工地只进入正式开放范围。
- 鄂东北孝感与应城：[孝感](./孝感市.md)以孝南主城为市级场馆、住宿和交通基点，云梦、孝昌与大悟分属不同普通县方向。[应城](./应城市.md)是孝感代管的法定县级市，已由独立页面承接蒲阳老城、矿山公园、汤池、老观湖、住宿和市内交通，不作为孝感主城景点；安陆、汉川同样不是孝南郊区，具体内容仍须分别查阅属地信息。孝感北站服务大悟而非孝南主城；应城客运门户为应城站，应城东站当前以货运为主。考古保护区、矿井生产区、养殖堤、湿地和森林只进入正式开放范围，同一旧址群、主题乐园或景区内部节点属于一个整体游线。
