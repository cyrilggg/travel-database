# 湖北省旅行目的地

湖北位于长江中游，旅行空间从江汉平原、长江与汉江沿岸延伸到鄂西山地。省内目的地之间差异明显：武汉是一座由两江三镇、东湖和大型文化场馆共同构成的超大城市；宜昌关联长江三峡与水利工程；襄阳、荆州偏重古城与历史；十堰、恩施等方向则具有更强的山地交通、天气和体力边界。各地不能按“武汉周边顺路景点”合并处理。

当前目录只收录达到 `researched` 状态的武汉城市页。其他湖北城市将在城市边界、交通结构、景点去重、动态核对项和官方来源均完成研究后加入；空模板、自动目录和未研究页面不计作覆盖完成。

## 区域格局与行程组合

- 武汉中心城区：长江与汉江把城市分为武昌、汉口、汉阳。跨江移动应视作行程节点，黄鹤楼—汉口历史轴、省博—东湖和汉阳近江片区适合分日组织。
- 武汉北部远郊：黄陂木兰片区包含多个相互独立的景区，一日通常只选一处；山地天气、道路和返程接驳需要单独核对。
- 鄂西长江方向：宜昌及三峡相关目的地涉及船期、坝区规定、峡谷天气和较长交通，应以后建立独立城市及区域资料，不纳入武汉页完成率。
- 鄂西北与鄂西南：十堰、神农架、恩施等地的山地、高海拔局部环境和自然风险与江汉平原不同，需要独立研究，不能套用武汉交通与气候判断。
- 历史城市带：襄阳、荆州及其他城市拥有各自的古城、博物馆和周边遗址，待形成可审计城市页后再加入本目录。
