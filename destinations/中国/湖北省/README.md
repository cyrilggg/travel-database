# 湖北省旅行目的地

湖北位于长江中游，旅行空间从江汉平原、长江与汉江沿岸延伸到鄂西山地。省内目的地之间差异明显：武汉是一座由两江三镇、东湖和大型文化场馆共同构成的超大城市；鄂州以古武昌、吴都文物、西山、武昌鱼和梁子湖连接紧凑主城与湖区；黄石沿长江南岸展开，以古今矿冶、工业遗产和湖山景观见长；宜昌关联长江三峡与水利工程；襄阳、荆州偏重古城与历史；荆门从东宝—掇刀主城延伸到漳河水库、江汉平原农业和县级市遗产地；孝感从江汉平原孝文化与云梦简牍延伸到北部山地、温泉和湖区；随州以曾随考古、炎帝传统和大洪山连接主城与县域；十堰、恩施等方向则具有更强的山地交通、天气和体力边界。各地不能按“武汉周边顺路景点”合并处理。

当前目录收录 **10 座**达到 `researched` 状态的城市：武汉、鄂州、黄石、宜昌、十堰、襄阳、荆州、荆门、孝感与随州。其他湖北城市将在城市边界、交通结构、景点去重、动态核对项和官方来源均完成研究后加入；空模板、自动目录和未研究页面不计作覆盖完成。

## 区域格局与行程组合

- 武汉中心城区：长江与汉江把城市分为武昌、汉口、汉阳。跨江移动应视作行程节点，黄鹤楼—汉口历史轴、省博—东湖和汉阳近江片区适合分日组织。
- 武汉北部远郊：黄陂木兰片区包含多个相互独立的景区，一日通常只选一处；山地天气、道路和返程接驳需要单独核对。
- 鄂东鄂州：[鄂州](./鄂州市.md)的鄂城主城以博物馆、西山、洋澜湖和分段开放的长江滨水空间为核心；华容与葛店位于西向，偏田园、休闲和武汉都市圈联程，梁子湖位于南向，以梁子岛正式景区、游客码头和持证船舶为旅行边界，两者不应合并为同一日环线。花湖机场位于临空方向，兼有客运与大规模货运功能，客运航班和接驳须按当日核对；机场货站、跑道周界、沿江货运港区、码头、堤防、湿地保护区和渔业水域均不因临水或具有产业特色而成为公众景区。观音阁是否可进入以文物部门当期公告为准，无正式开放信息时只从认可的岸上公共位置远观。
- 鄂东南黄石：[黄石](./黄石市.md)主城由黄石港、西塞山、下陆和铁山等组团构成，长江岸线、磁湖、工业遗产和山地景区并非一段连续步行区。大冶是法定县级市，阳新是县；“黄石经济技术开发区·铁山区”属于功能管理表述，不是新增的法定县级行政区，黄石页也不代表大冶已按独立城市完成。国家矿山公园、铜绿山遗址公园、华新 1907 等正式开放目的地与在产矿厂、尾矿库、港区、专用铁路和治理区必须分开，仙岛湖与龙港等阳新方向通常各需完整一天。
- 鄂西长江方向：[宜昌](./宜昌市.md)的沿江主城、三峡大坝、三峡人家与县域景区需分日安排。大坝、船闸、升船机、专用码头及部分水域是持续运行的生产设施，只能进入官方开放区并使用持证交通；三峡人家、大坝、清江画廊等完整景区的内部节点不重复计数。
- 宜昌县级城市边界：宜都、当阳、枝江是代码独立的县级市，不是宜昌主城郊区；本目录收录宜昌地级市页不代表这三座城市已经完成。秭归、长阳、兴山、远安与五峰等县域方向也要分别核对公路、船期、天气与住宿。
- 鄂西北十堰：茅箭、张湾构成河谷型主城，武当山旅游经济特区、丹江口市与水库、郧阳及四县都是需要独立接驳的旅行单元。武当山内部宫观按一个整体景区去重；神农架林区、襄阳市和陕西省安康市属于十堰市域之外。
- 汉江中游襄阳：襄阳古城与樊城隔汉江相望，主城两岸、古隆中、唐城、鹿门山和县域山地不能按一片连续步行区理解。襄阳古城墙及其城门按一个整体去重；唐城是当代影视主题景区，不与真实历史遗址混称。老河口、枣阳、宜城是代码独立的县级市，襄阳页提供市域交通关系并不代表三座城市已经分别完成。
- 鄂中荆门：[荆门](./荆门市.md)以东宝—掇刀为主城，东宝老城、掇刀公共文化片区之间需要地面接驳；漳河位于主城西南，沙洋县和屈家岭管理区位于江汉平原方向，均不与主城构成连续步行区。钟祥市、京山市是代码独立的县级市，需分别核对往返、住宿和天气；明显陵位于钟祥，是世界文化遗产“明清皇家陵寝”的组成部分，遗产身份不外扩到钟祥全域或荆门主城，只进入正式开放的遗产景区。漳河机场是通用机场，公众展陈或持证体验不代表跑道、停机坪和机库开放；水库大坝、闸室、取水设施、港区、磷矿及其他生产矿区也不属于公共游线。漳河、京山及市域林区遇暴雨、山洪、地质灾害或森林防火管制时，应按官方公告取消临水、进沟、穿林和非开放道路活动。
- 鄂北随州：[随州](./随州市.md)以曾都主城为场馆、住宿和交通基点，随县的厉山与大洪山分属不同方向，大洪山通常占用完整一日；广水市是代码独立的县级市，不能由随州地级市页自动完成。擂鼓墩古墓群、曾侯乙墓与遗址博物馆按一个遗址母景点去重，毗邻的随州市博物馆因承担地方综合展陈可单列；考古工地、保护区和施工范围只按公告开放。大洪山内部山峰、寺院、洞穴和步道不拆分计数；河湖水库、未开放林道和矿业作业区也不是公共景区。暴雨后以及山洪、地灾或森林火险预警期间，应避开沟谷、临水岸线和林区小路，并服从封山、停运与疏散安排。
- 鄂西南与其他山地：神农架、恩施等地的高海拔局部环境、山地交通和自然风险与江汉平原不同，需建立独立资料，不能套用武汉或十堰主城的交通与气候判断。
- 江汉平原荆州：[荆州](./荆州市.md)的荆州古城—博物馆、纪南考古片区、沙市商埠和长江公共岸线分属不同组团。古城墙按一个整体、熊家冢遗址博物馆与车马阵按一个景区去重；石首、洪湖、松滋、监利是法定县级市，不能由荆州地级市页自动完成。港口、堤防、行洪区、湿地保护地和考古工地只进入正式开放范围。
- 鄂东北孝感：[孝感](./孝感市.md)以孝南主城为市级场馆、住宿和交通基点，云梦简牍、孝昌双峰山、大悟红色旧址、应城温泉与湿地、安陆李白文化与银杏、汉川湖区分别占用独立县市日。应城、安陆、汉川是法定县级市，仍需各自独立记录；孝昌、大悟、云梦是普通县。孝感北站服务大悟而非孝南主城；考古保护区、矿井生产区、养殖堤、湿地和森林只进入正式开放范围，同一旧址群、主题乐园或景区内部节点不重复计数。
