# 齐齐哈尔旅行指南

齐齐哈尔坐落在嫩江平原，湿地、鹤类保护、清代以来的省城记忆、中东铁路遗存和重工业共同构成这座“鹤城”的旅行线索。龙沙、建华、铁锋三个相连城区适合看博物馆、公园和日常街区；扎龙生态旅游区在城东南，需要半天至一天；富拉尔基、昂昂溪、梅里斯和碾子山则是彼此分离的市域组团，不能按普通市郊景点顺路加入。齐齐哈尔烤肉是最鲜明的餐饮体验，但自然保护区、生产厂区、嫩江冰面和极寒天气都有明确的安全边界。

> 建议停留：2–4 天；富拉尔基、昂昂溪或碾子山方向各按独立半天至一天安排\
> 旅行关键词：扎龙湿地、丹顶鹤、嫩江、北疆城市史、铁路与重工业、齐齐哈尔烤肉\
> 主要体力：中等步行；湿地栈道、江岛和冬季冰雪会提高负担\
> 最近研究：2026-09-04

## 城市格局与游览区域

齐齐哈尔的旅行空间不是围绕一个老城向外均匀展开。龙沙、建华、铁锋通常构成中心城区连续生活圈，主要场馆、公园、车站和餐饮集中于此；扎龙虽属铁锋区，却位于城东南的湿地区域。嫩江以西和江心岛方向连接梅里斯文化与明月岛，南侧的昂昂溪、富拉尔基是分离组团，西南远端的碾子山更接近独立目的地的尺度。

几个常见的范围误区：

- **扎龙生态旅游区不等于整个扎龙国家级自然保护区。** 面向游客的生态旅游区位于铁锋区，完整保护区跨齐齐哈尔多个区县并延伸至大庆市；只有正式开放、设有管理和游览设施的区域属于公共参观空间。
- **定时鹤类放飞展示不等于野生鸟类保证出现。** 展示时段、地点和次数会调整，野生鸟类的迁徙、繁殖与活动取决于自然条件；两者均只作为扎龙一个景区项目记录。
- **市博物馆主馆与黑龙江督军署旧址属于同一城市史场馆体系。** 两处可能分址、分时开放，但不应拆成两个“必去博物馆”重复计数。
- **黑龙江督军署旧址与明月岛黑龙江将军府不是同一建筑。** 督军署旧址位于中心城区；将军府于城市改造后移建至明月岛，参观时应明确其迁移与重建背景。
- **工业旅游区不等于开放厂区。** 中国一重、北满特钢和军工相关项目只能按企业或景区划定的参观线活动；正常生产车间、铁路专用线、能源设施和保密区域均不对普通游客当然开放。
- **行政上的“区”不代表近郊。** 昂昂溪、富拉尔基、碾子山和梅里斯的旅行距离差异很大，应按实际道路、班次与返程安排，而不是按市辖区名称判断。

## 主要景点

优先级用于安排时间，不代表绝对排名：**A** 为首访核心，**B** 为按兴趣补充，**C** 为远区、季节性或通常需要独立半天以上的目的地。车站、江岸入口和广场属于路线节点，不单独计入完成率。同一景区的湿地博物馆、栈道、观鹤点和放飞展示只计一次；工业旅游区内部展馆与公园也按一个项目记录。

工业旅游必须服从讲解员与企业安全管理，不翻越隔离、不触碰设备、不擅自拍摄生产线，不穿拖鞋、裙摆过长或其他不符合现场要求的服装。是否接待散客、儿童、外籍访客，以及身份证件、着装、摄影和保密规则都要在出发前确认；没有预约确认时，整段工业线应取消，而不是到厂门口尝试进入。

当届冰雪乐园、雪地露营、滑雪、冰球活动、冬捕和嫩江冰上项目具有明显季节性，只在主管部门或合法运营方公告的场地与日期内成立。它们不作为常设景点重复计数，也不能把自然江面、河汊、山坡或封闭园区当成免费替代项目。

## 美食与餐饮

齐齐哈尔餐饮以桌边烤肉最具辨识度，同时包含东北家常菜、面食、江鱼、达斡尔族风味、乳制品与县域发酵食品。中心城区各生活商圈都能找到烤肉，不必把某一家店当作唯一答案；昂昂溪、富拉尔基、梅里斯和各县的地方菜更适合在对应区域旅行时顺路品尝，而不是为一道菜长距离往返。

| 菜品或餐饮类型 | 常见区域 | 一个人用餐与常见份量 | 风味、过敏原与饮食限制 | 排队风险与替代方法 |
|---|---|---|---|---|
| 齐齐哈尔烤肉 | 龙沙、建华、铁锋及全城生活商圈 | 牛羊肉常按盘或重量点，传统桌边烤适合 2–4 人分享；独行先问最低起点、小份和单人套餐 | 常见腌肉、洋葱、油料、干蘸料、生菜或苏子叶；酱油可能含大豆和小麦，蘸料常含芝麻、花生或辣椒，共用烤盘交叉接触明显 | 热门晚餐店和节庆排队高；按明码标价、肉品来源、通风和小份能力选择社区同类店，不必追逐单一品牌 |
| 烤牛肉与家庭拌肉 | 市场、肉店及烤肉馆 | 购买生拌肉回住处并不适合普通酒店；堂食由同桌自行烤熟，人数少时避免点多种大盘 | 生肉与熟食必须分夹，牛羊肉也需彻底加热；腌料盐分、糖、大豆、小麦和香辛料需确认 | 节前肉店客流大；旅行者优先选证照、冷链和堂食管理清楚的餐馆，不在无烹饪条件的住宿内操作生肉 |
| 十二忠手拉面等牛肉面食 | 中心城区及普通居民商圈 | 一碗适合独食，是早午餐和控制预算的方便选择 | 面含小麦，汤底通常含牛肉与油脂；辣油、香菜和葱可否调整需点单时询问，清真要求看门店实际资质和管理 | 用餐高峰翻台较快；任一菜单清楚、现拉现煮的同类型面馆都可替代 |
| 杀猪菜、酸菜白肉与血肠 | 东北菜馆、富拉尔基及县域餐饮 | 多为共享盆菜，2–4 人较合适；独行可找小砂锅或套餐 | 常含猪肉、骨汤、血制品和酸菜，油盐较高；素食、忌内脏或不能食猪肉者不适用，蘸料可能含大豆和小麦 | 冬季热门店等位较长；先问份量，改点小份酸菜炖菜，不与多道大菜同时下单 |
| 嫩江鱼与炖鱼 | 嫩江沿线、梅里斯及全城东北菜馆 | 整鱼通常适合多人，可能按重量计价；独行选鱼块、小份炖鱼或其他蛋白质 | 淡水鱼有细刺，酱汁可能含大豆和小麦；对鱼类过敏者须避开共锅、共油和同一砧板交叉接触 | 先确认鱼种、重量、单价和来源；不购买或食用来源不明的野生保护动物，也不把“江鱼”名称当作产地证明 |
| 达斡尔族风味与柳蒿芽菜品 | 梅里斯哈拉新村及民族餐饮 | 饺子、汤菜可按人点；手把肉等常为共享份量 | 可能含牛羊肉、奶制品、小麦和野菜；季节性野菜的来源与制作由正规经营者说明，严格过敏者逐项询问 | 节庆和团队活动需预订；没有正式接待时，选择市区菜单标注清楚的民族风味餐馆，不闯入居民家中求餐 |
| 克东腐乳及县域发酵食品 | 商场、正规特产店和部分餐馆 | 适合作为调味或小包装伴手礼，不宜按一道主菜大量食用 | 大豆制品，盐分较高；配方可能含酒、辣椒或小麦，按包装配料和保质条件判断 | 比较生产者、标签、净含量和储存要求即可，不必前往克东县只为购买单一产品 |
| 乳制品、奶食与冰品 | 商场、正规门店及梅里斯、富裕相关产品店 | 小包装适合独食，冷冻品不适合长途无冷链携带 | 常含牛乳、糖、坚果或蛋；乳糖不耐和乳蛋白过敏是不同限制，应看配料而非只问“有没有奶味” | 选择标签完整和冷链可靠的同类产品；冬季食用冷饮按身体状况控制，不把耐寒当挑战 |
| 北大仓酒等地方白酒 | 正规餐馆、商场和特产店 | 适合少量品尝或购买密封产品；不建议独自大量饮酒 | 酒精度高，孕期、未成年人、用药者及需驾驶者不适用；所谓“暖身”不能替代保暖和进食 | 按包装标签、生产者和容量比较；拒绝散装来源不明酒，饮酒后不驾车、不参加冰上和器械项目 |

桌边烤肉的首要安全事项是生熟分开和彻底加热。夹生肉的夹子不要直接夹入口食物，儿童不应独自操作炭火或高温烤盘。严重过敏、纯素、无麸质或需要清真饮食者，应分别确认腌料、蘸料、共用烤盘和厨房交叉接触；“不辣”不能说明这些条件。

## 经典行程

### 一日经典路线

**路线**：扎龙生态旅游区 → 返回中心城区午餐与长休 → 齐齐哈尔市博物馆主馆或黑龙江督军署旧址 → 龙沙公园短段 → 齐齐哈尔烤肉

- **串联逻辑**：上午把天气敏感、距离最远的湿地作为主任务，下午回到中心城区，用一个城市史场馆补足人文背景；公园和晚餐都是可伸缩的收尾，不再跨江或去南部组团。
- **预约锚点**：扎龙门票、入园时段与当日开放线路最优先，其次是市博物馆实际开放的馆址；鹤类放飞展示只是当日活动，不应取代湿地游览。
- **休息安排**：扎龙游客服务区按开放设施休息，返城后安排完整午餐；低温、大风或高温时直接删除龙沙公园。
- **时间不足时**：先删公园，再只保留市博物馆主馆或督军署旧址之一；不能通过离开栈道、压缩安全停留或追赶远处鸟群来“节省时间”。

### 两日城市路线

**第 1 天**：市博物馆主馆 → 黑龙江督军署旧址 → 建华区午餐 → 获准开放时参观卜奎清真寺，否则只做外部历史街区观察 → 龙沙公园 → 烤肉晚餐<br>
**第 2 天**：扎龙生态旅游区完整半日至一日 → 返回中心城区休息

- **串联逻辑**：第一天集中老城与公共文化，第二天把湿地的往返、栈道、观鸟和天气缓冲完整留出，避免在扎龙日再硬塞江岛。
- **预约锚点**：第一天锁定博物馆分馆开放；第二天锁定扎龙。宗教场所不以商业预约代替现场许可。
- **休息安排**：第一天在建华或龙沙室内午休，第二天带足饮水和防晒或保暖用品，并只在景区允许地点补给。
- **时间不足时**：第一天删卜奎清真寺内部参观和公园长线；第二天不再追加龙沙动植物园。

### 三日深度路线

**第 1 天**：市博物馆—督军署旧址—龙沙公园与中心城区<br>
**第 2 天**：扎龙生态旅游区<br>
**第 3 天 A（嫩江与民族文化）**：明月岛或哈拉新村二选一<br>
**第 3 天 B（考古与铁路）**：昂昂溪遗址博物馆 → 午餐与休息 → 罗西亚大街—中东铁路建筑群

- **串联逻辑**：前两天固定城市核心与湿地，第三天才按兴趣选择“江岛／民族文化”或“史前考古／铁路遗产”；A、B 两条方向不可在同一天全部完成。
- **预约锚点**：A 线确认上岛交通、景区或村落正式接待；B 线确认遗址博物馆开放。若依赖包车，还要把返程写入预约。
- **休息安排**：明月岛和哈拉新村使用正式游客服务设施；昂昂溪在博物馆与街区之间安排室内午餐，不在铁路沿线席地休息。
- **时间不足时**：第三天整段取消，保留完整的两日路线；不把远区压缩成到门口拍照即返。

### 雨雪天路线

**路线**：齐齐哈尔市博物馆主馆重点展厅 → 室内午餐 → 黑龙江督军署旧址 → 提前进入通风良好的烤肉店

- **适用条件**：普通降雨、小雪或户外体验较差但交通仍正常时适用；暴雨、暴雪、大风、道路结冰预警下应减少移动或取消行程。
- **预约锚点**：两个室内场馆的开放、预约与最晚入场；若督军署因活动关闭，以主馆延长参观代替。
- **休息安排**：午餐不跨区，馆间优先车辆短接；湿衣和积雪装备在允许区域整理，避免弄湿展厅地面。
- **时间不足时**：只保留市博物馆主馆和晚餐；不要用未经许可的厂区展馆临时替代。

### 亲子或低体力路线

**亲子路线**：齐齐哈尔市博物馆重点展厅 → 长午休 → 龙沙动植物园选定区域或龙沙公园短线 → 提前用餐<br>
**低体力路线**：车辆抵达市博物馆最近可用入口 → 只看一组核心展览 → 室内午餐 → 龙沙公园近入口平缓段或督军署旧址二选一 → 返回住宿

- **减负方式**：亲子路线不把动物园全园设为完成目标，儿童接触动物和游乐设备按现场规则；低体力路线每次户外不超过身体可承受范围，冬季把上下车、换衣和防滑都计入体力。
- **预约锚点**：儿童票、推车、寄存、科普活动和场馆入口；轮椅使用者须确认坡道、直梯、卫生间与下客点是否连续。
- **休息安排**：午休至少留出一个完整用餐时段，下午只选一处；需要安静休息者以博物馆或住宿为基地。
- **时间不足时**：亲子线删动物园远端区域，低体力线删公园；不以减少保暖层、取消饮水或冒险走冰面换时间。

### 工业与铁路遗产一日路线

**路线**：中心城区出发 → 昂昂溪遗址博物馆 → 罗西亚大街与中东铁路建筑群 → 午餐 → 预约获准的中国一重工业旅游区或建龙北满特钢工业旅游区二选一 → 返回中心城区

- **串联逻辑**：昂昂溪与富拉尔基都在城市南部方向，车辆与预约衔接良好时可把铁路聚落和重工业城市放在同一条近现代发展线上；公共交通不顺或冬季道路不佳时只做昂昂溪完整日。
- **预约锚点**：工业旅游的书面或官方渠道确认是绝对锚点，其后才是昂昂溪博物馆开放；没有企业确认则不前往厂区。
- **休息安排**：在昂昂溪或富拉尔基正常营业的餐饮区午休，不在厂门、专用线、设备区或道路边停留。
- **时间不足时**：先删工业旅游整段；如果已经获得严格时段预约，则反过来保留预约项目并删罗西亚大街长线。

### 冬季路线

**路线**：扎龙冬季开放线 → 返回城区复温和午餐 → 市博物馆或督军署旧址 → 当届正式开放的城市冰雪项目或烤肉晚餐二选一

- **串联逻辑**：把最冷、最开阔的湿地放在日照较好的时段，之后转入室内；夜间冰雪项目只有在气象、运营和返程都确认时加入。
- **预约锚点**：扎龙当日线路与活动、冰雪项目合法运营公告、返程车辆；往年开放日期不适用于本届。
- **休息安排**：每段户外后安排室内复温，衣物分层并保持干燥；相机与手机从低温进入室内时先装袋缓慢回温。
- **时间不足时**：删除夜间冰雪项目，不删除复温和用餐；极端低温、暴雪、大风或道路管制时取消扎龙，改用雨雪天路线。

### 县域远点路线

**路线**：中心城区出发 → 泰来县江桥抗战纪念地完整参观 → 县城或正式服务区午餐 → 原路返回

- **适用条件**：适合对抗战史有明确兴趣、能落实整日车辆和场馆开放的旅行者；碾子山、讷河或其他县域应另做独立路线，不与江桥同日。
- **预约锚点**：纪念馆开放、讲解、证件规则及往返交通；纪念场所不与娱乐项目包装成“刺激体验”。
- **休息安排**：只在县城、场馆或道路正式服务区停留，冬季随车准备应急保暖和饮水。
- **时间不足时**：整段取消，改留中心城区；不压缩为夜间长途往返。

**龙江方案**：龙江县城住宿地 → 新功杜鹃山或库勒湾当日开放项目 → 返回县城。**逻辑**：固定 **Longjiang / GeoNames 2035970** 对应龙江县城，以县城作补给和车辆锚点，两处远点按季节择一。**预约锚点**：道路、开放、车辆与返程。**休息**：县城和景区正式服务点。**删除条件**：花期不合适、强天气或开放未确认时保留县城休整。

## 住宿区域

| 区域 | 优点 | 缺点 | 适合人群 | 交通特点 |
|---|---|---|---|---|
| 龙沙中心商业与公园周边 | 餐饮、购物、烤肉和城市生活便利，去建华与铁锋距离相对均衡 | 节庆、夜间餐饮和主路可能嘈杂；去扎龙仍需车辆 | 首访、独行、重视餐饮和晚间便利 | 公交、出租和网约选择较多；以具体酒店到车站和场馆的实际路线为准 |
| 建华区市博物馆—卜奎街周边 | 靠近城市史场馆和老城，适合文博与低强度路线 | 晚间商业密度因街段而异，历史街区不等于全程适合拖箱 | 文博、长者、慢游 | 与龙沙可短途移动；去机场、南站和远区需预留跨城时间 |
| 铁锋区齐齐哈尔站周边 | 铁路抵离方便，前往城东和扎龙方向相对直接 | 站前环境、噪声和酒店品质差异大；不代表有直达扎龙的固定交通 | 早晚火车、行李较多、次日去扎龙 | 必须确认到达的是齐齐哈尔站而非齐齐哈尔南站，扎龙接驳另行落实 |
| 齐齐哈尔南站与机场南部方向 | 减少早班高铁或航班的市内移动 | 离老城、博物馆和普通夜间餐饮较远，不适合作为连续观光基地 | 过夜中转、极早出发或极晚抵达 | 依靠公交或道路交通，首末班、上客点和新航站楼服务需重查 |
| 富拉尔基或昂昂溪 | 便于早晨进入已预约工业项目，或慢看铁路遗产 | 与中心城区分离，餐饮住宿选择和晚间交通不如主城集中 | 工业研学、铁路遗产专项旅行 | 先确定具体项目与返程；不要只因行政上同属市辖区而低估距离 |
| 梅里斯、碾子山及县域 | 可配合民族节庆、山地赛事或县域专题行程 | 季节性强、交通疏、信息更新慢，临时换方案困难 | 有明确活动、车辆和接待确认的旅行者 | 按独立目的地订房，确认夜间供暖、停车、取消政策和次日道路 |
| 龙江县城 | 方便县域补给并缩短新功杜鹃山或库勒湾当日公路压力 | 与齐齐哈尔中心城区分离，景区仍需车辆 | 龙江县山地、度假区专题旅行者 | 先核对抵离班次、次日车辆、供暖和退改 |

冬季住宿除位置和价格外，还要确认供暖、热水、电梯、窗体密封、车辆能否停到入口和暴雪退改。无障碍需求不应只看“有电梯”三个字，还需确认从下客点、门口、前台、客房到卫生间是否连续可达。

## 市内交通

齐齐哈尔中心城区以公交、出租车、网约车和片区内步行为主；远离北三区后，公共交通班次、末班和最后一段接驳成为决定行程的关键。齐齐哈尔站、齐齐哈尔南站和三家子机场是不同门户，车票或机票上的完整名称不能省略。三家子机场新航站楼已于 2026 年 1 月启用，旧攻略中的候机楼入口和上客点可能已经失效。

| 场景 | 建议与取舍 | 行前需要重查的内容 |
|---|---|---|

| 龙沙—建华—铁锋移动 | 跨片区用公交或短途车辆，到达后集中步行；一天只安排一至两个步行单元 | 公交线路、临时改道、冬季清雪、道路管制和最后入馆时间 |

| 明月岛与嫩江沿线 | 先确认开放入口和上岛方式，再决定公交、车辆或运营方交通；游船与游览列车不是全年固定服务 | 水位、风力、开放期、船班或陆路入口、末班、救生与无障碍登乘 |
| 梅里斯哈拉新村 | 节庆或团队交通可能具有临时性，普通日不应假设有固定旅游专线 | 正式接待、车辆、返程、活动日期、餐饮预订和冬季道路 |
| 昂昂溪—富拉尔基 | 铁路、公路或正规包车均可能可行，但企业预约时间通常不允许迟到 | 车次和站名、区间道路、企业集合点、证件、返程末班及等候空间 |
| 碾子山与县域 | 距离和班次达到独立目的地尺度，优先先订往返再排景点 | 铁路或客运班次、道路封闭、山区天气、夜间驾驶、住宿和退改 |
| 龙江县城与县域景点 | 先抵达龙江县城，再按当日开放选择新功杜鹃山或库勒湾；县城承担补给和返程锚点 | 铁路或客运班次、县内车辆、景区开放、花期、道路天气和返程 |
| [讷河](./讷河市.md) | 讷河是独立县级市，可按铁路或公路、住宿和当地路线另起一段行程 | 到发车次、讷河当地交通、具体场馆开放、极端天气与返程 |
| 自驾 | 核心城区通常不必租车，远区自驾提高灵活性；冬季、湿地和山地显著增加责任与风险 | 停车、道路施工、冰雪路况、车辆防寒、防滑设备适用要求、保险和驾驶资质 |

嫩江及支流的天然冰面不是交通捷径。只有运营方明确开放、设有边界、巡查和救援的冰上场地才可进入；任何“看起来已经冻实”的江面、河汊、湖泡和湿地水面都不得自行步行或驾车穿越。

## 不同旅行者须知

| 旅行维度 | 可行条件 | 主要取舍 | 需额外核对 |
|---|---|---|---|
| 独行旅行 | 中心城区场馆、公园、公交和单份面食易安排，扎龙可搭正规交通往返 | 烤肉和东北大菜不易多样化，远区包车成本高，冬季夜间独自滞留风险上升 | 单人小份、扎龙返程、末班公交、正规车辆和住宿前台服务时段 |
| 亲子旅行 | 博物馆、科技馆、动物园和扎龙短线具有科普价值 | 湿地水边、长栈道、明火烤肉、动物互动、冰雪和军工体验需要持续看护 | 儿童预约、年龄身高、推车、喂食规则、护具、陪同与演示内容强度 |
| 长者或低体力旅行 | 每天一处主景点、车辆接驳、长午休和室内外交替可以减负 | 扎龙全线、明月岛、动物园和冬季户外尺度仍大，分离组团换乘消耗明显 | 最近下客点、座椅、轮椅借用、电梯、卫生间、积雪清理与返程 |
| 无障碍需求 | 机场可提前申请适老或特殊旅客服务；现代馆舍可能具备单点设施 | 单点坡道或电梯不代表整条路线连续，历史建筑、栈道、码头、厂区和冰雪路面可能中断 | 逐场馆确认无障碍入口、坡度、直梯、卫生间、轮椅尺寸、陪同与可停靠车辆；资料不足处均需向官方确认 |
| 观鸟与自然旅行 | 扎龙开放栈道和指定观鸟区提供湿地观察条件，望远镜比靠近鸟群更有用 | 野生鸟类不按演出时间出现，强风、降雨、芦苇高度和迁徙期都会改变观察 | 开放线路、鸟情简报、放飞展示、导览、长焦摄影规则与防火要求 |
| 摄影旅行 | 湿地、嫩江、铁路建筑和工业展陈题材差异鲜明 | 扎龙禁扰、厂区保密、宗教和纪念场所尊重优先；冬季电池衰减和镜头结露明显 | 无人机、三脚架、闪光灯、商业拍摄、生产线、礼拜与纪念馆摄影规则 |
| 预算有限 | 市博物馆、街区、公园常态空间和公交可组成低成本骨架，面食适合独食 | 免费场馆仍可能预约，扎龙交通、远区包车和节庆住宿是主要增量 | 免费预约、优惠证件、交通套票、寄存、退改与餐厅计价单位 |
| 晚出发或紧凑行程 | “市博物馆或督军署旧址＋龙沙公园短段＋烤肉”可形成完整半日 | 不临时加入扎龙、明月岛、昂昂溪、富拉尔基或县域 | 最晚入馆、晚餐排队、公交末班、冬季日落和道路结冰 |
| 严寒、暴雪与春融 | 分层保暖、防风防水鞋、缩短户外并反复室内复温 | 低温可导致冻伤失温，暴雪和风吹雪影响能见度，昼化夜冻产生暗冰与坠冰 | 气象预警、景区闭园、道路封闭、航班铁路、冰面禁入和退改 |
| 夏季降雨、雷暴与高温 | 上午安排湿地和公园，中午转场馆；携带防晒、饮水和防虫用品 | 雷暴、水位和短时强降水影响栈道、江岛、船班与道路，湿地曝晒且遮蔽有限 | 气象预警、嫩江水情、景区关闭、船班、雷电避险和防虫用品限制 |

冬季出现皮肤苍白、麻木或其他明显不适时，应立即结束户外活动、转入室内，并按官方安全提示寻求医疗帮助。后续复温方式和是否继续行程应听从当地医务、应急或现场工作人员指引，不凭经验自行处理。
