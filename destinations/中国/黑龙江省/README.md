# 黑龙江省旅行目的地

黑龙江位于中国东北部，旅行主题从哈尔滨的城市建筑、松花江与冰雪文化，延伸到大庆的石油工业遗产、湖泊湿地与温泉，再扩展至大小兴安岭森林、三江平原湿地、边境口岸和东南部山地雪乡。省域尺度很大，冬季道路、铁路和航空又容易受暴雪、低温与风吹雪影响；“从哈尔滨出发”不等于可以当天往返。各目的地应按实际交通、季节开放和自然风险分别研究。

当前目录收录达到 `researched` 状态的哈尔滨和大庆城市页。其他黑龙江城市及景区将在城市边界、交通结构、景点去重、动态核对项与官方来源完成研究后加入；空模板、自动目录和未研究页面不计作覆盖完成。

## 区域格局与行程组合

- 哈尔滨中心城区：道里、道外、南岗与松花江北岸构成主要城市旅行范围。中央大街—圣索菲亚、道外中华巴洛克、南岗博物馆带和太阳岛适合分片区安排；冬季跨江和长距离步行要为严寒、积雪与道路结冰额外留时。
- 哈尔滨市域远点：香坊区成高子镇的伏尔加庄园需要完整往返交通，通常单独占用一天；平房区的侵华日军第七三一部队罪证陈列馆距离传统旅游核心较远，至少预留半天并尊重纪念场所性质。
- 尚志—亚布力方向：亚布力滑雪旅游度假区虽属哈尔滨市域内的尚志市，但与中心城区不是同一旅行尺度。滑雪装备、雪道能力、天气、铁路余票和景区接驳共同决定行程，宜至少住宿一晚。
- 大庆城市带：萨尔图、龙凤与高新区构成东部公共文化和生活片区，让胡路集中铁人纪念、石油科技与油田生活线索；东西两端距离明显，不能按连续步行老城处理。大庆西、大庆东和大庆站也是不同铁路门户。
- 大庆县域方向：杜尔伯特的县城、连环湖各运营景区与民族文化场馆不属于一个统一票制；林甸温泉由不同经营主体组成。肇州、肇源以及红岗、大同南部油田带都需独立交通，生产井场、保护区核心和自然冰面不是公共游览空间。
- 牡丹江—雪乡方向：中国雪乡位于牡丹江市海林市，不属于哈尔滨景点。其道路、住宿、倒站交通与极端天气应在牡丹江或独立区域资料中研究，不能计入哈尔滨城市页完成率。
- 北部森林与边境方向：伊春、漠河、黑河、抚远等地距离遥远，气候、铁路航空和边境规则各不相同，应作为独立目的地，不以哈尔滨“远郊”概括。
