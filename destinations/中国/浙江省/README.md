# 浙江省旅行目的地

浙江从太湖平原、钱塘江流域延伸到浙西山地和东部海岸，城市之间既有密集高铁，也有需要换乘公路或轮船的山水目的地。当前已完成杭州、宁波、温州、绍兴、台州、慈溪、金华、义乌与嘉兴九座城市指南：杭州以西湖、大运河和良渚为主轴，宁波由海曙老城、三江口、东钱湖和港口城市空间展开，温州从鹿城老城与瓯江延伸到雁荡山、楠溪江、南部海岸和西南山地，绍兴连接越城水乡古城、柯桥鉴湖与广域县市方向；台州以椒江—黄岩—路桥组团为城市入口，再向府城、山岳和海岛延伸；慈溪以越窑青瓷、古镇和杭州湾湿地展开；金华连接婺州古城、三江六岸、双龙洞与浙中县市；义乌以国际商贸城、绣湖、佛堂古镇和国际餐饮呈现县级商贸城市的结构；嘉兴则从南湖与运河古城延伸到分散的水乡、海塘和县级市方向。

## 区域格局与城市组合

杭州行政范围很大：西湖、湖滨和大运河属于主城区旅行尺度；西溪位于城市西部，良渚古城遗址位于余杭区，均应留出独立半日至一日；千岛湖位于淳安县，已经是跨县远郊和度假目的地，不宜与西湖、良渚或机场抵离日顺路拼接。

宁波的核心旅行区从海曙老城和月湖延伸到三江口，鄞州新城与东钱湖位于南部和东南部；慈城—保国寺、镇海、北仑及奉化溪口分处不同方向。余姚、慈溪、宁海和象山虽属宁波市域，也不能当作主城区附近景点。宁波舟山港是跨宁波、舟山两市的港口名称，舟山群岛并不属于宁波城市页。

温州的鹿城老城、瓯海与龙湾城市组团仍只是地级市域的一部分。江心屿可与五马—朔门同日，乐清雁荡山和永嘉楠溪江各是完整而分散的大型景区；瑞安、平阳与苍南海岸、文成和泰顺山地也应按独立县域日安排。温州南站在瓯海，温州北站在永嘉，龙湾机场位于东部，站名不能代替实际目的地核对。

绍兴越城古城内，鲁迅故里—沈园、仓桥直街、书圣故里和八字桥属于不同游览片区；镜湖新区的绍兴博物馆新馆与古城也需乘车衔接。鲁迅故里与沈园按一个官方景区计数，柯岩、鉴湖和鲁镇按一个柯岩风景区计数，各自内部节点不重复拆分。

绍兴的柯桥、上虞、诸暨、嵊州和新昌不是古城附近的一组“顺路景点”。兰亭、安昌、五泄、覆卮山、越剧小镇、大佛寺和十九峰分别需要公路接驳或独立旅行日；嵊州新昌站的复合站名也不代表两个县市的景点可以无缝串联。

台州由椒江、黄岩、路桥三个中心城区组团，以及天台、仙居、三门三县和临海、温岭、玉环三个县级市构成。临海府城、天台山、神仙居、温岭石塘和大陈岛各需独立游览日；景区内部城墙、索道、桥梁、洞穴或岛上节点不重复计数。浙江台州与江苏泰州的拼音容易混淆，订票时必须核对省份与完整站名。

慈溪是宁波市代管的法定县级市，浒山—白沙路主城、上林湖—鸣鹤、龙山和杭州湾北部片区相距明显。宁波前湾新区是跨慈溪、余姚部分区域的规划管理平台，不是新增县级市；慈城古县城则位于宁波江北区，也不能与慈溪混淆。湿地、主题乐园与跨海大桥属于不同运营和交通单元。

金华的婺城—金东主城、金华山双龙、白沙溪水利遗产及兰溪、义乌、东阳、永康等县级市不在同一连续游览区。婺州古城内部建筑、双龙景区内部洞穴与白沙溪三十六堰均按各自完整物理或运营单元去重；义乌现已建立独立城市记录，横店影视城和兰溪古城同样属于各自县级市旅行内容，不能因市域轨道相连就并入金华主城完成率。

义乌由福田国际商贸城、稠城—绣湖老城、江东—梅湖会展与国际餐饮片区，以及南部佛堂镇和分散的乡村人物文物组成。国际商贸城各区、楼层和购物游街区按一个市场综合体去重，公开商铺与仓库、装卸区、工厂、保税及物流作业区的准入边界必须区分。金华主城区、东阳、永康、浦江等地不计入义乌景点完成度；普通观光、专业采购和会展参加也应按不同目标安排时间和证件。

嘉兴主城区以南湖、子城、月河和运河沿线为核心；桐乡乌镇、嘉善西塘、海宁盐官以及平湖、海盐方向分属不同县市或县域，应各留完整半日至一日。乌镇、西塘与南湖都是大型运营或历史空间，内部街区、码头、展馆和观潮节点不拆分成多个覆盖项；海宁市、平湖市和桐乡市仍需独立城市页才算完成县级城市覆盖。

湖州、衢州、丽水和舟山等地也各有独立的城市与区域结构。高铁能够缩短城市间移动，不代表车站、老城和景区彼此相邻；跨城组合仍应按实际到发站、住宿地、山区公路、海岛船班和天气逐段核算。
