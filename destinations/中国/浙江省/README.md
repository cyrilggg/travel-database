# 浙江省旅行目的地

浙江从太湖平原、钱塘江流域延伸到浙西山地和东部海岸，城市之间既有密集高铁，也有需要换乘公路或轮船的山水目的地。当前以杭州作为首个完整城市指南，重点整理西湖、大运河、西溪湿地、良渚遗址与远郊千岛湖之间的空间和时间边界。

## 区域格局与城市组合

杭州行政范围很大：西湖、湖滨和大运河属于主城区旅行尺度；西溪位于城市西部，良渚古城遗址位于余杭区，均应留出独立半日至一日；千岛湖位于淳安县，已经是跨县远郊和度假目的地，不宜与西湖、良渚或机场抵离日顺路拼接。

宁波、绍兴、嘉兴、湖州、金华、衢州、温州、台州、丽水和舟山各有独立的城市与区域结构。高铁能够缩短城市间移动，不代表车站、老城和景区彼此相邻；跨城组合仍应按实际到发站、住宿地、山区公路、海岛船班和天气逐段核算。
