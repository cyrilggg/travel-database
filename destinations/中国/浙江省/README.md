# 浙江省旅行目的地

浙江从太湖平原、钱塘江流域延伸到浙西南群山和东部海岸，城市之间既有密集高铁，也有需要换乘公路或轮船的山水目的地。当前目录收录二十六座城市指南；新增的[建德](./建德市.md)、[温岭](./温岭市.md)和[临海](./临海市.md)分别把新安江山水、采石海岸和台州府城组织成独立县级市行程。

## 区域格局与城市组合

杭州行政范围很大：西湖、湖滨和大运河属于主城区旅行尺度；西溪位于城市西部，良渚古城遗址位于余杭区，均应留出独立半日至一日；千岛湖位于淳安县，已经是跨县远郊和度假目的地，不宜与西湖、良渚或机场抵离日顺路拼接。

宁波的核心旅行区从海曙老城和月湖延伸到三江口，鄞州新城与东钱湖位于南部和东南部；慈城—保国寺、镇海、北仑及奉化溪口分处不同方向。余姚、慈溪、宁海和象山虽属宁波市域，也不能当作主城区附近景点。宁波舟山港是跨宁波、舟山两市的港口名称，舟山群岛并不属于宁波城市页。

温州的鹿城老城、瓯海与龙湾城市组团仍只是地级市域的一部分。江心屿可与五马—朔门同日，永嘉楠溪江及平阳、苍南、文成、泰顺等普通县方向需要分日安排。乐清、瑞安和龙港是独立法定县级市，从温州主城前往应另算跨城交通、返程和是否换宿，三市旅行内容不纳入温州主城路线。温州南站在瓯海，温州北站在永嘉，龙湾机场位于东部，站名不能代替实际目的地核对。

瑞安是温州市代管的法定县级市。玉海—安阳主城、塘下、莘塍—东山走廊、飞云江南岸铁路门户、中西部东源—曹村—寨寮溪和北麂海岛分属不同旅行单元；忠义街、曹村和寨寮溪各按完整街区或景区去重。温州市区不计入瑞安，平阳南麂列岛与文成百丈漈也在市界之外；北麂船班、山地防火、梅雨台风、港区边界和仍在建设的市域铁路均须行前重查。

绍兴越城古城内，鲁迅故里—沈园、仓桥直街、书圣故里和八字桥属于不同游览片区；镜湖新区的绍兴博物馆新馆与古城也需乘车衔接。鲁迅故里与沈园按一个官方景区计数，柯岩、鉴湖和鲁镇按一个柯岩风景区计数，各自内部节点不重复拆分。

绍兴的柯桥、上虞和新昌不是古城附近的一组“顺路景点”，兰亭、安昌、覆卮山、大佛寺和十九峰分别需要公路接驳或独立旅行日。诸暨和嵊州是独立法定县级市，从越城前往应另算跨城交通、返程和是否换宿，两市旅行内容不纳入绍兴古城路线；嵊州新昌站的复合站名也不代表两地的景点可以无缝串联。

台州由椒江、黄岩、路桥三个中心城区组团，以及天台、仙居、三门三县和临海、温岭、玉环三个县级市构成。天台山、神仙居和大陈岛各需独立游览日；临海、温岭和玉环是独立法定县级市，从主城前往应另算跨城交通、返程和是否换宿，三市旅行内容不纳入台州主城路线。景区内部索道、桥梁、洞穴或岛上节点不重复计数。浙江台州与江苏泰州的拼音容易混淆，订票时必须核对省份与完整站名。

慈溪是宁波市代管的法定县级市，浒山—白沙路主城、上林湖—鸣鹤、龙山和杭州湾北部片区相距明显。宁波前湾新区是跨慈溪、余姚部分区域的规划管理平台，不是新增县级市；慈城古县城则位于宁波江北区，也不能与慈溪混淆。湿地、主题乐园与跨海大桥属于不同运营和交通单元。

金华的婺城—金东主城、金华山双龙和白沙溪水利遗产不在同一连续游览区。兰溪、义乌、[东阳](./东阳市.md)和永康是金华代管的独立法定县级市，从主城前往应另算跨城交通、返程和是否换宿；东阳的卢宅、横店与木雕路线由独立页面承接。市域轨道相连也不会改变行政与旅行边界。

义乌由福田国际商贸城、稠城—绣湖老城、江东—梅湖会展与国际餐饮片区，以及南部佛堂镇和分散的乡村人物文物组成。国际商贸城各区、楼层和购物游街区按一个市场综合体去重，公开商铺与仓库、装卸区、工厂、保税及物流作业区的准入边界必须区分。金华主城区、东阳、永康、浦江等地不纳入义乌景点清单；普通观光、专业采购和会展参加也应按不同目标安排时间和证件。

永康是金华市代管的法定县级市，中心城区、城东约 25 千米的方岩，以及前仓厚吴、芝英、龙山和石鼓寮等乡镇方向属于不同旅行单元。五金城、会展中心、园区、仓库和工厂首先是经营生产空间，只有正式公布开放的博物馆、精品馆、展会或接待线路可参观；方岩核心与石鼓寮也不默认共享票务和内部交通。GeoNames `1809412` 的名称 **Guli** 来自旧县城“古丽镇”，地方志说明古丽取古代丽州之意；现行记录覆盖法定永康市，而不是只覆盖旧镇。义乌、东阳、磐安、武义、缙云和金华主城区均不计入永康景点；山区暴雨、山洪地灾、庙会分流、展会规则、产业参访授权和乡镇返程须行前重查。

嘉兴主城区以南湖、子城、月河和运河沿线为核心；嘉善西塘与海盐方向分属不同普通县域，应各留完整半日至一日。西塘与南湖都是大型运营或历史空间，内部街区、码头和展馆不拆分成多个独立目的地。海宁、平湖和桐乡是独立法定县级市，从主城前往应另算跨城交通、返程和是否换宿，三市旅行内容不纳入嘉兴主城路线。

湖州的吴兴主城、南太湖湖岸和南浔古镇需要车辆衔接；德清、长兴与安吉虽是湖州市下辖普通县，也都是应独占一日的县域延伸。南浔古镇、莫干山、太湖龙之梦和安吉竹博园各按完整运营单元去重，保护地、茶园、竹林和生产空间不能因地图可见而自由进入。湖州站与湖州东站承担的铁路方向不同，仍须按实际车次和目的地选择。

衢州以柯城—衢江主城为铁路、古城与南孔文化基点，龙游石窟、常山地质景观及开化根雕与钱江源方向均需独立半日至一天。龙游、常山、开化是普通县；江山是独立法定县级市，从主城前往应另算跨城交通、返程和是否换宿，江山旅行内容不纳入衢州主城路线。孔氏南宗家庙与衢州古城步行区分作两个实用单元，龙游石窟内部洞室不重复计数；钱江源保护管理范围与正式开放景区也不能混同。浙江衢州 GeoNames `1797264` 还须与河北曲周 `1797263` 消歧。

丽水以莲都老城、万象山、丽水站和南明湖构成主城旅行范围，碧湖—古堰画乡及东西岩已是需要公路接驳的莲都远线。青田、缙云、遂昌、松阳、云和、庆元、景宁分处不同山地和河谷方向，每次宜只选一县并留出完整旅行日；龙泉是丽水市代管的独立法定县级市，从主城前往应另算跨城交通、返程和是否换宿，龙泉旅行内容不纳入丽水主城路线。古堰画乡两岸、仙都、云和梯田和其他大型景区均按实际运营单元理解，内部码头、索道、观景台与村落节点不重复拆分；传统村落、茶园、梯田、工坊和国家公园候选区还要区分公共游线、居民生产空间与保护管理边界。

舟山是由定海、普陀两个市辖区和岱山、嵊泗两个普通县组成的群岛地级市。舟山本岛、朱家尖、普陀山、东极、岱山与嵊泗依靠桥梁或不同船线连接，不是连续城区；普陀山整座景区、东极列岛各岛际运营体系和嵊泗各景区均按实际运营边界去重。跨岛行程必须按海况、台风、雾、客船停复航和住宿逐段安排，港口、船厂、渔业生产区、军事与海事管制水域只进入明确开放范围。
