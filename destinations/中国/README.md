## 跨区域旅行概览

长距离移动通常需要在铁路与航空之间按城市位置、总耗时和抵离机场成本取舍。城市页只说明枢纽结构，不保存容易变化的具体车次、票价和航班。

## 全国性行前核对

- 铁路车次、到发站和实名购票规则：[中国铁路 12306](https://www.12306.cn/)
- 入境、停留和口岸政策：[国家移民管理局](https://www.nia.gov.cn/)
- 全国天气预警：[中国气象局](https://www.cma.gov.cn/)
