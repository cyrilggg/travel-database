# 重庆市旅行目的地

重庆既是直辖市，也是范围广阔的省级行政区。城市旅行通常从长江、嘉陵江交汇处周边的中心城区开始；大足石刻、武隆喀斯特以及三峡沿线目的地则需要按独立城市或远郊行程安排，不能按普通“市区景点”理解。

## 区域格局与城市组合

重庆市行政范围包含中心城区和多个相距很远的区县。重庆城市页以渝中半岛、南岸、江北和沙坪坝等中心城区片区为主体，把大足石刻与武隆喀斯特列为各自需要完整一天、必要时当地住宿的远郊方向。万州已有独立页面：其主城位于三峡库区腹心，与重庆中心城区并不连续；甘宁瀑布、罗田与恒合高山又需从万州主城另行接驳。[涪陵](./涪陵区.md)也已按独立旅行尺度建页：城区文化、白涛—816 与武陵山方向分别组织，不归入重庆中心城区景点、路线、住宿或市内交通。黔江、奉节、巫山等具有独立交通与旅行结构的目的地仍应分别建立记录。

现行行政实体是重庆市万州区，并非法定城市。本目录保留独立页面，是因为其具有完整的跨城抵离、住宿和多日游览尺度；历史 GeoNames 记录 `1791748`（Wanxian）由现名记录 `12358576`（Wanzhou）承接，不另算第二个目的地。云阳、奉节、巫山等区县的三峡景点，以及生产港区、专用码头和未开放岸线，均不纳入万州景点范围。

涪陵的现行行政实体也是市辖区而非法定城市；独立页面采用固定 GeoNames 城市居民点 `1810979` 定位旅行门户，以 Wikidata `Q553934` 和法定代码 `500102` 确定行政边界。该 Wikidata 实体的 `P1566=1810978` 指向行政记录，不能与固定居民点互换。重庆中心城区页只保留跨城边界和链接，不承接涪陵的具体景点、路线、住宿或区内交通。
