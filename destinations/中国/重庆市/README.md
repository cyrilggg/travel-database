# 重庆市旅行目的地

重庆既是直辖市，也是范围广阔的省级行政区。城市旅行通常从长江、嘉陵江交汇处周边的中心城区开始；大足石刻、武隆喀斯特以及三峡沿线目的地则需要按独立城市或远郊行程安排，不能按普通“市区景点”理解。

## 区域格局与城市组合

重庆市行政范围包含中心城区和多个相距很远的区县。重庆城市页以渝中半岛、南岸、江北和沙坪坝等中心城区片区为主体，把大足石刻与武隆喀斯特列为各自需要完整一天、必要时当地住宿的远郊方向。万州、涪陵、黔江、奉节、巫山等具有独立交通与旅行结构的城市，后续应分别建立城市记录。
