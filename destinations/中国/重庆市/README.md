# 重庆市旅行目的地

重庆既是直辖市，也是范围广阔的省级行政区。城市旅行通常从长江、嘉陵江交汇处周边的中心城区开始；大足、武隆、三峡沿线及[梁平](./梁平区.md)等目的地按独立城市或远郊行程安排。

## 区域格局与城市组合

重庆市行政范围包含中心城区和多个相距很远的区县。重庆城市页以渝中半岛、南岸、江北和沙坪坝等中心城区片区为主体。万州、[奉节](./奉节县.md)、[云阳](./云阳县.md)、涪陵、[长寿](./长寿区.md)、北碚、南川、[巴南](./巴南区.md)、江津、开州、永川、荣昌、合川、[黔江](./黔江区.md)、[彭水](./彭水苗族土家族自治县.md)、[石柱](./石柱土家族自治县.md)与[梁平](./梁平区.md)均有独立旅行页；进入对应页面可分别查看城区、远线、住宿和区内交通。

现行行政实体是重庆市万州区，并非法定城市。本目录保留独立页面，是因为其具有完整的跨城抵离、住宿和多日游览尺度；历史 GeoNames 记录 `1791748`（Wanxian）由现名记录 `12358576`（Wanzhou）承接，不另算第二个目的地。[云阳](./云阳县.md)与[奉节](./奉节县.md)分别承接本县的三峡景点和南部地质远线，巫山等其他区县也按属地规划；生产港区、专用码头和未开放岸线按作业边界管理。

长寿以老城、菩提片区与长寿湖组成独立旅行尺度；奉节和云阳分别承担三峡西入口、峡江文物与地质远线；彭水、石柱位于渝东南及武陵山区，苗乡峡谷、土家文化、高山森林和长江古镇均需要换宿或完整公路日。这五个页面使用固定城市点定位入口，再由县区实体和行政边界确定完整属地。

涪陵的现行行政实体也是市辖区而非法定城市；独立页面采用固定 GeoNames 城市居民点 `1810979` 定位旅行门户，以 Wikidata `Q553934` 和法定代码 `500102` 确定行政边界。该 Wikidata 实体的 `P1566=1810978` 指向行政记录，不能与固定居民点互换。重庆中心城区页只保留跨城边界和链接，不承接涪陵的具体景点、路线、住宿或区内交通。

北碚的现行行政实体同样是市辖区而非法定城市。独立页面采用 GeoNames 居民点 `1816790` 定位主要旅行门户，以 Wikidata `Q713547`、法定代码 `500109` 和 2025 年重庆行政区划调整公告确定当前边界；该实体的 `P1566=1909732` 指向 GeoNames 行政记录，另一个信息很薄的居民点 `Q28804420` 只用于消歧。2025 年五镇划入、五个镇街划出后，旧地图上的渝北、北碚与两江新区归属须按最新公告校正。

南川也是市辖区而非法定城市。独立页面采用固定 GeoNames `8544703` 定位东城一带的主要旅行门户；Wikidata `Q10869906` 表达东城街道，并以 `P1566=8544703` 连接这个点，以 Wikidata `Q714170` 和法定代码 `500119` 确定区界。法定区实体当前无可核验的 `P1566` 直连，因此居民点坐标不替代整个区的行政边界。金佛山景区与自然保护区、世界遗产组成部分、神龙峡和乡村环线也分别按管理方公布的入口与游线理解。

巴南同样按市辖区旅行尺度独立组织。固定 GeoNames `1785964` 对应鱼洞主城居民点，Wikidata `Q11172932` 表达鱼洞街道；法定区实体采用 `Q554491` 与代码 `500113`。鱼洞—龙洲湾作为住宿和交通底盘，南温泉、东温泉、丰盛古镇、木洞及山地各按独立方向规划。

江津是市辖区而非法定城市。独立页面采用固定 GeoNames 居民点 `1805798` 定位几江主要旅行门户，以 Wikidata `Q201723` 和法定代码 `500116` 确定江津区界；该法定实体同样记录 `P1566=1805798`，但共享编号不表示几江点坐标等于整个行政面。四面山、津西古镇、港区、自然保护和林业空间分别按正式入口与管理边界理解。

开州也是市辖区而非法定城市。独立页面固定 GeoNames `1808950` 这一汉丰居民点，以 Wikidata `Q1371311`、法定代码 `500154` 和其 `P1566=1804855` 行政记录确定现行开州区界；历史汉丰点不能替代行政面。汉丰湖水域、刘伯承纪念馆与故居、雪宝山自然保护区分别按运营、场馆和保护地规则理解。

永川同为市辖区而非法定城市。独立页面固定 GeoNames 城市点 `1786378`，以薄居民点 `Q28795620` 说明其 `P1566`，再用法定区实体 `Q713989`、代码 `500118` 和 `P1566=1786371` 行政记录锁定区界。茶山竹海、乐和乐都、松溉古镇及长江生产岸线均按各自正式开放与管理边界组织。

荣昌独立页面固定 GeoNames 昌元主城点 `1815477`，以法定区实体 Wikidata `Q1331275`、代码 `500153` 和行政记录 `1797123` 确定区界。合川独立页面固定 GeoNames 合阳城主城点 `8417605`，以法定区实体 `Q714045`、代码 `500117` 和行政记录 `1808212` 确定区界。
