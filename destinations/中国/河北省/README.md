# 河北省旅行目的地

河北横跨燕山、太行山与华北平原，并延伸至渤海海岸，省内旅行并不是围绕省会展开的一组短途往返。石家庄适合作为河北中南部的铁路门户，也有河北博物院、正定古城、西柏坡和太行山地貌等自身旅行内容；唐山以工业遗产、地震记忆、清东陵和渤海海岸形成另一组完整目的地；保定由直隶古城、满城汉墓、清西陵和太行山远郊构成广域目的地；邯郸则从赵都与成语文化延伸至广府古城、响堂山石窟和涉县太行山区。承德、秦皇岛等城市距离远、主题独立，也应分别安排住宿和完整游览日。

## 区域格局与城市组合

石家庄市域从华北平原延伸至太行山东麓，现代主城、北侧正定古城与西部山地之间不能连续步行。河北博物院和解放广场分处主城东西两侧，可用轨道交通串联；正定适合单列半天至一天；西柏坡位于平山县方向，嶂石岩位于赞皇县方向，赵州桥位于赵县方向，三者彼此不顺路。

唐山市域从北部燕山地带延伸到南部渤海海岸。路北、路南集中了唐山博物馆、两组地震纪念空间、开滦与南湖；清东陵位于遵化方向，山叶口位于迁安方向，滦州古城位于东部，曹妃甸海岸位于南部，四者都应按独立专程规划。唐山南湖与开滦共同构成一个景区总称，但仍是两个实体游览单元；清东陵内部陵寝不拆分重复计数。

保定主城以莲池古城、竞秀生活区和东部公共文化片区为主要旅行轴线。直隶总督署、古莲花池与西大街可分段步行，保定市博物馆和保定自然博物馆需乘车连接；满城汉墓在主城西侧，清西陵位于易县，野三坡位于涞水，白石山位于涞源，后四者都不能横向压进同一日。高碑店虽属保定地级市范围，旅行上仍是有独立车站和生活圈的县级城市，不是古城近郊步行点。

邯郸主城的市博物馆、丛台公园和邯郸道可组成一条文化主线，但东部公共文化片区与传统核心仍需乘车连接。广府古城位于永年方向，响堂山与磁州窑位于峰峰方向，娲皇宫和一二九师纪念地位于涉县方向，三组远郊彼此不顺路。武安市虽由邯郸市代管，却是代码 130481 的独立县级市；京娘湖、东太行等武安目的地不计入邯郸页完成率。

雄安新区使用独立行政区划代码并按独立目的地管理，雄县、容城、安新及白洋淀相关内容不计入保定城市页完成率。承德的避暑山庄与外八庙、秦皇岛的山海关与北戴河也都属于独立城市目的地；天津市区与滨海新区不属于唐山。河北博物院虽然展示满城汉墓等全省文物，参观展览并不等于到访文物出土地；跨城路线应另查当地城市页、铁路车次和住宿条件。
