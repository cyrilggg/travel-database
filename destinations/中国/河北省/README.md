# 河北省旅行目的地

河北横跨燕山、太行山与华北平原，并延伸至渤海海岸，省内旅行并不是围绕省会展开的一组短途往返。石家庄适合作为河北中南部的铁路门户，也有河北博物院、正定古城、西柏坡和太行山地貌等自身旅行内容；承德、秦皇岛、保定等城市距离远、主题独立，应分别安排住宿和完整游览日。

## 区域格局与城市组合

石家庄市域从华北平原延伸至太行山东麓，现代主城、北侧正定古城与西部山地之间不能连续步行。河北博物院和解放广场分处主城东西两侧，可用轨道交通串联；正定适合单列半天至一天；西柏坡位于平山县方向，嶂石岩位于赞皇县方向，赵州桥位于赵县方向，三者彼此不顺路。

承德的避暑山庄与外八庙、秦皇岛的长城与滨海空间、保定的古城及太行山沿线都属于独立城市目的地。河北博物院虽然展示满城汉墓等全省文物，参观展览并不等于到访文物出土地；跨城路线应另查当地城市页、铁路车次和住宿条件。
