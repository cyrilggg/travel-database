# 河北省旅行目的地

河北横跨燕山、太行山与华北平原，并延伸至渤海海岸，省内旅行并不是围绕省会展开的一组短途往返。石家庄、唐山、保定、邯郸与邢台分别呈现省域文博、工业海岸、直隶古城、赵文化，以及邢州古城、泉水与太行山；邢台还要区分襄都—信都主城、任泽与南和组团及西部太行山的旅行尺度。廊坊则夹在北京与天津之间，由广阳—安次主城、与河北主体不连续的北三县和向南展开的县市组成，戏剧、运河、古镇、风筝与温泉需要按方向拆分。三河作为廊坊代管的县级市，另有燕郊、泃阳和东部山地构成的独立旅行结构。承德、秦皇岛等城市距离远、主题独立，也应分别安排住宿和完整游览日。

## 区域格局与城市组合

石家庄市域从华北平原延伸至太行山东麓，现代主城、北侧正定古城与西部山地之间不能连续步行。河北博物院和解放广场分处主城东西两侧，可用轨道交通串联；正定适合单列半天至一天；西柏坡位于平山县方向，嶂石岩位于赞皇县方向，赵州桥位于赵县方向，三者彼此不顺路。

唐山市域从北部燕山地带延伸到南部渤海海岸。路北、路南集中了唐山博物馆、两组地震纪念空间、开滦与南湖；清东陵位于遵化方向，山叶口位于迁安方向，滦州古城位于东部，曹妃甸海岸位于南部，四者都应按独立专程规划。唐山南湖与开滦共同构成一个景区总称，但仍是两个实体游览单元；清东陵内部陵寝不拆分重复计数。

保定主城以莲池古城、竞秀生活区和东部公共文化片区为主要旅行轴线。直隶总督署、古莲花池与西大街可分段步行，保定市博物馆和保定自然博物馆需乘车连接；满城汉墓在主城西侧，清西陵位于易县，野三坡位于涞水，白石山位于涞源，后四者都不能横向压进同一日。高碑店虽属保定地级市范围，旅行上仍是有独立车站和生活圈的县级城市，不是古城近郊步行点。

邯郸主城的市博物馆、丛台公园和邯郸道可组成一条文化主线，但东部公共文化片区与传统核心仍需乘车连接。广府古城位于永年方向，响堂山与磁州窑位于峰峰方向，娲皇宫和一二九师纪念地位于涉县方向，三组远郊彼此不顺路。武安市虽由邯郸市代管，却是代码 130481 的独立县级市；京娘湖、东太行等目的地应按武安市独立指南规划，不列入邯郸城市景点范围。

邢台主城以襄都区的邢州古城与博物馆、信都区的达活泉与郭守敬主题为两条主要线索，片区之间宜乘公交或车辆。百泉鸳水位于主城另一侧，适合另列半天；任泽区、南和区虽是正式市辖区，却是相对独立的东部、东南部组团，不是古城连续步行范围。信都区西部的大峡谷、英谈古寨、前南峪和天河山已经进入太行山深处，临城县的崆山白云洞、内丘县的扁鹊庙与邢窑文化旅游区也都应按县域完整游览日规划。

南宫市和沙河市分别使用代码 130581、130582，虽由邢台市代管，仍是独立法定县级市。王硇村、秦王湖和沙河玻璃文化等目的地应按沙河市独立行程研究，南宫境内目的地也不并入邢台城市景点范围。邢台大峡谷内部各峡谷与项目按一个景区组织，邢窑文化旅游区内的遗址馆、专题馆与体验馆也按一个文化区组织；大峡谷与英谈古寨则是两处可顺路组合的独立目的地。太行山沿线的生产矿山、采石场、厂区、尾矿库、铁路专用线和未开放废弃矿坑不是观光空间，只进入经营主体明确开放并有正式游线与安全管理的区域。

廊坊以广阳—安次为主城，主城、北部飞地式辖区和中南部县市应按城际尺度组织。三河、大厂和香河构成与廊坊主城及河北主体不连续的“北三县”；三河和霸州是县级市，香河、固安、永清、文安和大城是普通县，大厂是回族自治县。燕郊属于三河，不是廊坊主城的街道；廊坊经济技术开发区和临空经济区（廊坊）是功能管理区，不是新增的县级行政区。

北京大兴国际机场用地跨越京冀边界，旅客使用的航站楼、机场站及值机、安检和航班服务仍应通过机场统一渠道核对；跨京冀的机场用地与范围更大的临空经济区廊坊片区也不是同一概念。梦廊坊的戏剧幻城、艺术交流中心和文化商街按一个文旅组合组织，胜芳的博物馆、古建筑和传统院落按一个古镇整体组织，均不拆分重复计数。机场净空保护区、物流仓储、产业园生产区和施工区不是普通观光空间，只进入正式开放并有明确管理规则的区域。

三河由廊坊代管，却与廊坊主城不连续。燕郊西市区邻北京通州，泃阳东市区承担传统行政与生活功能，中部镇域和福山—浩然文化村方向需要公路接驳。北京通州、顺义、平谷，天津蓟州、宝坻，以及大厂、香河都在三河法定边界之外；跨省公交和在建轨道不能改变景点归属。福山与浩然文化村按一个山地文化方向组织，河道、林区、居民村落和生产空间只进入正式开放区域。

雄安新区使用独立行政区划代码并按独立目的地管理，雄县、容城、安新及白洋淀相关内容不列入保定城市景点范围。承德的避暑山庄与外八庙、秦皇岛的山海关与北戴河也都属于独立城市目的地；天津市区与滨海新区不属于唐山。河北博物院虽然展示满城汉墓等全省文物，参观展览并不等于到访文物出土地；跨城路线应另查当地城市页、铁路车次和住宿条件。
