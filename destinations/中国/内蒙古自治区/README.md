# 内蒙古自治区旅行目的地

内蒙古东西跨度很大，草原、森林、沙漠、黄河峡谷和历史城市分布在不同盟市，不能以自治区首府为中心压缩成若干当天往返。呼和浩特兼具归化城与绥远城遗存、自治区级博物馆、阴山南麓生态空间及黄河市域远郊，适合作为理解内蒙古中部历史地理的一站；呼伦贝尔、锡林郭勒、阿拉善等区域的景观尺度、抵达方式和适游季节完全不同，需要分别规划。

## 区域格局与城市组合

呼和浩特市域包括新城区、回民区、玉泉区、赛罕区以及土默特左旗、托克托县、和林格尔县、清水河县、武川县。市中心位于大青山南麓、土默川平原东部；哈素海位于土默特左旗，和林格尔土城子遗址在和林格尔县，老牛湾黄河大峡谷在清水河县。它们在行政上属于呼和浩特市，但与主城区相距较远，不能按普通城区景点处理。

“敕勒川”既见于历史文化叙述，也用于今天多处公园、景区和度假区名称；“土默川”主要指阴山南麓的地理平原。呼和浩特北部的敕勒川国家草原自然公园，与土默特左旗的敕勒川草原文化旅游区（哈素海）不是同一处。检索路线时应同时核对完整名称、旗县和入口，不能只凭“敕勒川”三个字判断位置。

包头、鄂尔多斯、乌兰察布均为独立地级市。五当召和希拉穆仁草原属于包头市范围；响沙湾和鄂尔多斯草原属于鄂尔多斯市；乌兰哈达火山、辉腾锡勒草原属于乌兰察布市。它们可以与呼和浩特组成跨城线路，但交通、住宿和当地接驳均应另计，不能算入呼和浩特城市景点完成率。

## 浏览与贡献

城市页按城市速览、区域关系、景点、美食、路线、住宿、交通、不同旅行者须知、行前核对和来源顺序组织。更新时应优先采用政府、文旅主管部门、场馆和交通运营方资料，并把稳定的地理与历史关系和会变化的票价、班次、预约、施工、节庆分开记录。

同一景区及内部场馆只计算一次。由同一博物院管理、但地址和参观流程独立的分馆，可以分别安排时间，但必须在正文写清管理关系；自然保护区只有明确开放的游径和服务区可以列入路线，不得把保护区整体描述为可自由进入的景点。
