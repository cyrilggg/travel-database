# 内蒙古自治区旅行目的地

内蒙古东西跨度很大，草原、森林、沙漠、黄河峡谷和历史城市分布在不同盟市，不能以自治区首府为中心压缩成若干当天往返。呼和浩特兼具归化城与绥远城遗存、自治区级博物馆、阴山南麓生态空间及黄河市域远郊；包头把黄河老城、钢铁与稀土工业、城中草原、阴山寺院和山北草原连接在一个广阔市域内；鄂尔多斯则由东胜—康巴什—伊金霍洛核心城市组团向库布其沙漠、黄河峡谷、草原、能源矿区和西部旗区展开；巴彦淖尔以临河为中心，沿黄河和河套灌区连接五原、磴口与乌梁素海，越过阴山后又转为草原、岩画分布区和边境口岸方向；乌海以海勃湾为主城，隔着黄河与乌海湖连接乌达、海南两片城区，并向桌子山岩画、正式开放湖岸、沙漠与葡萄酒庄展开；乌兰察布以集宁为铁路、住宿和市级文博中心，乌兰哈达火山、辉腾锡勒草原、岱海和四子王旗分别位于不同旗县和长途方向；锡林浩特是锡林郭勒盟驻地县级市，以城市文博、贝子庙和锡林河为基地进入有管理的草原空间；呼伦贝尔以海拉尔为中心，草原、森林、湿地与五个独立县级市分布在极大的市域内；赤峰则从红山—松山中心城区向红山文化、辽文化、克什克腾地质景观和翁牛特沙地展开；通辽以科尔沁主城为文博和交通基地，向哈民遗址、大青沟、库伦古建、奈曼历史与不同旗县沙地展开。前往表格之外的盟市、旗县和县级市时，应按当地景观尺度、抵达方式和适游季节另查属地资料。

## 区域格局与城市组合

呼和浩特市域包括新城区、回民区、玉泉区、赛罕区以及土默特左旗、托克托县、和林格尔县、清水河县、武川县。市中心位于大青山南麓、土默川平原东部；哈素海位于土默特左旗，和林格尔土城子遗址在和林格尔县，老牛湾黄河大峡谷在清水河县。它们在行政上属于呼和浩特市，但与主城区相距较远，不能按普通城区景点处理。

包头主城区沿昆都仑、青山、九原和东河方向展开，石拐区五当召、土默特右旗美岱召、固阳县山地、达茂旗希拉穆仁草原和白云鄂博矿区则属于不同的远郊方向。赛汗塔拉是建成区之间的城中草原，希拉穆仁是由多个接待点和经营主体组成的远郊草原区域；两者不能按同一景区、同一票制或同一交通方式处理。

鄂尔多斯的核心城市组团由东胜区、康巴什区和伊金霍洛旗阿勒腾席热镇共同构成：东胜偏较早形成的商业生活中心，康巴什集中市级政务与公共文化，机场和鄂尔多斯站则在伊金霍洛旗方向。达拉特旗响沙湾、准格尔旗黄河峡谷和工业参访、杭锦旗鄂尔多斯草原与七星湖、乌审旗萨拉乌苏、鄂托克旗阿尔寨石窟分属不同远郊方向；同属鄂尔多斯市不代表可在一天内连续完成。

巴彦淖尔以临河区为住宿、铁路和市级文博中心，黄河与河套灌区沿南部东西展开；五原县的农耕文化、乌拉特前旗的乌梁素海、磴口县的三盛公水利枢纽，以及乌拉特中旗、乌拉特后旗的阴山北麓和边境方向分属不同长途路线。河套灌区是仍在运行的农业水利系统，乌梁素海景区只覆盖湿地中明确管理的游览范围，阴山岩画是分布式文物，甘其毛都口岸首先是海关、边检和货运作业区；农田、渠道闸站、自然保护地未开放区、岩画野外坐标和口岸监管区都不能按自由进入景点处理。

乌兰察布以集宁区为铁路、机场接驳、住宿和市级文博中心；察哈尔右翼后旗的乌兰哈达火山群、察哈尔右翼中旗的辉腾锡勒草原与黄花沟、凉城县的岱海、兴和县的苏木山以及四子王旗的乌兰花镇和格根塔拉分属不同远郊方向。火山群中的编号山体和游客中心按同一景区处理，不能重复计算；辉腾锡勒是跨旗县的草原保护对象，黄花沟只是其中具有明确入口的旅游区；岱海首先是湖泊湿地和生态治理区域；四子王旗地域广阔，牧业生产区、风电设施、边境道路和航天返回任务区域都不属于自由观光空间。上述方向不能拼成集宁出发的一日环线。

乌兰哈达火山只走管理步道和指定停车接驳，不采挖火山石、不驶离道路碾压草场；辉腾锡勒和格根塔拉只在正式景区或获准经营范围活动，不擅入牧场、蒙古包、圈舍和风机检修路；西汉长城等遗址只在文物部门明确开放的展示点参观，不攀爬、取石或按野外坐标寻找；岱海湖泊湿地自然保护区只进入明确开放的公共观察与接待范围。大风、低温、雷暴、冰雹、草原森林火险和冬季道路结冰都可能使整段远郊日取消。

锡林浩特市是法定代码 152502 的县级市，也是锡林郭勒盟行政公署驻地；“盟府”说明驻地职能，并不把锡林浩特提升为地级市。城市文博、贝子庙、额尔敦敖包与锡林河可组成城区和近郊框架，白音锡勒牧场、火山地貌、口岸和边境方向则可能跨入阿巴嘎旗、东乌珠穆沁旗、西乌珠穆沁旗或其他旗县。草原首先是生态与牧业生产空间，口岸首先是海关、边检和货运作业空间；围栏、牲畜通道、水源点、边境道路、矿运路和未开放保护地不能按公共景点进入。二连浩特是自治区直辖、锡林郭勒盟代管的独立县级市，不属于锡林浩特城区路线。

呼伦贝尔以海拉尔区为行政、航空、铁路和住宿中心，鄂温克族自治旗巴彦托海镇虽与海拉尔建成区相邻但行政独立，陈巴尔虎旗莫尔格勒河、鄂温克旗红花尔基森林与其他旗域湿地、湖泊、边境方向都需要另计车程。[满洲里](./满洲里市.md)、[牙克石](./牙克石市.md)、[扎兰屯](./扎兰屯市.md)、[额尔古纳](./额尔古纳市.md)和[根河](./根河市.md)是五个独立县级市，分别选择自己的交通、住宿和城市路线。草原牧场、天然林保护区、林业施业区、湖泊湿地、口岸和边境巡护区的管理目标不同；防火、极端天气和边境规则可使整条远线取消。

赤峰中心城区主要由红山区和松山区展开，元宝山区以及阿鲁科尔沁旗、巴林左旗、巴林右旗、克什克腾旗、翁牛特旗、喀喇沁旗、敖汉旗、林西县和宁城县分属不同方向。赤峰博物馆、辽代历史文化博物馆、红山文化博物馆和二道井子遗址可用于建立城市历史框架；辽上京、喀喇沁亲王府、阿斯哈图、达里诺尔、乌兰布统和玉龙沙湖不能拼成中心城区的一日环线。红山文化遗址与辽代遗址以考古和文保为先，克什克腾各地质园区与达里诺尔保护区有独立入口和保护边界，草原沙地兼有牧业、治沙和生态功能，矿山、尾矿库、爆破区与矿运道路则属于生产空间，均不能依靠旧攻略或导航自由进入。

通辽以科尔沁区主城为铁路、机场接驳、住宿和市级文博基地；科尔沁左翼中旗的哈民遗址与孝庄园、科尔沁左翼后旗的大青沟、库伦旗的古建和沙地、奈曼旗的王府和沙地、开鲁县的纪念设施以及扎鲁特旗北部方向分属不同远线。考古遗址、自然保护区、宗教古建、沙地景区、农牧业空间和治沙工程各有独立开放与保护边界，不能依靠一条“500 公里风景大道”宣传线推定一日可达或全线自由进入。霍林郭勒市法定代码 150581，是通辽市代管的独立县级市，不属于科尔沁主城或普通旗县远郊；本目录与通辽页只保留行政边界，不预写其具体景点、路线或住宿。

乌海是法定代码 150300 的地级市，辖海勃湾、乌达和海南三个市辖区，没有下辖独立县级市。海勃湾承担行政、铁路、航空、住宿与市级文博功能；乌达和海南各有独立城区、产业空间与接驳需求，不能视作海勃湾可步行到达的街区。乌海湖是黄河海勃湾水利枢纽形成的库区，只把一号码头等当期正式开放岸线作为公共游览空间；桌子山岩画只到文物部门明确开放的召烧沟等接待范围。露天矿、井工矿、排土场、采空塌陷治理区、工业园、港区、库区工地、黄河冰面和荒漠生产路均不因邻近城区或出现在导航中而开放，普通旅行者不得自行进入。

丰镇市法定行政区划代码为 150981，是乌兰察布市代管的独立县级市，不属于集宁城区或乌兰察布主城行程；前往丰镇须另查属地交通、住宿和开放信息。

“敕勒川”既见于历史文化叙述，也用于今天多处公园、景区和度假区名称；“土默川”主要指阴山南麓的地理平原。呼和浩特北部的敕勒川国家草原自然公园，与土默特左旗的敕勒川草原文化旅游区（哈素海）不是同一处。检索路线时应同时核对完整名称、旗县和入口，不能只凭“敕勒川”三个字判断位置。

包头、鄂尔多斯、乌兰察布、呼伦贝尔、赤峰和通辽均为独立地级市；锡林郭勒盟为盟级行政区，锡林浩特是其驻地县级市。五当召和希拉穆仁草原属于包头市范围；响沙湾和鄂尔多斯草原属于鄂尔多斯市；乌兰哈达火山、辉腾锡勒草原属于乌兰察布市；海拉尔与莫尔格勒河属于呼伦贝尔不同旗区；辽上京和阿斯哈图分别属于赤峰市巴林左旗、克什克腾旗；哈民遗址和大青沟分别属于通辽市科尔沁左翼中旗、科尔沁左翼后旗。它们可以组成跨城或跨旗县线路，但交通、住宿和当地接驳均应另计，不能计入另一座城市的景点。

## 阅读说明

城市页按城市速览、区域关系、景点、美食、路线、住宿、交通、不同旅行者须知、行前核对和来源顺序组织。稳定的地理与历史关系可用于组合行程；票价、班次、预约、施工和节庆等动态事项应通过政府、文旅主管部门、场馆和交通运营方入口在出发前重查。

同一景区及内部场馆不必拆成多站。由同一博物院管理、但地址和参观流程独立的分馆，可以分别安排时间；自然保护区只有明确开放的游径和服务区可进入，不能把保护区整体理解为自由游览空间。
