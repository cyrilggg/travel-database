# 南宁旅行指南

南宁的旅行线索不只是一座“绿城”。邕江穿过老城，朝阳商圈、三街两巷、水街和滨江空间保留着市井与城市历史；向东沿民族大道进入南湖、会展中心和东盟商务区，可以看到自治区首府面向东南亚的当代城市界面；青秀山、广西民族博物馆和更外缘的园博园，又把亚热带植物、园林与广西多民族历史连接起来。市内核心适合分片游览，武鸣、大明山以及更远的边关目的地则必须按独立行程处理。

> 建议停留：2–4 天\
> 旅行关键词：邕江老城、亚热带园林、广西多民族历史、东盟会展、老友粉\
> 主要体力：市区中等步行；青秀山、园博园与大明山为中等至较高体力\
> 最近研究：2026-07-30

## 城市速览

| 项目 | 旅行信息 |

| 建议停留 | 1 天可走老城—邕江轴；2 天可加入广西民族博物馆和青秀山；3 天可完整安排南湖—会展片区；4 天适合增加园博园或武鸣、大明山远郊 |

| 独行旅行 | 米粉、酸嘢和简餐便于单人点单，轨道交通覆盖主要城区；共享菜、夜间游船和远郊交通需要额外处理份量、返程或成团条件 |
| 亲子旅行 | 博物馆、短段湖岸和有明确服务设施的园区可以组合；滨江临水、长时间户外暴晒、园区接驳及游乐项目年龄或身高规则需逐项确认 |
| 长者与低体力旅行 | 可用博物馆、会展片区和平缓滨水短段组成低强度日；青秀山不宜默认“坐车即可全覆盖”，园博园和大明山更应压缩点位 |
| 无障碍信息 | 现代场馆和地铁设有部分服务信息，但历史街巷、景区坡道、园区车辆与远郊山地的连续可达范围资料不足；设施连续性需向官方确认 |

## 城市格局与游览区域

南宁中心城区沿邕江两岸展开，旅行者最常使用的是江北老城、民族大道东西轴和江南五象新区三套空间。朝阳广场位于老城交通与商业核心，向南步行可进入三街两巷、水街、中山路和邕江北岸；民族大道则从民族广场、南湖一路向东连接会展中心、东盟商务区与南宁东站方向。青秀山和广西民族博物馆位于更靠南的青环路一带，地图上看似邻近，实际入口、围墙和道路尺度决定了两者不能按普通街区连续步行。园博园在东南外缘，武鸣与大明山在北部远郊，都需要单独计算往返时间。

| 区域 | 主要内容 | 游览特点 | 与其他区域的关系 |
|---|---|---|---|
| 朝阳—三街两巷—邕江北岸 | 朝阳商圈、邕州古城·三街两巷、水街、中山路、民生广场与滨江节点 | 历史街区、市场餐饮和江岸可以连续走半日至一日；商业街翻修、夜市营业和游船均有时效性 | 南宁站靠近朝阳；从老城到南湖或会展片区适合搭地铁，不宜沿主干道硬走 |
| 民族广场—南湖 | 广西壮族自治区博物馆、民族大道西段、南湖公园 | 博物馆适合室内理解广西历史，南湖适合选一段慢行；环湖全走会显著增加距离 | 向东接会展中心与东盟商务区，向西可返回朝阳；不是与青秀山同一个入口体系 |
| 会展中心—东盟商务区 | 南宁国际会展中心、民歌湖周边、商务区公共空间与商业设施 | 以现代建筑、会展和城市夜景为主；大型展会时安检、封控和客流会改变平日路线 | 地铁与南湖、南宁东站联系清楚；可与南湖同日，不能把展馆内部开放视为常态 |
| 青秀山—青环路 | 青秀山、广西民族博物馆、孔庙等沿线场馆 | 青秀山本身足以占半天至一天；博物馆需单独留出完整参观时间，青环路不适合把所有场馆串成徒步清单 | 博物馆与青秀山可用车辆同日组合，但应缩小青秀山范围；与会展片区仍需转场 |
| 五象新区 | 南宁博物馆、广西文化艺术中心、总部与公共建筑、邕江南岸空间 | 道路宽、点位疏，室内场馆和滨江建筑适合主题补充，不是老城的步行延伸 | 过江后进入良庆方向；可与抵离日或雨天场馆日组合 |
| 邕宁东南外缘 | 南宁园博园、八尺江与园林展园 | 园区巨大，主题园、矿坑花园和水体之间距离长；普通公交与园内交通都需预留时间 | 适合独立半天以上，不与三街两巷、青秀山强行拼成同日“打卡” |
| 武鸣与北部远郊 | 武鸣城区、伊岭岩、大明山及环大明山方向 | 城区、溶洞和山地并不集中；大明山受山路、天气与景区交通约束，通常独立一日或住宿 | 南宁北站在武鸣方向，但不等于下车即可到景区；按实际班次闭合接驳链 |

德天跨国瀑布位于崇左市大新县，崇左也是独立的地级市；两者即使常以南宁为集散地销售，也不属于南宁市景点。明仕田园、花山岩画等桂西南边关目的地同理，不能纳入南宁城市景点完成率，也不适合在南宁两日路线中压缩为“顺路半天”。

## 主要景点

优先级用于安排时间，不代表绝对排名：**A** 为首访核心，**B** 为按兴趣补充，**C** 为远郊、季节性或通常需要独立半天以上的目的地。“路线节点”不计入城市景点完成率；同一景区及其内部子景点只作为一个项目记录。

大明山山体及环山旅游带跨武鸣、上林、马山、宾阳等县区语境，常见景区入口和接驳并不能由“地图上位于南宁北部”直接推定。武鸣节庆、歌圩和社区文化活动有明确日期与主体，应先查主办方，再尊重现场摄影、进入生活空间和参与活动的规则；不要把广西各族文化压缩成同一种装饰性“民俗体验”。

## 美食与餐饮

南宁饮食以米粉、酸辣发酵风味、时令水果和适合共享的桂菜并行。朝阳、水街、中山路、建政路以及成熟居民街区都能找到多种价位，夜市便于一次尝小份，但摊位位置、营业时间和卫生状况变化快。老友粉并不是只能在某一家店吃到的“打卡品”；判断同类店时，优先看是否现点现炒、份量与加料是否明示、厨房和食材保存是否清楚。

| 菜品或餐饮类型 | 常见区域 | 一个人用餐与常见份量 | 风味、过敏原与饮食限制 | 排队风险与替代方法 |
|---|---|---|---|---|
| 老友粉、老友面与老友风味 | 全城粉店，老城、水街和居民街区密集 | 一碗即一餐，最适合单人；可选鲜肉、猪杂、牛肉或素配菜，但“素配菜”不代表汤底无动物成分 | 典型风味来自酸笋、豆豉、蒜和辣椒的猛火爆香，酸辣和发酵气味明显；豆豉、酱油涉及大豆，酱料或面条可能涉及小麦，猪杂和高汤需另问 | 早餐与午餐高峰翻台快；避开只剩长队的单店，在相邻生活街区找菜单、加料和价格清楚的老友粉店 |
| 生榨米粉、干捞粉与其他南宁米粉 | 邕宁、江南及全城传统粉店 | 多为单人一碗，可按大小份和肉码调整；生榨粉的发酵米香并非变质气味 | 汤底、肉末、酱油、酸菜、花生或黄豆配料因店而异；素食、花生、大豆和麸质需求必须逐项确认 | 早晨供应通常更稳定；若某种粉售罄，可换同店干捞粉或邻近传统粉店，不必跨城追店 |
| 粉饺、卷筒粉与糯米类早餐 | 水街、市场和居民早餐区 | 可按个或小份购买，适合单人组合试吃；多样拼盘容易不知不觉过量 | 米皮内常包猪肉、木耳或马蹄，浇汁可能含酱油；花生碎、芝麻、蛋和共用蒸具带来交叉接触风险 | 热门市场早间排队较集中；优先选择周转快、馅料标示清楚的摊档，同类早餐在多个社区都有 |
| 南宁酸嘢 | 市场、夜市、水街及水果店 | 常按重量或盒售，适合一人少量品尝；先买小份判断酸、辣与咸甜接受度 | 多用木瓜、芒果、菠萝、李子、萝卜等腌拌，常加糖、盐、辣椒或甘草风味；糖盐摄入、果酸刺激、芒果或菠萝过敏及共用夹具需留意 | 夜市热门摊可能排队；看现切保存、价签和容器卫生，附近水果店或市场酸嘢档可替代 |
| 武鸣柠檬鸭 | 桂菜馆、武鸣方向餐馆 | 多为带骨整盘，更适合 2–4 人共享；单人先问半份、小锅或工作日套餐 | 鸭肉配酸柠檬、酸姜、酸辣椒等形成咸酸香，辣度可变；酱油可能含大豆和小麦，带骨食用需慢 | 正餐高峰和节庆期间较忙；不锁定单一名店，先问份量、是否现炒、酸辣度和能否打包 |
| 五色糯米饭及节庆米食 | 市场、早餐店与节期活动 | 小份适合分享或作加餐，糯米饱腹感强，不宜与多碗米粉叠加 | 颜色传统上来自不同植物原料，但具体配方、糖、油、芝麻、花生和染色来源应向摊主确认 | “三月三”等节期供应多、客流也大；平日可找正规市场或非遗活动，不追求脱离节期的表演化消费 |
| 东南亚与跨境风味餐饮 | 会展—东盟商务区、成熟商业区 | 粉面和简餐适合单人，海鲜、火锅与合菜更适合共享 | “东南亚菜”不是单一口味；鱼露、虾酱、花生、椰浆、甲壳类、香茅和辣椒因国家与菜式而异，应按具体菜名确认 | 展会期热门餐厅拥挤；按菜系与具体菜品寻找替代，不能把装修主题当作菜品来源和过敏原保证 |

清淡需求可以直接说“不要辣椒、酸笋少放、另放调料”，但豆豉、汤底和已腌食材未必能现场去除。严格素食、乳糜泻、严重花生或甲壳类过敏者，应选择能解释配料和共用锅具的餐厅；“米粉”只说明主食原料，不自动等于整碗无麸质。

## 经典行程

### 一日经典路线

**路线**：朝阳广场 → 邕州古城·三街两巷 → 水街或中山路午餐 → 民生广场 → 邕江北岸短段

- **串联逻辑**：这条路线把老城商业核心、历史街巷、日常饮食和邕江放在一条由北向南的步行轴上，避免第一天跨越多个新区。水街、中山路和民生广场是连接与休息节点，不拆成多个必须完成的景点。
- **预约锚点**：街区本身通常不是预约锚点；若进入邓颖超纪念馆等内部场馆，以该馆当日开放为锚点。若增加邕江游船，则船票、码头和开航状态成为第一锚点。
- **休息安排**：三街两巷内的公共文化空间、朝阳成熟商业设施，以及水街或民生广场附近有固定座位的餐厅；盛夏午后不在无阴影江岸连续暴晒。
- **时间不足时**：先删江岸延伸和夜游，只保留三街两巷与一顿老城餐饮；晚到则直接选“三街两巷—民生广场”短线，不绕行会展区。

### 两日城市路线

**第 1 天**：一日经典路线，傍晚按天气选择邕江公共滨水空间\
**第 2 天**：广西民族博物馆 → 青环路一带午餐或固定休息 → 青秀山选定入口与一条主题线路

- **串联逻辑**：第一天完整处理老城，第二天集中在城市南东部。广西民族博物馆和青秀山地理相邻但并非连续步行点，用出租车、网约车或核实后的公交连接；青秀山只选植物专类园、东盟友谊主题或登高观景中的一到两个重点。
- **预约锚点**：广西民族博物馆开放、预约或团体规则优先；随后核对青秀山门票、入口、园内车辆和闭园时间，不能只看地图决定从哪个门进入。
- **休息安排**：博物馆主馆、青环路正规餐厅和青秀山游客服务点；高温天把主馆放在午间，山中步行放在较早或较晚时段。
- **时间不足时**：先删青秀山深处与登塔，只保留博物馆和青秀山一个近入口园区；若博物馆闭馆，则不要用多个青秀山内部景点“补数量”。

### 三日深度路线

**第 1 天**：朝阳 → 三街两巷 → 水街 → 邕江\
**第 2 天**：广西民族博物馆 → 青秀山精简路线\
**第 3 天**：广西壮族自治区博物馆 → 南湖选段 → 南宁国际会展中心外围与东盟商务区

- **串联逻辑**：第三天沿民族大道由西向东推进，博物馆提供历史背景，南湖提供中段休息，会展与商务区呈现当代南宁。南湖不必绕行完整一圈，展馆无公开活动时以建筑外围和公共空间为主。
- **预约锚点**：第 2 天以广西民族博物馆为锚点；第 3 天以自治区博物馆和会展中心是否有可参观展览为锚点。东博会或大型展会期间须先看交通管制，再决定是否进入会展片区。
- **休息安排**：博物馆、南湖邻近商业设施和会展片区商场；用地铁代替民族大道长距离步行。
- **时间不足时**：第三天先删东盟商务区远端，只保留自治区博物馆与南湖；园林兴趣更强者可把整天替换成园博园，不把两套路线叠加。

### 雨天路线

**路线**：广西壮族自治区博物馆 → 民族大道沿线室内午餐 → 乘地铁或车辆前往南宁博物馆

- **适用条件**：只适用于普通降雨。暴雨红橙色预警、雷暴大风或城区积涝风险较高时，应减少跨江和跨区移动，留在最近的安全室内场所；青秀山、园博园和大明山不因有接驳车就适合极端天气。
- **预约锚点**：两馆闭馆日、临时展览、入馆证件和停止入场时间；两馆相距较远，中间必须以公共交通或车辆转场。
- **休息安排**：博物馆大厅、正规餐厅和轨道站内公共设施，鞋履仍需防滑；不要把地下通道视为暴雨积水时的绝对安全路线。
- **时间不足时**：只留距离住宿更近的一座博物馆，不为“凑满两馆”在晚间横跨城市。

### 亲子或低体力路线

**亲子路线**：广西民族博物馆主馆 → 固定座位午餐 → 视天气选择馆外民居展示园短段，或乘车前往青秀山一个近入口植物园区\
**低体力路线**：广西壮族自治区博物馆 → 乘车至南湖一处平缓短段 → 会展中心或东盟商务区室内休息

- **减负方式**：亲子路线先室内后室外，不同时加入青秀山深处、园博园和夜游；推车、儿童活动和园内车辆规则逐项确认。低体力路线把每次步行限定在单一入口周边，以车辆连接，不绕完整南湖，不登青秀山，也不把会展中心台阶和连廊想当然视为全程无障碍。
- **预约锚点**：亲子路线核对博物馆儿童活动、推车和青秀山园内交通；低体力路线核对博物馆电梯、南湖实际下车点、会展片区无障碍入口与休息座椅，均需官方确认连续性。
- **休息安排**：博物馆、餐厅和大型商业设施；每半日至少保留一处可长坐、避暑和使用卫生间的室内节点。
- **时间不足时**：亲子路线删去第二个园区，只留博物馆；低体力路线删南湖，只留博物馆与会展片区中的一个短段。

### 园博园一日路线

**路线**：中心城区 → 南宁园博园主入口 → 城市展园或东盟园择一组 → 矿坑花园 → 园内休息 → 原路返回

- **适用条件**：适合对园林、植物和生态修复有明确兴趣，并能接受园区大尺度步行的人群；高温、暴雨和大型活动会明显改变舒适度。
- **预约锚点**：门票、开放入口、园内车辆、临时活动和返程公交；不要按过去园博会时期的票价与专线安排行程。
- **休息安排**：游客中心、室内展馆实际开放区域和有遮阴座位的餐饮点；先根据园区图选两个主题，避免在正午跨越全部展园。
- **时间不足时**：删去最远的一组展园，保留矿坑花园和一个主题园；若只有半天且住宿在老城，整段替换成南湖或青秀山近入口短线更稳妥。

### 武鸣与大明山远郊路线

**路线**：南宁中心城区 → 核定的武鸣或大明山接驳节点 → 南宁大明山风景旅游区 → 按景区当日线路游览 → 返回武鸣或南宁

- **适用条件**：适合能承受长时间公路、山地气候变化和景区车辆衔接的人群。若重点是伊岭岩，应另做“南宁—伊岭岩—武鸣”半日至一日线，不与大明山在短日照日硬拼。
- **预约锚点**：大明山开放、实名票务、允许的上山交通方式、景区车、道路与返程；南宁北站、武鸣城区和景区入口是不同节点，不能只买到武鸣的车票就视为交通闭合。
- **休息安排**：武鸣城区、景区游客中心和官方开放的山上服务点；自备饮水、雨具和保暖层，但不进入关闭步道或自然保护区域非游览线路。
- **时间不足时**：大明山整段删除，不能压缩成市区半日附加项；改为青秀山或广西民族博物馆。出现暴雨、雷暴、浓雾、地灾或道路管制时也应整段取消。

## 住宿区域

| 区域 | 优点 | 缺点 | 适合人群 | 交通特点 |
|---|---|---|---|---|
| 朝阳广场—南宁站 | 靠近老城、三街两巷、餐饮和铁路站，短停留效率高 | 商业与交通噪声较明显，夜市周边卫生、消防和隔音差异大 | 首访、晚到早走、预算有限、重点游老城 | 多条轨道线路和公交汇集；去青秀山、会展与南宁东站需换乘 |
| 民族广场—南湖西侧 | 靠近自治区博物馆与南湖，城市中心和文化场馆平衡 | 与三街两巷、青秀山入口都还有一段距离；环湖不同位置差异大 | 偏好博物馆、城市散步和相对均衡通勤 | 民族大道轨道交通便利，适合东西向移动 |
| 会展中心—东盟商务区 | 商业设施、会展和现代城区集中，前往南宁东站较顺 | 大型展会、演唱会和节庆会推高房价并造成交通管制；老城步行氛围弱 | 商务会展、偏好现代配套、需要接南宁东站 | 轨道交通连接老城和东站；到青秀山、民族博物馆仍需公交或车辆 |
| 青秀山—竹溪方向 | 靠近青秀山外围，环境与绿地较多 | “靠近景区”不等于靠近计划使用的入口，晚间餐饮和轨道便利按具体路段变化 | 以青秀山为主、愿意减少老城夜生活 | 到青环路博物馆和各景区入口常用出租车或公交，订房前查实际距离 |
| 五象新区—南宁博物馆方向 | 新区道路、文化场馆和现代商业空间较完整，适合五象活动 | 距朝阳老城与南宁东站较远，点位之间步行尺度大 | 参加五象活动、场馆旅行、偏好较新住宿设施 | 依赖轨道交通和短途车辆；过江拥堵与活动管制需重查 |
| 南宁东站周边 | 高铁抵离便捷，去会展—东盟片区顺向 | 不是老城旅行氛围区，前往邕江、水街和五象都需时间 | 早班高铁、短暂停留、把南宁作为广西交通中转 | 轨道交通可进入民族大道轴，按车票确认是否真在南宁东站到发 |
| 武鸣城区 | 可把大明山或伊岭岩的早出发压力分散到前一晚 | 不适合每天往返南宁老城；住宿、夜间交通和接驳信息需逐店逐线核对 | 明确安排武鸣和大明山、愿意住一晚 | 南宁北站与城区、景区入口仍需二次接驳，不能等同 |

不推荐未经核验的具体酒店。订房时把“离地铁近”“离青秀山近”“离机场近”转换成可核查的问题：最近可用出入口是否有电梯、到计划入口需几次换乘、展会或节庆是否管制、深夜抵达是否仍有合法交通。

## 市内交通

| 场景 | 建议与取舍 | 行前需要重查的内容 |
|---|---|---|
| 南宁吴圩国际机场抵达 | 机场位于中心城区南侧较远处，可比较机场巴士、出租车、网约车及与吴圩机场站相关的铁路服务；不要默认普通地铁已直达航站楼 | 实际航站楼、机场巴士停靠与末班、铁路车次和站内换乘、夜间附加费、施工 |
| 南宁站与南宁东站 | 南宁站靠近朝阳老城，南宁东站更靠近民族大道东端和会展片区；两站不能仅凭“南宁”二字互换 | 车票到发站、进站口、地铁运营、节假日安检和无障碍服务 |
| 南宁北站与武鸣 | 南宁北站服务武鸣方向，但距离大明山、伊岭岩和武鸣具体住宿仍有二次交通 | 实际列车、公交或客运接驳、出租车候车、景区专线、返程末班 |
| 城区轨道交通 | 轨道交通适合在朝阳、民族广场、南湖、会展中心、东盟商务区和南宁东站之间跨片区移动；出站后仍要根据景区入口步行或转车 | 线网图、首末班、换乘通道、电梯出口、展会临时封站与票制 |
| 老城步行 | 朝阳—三街两巷—水街—民生广场可以分段连续走，适合“到片区后步行”；夜市人流和过街会降低速度 | 街区施工、临时活动、积水、夜间照明、共享交通停放与场馆开放 |
| 青秀山与青环路 | 广西民族博物馆和青秀山宜用公交或出租车连接，青秀山内部再按官方地图选择步行与园内车辆 | 入口、园内车线路与停靠、闭园、票务、无障碍与婴儿车规则 |
| 园博园 | 外缘景区往返时间长，先确定使用的入口，再比较公交、旅游线路和出租车；返程不能只依赖临时活动专线 | 公交班次、园内车辆、活动散场、入口关闭和叫车位置 |
| 邕江游船 | 属旅游观光产品，不是稳定的日常过江通勤；码头、路线和夜景产品随水位、活动与运营安排变化 | 开航、码头、航线、实名证件、退改、儿童与无障碍登船条件 |
| 自驾 | 城区核心并非必需；去武鸣和大明山可增加灵活性，但山区是否允许自驾上山由当日规定决定 | 城区停车、景区停车、展会限行、山路与地灾、租车保险和上山交通方式 |

南宁最实用的城市移动原则是“轨道跨片区、车辆到景区入口、片区内步行”。青秀山、广西民族博物馆、园博园和大明山四者不能仅按直线距离排序；入口位置、园区封闭边界和返程班次比地图上的距离更重要。

## 不同旅行者须知

| 旅行维度 | 可行条件 | 主要取舍 | 需额外核对 |
|---|---|---|---|
| 独行旅行 | 米粉、早餐、小吃和轨道交通对单人友好，老城与博物馆可独立完成 | 柠檬鸭等共享菜份量大，夜游和远郊包车可能有最低人数或成本劣势 | 餐厅半份、夜游开航、远郊成团、晚间返程与合法上车点 |
| 亲子旅行 | 民族博物馆、城市博物馆和一个园区短线能交替室内外 | 滨江、湖岸、山地和大型园区容易造成看护与体力负担，游乐项目规则不统一 | 儿童票、证件、推车、身高年龄、园内车与卫生间位置 |
| 长者或低体力旅行 | 以一馆一片区为单位，使用轨道和出租车连接，可明显降低总步数 | 青秀山、园博园和大明山即使有车辆仍存在上下车、坡道和等待；南湖不必环湖 | 电梯出口、最近下车点、景区车辆座位、休息点、可达卫生间与陪同要求 |
| 无障碍需求 | 南宁博物馆官网设有便民服务与手语讲解入口，交通枢纽和现代场馆可提前联系 | 有一项服务不代表建筑、室外园区、地铁换乘与景区车辆全程连续可达；历史街巷和山地资料尤其不足 | 轮椅尺寸、坡道、电梯、无障碍卫生间、登船设备、园内车、无障碍入口均需向官方确认 |
| 摄影旅行 | 邕江桥岸、老城街巷、南湖、会展建筑和青秀山各有不同城市层次 | 商业街人流、湿热、雨雾和山地负重会改变成果；民族文化活动不等于可任意近拍 | 场馆拍摄、三脚架、无人机、商业摄影、人物许可和展会安检 |
| 预算有限 | 老城步行、公共江岸、南湖选段、米粉和轨道交通可组成低成本路线 | 远郊省下的门票可能被接驳费用抵消；只看低房价可能增加跨城通勤 | 景区免费范围、优惠资格、公交末班、园内交通和住宿活动期涨价 |
| 晚出发或紧凑行程 | 半天保留“三街两巷—邕江”或“自治区博物馆—南湖”一组即可 | 不临时加入青秀山全园、园博园、武鸣或德天瀑布；会展中心内部也未必随时开放 | 场馆最晚入场、地铁末班、夜市营业、江岸天气与返程 |
| 高温、雨季与山地天气 | 高温天早晚户外、午间进馆；普通小雨可转博物馆 | 强降雨会带来积涝、雷电、邕江水位、景区闭园和山地地灾，不能只靠雨伞继续原计划 | 南宁市气象预警、景区公告、山洪地灾、道路管制、航班铁路退改 |

参观广西民族博物馆或参与武鸣节庆时，应把展品、讲解和社区主体作为理解文化的起点。广西各民族的传统与当代生活都具有地区、历史和个体差异；不使用笼统标签替代具体族群与展览语境，不把服饰或仪式仅当作拍照布景，人物摄影先征得同意。
