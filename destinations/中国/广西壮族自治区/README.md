# 广西壮族自治区旅行目的地

广西从北部的南岭与喀斯特峰林延伸到南部沿海，城市之间距离较大，山地、公路与水上交通都会影响实际游览节奏。桂林、南宁、柳州、钦州、贵港与玉林分别呈现山水、首府、工业、海岸、港城和侨乡结构；贺州位于桂粤湘交界，以八步—平桂主城为枢纽，向姑婆山、临贺故城、昭平黄姚古镇以及钟山、富川的乡村文化方向展开。后续城市与县城仍须依覆盖清单分别研究，不能由任一城市页代替。

## 区域格局与城市组合

桂林位于广西东北部，常见旅行线路会把桂林中心城区、漓江游船、阳朔与龙胜龙脊梯田连写在一起，但它们不是一个可连续步行的目的地。桂林市页以秀峰、象山、叠彩、七星等中心城区为起点，将漓江写成通往阳朔的旅行走廊，将阳朔与龙胜写成需要独立半天以上、通常更适合整日或住宿的目的地。阳朔县、阳朔镇、兴坪镇、龙胜各族自治县及其聚落是否需要独立建页，仍须按 GeoNames 清单逐条处理。

南宁位于广西中南部，中心城区可分为朝阳—三街两巷—邕江老城轴、民族广场—南湖—会展中心的东西向城市轴、青秀山—青环路场馆片区和五象新区。园博园在东南外缘，武鸣、伊岭岩与大明山在北部远郊，不能按中心城区景点密度压缩。德天瀑布位于崇左市大新县，崇左也不是南宁市辖区；它们即使以南宁为交通集散地，也不计入南宁城市景点。

柳州中心城区由柳江两岸、老城、河东工业片区和南部喀斯特公园组成。柳州博物馆—柳侯公园适合连续步行，工业博物馆需过江，龙潭、白莲洞与柳东则需要分别乘车。柳城、鹿寨、融安、融水和三江属于柳州市域，但每个县的景区、社区和交通都应按独立一日或住宿行程处理。

钦州主城区可从钦北的铁路门户与冯子材故居向南串联刘永福故居、老街和坭兴陶文化片区；三娘湾、茅尾海和钦州港则需要公路接驳。港城公共空间与生产港区必须分开，码头、堆场、海关监管区、石化园区和航道不因地图可见而开放参观。三娘湾、八寨沟、灵山和浦北分属不同方向，海况、台风、山洪与返程交通都应逐日核对。

贵港主城由郁江分隔港北与港南，覃塘的荷田、港北西郊的园博园和平天山也不是一片连续步行区。桂平是代码独立的县级市，西山、龙潭、金田和大藤峡应从桂平另作路线；运行中的港口、水利航运设施、林区和农业生产田只能进入正式开放范围。玉林主城的玉州老城、玉东公共文化片区与福绵方向同样需要车辆转换，容县、陆川、博白、兴业分属不同县域日；北流是独立法定县级市，不因“玉北容”交通联系而并入玉林主城完成率。

贺州的八步与平桂构成主城和铁路集散框架，姑婆山、玉石林、十八水等北部山地景区各有独立入口；临贺故城位于八步区贺街镇，黄姚古镇位于昭平县，钟山与富川也各是独立县域方向。黄姚内部街巷、古榕、桥井与建筑按一个完整古镇景区去重；姑婆山度假区、森林公园和各运营景区名称相近却不等于边界相同。村落、果园、茶园、矿区和自然保护地只有明确开放的公众范围可以进入。

柳州、北海、梧州、崇左等地与桂林、南宁的城市体验和气候风险不同，不能把现有样例当作全区通用模板。跨市组合应先按铁路或公路枢纽确定顺序，再核对山区道路、汛期风险和实际班次。
