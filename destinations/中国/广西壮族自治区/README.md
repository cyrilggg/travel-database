# 广西壮族自治区旅行目的地

广西从北部的南岭与喀斯特峰林延伸到南部沿海，城市之间距离较大，山地、公路与水上交通都会影响实际游览节奏。本阶段以桂林建立“中心城区、河流走廊、县域目的地”并存时的写法；后续城市与县城仍须依覆盖清单分别研究，不能由桂林一页代替。

## 区域格局与城市组合

桂林位于广西东北部，常见旅行线路会把桂林中心城区、漓江游船、阳朔与龙胜龙脊梯田连写在一起，但它们不是一个可连续步行的目的地。桂林市页以秀峰、象山、叠彩、七星等中心城区为起点，将漓江写成通往阳朔的旅行走廊，将阳朔与龙胜写成需要独立半天以上、通常更适合整日或住宿的目的地。阳朔县、阳朔镇、兴坪镇、龙胜各族自治县及其聚落是否需要独立建页，仍须按 GeoNames 清单逐条处理。

南宁、柳州、北海、梧州、崇左等地与桂林的城市体验和气候风险不同，不能把桂林样例当作全区通用模板。跨市组合应先按铁路或公路枢纽确定顺序，再核对山区道路、汛期风险和实际班次。
