# 广西壮族自治区旅行目的地

广西从北部的南岭与喀斯特峰林延伸到南部沿海，城市之间距离较大，山地、公路与水上交通都会影响实际游览节奏。桂林、南宁、柳州、钦州、贵港、梧州与玉林分别呈现山水、首府、工业、海岸、内河港城、岭南商埠和侨乡结构；贺州位于桂粤湘交界，来宾则从兴宾主城与红水河向合山矿业、忻城土司、象州温泉、武宣峡谷和金秀瑶山展开。本目录目前收录 9 篇完成资料核验的城市指南；城市、县域与独立县级市各有不同的交通和住宿边界，不能由任一城市页相互替代。

## 区域格局与城市组合

桂林位于广西东北部，常见旅行线路会把桂林中心城区、漓江游船、阳朔与龙胜龙脊梯田连写在一起，但它们不是一个可连续步行的目的地。桂林市页以秀峰、象山、叠彩、七星等中心城区为起点，将漓江写成通往阳朔的旅行走廊，将阳朔与龙胜写成需要独立半天以上、通常更适合整日或住宿的目的地。阳朔县、阳朔镇、兴坪镇、龙胜各族自治县及其聚落具有各自的交通与住宿条件，应按具体目的地单独规划。

南宁位于广西中南部，中心城区可分为朝阳—三街两巷—邕江老城轴、民族广场—南湖—会展中心的东西向城市轴、青秀山—青环路场馆片区和五象新区。园博园在东南外缘，武鸣、伊岭岩与大明山在北部远郊，不能按中心城区景点密度压缩。德天瀑布位于崇左市大新县，崇左也不是南宁市辖区；它们即使以南宁为交通集散地，也不计入南宁城市景点。

柳州中心城区由柳江两岸、老城、河东工业片区和南部喀斯特公园组成。柳州博物馆—柳侯公园适合连续步行，工业博物馆需过江，龙潭、白莲洞与柳东则需要分别乘车。柳城、鹿寨、融安、融水和三江属于柳州市域，但每个县的景区、社区和交通都应按独立一日或住宿行程处理。

钦州主城区可从钦北的铁路门户与冯子材故居向南串联刘永福故居、老街和坭兴陶文化片区；三娘湾、茅尾海和钦州港则需要公路接驳。港城公共空间与生产港区必须分开，码头、堆场、海关监管区、石化园区和航道不因地图可见而开放参观。三娘湾、八寨沟、灵山和浦北分属不同方向，海况、台风、山洪与返程交通都应逐日核对。

贵港主城由郁江分隔港北与港南，覃塘的荷田、港北西郊的园博园和平天山也不是一片连续步行区。桂平是代码独立的县级市，西山、龙潭、金田和大藤峡应从桂平另作路线；运行中的港口、水利航运设施、林区和农业生产田只能进入正式开放范围。玉林主城的玉州老城、玉东公共文化片区与福绵方向同样需要车辆转换，容县、陆川、博白、兴业分属不同县域日；北流是独立法定县级市，不因“玉北容”交通联系而归入玉林主城路线。

梧州中心城区由万秀、长洲和龙圩三个市辖区构成：万秀河东老城集中骑楼城—龙母庙、珠山与白云山，长洲承担梧州站、现代城市服务和摩天岭茶旅方向，龙圩则连接梧州南站、苍海与李济深故里。浔江与桂江在城区汇合后称西江，江河既塑造商埠景观，也带来真实的防洪与航运边界。苍梧县六堡镇、藤县石表山和蒙山县城文化线都需要独立一日或住宿；岑溪行政区划代码为 `450481`，是梧州市代管的法定县级市，应作为独立城市规划。六堡茶展馆、明示开放的体验区和观景步道可以游览，生产茶园、加工车间与仓库不可默认进入；港区码头、锚地、船闸和水利设施同样首先是生产空间。汛期和台风风雨会同时影响江岸、桥梁、山区与县域交通；公开资料也不足以证明骑楼、庙宇、公园和山地之间存在连续无障碍路线，设施条件需逐段向运营方确认。

贺州的八步与平桂构成主城和铁路集散框架，姑婆山、玉石林、十八水等北部山地景区各有独立入口；临贺故城位于八步区贺街镇，黄姚古镇位于昭平县，钟山与富川也各是独立县域方向。黄姚内部街巷、古榕、桥井与建筑按一个完整古镇景区去重；姑婆山度假区、森林公园和各运营景区名称相近却不等于边界相同。村落、果园、茶园、矿区和自然保护地只有明确开放的公众范围可以进入。

来宾以兴宾区为中心城区与铁路门户，合山市是法定县级市，忻城、象州、武宣是普通县，金秀是瑶族自治县；县市之间需要独立公路接驳或住宿，不能从来宾北站连续步行串联。桂中水城各公园、水道和夜游项目按一个城市水景单元去重，合山国家矿山公园内部展馆与安全改造游线也不拆分；金秀“大瑶山盘王界”与旧称“莲花山”指同一景区。红水河闸坝、航道、港区和泄洪水域、非开放矿井、自然保护地及瑶族生活社区均有各自准入边界，不因旅游主题或地图可见而自由进入。

柳州、北海、梧州、崇左等地与桂林、南宁的城市体验和气候风险不同，不能套用同一种游览节奏。跨市组合应先按铁路或公路枢纽确定顺序，再核对山区道路、汛期风险和实际班次。
