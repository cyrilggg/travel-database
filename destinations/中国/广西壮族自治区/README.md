# 广西壮族自治区旅行目的地

广西从北部的南岭与喀斯特峰林延伸到南部沿海，城市之间距离较大，山地、公路与水上交通都会影响实际游览节奏。桂平以西山、浔州古城、龙潭森林和北回归线乡村为独立旅行尺度；阳朔以遇龙河、十里画廊、兴坪和漓江形成县域旅行结构。目前可查阅 20 篇城市或县域指南。

## 区域格局与城市组合

桂林位于广西东北部，常见旅行线路会把桂林中心城区、漓江游船、阳朔与龙胜龙脊梯田连写在一起，但它们不是一个可连续步行的目的地。桂林市页以秀峰、象山、叠彩、七星等中心城区为起点，将漓江写成通往阳朔的旅行走廊，将阳朔与龙胜写成需要独立半天以上、通常更适合整日或住宿的目的地。阳朔县、阳朔镇、兴坪镇、龙胜各族自治县及其聚落具有各自的交通与住宿条件，应按具体目的地单独规划。

南宁位于广西中南部，中心城区可分为朝阳—三街两巷—邕江老城轴、民族广场—南湖—会展中心的东西向城市轴、青秀山—青环路场馆片区和五象新区。园博园在东南外缘，武鸣、伊岭岩与大明山在北部远郊，不能按中心城区景点密度压缩。德天瀑布位于崇左市大新县，崇左也不是南宁市辖区；它们即使以南宁为交通集散地，也不计入南宁城市景点。

柳州中心城区由柳江两岸、老城、河东工业片区和南部喀斯特公园组成。柳州博物馆—柳侯公园适合连续步行，工业博物馆需过江，龙潭、白莲洞与柳东则需要分别乘车。柳城、鹿寨、融安、融水和三江属于柳州市域，但每个县的景区、社区和交通都应按独立一日或住宿行程处理。

钦州主城区可从钦北的铁路门户与冯子材故居向南串联刘永福故居、老街和坭兴陶文化片区；三娘湾、茅尾海和钦州港则需要公路接驳。港城公共空间与生产港区必须分开，码头、堆场、海关监管区、石化园区和航道不因地图可见而开放参观。三娘湾、八寨沟、灵山和浦北分属不同方向，海况、台风、山洪与返程交通都应逐日核对。

北海的海城区北岸与银海区南岸组成大陆主游览轴，老城、北海站、侨港、国际客运港、银滩和金海湾红树林之间需要公交或车辆分段；北海老城内部街巷、陈列馆和单体近代建筑按一套历史城区体系理解。[合浦](./合浦县.md)拥有自己的县城、车站、汉墓群保护范围、海丝首港和湿地路线，适合独立一至三日；铁山港区以临港工业和生产港口为主，码头、堆场、厂区、专用线和航道按作业边界管理。涠洲镇虽属海城区，却是需要往返船票和住宿余量的独立远海单元，南湾鳄鱼山及各海岸、教堂和村落属于同一岛内景点体系。台风、海上大风、海雾、雷电与大浪可能导致停航；港区、养殖区、珊瑚礁、红树林和自然保护地按明确开放范围进入。

防城港以港口区、防城区为城市与海岸旅行主体：防城港北站—市博物馆—西湾组成城市轴，防城老城—江山半岛和企沙镇—簕山古渔村分属两个需车辆接驳的滨海方向。上思县适合作为单独的森林日；前往[东兴](./东兴市.md)后按独立指南选择口岸、竹山或京族三岛方向。生产码头、航道、养殖区和自然保护区核心区继续按安全与保护边界管理。

贵港主城由郁江分隔港北与港南，覃塘的荷田、港北西郊的园博园和平天山也不是一片连续步行区。桂平是代码独立的县级市，具体游览、住宿和交通须另查属地信息；运行中的港口、水利航运设施、林区和农业生产田只能进入正式开放范围。玉林主城的玉州老城、玉东公共文化片区与福绵方向同样需要车辆转换，容县、陆川、博白、兴业分属不同县域日；[北流](./北流市.md)是独立法定县级市，不因“玉北容”交通联系而归入玉林主城路线。玉林北站虽位于北流新圩镇，却是服务玉林全域的区域铁路门户；北流城区、勾漏洞、铜石岭和大容山应按北流行程安排。大容山旅游景区的主要游客服务在北流民乐方向，但更大的山系和生态空间跨邻接县区，景区门票不代表整片山林开放。

梧州中心城区由万秀、长洲和龙圩三个市辖区构成：万秀河东老城集中骑楼城—龙母庙、珠山与白云山，长洲承担梧州站、现代城市服务和摩天岭茶旅方向，龙圩则连接梧州南站、苍海与李济深故里。浔江与桂江在城区汇合后称西江，江河既塑造商埠景观，也带来真实的防洪与航运边界。苍梧县六堡镇、藤县石表山和蒙山县城文化线都需要独立一日或住宿；岑溪行政区划代码为 `450481`，是梧州市代管的法定县级市，应作为独立城市规划。六堡茶展馆、明示开放的体验区和观景步道可以游览，生产茶园、加工车间与仓库不可默认进入；港区码头、锚地、船闸和水利设施同样首先是生产空间。汛期和台风风雨会同时影响江岸、桥梁、山区与县域交通；公开资料也不足以证明骑楼、庙宇、公园和山地之间存在连续无障碍路线，设施条件需逐段向运营方确认。

贺州的八步与平桂构成主城和铁路集散框架，姑婆山、玉石林、十八水等北部山地景区各有独立入口；临贺故城位于八步区贺街镇，黄姚古镇位于昭平县，钟山与富川也各是独立县域方向。黄姚内部街巷、古榕、桥井与建筑共同组成一处完整古镇景区；姑婆山度假区、森林公园和各运营景区名称相近却不等于边界相同。村落、果园、茶园、矿区和自然保护地只有明确开放的公众范围可以进入。

来宾以兴宾区为中心城区与铁路门户，合山市是法定县级市，具体游览须另查属地信息；忻城、象州、武宣是普通县，金秀是瑶族自治县。县市之间需要独立公路接驳或住宿，不能从来宾北站连续步行串联。桂中水城各公园、水道和夜游项目共同组成一套城市水景游线；金秀“大瑶山盘王界”与旧称“莲花山”指同一景区。红水河闸坝、航道、港区和泄洪水域、非开放矿井、自然保护地及瑶族生活社区均有各自准入边界，不因旅游主题或地图可见而自由进入。

百色以右江区主城和百色站为首访起点，百色起义纪念园内部场馆、碑园与旧址共同组成一处主题景区。田阳虽为市辖区，仍不能从右江主城连续步行到达；田东是普通县，平果和靖西是法定县级市。田阳—田东—平果沿右江河谷向东展开，德保—靖西—那坡通往南部喀斯特山地与中越边境，凌云—乐业构成湖泊、天坑与世界地质公园方向，田林—西林—隆林则需要更长的西部县域行程。乐业—凤山世界地质公园还跨入河池市凤山县，不能因共用地质公园名称而忽略行政边界；峡谷、洞穴、天坑、湖岸、口岸、矿区和民族社区均只能进入正式开放或明确接待范围。

崇左以江州区主城和崇左南站为城市入口，大新、宁明、龙州、扶绥与天等是各有县城、交通和住宿边界的普通县，凭祥则是法定县级市。德天跨国瀑布和明仕景区均在大新县，但属于不同运营单元；宁明花山是左江花山岩画文化景观的关键游览点，世界遗产整体还包括宁明、龙州、江州和扶绥范围内的其他组成部分。龙州起义纪念园宜作为独立县域历史日。甘蔗田、糖厂、林场、口岸货检与仓储区、自然保护地和遗产缓冲区不能因地图可见或邻近旅游道路而默认开放。

河池由金城江传统主城与宜州政府驻地共同构成双核心。宜州在 2016 年撤市设区后成为河池市辖区，不是独立县级市，但从金城江前往仍需按县域尺度安排交通和住宿。环江、罗城、南丹、天峨、凤山、东兰、巴马、都安和大化各有独立县城与山地远线，不能压进双城区日程；环江世界遗产组成部分与木论自然保护区、凤山地质公园的开放景区与更大保护范围、南丹和金城江矿区、宜州桑蚕生产空间也分别有准入边界。

柳州、北海、梧州、崇左等地与桂林、南宁的城市体验和气候风险不同，不能套用同一种游览节奏。跨市组合应先按铁路或公路枢纽确定顺序，再核对山区道路、汛期风险和实际班次。
