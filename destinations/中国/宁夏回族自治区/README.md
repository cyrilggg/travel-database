# 宁夏回族自治区旅行目的地

宁夏位于黄河上游，贺兰山、宁夏平原、黄土高原、六盘山和腾格里沙漠边缘共同塑造了各地不同的旅行主题。这里收录银川、石嘴山、吴忠、固原与中卫 5 座城市的完整指南：银川连接自治区级文博、历史城区与贺兰山东麓遗址；石嘴山把大武口、惠农、平罗和沙湖按实际距离拆分，并兼顾工业遗产与湿地生态；吴忠以利通主城衔接红寺堡、盐池和同心；固原以原州主城为基地，分日进入须弥山、西吉、隆德、泾源和彭阳；中卫则以沙坡头主城为基地，分别安排黄河—沙漠景区以及中宁、海原两个县域方向。

## 区域格局与城市组合

银川市包括兴庆、金凤、西夏三个市辖区，以及永宁、贺兰两县和代管的灵武市。兴庆老城、金凤新城与西夏城市区形成连续建成区；贺兰县方向需要另算往返。灵武是法定县级市，其旅行内容不纳入银川主城路线，联程时应另查属地交通、住宿与开放信息。银川西侧和西北方向的景区之间距离明显，不能按同一片步行景区处理。

石嘴山市由大武口区、惠农区和平罗县组成。大武口是行政、住宿和主要公共交通基地，市区文博、星海湖与近郊工业遗产可按开放情况组合；石炭井虽属大武口区，但位于贺兰山腹地，不能按普通市区景点计算接驳时间。惠农在市域北部，黄河沿岸、工业记忆和煤炭地质主题需要单独往返；平罗位于南部，县城与黄渠桥可同向安排，沙湖也在平罗县境内，但作为面积较大的独立景区，通常占用半天以上。沙湖不属于银川市，银川出发只是常见交通方式，不改变其行政归属和返程距离。

石嘴山的工业景观与生态空间都有明确边界。列入工业遗产名录的厂区、矿区或铁路设施，不等于整片生产区域向公众开放；在产矿井、工厂、料场、专用铁路及其轨道不得自行进入，废弃矿洞、采空区和边坡也不应探访。水利工程只能在批准的参观区域和道路停留，不接近闸口、泵站、渠首等作业设施。沙湖、星海湖及黄河沿岸湿地应遵守保护区、鸟类繁殖期、防火和水域管理要求，不跨越围栏、堤埂或临时封闭线。

吴忠市包括利通区、红寺堡区、青铜峡市、盐池县和同心县。利通主城承担主要城市服务；红寺堡、盐池和同心分别位于南部或东部，县城与景点跨度大，应各自成日或过夜。青铜峡是法定县级市，其景点、住宿与交通应按独立跨城行程查询，不纳入利通主城路线。

中卫市以沙坡头区主城为交通与服务基地，沙坡头旅游区位于城西并把黄河、沙丘、铁路治沙和户外项目纳入同一大型运营单元，内部节点宜连贯游览。中宁县沿黄河向东，以枸杞文化和石窟遗存为主；海原县在南部山地，地震记忆和南华山方向需另行往返或过夜。腾格里沙漠跨越省区，地图上的沙地、生产道路和非正规营地不因行政或自然名称相连而成为开放游线。

固原市由原州区和西吉、隆德、泾源、彭阳四县组成。原州主城承担交通、住宿和文博服务，须弥山位于原州区西北方向，但仍需独立大半天；西吉、隆德、泾源和彭阳都应按县域分日。六盘山国家森林公园、六盘山红军长征景区和六盘山国家级自然保护区不是同一门票或同一游线；须弥山博物馆与各洞窟则属于须弥山旅游区内部节点，宜在同一次游览中安排。

银川河东国际机场虽可作为吴忠或中卫的进出门户，但机场位于银川市域；跨市铁路或公路组合不改变景点归属，也不能用“从银川出发”代替住宿、最后一段接驳和返程判断。固原六盘山机场位于固原市域，但支线航班和地面接驳具有时效性；进入四县和山地景区仍需重新核对最后一段交通。
