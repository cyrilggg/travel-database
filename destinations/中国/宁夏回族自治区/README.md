# 宁夏回族自治区旅行目的地

宁夏位于黄河上游，贺兰山、宁夏平原、黄土高原和腾格里沙漠边缘共同塑造了各地不同的旅行主题。当前完整城市指南从银川开始，重点说明三城区、贺兰山东麓遗址、黄河湿地和灵武远郊之间的空间关系。

## 区域格局与城市组合

银川市包括兴庆、金凤、西夏三个市辖区，以及永宁、贺兰两县和代管的灵武市。兴庆老城、金凤新城与西夏城市区形成连续建成区；贺兰县的贺兰山岩画和灵武市的水洞沟虽在银川市域内，往返与内部游览仍各需大半天至一整天。西夏陵、镇北堡和岩画都位于城市西侧或西北方向，但景区之间距离明显，不能按同一片步行景区处理。

宁夏其余主要目的地需要按地级市边界单独规划。沙湖位于石嘴山市平罗县；青铜峡黄河大峡谷和一百零八塔位于吴忠市青铜峡市；沙坡头属于中卫市；六盘山区域主要在固原市。它们可以与银川通过铁路或公路组合，但不计入银川城市景点完成率，也不以“从银川出发”代替跨市住宿和返程判断。
