# 宁夏回族自治区旅行目的地

宁夏位于黄河上游，贺兰山、宁夏平原、黄土高原和腾格里沙漠边缘共同塑造了各地不同的旅行主题。当前完整城市指南包括银川与吴忠：银川页说明三城区、贺兰山东麓遗址、黄河湿地和灵武远郊之间的空间关系；吴忠页区分利通—青铜峡黄河主线与红寺堡、盐池、同心三个县域方向。

## 区域格局与城市组合

银川市包括兴庆、金凤、西夏三个市辖区，以及永宁、贺兰两县和代管的灵武市。兴庆老城、金凤新城与西夏城市区形成连续建成区；贺兰县的贺兰山岩画和灵武市的水洞沟虽在银川市域内，往返与内部游览仍各需大半天至一整天。西夏陵、镇北堡和岩画都位于城市西侧或西北方向，但景区之间距离明显，不能按同一片步行景区处理。

吴忠市包括利通区、红寺堡区、青铜峡市、盐池县和同心县。利通主城与青铜峡位于北部黄河灌溉区，可以组成两日核心路线；红寺堡、盐池和同心分别位于南部或东部，县城与景点跨度大，应各自成日或过夜。青铜峡黄河大峡谷内的一百零八塔、水利枢纽、峡谷和相关展陈作为同一个景区项目记录，不重复计算。

其余主要目的地仍需按地级市边界单独规划。沙湖位于石嘴山市平罗县；沙坡头、高庙属于中卫市；六盘山、须弥山石窟和固原博物馆应纳入固原市行程。银川河东国际机场虽可作为吴忠的进出门户，但机场位于银川市域；跨市铁路或公路组合不改变景点归属，也不能用“从银川出发”代替住宿、最后一段接驳和返程判断。
