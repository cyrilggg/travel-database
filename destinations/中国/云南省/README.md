# 云南省旅行目的地

云南位于中国西南部，地形从滇中高原延伸到滇西高山峡谷和滇东北乌蒙山区，气候、海拔与交通条件在省内差异很大。当前目录收录昆明、曲靖、保山、昭通、蒙自、楚雄六座已经完成研究的城市：昆明适合从省会公共交通和高原湖泊入门，曲靖以滇东喀斯特、珠江源和县域山地为主，保山连接古永昌、火山地热、滇西抗战、高黎贡山及咖啡茶产区，昭通以昭阳主城为基点延伸到高原湿地、五尺道、峡谷与金沙江库区，蒙自围绕南湖、近代开埠、滇越铁路、过桥米线和石榴产区展开，楚雄则连接州府文博、鹿城公共空间、彝族文化展示和紫溪山森林。行政上同属一市或一州不代表可以压缩成一条城市步行线，县级市、普通县、保护区和生产园区也各有独立边界。

## 区域格局与城市组合

### 昆明

昆明主城区位于滇中高原。翠湖—云南大学—昆明老街属于老城连续游览范围；滇池北岸与西山位于城市西南部，需要公共交通和景区接驳；云南省博物馆—官渡古镇位于东南片区；斗南在更南侧的呈贡区；石林风景区位于石林彝族自治县，已是完整的一日远郊行程。机场、昆明站和昆明南站也分处不同方向，订票时必须核对具体枢纽。

### 曲靖

曲靖以麒麟主城作为住宿和换乘中心，沾益珠江源、陆良彩色沙林、罗平峰林与瀑布、师宗山地、富源峡谷和会泽古城分别需要独立一日或住宿。宣威是曲靖代管的法定县级市，仍须建立独立城市记录；罗平花田具有明显季节性，山区公路、海拔和强对流天气会改变行程，不能沿用固定花期或旧班次。

### 保山

保山市以隆阳区主城承担市级场馆、住宿、保山站和云瑞机场等主要公共服务。青华海与主城联系紧密，板桥、潞江坝和高黎贡山东坡则需要分别接驳。腾冲市是保山代管的法定县级市，拥有独立城区、驼峰机场和完整的火山地热、和顺侨乡及抗战旅行体系；保山页提供市域组合信息，但不能替代腾冲独立法定城市记录。施甸县、龙陵县和昌宁县均为普通县，分别适合善洲林场、松山抗战遗址和右甸河—茶文化方向，跨县游览通常需要整日或换宿。

保山市域与缅甸相连，但实际承担国境线的是腾冲和龙陵，隆阳、施甸与昌宁不能笼统写成边境县。进入边境乡镇仍须服从证件、检查、拍摄和无人机管理，常规景区开放也不等于可以接近界线或跨境。高黎贡山国家级自然保护区和北海湿地保护区只允许在当期批准范围活动，不能把社区观鸟点、景区栈道或保护区外围当成自由穿越许可。潞江坝咖啡、昌宁红茶、龙陵石斛等种植与加工区域首先是生产空间，只有明确开放接待的园区、庄园或门店才能进入。

火山景区与热海景区位于腾冲不同乡镇，是两个需要分别抵达的游览单元；同一景区内部的火山口、泉眼和展示节点不重复计算。滇西抗战纪念馆与国殇墓园按一个景区安排，龙陵松山则是另一处大尺度原址战场。温泉经营项目不等于公共地热资源，天然泉眼、生产井、加工车间和尾水处理区均不属于自由取水或探访空间。

### 昭通

昭通以昭阳区主城作为市级场馆、古城街区和主要住宿基地。大山包位于昭阳区西部高原，但海拔、天气和道路条件已与主城明显不同，宜作为独立整日；豆沙关、黄连河、小草坝、扎西会议旧址等分属盐津、大关、彝良、威信等县，彼此不是同一条近郊环线。水富是昭通代管的法定县级市，拥有独立城区与金沙江沿线旅行结构，仍须建立独立城市记录，不能因在昭通页中出现便视作已经完成。

大山包黑颈鹤国家级自然保护区、金沙江库区和乌蒙山峡谷都存在明确的生态、水域与天气边界。观鸟只在当期开放区域进行，不进入保护核心空间，不以投喂、追逐或无人机干扰野生动物；库岸、码头、工程道路和水电设施周边不等同于公共观景区。昭通县域公路受高差、雾、降雪和雨季崩塌、滑坡、泥石流影响，强降雨结束后仍应继续核对道路与景区公告；大山包等高海拔地点也不能仅凭主城天气判断衣物和体力需求。

### 蒙自

蒙自市是红河哈尼族彝族自治州州府所在地的法定县级市。南湖与文澜老城集中西南联大蒙自分校纪念馆、蒙自海关旧址和老城餐饮，天马路—州行政中心一带集中了红河州博物馆等州级公共设施；州级场馆位于蒙自，只说明馆址和服务层级，不能把展陈涉及的建水、元阳、河口、个旧、开远、弥勒等州内县市视为蒙自景点。上述目的地均有独立行政、交通和住宿结构，应分别换城或另作县域行程。

碧色寨位于主城北侧，是以滇越铁路和个碧石铁路遗产为核心的独立近郊单元。碧色寨村已由草坝镇整建制划归观澜街道，不能继续按旧资料笼统写作草坝景点；草坝镇仍是稻作、蓝莓、设施蔬菜等现代农业片区，只有明确开放接待的田园项目、研学点或经营基地才能进入。铁路线路、桥隧、机车库后场、长桥海湿地、果园、大棚、分选加工、冷库和物流区也各有安全、生态与生产边界，不因出现在旅游路线附近而自动开放。

红河站、蒙自站和仍待正式通航公告确认的红河蒙自机场属于不同交通节点。红河站位于城北，机场建设状态不等于已有可售民航航班；任何具体车次、公交、旅游专线、航线和末班接驳都应在出发前重新核对。

### 楚雄

楚雄市是楚雄彝族自治州州府所在地的法定县级市。鹿城主城集中楚雄州博物馆、文庙与日常餐饮，彝人古镇—十月太阳历片区偏向当代商业文化、住宿和活动，彝海公园位于东南新城，紫溪山则是距主城约 20 公里、通常需要独立一日的山地单元。州博物馆展示禄丰恐龙、元谋人、万家坝铜鼓及全州民族文化，并不把文物原址或相关县市并入楚雄市。

禄丰世界恐龙谷、禄丰恐龙博物馆和黑井古镇位于禄丰市，元谋土林与元谋人博物馆位于元谋县，武定狮子山、姚安光禄古镇、大姚石羊古镇也分别属于对应县域；南华、牟定、双柏、永仁等同样不属于楚雄市近郊景点。即使从楚雄站或客运场站可以换乘，往返车程、开放、住宿和天气仍要按独立目的地计算。

紫溪山旅游景区与紫溪山省级自然保护区不是同一开放边界。游客只使用景区、林草部门和保护区当期批准的道路与游线，不进入封闭林地、水源地、科研监测区或森林防火封控区；紫溪彝村等社区首先是居民生活与生产空间，公开体验、演出和彝绣活动须以接待主体公告为准。雨季暴雨、雷电、山洪与地质灾害，以及旱季森林火险和禁火命令，都可能使紫溪山整段取消。

### 省内其他目的地

大理白族自治州和丽江市是云南省内独立的州（市），不属于昆明景点或昆明远郊。铁路和航空可以连接这些目的地，但车站接驳、住宿搬迁、海拔变化和各地停留天数仍需分别计算。西双版纳、香格里拉、普洱等地同样应建立独立城市或地区页；腾冲虽已在保山页中说明行政关系和换城条件，仍须按法定县级市建立独立记录，不能用地级保山页视作已经完成。

## 来源与维护

区域关系依据民政部、云南省以及昆明、曲靖、保山、昭通、蒙自、楚雄各级政府，文旅、交通、自然资源、林草、移民管理部门和场馆运营方公开资料整理。昆明资料核验于 2026-07-30，曲靖、保山、昭通、蒙自与楚雄资料核验于 2026-07-31。昆明城市点采用 GeoNames `1804651`、Wikidata `Q182852`；曲靖采用 GeoNames `1797318`、Wikidata `Q496405`；保山采用 GeoNames `1281673`、Wikidata `Q496576` 和法定地级代码 `530500`；昭通采用 GeoNames `1784841`、Wikidata `Q197519` 和法定地级代码 `530600`；蒙自采用 GeoNames `13512502`、Wikidata `Q1201056` 和法定县级代码 `532503`；楚雄采用 GeoNames `1814760`、Wikidata `Q1090087` 和法定县级代码 `532301`。

Wikidata 实体 `Q1201056` 的 GeoNames 标识（`P1566`）在核验时仍指向旧记录 `1800663`。该记录名为 `Wenlan`，对应旧文澜驻地点，适合保留历史坐标关联；当前蒙自城市点采用名称、人口和行政链相符的 `13512502`。两条记录用途不同，不将旧驻地点重复视作另一座城市。

保山页按地级行政范围说明隆阳主城、腾冲县级市和三个普通县的旅行关系。腾冲法定县级代码为 `530581`，拥有独立城区、机场、住宿和完整的火山地热旅行体系，应作为单独一站规划；宣威及省内其他法定城市同理。上表只列出已有完整旅行指南的城市，其他目的地即使在地级市路线中有所提及，仍应分别核对交通、住宿、开放状态和合理停留时间。

蒙自页只覆盖县级蒙自市，不以州府身份替代红河州其他县市；楚雄页只覆盖县级楚雄市，不以州博物馆馆藏或州府交通替代楚雄州其他县市。两座城市的州级场馆提供区域背景，实地行程仍按文物原址、景区所在地和现行行政边界分别安排。

城市页保存长期稳定的空间关系、游览边界和路线取舍。门票、开放时间、预约、铁路与公路班次、道路施工、边境规则、保护区和生产园区开放、森林火险、极端天气、野生菌风险及具体经营场所状态均需在出发前重新核对。
