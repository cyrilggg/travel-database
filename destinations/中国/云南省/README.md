# 云南省旅行目的地

云南位于中国西南部，地形从滇中高原延伸到滇西北高山峡谷和滇南河谷，气候、海拔与交通条件在省内差异很大。省会昆明是航空、铁路和公路枢纽，也是一座需要单独停留的城市；滇池、老城、博物馆、花卉市场和石林分别对应不同片区。曲靖位于滇东高原，麒麟主城、沾益珠江源、陆良、罗平、师宗、富源与会泽同样分属不同旅行方向。行政上同属一市不代表可以压缩成一条城市步行线。

## 区域格局与城市组合

昆明主城区位于滇中高原。翠湖—云南大学—昆明老街属于老城连续游览范围；滇池北岸与西山位于城市西南部，需要公共交通和景区接驳；云南省博物馆—官渡古镇位于东南片区；斗南在更南侧的呈贡区；石林风景区位于石林彝族自治县，已是完整的一日远郊行程。机场、昆明站和昆明南站也分处不同方向，订票时必须核对具体枢纽。

曲靖以麒麟主城作为住宿和换乘中心，沾益珠江源、陆良彩色沙林、罗平峰林与瀑布、师宗山地、富源峡谷和会泽古城分别需要独立一日或住宿。宣威是曲靖代管的法定县级市，仍须建立独立城市记录；罗平花田具有明显季节性，山区公路、海拔和强对流天气会改变行程，不能沿用固定花期或旧班次。

大理白族自治州和丽江市是云南省内与昆明并列的独立州（市），不属于昆明景点或昆明远郊。铁路和航空可以连接这些目的地，但车站接驳、住宿搬迁、海拔变化和各地停留天数仍需分别计算。西双版纳、香格里拉、腾冲、普洱等地同样应建立独立城市或地区页，不能用昆明页面代替。
