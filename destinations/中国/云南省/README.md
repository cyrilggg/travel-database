# 云南省旅行目的地

云南位于中国西南部，地形从滇中高原延伸到滇西高山峡谷、滇东北乌蒙山区、滇东南喀斯特丘陵和滇西南热带山地，气候、海拔与交通条件在省内差异很大。当前可直接查阅昆明、大理、曲靖、保山、昭通、蒙自、楚雄、文山、临沧、普洱十座城市：昆明适合从省会公共交通和高原湖泊入门，大理需要在下关、古城、苍山、洱海西岸、喜洲与双廊之间分片取舍，曲靖以滇东喀斯特、珠江源和县域山地为主，保山连接古永昌、青华海、潞江坝、高黎贡山东坡及咖啡茶产区，昭通以昭阳主城为基点延伸到高原湿地、五尺道、峡谷与金沙江库区，蒙自围绕南湖、近代开埠、滇越铁路、过桥米线和石榴产区展开，楚雄连接州府文博、鹿城公共空间、彝族文化展示和紫溪山森林，文山以州府文博、铜鼓、三七产业、盘龙河和喀斯特山地见长，临沧从临翔主城延伸到凤庆滇红、双江古茶山及沧源—耿马边境县域，普洱则以思茅主城为基点连接宁洱、墨江、景迈山和西盟—孟连长线。行政上同属一市或一州不代表可以压缩成一条城市步行线，县级市、普通县、边境县、保护区和生产园区也各有独立边界。

## 区域格局与城市组合

### 昆明

昆明主城区位于滇中高原。翠湖—云南大学—昆明老街属于老城连续游览范围；滇池北岸与西山位于城市西南部，需要公共交通和景区接驳；云南省博物馆—官渡古镇位于东南片区；斗南在更南侧的呈贡区；石林风景区位于石林彝族自治县，已是完整的一日远郊行程。机场、昆明站和昆明南站也分处不同方向，订票时必须核对具体枢纽。

### 大理

大理市是大理白族自治州州府所在地的法定县级市。下关—太和—满江承担大理站、机场接驳、州级公共文化与主要城市服务，大理古城—崇圣寺三塔位于更北的苍山东麓，龙龛、才村、磻溪、古生等连接洱海西岸生态廊道，喜洲—周城位于西北岸，双廊—挖色—海东则构成东北岸和东岸长线。上述片区不能按同一城市步行圈安排；苍山洗马潭、感通和中和入口也需分别核对票务、开放段与出口。

洱海湖区、湖滨生态红线、湿地与生态廊道受专门保护制度约束，进入公开慢行空间不等于可以下水、垂钓、露营或驶入全部车辆。喜洲、周城和双廊同时是居民生活与生产社区，古宅、扎染作坊、田地、湖岸民宿和餐饮后场只在明确开放时进入。巍山、剑川、宾川、祥云、洱源、鹤庆和漾濞等州内县市不属于大理市；巍山古城、沙溪古镇、鸡足山和石门关均应按独立县域行程计算。

### 曲靖

曲靖以麒麟主城作为住宿和换乘中心，沾益珠江源、陆良彩色沙林、罗平峰林与瀑布、师宗山地、富源峡谷和会泽古城分别需要独立一日或住宿。宣威是曲靖代管的法定县级市，拥有独立城区、住宿与交通节奏，应按单独目的地安排；罗平花田具有明显季节性，山区公路、海拔和强对流天气会改变行程，不能沿用固定花期或旧班次。

### 保山

保山市以隆阳区主城承担市级场馆、住宿、保山站和云瑞机场等主要公共服务。青华海与主城联系紧密，板桥、潞江坝和高黎贡山东坡则需要分别接驳。腾冲市是保山代管的独立法定县级市，从保山主城前往应另算跨城交通、返程和是否换宿，腾冲旅行内容不纳入保山主城路线。施甸县、龙陵县和昌宁县均为普通县，分别适合善洲林场、松山抗战遗址和右甸河—茶文化方向，跨县游览通常需要整日或换宿。

保山市域与缅甸相连，但实际承担国境线的是腾冲和龙陵，隆阳、施甸与昌宁不能笼统写成边境县。进入边境乡镇仍须服从证件、检查、拍摄和无人机管理，常规景区开放也不等于可以接近界线或跨境。市域自然保护地只允许在当期批准范围活动，不能把社区观鸟点、景区栈道或保护区外围当成自由穿越许可。潞江坝咖啡、昌宁红茶、龙陵石斛等种植与加工区域首先是生产空间，只有明确开放接待的园区、庄园或门店才能进入。

隆阳及普通县域的温泉、咖啡、茶和石斛接待项目与天然资源、农业生产、加工车间和仓储物流空间并非同一开放范围。只有经营主体明确开放并具备接待条件的区域可进入，天然泉眼、生产井、加工后场和尾水处理区均不属于自由取水或探访空间。

### 昭通

昭通以昭阳区主城作为市级场馆、古城街区和主要住宿基地。大山包位于昭阳区西部高原，但海拔、天气和道路条件已与主城明显不同，宜作为独立整日；豆沙关、黄连河、小草坝、扎西会议旧址等分属盐津、大关、彝良、威信等县，彼此不是同一条近郊环线。水富是昭通代管的法定县级市，拥有独立城区与金沙江沿线旅行结构，应按单独目的地计算住宿、交通与停留时间。

大山包黑颈鹤国家级自然保护区、金沙江库区和乌蒙山峡谷都存在明确的生态、水域与天气边界。观鸟只在当期开放区域进行，不进入保护核心空间，不以投喂、追逐或无人机干扰野生动物；库岸、码头、工程道路和水电设施周边不等同于公共观景区。昭通县域公路受高差、雾、降雪和雨季崩塌、滑坡、泥石流影响，强降雨结束后仍应继续核对道路与景区公告；大山包等高海拔地点也不能仅凭主城天气判断衣物和体力需求。

### 蒙自

蒙自市是红河哈尼族彝族自治州州府所在地的法定县级市。南湖与文澜老城集中西南联大蒙自分校纪念馆、蒙自海关旧址和老城餐饮，天马路—州行政中心一带集中了红河州博物馆等州级公共设施；州级场馆位于蒙自，只说明馆址和服务层级，不能把展陈涉及的建水、元阳、河口、个旧、开远、弥勒等州内县市视为蒙自景点。上述目的地均有独立行政、交通和住宿结构，应分别换城或另作县域行程。

碧色寨位于主城北侧，是以滇越铁路和个碧石铁路遗产为核心的独立近郊单元。碧色寨村已由草坝镇整建制划归观澜街道，不能继续按旧资料笼统写作草坝景点；草坝镇仍是稻作、蓝莓、设施蔬菜等现代农业片区，只有明确开放接待的田园项目、研学点或经营基地才能进入。铁路线路、桥隧、机车库后场、长桥海湿地、果园、大棚、分选加工、冷库和物流区也各有安全、生态与生产边界，不因出现在旅游路线附近而自动开放。

红河站、蒙自站和仍待正式通航公告确认的红河蒙自机场属于不同交通节点。红河站位于城北，机场建设状态不等于已有可售民航航班；任何具体车次、公交、旅游专线、航线和末班接驳都应在出发前重新核对。

### 楚雄

楚雄市是楚雄彝族自治州州府所在地的法定县级市。鹿城主城集中楚雄州博物馆、文庙与日常餐饮，彝人古镇—十月太阳历片区偏向当代商业文化、住宿和活动，彝海公园位于东南新城，紫溪山则是距主城约 20 公里、通常需要独立一日的山地单元。州博物馆展示禄丰恐龙、元谋人、万家坝铜鼓及全州民族文化，并不把文物原址或相关县市并入楚雄市。

禄丰市是楚雄州管辖的独立法定县级市，不属于楚雄市近郊；从楚雄前往应另算跨城交通、返程和是否换宿。元谋、武定、姚安、大姚、南华、牟定、双柏、永仁等县也不属于楚雄市近郊景点；即使从楚雄站或客运场站可以换乘，往返车程、开放、住宿和天气仍要按独立目的地计算。

紫溪山旅游景区与紫溪山省级自然保护区不是同一开放边界。游客只使用景区、林草部门和保护区当期批准的道路与游线，不进入封闭林地、水源地、科研监测区或森林防火封控区；紫溪彝村等社区首先是居民生活与生产空间，公开体验、演出和彝绣活动须以接待主体公告为准。雨季暴雨、雷电、山洪与地质灾害，以及旱季森林火险和禁火命令，都可能使紫溪山整段取消。

### 文山

文山市是文山壮族苗族自治州州府所在地的法定县级市。开化老城—盘龙河集中了楚图南故居、居民餐饮和滨水公共空间，凤凰路—凤凰广场一带以文山州博物馆和州级公共服务为主，华龙湖适合短程休闲，西华山则是坡陡、台阶多且曾列入提质改造安排的山地单元，开放范围还受雷雨与森林防火影响。州博物馆展示全州铜鼓、历史和民族文化，只说明馆藏与解释范围，不把相关县域的文物原址并入文山市。

三七工业旅游园区分布在产业片区，生产、研发、仓储与游客参观通道各有边界，通常需要预约；平坝镇沙老寨、龙潭寨等村落同时承担居民生活、农业生产与旅游接待，只有接待主体、公共区域和返程明确时加入。普者黑位于丘北县，坝美位于广南县，两处都不是文山市远郊；旅行社使用自治州品牌统称时，仍应分别计算县域交通、住宿、票务和天气。

文山砚山机场位于砚山县，抵达文山市需要公路接驳。文蒙铁路仍在建设，规划中的文山站、马塘站和薄竹站不能当作已经运营的客运枢纽。文山市处在滇东南岩溶区与高原斜坡过渡地带，5–10 月强降雨、雷电、积涝、山洪与滑坡会同时影响城区山地和乡道；雨季开始前低海拔区域还可能出现高温，山地路线应按当日预警取舍。

### 临沧

临沧以临翔主城作为市级公共文化、住宿和铁路航空换乘中心。博尚碗窑、五老山和昔归已分别需要专门接驳；凤庆的滇红与鲁史、双江的冰岛、沧源的翁丁和司岗里崖画、耿马—孟定的边境县域更应按换宿长线安排。翁丁、鲁史、冰岛和孟定方向分散，不能压成从临翔出发的一日环线。

沧源、耿马和镇康承担主要国境线，临翔、凤庆、双江不能笼统写成边境县。茶山、咖啡和坚果园首先是生产空间，古茶树另有保护规则；佤族、拉祜族、布朗族、傣族等社区首先是居民生活空间。常规景区开放不等于可以进入居民住宅、私人茶园、保护地、口岸通道或界线附近，无人机、拍摄、村寨活动和跨境事项须分别按当期规定核对。

临沧站和临沧博尚机场服务临翔主城，沧源佤山机场服务另一县域；规划或建设中的临沧—普洱、临沧—清水河铁路不能当作已运营线路。全市海拔和垂直气候差异显著，雨季山路的雾、落石、滑坡、泥石流与夜间驾驶风险，以及干季森林防火封控，都可能使整条县域线路取消。

### 普洱

普洱以思茅主城作为市级公共文化、茶咖体验、住宿和交通基点。茶马古道旅游景区、中华普洱茶博览苑、太阳河方向已是不同近郊单元；宁洱、墨江、澜沧、西盟和孟连则各有独立县城、住宿与末段接驳。普洱站和普洱思茅机场服务主城，澜沧景迈机场服务澜沧县域，不能把三个交通节点混作同城换乘。

景迈山位于澜沧县，是由古茶林、传统村寨、防护林和社区生产共同构成的活态世界遗产，宜至少安排两个完整游览日并换宿；进入公开游线不代表古茶林、居民住宅和祭祀空间全部开放。太阳河游客景区也不等同于太阳河省级自然保护区，茶园、咖啡园、加工车间和仓储区域只有明确开放接待的部分可进入。

澜沧、西盟、孟连和江城属于边境县，常规县城或景区游览不包含接近界线、口岸通行或跨境许可。西盟—孟连等山地公路在雨季可能受暴雨、地质灾害、落石、抢险和交通管制影响；墨江等方向还应结合最新震情与次生灾害公告。长线以县城换宿、白天行车和返程缓冲为前提，不用夜间赶路换取更多县域。

### 省内其他目的地

丽江市是云南省内独立的地级市，不属于昆明或大理的景点与远郊。铁路和航空可以连接这些目的地，但车站接驳、住宿搬迁、海拔变化和各地停留天数仍需分别计算。西双版纳、香格里拉、腾冲等地也拥有各自的城区、住宿、交通与自然风险，应按单独目的地安排；其中腾冲是保山市代管的法定县级市，也不能作为保山主城当日近郊处理。

Wikidata 实体 `Q855228` 的 GeoNames 标识（`P1566`）截至核验时同时列出下关核心城区的城市点 `1814093` 与县级行政记录 `1814039`。前者对应本项目固定清单中的城市居民点，后者表达大理市法定行政范围，两条记录不重复计算为两座城市；下关与大理古城也只在同一篇大理指南中按不同游览片区组织。

Wikidata 实体 `Q1201056` 的 GeoNames 标识（`P1566`）在核验时仍指向旧记录 `1800663`。该记录名为 `Wenlan`，对应旧文澜驻地点，适合保留历史坐标关联；当前蒙自城市点采用名称、人口和行政链相符的 `13512502`。两条记录用途不同，不将旧驻地点重复视作另一座城市。

保山指南按地级行政关系区分隆阳主城、腾冲县级市和三个普通县。腾冲法定县级代码为 `530581`，应作为独立城市另算跨城交通、返程和是否换宿，其旅行内容不纳入保山主城路线；宣威及省内其他法定城市同理。其他目的地即使在广域路线中有所提及，仍应分别核对交通、开放状态和合理停留时间。

蒙自指南只讨论县级蒙自市，不以州府身份替代红河州其他县市；楚雄指南只讨论县级楚雄市，不以州博物馆馆藏或州府交通替代楚雄州其他县市；文山指南也不把丘北普者黑、广南坝美或砚山县机场并入文山市。州级场馆提供区域背景，实地行程仍按文物原址、景区所在地和现行行政边界分别安排。

法定文山市实体 `Q1201048` 的 GeoNames 标识（`P1566`）指向旧县级行政记录 `1791425`（`Wenshan Xian`，`A.ADM3`），而 GeoNames 2026-07-30 快照中的城市点采用 `8505006`（`Wenshan City`，`P.PPLA2`）；后者表示州府驻地性质，不代表文山市为法定地级市。居民点实体 `Q28795301` 虽指向 `8505006`，坐标却与旧行政记录相同、距城市点约 17.3 公里，因此只作交叉引用，不据此更改城市点位置。
