# 福建省旅行目的地

福建位于中国东南沿海，山地、河谷、港湾与岛屿把各城市分成差异明显的旅行单元。沿海高铁方便福州、莆田、泉州、厦门、漳州之间移动，但车站、历史城区、山区村落和海岛码头并不一定相邻；武夷山、闽西客家地区和各地土楼还需要按公路接驳、天气与景区开放情况单独安排。

## 区域格局与城市组合

福州的常规城市旅行核心位于鼓楼、台江和仓山，鼓山—鼓岭在晋安东部，马尾沿闽江继续向下游，长乐则延伸到闽江口、滨海新城和机场。三坊七巷、上下杭与烟台山可理解为一条古城至闽江的文化轴，但片区之间不必全程步行；马尾、长乐、福清和永泰均应按独立半天至一日方向安排。平潭县虽出现在部分福州市行政区划统计中，但平潭综合实验区以独立海岛目的地运营，本库不把平潭景点计入福州城市完成率。

厦门的常规旅行范围包括厦门岛、鼓浪屿，以及集美、海沧、同安、翔安等岛外行政区。鼓浪屿需乘厦鼓客运航线进入；集美与厦门北站位于岛外北侧；同安北部山地和翔安东部海湾距离岛内老城较远，不宜在同一天跨多个远郊片区。

泉州是独立的世界遗产城市，漳州、莆田、宁德、龙岩、三明、南平也各有自己的城市与区域结构。福建土楼分布在漳州、龙岩等地，不属于厦门或福州景点；即使旅行社从沿海城市发车，也应按跨城一日游或过夜行程核算。金门与厦门隔海相望，但涉及不同的出入境、证件与航运规则，不纳入厦门或福建省内城市景点完成率。
