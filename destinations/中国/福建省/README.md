# 福建省旅行目的地

福建位于中国东南沿海，山地、河谷、港湾与岛屿把各城市分成差异明显的旅行单元。沿海高铁方便福州、莆田、泉州、厦门、漳州、宁德之间移动，但车站、历史城区、山区村落和海岛码头并不一定相邻；龙岩把闽西客家文化、土楼、革命旧址、古城与山地景区组织成跨县路线，三明则沿沙溪河谷连接工业主城、沙县饮食文化、泰宁丹霞和多个山地县域。南平还需区分延平传统江城、建阳行政与文化核心、武夷新区交通节点、五个县域方向和三座独立县级市；宁德则从蕉城主城和三都澳延伸到霞浦潮汐海岸、屏南地质景观、古田湖区与北部高山廊桥，福安与福鼎两个县级市另作独立城市，其中福鼎还需把桐山主城、太姥山、白茶乡镇、沙埕湾和嵛山岛分日安排；漳州则要在芗城—龙文主城、龙海与长泰两区、南靖与华安土楼、东山与漳浦海岸之间作取舍。这些内陆或跨县远线都要按公路接驳、天气与景区开放情况分别安排。

## 区域格局与城市组合

福州的常规城市旅行核心位于鼓楼、台江和仓山，鼓山—鼓岭在晋安东部，马尾沿闽江继续向下游，长乐则延伸到闽江口、滨海新城和机场。三坊七巷、上下杭与烟台山可理解为一条古城至闽江的文化轴，但片区之间不必全程步行；马尾、长乐和永泰均需另算往返。福清是法定县级市，应另查属地交通、住宿与开放信息；平潭综合实验区也按独立海岛目的地安排，不与福州城区路线合并。

厦门的常规旅行范围包括厦门岛、鼓浪屿，以及集美、海沧、同安、翔安等岛外行政区。鼓浪屿需乘厦鼓客运航线进入；集美与厦门北站位于岛外北侧；同安北部山地和翔安东部海湾距离岛内老城较远，不宜在同一天跨多个远郊片区。

莆田的城厢—荔城主城、涵江、秀屿滨海、仙游县和两座主要海岛属于不同旅行尺度。兴化府、广化寺、绶溪与木兰陂需要车辆串联；湄洲岛使用文甲—宫下轮渡体系，南日岛使用石城—南日岛轮渡体系，两套码头和船票不可互换。仙游九鲤湖、湄洲岛和南日岛均应各占完整一天，台风、海上大风或强降雨时整段取消。

泉州的鲤城古城与丰泽连续建成区适合分片组合，清源山、洛阳桥、晋江口、泉港和环湾县市则需要交通接驳。世界遗产由 22 处组成遗产共同构成，系列遗产总名、景区内部建筑和跨界古桥两岸无需各自另排一站。晋江、石狮、[南安](./南安市.md)都是法定县级市，各自按独立城市安排；南安页承接九日山、五里桥南安侧、蔡氏古民居与石井文化，安溪、永春、德化等山区县也各有独立旅行单元。

晋江由青阳—梅岭主城、五店市传统街区、安海—东石、磁灶、深沪和金井等片区组成，晋江机场、晋江站与泉州南站服务的方向也不同。安平桥横跨晋江安海与南安水头，但仍是一处完整的世界遗产组成要素，两岸无需重复安排；草庵摩尼光佛造像、磁灶窑址和安平桥则是三个独立的世界遗产组成要素。泉州古城、石狮和南安不属于晋江城市游览范围，生产港区与产业厂区也不因地图可见而开放。

龙岩的连续主城区主要位于新罗，永定土楼、上杭古田、长汀古城、连城冠豸山和武平山地分处不同县域，漳平还是法定县级市。福建土楼是跨龙岩、漳州的系列遗产，永定各遗产组件、商业景区和单体楼应按实际游览关系组织；古田会议旧址群、长汀革命旧址群及冠豸山内部模块也分别作为完整目的地理解。梁野山自然保护地、矿山、林区和生产道路只有明确开放的公众范围可以进入。

三明的连续主城主要位于三元区，三明站、博物馆、沙溪河与三钢工业文化节点可组成城市路线；沙县虽已改设沙县区，沙县老城、三明北站和三明沙县机场仍与三元主城分处不同片区，需要专门接驳。泰宁位于西北山地，中国丹霞泰宁组成部分、世界地质公园、古城及内部船筏峡谷共同构成一处完整远线，遗产总名、景区名和内部节点无需分别安排；将乐、建宁、宁化等方向各占一日或需要过夜。永安是法定县级市，应按独立城市安排行程，不能视作三元主城的普通远郊。天然林、河道水库、洞穴峡谷、矿山冶炼、铁路货场和未开放林道均有明确管理边界，暴雨山洪、滑坡、雷电、森林火险与冬季山路状态会使县域路线整段失效。

南平采用延平与建阳双城结构：传统江城、市级博物馆和闽江城市生活集中在延平，市级行政中心、考亭书院、建盏文化与南平市站位于建阳及武夷新区，两地不构成连续步行区。顺昌、浦城、光泽、松溪、政和分别是独立县域方向；武夷山、邵武、建瓯则是法定县级市，应另查各市属地交通、住宿与开放信息。跨行政区的国家公园、世界遗产地、风景名胜区和茶园生产空间边界并不完全重合，只进入管理方公告开放的入口和游线。

宁德的连续主城位于蕉城与东侨，宁德站、宁德市博物馆、东湖和老城可组成城市底盘；霍童—支提山、三都澳、霞浦海岸、屏南—古田及周宁—寿宁—柘荣属于不同公路、铁路或船舶方向。宁德联合国教科文组织世界地质公园跨越屏南县与独立县级市[福安](./福安市.md)、[福鼎](./福鼎市.md)，三处分别按属地入口和交通安排；福安以韩阳主城、白云山和溪塔方向组织，福鼎以太姥山、白茶乡镇和嵛山岛组织。港区、养殖海域和潮间带按公开游览区、潮汐与生产边界选择路线；台风、海上大风和山地预警发布时改用城区方案。

漳州的连续城市游核心主要是芗城古城与龙文公共文化场馆，九龙江南岸和漳州站需另外接驳；漳州站实际位于龙海区，不能按站名推断已到古城。龙海、长泰虽已改设市辖区，石码—海澄月港、长泰武安—马洋溪仍是各自独立的公路方向；台商投资区、高新区、古雷开发区和招商局漳州开发区等功能区名称也不能替代四区七县的法定边界。南靖与华安的土楼分别是福建土楼系列世界遗产的组成部分，景区品牌、遗产总名和单体建筑需要按实际游线理解，不必各自另排一站。东山岛和漳浦火山海岸均应各占一日或过夜，台风、海上大风、离岸流、暴雨山洪和跨县道路中断会使海岸或土楼路线整段失效。

泉州是独立的世界遗产城市，莆田、宁德、龙岩、三明、南平也各有自己的城市与区域结构。福建土楼分布在漳州、龙岩等地，不属于厦门或福州景点；即使旅行社从沿海城市发车，也应按跨城一日游或过夜行程核算。厦门高崎机场常作为漳州的航空入口，但厦门仍是另一座城市，鼓浪屿、厦门岛和海沧不属于漳州市内景点。金门与厦门隔海相望，涉及不同的出入境、证件与航运规则，不能当作厦门或福建省内的普通城市景点。
