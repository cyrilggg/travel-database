# 肯尼亚旅行目的地

从内罗毕乘 Madaraka Express 可到蒙巴萨，把首都的博物馆与印度洋老城串成一程。往西走则先入裂谷，纳库鲁的湖泊国家公园和基苏木的维多利亚湖港是两个不同的落脚点。 [肯尼亚铁路](https://krc.co.ke/madaraka-express-passenger-service/)
