# 泰国旅行目的地

从曼谷出发，大城适合看旧王都，华欣适合住海边。往北可把南邦的旺河老街与清迈串在一起；往南到宋卡府，合艾的车站与商街、宋卡的湖岸老城是两座不同的城市。预订泰国湾行程时，先分清大陆上的素叻他尼和海上的苏梅岛。

## 组合与行前准备

从素叻他尼去苏梅岛，先看票面写的是市区集合点还是东萨（Donsak）码头。若买的是 Seatran 从东萨到纳通（Nathon）的船票，需另外算上到东萨的公路时间，以及从纳通去所住海滩的车程。购买车船联票时再核对接车地点和下车地点。[Seatran Ferry 航线与订票](https://www.seatranferry.com/)
