# 普吉市旅行指南

普吉市位于普吉岛东南部。锡矿贸易带来的财富曾沿街造起一排排狭长店屋，彩色灰塑山墙面向街道，连廊遮住南方日头，也给阵雨中的行人留出一段干路。福建移民的生活印记还在老城的华文学校旧址、面摊和点心店里。今天的咖啡馆、画铺与家族餐馆共用这些街巷，海岛上的城市生活自有一套节奏。

> 建议停留：1–2 天，另加海滩或岛上其他区域的交通日\
> 旅行关键词：锡矿商埠、骑楼店屋、闽南移民、老城早餐\
> 主要体力：老城步行中等，骑楼间有台阶，炎热或阵雨时宜分段\
> 最近研究：2026-11-23

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 初次到访 | 上午吃点心、看店屋，午后进泰华博物馆。若逢周日，留到傍晚逛塔朗路步行街 |
| 停留 | 一天能走完老城核心，住一晚方便清早吃早餐和参加晚间活动。西岸海滩安排独立半天至一天 |
| 预算 | 街巷散步和市集可自由进入。博物馆、旧宅参观、跨岛交通分别计算 |
| 天气 | 雨后地砖较滑，午后高温时将室内主馆放在中段，骑楼与车道交接处留意车辆 |

## 城市格局与游览区域

塔朗路（Thalang Road）是辨认老城最方便的轴线。北边的迪布路（Dibuk Road）、南边的攀牙路（Phang Nga Road）大致与它平行，Soi Romanee 小巷串起塔朗路与迪布路。向西走到甲米路（Krabi Road），泰华博物馆和钦普拉差宅邸都在这一带。这里的街名借用了其他府的名字，导航时同时输入 Phuket Town 和场馆名。

普吉市是普吉府的城市自治体，攻略的步行范围主要在老城。芭东海滩在岛西的卡图县，卡伦和卡塔在岛西南，机场位于岛北。预订时看到地址里的 Phuket 或 Mueang Phuket，还需要看街道和海滩名，才能判断是住在城里还是海边。

## 美食与餐饮

老城的早餐适合从蒸笼开始。点心店可按桌上端来的包点、饺类和炸物选择，几个人分食更容易尝出差别。想吃米食，可点 kanom jeen，细米线浇咖喱汁，再配当店供应的蔬菜，点餐时先问辣度。

普吉福建面（Hokkien mee）把闽南面食带进当地餐厅，常见黄面配肉或海鲜；下单前问清配料，尤其是虾、贝类和汤底。下午若看到 a-pong，可买一份薄脆卷饼佐饮。周日把夜市当作晚餐的一部分，平日则到迪布路、攀牙路周边的固定餐馆坐下用餐。

## 经典行程

| 场景 | 走法与取舍 |
|---|---|
| 一日初访 | 上午在老城吃点心，沿塔朗路走进 Soi Romanee，从迪布路折返。中午吃福建面，午后往甲米路看泰华博物馆，傍晚回老街用餐 |
| 两日城市与海岸 | 首日集中看街区和华人移民历史；次日乘车到岛西南的卡伦观景台，再挑一处海滩。住宿仍在老城时提前约回程车辆 |
| 三日慢游 | 将海岸单列一天。另两天分别安排甲米路旧宅与博物馆、老城早餐与周日市集。未遇周日则选一家街边餐馆和傍晚街景 |
| 周日到访 | 上午看安静街景并拍建筑，午餐后回馆内或住宿休息，傍晚再进入塔朗路。离开时走到约好的外围接送点 |
| 雨天 | 先在泰华博物馆读锡矿与华人迁移，午后选一间可坐下的老店。雨小后只走附近一排骑楼，跨岛看海改到天气较好的一天 |
| 亲子与少步行 | 只选泰华博物馆、塔朗路的一小段和一顿正餐，同行者在同一街区上下车。周日人多时提早逛，给临时休息留位置 |

## 住宿区域

| 区域 | 适合谁 | 预订取舍 |
|---|---|---|
| 塔朗路／攀牙路附近 | 重视建筑、早餐和周日步行街的人 | 老店屋有楼梯，问清客房楼层、行李搬运与夜间噪声 |
| 老城外围／一号汽车站附近 | 以机场巴士和陆路接驳为主、希望车辆直达的人 | 按实际下车站到门口的街面距离选住处，确认汽车站编号 |
| 芭东／卡伦／卡塔（市外） | 以海滨度假为主，仅抽一天访老城的人 | 确认返程车和高峰路况，参加周日晚市要安排晚间跨岛交通 |

## 市内交通

从普吉国际机场（HKT）到普吉市，机场公布的橙色 8411 路巴士驶往 Phuket Town，城内一端为旧汽车站（Bus Terminal 1）。在机场按公共交通标识找候车处。沿西岸开往海滩的巴士走另一条线路，按住宿街区选车。预订陆路车票时同时确认市内一号站与北侧二号站，按票面站名打车。

老城适合步行，去海滩、观景台或机场则按公路行程单独计算。周日塔朗路活动时，先走出步行区再叫车。度假村地址常写 Phuket，给司机完整酒店名及所在海滩，可减少从城市方向折返。

## 不同旅行者须知

使用轮椅或推车的人可请住宿方说明前门与街道间的台阶，逐段确认骑楼连通情况。带孩子适合在上午参观小巷，午后在馆内与餐馆休息。喜欢拍摄的人可利用早间斜光看灰塑细节，拍摄居民或店内空间先征得同意。

## 行前核对

- 周日晚市按当天活动和天气安排，明确接送街口；平日按固定餐馆营业时间安排晚餐。
- 历史宅邸与博物馆分别确认开放区域和票务。是否有电梯、能否推车进入，可先与场馆联系。
- 搭机场巴士时核对方向、上车位置和末班；从西岸去机场与从普吉市去机场各查对应路线。
