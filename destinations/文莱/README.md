# 文莱旅行目的地

在斯里巴加湾市，清真寺、王室收藏与文莱河上的高脚屋可以串在一天里。沿海岸公路往西到诗里亚，则能从十亿桶原油纪念碑认识这个国家的另一段历史。若在首都住宿，西部海岸宜另排一天，把回程用车与参观时段一起约好。[文莱旅游局国家概览](https://www.bruneitourism.com/about/) · [诗里亚海岸纪念碑](https://www.bruneitourism.com/places/billionth-barrel-monument/)
