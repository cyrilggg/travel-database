# 澳大利亚旅行目的地

从悉尼出发，南行去卧龙岗看伊拉瓦拉海岸，北行去纽卡斯尔看港口与海水浴池。以墨尔本为起点，克兰伯恩的植物园和本迪戈的金矿街区也在不同方向，适合分别安排行程。
