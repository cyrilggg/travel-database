# 海得拉巴旅行指南

海得拉巴位于印度德干高原，穆西河穿过城区。河南岸的查尔米纳四面张开高拱，脚下的市集向几条街巷铺展，漆面手镯、香料和茶馆挨在一起。城西的花岗岩山上还保留着戈尔孔达堡的层层城墙，老城宫殿的吊灯和礼仪大厅则记录着后来尼扎姆王朝的生活。伊朗式奶茶配小饼干和慢焖香饭，如今仍是当地餐桌上两样熟悉的味道。

> 建议停留：2–3 天\
> 旅行关键词：德干王朝、四拱门、山堡、手镯市集与海得拉巴香饭\
> 主要体力：老城街面拥挤，戈尔孔达堡有长段上坡石阶，跨区需乘车\
> 最近研究：2026-11-23

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 初访重点 | 在老城看王宫与手镯街的日常，在西部古堡和陵园辨认早期王朝的建筑 |
| 时间 | 两天分别给老城和西部古迹。第三天适合专访萨拉尔·忠博物馆，在湖边或茶馆结束行程 |
| 天气 | 炎热季节把堡垒放在上午，午后参观室内展馆。雨季石阶湿滑，可在下层城门与庭院折返 |
| 预算 | 古迹、王宫与博物馆分开售票，部分场馆对印度公民及国际访客有各自的票种，跨区包车或出租车另计 |

## 城市格局与游览区域

穆西河南岸的 Charminar（查尔米纳，四塔门楼）是老城认路的中心。Laad Bazaar 手镯街紧挨门楼，Chowmahalla Palace 王宫在其西南，萨拉尔·忠博物馆则靠近河岸。两处馆舍与市集虽在同一片区，街口的人流和车流会让短距离移动花上更多时间。

戈尔孔达堡与库特布·沙希王陵在城西，彼此适合串联，从老城过去要单独安排一段车程。侯赛因萨加尔湖（Hussain Sagar）位于老城以北；更西面的 HITEC City、Madhapur 和 Gachibowli 是商务区，按酒店地址判断每天进老城的交通时间。

## 美食与餐饮

Hyderabadi biryani 将长粒米、肉和香料分层焖熟。午餐点一份时先问分量与肉类，搭配酸奶酱可调节辛辣感。Haleem 是肉、谷物与豆类慢煮而成的浓稠料理，在斋月尤其常见；应按当日供应时间安排。

老城市集逛到一半，可以坐下喝一杯 Irani chai，配一两块 Osmania biscuits。奶茶浓甜，略带咸味的酥饼适合分着吃。若希望以当地甜品收尾，可选用杏干熬成的 Qubani ka meetha，先问是否配奶油或冰淇淋。

## 经典行程

| 场景 | 建议走法 |
|---|---|
| 老城一日 | 上午看查尔米纳与手镯街，午饭吃香饭，午后逛乔马哈拉宫两座庭院，回到茶馆歇脚 |
| 两日古都 | 首日走老城。次日早上乘车到戈尔孔达堡，按体力选择攀登高度，中午休息后转到王陵园区，再乘车回酒店 |
| 三日慢游 | 前两日分别给老城与城西，第三日上午看萨拉尔·忠博物馆，午后用餐休息，天色较凉时去侯赛因萨加尔湖岸 |
| 周五到访 | 把王宫、萨拉尔·忠博物馆移到周六或周日。周五选戈尔孔达堡的白天游览，老城市集另留半天，并给礼拜时段的道路客流留余量 |
| 雨天或低体力 | 选一座室内主馆，午后到可直接上下车的餐馆休息。若天气适合，城堡选入口一带的短段，览毕按原集合点乘车 |
| 工艺与收藏 | 上午到手镯街看颜色和镶嵌方式，午后去萨拉尔·忠博物馆看玉器及装饰艺术。当日只有半天可将两个街区分到抵达与离开两天 |

## 市内交通

拉吉夫·甘地国际机场（HYD）在城市南侧，机场设 Pushpak Airport Liner 巴士、预付费出租车与网约车上客区。提取行李处的显示屏会列出巴士班次与车辆信息；先按酒店所在片区选线路，再看当天站位。

中心区部分路段可搭地铁，到王宫和查尔米纳仍要安排街面接驳。城堡与王陵可约同一辆车接送，在堡门口确认司机会合点后再上坡。搭长途火车尤其要看清票面是 Hyderabad Deccan（Nampally）、Secunderabad Junction 还是其他车站。

## 不同旅行者须知

带孩子逛博物馆可以把整点报时作为观展节奏，选择相邻的展厅，再安排一次坐下喝水的休息。轮椅使用者先向王宫或博物馆询问当天通行入口，市集选择人流较少的时段。进入仍在使用的宗教场所前，按当日礼拜、着装和鞋履存放规则参观。

## 行前核对

- 周五行程留意王宫与萨拉尔·忠博物馆的共同休馆日，确认改期后再约车。
- 堡垒白天入场与晚间声光项目分别查当日公告，雨后按阶梯情况调整折返点。
- 核对机场 Pushpak 路线、铁路站名与酒店片区，早班航班给跨城公路留余量。
