# 新西兰旅行目的地

北岛可从奥克兰的火山海湾、内皮尔的震后建筑走到惠灵顿的海峡港口。南岛的克赖斯特彻奇（基督城）与达尼丁分别连接坎特伯雷平原和奥塔哥半岛。
