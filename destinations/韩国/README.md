# 韩国旅行资料

韩国的城市沿山地、河流和海岸展开。首尔的宫阙与商业街区、釜山的山坡港湾、庆州的新罗遗产、全州的韩屋与餐桌，分别呈现都会、海港和古都的生活。地方城市可围绕寺院、市场、产业遗存、河岸或岛屿阅读，每篇攻略的简介先介绍城市，正文再展开体验与出行信息。

## 入境与证件

核查日期：2026-09-06。先根据本人护照、居留身份、旅行目的和入境口岸确认适用签证，再预订交通与住宿。

- 韩国驻华使馆 2026-06-30 公告将指定旅行社申请的 C-3-2 团体签证手续费优惠延续至 2026-12-31。该政策适用的是团体签证申请费用，旅行资格按签证和证件条件确认。
- K-ETA 临时豁免延续至 2026-12-31，适用于公告列明的护照范围。中国普通护照持有人按领馆签证及具体适用政策办理。
- 济州相关入境安排需结合证件、实际航线、经停地点和后续前往韩国其他地区的计划单独核实。

## 城际与市内交通

韩国观光公社的交通指南分别说明铁路、长途巴士、机场交通和市内交通卡。跨城铁路按实际出发站、到达站和运营商订票；高速巴士与市外巴士也有各自的售票平台。大型车站的铁路、地铁和巴士站点可能分布在相邻街区，给换乘留足步行时间。

市内公交与地铁可按当地支持范围使用 T-money 等交通卡，城际列车按车票乘坐。海岛航班、渡轮和山地设施以当天运营公告为准，各城市正文列出更具体的片区与接驳条件。
