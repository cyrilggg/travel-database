# 卡萨布兰卡旅行指南

卡萨布兰卡是摩洛哥的大西洋港城。港口旁的老城里，店铺沿窄巷铺开；跨出城墙，电车穿过装饰艺术风格的楼群，楼下是咖啡馆和卖鱼的中央市场。临海的哈桑二世清真寺用木雕、石膏花饰和拼贴瓷砖围合出巨大的礼拜空间。沿海岸向西，港区的街景渐渐换成面向海浪的长廊、沙滩和露天餐座。

> 建议停留：1–2 天\
> 旅行关键词：大西洋港城、清真寺工艺、装饰艺术建筑、市场海鲜\
> 主要体力：中心城区较平坦，老城与海滨之间距离较长\
> 最近研究：2026-11-23

| 项目 | 旅行信息 |

| 花费 | 公共广场、海边和老城适合自由步行；清真寺内部参观购导览票，食用海鲜先问整餐计价 |
| 天气 | 大西洋风会改变海边体感，午后可回中央市场或广场旁咖啡馆休息 |

## 城市格局与游览区域

Casa Port 火车站靠近港口和老城东侧。老城（Ancienne Médina）南缘靠近联合国广场（Place des Nations Unies）；从广场沿穆罕默德五世大道向东，是电车、中央市场和商业建筑集中的街面。穆罕默德五世广场（Place Mohammed V）则在联合国广场以南，靠近阿拉伯联盟公园。大道、广场和机场都以穆罕默德五世命名，问路时说完整名称更清楚。

哈桑二世清真寺在老城西北的海边，艾因迪亚卜（Aïn Diab）海滨在更远的西侧。哈布斯（Habous）被称为“新麦地那”，位于中心东南的内陆街区。想看手工艺的半天和想去海边的半天，可分别搭车往返。

## 美食与餐饮

中央市场（Marché Central）适合把看鱼档和吃午餐连在一起。先看鱼的品种与大小，再确认是按重量还是整条计价、加工费和配菜如何计算；附近小餐馆可将当场选的鱼烤制。住在港口一侧的人，午后可从市场步行回老城。

街区餐馆和小摊可尝 harira 浓汤、烤肉串或层层摊开的 msemen 煎饼。哈布斯区适合逛完铜器铺后买一两块摩洛哥点心配薄荷茶。安排海滨晚餐时，先按店址决定到艾因迪亚卜还是清真寺周边，两段海岸之间另有车程。

## 经典行程

| 场景 | 建议走法 |
|---|---|
| 一日初访 | 上午按场次进哈桑二世清真寺，回中央市场吃午餐。下午走穆罕默德五世大道到联合国广场，从城门进老城，结束后回 Casa Port |
| 两日城市与海岸 | 首日看清真寺与老城。次日上午去哈布斯看工艺与点心铺，午后回中心逛广场和公园，傍晚乘车到艾因迪亚卜看海 |
| 三日慢游 | 将美术与建筑留成两个上午：首日上午专看清真寺，第二天在大道与市场细看街区，第三天逛哈布斯；选择风较小的傍晚走海岸 |
| 雨天与大风 | 清真寺按参观时段进室内，午间在中央市场附近用餐，下午挑有顶拱廊或咖啡馆。雨停后再到联合国广场短走 |
| 亲子与低体力 | 一天只选清真寺与公园两个停留点，中间搭车午餐；若导览站立时间偏长，可在广场近看门廊后休息 |
| 工艺与建筑 | 上午在清真寺看瓷砖与木雕，下午去哈布斯观察铜器和皮具，另一个清晨再沿电车街看近代商业建筑，减少午间日晒 |

## 市内交通

穆罕默德五世国际机场（CMN）位于市区以南。ONCF 机场铁路连接 Aéroport Med V、Casa Oasis、Casa Voyageurs 和 Casa Port；住老城或港口一侧通常以 Casa Port 较方便，换长途列车则按车票决定在哪一站下。早晚航班要将铁路首末班、安检及酒店到站的路程连起来算。

电车适合走中心大道或去西部海滨。前往海滩可查 T2 的 Aïn Diab Plage 方向，中心到具体站点可能需要换线。清真寺的访客入口、宗教活动入口和广场位置分别查看，到场前在地图上标好购票点。去哈布斯或携大件行李时，也可按明确的门牌乘车直达。

## 不同旅行者须知

清真寺是日常宗教场所，需按导览路线集合，入内前穿好能覆盖肩膀、躯干并长过膝盖的衣物。带孩子可把找几何图案作为参观线索。行动较慢者可先向基金会询问导览的站立时间、台阶和具体入口，在海边广场看建筑也能看到完整的外立面。

周五想逛市场与作坊的人，可先查参与店铺营业时段，午后安排公园或海边散步。独自旅行者在老城先记下所进城门，约车时用广场、车站等明确地点作集合点。

## 行前核对

- 向清真寺基金会核对选定日期的导览、周五及斋月特殊场次，留足买票和集合时间。
- 机场车票、城际车票、酒店地址分别查看 Casa Port、Casa Voyageurs 或 Casa Oasis，按旅行日向 ONCF 查班次。
- 出发去大西洋海岸前查看当日风况与电车服务，留意返程时间。
