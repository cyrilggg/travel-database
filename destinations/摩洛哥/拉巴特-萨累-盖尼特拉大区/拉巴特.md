# 拉巴特旅行指南

布雷格雷格河在拉巴特汇入大西洋。河口高处，乌达雅堡的巷子沿城墙转折，能望见对岸萨累的屋顶和海口的浪。老城的商街向南接上宽阔的林荫大道，首都的车站、办公楼与咖啡馆沿线而立。往上游走，哈桑塔和广场上一排排石柱标出了中世纪大清真寺的尺度，旁边的王陵今天仍有人前来致敬。

> 建议停留：2–3 天\
> 旅行关键词：河口城堡、王朝遗产、老城手工艺、跨河电车\
> 主要体力：老城以步行为主，城堡街巷和舍拉遗址有坡与台阶\
> 最近研究：2026-11-23

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 初访 | 从老城走到乌达雅堡看河口，再看哈桑塔广场，能辨清商贸、海防与王朝礼仪各自所在的位置 |
| 停留 | 一天够走老城与河口；两天可另看哈桑塔和舍拉，第三天适合到对岸萨累 |
| 天气 | 海风会改变河口体感，舍拉遗址则有较长露天路段。炎热时把遗址放在上午，午后留给室内展馆 |
| 预算 | 老城、河滨与广场适合自由步行，国家饰物博物馆、舍拉门票及语音导览另计 |

## 城市格局与游览区域

从 Rabat Ville 火车站沿穆罕默德五世大道向北走，宽阔的现代街区渐渐收进有城墙的麦地那（Médina）。穿过老城北缘，乌达雅堡（Kasbah des Oudayas）就在河口岬角上。堡内通往住宅的巷子和面向游人的博物馆、花园各有入口，步行时可以靠城门定位。

哈桑塔在城堡上游一侧，舍拉（Chellah）则在老城东南方的城墙外。萨累（Salé）是对岸的独立城市，轻轨经哈桑二世桥跨河。把河口两岸排在不同半天，比在旧城巷道里反复找桥省时。

## 美食与餐饮

想在老城吃一顿简便午饭，可在面包铺和小餐馆间找烤鱼、沙拉或塔吉锅；点鱼时先问品种、份量和计价方式。想吃蒸粗麦粉 couscous，可以在周五午餐前问当天菜单，给家庭式慢炖菜留出用餐时间。

堡区看完首饰与庭院后，适合留一段时间喝薄荷茶。若还要去舍拉，可将正餐放在城区，再乘车去遗址；住在旧城的人，晚餐结束后沿白天走过的城门返回更容易认路。

## 经典行程

| 场景 | 建议走法 |
|---|---|
| 初次一日 | Rabat Ville 出发，沿大道进麦地那，午饭前后到乌达雅堡看河口；下午乘车到哈桑塔与王陵，把广场留在日照较柔和的时段 |
| 两日历史建筑 | 首日老城、乌达雅堡与国家饰物博物馆。次日上午去舍拉看两层历史遗存，午后到哈桑塔，沿河选一段平缓步道收尾 |
| 三日双城 | 前两天走拉巴特，第三天搭电车跨河到萨累，另留半天走对岸老城。返程按实际站点选火车站或市区住宿 |
| 风雨天 | 用国家饰物博物馆作主站，雨歇时再走堡内花园；周二可把这一段换到次日，先在老城用餐、逛商街 |
| 低体力 | 乘车到哈桑塔附近，以广场和陵寝为半日，午后在河边安排休息。堡区和遗址另择一天，并向场馆确认合适入口 |
| 亲子考古 | 首日上午去舍拉，在古城街道与围墙各选一个观察点，午后回城休息。次日从城堡高处找桥、河道和对岸城墙 |

## 市内交通

火车票按酒店和行程选择 Rabat Ville 或 Rabat Agdal。前者靠近市中心大道，轻轨 Mohammed V – Gare de Rabat 站方便接续市内路程。前往萨累可查朝 Bab Lamrissa 或 Gare de Salé 一侧的站序；从老城去舍拉则应按遗址大门定位，再决定乘车或步行。

拉巴特–萨累机场（RBA）位于萨累一侧。机场接驳与市内电车分别查站点，按实际航班确认接驳方向和末班时间。住在麦地那，应把机场车辆抵达城门至庭院住宿的步行时间也算进去。

## 不同旅行者须知

带孩子看首饰展时可选一组扣饰观察其佩戴方式，再去花园休息。需要平缓路线的旅客可把堡区观景和舍拉分开安排，向馆方确认同行者能走到的范围。参观王陵和拍摄住宅街景时，按现场礼仪行动，拍人像先征得对方同意。

## 行前核对

- 国家饰物博物馆常规周二闭馆；城堡街巷与博物馆按各自开放安排。
- 舍拉按冬夏季和斋月分别公布开放时间，选择语音或人工讲解时核对语言与集合时间。
- 从另一座城市当天往返，核对火车票站名和跨河电车返程，给行李接送留出余量。
