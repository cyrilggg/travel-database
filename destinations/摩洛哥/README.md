# 摩洛哥旅行目的地

北部可从丹吉尔搭铁路到盖尼特拉，再前往拉巴特。去帝都老城，可对照非斯与梅克内斯两篇攻略。阿尤恩位于地位有争议的西撒哈拉，由摩洛哥实际管理，本目录沿用项目地图的旅行入口。
