# 朝鲜旅行资料

朝鲜的城市认识可从大同江流域、东海岸港湾、西部古都和北部山地展开。平壤的战后建筑、开城的高丽遗产、南浦的河口工程以及东北城市的工业背景，呈现各自的历史与地理。城市正文结合遗产资料和有日期的参访记录，帮助理解地方文化与空间关系。
