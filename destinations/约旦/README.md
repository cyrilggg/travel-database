# 约旦旅行目的地

安曼适合作为北部行程的基地，杰拉什看古城柱廊，萨尔特沿坡道穿过仍在使用的市集和老宅。向南走，马达巴的教堂保存着马赛克地图；前往佩特拉可住在瓦迪穆萨，最后到亚喀巴，把红海海岸单列一天。

## 多城行程的门票选择

同时游览杰拉什和佩特拉时，可按在佩特拉需要的连续参观天数比较 Jordan Pass 套餐。佩特拉夜游另行购票；马达巴地图教堂和尼波山也各自售票。把这些费用分开计算，再与逐处购票比较。[通票套餐](https://www.jordanpass.jo/contents/Prices.aspx) · [夜游票务说明](https://www.jordanpass.jo/Contents/FAQs.aspx) · [宗教遗址适用范围](https://www.jordanpass.jo/Contents/Biblical_Trail.aspx)
