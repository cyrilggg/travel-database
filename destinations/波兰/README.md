# 波兰旅行目的地

沿波罗的海一带，格但斯克适合从老港和造船厂读起，格丁尼亚则以近现代港城、航海训练船和海滨街区见长。内陆工业城市各有不同的步行线索：罗兹看纺织厂和电影文化，卡托维兹看煤矿改建的文化区与工人住宅。往东可分别以卢布林和比亚韦斯托克为落脚点。
