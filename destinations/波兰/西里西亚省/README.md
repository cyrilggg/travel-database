# 西里西亚省旅行目的地

| 城市指南 | 旅行特点 |
|---|---|
| [卡托维兹](./卡托维兹.md) | 矿区、音乐厅与工人社区 |
| [格利维采](./格利维采.md) | 老城、广播塔与运河工业 |
| [比托姆](./比托姆.md) | 歌剧院与上西里西亚工业文化 |

跨城看工业遗产，可先按住宿地查两段区域列车：卡托维兹至格利维采查 S1，格利维采至比托姆查 S18。车票上的站名只对应铁路车站，去工人社区、广播塔或剧院还需算上市内接驳。出发前按日期查看运营方的施工与替代巴士公告。[西里西亚铁路分线时刻表](https://www.kolejeslaskie.pl/rozklad_jazdy/liniowy-rozklad-jazdy/)
