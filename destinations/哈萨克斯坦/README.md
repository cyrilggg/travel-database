## 跨城铁路

订阿斯塔纳至阿拉木图的夜车时，把车票上的站名也写进接送订单。部分车次从 Nurly Zhol 发车，次日抵达 Almaty-2；查票时同时核对两端车站和抵达日期，再安排住宿与进城交通。[哈萨克斯坦铁路客运订票](https://bilet.railways.kz/)

## 选海岸、湖岸还是河岸

想在里海边留宿，选西部的[阿克套](./曼格斯套州/阿克套.md)。[阿特劳](./阿特劳州/阿特劳.md)同在西部，市中心的步行路线沿乌拉尔河展开。内陆的[巴尔喀什](./卡拉干达州/巴尔喀什.md)则位于同名大湖北岸，订房时要区分城区滨水地段与其他湖岸村镇。
