# 哈萨克斯坦旅行目的地

阿斯塔纳和阿拉木图相距较远，即使搭乘夜车，两城也需要分开安排游览日。想了解南部丝路城市，可从奇姆肯特的老城和集市出发，再到突厥斯坦参观亚萨维陵墓。

## 跨城铁路

订阿斯塔纳至阿拉木图的夜车时，把车票上的站名也写进接送订单。部分车次从 Nurly Zhol 发车，次日抵达 Almaty-2；查票时同时核对两端车站和抵达日期，再安排住宿与进城交通。[哈萨克斯坦铁路客运订票](https://bilet.railways.kz/)
