# 明亚旅行指南

明亚坐落在埃及中部的尼罗河西岸，火车站、市街和临河大道挨得很近。河西是城镇与农田，越过河面向东，石灰岩山崖便从河谷绿地背后升起。南边贝尼哈桑的地方长官把耕作、狩猎和摔跤画进山壁里的墓室；再往南，法老阿肯那顿曾在阿玛尔纳的荒原上建都。省城今天的滨河生活、岩墓里的田野和沙地上的古都，都与这条河有各自的联系。

> 建议停留：市区和贝尼哈桑 1 天，阿玛尔纳另留 1 天\
> 旅行关键词：尼罗河滨、贝尼哈桑岩墓、中王国壁画、阿玛尔纳、迈拉维博物馆\
> 主要体力：市区河滨平缓，岩墓有露天坡梯，阿玛尔纳各区之间需车辆接驳\
> 最近研究：2026-11-24

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 看城市 | 从明亚站一带走到西岸滨河大道，午餐和傍晚散步都可留在城区 |
| 看壁画 | 贝尼哈桑（Beni Hasan）在市区东南约 22 公里，从河谷登东岸山坡看中王国地方官员墓 |
| 看法老都城 | 阿玛尔纳（Tell el-Amarna）在东南约 60 公里，市区出发单程约 1.5 小时，各遗址间还需乘车 |
| 看博物馆 | 南边迈拉维市的地区博物馆已开放；明亚市东岸的阿吞博物馆处于建设阶段，开馆时间以新公告为准 |

## 城市格局与游览区域

**明亚市中心**在尼罗河西岸。火车站附近街道连接餐馆、商店和旅馆，往东到滨河大道（Nile Corniche）便能沿西岸走一段。国家旅游咨询处在河滨的 Al-Hurriya 街，可询问当天的遗址开放与交通。对岸金字塔造型的建筑是筹建中的阿吞博物馆（Aten Museum）。

**贝尼哈桑**和**阿玛尔纳**都在明亚省的尼罗河东岸。前者是刻在陡崖中的地方官员墓地，后者是一片含古城、北墓群与王室山谷的遗址区，两处对应的年代、尺度和入口各异。

**迈拉维（Mallawi）**是省内南部另一座城市，地区博物馆位于其西岸城区。由西岸前往阿玛尔纳，可利用迈拉维与代尔穆瓦斯（Deir Mawwas）之间的跨河大桥。游览博物馆要预留它自己的入馆时段。

## 主要景点

| 地点 | 看点与游法 | 建议用时 |
|---|---|---|
| 明亚滨河大道 | 从西岸看尼罗河把密集的省城街区与东岸山地分开。傍晚在河边散步，随后转入市街吃饭 | 45–90 分钟 |
| 贝尼哈桑墓地 | 上层岩墓中保留地方长官家族的彩绘。留意画师如何用一排排动作表现摔跤、用各类工具区分职业，再走到墓前看画中农田所在的河谷 | 现场约 1.5–2 小时，含接送留半天 |
| 阿玛尔纳游客中心与古城区 | El-Till 村的游客中心用原尺寸剖面模型展示官员宅邸；再到古城看低矮的宫殿和建筑基址，较容易想象城市规模 | 两处合计约 2 小时，另计区间行车 |
| 阿玛尔纳北墓群与王墓 | 北墓群是大臣的崖墓，壁面保存宫廷场景；王墓深入东侧山谷。两区之间乘车，先到北墓群方向的售票处确认当天开放墓室及票种 | 两区合计约半天 |
| 迈拉维博物馆 | 观察代尔贝尔沙出土的墓葬随葬品、日常生活模型，以及阿肯那顿女儿的雕像。馆内的小件器物可补充在古城看到的建筑遗迹 | 1–1.5 小时，另计明亚出发车程 |

## 美食与餐饮

- **早餐选蚕豆与塔阿梅亚（ful、taameya）**：慢煮蚕豆适合用埃及扁面包蘸着吃，蚕豆泥炸饼也可夹进面包。清早出城看墓时，这样的早餐容易带走。
- **在明亚市内吃烤肉**：市中心有供应烤肉拼盘的餐馆，可点烤鸡或 kofta 肉串，配米饭、面包和沙拉。多人用餐先问拼盘份量，再添配菜。
- **滨河晚餐**：河滨餐厅适合在散步后坐下来吃埃及家常菜。阿玛尔纳遗址各区相隔较远，出发前在城内备足饮水、便餐，将正式晚餐留在返城后。

## 经典行程

| 时间 | 路线 | 安排理由 |
|---|---|---|
| 第一天上午 | 明亚 → 贝尼哈桑 → 看岩墓壁画、从山坡俯瞰尼罗河谷 | 上午先走上坡路，司机在约定停车点等候。赶中午抵达的列车时，可把岩墓放到次日上午 |
| 第一天下午 | 返回明亚午餐 → 市街 → 傍晚沿 Corniche 散步 | 从岩墓内的农业场景回到今天的河谷城市，下午可按体力缩短步行 |
| 第二天 | 早离明亚 → 阿玛尔纳北墓群售票处 → 开放墓室 → 古城、游客中心 → 回明亚 | 售票处和河边游客中心位于不同位置。想进王室山谷可减少古城区停站，请车一直等候 |
| 多半天 | 迈拉维市区 → 迈拉维博物馆 → 当地午餐或返回明亚 | 用独立上午看馆藏。馆方常规时段为 9:00–15:00，最晚入场为闭馆前一小时 |

## 住宿区域

| 区域 | 适合 | 订前确认 |
|---|---|---|
| 明亚西岸滨河大道 | 住两晚、想傍晚散步和在同一住处往返遗址 | 预订时问清河景房朝向、接送车停靠位置与早餐时间 |
| 明亚站附近 | 早晚乘火车，优先缩短车站接驳 | 具体入口、隔音、晚到入住安排 |
| 迈拉维 | 用一个上午看博物馆，另一天横渡尼罗河向阿玛尔纳出发 | 确认旅馆可接待情况、车辆与晚餐，预订时搜 Mallawi 或 Malawy |

## 市内交通

- **从开罗抵达**：明亚在开罗往上埃及的铁路沿线上，购票时认明 El Minya 及具体列车的停靠站。市区火车站到滨河住处可乘短程出租车。
- **贝尼哈桑**：按墓地入口安排车辆，议价写清去程、等候与返回明亚。上山参观的台阶从停车区之后开始，把饮水随身带上。
- **阿玛尔纳**：过桥走陆路，或从西岸搭当地渡船到 El-Till。渡船抵岸后仍需汽车；购票点、北墓群、古城和王室山谷分散，宜在明亚约好全程车辆。
- **参观协调**：请住宿方或当地接待方在前一天向遗址核实开放区和抵达安排，司机备好每一段的英文或阿拉伯文地名，回程火车留出余量。

## 不同旅行者须知

- **带孩子出行**：贝尼哈桑可选一两座开放墓室，在图中找摔跤、工匠和农活；阿玛尔纳游客中心的宅邸模型更适合解释古城生活。
- **行动辅助器具使用者**：优先考虑滨河铺装路、迈拉维博物馆或阿玛尔纳游客中心。崖墓台阶与天然石地面起伏明显，预约车时请接待方逐点确认入口高差。
- **考古与摄影爱好者**：先向工作人员确认每一墓室可拍摄范围，沿标出的通道通行。地表陶片等遗存保留原位，有助于考古人员判断古城区布局。

## 行前核对

- 地图分别保存明亚站、贝尼哈桑墓区、迈拉维博物馆、阿玛尔纳北墓群售票处和 El-Till 游客中心。
- 将墓区开放情况、返程车辆、饮水和遮阳帽落实后再进山谷。早班出发时请旅店准备便携早餐。
- 省城阿吞博物馆的官方计划指向 2027 年底，目前看室内藏品可安排迈拉维博物馆；未来日期出行以正式开馆公告为准。
