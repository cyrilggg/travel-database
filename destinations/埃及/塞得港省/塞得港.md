# 塞得港旅行指南

在埃及东北角，苏伊士运河从塞得港汇入地中海。十九世纪为开凿运河而兴起的港城，至今还保留着旧灯塔、木阳台楼房和面朝航道的运河管理建筑。远洋货轮沿南北方向进出，载着居民和车辆的渡船却横向往返，把西岸的商业街与东岸福阿德港的林荫街道连在一起。离开码头走进阿拉伯区，鱼市里的秤盘和烤炉接续着海港的日常。

> 建议停留：1–2 天，两岸渡轮与老港区可合走半天\
> 旅行关键词：苏伊士运河北口、福阿德港渡轮、旧灯塔、木阳台、鱼市\
> 主要体力：西岸中心可步行，码头要过坡板，海滨与鱼市之间可乘车\
> 最近研究：2026-11-24

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 认方向 | 市中心西岸面东望运河，向北走到地中海沿岸。渡轮对面是同省的另一座城市福阿德港 |
| 看船 | 运河岸边适合看远洋船只，渡轮提供从水面回望两岸的角度。沿开放步道观望即可 |
| 城市史 | 军事博物馆讲述运河开凿与 1956 年苏伊士危机等历史；旧国家博物馆已拆除，恢复公众参观日期待公布 |
| 日晒与海风 | 中午进馆或去鱼市吃饭，较凉爽时段沿运河和海边步行，海风强时带一件薄外套 |

## 城市格局与游览区域

苏伊士运河在城市东面，沿巴勒斯坦街（Palestine Street）走会经过渡口附近的老港区，从开放岸线能看到运河管理建筑的轮廓。往北方向是运河北口与地中海，沿海岸向西则进入面向海滩的街区。几条相交的老街上可看木阳台楼房与商铺；有些楼房仍是私宅，适合在街面欣赏。

福阿德港（Port Fouad／Port Fuad）位于东岸，渡口外的住宅街、树木和花园体现了另一种港城布局。回到塞得港西岸，七月二十三日街一带有军事博物馆，阿拉伯区的鱼市也在这一侧。看海和看运河要选不同朝向的岸线。

## 主要景点

| 地点 | 看点与游览方式 |
|---|---|
| 运河北口与巴勒斯坦街 | 从市中心渡口向北沿开放步道行走，观察主航道如何进入地中海。货轮出现的时间由航行调度决定，可用等船时间看街景 |
| 旧灯塔（Old Lighthouse） | 现存旧塔建于 1869 年，与运河正式通航同年。可从街道观察高塔和周边楼房的关系，按外观参观安排行程 |
| 福阿德港渡轮与东岸 | 乘居民往返的渡船横穿航道，抵达后在东岸街区走一小圈。返航时朝西岸看运河管理建筑与旧港天际线 |
| 塞得港军事博物馆 | 运河展厅用模型和资料讲述开凿与通航，另有关于 1956 年苏伊士危机和 1973 年战争的展览及庭院陈列，适合留一至一个半小时 |
| 阿拉伯区鱼市 | 挑午餐前先走一圈，看鱼贩如何按鱼种与大小陈列当天货品。带家人可选已列好鱼价、烹调费和配菜的餐馆 |

有兴趣看运河专题馆，可在当地军事博物馆参观运河展厅。运河管理局对公众介绍的苏伊士运河博物馆在另一座城市伊斯梅利亚；旅游与文物部名录里的苏伊士国家博物馆则位于运河南端的苏伊士城。塞得港国家博物馆的旧馆历史资料仍可查阅，到访前应以当地主管部门发布的重新开放通知为准。

## 美食与餐饮

鱼市里的整鱼按重量出售，先和摊主确定鱼种、重量、每公斤价格，再问清餐厅或加工档的烤制、油炸与配菜费用。菜单上的 sayadeya 常指搭配洋葱调味米饭的鱼餐；多人分食时可以选一条烤鱼，加一份米饭、沙拉和芝麻酱。

若时间主要留给渡轮，午餐可安排在西岸，回程后再去市场。当天要赶开罗方向的长途车，可在点餐时询问烹制所需时间，并把离市中心的接车距离算进去。

## 经典行程

| 可用时间或情境 | 建议安排 |
|---|---|
| 半天走两岸 | 从西岸旧灯塔走到运河步道，到市中心渡口乘船去福阿德港。东岸短走一段再搭船回西岸吃鱼 |
| 一日港城 | 上午先进军事博物馆了解运河城市史，中午乘车到阿拉伯区鱼市吃饭。下午到巴勒斯坦街看老建筑，渡轮往返后在海滨结束 |
| 两日慢游 | 首日游西岸博物馆、鱼市和地中海沿岸；次日上午往返福阿德港，留足时间在两岸比较住宅与岸线。下午从容转车 |
| 大风或赶车 | 缩短海岸步行，在馆方开放时段参观军事博物馆；若渡轮候船时间长，以西岸的运河步道看船收尾 |

## 住宿区域

- **老港区与市中心渡口附近**适合第一次来、打算清早坐船的人。面运河的房间利于看航道，订房时确认窗户朝向。
- **地中海海滨一带**适合以海滩及傍晚散步为主的旅客。去鱼市或渡口按旅馆实际位置安排短程车。
- **福阿德港**适合喜欢较安静街区的人。次日要从塞得港西岸赶车，预留去码头、排队与过河时间。

## 市内交通

从开罗可搭长途巴士前往塞得港，购票时确认开罗上车点、塞得港到站以及两端接驳。西岸的运河步道、旧港街区和渡口可以一起步行，携行李或要去鱼市时可约车，给司机看具体市场或酒店定位。

搭轮渡可向司机说明前往市中心的福阿德港渡口（معدية بورفؤاد）。到码头按指示进入行人通道；上船、下船及等候时以现场交通安排为准。它承担两岸通勤，水上行程短，排队与航道调度会影响总用时。使用公路接送的人应和司机确认车辆是过浮桥还是到渡口接人。

## 不同旅行者须知

- **带儿童出行**可以在西岸先观察渡船横向和货轮纵向的航迹，再亲自搭船，候船和上下坡板时留在行人通道内。
- **行动不便者**可把西岸步道与博物馆作为主线。渡轮坡板的坡度会随靠泊条件变化，出发前向码头确认轮椅通行和工作人员协助。
- **建筑与摄影爱好者**可从公共街道拍旧灯塔、木阳台与海面。港务设施、办公建筑及展厅各有拍摄要求，按现场标识和工作人员指引取景。

## 行前核对

- 军事博物馆由埃及国防部运营，官网列有日间与晚间参观时段，出发当日应确认节假日、晚间开放及入馆证件要求。
- 预留渡轮两次候船的时间。希望赶特定长途车时，先完成跨河再安排西岸活动。
- 看旧灯塔与管理局建筑时选择开放街段；海滨大风时从岸上看北口，跟随当日开放的步行区域活动。
