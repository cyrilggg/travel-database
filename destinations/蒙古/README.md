# 蒙古旅行目的地

乌兰巴托适合作为城市旅行的第一站。若想看西部阿尔泰山麓的哈萨克文化，可把乌列盖作为落脚点；想认识戈壁的地质和古生物，则可从南部的达兰扎德嘎德开始。订住宿前，先区分省会城区、郊外营地和景区入口，三处常需分别接送。

## 首都机场进城

抵达成吉思汗国际机场后，可在航站楼一层西侧的自助机，或巴士与出租车柜台购买市区巴士票。夜间去苏赫巴托广场的旅客，先核对机场公布的发车时间，再安排从广场到住处的最后一段路。[机场公共交通与时刻表](https://en.ulaanbaatar-airport.mn/public-transportation-service)
