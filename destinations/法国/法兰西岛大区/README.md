# 法兰西岛大区旅行目的地

法兰西岛大区以巴黎为核心，城市轨道、区域铁路和公交把中心城区、机场、凡尔赛等外围目的地连接起来。巴黎的连续步行范围集中在具体街区和塞纳河沿岸，不能把整个大区视为一个步行目的地。

## 城市指南

## 区域格局与城市组合

巴黎中心区适合按塞纳河两岸和相邻街区组合。凡尔赛等大区外围目的地需要区域铁路或其他接驳，通常单独安排半天以上；机场不属于顺路景点。
