# 普罗旺斯-阿尔卑斯-蓝色海岸大区旅行目的地

由西向东，马赛、土伦和尼斯是三个独立的海港城市。土伦一篇写港湾通勤船和法龙山，尼斯与马赛分别介绍各自的海岸及艺术收藏。

| [马赛](./马赛.md) | 老港、Mucem、守护圣母院、渔港与卡朗格 | 2–3 天，徒步另留时间 | `researched` | 2026-09-25 |
