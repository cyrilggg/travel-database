# 利兹旅行指南

利兹位于英格兰北部的艾尔河畔，羊毛和布匹贸易曾把商人带进这座西约克郡城市。今天仍能在几条相邻的街上看见三种做买卖的空间：玻璃拱廊让细小的橱窗也有充足光线，谷物交易所用一整片拱顶覆盖大厅，柯克盖特市场的铁柱之间则排着鱼档、布摊和热食柜台。河对岸，当年运货的码头成了博物馆的门前水道。

> 建议停留：1–2 天\
> 旅行关键词：维多利亚拱廊、室内市场、艾尔河、装饰艺术与盔甲工艺\
> 主要体力：市中心景点集中，到南岸码头另有一段步行\
> 最近研究：2026-11-23

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 初访 | 用一个上午比较市场、拱廊和交易所，下午选美术馆或南岸码头 |
| 停留 | 一天适合商业建筑加一座主馆；两天能将河岸和市中心分开慢走 |
| 花费 | 逛市场和拱廊可自由进出。美术馆按能力捐款，皇家军械博物馆常设展免费 |
| 天气 | 市中心几处室内建筑之间只有短段露天街道，沿河至码头则要连续在户外行走 |

## 城市格局与游览区域

Leeds 火车站北侧通往 City Square。从这里向东北走是购物主街 Briggate，玻璃顶的商业拱廊从街旁向里延伸。穿到 Vicar Lane 一带，可把谷物交易所（Corn Exchange）和柯克盖特市场（Kirkgate Market）串起来。美术馆在商业街西北的 The Headrow，更适合与北面的市政文化区连逛。

Leeds Dock 在中心东南、艾尔河南岸。火车站南侧的 Granary Wharf 是另一个码头，两处之间有水上出租船。短住者若想坐船，可以从车站南出口出发，参观后步行过河去市场，这样一路都在看新的街景。

## 美食与餐饮

周一至周六可把午餐留在柯克盖特市场。先看生鲜和日杂摊，再按当日柜台挑热食；多人同行可以各点一份，在餐饮区会合。周日可改到谷物交易所周边用餐，或在酒馆菜单上找 Sunday roast，配约克郡布丁和肉汁。

美术馆的 Tiled Hall Café 适合下午停一站。若想看完整展厅，先看画再喝茶，特别是周六上层展厅通常在 16 时起陆续关闭。去南岸看馆的日子可直接在码头一带午餐，再决定是否搭船回车站。

## 经典行程

| 场景 | 建议走法 |
|---|---|
| 一日初访 | 从火车站经 Briggate 进拱廊，再到谷物交易所，午餐放在柯克盖特市场。下午过河去皇家军械博物馆；回程看船况选择水路或步行 |
| 两日慢游 | 第一天逛拱廊、市场与美术馆，在 Tiled Hall 休息。第二天从 Granary Wharf 搭船或步行去 Leeds Dock，午前后看博物馆，傍晚沿河回中心 |
| 三日艺术与工艺 | 第一天集中看三种商业建筑，第二天看河岸和盔甲工艺，第三天留给美术馆的绘画、雕塑与咖啡厅，按展厅开放日调整顺序 |
| 雨天 | 上午逛拱廊和交易所，午餐后去美术馆。若遇周一，可把市场、商铺与 Tiled Hall 咖啡厅串在一起 |
| 家庭与低体力 | 以 Leeds Dock 单馆为主，馆内分段休息。去程先查水位与登船条件，返程预留公交或出租车，缩短沿河折返 |
| 周日短住 | 上午去谷物交易所，接着在美术馆较短的周日开放时段入内。下午挑一个河边观景点，市场排到其他开市日 |

## 市内交通

从 Leeds 火车站走到皇家军械博物馆，馆方估计约 20–25 分钟。若想坐船，找南出口附近的 Granary Wharf 登船点，终点在 Leeds Dock 馆旁。抵达长途汽车站的人离馆更近，步行约 15–20 分钟。大件行李、看展时间或河水水位都可能影响路线选择。

利兹布拉德福德机场（LBA）与市中心之间有 FLYER 公交。铁路旅客可在利兹市内接驳，按旅行日查机场方向站牌、首末班与联程票范围，机场公路段单独计时。

## 不同旅行者须知

使用轮椅或推车时，从站南出口到船上还涉及码头与船舱之间的高差，订行程前向运营方确认当日登船条件。偏好少步行的人可以把 Briggate、市场与交易所作为半日，在市场坐下休息后直接返程。喜欢安静看馆的人可选工作日下午，先从当天最感兴趣的一个展厅开始。

## 行前核对

- 美术馆周日通常 11–15 时开放，周一咖啡厅与展厅日历分开；市场常规周日休市。
- 军械博物馆按学期、校假及法定假日安排开馆日，特展与活动依各自票务。
- 水上出租船出发前查看水位及运营公告，赶火车时给候船另留余量。
