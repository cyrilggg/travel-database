# 英国旅行目的地

沿英格兰中部和北部走一段工业城市路线，斯托克的陶器、谢菲尔德的刀具和布拉德福德的羊毛纺织各有不同的厂区可看。若偏爱海岸，可从南部的伯恩茅斯、西部的斯旺西，或东北部桑德兰的罗克海岸挑选落脚点。
