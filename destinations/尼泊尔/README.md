# 尼泊尔旅行目的地

加德满都谷地有三座常被简称为「杜巴广场」的王宫广场。看哈努曼多卡宫选加德满都，想看铜像与宫廷庭院选帕坦，沿砖铺街巷从王宫走到陶工广场选巴克塔普尔。三城分别有自己的古城入口和参观安排，约车时写全城市名。博卡拉在谷地以西，费瓦湖畔适合住宿，也是往返安纳普尔纳山区时常用的停留地。[联合国教科文组织的谷地遗产分区](https://whc.unesco.org/en/list/121/) · [尼泊尔旅游局博卡拉指南](https://ntb.gov.np/pokhara)
