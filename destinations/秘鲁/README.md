# 秘鲁旅行目的地

从[利马](./利马省/利马.md)去[卡亚俄](./卡亚俄宪法省/卡亚俄.md)，老港、拉蓬塔海滨和机场各有不同的下车点。沿北部海岸追访古代遗址，可在[特鲁希略](./拉利伯塔德大区/特鲁希略.md)看昌昌古城，到[奇克拉约](./兰巴耶克大区/奇克拉约.md)再分开安排皇家陵墓博物馆与西潘考古区。
