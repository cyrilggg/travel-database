# 坦桑尼亚旅行目的地

从达累斯萨拉姆坐船到桑给巴尔，海峡两端是大陆港城和岛上的石头城。去北部山地时，想看梅鲁山和国家公园可住阿鲁沙，走乞力马扎罗山麓的村庄与咖啡园则以莫希为起点。
