# 格鲁吉亚旅行目的地

从第比利斯出发，姆茨赫塔适合用一天看河谷古都。想走卡赫季酒乡，可在泰拉维的市场和王宫安排半天，再约车去周边村落；锡格纳希则适合沿山脊走城墙、俯瞰葡萄园。向西旅行可把库塔伊西与黑海港城巴统串联，博尔若米的山林步道另留时间。

## 西行列车怎样选站

从第比利斯去黑海沿岸，可查直达巴统的列车。若想中途游库塔伊西，先看车票写的是市区的 Kutaisi I，还是 Kutaisi International Airport；机场铁路站还需接驳进城。两段分开订票时，把进出市区的时间留在行程里。[格鲁吉亚铁路时刻表](https://www.gr.com.ge/en/schedule)
