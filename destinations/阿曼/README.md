# 阿曼旅行目的地

从马斯喀特出发，向内陆走是尼兹瓦的城堡与集市，沿东部海岸走则抵达以造船传统闻名的苏尔。南部的塞拉莱和北部穆桑达姆飞地的海塞卜各适合单列一段行程。想看季风中的佐法尔山地，或乘船进入穆桑达姆海湾，先按季节和抵达方式决定住几晚。
