# 吉尔吉斯斯坦旅行目的地

从北部入境，可先在比什凯克看首都街区，再沿伊塞克湖前往东端的卡拉科尔。奥什位于南部费尔干纳盆地，适合围绕苏莱曼山和老城单独安排停留。

## 沿伊塞克湖到卡拉科尔

从比什凯克出发，巴雷克奇位于湖西端，卡拉科尔在另一端。沿途想停[乔尔蓬阿塔](./伊塞克湖州/乔尔蓬阿塔.md)可走北岸，计划去巴尔斯孔则看南岸。订车时写明停靠的城镇和最终下车地点，湖畔住宿与卡拉科尔市区住宿应分别定位。[卡拉科尔目的地协会交通指南](https://destinationkarakol.com/plan-your-trip/transportation/)
