# 老挝旅行目的地

琅勃拉邦和万象适合围绕寺院、博物馆与湄公河岸安排行程。往南，沙湾拿吉的老城适合步行；巴色则是去占巴塞古迹、波罗芬高原和四千美岛前安排车辆与住宿的门户。

## 组合与行前准备

在巴色预订车辆时，把目的地写到具体景点。向东经巴松方向可到高原瀑布，往南沿 13 号公路去四千美岛则要另计公路车程；住岛的旅客还需核对上船点。把这两段分日安排，才能在白天留出游览和转车时间。[老挝旅游部门占巴塞省指南](https://www.tourismlaos.org/southern-provinces/champasak-province/)
