# 菲律宾旅行目的地

吕宋北部的美岸和佬沃适合串成一段陆路行程。前往米沙鄢群岛，可用伊洛伊洛市和巴科洛德认识海峡两岸，在杜马盖地或塔比拉兰衔接渡轮。预订宿务和薄荷岛的住宿前，先对照船票上的港口与机票上的机场，分别估算抵达旅店的时间。

## 组合与行前准备

机票上的“宿务”对应麦克坦岛的机场。住海边或赶早班机可先看[拉普拉普](./宿务/拉普拉普.md)，安排老城和客运码头则看[宿务市](./宿务/宿务.md)。马尼拉都会区也分多个城市，王城在[马尼拉市](./国家首都区/马尼拉.md)，阿亚拉中心在[马卡蒂](./国家首都区/马卡蒂.md)，迪利曼校园在[奎松市](./国家首都区/奎松市.md)。

从宿务乘船去薄荷岛，查票时看目的港全名。Tagbilaran 和 Getafe 是两处港口，去塔比拉兰老城或转车到邦劳的旅客，应先把抵达港放进当天的陆路行程。伊洛伊洛市和巴科洛德之间也可查客轮；遇天气调整时，先看船公司按日期发布的公告，再安排接船车辆。[OceanJet 航线与运营公告](https://www.oceanjet.net/news-and-updates)
