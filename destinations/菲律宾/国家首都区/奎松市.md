# 奎松市旅行指南

奎松市位于大马尼拉都会区东北部，曾是菲律宾首都。纪念环岛原本预留给国会，如今园中立着三根高耸的纪念塔，旁边的林荫道成了居民晨跑、散步的去处。再往东，菲律宾大学迪利曼校区围着椭圆形大道展开，学生走过树荫和水塘去上课；往南到了库包，体育馆的观众和赶长途巴士的人又在商场通廊里相遇。

> 建议停留：一天走纪念环岛与迪利曼，参加库包活动可住一晚\
> 旅行关键词：菲律宾前首都、奎松纪念环岛、迪利曼校园、马金哈瓦餐饮街、库包\
> 主要体力：园内和校园分段步行，跨越主干道及片区之间需留接驳时间\
> 最近研究：2026-11-24

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 城市边界 | 奎松市（Quezon City，简称 QC）与马尼拉市（City of Manila）同属国家首都区。奎松省（Quezon Province）在吕宋岛东南方向，是另一目的地 |
| 初访重点 | 上午看纪念环岛的纪念塔、博物馆或故居，午后到迪利曼散步，傍晚在马金哈瓦街用餐 |
| 交通枢纽 | Araneta City 在库包（Cubao）。两条轨道线、长途车站和活动场馆各有入口，接送宜用具体建筑名 |
| 天气取舍 | 校园与公园都要走露天路段，炎热时把展馆放到午间；大雨可改到库包的室内画廊 |

## 城市格局与游览区域

| 区域 | 方位与使用方式 |
|---|---|
| 奎松纪念环岛 | 椭圆路（Elliptical Road）围着整座公园，市政厅在路外。抵达后要找指示的入口或行人通道 |
| 迪利曼（Diliman） | 菲律宾大学迪利曼校区位于环岛以东。学术环道、湖畔与各院系有一定距离，按开放空间选一段步行 |
| 马金哈瓦街（Maginhawa Street） | 住宅街与小餐馆交错，适合与校园同日安排。选好店名再叫车，街道本身有相当长度 |
| 库包与阿拉内塔城 | 位于纪念环岛以南。购物、画廊、体育比赛和演出集中在阿拉内塔城，适合结合轨道或长途巴士到发 |

## 主要景点

**奎松纪念环岛（Quezon Memorial Circle）。** 公园中央的三根塔柱高66米，对应前总统曼努埃尔·奎松去世时的年龄。纪念祠及博物馆呈现他的政治生涯，园中另有展现家庭生活的奎松故居。那座房屋从新马尼拉住宅区迁建而来，市府场馆页列为预约参观；想看室内，出发前应分别确认故居与纪念馆。公园本身免费，适合早上先走一圈。[纪念环岛介绍](https://quezoncity.gov.ph/place/quezon-memorial-circle/) · [奎松故居预约信息](https://quezoncity.gov.ph/place/quezon-heritage-house-manuel-l-quezon/)

**菲律宾大学迪利曼校区。** 以 Academic Oval 学术环道为线索，选树荫较多的一段走到校园湖畔。留意教学楼、草地和公共艺术如何沿环道展开，路上的慢跑者与学生也构成校园的日常景象。进教学楼或专题场馆前单独确认接待安排；只想休闲散步，可在开放路段折返。[菲律宾大学文化艺术办公室公共空间指南](https://oica.upd.edu.ph/culture-arts-in-up-diliman/cultural-facilities/multi-purpose-spaces/)

**库包的 Gateway Gallery。** 画廊位于阿拉内塔城 Gateway Tower 五层，以菲律宾文化、历史与艺术为主题。在体育馆一带看比赛或等车时，可先到这里看展，把商场与场馆之间的室内连廊当作避雨路线。先确认画廊当天开门，再按楼名寻找电梯。[奎松市政府画廊指南](https://quezoncity.gov.ph/place/gateway-gallery/)

## 美食与餐饮

在迪利曼游览后，可到马金哈瓦街找家小餐馆吃午晚餐。这片街区适合分着点菜，例如先点一份酸汤 sinigang 配米饭，再按食量加烤肉或炸物；想试甜品可点碎冰、奶和多种配料做成的 halo-halo。餐馆集中在不同街段，遇学校假期或节庆时先核对营业和候位情况。看库包晚场演出，则可在场馆步行范围内先吃饭。[奎松市旅游部门街区活动介绍](https://quezoncity.gov.ph/departments/quezon-city-tourism-department/)

## 经典行程

| 可用时间 | 顺序 |
|---|---|
| 半天看前首都 | 市政厅一侧进纪念环岛 → 纪念祠与博物馆 → 按预约看奎松故居，或沿园内树荫步道折返 |
| 完整一天 | 上午纪念环岛 → 午餐 → 午后乘车到菲律宾大学迪利曼校区 → 傍晚去马金哈瓦街吃饭 |
| 演出或转车日 | 上午选环岛或校园一处 → 下午提前到库包，先确认场馆入口或车站月台 → 逛 Gateway Gallery、吃饭，再看演出或搭车 |

## 住宿区域

参加大学活动可住迪利曼附近，预订时核对每天要进哪一扇校门。要在大马尼拉不同城市之间移动，库包靠近轨道和多家巴士公司，更方便转车；比赛或演出散场时会集中叫车，步行可回酒店的优势尤其明显。以马尼拉市王城区为主要目标时，要把两座城市之间的往返单独算进时间。

## 市内交通

MRT-3 与 LRT-2 都设有名为 **Araneta Center–Cubao** 的站，两站由商场一带的步行通道联系，换线需要出闸、步行并重新进站。前往纪念环岛或迪利曼校园时，再按公园入口、校园建筑选择巴士、吉普尼或预约车辆。若从马尼拉市中心来，先查出发点更适合接哪条轨道线。

库包有多个长途巴士终点和上客处，车票写 Cubao 仍需找运营公司和实际站名。马尼拉国际机场（NAIA）在都会区南部，往返奎松市属于跨城交通；给司机发航站楼与酒店全名，工作日尽量避开通勤尖峰。

## 不同旅行者须知

带儿童可在纪念环岛选游乐区与一处展馆，避免正午连续走完整座公园。轮椅或婴儿车使用者可先向公园管理处问有坡道的入口，再决定如何穿过外围主干道。喜欢建筑的人除了奎松故居，还可看同园的 Bahay Modernismo，了解战后菲律宾住宅的格局与日用品。[公园无障碍设施](https://quezoncity.gov.ph/departments/quezon-memorial-circle-administration-offic/) · [Bahay Modernismo](https://quezoncity.gov.ph/program/bahay-modernismo/)

## 行前核对

- 酒店与活动地址应写 Quezon City 或 NCR，避免导航到 Quezon Province 或马尼拉市的同名道路。
- 分别确认纪念馆、故居和校园展馆的开放及预约，公园开放不等于每座场馆同时开放。
- 查库包车站或活动的实际入口，预留换轨道、穿商场和散场后叫车的时间。
