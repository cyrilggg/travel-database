# 沙哇伦多旅行指南

沙哇伦多（Sawahlunto）坐落在苏门答腊西部山间，城镇沿翁比林煤田发展。十九世纪末，荷属东印度当局在这里开矿，米南加保人、来自爪哇和中国的契约劳工，以及被押来服役的囚犯，共同留下矿城的历史。如今山谷里的旧厨房保存着为工人做饭的巨锅，老站房记录煤炭怎样翻山运到印度洋港口，矿工的生活和一块煤的去向都有迹可循。

> 建议停留：1–2 天，三座市区博物馆约一天，从巴东往返另计山路车程\
> 旅行关键词：翁比林煤矿、矿工厨房、姆巴苏罗矿井、山地铁路、米南加保饮食\
> 主要体力：老城分段步行，矿井出入有台阶，地面展览可独立安排\
> 最近研究：2026-11-24

## 城市速览

| 想了解什么 | 从哪里开始 |
|---|---|
| 矿工怎样在井下工作 | 到姆巴苏罗矿井的 Info Box 了解采矿与劳役史，再随现场安排进入开放坑道 |
| 谁为整座矿城做饭 | 在配给厨房博物馆看炉灶、炊具和成批供餐的设备 |
| 煤炭怎样离开山谷 | 到铁路博物馆辨认老车站，再对照遗产地图找出山地铁路和巴东海港 |

## 城市格局与游览区域

老城的参观重点在 Lembah Segar 一带。以三角公园（Taman Segitiga）为参照，矿井展示馆在公园附近，配给厨房和车站各有自己的入口。街区间可以步行，向司机报地名时可直接使用各馆的印尼文名称。

翁比林煤矿世界遗产共有十二个组成部分，分布在三片区域。沙哇伦多的矿场、煤处理设施和公司城镇属于 A 区。B 区是绵延约 155 公里的山地铁路及其桥隧，C 区是巴东沿海旧称 Emmahaven 的港口储煤设施。老城能看见运输链的起点；若想了解全线走向，遗产地图比在城内寻找港口更直观。

## 主要景点

| 地点 | 现场看点 | 建议用时 |
|---|---|---|
| 姆巴苏罗矿井与 Info Box（Lubang Tambang Mbah Soero） | 展厅介绍井下劳动和被强制服役的囚犯。馆方整修的一段坑道提供地下参观，到馆先问当日带领时段及装备要求 | 60–90 分钟 |
| 配给厨房博物馆（Museum Goedang Ransoem） | 从大锅、炉灶和供热设备的尺度理解矿区怎样集中供餐，再对照展陈了解服务对象和厨房工人的劳动 | 约 1 小时 |
| 沙哇伦多铁路博物馆（Museum Kereta Api Sawahlunto） | 旧站房保留了矿城向外运煤的历史线索，从车站陈列认识铁路作业，再回到地图上看山区为何需要齿轨线路 | 约 45–60 分钟 |

## 美食与餐饮

午餐可以点 **dendeng batokok**，捶薄的牛肉常配辣椒佐饭；当地也有以市内 Silungkang 地名命名的汤品 **sup Silungkang**。在老城饭馆看当天备菜，单点一盘牛肉和米饭即可尝到西苏门答腊的家常搭配。

市内 Talawi 一带的 **lamang tungkek** 用米粉、椰浆与棕榈糖制作，当地家庭在宰牲节期间制作这种甜点。碰上节庆或地方食品展时，可向摊主询问 Talawi 的做法。

## 经典行程

**老城一天**：上午到姆巴苏罗的 Info Box，把地下参观排在馆方可带领的时段。随后去配给厨房，午餐后到旧车站，从矿工的工作、饮食一路看到煤炭外运。傍晚回三角公园一带走走，留时间观察旧矿城与今天商业街的交界。

**从巴东出发住一夜**：第一天经索洛克一带进入山谷，抵达后根据余下开放时间先看车站。第二天上午参观矿井与厨房，午后乘车返程。雨天若坑道接待调整，可把 Info Box 和厨房室内展排在一起。

## 住宿区域

以参馆为主可住三角公园或旧车站周围。订房时把住宿点和三个博物馆同时标在地图上，特别留意山坡上的客房与谷底街道之间的高差。住巴东适合兼顾海岸行程，往返矿城的一天则需为两段山路留出余量。

## 市内交通

从巴东或服务巴东的米南加保国际机场出发，前往沙哇伦多主要走陆路。巴东出城后经 Sitinjau Lauik 山路和索洛克一带，再转入矿城。约车时写明进城、等候和返程地点，出发当天向司机了解沿线路况。

老城按场馆入口分段步行即可。历史铁路的 155 公里是遗产线路长度；想乘观光列车，应另查旅行日的实际始发站、终点、售票和开行公告。

## 不同旅行者须知

带孩子参观，厨房的大锅与站房比抽象的工业年表容易理解，可以先找出“工人吃饭”和“煤炭离城”的实物。对台阶、狭窄空间或井下环境有顾虑的游客，可以在 Info Box 看地面展览；需要无台阶入口时，出发前分别向各馆确认进馆路线。

## 行前核对

- 分别查询矿井、厨房和铁路馆在到访日期的开放情况，先确定井下参观时段。
- 将三家博物馆的印尼文名称和地址存入离线地图，向司机指定返程会合点。
- 若计划追访山地铁路或沿海储煤设施，先选具体地点并向管理方确认公众可达范围，再安排跨城用车。
