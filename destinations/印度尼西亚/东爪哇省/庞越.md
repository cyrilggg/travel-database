# 庞越旅行指南

庞越坐落在东爪哇北岸，城北的渔船驶向马都拉海峡，红树林在潮间带扎根。火车站前的中央广场将铁路与老街相连，往南走，市博物馆和一座红色的教堂仍保留着殖民时期的街景。沿海的马扬安街区里，小贩把椰香调味粉撒进热汤，端出当地的索托。再往内陆，沿岸平原逐渐升入腾格尔高地，那里才是布罗莫火山所在的地方。

> 建议停留：市区半天至一天，去布罗莫另留一晚和次日白天\
> 旅行关键词：爪哇北岸、红教堂、马扬安红树林、椰香索托、布罗莫东侧入口\
> 主要体力：老城平缓，海边栈道露天，山区另有弯道、松砂与清晨低温\
> 最近研究：2026-11-24

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 初次到访 | 从车站前的中央广场出发，沿老街看红教堂与博物馆，再到马扬安吃一碗索托 |
| 海岸 | 从老城另搭车往马扬安渔港一带，购买红树林游览区门票后走栈道看潮滩 |
| 去布罗莫 | 市区是低地换乘点。看日出可先到山上的 Cemoro Lawang 留宿，提前安排次晨的司机与门票 |
| 主要开支 | 市内短程用车、山路接送、当地四驱车、国家公园门票分别询价，拼车时确认按人或整车计费 |

## 城市格局与游览区域

庞越市（Kota Probolinggo）的火车站位于中央广场（Alun-Alun）北侧，沿 Jalan Suroyo 走向红教堂和市博物馆，适合安排为同一段步行。马扬安（Mayangan）的渔港和潮间带在铁路以北，去 Bee Jay Bakau Resort 红树林栈道需认准园区入口。丹绒登巴加港（Tanjung Tembaga）是港口作业区，观潮可选面向游客开放的栈道。

庞越县（Kabupaten Probolinggo）和庞越市是各自独立的行政区。布罗莫方向的山村 Cemoro Lawang 位于县内 Sukapura 区的 Ngadisari 村，靠近腾格尔破火山口边缘。预订写着“Probolinggo”的酒店时，先看地址属于市区还是山村，两处的海拔、衣着和次晨出发时间差别很大。

| 马扬安红树林 | 在 Bee Jay Bakau Resort 的木栈道观察红树林的根系，以及潮水进退后露出的泥滩，适合对海岸生态感兴趣的人 | 1.5–2 小时，付费园区，午间遮阴有限，雨后留意湿木板 | B |
| 布罗莫与腾格尔破火山口 | 从当天开放的高处观景点看火山锥、大片砂海与外缘山壁，再由当地司机前往开放的砂海路段。庞越方向进山常取道 Cemoro Lawang | 市外，含山路接送另留一晚与半天以上；游览范围以火山警戒和园方公告为准 | A（跨区） |

## 美食与餐饮

马扬安区 Mangunharjo 的 Jalan Imam Bonjol 一带有专卖索托的街坊，称为 Kampung Soto Sentono。这里的 soto koya kelapa 用椰香调味粉给汤增添浓香，一人点一碗配米饭就能吃成一餐。市府举办美食活动时会把摊位集中起来，平日可以到街坊里找各自营业的小店。

想吃鱼可在马扬安一带问当天供应的烤鱼（ikan bakar），先确认整条鱼的份量、价格与配饭。准备上山的人可在城里吃过午餐再出发；若约了凌晨的观景车，入住时问好山村旅馆早餐何时供应、能否打包。

## 经典行程

| 场景 | 路线与取舍 |
|---|---|
| 过境半天 | 行李放在住宿处，从中央广场走到红教堂与博物馆。临近列车发车时回车站附近吃饭，将红树林留给停留更久的行程 |
| 城市一日 | 上午走老城，午餐去 Kampung Soto Sentono。午后乘车前往马扬安红树林，气温下降后走一小段栈道，再按园区营业时间返回 |
| 接布罗莫两日 | 首日上午游老城，中午前后搭已确认的车上山，住 Cemoro Lawang，入夜前落实次晨接送。次日按开放状态游观景点和砂海，回山村取行李后下山 |
| 云雨或火山管制 | 能见度差时可在山村休息，按开放路段调整观景点。园区关闭时保留市区博物馆与饮食行程，将上山日期另作安排 |

## 市内交通

从泗水等地搭铁路抵达时，用印尼铁路 KAI 查询目的站 Probolinggo；出站即到老城一带。长途公路客运则多使用市区西侧 Kademangan 的 Bayuangga 客运站，该站与火车站分处两地。若由泗水机场抵达，还需另接公路或先到市内铁路车站。

前往布罗莫可在 Bayuangga 向站务人员询问当日去 Sukapura、Ngadisari 或 Cemoro Lawang 的山路车辆，也可向住宿方预订从庞越市区直接接送。上车前用文字确认终点到哪一家旅馆、等待拼车的安排和下山接人时间。山路接送与园内四驱车是两段服务，预约后保留司机联系方式，回城当天给长途火车留出机动时间。

## 不同旅行者须知

亲子或少步行旅行者可选广场与红教堂周边的一段市街，去红树林前确认入口到栈道的距离与休息处。火山观景涉及凌晨出行、颠簸路面及风沙，订车时向司机问清停车点到观景台的坡度与步行距离。腾格尔人的祭祀与宗教活动可能影响开放，拍人像、仪式或进入宗教场所先听当地指引。

## 行前核对

- 在国家公园官方系统选 **Bromo**、游览日期与庞越方向入口，按印尼公民（WNI）或外国公民（WNA）对应类别购票。将付款后的二维码离线保存，入口扫码查验。
- 向旅馆或司机逐项确认市区接送、园内车辆与入园票的费用。车费报价里若包含门票，索取对应日期与人数的凭证。
- 火山主管机关要求访客在布罗莫活动火山口一公里警戒范围以外活动。出发前核对当天最新通告，行程选开放的远观位置，现场如扩大警戒，以新边界为准。
- 保存下山车辆的时间与车牌，向住宿处核对行李领取和返程车站，清晨准备挡风衣物。
