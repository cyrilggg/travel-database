# 泗水

泗水是东爪哇省会，卡利马斯河从市区向北流入港口。红桥连着殖民时期的商业街和华人店屋，再往北，通往安佩尔清真寺的巷子里挤着朝圣者和商铺。英雄纪念碑把这座海港与一九四五年的独立斗争联系起来。至今，从老城的成排货栈到市中心灯火通明的敦军干街，贸易和人群往来仍塑造着泗水的面貌。

> 建议停留：1–2 天，跨城行程另计\
> 旅行关键词：爪哇港城、独立运动、红桥商区、安佩尔朝圣街巷\
> 主要体力：老城步行中等，天气湿热，跨街区适合乘车\
> 最近研究：2026-11-23

## 城市格局与游览区域

泗水的历史核心沿卡利马斯河展开。北部 Kota Lama（老城）以 Jembatan Merah（红桥）为方向标：河西 Jalan Rajawali 一带保留旧商行建筑，过桥向东沿 Kembang Jepun 可看华人商业街，再往北才是 Ampel 朝圣街区。这片老城与仍承担客货运的 Tanjung Perak 港各有用途，若只为看港城建筑，目的地选红桥更直接。

英雄纪念碑在红桥以南，继续向南到 Jalan Tunjungan（敦军干街），便进入现代市中心的商业区。Balai Pemuda 与城市广场在这一带东侧，Surabaya Gubeng 火车站更靠东。住市中心适合把北部老城排一个半天，进出各选明确的路口。

## 美食与餐饮

Rujak cingur 是泗水有代表性的咸香拌菜。煮软的牛鼻部位配蔬菜、水果、豆腐、天贝和米糕，酱料通常把花生、虾膏 petis 与辣椒捣匀。初次尝试可请店家少放辣椒；需要避开花生、甲壳类或牛肉时，点单前把酱汁与配料一起确认。

在红桥周边看店屋，可把午餐安排在华人街区附近；晚上回市中心，则以敦军干街周边餐馆作终点。进入安佩尔的市集小巷时，适合先吃简餐再参观，把礼拜和朝圣人流集中的出入口留给通行。

## 经典行程

| 场景 | 建议走法 |
|---|---|
| 一日初访 | 上午看英雄纪念碑与十一月十日博物馆，中午乘车到红桥附近用餐，下午走 Rajawali 和 Kembang Jepun 两岸街段，傍晚回市中心 |
| 两日港城史 | 首日走纪念馆、红桥与华人街区，次日上午从安佩尔市集步行到清真寺，午后回酒店休息，傍晚串联 Balai Pemuda 和敦军干街 |
| 三日慢游 | 将首日的红桥两岸独立成半天，另留一日看安佩尔和市内文化展演。离城日按车站位置只选最近的街区，避免横穿全城赶车 |
| 炎热或阵雨 | 先选开放的博物馆，午间在中心城区休息。雨势转小再走红桥一岸，另一岸的商店和安佩尔市集移到较凉时段 |
| 亲子或少步行 | 一天只选纪念碑展馆加一段街区，从广场附近叫车到红桥，靠河看完桥与店屋后就近上车；安佩尔另择半天 |
| 社区与建筑 | 上午从 Rajawali 旧商行走到 Kembang Jepun 商铺，乘车去安佩尔，从朝圣市集看另一种社区中心。把晚餐留给敦军干街 |

## 市内交通

市区有 Suroboyo Bus 等公交服务。查看路线时使用目的地的印尼语名称，按当日站点和支付方式安排；跨区点对点也可用正规出租车或叫车服务。红桥两岸适合步行，去安佩尔宜在主要入口下车，再穿过市集小巷。

朱安达国际机场（Juanda，SUB）位于泗水南面的诗都阿佐县（Sidoarjo）。机场提供巴士与出租车，按航司确认 T1 或 T2，并按到达航站楼选择接车点。接续爪哇长途铁路时先看票面站名，Gubeng 与 Pasar Turi 位于不同片区；前往布罗莫火山等城外目的地，另排公路或铁路转移日。

## 不同旅行者须知

安佩尔是持续使用的礼拜与朝圣空间。穿着遮肩过膝的衣物，依入口标识选择访客可进入区域，拍摄人物或仪式前先征求同意。轮椅使用者或推车家庭可先向博物馆询问入口和展区层差，红桥与市集则挑人流较少的一段走，两端都约好接车点。

## 行前核对

- 查十一月十日博物馆票务页面，确认旅行日的场次和适用票类；学生优惠有本地资格条件。
- 留意清真寺当日礼拜与活动安排，老城用餐查看具体营业日。
- 核对机场航站楼、火车站和跨城接送的完整名称。高峰期从北城赴机场需另留交通余量。
