# 巴厘巴板旅行指南

巴厘巴板位于婆罗洲东岸，城南面向望加锡海峡，西侧的海湾深入陆地。石油工业与航运塑造了这座港城的岸线：在梅拉瓦伊海边能望见出入港湾的船只，再往湾内走，水上聚落和渡口沿岸展开。淡水河汇入海湾的地方长着成片红树林，长鼻猴生活在林冠间。海味也进了街头店铺，鲜蟹端上餐桌，蟹肉松和薄脆则成为人们带走的伴手礼。

> 建议停留：1–2 天，去佩纳扬跨湾另留半天至一天\
> 旅行关键词：巴厘巴板湾、梅拉瓦伊海岸、红树林、长鼻猴、海蟹\
> 主要体力：海岸可分段步行，红树林栈道湿滑，坐小船需上下码头\
> 最近研究：2026-11-24

## 城市速览

| 想做的事 | 地点与安排 |
|---|---|
| 看港口城市 | 从克兰达桑（Klandasan）一带沿城南海岸去 Melawai 看海面与港湾船只 |
| 从陆上看红树林 | 选 Margomulyo，看树根、泥滩和林间木桥，先问当天可走的栈道范围 |
| 从河里看红树林 | 选 Graha Indah，从 Somber 河一带随向导乘船观察岸边生态 |
| 乘船过湾 | 从 Kariangau 车渡码头前往对岸 Penajam；搭快艇则另查 Kampung Baru 客运码头 |

## 城市格局与游览区域

市区商业、住宿和餐饮沿南岸的 Jalan Jenderal Sudirman 一带展开。往西经过 Kemala 和 Melawai 海岸，便接近 Semayang 港。这里服务海上客货运输，海港作业区和客运站各按现场规定通行；只想看船，可留在开放的海岸。再往湾内是 Kampung Baru 一带的社区与客运渡口。

Graha Indah 和 Margomulyo 都在巴厘巴板一侧，前者以沿河乘船为主，后者有木桥步道。西北方向的 Kariangau 另有车渡码头和港口设施，叫车时直接输入「Pelabuhan Feri Kariangau」。乘船抵达 Penajam 后已经进入北佩纳扬巴塞尔县（Penajam Paser Utara）。

## 主要景点

| 地点 | 具体看点 | 建议用时 |
|---|---|---|
| 梅拉瓦伊海岸（Pantai Melawai） | 在湾口面海的公共区域观察船只与沿岸生活，傍晚可把看海与摊点晚餐放在一起 | 45–90 分钟，雨势较大时移到有遮蔽的餐馆 |
| Graha Indah 红树林 | 搭当地称为 klotok 的小船沿 Somber 河行驶，从水面看两岸红树根系与林冠。长鼻猴是野生动物，能否遇见取决于当天活动 | 交通与候船合留半天，先约船与向导 |
| Margomulyo 红树林 | 木桥穿过红树林，停下来可看树根如何扎在潮间带泥滩上，也可观察林间鸟类，适合想从陆上近看的人 | 约 1 小时，出发前确认入口及木桥开放状况 |
| Kebun Sayur 市场 | Pasar Inpres Kebun Sayur 有地方工艺品、织物和纪念品摊，可和同侧湾岸街区串访 | 45–90 分钟，白天较适合挑选 |

## 美食与餐饮

本地海鲜餐馆常以 kepiting（蟹）为主菜，几人同桌可先问当日蟹种、份量和计价单位，再点一份共享。想带走海味，可找 abon kepiting（蟹肉松）和加了蟹肉的脆饼，原味、辛辣或黑胡椒口味各有区别。梅拉瓦伊一带适合傍晚吃点心、喝饮料，看海后想坐下来吃一整餐，可回克兰达桑或市区商业街。

## 经典行程

| 时间与兴趣 | 路线及调整 |
|---|---|
| 海岸与市场一日 | 上午逛 Kebun Sayur 市场，午后回市区吃海鲜，太阳较低时再去 Melawai 看湾口。遇阵雨可先吃饭，等雨势减弱后走海边短段 |
| 红树林两日 | 第一天逛市区海岸，第二天按约好的时段前往 Graha Indah 乘船。更喜欢陆上观察则改去 Margomulyo；两处入口分开，用车时预留往返市区的时间 |
| 跨湾另一天 | 想体验当地渡运，可从 Kariangau 乘车客渡船到 Penajam，或从 Kampung Baru 乘当地客船。确定对岸要去的地点、落客码头和回程选择，再从港镇继续乘车 |

## 住宿区域

克兰达桑及 Sudirman 沿线适合短住、在市内吃晚饭并分头前往海岸和红树林。住在 Sepinggan 机场附近适合早班机乘客，去西侧海湾仍要穿行市区。乘长途客轮时可依船票上的码头选住宿；若只是想看湾景，按旅馆到开放海岸的步行路径选择，港区围栏会改变实际走法。

## 市内交通

苏丹阿吉穆罕默德苏莱曼·瑟宾甘机场（Sultan Aji Muhammad Sulaiman Sepinggan，BPN）位于市区东侧的 Sepinggan。航站楼有机场出租车，机场官网另列巴士服务；到达后确认当日目的站及运营时间，前往具体旅馆或带大件行李可直接约车。

Semayang 是长途海上客运港；Kariangau 的渡运业务连接 Penajam，车辆和乘客依客渡规定办理；Kampung Baru 则有通向对岸的快艇和当地客船。前往红树林的游船从景区集合，不同船型使用各自码头。计划同日搭机时，应先留足下船、候车和横穿市区的时间。

## 不同旅行者须知

带孩子乘红树林小船时，与向导确认儿童救生衣、上下船的高差和遮阳条件。行动不便者可在出发前向管理方询问栈道连续性、坡度及近期维修路段，或选海边车辆可达的短程观景点。观察长鼻猴时听从向导，保持距离，让船停在合适水域。

## 行前核对

- 出海前向运营方确认乘客或车辆票、出发码头、对岸落客点及末班安排。
- 红树林预约要写明 Graha Indah 或 Margomulyo，并按当日潮水、天气和设施情况选船游或步道。
- 叫车时区分机场、Semayang 长途港、Kariangau 车渡码头和 Kampung Baru 快艇码头。
