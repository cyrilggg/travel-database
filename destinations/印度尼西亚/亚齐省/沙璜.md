# 沙璜旅行指南

沙璜坐落在苏门答腊岛北端外海，市区沿韦岛北部的港湾展开。早市上摆着渔获，街边小店把章鱼穿成串，烤熟后浇上酱汁。越过林木覆盖的山坡，东岸的沙滩迎向晨光，西北岸的村落隔海望着鲁比亚岛，船夫从岸边载人去看珊瑚。岛上的「零公里」纪念碑，也让印尼人形容国土跨度时常说的「从沙璜到马老奇」有了具体的起点。

> 建议停留：2–3 天，往返渡船与岛内车程分别留时间\
> 旅行关键词：韦岛、港市早市、苏穆尔蒂加海滩、伊博伊、鲁比亚岛、章鱼沙嗲\
> 主要体力：市区可短走，滩岸有台阶和湿滑礁石，浮潜需适应水流\
> 最近研究：2026-11-24

## 城市速览

| 旅行重点 | 地点与安排 |
|---|---|
| 沙璜与韦岛 | 沙璜（Kota Sabang）是行政市，韦岛（Pulau Weh）是主岛，沙璜老城区在岛北岸 |
| 主要登岛门户 | 班达亚齐 Ulee Lheue 港出发，到韦岛南部 Balohan 港下船，再分车去市区或海滩 |
| 看东岸 | 市区早市与 Sumur Tiga 海滩可串成半天，适合陆上看海 |
| 看珊瑚 | 先沿公路去 Iboih 村，再视海况乘小船去鲁比亚岛附近水域 |

## 城市格局与游览区域

**北岸市区与东岸沙滩**　这里的市区指沙璜老城、市场和北岸港湾一带。Sumur Tiga 位于市中心以东约 4 公里，适合吃过早餐后短程乘车去看海。

**南部客运港**　从苏门答腊主岛抵达的客船停靠 Balohan。买票时目的地常只写「Sabang」，住宿接送应约在 Balohan 所乘船型的到达处。北岸城区的老港和游轮码头是另外的位置。

**西北岸**　Gapang 与 Iboih 分属沿海公路上的不同落脚点。市区到这一带沿公路约 20 公里。Pulau Rubiah 是 Iboih 对面的小岛，岛上小船行程与往返班达亚齐的大船分别安排。

## 主要景点

- **沙璜早市与老城**　围绕市场看岛上日常的食材供应，买点心或找早餐。随后到北部港湾看岸线，和下午前往的外海沙滩形成两种截然不同的沿岸景象。
- **苏穆尔蒂加海滩（Pantai Sumur Tiga）**　白沙滩位于韦岛东岸，沿岸住宿和餐厅各有通往海边的道路或阶梯。想看日出可以住在这一侧，进入海水前先问当日浪况和适合下水的位置。
- **伊博伊与鲁比亚岛（Iboih、Pulau Rubiah）**　村里可找船和浮潜装备。海底珊瑚集中在若干水域，按当天流速与能见度由当地人员选点；只想观景可问有无玻璃底船。约船时先写明是否上岛、停靠时长、装备与回程。
- **零公里纪念碑（Tugu Kilometer Nol）**　从 Iboih 还要乘车沿林地道路往西北。纪念碑象征印尼从西到东的国土跨度，适合作为海边活动后的陆上停靠点，提前约好返程车辆。

## 美食与餐饮

沙璜常见的 sate gurita 是章鱼沙嗲，将章鱼切块穿签，烤好配酱汁。市区还可找亚齐香料面 mie Aceh、当天的烤鱼和米饭。海边小店用餐时先问当日鱼种、份量以及是否按重量计价；清晨赶船可请住处提前准备早餐。

## 经典行程

**两天看港城与一片海**　首日上午从班达亚齐乘船到 Balohan，先去市区放行李、吃午餐，再到东岸 Sumur Tiga 散步。次晨逛市场，若船班较晚可再到北岸港湾，随后提前乘车回南部客运港。准备从苏门答腊搭早班飞机的人可在前一晚先过海。

**三天加西北岸**　把第二天完整留给 Iboih。上午乘车到村里，依海况选小船和浮潜，午后可顺道去零公里纪念碑。第三天从住处直接约车回 Balohan。风浪使海上活动取消时，保留村落、林间公路和岸上观景，返程先确认大船运行。

## 住宿区域

住市区方便逛早市、晚餐和购买日用品，第二天可分向东岸或西北岸出发。Sumur Tiga 适合看日出，订房时问到房间和沙滩各有多少级台阶。以浮潜、潜水为主，可住 Iboih 或 Gapang，托住处提前约好 Balohan 的接船及离岛车辆。

## 市内交通

| 区段 | 交通与衔接 |
|---|---|
| 班达亚齐至韦岛 | 在 Ulee Lheue 登船，过海到 Balohan。Express Bahari 的快船表定约 45 分钟；携带车辆需另查可载车的慢船、车位及报到规则。陆侧行程可接[班达亚齐旅行指南](./班达亚齐.md)。 |
| Balohan 至市区或住宿 | 预订酒店接送、包车或在港口谈好接驳，写清市区、Sumur Tiga、Gapang 或 Iboih。船只抵港后还要沿岛内公路行驶。 |
| 市区内与跨区 | 市区短段适合步行，跨海湾以约车或当地机动三轮车为主。往零公里纪念碑可议定往返，保存司机联系方式。 |
| Iboih 至鲁比亚 | 到村内小船出发点另办船位，确认救生衣、登船踏步和回程集合点。 |

## 不同旅行者须知

同行者水性差异较大时可分别选岸上停留、玻璃底船或有向导的浮潜，按体型试穿救生衣。在珊瑚区保持浮力，双脚和脚蹼与珊瑚留出距离。进入村庄、市场或宗教场所时穿好遮肩及膝的衣物；出发前向住处询问星期五礼拜前后的餐饮和水上活动时间。

## 行前核对

- 按方向查快船或车辆渡轮，保存船班、码头名称和报到时间。遇天气变化以港务部门及运营商的实际放行为准。
- 返程先安排从具体海滩到 Balohan 的车辆，再确认 Ulee Lheue 到班达亚齐机场或市区的车程。
- 下水活动按当天海况选区域，和船家核对设备、集合点、费用及天气取消安排。
