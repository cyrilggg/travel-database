# 棉兰旅行指南

棉兰位于苏门答腊岛东北部平原。德里苏丹的王宫以明黄为主色，附近的大清真寺将黑色穹顶托在浅色立面上。向北走进 Kesawan 老商业区，华商宅院的天井和临街店屋又讲述了另一段城市史。今天，人们仍会专程来吃一碗椰奶香浓的棉兰汤，离城时再带上一盒切开后布满细孔的金黄色蜂窝糕。

> 建议停留：1–2 天\
> 旅行关键词：马来王宫、华商宅院、苏门答腊饮食、老商业街\
> 主要体力：市区分两段步行，炎热或阵雨时宜缩短街面行程\
> 最近研究：2026-11-23

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 初次来访 | 将苏丹王宫与张阿辉故居各留一个时段，比较王室接待空间和商人家庭住宅 |
| 停留 | 一天可走南北两处核心片区；两天可放慢用餐和看馆节奏，第三天适合开始独立的高地行程 |
| 天气 | 平原湿热，上午走街，午后安排室内讲解和坐下吃饭。遇强降雨时跨区乘车 |
| 花费 | 宅院门票含馆方讲解，王宫和接送分别预算；市区车辆与机场列车可按人数、行李组合 |

## 城市格局与游览区域

棉兰站（Stasiun Medan）附近是市中心的交通起点。由车站往 Kesawan 走，Jalan Ahmad Yani 一带的商铺与张阿辉故居适合连访。往南到迈文宫与马斯吉德拉亚大清真寺，则进入与德里苏丹国相关的片区。两个片区各自适合步行，跨区时把路口、雨势和等车都计入时间。

瓜拉纳穆机场（KNO）在棉兰以东的德利沙登县。布拉士打宜（Berastagi）在市区以南的高地，多巴湖又有自己的沿湖城镇和渡口；以棉兰为出发点安排跨城旅程时，应先确定下一晚住在哪里。

## 美食与餐饮

Soto Medan 是认识当地口味的好起点，椰奶与香料让汤底浓厚，搭配鸡肉或其他配料和米饭，各店做法不同。需要清真餐食时，可向店家确认标识与做法；从老商业街换到王宫一带用餐，菜单的肉类和烹调传统也会变化。

Bika ambon 虽然名字里有 Ambon，却是棉兰著名的伴手礼。糕体有细长的蜂窝孔和柔韧口感，先尝原味再挑整盒更便于比较。若隔天飞行，可把采购安排在回酒店前，核对生产日期和包装。

## 经典行程

| 场景 | 路线与取舍 |
|---|---|
| 初访一日 | 上午参观迈文宫，按礼拜安排短访大清真寺。午餐后乘车去 Kesawan，先留足故居讲解时间，再走周边商街 |
| 两日慢游 | 首日集中在王宫、清真寺和当地餐馆，傍晚休息。次日上午从棉兰站附近进入商业区看宅院，午后买糕点或搭机场列车 |
| 三日含高地 | 前两天保留市区行程，第三天上午出发去布拉士打宜并在高地留宿；想继续多巴湖可在后续日期接上湖区交通 |
| 大雨或炎热 | 先预约或确认故居讲解，把较长时间留在室内，再找一处餐馆吃午餐。道路积水或强降雨时取消额外街段 |
| 亲子与低体力 | 住站区附近，只走故居与附近一小段街。下午用车到王宫看开放接待厅，带推车者先确认台阶与寄存安排 |
| 建筑专题 | 上午看王宫和清真寺的轴线、柱廊，午后在华商故居看天井与二层空间，最后从街对面回看店屋立面 |

## 住宿区域

| 区域 | 适合谁 | 订房取舍 |
|---|---|---|
| 棉兰站／市中心 | 接机场铁路、首访或短暂停留 | 看清酒店在车站哪一侧，拖行李时按实际出口和过街位置估算 |
| Kesawan 周边 | 想早晨步行逛老街、看故居 | 确认下车入口和夜间餐饮位置，主干道沿线可询问房间朝向 |
| 机场附近 | 深夜抵达或清早航班 | 与市区游览分成两段，先确认接送时段及具体航站楼集合点 |

## 市内交通

从 Kualanamu 搭机场铁路到 **Medan** 站，可在运营方时刻表选 Medan 地区，然后按机场至市区或反方向查班次。线路同时服务其他站点，买票和上车都核对始发、终到与日期。从市中心酒店到车站另留道路拥堵与进入站厅的时间。

在 Kesawan 内步行看宅院和店屋，王宫区则以迈文宫和大清真寺为一组。跨区可通过住宿方或叫车服务确认上客点，输入具体景点入口会比只输入街区名清楚。去湖区或高地时向运营方核对接人地点、终点与中途换车安排。

## 不同旅行者须知

张阿辉故居有上下两层，希望减少台阶时可先向馆方确认首层路线。带孩子听讲解，可以从天井的位置、接待客人的厅堂等具体细节开始。参观清真寺先确认当日礼拜和访客区域；拍摄礼拜者或居民时先征得同意。

## 行前核对

- 故居常规参观为 9–17 时，最晚入场 16:30；农历新年初一另排其他行程。
- 王宫开放范围和清真寺访客时段出发前再问，宗教节庆期间给用餐与交通留出更多时间。
- 到机场同时核对铁路方向、末班与航班报到时间。跨城去多巴湖另查最终目的地和船班。
