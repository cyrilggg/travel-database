# 印度尼西亚旅行目的地

在爪哇岛上，日惹与梭罗可以串起两座宫廷城市。苏门答腊的巴东和武吉丁宜分居海岸与高地；苏拉威西的马卡萨在岛的西南部，万鸦老在北端，两地要分别安排交通。中雅加达篇聚焦首都特区的中央行政市。

## 组合与行前准备

从日惹去梭罗，可查 Yogyakarta–Palur 通勤铁路的 Solo Balapan 站，再换市内交通前往宫廷区。按出发日期核对去回两程，尤其是当日往返时的末班车。[KAI Commuter 日惹线站序与时刻表](https://www.commuterline.id/files/download/documents/Jadwal%20Commuter%20Line%20Yogyakarta%20-%20Prameks.pdf)

从新加坡乘船去[巴淡](./廖内群岛省/巴淡.md)，订票时先按住宿位置选码头；到[马塔兰](./西努沙登加拉省/马塔兰.md)后若要继续去吉利群岛，则还要安排前往龙目岛西北岸码头的陆路交通。

跨城时按具体机场、铁路站或码头计算抵离时间；当天开放、预约、班次及天气通过各篇官方入口确认。
