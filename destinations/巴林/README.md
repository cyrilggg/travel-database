# 巴林旅行目的地

麦纳麦的老市场在巴林门后方，国家博物馆则在滨海一侧。跨桥到穆哈拉格，采珠业的历史从商人的庭院延伸到珍珠渔船昔日出航的海岸。两城适合各留一段步行时间，预订接送车时写明所在城市和建筑名称。

| 地区 | 城市指南 | 旅行主题 |
|---|---|---|
| [首都省](./首都省/README.md) | [麦纳麦](./首都省/麦纳麦.md) | 首都老市场、博物馆与港湾 |
| [穆哈拉格省](./穆哈拉格省/README.md) | [穆哈拉格](./穆哈拉格省/穆哈拉格.md) | 采珠商宅、老市集与海岸堡垒 |

## 从哪里走采珠之路

想先看老城住宅与市场，可从盖萨里耶市场附近的采珠之路游客中心开始；想先了解渔船出海的海岸地形，则从布马希尔堡游客中心看起。这是两个不同的入口，约车时可直接使用官方地图上的英文名称。[采珠之路参观指南](https://pearlingpath.bh/en/visitor-information/)
