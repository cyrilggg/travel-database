# 沙特阿拉伯旅行目的地

利雅得和邻近的德拉伊耶适合一起读：前者从市场和博物馆认识今天的首都，后者沿哈尼法谷地参观纳季德土建筑。西部以吉达为红海门户；麦加的行程面向穆斯林旅客，塔伊夫则从海岸转入山地。若以考古和绿洲为主，西北的埃尔奥拉与东部的胡富夫相距遥远，宜分别安排。

## 在吉达接哈拉曼高铁

从吉达前往麦地那，或由穆斯林旅客前往麦加，购票时先选出发站。住在吉达市区可查 Sulaymaniyah 站；从阿卜杜勒阿齐兹国王国际机场转车，则查机场站。两站都服务吉达，接机、订车和买票时要写清站名。[沙特铁路线路说明](https://www.sar.com.sa/about-sar/railnetwork/)
