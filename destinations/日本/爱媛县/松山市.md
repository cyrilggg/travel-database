# 松山市旅行指南

松山是四国西北部的爱媛县首府。城堡坐在胜山山顶，山下的商店街和路面电车围着城山展开，站在本丸石垣旁便能看出街区的走向。电车到了东北侧的道后，车站与木造浴场之间的小街成了人们穿浴衣散步的地方。生于松山的正冈子规把明治时代的风物写进俳句，今天的市内电车、温泉街和文学展馆仍保留着这座城与诗歌的联系。

> 建议停留：2–3 天\
> 旅行关键词：山城、公共汤屋、俳句、有轨电车、鲷鱼饭\
> 主要体力：城山有坡道与陡梯，道后街区可短段步行\
> 最近研究：2026-11-23

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 初访 | 上午上松山城看城郭与市区，傍晚到道后泡汤，隔天再看温泉街和子规作品 |
| 时间 | 一天可走山城与温泉双主线，两天能留出文学馆和道后公园的时间 |
| 花费 | 本丸广场免费，天守、上下山交通和道后浴场分别购票 |
| 天气 | 雨天单人吊椅停运，优先查箱式缆车；石阶潮湿时改到山下商店街或文学馆 |

## 城市格局与游览区域

高处的松山城是辨认市区方位的地标。从城山东南的大街道电车站出发，向北沿登城商店街走到东云口缆车站，南面则是有顶购物街。城西的 JR 松山站连接四国铁路；市中心偏西南的松山市站属于伊予铁，两站各有自己的站前电车站和巴士停靠点。

道后温泉在城东北，从市中心搭电车到终点，道后温泉站和本馆之间以商店街相连。道后公园、松山市立子规纪念博物馆在温泉街旁，是另一组可连走的地点。松山观光港则在市区西北海岸，搭海路离开要给港口接驳留时间。

## 美食与餐饮

在松山点鲷鱼饭（鯛めし），先看菜单写的是哪种做法。松山北条一带把鲷鱼和米放进锅里同煮，拆鱼后将鱼肉拌回饭中；爱媛南部宇和岛式则把生鲷鱼片和调味汁拌到热饭上。两种做法在市区都有机会尝到，想吃熟鱼时可认“炊き込み”字样。

大街道与登城商店街适合下山后吃午餐，点一份釜饭时可问需要等候多久。道后商店街有爱媛柑橘点心和果汁，住宿已含晚餐的旅客适合分食小份，把泡汤和正餐之间的时间放宽。

## 经典行程

| 场景 | 建议走法 |
|---|---|
| 初次一日 | 上午从大街道上松山城，午餐回登城街。下午搭路面电车去道后，看本馆即时等候时间，再决定先泡汤还是先逛商店街 |
| 两日经典 | 首日走山城、大街道与中心商业街。次日上午参观子规纪念博物馆，午餐后走道后公园，下午选择一座浴场 |
| 三日慢游 | 在两日线上给道后留一晚，另一天把城山的本丸与山脚护城河分开慢走。海路离开时，把最后半天留给取行李与观光港接驳 |
| 雨天 | 上午去文学馆，下午走道后商店街和浴场。雨停时再查城山缆车，遇大风或湿滑时保留山下观景 |
| 亲子与低体力 | 上山乘箱式缆车，从长者平按同行者体力分段走；本丸广场是合适的折返点。道后另择半天，事前确认浴池入口台阶 |
| 文学主题 | 上午进子规纪念博物馆，午后在道后公园慢走，沿商店街到道后温泉站。想乘“少爷列车”时，按其独立运营日与票务安排 |

| 区域 | 适合谁 | 订房时留意 |
|---|---|---|

## 市内交通

市内路面电车串联大街道、JR 松山站前、松山市站前与道后温泉。上车前看车头终点和站牌线路，尤其是从城山返回车站时。松山城箱式缆车与单座吊椅均由东云口到长者平，吊椅有年龄与天气条件；从山顶车站到天守还要穿过城门与坡道。

松山机场到市区查伊予铁机场巴士，常见停靠包括 JR 松山站前、松山市站、大街道和道后温泉。去松山观光港则另查港口巴士或轨道加接驳线路。机场巴士、普通电车、观光少爷列车各自售票，按实际行程比较通票范围。

## 不同旅行者须知

轮椅使用者上城前可向东云口站确认同行协助、山顶站助力轮椅及归还时间。城方建议由同行者协助通过下车后的坡与阶梯，本丸和天守应分开评估。带学龄前儿童家庭上山选箱式缆车；预约道后私室时，先核对票种包含的浴池和休息空间。

## 行前核对

- 分别查看松山城天守、缆车与吊椅的当日运行，冬季注意下山末班。
- 道后本馆普通入浴、休息席和预约私室条件不同，出门前看官网即时等候和当月休馆公告。
- 对照 JR 松山站、松山市站与观光港的实际出发位置，再确定机场或船班接驳。
