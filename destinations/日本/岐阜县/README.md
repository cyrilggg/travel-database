# 岐阜县旅行目的地

徒步中山道可以跨县进出。岐阜县一侧从中津川站乘巴士到马笼宿，翻过马笼峠进入长野县，走到妻笼宿后可换巴士前往南木曾站。单程徒步要按出山一侧的巴士班次倒推起步时间。[岐阜县旅游局中山道线路图](https://cdn.visitgifu.com/wp/2020/09/0aae3320-202009gifunakasendo3d2n.pdf)
