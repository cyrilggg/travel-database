# 山形县旅行目的地

米泽和山形在内陆的山形新干线上。鹤冈与酒田则在日本海一侧的庄内平原，可沿羽越本线连游。订住宿前先确定要走内陆城下町还是沿海港市。 [JR 东日本车站时刻表](https://timetables.jreast.co.jp/)
