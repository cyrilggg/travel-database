# 富山市

富山位于本州北陆，平原向北一直延伸到富山湾，晴朗时从市内就能望见东面的立山连峰。昔日北前船在岩濑靠港，船主宅邸与装卸货物的仓库至今排在老街两旁；市中心的电车则从城址边穿过，把玻璃美术馆和商店街连在一起。车站售卖的鳟鱼寿司仍用竹叶包裹，把盐渍鱼、醋饭和北陆铁路便当的传统装进一盒。

> 建议停留：1–2 天，立山黑部山岳交通另留完整一日或山中住宿\
> 旅行关键词：玻璃艺术、城址、富岩运河、岩濑港与富山湾海产\
> 主要体力：中心区和环水公园以平地步行为主，跨区有电车，冬季留意积雪\
> 最近研究：2026-11-23

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 初次到访 | 从站南的富山城和玻璃美术馆认识城下町，再去站北看运河怎样通向海港 |
| 停留 | 一天适合市中心加环水公园；两天可沿富岩运河或电车线去岩濑看北前船留下的港町 |
| 季节 | 空气通透时，站北的运河沿岸可望见立山连峰；冬日可把室内馆舍作为主线。游船、屋顶花园和立山山路各有季节 |
| 花费 | 公园与岩濑街面可自由散步，两座美术馆、游船、电车和山岳交通各按所选项目计费 |

## 城市格局与游览区域

北陆新干线富山站是中心城区的分界点。站南有富山城址公园、总曲轮商店街与位于西町的 TOYAMA KIRARI，市玻璃美术馆就在其中；站北是富岩运河环水公园与富山县美术馆。这两处美术馆分在铁路两侧，常设展内容和休馆日分别安排。

运河从环水公园向北通往岩濑。岩濑是富山市临富山湾的港口街区，老船商宅邸与仓库沿传统街道分布。立山黑部阿尔卑斯山脉路线的西侧门户“立山站”则在立山町；市区可远看群山，真正上山要从电铁富山站衔接地方铁路及季节性山岳交通。

## 美食与餐饮

鳟鱼寿司（ます寿し）将盐渍、醋调的鳟鱼或樱鳟压在米饭上，用竹叶包住，常做成圆形再切块分食。它在北陆铁路便当中流传已久，适合到站后试吃小份，也适合买作列车上的一餐。各家鱼片厚薄、酢味与压制方式略有差异，想比较时可在市区专门店挑不同份量。

富山湾的白虾常见于寿司与炸物，也可在当季菜单上留意萤乌贼等海产。偏爱热食的人可以尝汤色深、酱油味浓的富山黑拉面。站内餐饮便于赶车，岩濑的仓库餐厅适合配合街区散步，提前核对当日营业与回程电车。

## 经典行程

| 场景 | 路线与取舍 |
|---|---|
| 一日城下町 | 从富山站往南看城址与乡土博物馆，午后在总曲轮用餐并逛玻璃美术馆。回车站后到北口环水公园走一小段，晚上在站区吃寿司 |
| 两日山海城市 | 首日走站南城址、商店街和玻璃美术馆；次日上午看县美术馆与环水公园，午后到岩濑。航季可船去、电车回，冬季用电车往返 |
| 三日含立山方向 | 前两日按市区线，第三日只在当季山岳交通开放时从电铁富山站经立山站上山。事先定终点与回程，跨越山脉去长野一侧需连同住宿和行李另作安排 |
| 雨雪或停航 | 集中游站南的一座馆与有顶商店街。另一天按周休日选县美术馆或乡土博物馆；想去岩濑时改搭电车，街区只走较易通行的短段 |
| 亲子与少步行 | 从环水公园短走至县美术馆，先看一个展区，再视天气决定是否进屋顶庭园。用半天走这一片，站南景点另择时段乘电车直达 |
| 港口与水利专题 | 从环水公园乘经过船闸的航线到岩濑，午餐后沿港町街道看商家与仓库。若想专门看船闸操作室，订票时选注明此内容的线路 |

## 市内交通

从北陆新干线富山站可直接转市内电车。去玻璃美术馆可选往南富山站前方向、在“西町”下，或乘环线在“Grand Plaza 前”下车；到岩濑则查往“岩濑滨”的富山港线，依目的地选东岩濑或岩濑滨等站点。富山机场与市区之间可搭富山地方铁道公司的机场巴士，按酒店位置选择市中心或富山站下车。

富岩游船有环水公园到岩濑、反向及中途折返等区别，预订时先看终点，再看票内是否含电车回程。上立山需要另外确认电铁富山至立山、立山缆车与高原巴士等各段班表。11 月后段可能因降雪暂停富山侧高原巴士，即便市中心晴朗，也应按运营方山上公告决定出发。

## 不同旅行者须知

少步行者可将市区分成站南和站北两天，每天以一馆一段街区为主。冬季从车站到公园留出雪地步行时间，带孩子使用屋顶庭园前先看当日开放状态。需要无台阶上下船或搭电车时，先将所选码头、车次与移动辅助设备类型告知运营方确认。

## 行前核对

- 分别查询市玻璃美术馆、县美术馆和乡土博物馆的休馆与换展日，屋顶另有冬休。
- 按游船具体航季、维护日和终点订票；旧船商宅邸按各馆当天公告参观。
- 山岳线路另查开放季、预约、天气与首末班，富山站和立山站之间单列铁路时间。
