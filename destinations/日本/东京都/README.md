# 东京都旅行目的地

东京都既包含高度密集的 23 区，也包括多摩地区和岛屿。东京城市指南以 23 区主要旅行片区为核心，把多摩远点和山地目的地作为独立半日或一日安排，不把整个行政区域写成可连续游览的市中心。

## 城市指南

| 城市 | 旅行重点 | 建议停留 | 状态 | 最近研究 |
|---|---|---:|---|---|
| [东京](./东京.md) | 传统街区、博物馆、神社寺院、都市景观与多中心餐饮 | 3–5 天 | `researched` | 2026-07-30 |

## 区域格局与城市组合

东京适合按东部旧城区、中央商务与购物区、西部副都心、湾岸和多摩方向拆分。一天通常安排一个相邻片区组合；跨城反复移动会显著增加车站步行和换乘负担。
