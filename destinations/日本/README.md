# 日本旅行目的地

日本城市旅行常以铁路网络串联，但不同都市圈、岛屿和山区的尺度差异明显。国家页只提供导航与全国性核对入口，具体移动方式见城市指南。

## 跨区域旅行概览

大城市之间通常可比较新干线、常规铁路、航空和长途巴士；总耗时应计入前往车站或机场、换乘和行李处理。票制、指定席、行李规则和通票适用范围都可能调整，应在购买前核对运营方。
