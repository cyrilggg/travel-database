## 跨区域旅行概览

从[北九州市](./福冈县/北九州市.md)的门司港可以乘船到[下关市](./山口县/下关市.md)唐户，两岸适合安排在同一天。游琵琶湖东岸时，可把[彦根市](./滋贺县/彦根市.md)的城郭和[长滨市](./滋贺县/长滨市.md)的老街用铁路串联，按车次确认是否在米原换乘。[关门汽船时刻表](https://www.kanmon-kisen.co.jp/route/kanmon.html) · [滋贺县交通指南](https://www.biwako-visitors.jp/access/)

大城市之间通常可比较新干线、常规铁路、航空和长途巴士；总耗时应计入前往车站或机场、换乘和行李处理。票制、指定席、行李规则和通票适用范围都可能调整，应在购买前核对运营方。
