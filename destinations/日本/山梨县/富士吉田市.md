# 富士吉田市

富士吉田市在富士山北麓。上吉田街头的金鸟居横跨马路，过去结伴登山参拜的人从这里走进御师町，在御师家吃饭、投宿、祈愿，再往山上走。下吉田靠织造业兴旺起来，街边至今能找到布店和卖硬乌冬的小馆。隔着一排排屋顶望向南面，富士山正对着本町的大街；回头登上新仓山的坡地，又能看见这座织物小城如何铺展在山脚下。

> 建议停留：半天看下吉田，一天可兼顾上吉田御师町  
> 旅行关键词：新仓山浅间公园、御师町、织物、吉田乌冬  
> 主要体力：市街缓坡步行，新仓山展望台需连续爬阶  
> 最近研究：2026-11-24

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 第一次来 | 山色清楚时，先从下吉田站上新仓山看忠灵塔，再回街区吃午饭；云层较厚时，御师旧宅和织物街也值得专程看 |
| 两座车站 | 下吉田站方便去新仓山与本町；富士山站方便去金鸟居、御师町，并可转车去北口本宫 |
| 时节 | 春季樱花与秋季红叶吸引较多人，展望台和石阶要留出等候时间；冬季早晚留意台阶结冰 |
| 延伸方向 | 河口湖站在邻近的富士河口湖町。湖畔散步、游船或住宿可另排半天以上 |

## 城市格局与游览区域

| 片区 | 怎样走 |
|---|---|
| 下吉田站与新仓山 | 从车站依指示去山坡上的新仓山浅间公园。新仓富士浅间神社在这段参观动线上，忠灵塔及展望台位置更高 |
| 下吉田本町通 | 从坡地回到市街，沿人行道看老招牌、布店与沿街展开的山景。这里是车辆照常行驶的生活街区 |
| 上吉田与御师町 | 富士山站附近的金鸟居是街头地标。沿御师町走，可以从街道转入旧外川家细长的宅地，看昔日接待登山信众的房屋 |
| 北口本宫一带 | 北口本宫冨士浅间神社位于上吉田靠山的一侧，与新仓山的神社相隔一段市街，从富士山站一带转巴士更省力 |

## 主要景点

**新仓山浅间公园与忠灵塔。** 从下吉田站跟随观光协会公布的步行路线进山，经过神社后沿「咲くや姫階段」攀登398级台阶。常见照片里五重塔形的建筑是纪念战争死者的忠灵塔；展望台位于塔后上方，天气合适时，富士山、城区与塔可以同框。山腰的展望台已经能看到全景，继续走往新仓山山顶则是另一路徒步。[官方步行路线](https://www.fujiyoshida.net/course/index.php?p=course-365) · [园区介绍](https://fujiyoshida.net/spot/index.php?p=12)

**金鸟居与御师旧外川家住宅。** 从大鸟居往山的方向走，留意主街向内延伸的小路。旧外川家保留了接待富士讲信众的客室和祭祀富士山神灵的空间，同一屋檐下既能投宿也能礼拜。主屋始建于1768年，配合宅内古文书，比只看街道外观更容易理解御师的工作。[旧外川家住宅](https://fujiyoshida.net/spot/index.php?p=26)

**北口本宫冨士浅间神社。** 沿林中参道走过石灯笼，再到鸟居、社殿，是传统吉田口登拜路线在山脚的重要一站。先看过御师住宅再来，可以把信众投宿、参拜和启程登山的先后串起来。只游神社可在当日返回富士山站。[御师町与北口本宫路线](https://www.fujiyoshida.net/course/index.php?p=course-371)

## 美食与餐饮

吉田乌冬（吉田のうどん）的面条厚实有嚼劲。常见的一碗配汆熟卷心菜和甜咸马肉，汤底可用味噌、酱油调和；桌上的「すりだね」由辣椒等香料制成，先尝原汤再少量加入。当地把这碗耐饱的午餐与织工的生活联系在一起。许多面馆集中在午间营业，适合从新仓山下来就去，点肉乌冬前可确认肉类。[富士吉田观光协会乌冬专题](https://fujiyoshida.net/feature/index.php?p=udon)

## 经典行程

| 时间 | 走法 |
|---|---|
| 半天看山与街景 | 下吉田站 → 新仓山浅间公园、忠灵塔 → 原路下山 → 本町通、乌冬午餐。时间紧时到山腰展望台折返 |
| 一天看两片街区 | 上午走下吉田路线，午后乘车到富士山站，走金鸟居与旧外川家，再搭巴士去北口本宫；先查神社回站的班次 |
| 天阴或行动不便 | 以富士山站为起终点，参观御师旧宅、在街区用餐；按体力选下吉田平地商街或北口本宫参道 |
| 两天加河口湖 | 第一天留在富士吉田，第二天乘富士急行线到河口湖站，再按要去的湖岸转当地巴士 |

## 住宿区域

想赶早看展望台，可住下吉田站或本町通附近，清晨从住宿直接出发。需要转高速巴士、计划走御师町，可选富士山站周边，订房时核对车站入口与旅馆之间的步行距离。若想推窗看湖，应找富士河口湖町湖畔的住宿，并确认从河口湖站到旅馆的接驳。

## 市内交通

从大月方向搭富士急行线进入山麓，先按景点选择下车站，购票时再看具体列车的停靠站。富士山站位于市区，搭到这里仍在山脚。到北口本宫可查询前往「浅間神社前」一带的巴士；返程先记下站牌位置，避免沿国道找车。下吉田与富士山站之间若选择步行，往上吉田方向整体上坡。[市观光协会交通问答](https://fujiyoshida.net/about/index.php?p=qa)

## 不同旅行者须知

带幼儿或同行者膝盖不便，可分组登忠灵塔，在下吉田约好会合时间。摄影者在本町通应站在人行道内，把通勤车辆、路口信号和居民出入放在取景之前。想从吉田口登富士山的人需另外规划高山行程，依据出行年度官方通告确认开放期、预约及入山要求。

## 行前核对

- 看山前查看云量、园区通行公告和展望台等候安排，遇到大雾可先逛市街。
- 查旧外川家的开放日和最后入馆时间，确认午餐面馆仍在营业。
- 确认返程车票写的是下吉田站、富士山站还是河口湖站，按实际乘车点安排行李寄存。
