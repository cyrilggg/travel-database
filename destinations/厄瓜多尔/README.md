# 厄瓜多尔旅行目的地

基多、安巴托和昆卡都在安第斯山区。基多看沿山谷展开的旧城，安巴托逛市场、吃当季水果，昆卡则适合沿托梅班巴河散步。瓜亚基尔在西部低地，行程从山城转向瓜亚斯河畔时，衣着也要按海岸气候调整。
