# 加拿大旅行目的地

从多伦多沿安大略湖东行可到奥沙华，向西绕过湖头则到哈密尔顿。草原省份可按温尼伯、里贾纳和萨斯卡通分别查阅。纽芬兰的圣约翰斯位于岛东端，订票时认准 St. John’s。
