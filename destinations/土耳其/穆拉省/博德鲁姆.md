# 博德鲁姆旅行指南

博德鲁姆坐落在土耳其西南部伸向爱琴海的半岛上。港湾之间的岬角托起一座中世纪城堡，堡内陈列的玻璃器和船货曾随商船沉入海底。回到港边，传统木制帆船 gulet 至今仍与游艇并排停泊。在白色房屋后方，古剧场沿山坡展开，街巷下还保留着古城哈利卡纳苏斯的陵墓遗址。几段相距很远的历史，在这里共用同一片海湾。

> 建议停留：2–3 天\
> 旅行关键词：爱琴海港、沉船考古、古代陵墓、半岛海湾\
> 主要体力：港边较平缓，城堡与古剧场有高差，半岛海湾需乘车或船\
> 最近研究：2026-11-23

## 城市速览

| 项目 | 旅行信息 |
|---|---|
| 初访 | 从城堡的沉船展览走到今天的泊船港，再到古城遗址，能读懂港口跨时代的用途 |
| 停留 | 一天看老港与城堡，两天加入陵墓和古剧场；海湾度假或出海另留一天 |
| 季节 | 盛夏古迹地面曝晒，早间适合上城堡和剧场；淡季住宿与船班依各海湾实际营业情况安排 |
| 预算 | 城堡博物馆、陵墓和出海行程分别计费，港边散步适合短停留 |

## 城市格局与游览区域

城堡占据两座港湾之间的岩石岬角，入口在市中心 Çarşı 区。沿城堡西面的港岸走，岸边有传统木船和游艇；向东则是商业巷和近城海滨。古代哈利卡纳苏斯的摩索拉斯陵墓遗址在港区西北方的街巷内，古剧场还要往更高的山坡走。

Bodrum 也是整个半岛行政区的名称。比泰兹（Bitez）、居米什吕克（Gümüşlük）、亚勒卡瓦克（Yalıkavak）各有自己的海湾、餐馆与住宿。订酒店和船票时，用海湾或码头名计算接送路程，能避免把半岛另一端的地址当作中心港步行范围。

## 美食与餐饮

想尝本地菜，可找 Çökertme kebabı，细切脆薯条上铺肉和酸奶酱，适合逛过遗址后来一顿正餐。爱琴海餐桌常从几小碟 meze 开始，橄榄油蔬菜和酿西葫芦花都适合分食。点整鱼前问清按份还是按重量计价，再决定搭配多少前菜。

博德鲁姆也盛产橘子，甜品、果酱和冰淇淋里都能见到当地柑橘。老港午餐适合接城堡或陵墓；若特意去半岛西岸看日落，晚餐就近安排，并把返程交通与订位一起确定。

## 经典行程

| 场景 | 建议走法 |
|---|---|
| 初访一日 | 上午参观城堡与水下考古博物馆，在老港用午餐；下午去陵墓遗址，傍晚回水边看木船与城堡 |
| 两日城市与海湾 | 首日走港区与考古馆，次日上午看陵墓和古剧场，下山休息后乘车去比泰兹，晚餐后回城 |
| 三日慢游 | 前两日各留半天给城堡、古迹和近城海湾。第三天按风浪选船游或到居米什吕克，给还船、上岸和返程留足时间 |
| 周一到访 | 把城堡作为主馆，午后走港边与街巷；陵墓遗址移到次日上午，再去古剧场 |
| 高温或有风 | 早间先走露天古迹，午间选城堡开放的室内展厅或在港边用餐。风浪影响船班时改走陆路到海湾 |
| 亲子或少步行 | 在码头观察木船和城堡全貌，进馆前选定最想看的沉船展区，按石阶与体力缩短路线，另一天再安排海湾 |

## 住宿区域

| 区域 | 适合谁 | 订房取舍 |
|---|---|---|
| 城堡与中心港 | 首次到访、参观博物馆、短住 | 海滨商业街晚间较热闹，可按具体巷口和客房朝向选房 |
| 比泰兹 | 想在海湾休息又兼顾城区 | 住处到海边与往返市中心是两段路，各自查距离 |
| 西部、北部海湾 | 长住、游艇或海滨度假 | 核对机场接送、船游集合点和返程车次，跨半岛移动单独计时 |

## 市内交通

中心港与老街适合步行。去古剧场须上坡，低体力者可乘车到入口后从较低座席观看。到半岛各湾查目的地名对应的公交或小巴线路；船游票面注明的码头比“博德鲁姆出发”更能确定实际接人地点。

米拉斯–博德鲁姆机场（BJV）位于中心城区之外。机场列有 Havaş、MUTTAŞ 巴士和出租车等选择。机场巴士抵达的汽车站与具体海湾旅馆往往还隔一程，确认航站楼、当班停靠站和接机门牌后再预订。

## 不同旅行者须知

参观城堡要在室内展厅、庭院和台阶之间移动，使用轮椅或推车的旅客可向馆方确认当日可达展区。喜欢考古的人可先看一组有明确年代的船货，再到陵墓与古剧场比较陆上的遗存。带孩子出海前确认船上遮阴、救生设备与返港时间。

## 行前核对

- 查城堡白天、夜间与个别展厅开放情况，陵墓另查周休和最晚购票时刻。
- 船票核对登船港和返港时间。住半岛另一侧时，单独安排往返码头的车辆。
- 前往机场前，按所乘航班和承运方确认市区汽车站位置与发车时刻。
