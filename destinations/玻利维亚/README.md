# 玻利维亚旅行目的地

拉巴斯的缆车把山谷里的街区接到埃尔阿尔托高原。若从东部低地的圣克鲁斯抵达，再往科恰班巴、苏克雷和拉巴斯走，每站的海拔与气温都不同。想看独立史可把时间留给宪法首都苏克雷，逛市场、吃山谷菜则可在科恰班巴多住一晚。
