# 马尔代夫旅行目的地

坐船靠近马累时，临水的楼群和渔港先于沙滩映入眼帘。南部的阿杜和福阿穆拉则是两种不同的岛上生活：阿杜的部分居民岛由堤道串联，福阿穆拉的居民区和淡水湖集中在一座岛上。订住宿时先看岛名和抵达机场，再决定该留多少时间转车或转船。

## 晚班机抵达后的第一晚

先请住宿方按国际航班的落地时间确认接驳。通过 Trans Maldivian Airways 转水上飞机的旅客由合作度假村预约，航班在日出至日落之间运行。赶不上当天接驳时，可在马累一带住一晚，约好次日集合点；若接国内航班，则按机票核对目的机场，再确认机场到住处的最后一段。[水上飞机运营方转机说明](https://www.transmaldivian.com/faq/)
