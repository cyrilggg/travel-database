# 柬埔寨旅行目的地

暹粒的吴哥寺院群与马德望的河岸老城可以串成一段西部行程。从金边向南，贡布适合住河边、探访胡椒产区，白马以螃蟹市场和近岸小岛见长；前往高龙岛则从西哈努克市衔接客船。

## 组合与行前准备

从金边出发，铁路南线沿途设白马、贡布等站，通往西哈努克市。车站、海滨旅店和离岛客船各有自己的位置。计划当天换船时，先核对抵达车站和船票上的具体码头，再预留从车站到港口的车程与报到时间。[柬埔寨皇家铁路客运线路](https://www.royalrailway.com.kh/passenger_train)
