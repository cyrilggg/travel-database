# 智利旅行目的地

从圣地亚哥向西到海岸，可把瓦尔帕莱索的山坡港区和比尼亚德尔马的花园、海滩排在同一段行程。北部从阿里卡接秘鲁塔克纳；南部前往湖区时先确认机场和落脚城，去麦哲伦海峡则另查蓬塔阿雷纳斯的航班和船期。
