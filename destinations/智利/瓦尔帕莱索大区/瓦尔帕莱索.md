# 瓦尔帕莱索旅行指南

瓦尔帕莱索的街道从太平洋港湾爬向环抱海岸的山坡。十九世纪远洋贸易兴盛时，海军建筑、商行和码头沿着岸边窄长的平地排开，住宅则在上方逐层叠起。当地人修了沿斜轨运行的升降机，让山腰小广场与山脚商业街有了捷径。如今在坡上的巷道里穿行，转过彩色铁皮屋和壁画，房屋之间就能望见港池与作业中的船只。

> 建议停留：1–2 天，港区与山坡街区一天，邻城比尼亚德尔马另排半天至一天\
> 旅行关键词：太平洋港口、坡道升降机、彩色铁皮屋、山坡步道、码头广场\
> 主要体力：港区平地便于短步行，山坡街巷有长阶和陡坡，升降机只覆盖部分高差\
> 最近研究：2026-11-24

## 城市速览

| 旅行兴趣 | 合适的地点 |
|---|---|
| 看传统港城如何布局 | 由索托马约尔广场走向普拉特码头，从广场轴线看海军建筑、铁路与海港的距离 |
| 走彩色街巷 | 在阿莱格雷山（Cerro Alegre）和康塞普西翁山（Cerro Concepción）之间走山腰街道，从观景步道俯瞰港湾 |
| 体验升降机 | El Peral 通往 Paseo Yugoslavo，Reina Victoria 上站近 Paseo Dimalow，先按当天运行状况选一座 |
| 看滨海度假城 | 从 Puerto 站乘区域铁路前往比尼亚德尔马，另留在邻城散步与回程的时间 |

## 城市格局与游览区域

当地人把海滨平地称作 **el plan**，山坡则按一座座 **cerro** 称呼。索托马约尔广场（Plaza Sotomayor）、普拉特码头（Muelle Prat）和 Puerto 火车站集中在老港一带，经广场旁的 Plaza Justicia 可以找到 El Peral 升降机下站。升到山腰后是公共步道、民居和台阶小巷，原路上下与沿邻近山坡绕回是两种走法。

阿莱格雷与康塞普西翁两座山相邻，可由 Paseo Yugoslavo 一带走到 Paseo Gervasoni 或 Atkinson。地图上横向相隔一条街，实地往往还隔一道阶梯。比尼亚德尔马是沿海相连的另一座城市，以海滨花园和沙滩见长，往返按城际移动安排。

## 主要景点

| 地点 | 具体看点 | 建议用时 |
|---|---|---|
| 索托马约尔广场与普拉特码头 | 从广场面向码头，观察海军大楼、港务建筑与海岸形成的城市轴线。到公众码头看船，装卸作业区按港方划界通行 | 约 45–60 分钟 |
| 阿莱格雷山与 Paseo Yugoslavo | 从 El Peral 上站出门就是临港高地，巴布里察宫（Palacio Baburizza）临步道而建。先从露台看港池，再看大宅如何沿山坡布置 | 约 1 小时，进馆另留时间 |
| 康塞普西翁山 | 在 Gervasoni、Atkinson 等观景步道间走一小圈，从房屋间的空隙辨认港口设施，再看沿街教堂、楼梯与壁画 | 约 1–2 小时 |
| 坡道升降机（ascensores） | 多数传统线路以车厢沿斜轨爬升，承担山上居民出入街区的交通。可选一座上山、另一座下山，每座上下站各有街道入口 | 乘车仅数分钟，排队及寻路另计 |

## 美食与餐饮

海港午餐可选当天供应的煎鱼或 **caldillo de congrio** 鱼汤。想吃几样再继续走，可点一份 **empanada de mariscos** 海鲜馅饼，看看菜单里用的是虾、贝肉还是混合海鲜。沿海往北的孔孔（Concón）尤其以奶酪搭配海鲜的馅饼出名，去当地用餐需从比尼亚德尔马继续乘车。

想在山坡上用餐，可在逛 Paseo Yugoslavo 与康塞普西翁山之间安排午饭。约见同伴时写清餐馆街名及所在山坡，从山脚同名升降机站上来仍有一段路。

## 经典行程

**港城一天**：上午从索托马约尔广场走到普拉特码头，回 Plaza Justicia 搭 El Peral 上山。沿 Paseo Yugoslavo 看巴布里察宫与海湾，午餐后穿过阿莱格雷山和康塞普西翁山，选一段临海步道休息。傍晚根据开放情况乘 Concepción 或 Reina Victoria 下山，再从平地返回住宿。

**两城两天**：第一天留给瓦尔帕莱索旧港与坡地；第二天乘 EFE 区域列车进比尼亚德尔马，选市区公园或海滨步道。冬日海雾遮住远景时，第一天可增加宫内美术馆的停留，行前核对开馆时段。[比尼亚德尔马旅行指南](./比尼亚德尔马.md)

## 住宿区域

住阿莱格雷山或康塞普西翁山，清早便能走进观景步道，但坡地民宿常有楼梯。预订时问清出租车能抵达哪条街、下车后还有几级台阶。住平地且靠近 Puerto 或 Bellavista 站，带行李和去比尼亚德尔马较省力，游山坡时再乘升降机。

## 市内交通

从圣地亚哥通常搭长途客车抵达瓦尔帕莱索汽车总站（Terminal Rodoviario），随后再乘市区车辆去旧港或山坡住宿。**Estación Puerto** 是港边的区域铁路端点；由这里乘 Limache–Puerto 线可到比尼亚德尔马，返回时认准 Puerto 方向。

升降机各线分别运营，设备检修、工程与天气会影响服务。出门前核对当日运行状态，带小额现金；想尽量少爬坡，可请车辆直接送到上站附近可通车的街道。山坡与平地之间的楼梯适合轻装行走。

## 不同旅行者须知

带推车、轮椅或大行李时，可先安排广场、码头和平地街段。若想从山腰看海，向住宿或场馆问清能上下车的具体地址、路缘高差及露台入口。走壁画街巷时给住宅门口留出空间，拍人像前征得本人同意。

## 行前核对

- 确认想乘的升降机当天运行状态，上站与下站分别保存定位。
- 查巴布里察宫开放日，给山坡步行预留日照和雨后石阶慢行时间。
- 长途客车与区域铁路分别核对出发站、票务与末班时间，尤其是从邻城返回后要赶车的当天。
