# 波隆纳鲁沃旅行指南

波隆纳鲁沃坐落在斯里兰卡中北部的稻作平原上。古代国王在此蓄水灌田，水面宽阔到被称作“帕拉克拉马之海”，岸边砖墙则留下中世纪王宫的轮廓。沿林地往北，圆形佛殿的石柱围成一圈，几尊佛像从同一道花岗岩壁里雕出。今天，赤足礼佛的人仍走过古都的石阶，城东的市场和车站延续着另一种热闹。

> 建议停留：1–2 天，古城遗址宜留一个完整白天\
> 旅行关键词：波隆纳鲁瓦、灌溉水库、中世纪王都、圣四方院、伽尔石窟寺、稻米咖喱\
> 主要体力：遗址之间相隔数公里，骑车或包三轮车分站步行，礼拜区需脱鞋\
> 最近研究：2026-11-24

## 城市速览

| 旅行需求 | 安排依据 |
|---|---|
| 看古都 | 由南向北串联王宫、圣四方院、兰卡提拉卡佛殿和伽尔石窟寺，各处下车步行 |
| 看水利 | 帕拉克拉马水库沿古城西侧展开，东岸博物馆附近适合看水面，傍晚另留岸边散步时间 |
| 搭长途车 | 卡杜鲁韦拉（Kaduruwela）在古城以东，设主要客运站和火车站，到遗址仍须接驳 |
| 预算 | 使用斯里兰卡卢比（LKR）。把遗址门票、租车或三轮车等候费分开估算 |

## 城市格局与游览区域

古城沿水库东侧南北展开。南端考古博物馆邻近水岸，王宫建筑群与圣四方院在其以北，再向北才到兰卡提拉卡佛殿和伽尔石窟寺。从南端一路看过去，王室起居、供奉佛牙的圣地和大型寺院各占一片土地。把自行车停在每组遗址旁，院落内步行，较容易看懂这座都城的布局。

卡杜鲁韦拉以商业、巴士和铁路为主，城市行政设施另集中在新城（New Town）。地图搜索 Polonnaruwa 会同时出现古城、火车站与新城旅馆。看房或约车时，宜用博物馆、具体旅馆或客运站作为定位。

## 主要景点

- **考古博物馆与王宫区**。馆内模型可帮助辨认古建筑原貌，出馆后再看帕拉克拉马巴胡一世王宫的高墙和横梁孔，容易理解砖石底层如何托住上层建筑。附近议事厅基座上的动物浮雕，可从侧面沿阶梯逐层看。
- **圣四方院（Sacred Quadrangle）**。同一座高台上集中着几种供奉佛牙的建筑。圆形佛殿 Vatadage 最易辨认，绕外圈看四向阶梯、门口半月形月石与环形石柱，再走进开放区域看佛像如何面向入口。
- **兰卡提拉卡与伽尔石窟寺（Gal Vihara）**。前者残存的高大砖墙形成狭长佛殿，沿中轴线可看到尽头的立像。继续往北，在后者的岩壁前可比较坐、立、卧像的姿态，顺着卧像还看得出花岗岩纹理横贯身体。
- **帕拉克拉马水库（Parakrama Samudra）**。这片人工蓄水区为平原农业提供灌溉。可从考古博物馆附近到岸边，在 Deepa Uyana 一带沿开放的岸线短走，看水面、堤岸与古城相邻的位置。水库尺度很大，约车时写明岸段。

## 美食与餐饮

稻田与水库让一盘米饭配咖喱（rice and curry）格外应景。午餐可在古城外围餐馆或旅馆点当日套餐，常见搭配有扁豆、时蔬和椰蓉辣拌料；遇到淡水鱼咖喱，可询问鱼种与辣度。想多尝几种菜，点菜时先问每份能否分享。

卡杜鲁韦拉车站商街适合出发前买早餐。看到细米粉压成的小圆团，可搭椰奶汁或咖喱吃，这是 string hoppers。住水库旁家庭旅馆若想吃家常晚饭，上午先约用餐时间，古城北段看完就能直接回去。

## 经典行程

| 时间 | 路线与取舍 |
|---|---|
| 前一天下午抵达 | 在卡杜鲁韦拉换乘三轮车到住宿；有日光时先走一段水库东岸，约好次晨车辆或单车 |
| 上午 | 到博物馆一带办理遗址入场，参观王宫建筑群，再去圣四方院。带水，在有树荫处安排短休 |
| 午后 | 由圣四方院向北，到兰卡提拉卡和伽尔石窟寺；每站约好司机会合点，末站看完直接乘车返回 |
| 只有半天 | 王宫与圣四方院各选重点，包车直达伽尔石窟寺。时间紧或石面炎热时，将水岸散步留给傍晚 |

## 住宿区域

古城南端及博物馆附近便于早起取票、租车和用餐。水库东岸旅馆适合傍晚看水景，订前确认去遗址入口的道路距离、晚餐与返程接送。若要赶早班长途巴士或夜间列车，住卡杜鲁韦拉更便于带行李换乘，次日游古城时另约往返车。

## 市内交通

从科伦坡堡站（Colombo Fort）查询到 Polonnaruwa 的列车，火车在卡杜鲁韦拉一带停靠。乘城际巴士时可向售票员说明去 Kaduruwela Bus Stand，抵站后再约三轮车到考古博物馆或旅馆。列车时刻、可订座席和巴士出发点按旅行当天确认。

遗址内部适合骑自行车或用带司机的三轮车分段游览。取单车时检查车闸和车锁，问清归还地点；包三轮车则约定南端接人、北端等候和最后送达地点。若一天内赶下一段交通，从北端遗址出发时把取行李和去卡杜鲁韦拉的时间一起算上。

## 不同旅行者须知

- **礼佛与摄影**：进入指定神圣范围前脱鞋摘帽，衣物遮住肩膝。拍佛像时面向佛像，礼佛者身边留出通行空间。
- **亲子与长者**：圣四方院的石阶和露天石台晴天容易升温，可把这部分放在上午。古城纵向距离长，逐站乘车可以将步行体力留给石雕与院落。
- **行动辅助需求**：宫殿高台、佛殿入口常见台阶与石门槛。先在博物馆识别重点建筑，再请司机和工作人员推荐平坦的落客点与可通行的观赏位置。

## 行前核对

- 查看中央文化基金的当日票务说明，网购后保存订单凭证，按指引到现场柜台换取门票。
- 向旅馆确认租车、司机等候和古城北端的返程安排，随身带水、遮阳用品及方便穿脱的鞋。
- 保存火车站或巴士站全名及定位，说明是要进古城、去水库岸边，还是去卡杜鲁韦拉转车。
