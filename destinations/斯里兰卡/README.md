# 斯里兰卡旅行目的地

科伦坡和加勒适合连读，前者的海滨延伸到商业街区，后者的城墙围住一座老港城。转向内陆，康提的佛牙寺与丹布勒的石窟寺各有自己的参访习惯，阿努拉德普勒的礼佛场所则分散在广阔的古都遗址间。努沃勒埃利耶位于茶区高地，行程需给山路和站外接驳留出时间。

从机场落地后想先住海边，可看内贡博。北上贾夫纳要给半岛和离岛另留时间；走东岸可比较亭可马里的港湾与巴提卡洛阿的潟湖。文化三角的波隆纳鲁沃以分散的宫殿、寺院遗址为主，适合与丹布勒串联。

## 跨城铁路

从科伦坡出发，查票时按实际出发站选择 Colombo Fort 或 Maradana。去加勒查沿海线；去努沃勒埃利耶，铁路一段查 Nanu Oya，再单独安排进城的公路接驳。山区线路分段恢复运营时，以旅行当天的区段公告和可售车次安排行李转运。[斯里兰卡铁路时刻查询](https://www.railway.gov.lk/web/index.php?Itemid=0&id=1024&lang=en&option=com_content&view=article) · [铁路运营公告](https://www.railway.gov.lk/web/index.php/en/timetable.html)
