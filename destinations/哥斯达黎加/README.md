# 哥斯达黎加旅行目的地

在中央谷地，阿拉胡埃拉靠近国际机场，圣何塞则集中了国家剧院与博物馆。向东抵达利蒙后，城市生活转向加勒比海岸，继续去卡维塔要另排一段公路行程。
