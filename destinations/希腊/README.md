# 希腊旅行目的地

雅典与比雷埃夫斯分别收录。住在雅典去岛上前，先核对船票上的出发港和登船口；若在港城多留一天，可以把考古博物馆与游艇港串成步行路线。北部的塞萨洛尼基则适合沿海湾、拜占庭遗产与老街安排停留。
