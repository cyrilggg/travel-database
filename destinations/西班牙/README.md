# 西班牙旅行目的地

马德里与安达卢西亚的旧城适合按铁路沿线组合。北岸的希洪、拉科鲁尼亚与维戈则各有自己的港口和海滨街区。加那利群岛单独安排：拉斯帕尔马斯在大加那利岛，圣克鲁斯在特内里费岛，两城之间另有一段跨岛交通。
