## 两城之间的渡轮

如果船票写着 Agaete 至 Santa Cruz de Tenerife，大加那利岛一端在西北岸的阿加埃特港。从拉斯帕尔马斯市区出发，可先到圣卡塔利娜公园搭船公司的接驳巴士。订票时核对去程与回程的登船港，并把市区至码头的时间算入当天行程。[Fred. Olsen 港口与接驳说明](https://www.fredolsen.es/es/terminal-las-palmas-de-gran-canaria)
