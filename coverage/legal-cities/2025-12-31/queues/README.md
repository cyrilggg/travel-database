# 法定城市补充队列

这里保存法定城市优先队列中使用固定 `cities500` 快照外真实 GeoNames 城市点的批次。队列只服务 695 座法定城市交叉核对，页面标记 `coverage_scope: legal_city_only`，相应记录不进入固定 GeoNames 决策账本，也不改变 16,049 条候选分母。

第一百一十四批新增高平、河津、孝义和汾阳。四座城市均由同名城市点、坐标、现行行政归属和法定代码闭合；所用 GeoNames 点人口字段为零，因而未进入固定 `cities500` 快照。县级市完成度由 **378/398** 升至 **382/398**，固定 GeoNames 完成度保持 **902/16,049**。

第一百一十五批新增灯塔、调兵山、同江和龙港。灯塔与调兵山采用直接对应法定城市的 GeoNames `ADM3` 记录；同江与龙港采用同名城市点，并由坐标、父级行政关系或现行法定代码闭合。县级市完成度由 **382/398** 升至 **386/398**，固定 GeoNames 完成度保持 **902/16,049**。
