## 身份与来源

- 路径沿用 `destinations/中国/台湾省/<城市>.md`；元数据仍为 `schema_version: 1`、`country: 中国`、`country_code: CN`、`coverage_scope: taiwan_batch`。不因文案更新迁移到未接入的 v2。
- `taiwan-<administrative_code>` 地图 ID 与既有坐标保留；攻略 ID 继续为 `cn-<geonames_id>`。县辖市坐标仍是既有行政边界几何中心，不把它当作景点坐标。
- 朴子原先缺少 GeoNames 关联。本次从 [GeoNames TW 数据](https://download.geonames.org/export/dump/TW.zip)核对 `1670367`、名称 `Pozi`、别名 `朴子`、嘉义县 `CYQ` 与朴子 `Q02`，并以 [Wikidata Q706520](https://www.wikidata.org/wiki/Q706520)交叉确认。仅补外部关联，不移动地图点。来源与哈希记录在[地图数据说明](../../../site/data/README.md)。
- 大陆 GeoNames 942/16049、法定城市 692/695 的口径不变，台湾有独立候选账本。
- 正文引用旅游主管机构、场馆、交通运营方及主管机关的一手页面，核查日期与支持范围在各篇末尾。停留时间和取舍属于编辑建议；未知当前条件不写成已确认。

## 内容与阅读设计

| 层次 | 本次处理 |
|---|---|
| 城市简介 | 单独审读，选择地理、历史、文化与日常特征；不注入时间分配、交通预约或来源链接 |
| 城市正文 | 维持现有十节，景点比较、餐饮背景、片区导读和行程分别承担各自任务 |
| 区域正文 | 按真实旅行范围组织分线、主要体验、住宿交通与须知，不伪造城市元数据 |
| 总览与区域入口 | 独立站内阅读目录，复用全文组件；城市链接与区域链接在站内跳转 |
| 外部链接 | 保留正文中的官方证据链接；未发布的仓库维护文件引用在网页输出中显示为文字 |
| 当前边界 | 不新增区域地图几何、行程计算或图片；正文可以独立阅读 |

本批保留已核查的入境身份分流与证件提醒，避免将不同身份的许可条件写成所有人都能使用的统一规则。原住民族文化与离岛活动说明尊重当地接待、摄影和海况条件。基隆塔采用较新的重开公告；故宫南院不再推荐已停驶的 106 线；太鲁阁依具体路段与步道公告说明限制。
