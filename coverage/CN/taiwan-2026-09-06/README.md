## 产品、设计、数据与实现

| 责任 | 本批采用的选择 | 实际能力与差距 |

| 产品 | 地图发现三城，比较主题后读完整指南，再用台湾总览选跨城组合 | 只把通过研究的三城计为有攻略；其他城市仍显示待收录 |

| 内容 | 采用 Lonely Planet 编辑层次的原创中文：先城市性格和精选，再片区、短导读、比较表与可调整行程 | 不复制出版物文字、图片，不声称亲历；无图仍可阅读 |
