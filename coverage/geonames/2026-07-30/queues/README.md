# 中国分批队列

队列文件只记录研究顺序和选择理由，不代表页面已经完成。实际完成状态以 `../decisions/CN.csv` 为准，未进入决策账本的记录仍是未处理。

首批从 `cities15000` 选择九座差异明显的城市，用于验证直辖市、普通省会、县级旅游城市、高海拔、海滨、广域远郊和同名景区等边界。已有的苏州样例不重复列入首批新增队列。

第二批继续从 `cities15000` 选择八座区域中心，覆盖滨水超大城市、直辖市主城与远郊边界、山水古都、湖滨城市、三镇结构和高原省会等写作场景。队列中的每条记录仍须完成页面、账本登记和质量检查后才计入进度。

第三批继续验证沿海与跨湾城市、高纬度冬季城市、跨境交通枢纽、民族自治区首府、跨县海岛和大型山岳远郊等边界。一个城市进入队列不代表其行政范围内所有县市都合并进同一城市页，具体合并与拆分仍按覆盖口径逐条审计。

第四批选择八座尚未进入前三批的省会或区域中心，补齐东北工业城市、华北省会、长江中下游区域中心与西南山地省会等写作场景。队列以城市点为研究对象；同一省内已有城市页时必须合并省级导航，不能覆盖既有内容，也不能把省内其他城市或跨市景区并入省会页面。

第五批补齐尚未覆盖的自治区首府和西北省会，并加入大连、无锡、宁波三座空间结构差异明显的沿海或湖滨城市，用于继续核验高海拔、跨区海岸、跨县远郊与大城市群边界。呼和浩特已在本批研究启动后补录队列；进入队列仍不表示已经完成。

第六批从尚未处理的 `cities15000` 记录中选择八座人口规模较大的地级城市，继续覆盖珠江三角洲多中心镇街、潮汕海岛、黄河灌溉区、华北工业城市和中西部广域山地等结构。队列主动排除上海市内的 `PPLX`、`PPLA4` 等城区记录；这些记录须在后续审计中与既有上海页核对，不能作为独立城市完成页重复计算。

第七批继续从尚未处理且可与法定地级城市稳定对应的 `cities15000` 记录中选择八座人口规模较大的城市，覆盖运河工业城市、组团式工矿城市、东南沿海山海市域、沂蒙与大巴山广域山区等场景。宝安等既有城市内部行政区，以及地名和人口明显需要先消歧的记录暂不生成城市页，留待有证据的重复、合并或范围审计。

第八批继续选择可与法定地级市稳定对应的高人口记录，覆盖运河与长江入海水网、环渤海和珠江口海岸、海岛轮渡、草原沙漠工业城市及陇东黄土高原等场景。上海宝山、昆山等城市内部区县或县级市不在本批混入地级城市页；它们仍须按法定层级和 GeoNames 粒度另行研究或审计。

第九批继续从尚未处理、且能与法定地级市稳定映射的 `cities15000` 记录中按人口规模推进，覆盖鲁中城市群、黔北山地、江苏海陆交界、赣南客家地区、粤东潮汕平原、东北沿江城市、中原古城和嘉陵江流域。队列只确定研究对象；青州、普宁、阆中等县级城市以及各地级市内的广域县区仍要分别说明边界，不能因写入地级市页而自动视为这些法律城市已经完成。

第十批继续选择尚未处理、可与法定地级市稳定对应的高人口城市点，覆盖晋北石窟古建、南阳盆地、五邑侨乡、淮河平原、河套平原、潮州古城、粤北山地和泰山门户等场景。队列中的地级市页面只能覆盖其中心城市与明确说明的市域旅行关系；开平、台山、英德、新泰等法定县级城市仍须另建合格页面或留下审计决定，不能随地级市页面自动完成。

第十一批首次成组加入固定清单中的高人口法定县级市，以昆山、江阴、常熟和义乌核验“省／一级行政区／城市页”结构下的县级城市独立覆盖，并继续推进淮南、宿州、六安和盐城四座地级市。县级城市页必须写清与上级地级市的行政、交通和景点边界；同一 GeoNames 城市点与法定城市只能登记一次，也不能因苏州、无锡或金华已有或将有地级市页面而合并消失。

第十二批继续按固定清单中的人口顺序选择可与法定地级市稳定对应的记录，覆盖长江港城、东北油田组团、川东北与川西北山地、运河园林、珠江西江山水和闽中滨海岛屿等结构。泰州、扬州、绵阳、达州、肇庆等地级市页面必须明确靖江、泰兴、兴化、高邮、仪征、江油、万源、四会等县级市仍需独立处理；湄洲岛、油田片区、湿地和广域县域也不能因写入地级市路线而自动视为相应 GeoNames 记录完成。

第十三批继续从高人口且可与法定城市稳定对应的 `cities15000` 记录推进，并明确区分江苏泰州与浙江台州。泉州、金华、常德、鞍山、宝鸡和开封用于覆盖世界遗产港城、组团型地级市、湖区、工业城市、周秦文博与古都水系等结构；慈溪则作为宁波代管的法定县级市独立处理。晋江、石狮、义乌、东阳、永康、兰溪、津市、海城、临海、温岭等县级市仍须分别建立合格页面或留下审计决定，不能由上级地级市页面自动完成。

第十四批在跳过需要先做合并或消歧审计的城市内部区点后，继续按 `cities15000` 人口顺序选择可与法定城市稳定映射的记录。宿迁、柳州、亳州、曲靖、湛江和抚顺覆盖运河湖区、喀斯特工业河谷、中医药历史、高原花季、雷州半岛海岸与煤矿工业等差异场景；张家港和晋江继续验证法定县级市独立覆盖。沭阳、宣威、廉江、雷州、吴川等县级市及县域记录仍须单独处理，上级城市页只能说明衔接关系。

第十五批继续回到高人口且可与法定地级市稳定对应的 `cities15000` 记录，覆盖河洛与赵都古城、长江峡江、鲁西南牡丹、乌蒙山组团城市、粤西石化海岸、北部湾港城和沙澧河食品工业等场景。邯郸项目城市点与 Wikidata 行政区 GeoNames 记录并非同一条，页面必须明确两者用途；武安、宜都、枝江、当阳、盘州、高州、化州、信宜等法定县级市仍须独立处理。较早队列中尚未完成的六安、盐城和义乌继续优先研究，不能因新批次建立而跳过。

第十六批在跳过上海、深圳、重庆等已建城市页内部的区级居民点后，继续选择能与法定城市稳定映射的高人口记录。襄阳、阳江、许昌、自贡、徐州、内江和济宁覆盖汉江与汉水古城、粤西海岸、曹魏文化、盐业工业、汉文化、沱江与大运河等差异场景；宜兴继续检验由地级市代管的县级市独立覆盖。GeoNames 对自贡、济宁、内江和宜兴使用 `PPL` 或 `PPLA3` 等居民点分类，页面须以法定行政代码说明中国城市层级，不能把 GeoNames 要素代码当作法定等级。老河口、枣阳、宜城、阳春、禹州、长葛、新沂、邳州、隆昌、曲阜和邹城等县级市仍须独立处理。

第十七批继续选择法定城市映射清楚且能检验广域市域边界的 `cities15000` 记录。聊城、晋中、长治、天水、渭南、嘉兴、中卫和盘锦覆盖大运河水城、晋商古城与大院、太行山地、石窟、关中东府、水乡、黄河沙漠及辽河湿地等场景。页面必须把世界遗产或大型景区与所在县市的独立城市范围分开：平遥、介休、华阴、韩城、海宁、平湖、桐乡和临清等法定县级市仍须独立处理；石窟、山岳、湿地、沙漠和石油生产区还需明确准入、天气与生态安全边界。

第十八批继续从高人口且可与法定地级市稳定对应的 `cities15000` 记录推进，覆盖长江—鄱阳湖港城、殷商古都、黔西北喀斯特、湘江工业城市、赣东北山地、皖北煤城、岷江东坡故里和临川文化城市。九江、安阳、毕节、株洲、上饶、淮北、眉山与江西抚州都需要把中心城区同广域县域分开，并对庐山、林州、黔西、醴陵、德兴等法定县级市保留独立完成边界；世界遗产、矿区、湿地、洞穴、山岳和水域也必须写明预约、准入、天气、生产与生态安全。抚州使用“江西抚州”消歧，不与福建省福州市混称。

第十九批继续从固定库存中选择高人口、法定地级市映射清楚的记录，覆盖西江港城、湘江与南岳、岭南侨乡、长江楚文化、豫北太行、赣西山地、秦汉帝陵和粤北丹霞等结构。贵港、衡阳、玉林、荆州、新乡、宜春、咸阳与韶关页面需要区分中心城区、普通县域及桂平、北流、石首、洪湖、松滋、卫辉、辉县、丰城、樟树、高安、兴平、彬州、乐昌、南雄等法定县级市；南岳衡山、丹霞山、帝陵群、峡谷、湿地和港区生产空间也须按完整项目去重并说明文物、生态、天气与准入边界。

第二十批继续处理固定库存中人口较高且与法定地级市稳定对应的记录，覆盖闽西客家文化、潇湘山水、太湖南岸、河西走廊、汉水盆地、桂粤湘边地、黄河三角洲和长沱两江酒城。龙岩、永州、湖州、武威、汉中、贺州、东营与泸州页面需要严格区分中心城区、普通县域及漳平、祁阳等法定县级市；土楼与古村、石窟、荒漠、朱鹮和河口湿地保护地、石油与酿酒生产区、港口和跨省流域也须按完整单元去重并说明文物、生态、生产、天气和准入边界。

第二十一批跳过上海、深圳、重庆等已建城市页内部的区级居民点，也暂不把浦阳、赫山、信阳和已并入济南的莱芜等需要消歧或合并审计的记录直接生成城市页，继续选择与法定城市稳定对应的高人口记录。梅州、岳阳、本溪、平顶山、蚌埠和湘潭覆盖客家山地、洞庭湖湿地、东北工矿、豫中煤城、淮河考古与长株潭城市群等差异场景；诸城、三河则继续检验法定县级市独立覆盖。兴宁、汨罗、临湘、舞钢、汝州、湘乡与韶山等法定县级市仍须独立处理；湖泊河道、湿地、矿山、钢厂、农业区和跨省市通勤空间也必须说明水文、生态、生产与行政边界。

第二十二批继续选择法定城市映射清楚的高人口记录，并以瑞安补充由地级市代管的县级城市样本。临汾、镇江、葫芦岛、保山、来宾、孝感和资阳覆盖汾河古建、长江运河、辽西海岸、滇西山地、红水河、江汉平原和成渝走廊等结构。霍州、丹阳、扬中、句容、兴城、腾冲、合山、应城、安陆和汉川等法定县级市仍须独立处理；黄河峡谷、海岸港区、矿山工厂、高黎贡山、湖库水域和石窟文保区也必须区分公共开放、生产作业、生态保护与天气安全边界。

第二十三批继续选择能与法定城市稳定对应的高人口记录，并加入普宁这一揭阳代管的县级城市。衢州、枣庄、萍乡、舟山、齐齐哈尔、安康和廊坊覆盖四省边际山地、鲁南运河工矿、赣西工运与山岳、群岛船班、东北湿地、秦巴汉江及京津之间分割市域等结构。江山、滕州、讷河、旬阳、霸州和三河等县级市仍需独立处理；联合景区、岛屿船线、湿地保护地、矿区、库区、临空与物流生产空间也须按完整单元去重并说明准入边界。

第二十四批在单独审计万县、原闸北和上海金山等历史名称或市辖区记录后，继续按人口顺序选择法定城市映射清楚的记录。焦作、广安、威海、新余、宜宾、郴州和安庆覆盖太行山地、川东渠江、胶东海岸、赣西工业湖区、三江口、南岭及长江港城；太仓继续检验苏州代管县级市在沪苏城市群中的独立边界。沁阳、孟州、华蓥、荣成、乳山、资兴、桐城和潜山等县级市仍须单独处理；云台山、东江湖、天柱山等跨县市或大型景区不能因写入上级地级市路线而自动合并。
