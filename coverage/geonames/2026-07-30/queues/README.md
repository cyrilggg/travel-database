# 中国分批队列

队列文件只记录研究顺序和选择理由，不代表页面已经完成。实际完成状态以 `../decisions/CN.csv` 为准，未进入决策账本的记录仍是未处理。

首批从 `cities15000` 选择九座差异明显的城市，用于验证直辖市、普通省会、县级旅游城市、高海拔、海滨、广域远郊和同名景区等边界。已有的苏州样例不重复列入首批新增队列。

第二批继续从 `cities15000` 选择八座区域中心，覆盖滨水超大城市、直辖市主城与远郊边界、山水古都、湖滨城市、三镇结构和高原省会等写作场景。队列中的每条记录仍须完成页面、账本登记和质量检查后才计入进度。

后续批次应继续使用固定库存中的 `assigned_phase`，按 `cities15000 → cities5000 → cities1000 → cities500` 推进。任何队列都不能生成空城市页或提高覆盖率。
