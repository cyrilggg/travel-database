# 亚洲主要城市攻略首批发布

本批接入 23 篇已核查完整攻略：日本 12 城，以及新加坡、泰国 2 城、马来西亚 3 城、越南 3 城、印度尼西亚 2 城。逐城路径、原地图身份和网页攻略身份见 [发布清单](published-guides.json)。各篇保留实际研究日期，包含城市简介、片区、景点、美食、三条路线、住宿、交通和来源。

## 产品与数据

用户从已有地图城市入口打开攻略，查看摘要、分类内容及全文。地图 ID 和坐标直接复用现有名录；攻略沿用网站的国家代码与 GeoNames ID 组合方式，原稿 guide_id 留作编辑标识。正文按当前 schema_version 1 必填元数据接入，未声明结构化路线或景点坐标能力。

乔治市沿用槟岛行政入口，岘港明确 2025 年扩大后的行政范围和中心城区区别，登巴萨与巴厘岛、日惹与周边遗产分别说明旅行尺度。所有现有地图城市保持原身份；缺少 GeoNames 的纯地图城市继续显示现有缺内容体验，已编写攻略仍严格校验身份与坐标。

## 验证与发布

静态网站生产构建通过。新增检查覆盖 23 篇全文、分类阅读、摘要、唯一地图关联及缺内容城市；现有韩国、朝鲜和台湾阅读检查共同回归。公开全文仅按已接入国家开放，原中国大陆公开内容策略保持一致。

本批从远端 main 的 9a77d70 开始，在独立工作区整合，保留其他工作区的既有修改和删除。用户已要求直接推送 main，推送后由 GitHub Pages 工作流发布；攻略目录的任何国家变动均触发工作流。

世界主要城市为持续目标：本批优先已具备地图的重点亚洲目的地，其他亚洲城市及世界地区继续分批补齐。韩国首尔、釜山、庆州及济州市复用 main 的既有攻略与真实研究日期。
