# 旅行目的地知识库

这是一套提前沉淀、优先离线使用的旅行 Markdown 百科。内容按“国家 → 省/州/大区 → 城市”组织；当用户以后提出“想去某地”时，先读取本地城市文件，再只针对票价、开放时间、临时闭馆、预约和交通中断等高频变化信息做必要复核。

## 城市文件会回答什么

每座城市都尽量提供：

1. 值不值得去、适合停留几天、与用户偏好的匹配点；
2. 主要景点以及核心、次要、远郊层级；
3. 城市由哪些片区组成，哪些景点天然能串在一起；
4. 代表性美食、适合独食的选择和排队替代思路；
5. 首访主线、摄影步行、雨天线路和临场删减规则；
6. 清图率的建议分母，不把机场、车站、纯配套和远郊误算进去；
7. 哪些信息相对稳定，哪些必须出发前联网复核。

## 当前批次

第一批共 4 个国家、19 座城市，以用户已有经验和未来意向为优先：

- 中国：北京、上海、大连、武汉、成都、厦门、广州、深圳、杭州、宁波、临海、苏州、南京；
- 日本：东京、京都、大阪、福冈；
- 欧洲首访优先：伦敦、巴黎。

这不是“全球已经收齐”的声明。后续按城市批次扩展，每一批都要求有实质景点、美食和路线内容，而不是只生成空目录。

当前主存储就是可直接阅读和链接的 Markdown，不要求先查 SQL。旧的 `global-attractions-metadata` 目录只保留为早期架构实验，不再承担旅行问答入口。
