# 全球城市旅行资料库

这是一个面向公众的全球城市旅行 Markdown 资料库。每座城市页把城市格局、主要景点、美食、可组合路线、住宿、交通、体力与天气条件放在同一份可长期查阅的指南中，并把容易变化的开放时间、预约、票价和班次集中列入行前核对。

Markdown 是主要产品。覆盖清单与辅助脚本只用于审计和维护，不代替城市内容，也不会通过生成空页制造完成度。

> **当前阶段：中国固定清单与分批扩展。** 仓库已保存 2026-07-30 GeoNames 四档原始快照，并建立 `country_code=CN` 的 16,049 条固定清单；同时保存民政部数据截止 2025-12-31 的 695 座大陆法定城市清单，作为独立交叉核对。全球分母尚未建立；中国进度只按已研究页面和有证据的审计决定计算。详见 [GeoNames CN 快照摘要](./coverage/geonames/2026-07-30/summary.md)与[法定城市核对摘要](./coverage/legal-cities/2025-12-31/README.md)。

## 城市指南包含什么

每页开头用速览表说明旅行价值、建议停留、季节、预算、步行强度和主要风险，随后依次整理：

- 城区之间的关系，以及哪些片区可以连续步行；
- 按地理区域或主题归并的主要景点；
- 代表性菜品、餐饮区域、独食条件与饮食限制；
- 一日、两日、三日、雨天、低体力和远郊路线；
- 住宿片区、抵达方式和市内移动结构；
- 独行、亲子、长者、无障碍、摄影和预算等通用旅行条件；
- 出发前必须重新核对的动态信息；
- 支持正文的官方来源和研究日期。

路线是可组合的游览顺序，不是分钟级课表。每条路线会说明空间上的组合理由、预约锚点、休息区域，以及时间不足时应先删除的部分。

## 阅读说明

城市的空间关系、景点性质和饮食文化通常较稳定；开放时间、闭馆日、预约方式、票价、班次、展览、施工和极端天气具有时效性。城市页不会把当天查询到的动态数值写成永久事实，这些项目统一放在“行前核对”，并链接到官方入口。

| 内容状态 | 含义 | 是否计入完成 |
|---|---|---:|
| `researched` | 正文、路线、来源和动态核对项均经过实质研究，并通过当前质量检查 | 是 |
| `needs_review` | 曾经完成，但关键来源失效、内容过期或需要重新核验 | 否 |
| `draft` | 有实质草稿，但尚未完成研究或审阅 | 否 |
| 缺页、空页、模板副本 | 没有可用城市内容 | 否 |

`last_researched` 记录最近一次实质核验日期；只修改标点、排版或链接文字不会刷新该日期。

## 全球覆盖口径

本项目所说的“全球覆盖”是一个可复核的工程范围，不等同于各国法律或统计制度中对“城市”的定义。覆盖基线采用 GeoNames 的固定日期快照，并以 `geonameid` 作为记录主键。

GeoNames 官方提供四档城市摘录：

| 推进层级 | 官方范围摘要 | 官方约数 |
|---|---|---:|
| `cities15000` | 人口严格大于 15,000，或属于首都 | 25,000 |
| `cities5000` | 人口严格大于 5,000，或为一级行政区驻地 `PPLA` | 50,000 |
| `cities1000` | 人口严格大于 1,000，或为行政区驻地，层级下探至 `PPLA3` | 130,000 |
| `cities500` | 人口严格大于 500，或为行政区驻地，层级下探至 `PPLA4` | 185,000 |

这些数量只是 [GeoNames dump README](https://download.geonames.org/export/dump/readme.txt) 中的约数。覆盖率分母必须使用固定快照中实际的唯一 `geonameid` 数量。官方说明没有承诺四个文件严格嵌套，因此清单会保存记录在四档文件中的实际成员关系，不按人口或名称自行推断。

项目按 `cities15000 → cities5000 → cities1000 → cities500` 分阶段推进。中国阶段以 2026-07-30 的 `cities500` CN 集合作为最终工程边界，并保留四档真实成员关系、获取时间、SHA-256、实际记录数和生成版本。详细审计规则见 [覆盖与完成度](./coverage/README.md)，中国行政映射和排除阈值见 [中国城市覆盖口径](./coverage/CN-SCOPE.md)。

完成记录只有两类：

1. 有达到质量要求、仍在有效复核期内的 `researched` 城市页；
2. 经人工审计确认属于重复、合并或项目范围外，并留下理由、证据、审核日期和规范目标的记录。

两类数字会分别报告。`seed`、`draft`、`needs_review`、过期页面、空模板、自动目录和未建页都不计入完成。

## 贡献指南

1. 从固定覆盖清单的未处理记录中选择城市，并确认 GeoNames ID 没有对应其他页面；中国清单已建立，其他国家在各自快照建立前不得声称进入全球分母。
2. 复制 [城市模板](./templates/city.md)，按 `国家/一级行政区/城市.md` 建立页面，保持 `content_status: draft`。
3. 优先使用政府、官方旅游机构、景区或场馆官网、公共交通运营方和开放数据源，独立概括事实，不复制网页长段文字。
4. 完成城市格局、景点、美食、可用路线、住宿、交通、不同旅行者须知、行前核对和来源记录；删除所有占位符、空表与不适用小节。
5. 检查同一景区及内部子景点没有重复计数，远郊没有被硬塞进城区半日，低体力路线确实减少步行、坡度或换乘。
6. 检查相对链接、中文路径、来源支持关系和研究日期。资料不足的无障碍信息必须明确写“设施连续性需向官方确认”。
7. 经人工内容审阅后才能把状态改为 `researched`。提交说明应列出新增页面、主要来源和完成的检查。

## 内容标准

- 面向普通公众，所有景点取舍都使用可复用的旅行条件；
- 使用“城市速览”“主要景点”“经典行程”等稳定、自然、便于检索的标题；
- 直接提供旅行信息，不反复解释“本页如何使用”；
- 把稳定事实与出发前必须复核的信息分开；
- 以菜品和餐饮区域为主，不把一家热门店写成唯一答案；
- 不推荐未经核验的具体酒店；
- 只在图确实能更清楚说明空间、关系或流程时使用 Mermaid；
- 不以字数、表格行数或目录数量替代人工质量判断。
