# 功能变更：地图按尺度显示目的地并分开待核验入口

- 日期与维护者：2026-09-24 开始，2026-09-25 验收；Codex。
- 当前决定：采用，本地实现，尚未发布。
- 关联或替代的决定：替代所有库存点在中等缩放直接展开、未知行政类型统一灰点的显示行为。遵循[协作约定](../working-agreement.md)；不改变[数据契约提案](../designs/travel-guide-data-contract.md)的身份与模块边界。

## 用户场景与本次范围

用户浏览土耳其及周边时，大量县中心和人口聚居点挤满地图，灰色也无法区分来源类型。本次按缩放分层、延长聚合、明确显示标签，并让证据不足的城市候选退出默认目录。搜索仍可定位这些候选，已有攻略始终可用。

本次没有重建各国行政隶属树，没有逐项认证法定城市身份，也不把各国行政级别强行对应到中国省、市、县。颜色是共同展示组，详情保留来源类型对应的当地角色。注册表未标记待核验，不等于已经完成独立的官方身份认证。

如果某国数据没有单独区分主要城市，使用它已知的最高展示组参与概览聚合，避免整个国家消失；不会因此改写该组的行政身份。缺攻略继续显示空心点和周边入口；待核验详情明确说明城市身份未确认。地图加载失败沿用已有替代界面。

## 数据增量与兼容方式

- `mapCities`、`targetCityCount` 继续表达原始库存。首页覆盖数与默认目录改用可展示目的地集合，当前为 9,963 条；已有攻略的 915 条全部保留。搜索使用完整库存。
- 新增显示配置 `type`、`label`、`minZoom`、`reviewRequired`，其校验与实现以[规则表](../../site/data/city-level-policy.json)及[校验器](../../site/scripts/city-level-policy.mjs)为准。`minZoom=null` 与待核验状态配对；已有攻略可绕过显示门槛。
- 所有 `*_5000_plus` 来源类型暂列待核验，包括混合官方城市与人口聚居点的类型。此举表示缺少逐条区分依据，不表示这些地点一定不是城市。后续补充证据后细化来源类型，继续保留 ID。
- 未知来源类型会阻止构建，错误指出地点 ID 与类型；客户端防御性回退到“类型待核验”。不再根据外国中文译名的“市/县/区”字尾猜行政级别。
- 已有攻略、行程引用和保存记录的 ID 不迁移；搜索和行程高亮使用独立图层，即使该点被聚合或不在默认展示层也可定位。不改变保存数据格式。
- 回滚可恢复旧显示代码并重新构建，无需恢复或删除城市数据。新增注册表只影响本地构建和读取展示，无核心数据版本升级。
- 数据维护入口和原始库存含义已同步到[数据说明](../../site/data/README.md)。构建后运行 `npm run guides:audit`，在忽略跟踪的 `site/outputs/city-map-audit.json` 查看分国数量、分尺度数量及待核验 ID。

## 验收与实际覆盖

| 样例 | 期望行为 | 实际结果与证据 |
|---|---|---|
| 土耳其概览与放大 | 缩放 9 前保留 81 个入口，9 起加入 779 个县中心，111 个候选不进入默认层 | 自动测试通过；桌面实际显示稀疏城市点与聚合点 |
| 搜索伊斯坦布尔 | 精确城市名优先于行政归属包含同名的县；点击查找和回车均可定位 | 自动测试和浏览器检查通过 |
| 搜索棉花堡 | 保留原 ID、坐标、搜索入口和单独高亮，详情说明待核验 | 自动测试与窄屏浏览器检查通过 |
| 旧攻略与跨国缺数据 | 915 个攻略在各尺度仍参与展示；无主要城市分组的国家不消失 | 各缩放边界的单调性、国家覆盖和攻略保留测试通过 |
| 台湾与朝鲜半岛原有入口 | 稳定 ID、攻略关联、阅读链接及覆盖状态不受影响 | 连同本次测试，共 37 项通过 |
| 新类型与非法配置 | 未配置类型、继承属性名、待核验却有缩放门槛等输入构建失败 | 自动测试通过 |

验收环境为独立工作目录 `D:/Project/personal/travel-map-maintenance`，分支 `codex/map-density-maintenance`，基于 `9a77d70` 的本地未提交修改。`npm run build:pages`、本次修改文件的 ESLint 和 `git diff --check` 通过。审计结果：库存 10,647，默认目录 9,963，待核验 684，国家代码 60。

全项目 TypeScript 检查仍报错，位置在未修改的 `guideBrowse.ts`、两个大型生成文件和 Cloudflare worker 类型声明，未将其记为通过；生产构建有已有的大文件体积提醒。没有提交、推送或发布。逐项法定身份核验、未区分主要城市国家的进一步数据细化、实体手机键盘测试仍属后续维护范围。
