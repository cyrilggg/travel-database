# 功能变更：全球主要城市地图覆盖

- 日期与维护者：2026-09-25，Codex。
- 当前决定：采用；实现与本地验收完成，发布以对应 main 提交的 GitHub Actions 结果为准。
- 关联决定：[地图密度维护](2026-09-24-map-density.md)。用户明确要求补齐全球、优先主要城市，并推送远端 main；本次同时发布前述密度维护。

## 用户场景与本次范围

用户从全球地图浏览欧洲、美洲、非洲、大洋洲等目的地，搜索主要城市并确认攻略是否收录。新增国家以主要城市和地区中心接入，不再批量收录所有基层行政中心或人口超过 5,000 的聚居点。既有细分库存仍保留并按原缩放规则逐步显示。

本次新增 1,106 个地图入口、162 个国家或地区；总计 222 个国家或地区代码，覆盖 193 个联合国会员国及 2 个观察员国和六个有人居住的大洲。国家/地区代码用于组织目的地，不将属地和主权国家等同计数；这不是所有属地、所有城市或全世界攻略的完整清单。南极科考站、历史废弃地点不作为城市补入。

## 产品、设计与开发的共同样例

| 责任 | 当前状态与选择 | 证据或后续范围 |
|---|---|---|
| 产品 | 全球补齐采用主要城市入口；无攻略保持空心和“尚未收录” | 巴黎、纽约、里约热内卢、开罗、悉尼可搜索；小国也有入口 |
| 设计 | 首页和“全图”改为全球视野；按尺度聚合；主要城市统一展示组，不套用中国行政级别 | 桌面与 390×844 窄屏验证；允许低缩放适应窄屏，清除重复侧栏占位 |
| 开发 | 从固定快照构建，日常构建不联网抓取；新增类型、坐标、ID、重复点和全球覆盖检查 | `import-world-major-cities.mjs`、`world-city-inventory.mjs`、`world-major-cities.test.ts`；Pages 发布前运行地图测试 |
| 数据 | Natural Earth 主要城市选点，GeoNames 洲代码及瑙鲁亚伦补充；简体中文名称 | 来源、哈希、人工补充与排除表见[来源清单](../../site/data/world-major-cities.sources.json) |

选择条件为来源首都标记，或来源都市人口估计至少 25 万，或制图等级不高于 4 且来源人口估计至少 5 万；仍无入口的地区保留来源中人口最多的中心。人口仅辅助选点，不是当前人口发布值，也不据此认定法定城市。Natural Earth 的历史首都标记不直接转成产品中的“当前首都”标签：新增点标注“主要城市”或“地区中心”。布隆迪基特加依据政府资料单独补入；瑙鲁亚伦标注地区中心，不虚构正式首都地位。

## 数据增量与兼容方式

- 复用全部 10,647 个旧地图 ID、坐标和行政口径；本次合入远端已有的亚洲攻略更新，攻略总数为 958。
- 新快照 [world-major-city-centers.json](../../site/data/world-major-city-centers.json) 使用 `world-ne-<NE_ID>` 或 `world-geonames-<ID>` 稳定身份，保留来源名称、来源类型、坐标、选入理由与 GeoNames 关联。构建输出仍是原 `MapCity`，无需用户数据迁移。
- 全球清单不覆盖已接入国家的专用清单。塞瓦斯托波尔、辛菲罗波尔与既有 GeoNames 身份重复，列入排除表，继续使用既有乌克兰清单 ID；构建拒绝全球快照与旧库存重复。
- 新国家未开放攻略正文编译；后续按国家独立接入已研究内容，可通过 GeoNames 关联原地图 ID。测试覆盖此关联能力，不把尚未写作的攻略计为完成。
- 地图搜索使用完整库存；旧待核验入口继续保留搜索，默认目录仍排除 684 条。全库存 11,753，默认目录 11,069，其中有攻略 958、尚未收录 10,111。
- 名称采用来源中文名，经固定版本 OpenCC 转为简体，常见译名在来源清单显式覆盖。来源法律身份与细分行政关系尚未逐条核验，界面不作此承诺。
- 回滚本次提交可恢复原地图范围，不删除旧入口或保存记录。新入口尚未有攻略；已保存的新 ID 在回滚后需按既有缺入口处理，不应重定向到别的城市。

数据使用 Natural Earth 公有领域资料，GeoNames 为 CC BY 4.0，页面地图署名已补充。原始来源日期与固定版本、哈希在来源清单记录；生成阶段的提取、筛选、简繁转换和亚伦补充已明确标记。更新时将清单指定文件保存到 `site/outputs/world-import/`，运行 `npm run cities:world:import`；哈希变化必须先复核来源再修改清单，正常生产构建只读取已提交快照。

## 验收与实际覆盖

| 样例 | 期望行为 | 验收证据 |
|---|---|---|
| 195 个会员/观察员国与六大洲 | 无遗漏，各国在概览层至少有一个入口 | 全球覆盖与缩放测试通过 |
| 巴黎、纽约、里约、开罗、悉尼、亚伦 | 中文搜索命中对应国家，坐标落在合理范围 | 自动测试；浏览器抽查全球首页、搜索和窄屏布局 |
| 瑙鲁、梵蒂冈、图瓦卢等小国 | 不因人口阈值被漏掉 | 10 个小国样例测试通过 |
| 土耳其、台湾、朝鲜半岛及新发布亚洲攻略 | 类型分层、原 ID、攻略关联、正文链接继续有效 | 与本次新增测试合计 75 项回归通过 |
| 坐标非法、重复身份、未来攻略国家不符 | 明确拒绝，不产生错误空心点或重复攻略入口 | 校验测试通过 |

生产构建、修改文件 ESLint 与差异格式检查通过。生成 `site/outputs/city-map-audit.json` 可查看分国覆盖、缩放统计及 684 条待核验入口。全项目类型检查中的既有生成文件复杂类型、`guideBrowse.ts` 与 Cloudflare 类型问题未在本次范围内修复；不把该检查记为通过。生产构建仍有既有的大文件体积提醒。

此次使用原 GitHub 远程仓库，保留最新 main 的亚洲攻略与发布工作流；完成验证后正常快进推送，不强推。新地点身份完成接入不等于已完成攻略研究，后续攻略继续按项目写作规范独立推进。
