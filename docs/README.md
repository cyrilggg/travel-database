# 旅行地图产品与攻略规范

本项目采用产品、设计、开发并行推进的同步敏捷方式。先读[核心协作约定](working-agreement.md)，再根据本次变化读取具体契约。需求、交互和数据格式可以演进，已有城市与功能通过稳定身份、兼容读取和明确的替代体验继续可用。

Markdown 继续承担攻略正文；地点、路线、图片等按目的地和具体功能逐步补齐。不同国家、城市可以长期处于不同能力水平，新增功能不自动要求全库补齐数据。

本目录规范于 2026-09-06 从原工作区选择性带入；没有复制原工作区的个人攻略、删除状态或历史工作区审计。旧个人稿引用以历史路径文字保留；存在的规范城市稿使用本仓库链接。台湾批次采用当前可读取的 v1 十节正文，并应用新版编辑方法，v2 迁移应在兼容读取和校验工具完成后逐批进行。

网页目前公开加载攻略正文；本次台湾攻略按用户授权在公开 GitHub 仓库及既有网页发布全文。历史的摘要公开、正文私有提案不适用于本批 v1 公共攻略。未来 v2 私有内容需要单独实现导出隔离，正文中写有“私有”或前端不显示某字段都不会提供访问保护。

本项目继续通过 GitHub 管理发布。文档分别标记当前约定、设计提案和历史审计；提案中的字段与功能需以实现及验证证据确认，不能从文档存在推断已上线。
