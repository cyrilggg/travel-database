## 北京旅行可以拆成哪些板块

| 板块 | 典型内容 | 适合怎样安排 |
|---|---|---|
| 中轴线与老城核心 | 宫城、坛庙、前门及周边历史街区 | 首访优先；内容密度高，按相邻片区走，避免一天内反复跨城 |
| 什刹海与胡同片区 | 湖岸、胡同、钟鼓楼周边与城市日常 | 适合连续步行和摄影，可与老城核心相邻模块组合 |
| 西北皇家园林与高校片区 | 颐和园、圆明园及海淀文化资源 | 单独半天至一天；园林内部步行量大，不宜再叠远郊 |
| 城市博物馆与现当代文化 | 国家级博物馆、艺术机构、798 等 | 适合按预约硬锚点组织，也可作为天气不佳时的主模块 |
| 西山与京西古迹 | 山地、寺院、园林及城市边缘自然 | 与中心城区不是同一清图范围，适合重游或单独一天 |
| 长城与远郊 | 不同长城段及郊区历史自然内容 | 交通和体力成本高，应按独立日处理，不把多个长城段当作首访必清 |

对“不喜欢分钟级课表”的用法是：每天只锁定一处预约或远郊交通，再选一个相邻步行片区。北京景点多且预约约束常见，清图时更需要先冻结片区和层级，而不是追求全市百分比。

## 下一步值得补的地区专题

以下是同一座直辖市内部的扩展，不是“待新增城市”。

| 优先级 | 地区或专题 | 补完后能解决什么 |
|---|---|---|
| P1 | 中轴线—前门—什刹海连续步行专题 | 把首访最常用的老城内容变成可增删的路线模块 |
| P1 | 博物馆与预约型场馆专题 | 按兴趣、闭馆日和位置选择硬锚点，减少临时搜索 |
| P1 | 长城段选择专题 | 区分交通成本、步行强度、景观和人流，而不是笼统写“去长城” |
| P2 | 颐和园—圆明园—海淀文化片区 | 建立西北片区的一日与半日版本 |
| P2 | 京西与西山自然历史线 | 服务重游、摄影和自然需求，并与城市核心清图分开 |
| P3 | 通州、顺义等外围新城专题 | 只在出现明确活动、建筑或短居需求时补，不为行政区齐全而扩写 |
