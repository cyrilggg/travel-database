# 浙江省旅行索引

> 浙江当前已有杭州、宁波、临海三种不同样本：省会湖山城市、港口城市、台州古城。它们已经能支撑几种实用路线，但浙北水乡、舟山海岛、浙南海岸和浙西南山地仍未覆盖。

临海以独立城市文件呈现，是因为它可以作为明确目的地使用；省级索引仍会把它放回台州地区理解，避免误以为它与台州市是互不相关的两个省内板块。

## 浙江旅行可以拆成哪些板块

| 旅行板块 | 代表城市或地区 | 核心体验 | 组合提示 |
|---|---|---|---|
| 杭州与浙北江南 | 杭州、嘉兴、湖州 | 湖山、运河、水乡、古镇与江南城市 | 从上海复用率高，但古镇不必全部计入同一次清图 |
| 绍兴—宁波文化港城带 | 绍兴、宁波 | 水城、名人故里、藏书与港口历史 | 适合铁路串联，城市核心分别保留完整半日以上 |
| 舟山群岛 | 舟山及海岛 | 海岛、渔港、海岸与宗教文化 | 船班和天气决定性强，不能当作宁波普通近郊 |
| 台州山海与古城 | 临海、椒江、温岭、天台、仙居等 | 府城、海岸、山岳和小城生活 | 点位分散，应按古城、海岸或山地择一主线 |
| 浙南沿海 | 温州及周边 | 山海、江心、古村与商贸城市文化 | 可与台州相接，但内容足以独立成行 |
| 浙西南山地 | 丽水、衢州 | 山地、古村、摄影与地方历史 | 交通与天气影响更大，适合区域长线 |

## 当前可以怎样组合

- **杭州单城**：3—5 天可按西湖、运河、历史文化与城市日常拆分，不以“绕湖打完全部点位”为目标。
- **杭州＋宁波**：适合比较湖山省会与港城，建议各自保留完整城市日，不做当日往返式清图。
- **宁波＋舟山**：结构上很自然，但舟山尚未有本地文件；真正出行前要补海岛与交通专题。
- **临海＋台州山海**：临海可作古城核心，天台、仙居或沿海只选择一个方向扩展。
- **杭州＋绍兴**：是下一批最值得补齐的历史水城组合，绍兴文件完成前仍属待扩展路线。

|---|---|---|---|
| P1 | 绍兴市 | 历史、水城与名人文化密度高 | 衔接杭州与宁波最实用 |
| P1 | 舟山市 | 海岛和海岸是用户高匹配类型 | 解决宁波向海岛扩展时的路线与天气边界 |
| P1 | 嘉兴市、湖州市 | 用户去过嘉兴，且从上海短途复用率高 | 补齐浙北江南与水乡结构 |
| P2 | 台州市专题 | 将临海与温岭、天台、仙居等分区 | 避免一个县级市文件代表整个台州 |
| P2 | 温州市 | 山海与城市文化兼具 | 建立浙南沿海入口 |
| P2 | 丽水市、衢州市 | 古村、山地和摄影潜力高 | 补足浙江内陆，不让知识库只覆盖沿海 |
